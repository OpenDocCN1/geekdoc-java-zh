
# 编辑器和 IDE

Clojure 为许多编辑器和 IDE 提供了插件。

对于 Emacs，有 `clojure-mode` 和 `swank-clojure`，两者都位于 [`github.com/technomancy/swank-clojure`](https://github.com/technomancy/swank-clojure)。`swank-clojure` 使用适用于 Emacs 的 Superior Lisp Interaction Mode（Slime），相关介绍请参阅 [`common-lisp.net/project/slime/`](http://common-lisp.net/project/slime/)。

对于 Vim，有 VimClojure，参见 [`kotka.de/projects/clojure/vimclojure.html`](http://kotka.de/projects/clojure/vimclojure.html)。

对于 NetBeans，有 enclojure，参见 [`enclojure.org/`](http://enclojure.org/)。

对于 IDEA，有 “La Clojure”，参见 [`plugins.intellij.net/plugin/?id=4050`](http://plugins.intellij.net/plugin/?id=4050)。

对于 Eclipse，有 Counter Clockwise，参见 [`dev.clojure.org/display/doc/Getting+Started+with+Eclipse+and+Counterclockwise`](http://dev.clojure.org/display/doc/Getting+Started+with+Eclipse+and+Counterclockwise)。
