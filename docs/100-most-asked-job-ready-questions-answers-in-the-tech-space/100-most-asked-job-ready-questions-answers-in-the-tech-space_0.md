## 第一章：100 道高频 Python 求职面试题

1. **什么是 Python？**

   `Python` 是一种高级、解释型编程语言，以其简单性和易读性闻名。它强调代码的可读性，并鼓励简洁清晰的编码风格。

2. **Python 的核心特性有哪些？**

   `Python` 的核心特性包括易于阅读的语法、动态类型、自动内存管理、丰富的标准库以及对多种编程范式的支持。

3. **Python 与编程语言有什么区别？**

   `Python` 以其简单性、可读性和易于理解的语法脱颖而出。它拥有庞大活跃的社区、丰富的库，并广泛应用于 Web 开发、数据分析和科学计算等领域。

4. **什么是 PEP 8？**

   `PEP 8` 是 `Python` 代码的官方风格指南。它提供了关于如何格式化 `Python` 代码的指导，以增强可读性并保持项目的一致性。

5. **什么是 Python 模块（modules）？**

   `Python` 模块是包含 `Python` 代码的文件，定义了函数、类和变量。它们允许代码重用和组织，使得管理和维护大型项目变得更容易。

6. **什么是 Python 包（package）？**

   `Python` 包是将相关模块组织到目录层次结构的方法。它允许对模块进行逻辑分组，使代码更容易管理和分发。

7. **在 Python 中如何注释？**

   `Python` 中的注释用 `#` 字符表示。`#` 之后的任何内容都被视为注释，并被 `Python` 解释器忽略。

8. **Python 数据类型有哪些？**

   `Python` 支持多种数据类型，包括整数、浮点数、字符串、列表、元组、字典和布尔值。每种数据类型都有自己的特性和用途。

9. **Python 中的类型转换是什么？**

   类型转换也称为类型强制转换，是将一种数据类型转换为另一种数据类型的过程。`Python` 提供了 `int()`、`float()`、`str()` 等内置函数来执行类型转换。

10. **什么是 Python 中的字符串插值（string interpolation）？**

    `Python` 中的字符串插值允许你在字符串中嵌入表达式或变量，从而更方便地构建动态字符串。可以使用 `f-strings` 或 `format()` 方法来实现。

11. **Python 的条件语句包含哪些？**

    `Python` 的条件语句（如 `if`、`elif` 和 `else`）允许你根据某些条件执行不同的操作。它们根据条件的真假控制程序的执行流。

12. **什么是 Python 循环？**

    `Python` 循环（如 `for` 和 `while`）允许你重复执行一段代码块。它们遍历序列或持续执行到满足特定条件为止。

13. **Python 2 中 range() 和 xrange() 有什么区别？**

    在 `Python` 2 中，`range()` 生成一个数字列表，而 `xrange()` 返回一个迭代器。`xrange()` 在处理大范围时更节省内存，因为它按需生成值。

14. **什么是 Python 函数？**

    `Python` 函数是执行特定任务的可复重用代码块。它们有助于代码组织、重用和模块化。函数可以接受参数并返回结果。

15. **Python 中函数和方法（method）有什么区别？**

    在 `Python` 中，函数是独立调用的代码块。而方法是与对象或类相关的函数，可以访问对象的数据。

16. **如何在 Python 中定义函数？**

    在 `Python` 中，使用 `def` 关键字定义函数，后面跟着函数名、括号（如果有参数）和一个冒号。函数体需要缩进。

17. **`__init__` 方法的作用是什么？**

    `__init__` 方法是 `Python` 类中的一种特殊方法，在从类创建对象时自动调用。它用于初始化对象的属性并执行设置工作。

18. **什么是面向对象编程（OOP）？**

    面向对象编程（`OOP`）是一种通过对象组织代码的编程范式。它强调封装、继承和多态。

19. **Python 的类和对象是什么？**

    在 `Python` 中，类是定义对象属性和行为的蓝图。对象是类的实例。它代表一个特定的实体并能与其他对象交互。

20. **如何在 Python 中创建对象？**

    通过像调用函数一样调用类来创建对象。类充当构造函数，初始化对象并返回它。

21. **Python 中的继承是什么？**

    继承是 `Python` 中的一种机制，允许类从另一个类继承属性和方法。它实现了代码重用并支持创建层次类结构。

22. **什么是方法重写（method overriding）？**

    方法重写是在子类中定义与父类同名的方法的过程。子类方法覆盖了父类方法的实现。

23. **什么是方法重载（method overloading）？**

    `Python` 不直接支持方法重载。但是，你可以通过定义具有默认参数值的单一方法或使用可变参数来实现类似的功能。

24. **什么是 Python 中的封装（encapsulation）？**

    封装是将数据和方法封装在类中的过程。它允许数据隐藏，并通过 getter 和 setter 方法控制对对象属性的访问。

25. **什么是 Python 中的多态（polymorphism）？**

    多态是指对象采取多种形式或具有多种行为的能力。在 `Python` 中，多态通过方法重写和方法重载（使用默认参数值或可变参数）来实现。

26. **什么是 Python 中的生成器（generator）？**

    `Python` 中的生成器是一个返回迭代器的函数。它允许你动态地生成一个值序列，从而节省内存并提高性能。

27. **什么是 Python 中的装饰器（decorators）？**

    装饰器是在不直接更改源代码的情况下修改函数或类行为的方法。它们使用 `@decorator_name` 语法定义，可以用于日志记录、计时或修改函数参数等任务。

28. **什么是 Python 中的 lambda 函数？**

    lambda 函数是 `Python` 中的一种匿名函数，使用 `lambda` 关键字定义。它是一种创建小型单行函数的简便方法，而无需使用 `def` 显式地定义函数。

29. **什么是 Python 中的模块（module）？**

    `Python` 中的模块是一个包含 `Python` 定义和语句的文件。它可以被导入并用于其他 `Python` 程序中，以访问其函数、类和变量。

30. **如何在 Python 中导入模块？**

    在 `Python` 中，可以使用 `import` 关键字加上模块名来导入模块。你也可以使用 `from module_name import object_name` 语法从模块中导入特定对象。

31. **什么是 Python 中的虚拟环境（virtual environment）？**

    `Python` 中的虚拟环境是一个自包含的目录，包含特定版本的 `Python` 解释器和已安装的包。它允许为不同的项目隔离 `Python` 环境并管理它们的依赖关系。

32. **什么是 Python 中的异常（exceptions）？**

    `Python` 中的异常是程序执行过程中发生的、中断代码正常流的事件。可以使用 `try-except` 块来优雅地处理错误和异常。

33. **什么是 Python 中的错误处理（error handling）？**

    `Python` 中的错误处理涉及使用 `try-except` 块来捕获并处理代码执行过程中可能发生的异常。它允许从错误中优雅地恢复，并防止程序崩溃。

34. **Python 中 `try-except-else-finally` 块的作用是什么？**

    `Python` 中的 `try-except-else-finally` 块用于异常处理。`try` 块包含可能抛出异常的代码。`except` 块用于处理特定的异常。`else` 块在没有发生异常时执行。`finally` 块无论是否发生异常都会始终执行。

35. **Python 中的内置数据结构有哪些？**

    `Python` 提供了几种内置数据结构，包括列表（lists）、元组（tuples）、字典（dictionaries）、集合（sets）和字符串（strings）。这些数据结构提供了存储、操作和检索数据的不同方式。

36. **什么是 Python 中的列表？**

    `Python` 中的列表是元素的有序集合，可以是不同的数据类型。它是可变的，意味着它的元素可以被修改。列表用方括号 `[ ]` 表示，可以包含用逗号分隔的元素。

37. **什么是 Python 中的元组（tuple）?**

    `Python` 中的元组是类似于列表的元素有序集合。然而，元组是不可变的，意味着一旦赋值，其元素就无法更改。元组用圆括号 `( )` 表示，可以包含用逗号分隔的元素。

38. **什么是 Python 中的字典（dictionary）?**

    `Python` 中的字典是键值对的无序集合。它是可变的，并允许根据关联的键快速访问值。字典用花括号 `{ }` 表示，并使用冒号 `:` 分隔键和值。

39. **什么是 Python 中的集合（set）？**

    `Python` 中的集合是唯一元素的无序集合。它是可变的，并提供了数学集合操作，如并集、交集和差集。集合用花括号 `{ }` 或 `set()` 函数表示。

40. **什么是 Python 中的字符串（string）？**

    `Python` 中的字符串是用单引号、双引号或三引号括起来字符序列。它是不可变的，意味着它的单个字符不能被更改。字符串可以通过多种方式进行操作和处理。

41. **如何在 Python 中拼接字符串？**

    在 `Python` 中可以使用 `+` 运算符或使用 `.join()` 方法来拼接字符串。`+` 运算符拼接两个字符串，而 `.join()` 方法使用指定的分隔符拼接多个字符串。

42. **如何在 Python 中格式化字符串？**

    在 `Python` 中可以使用 `%` 运算符、`str.format()` 方法或 f-strings（格式化字符串字面量）对字符串进行格式化。这些方法允许你将值插入字符串中的占位符中。

43. **Python 中的文件操作有哪些？**

    `Python` 中的文件操作涉及读取和写入文件。`Python` 提供了打开、读取、写入和关闭文件的内置函数和方法。

44. **如何在 Python 中打开和关闭文件？**

    在 `Python` 中可以使用 `open()` 函数打开文件，它接受文件名和操作模式作为参数。`close()` 方法用于关闭已打开的文件并释放系统资源。

45. **Python 中不同的文件模式有哪些？**

    `Python` 中不同的文件模式包括用于读取的 `"r"`、用于写入的 `"w"`（覆盖现有内容）、用于追加的 `"a"`、用于独占创建 `"x"`（如果文件已存在则失败）以及用于二进制模式的 `"b"`。

46. **文件操作中的异常处理是什么？**

    文件操作中的异常处理涉及处理执行文件相关操作时可能发生的错误。这确保程序能够优雅地处理文件相关异常，并避免崩溃或数据丢失。

47. **什么是 Python 中的上下文管理器（context manager）？**

    `Python` 中的上下文管理器是一个定义了 `__enter__()` 和 `__exit__()` 方法的对象，用于启用 `with` 语句。它允许资源的分配和释放，例如在使用后自动关闭文件。

48. **什么是 Python 中的生成器函数（generator function）？**

    `Python` 中的生成器函数是一种使用 `yield` 关键字而不是 `return` 的特殊函数。它允许动态生成值序列，而无需将其全部存储在内存中。

49. **什么是 Python 中的列表推导式（list comprehension）？**

    `Python` 中的列表推导式是一种基于现有列表或其他迭代对象创建列表的简洁方法。它允许在单行代码中结合循环和条件逻辑。

50. **什么是 Python 中的 `pass` 语句？**

    `Python` 中的 `pass` 语句是一种不执行任何操作的占位语句。它在 `Python` 语法需要语句但不需要操作时作为句法占位符。

51. **Python 中 `self` 参数的作用是什么？**

    `self` 参数在 `Python` 中用作类实例的引用。它允许在类定义内部访问该实例的属性和方法。

52. **Python 中浅拷贝（shallow copy）和深拷贝（deep copy）的区别是什么？**

    在 `Python` 中，浅拷贝创建一个引用原始数据的新对象，而深拷贝则创建一个具有原始数据独立副本的新对象。修改原始数据不会影响深拷贝，但可能会影响浅拷贝。

53. **什么是 Python 中的全局解释器锁（GIL）？**

    全局解释器锁（`GIL`）是 `CPython` 解释器（Python 的引用实现）中的一种机制，允许只有一个线程执行 `Python` 字节码。这限制了 `Python` 线程的并行执行，并在某些情况下会影响性能。

54. **Python 中的元类（metaclass）是什么？**

    `Python` 中的元类是一种用于定义其他类的行为和结构的类。它允许你自定义类的创建、修改属性并为类添加额外的功能。

55. **如何在 Python 中处理文件 I/O 错误？**

    `Python` 中的文件 I/O 错误可以使用异常处理来处理。通过在文件相关操作周围使用 `try-except` 块，你可以捕获特定的异常（如 `FileNotFoundError` 或 `PermissionError`）并优雅地处理它们。

56. **Python 中 `__name__` 变量的目的是什么？**

    `Python` 中的 `__name__` 变量是一个内置变量，代表当前模块的。它可以用于判断一个模块是作为主脚本运行的还是作为模块导入的。

57. **Python 中浅比较（shallow comparison）和深比较（deep comparison）的区别是什么？**

    在 `Python` 中，浅比较检查两个对象是否具有相同的内存地址，而深比较检查对象是否具有相同的值。浅比较可以使用 `is` 运算符完成，而深比较通常使用 `==` 运算符完成。

58. **在 Python 中使用虚拟环境（virtual environments）有什么优势？**

    `Python` 中的虚拟环境为每个项目提供了一个专用环境，允许你隔离项目依赖，避免包之间的冲突，并维护项目特定的 `Python` 版本和包版本。

59. **Python 中 `__main__` 块的目的是什么？**

    `Python` 中的 `__main__` 块用于定义 `Python` 程序的入口。`if __name__ == "__main__":` 块中的代码只有在脚本被直接运行时才会执行，当它作为模块导入时不执行。

60. **Python 中 `__str__` 方法的目的是什么？**

    `Python` 中的 `__str__` 方法是一种特殊方法，用于返回对象的字符串表示。它用于在调用 `str()` 函数或打印对象时，提供一个人类可读的对象的表示。

61. **Python 中 `__repr__` 方法的目的是什么？**

    `Python` 中的 `__repr__` 方法是一种特殊方法，用于返回对象的字符串表示，该表示可以用于重建对象。它用于提供一个详细且无歧的对象的表示。

62. **Python 中 `__str__` 和 `__repr__` 方法的区别是什么？**

    `__str__` 方法旨在为对象提供一个人类可读的字符串表示，而 `__repr__` 方法旨在提供一个详细且无歧的字符串表示，并用于重建对象。

63. **Python 中 `super()` 函数的目的是什么？**

    `Python` 中的 `super()` 函数用于调用超类或父类中的方法。它通常用于方法重写，在向子类中添加额外功能之前调用父类对该方法的实现。

64. **Python 中 `__getitem__` 方法的目的是什么？**

    `Python` 中的 `__getitem__` 方法是一种特殊方法，允许对象定义索引和切片操作的行为。当使用方括号 `[]` 访问项时会调用该方法，并支持通过索引或切片访问项。

65. **Python 中 `__setitem__` 方法的目的是什么？**

    `Python` 中的 `__setitem__` 方法是一种特殊方法，允许对象定义使用方括号 `[]` 为项赋值的行为。当使用索引为项赋值时会调用该方法。

66. **Python 中 `__len__` 方法的目的是什么？**

    `Python` 中的 `__len__` 方法是一种特殊方法，返回对象的长度。当在对象上使用 `len()` 函数时会调用它。

67. **Python 中 `__iter__` 方法的目的是什么？**

    `Python` 中的 `__iter__` 方法是一种特殊方法，返回一个迭代器对象。它用于使对象变得可迭代，这意味着可以使用 `for` 循环对其进行遍历，或者与其他迭代器相关的函数和结构一起使用。

68. **Python 中 `__next__` 方法的目的是什么？**



Python 中的`__next__`方法是一种特殊方法，返回迭代器中的下一个项。它由`next()`函数调用，并与`__iter__`方法配合使用创建自定义迭代器。

## 70. Python 中`@property`装饰器的目的是什么？

Python 中的`@property`装饰器用于将方法定义为类属性的 getter（get）。它允许像访问普通属性一样访问该属性，同时内部调用 getter 方法。

## 71. Python 中`@staticmethod`装饰器的目的是什么？

Python 中的`@staticmethod`装饰器用于在类中定义静态方法。静态方法不需要类的实例即可调用，并且可以直接从类本身访问。

## 72. Python 中`@classmethod`装饰器的目的是什么？

Python 中的`@classmethod`装饰器用于定义类方法（class method）。类方法接收类本身作为第一个参数，允许它们访问和修改类级属性并执行特定于类的操作。

## 73. Python 中`__call__`方法的目的是什么？

Python 中的`__call__`方法是一种特殊方法，允许对象像函数一样被调用。

## 74. Python 中`*args`和`**kwargs`的目的是什么？

Python 中的`*args`允许接收任意数量的位置参数（元组），而`**kwargs`允许接收任意数量的关键字参数（字典）。

## 75. Python 中的装饰器（decorators）是什么？

Python 中的装饰器是一种在不直接修改源代码的情况下修改或增强函数行为的方法。装饰器包装目标函数或类并添加额外的功能。

## 76. Python 中`@classmethod`装饰器的目的是什么？

Python 中的`@classmethod`装饰器用于定义类方法。类方法接收类本身作为第一个参数，允许它们访问和修改类级属性并执行特定于类的操作。

## 77. Python 中的`lambda`函数是什么？

Python 中的`lambda`函数是一种定义在单行的匿名函数。它通常用于简单的一次性操作，不需要`def`语句。

## 78. Python 中的模块（modules）是什么？

Python 中的模块包含 Python 代码和定义的文件。它们可以被导入并用于其他 Python 程序以提供重用功能。

## 79. Python 中的包（packages）是什么？

Python 中的包是将相关模块组织成目录层次结构。它们允许对代码进行更好的组织和模块化，便于管理大型项目。

## 80. 包中`__init__.py`文件的目的是什么？

`__init__.py`文件作为该目录是 Python 包的标识。它可以为空，也可以包含在包被导入时执行的初始化代码。

## 81. Python 中`sys`模块的目的是什么？

# 第 2 章

## 100 道高频 SQL 职位面试题

### 1. 什么是 SQL？

a. `SQL`（结构化查询语言）是一种用于管理关系型数据库的编程语言。它允许用户从数据库中存储、操作和检索数据。

### 2. SQL 语句有哪些不同的类型？

a. SQL 语句可以分为三类：

i. 数据定义语言 (DDL)：用于创建、修改和删除数据库对象。

ii. 数据操作语言 (DML)：用于查询、插入、更新和删除数据。

iii. 数据控制语言 (DCL)：用于控制数据库访问，授予或撤销权限。

### 3. 什么是主键（Primary Key）？

a. 主键是表中用于唯一标识每条记录的列或列集合。它确保了数据的完整性并允许高效地检索数据。

### 4. 什么是外键（Foreign Key）？

a. 外键是表中的一列或一组列，它引用另一个表的主键。它在两个表之间建立了关系。

### 5. 什么是复合键（Composite Key）？

a. 复合键是由两个或多个列组成的主键。这些列共同唯一标识了表中的每条记录。

### 6. `DELETE`和`TRUNCATE`之间的区别是什么？

a. `DELETE`是一种 DML 语句，用于从表中删除特定行；而`TRUNCATE`是一种 DDL 语句，用于删除表中的所有行并重置表。

### 7. 什么是子查询（Subquery）？

a. 子查询是嵌套在另一个查询中的查询。它可以根据另一个表的值从一个表中检索数据或执行复杂的计算。

### 8. 子查询和连接（Join）之间的区别是什么？

a. 子查询是嵌套在另一个查询中的查询，而连接用于根据相关列合并两个多个表的行。

### 9. 什么是自连接（Self-join）？

a. 自连接是将表与其自身进行连接的操作。当你需要比较同一表内的行时，它是非常有用的。

### 10. `JOIN`操作有哪些不同的类型？

a. `JOIN`操作类型有：

i. `INNER JOIN`：返回两个表中匹配的行。

ii. `LEFT JOIN`：返回左表的所有行以及右表的匹配行。

iii. `RIGHT JOIN`：返回右表的所有行以及左表的匹配行。

iv. `FULL JOIN`：返回两个表的所有行。

### 11. SQL 中的归一化（Normalization）是什么？

a. 归一化是组织数据库数据以消除冗余和依赖问题的过程。它涉及将表分成更小、更易管理的实体。

### 12. 数据库归一化的不同范式有哪些？

a. 不同的范式有：

i. 第一范式 (1NF)：消除重复行并确保值的原子性。

ii. 第二范式 (2NF)：确保每个非键列都依赖于整个主键。

iii. 第三范式 (3NF)：确保每个非键列只依赖于主键，而不依赖于其他非键列。

iv. 第四范式 (4NF)：消除多值依赖。

v. 第五范式 (5NF)：消除连接依赖。

### 13. 什么是索引（Index）？

a. 索引是一种提高数据库表数据检索速度的数据库结构。它允许对数据进行快速搜索、排序和过滤。

### 14. 什么是聚集索引（Clustered Index）？

a.

聚簇索引决定了表中数据的物理顺序。每个表只能有一个聚簇索引，它通常创建在主键列上。

### 15. 什么是非聚簇索引？

非聚簇索引是一个独立于于表的单独结构，其中包含所选列的排序列表。它增强了搜索和过滤操作的性能。

### 16. 主键和唯一键之间有什么区别？

主键是列或一组列，它能够唯一地标识表中的每条记录，且不能包含 NULL 值。相反，唯一键允许 NULL 值并强制执行唯一性，但不会自动定义表的主标识符。

### 17. 数据库事务中的 ACID 是什么？

ACID 代表原子性（Atomicity）、一致性（Consistency）、隔离性（Isolation）和持久性（Durability）。它是一组确保数据库事务可靠性和完整性的属性。

### 18. `UNION`和`UNION ALL`之间有什么区别？

`UNION`连接两个或多个`SELECT`语句的结果集并删除重复项，而`UNION ALL`结合结果集但不删除重复项。

### 19. 什么是视图？

视图是根据一个或多个表派生的虚拟表。它不存储数据，但提供了一种以自定义或简化方式呈现数据的方法。

### 20. 什么是存储过程？

存储过程是一组预编译的 SQL 语句，用于执行特定任务。它可以使用不同的参数多次调用和执行。

### 21. 什么是触发器？

触发器是一组 SQL 语句，会对特定事件（如表上的`INSERT`、`UPDATE`或`DELETE`操作）自动执行。

### 22. 什么是事务？

事务是一个逻辑单元，由一个或多个数据库操作组成。它确保事务内的所有操作被视为一个整体，要么全部成功，要么全部失败。

### 23. 什么是死锁？

死锁是指两个或多个事务无法进行，因为每个事务都在等待另一个事务持有的资源。这可能导致永久等待状态。

### 24. `CHAR`和`VARCHAR`数据类型之间有什么区别？

`CHAR`是固定长度的字符数据类型，存储特定数量的字符，而`VARCHAR`是变长度字符数据类型，存储不同数量的字符。

### 25. 函数和存储过程之间有什么区别？

函数返回一个值并可 SQL 语句，而存储过程不直接返回值，但可以执行各种操作。

### 26. `GROUP BY`和`HAVING`子句之间有什么区别？

`GROUP BY`用于根据一个或多个列对行分组，而`HAVING`用于根据特定条件过滤分组后的行。

### 27. 数据库和模式（Schema）之间有什么区别？

### 28. 什么是数据仓库？

### 29. `OLTP`和`OLAP`之间有什么区别？

`OLTP`（在线事务处理）用于日常事务性操作，侧重于实时处理。`OLAP`（在线分析处理）用于复杂的分析查询，侧重于历史数据分析。

### 30. 什么是相关子查询？

相关子查询是引用外部查询列的子查询。它为外部查询的每一行执行一次，因此依赖于外部查询的结果。

### 31. 临时表和表变量之间有什么区别？

临时表是在会话或特定作用域内创建并临时物理表，而表变量是一个结构与表类似的变量，仅存在于用户定义函数或存储过程的作用域内。

### 32. `UNION`和`JOIN`之间有什么区别？

`UNION`在垂直方向上合并两个或多个表的行，而`JOIN`根据相关列在水平方向上合并两个或多个表的列。

### 33. `WHERE`和`HAVING`子句之间有什么区别？

`WHERE`用于在查询分组前过滤行，而`HAVING`用于在分组后过滤分组后的行。

### 34. 数据库和数据仓库之间有什么区别？

数据库是为事务目的而组织的相关数据集合，而数据仓库是为分析目的组织的大型数据库。

### 36. 模式（Schema）和数据库之间有什么区别？

答案：静态方法在任何类中都不能被重写，而接口中的任何方法默认都是 `abstract`（抽象的），并且应该在实现接口的类中实现。因此，在 Java 接口中有静态方法是没有意义的。

### 71. 在 Java 中可以通过多少种方式实现同步（synchronization）？

答案：在 Java 中实现同步有两种方法：

1. `Synchronized` 方法
2. `Synchronized` 块

为了实现同步，我们使用 `synchronized` 关键字。

### 72. 什么时候使用同步块（synchronized blocks），使用同步块有什么优点？

答案：如果只有少数几行代码需要同步，建议使用 `synchronized` 块。`synchronized` 块相比 `synchronized` 方法的主要优势是它减少了线程的等待时间并提高了系统性能。

### 73. Java 中访问修符（access specifiers）和访问修饰符（access modifiers）的区别是什么？

答案：在 C++ 中，我们有访问修符如 `public`、`private`、`protected` 和 `default`，以及访问修饰符 `static`、`final`。但在 Java 中没有这种访问修符和访问修饰符的划分。在 Java 中，我们有访问修饰符是非访问修饰符。

- 访问修饰符：`public`、`private`、`protected`、`default`
- 非访问修饰符：`abstract`、`final`、`strip`。

### 75. 类可以使用哪些访问修饰符？

答案：对于类可以使用两种访问修饰符：`public` 和 `default`。

- `public`：具有此修饰符的类可以在 1) 同一个类 2) 相同的包子类 3) 相同的包内 4) 不同的包 5) 不同的子类中访问。
- `default`：具有此修饰符的类可以在 1) 同一个类 2) 相同的包子类 3) 相同的包内访问，4) 不同的包 5) 不同的子类无法访问。

### 76. 解释 Java 中的抽象类（abstract classes）？

答案：有时我们可能会遇到无法为类提供实现的情况。我们希望将实现留给子类。在这种情况下，我们将类声明为 `abstract`。要使类变为抽象类，我们使用 `abstract` 关键字。任何包含抽象方法的类都声明为 `abstract`。如果我们尝试将包含抽象方法的类声明为非抽象类，将会产生编译错误。我们将得到以下错误：“必须是抽象类才能定义抽象方法。”



例如，如果我们取一个 `vehicle` 类，我们无法为其提供实现，因为可能有两轮车、四轮车等。在此时，我们将 `vehicle` 类变为抽象类。所有车辆的共同特征都声明为 `vehicle` 类中的抽象方法。任何扩展 `vehicle` 的类将提供其方法实现。这是子类的责任。

抽象类的重要特征是：

1. 抽象类不能实例化。
2. 抽象类包含抽象方法、具体方法或两者都有。
3. 任何扩展抽象类的类必须重写抽象类的方法。
4. 抽象类可以包含 0 个或多个抽象方法。

虽然我们不能实例化抽象类，但可以创建引用。通过父类引用，我们可以指向子类。

### 77. 抽象类可以创建构造函数吗？

答案：我们可以在抽象类中创建构造函数，这不会产生任何编译错误。但由于无法实例化，为抽象类创建构造函数是没有意义。

### 78. `String` 和 `StringBuffer` 都表示字符串对象。在 Java 中可以比较 `String` 和 `StringBuffer` 吗？

答案：虽然 `String` 和 `StringBuffer` 都表示字符串对象，但我们无法相互比较它们，如果我们尝试比较它们，将会得到错误。

### 79. 在 Java 中可以通过多少种方式创建线程？

答案：我们可以通过两种方式之一在 Java 中创建线程：

1. 扩展 `Thread` 类。
2. 实现 `Runnable` 接口。

### 80. 解释通过实现 `Runnable` 类来创建线程？

答案：这是创建线程的第一种也是主要的方法。通过实现 `Runnable` 接口并实现 `run()` 方法，我们可以创建一个新线程。方法签名：`public void run()`。`run` 是程序中另一个线程执行的起始点。

示例：

```java
public class MyClass implements Runnable {
    @Override
    public void run()
}
```

### 81. 在 Java 中我们何时使用同步方法（synchronized methods）？

答案：如果多个线程尝试访问一个方法，且该方法可能会操作对象的状态，在这种情况下，我们可以将方法声明为 `synchronized`。

### 82. 我们能通过类型转换将任何其他类型转换为 Boolean 类型吗？

答案：不能，我们既不能将任何原始数据类型转换为 `Boolean` 数据类型，也不能将 `Boolean` 数据类型转换为任何其他原始数据类型。

### 83. 什么是同步方法（synchronized methods）和同步语句（synchronized statements）？

答案：同步方法是用于控制对对象访问的方法。`synchronized` 语句只有在线程获取了 `synchronized` 语句所引用的对象或类的锁后才能被执行。

### 84. 解释 Java 中 finally 块的重要性？

答案：`finally` 块用于清理资源，例如关闭连接、套接字等。如果 `try` 块执行时没有异常，则 `finally` 在 `try` 块之后被调用，而不执行 `catch` 块。如果 `try` 块中抛出异常，`finally` 块会在 `catch` 块之后立即执行。如果抛出了异常，即使没有 `catch` 块处理异常，`finally` 块也会执行。

### 85. 我们可以在单个 catch 块中捕获多个异常吗？

答案：从 Java 7 开始，我们可以用单个 `catch` 块捕获多个异常。这种处理方式减少了代码重复。注意：当我们在单个 `catch` 块中捕获多个异常时，`catch` 参数是隐式 `final` 的。我们无法为 `catch` 参数分配任何值。例如：`catch(ArrayIndexOutOfBoundsException | ArithmeticException e)`

在上面的示例中，`e` 是 `final` 的，我们无法在 `catch` 语句中为 `e` 分配值或修改 `e`。

### 86. Java 中的抽象方法（abstract methods）是什么？

答案：抽象方法是没有主体的方法。`abstract` 方法用 `abstract` 关键字声明，并用分号代替方法体。签名：`public abstract void ();` 示例：`public abstract void getDetails();` 为 `abstract` 类中定义的 `abstract` 方法提供实现是子类的责任。

### 87. 列举一些 Java 中可能出现异常的情况？

答案：

1. 访问数组中不存在的元素。
2. 数字到字符串以及字符串到数字的无效转换（`NumberFormatException`）。
3. 类的无效强制转换（`ClassCastException`）。
4. 尝试为接口或抽象类创建对象（`InstantiationException`）。

### 88. Java 中的异常（exception）是什么？

答案：在 Java 中，异常是一个对象。当程序出现异常时，就会创建异常。异常可以由 `JVM` 创建，也可以由应用程序代码创建。所有的 `Exception` 类都定义在 `java.lang` 中。换句话说，我们可以把 `Exception` 视为运行时错误。

### 89. Java 中的错误（error）是什么？

答案：`Error` 是 Java 中 `Throwable` 类的子类。当错误由我们的程序引起时，我们称之为 `Exception`，但有时异常是由环境问题（如内存耗尽）引起的。在这种情况下，我们无法处理这些异常。无法恢复的异常在 Java 中被称为错误。例如：`OutOfMemory` 问题。

### 90. Java 中异常处理的优点是什么？

答案：

1. 将正常代码与异常处理代码分离，以避免程序的非正常终止。
2. 将异常分类为不同类型 `Exceptions`，这样我们就不用 `Exception` 根类处理所有异常，而是可以使用特定的异常进行处理。建议使用特定的 `Exception` 处理异常，而不是使用 `Exception` 根类。
3. 调用栈机制：如果一个方法抛出异常且未被立即处理，则该异常将传播或抛给该方法的调用者。这种传播会一直持续直到找到合适的异常处理器，如果找到了句柄，异常就会被处理；否则程序将异常终止。

### 91. 构造函数（constructors）与其他方法之间的区别是什么？

答案：构造函数的名称必须与类相同，且没有返回值。它们只会被调用一次，而普通方法可以被调用多次。

### 93. 何何以及如何使用私有构造函数（private constructor）？

### 94. 什么是类型转换（type casting）？

答案：类型转换意味着将一种类型的变量视为另一种类型。

### 95. `>>` 运算符和 `>>>` 运算符的区别是什么？

答案：`>>` 运算符在右移时会保留符号位。`>>>` 运算符会将向右移出的位填充零。

### 96. 内部类（inner class）和嵌套类（nested class）的区别是什么？

答案：当一个类被定义在另一个类的作用范围内时，它就变成内部类。如果内部类的访问修饰符是 `static`，则它变成嵌套类。

### 97. 如果类有多个构造函数，可以从一个构造函数调用另一个吗？

答案：可以，使用 `this()` 语法。

### 98. 为什么我们需要包装类（wrapper classes）？

答案：当方法期望对象时，我们可以将其作为方法参数传递。它还提供了工具方法。

### 99. Java 允许默认参数（Default Arguments）吗？

答案：不，Java 不允许默认参数。
