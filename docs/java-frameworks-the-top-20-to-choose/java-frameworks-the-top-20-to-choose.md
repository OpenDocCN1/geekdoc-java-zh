
# JavaScript 框架精选：20 佳选

过去一年，JavaScript 社区经历了一些重大的变革。ECMAScript 6 终于正式标准化并付印，众多知名编译器和网页浏览器都在努力适应所有新的规范和变更。要完全理解这种大规模的更新（上一次 ES 升级是在 2009 年），你需要熟悉一份优秀的分步指南，该指南详细讨论了新基准的各个方面。而我们能找到的最好的指南来自 Lars Kappert，他在 Smashing Mag 上分享了他的 ES6 变更记录文章。

在将 ES6 特性引入浏览器方面，Mozilla Firefox（85%）和 Google Chrome（71%）目前遥遥领先，其他浏览器也在紧随其后。然而，JavaScript 远不止于一门标准语言——今年有许多真正优秀的程序和平台为开发者构建和发布，其中最新的是 OS.js——一个功能完善的云平台，将桌面计算机功能集成到浏览器中。

JavaScript 正在快速发展，它正变得更加原生化，但最重要的是——它正变得更加稳定。近年来，JavaScript 世界的 Web 开发框架数量大幅增长，许多框架已经建立了庞大的社区，例如 `Angular`、`Meteor` 和 `React` 等。在本文中，我们将更深入地了解当前最热门的 JavaScript 框架，我们坚信这些框架在 2016 年将会有大量的发展、参与和曝光。请与我们分享你在使用列表中框架时的个人体验，因为我们非常希望能了解更多关于每个框架的具体使用案例。

## 响应式 JavaScript 框架

响应式 Web 开发的核心在于响应能力、弹性、可扩展性和精确性。我们希望构建的应用能够实时响应其面临的各种需求，同时我们也希望系统在峰值性能或来自未知来源的需求下依然保持弹性，并且我们的项目需要具备可扩展性，以便在需要时可以轻松地升级或降级应用以获得最佳性能。这些 JavaScript 框架正是为响应式 Web 开发而构建的，我们期待听到更多关于可能被遗漏的框架的介绍。

### MobX

借助 `MobX`，你将能够开始精心打造你的数据结构，同时让你的函数具有响应性，这意味着当数据实时发生变化时，它们会自动重新计算。从你的数据结构中取出任意一块数据并将其转换为另一行，然后将你的函数转变为自动更新的公式。`MobX` 的使命是帮助程序员轻松高效地构建始终完全响应式的视图，而无需承担其他全渲染框架可能带来的额外开销。

### Omniscient.js

`Omniscient` 为程序员提供了基于透明组件构建功能性 UI 的工具和特性，允许一种更静态的开发方式。非常类似于我们在 HTML 中进行的静态 Web 开发，但 `Omniscient` 赋予了编程的能力。你仍然可以将你的视图构建得优雅流畅，只是无需再使用模板引擎或领域特定语言等工具。`Omniscient` 倡导小型、可组合的组件，以及通过 `mixins` 实现共享性能。

### Ractive.js

`Ractive` 已经存在一段时间了，许多世界顶级网站都采用了其原生性能来构建基于模板的用户界面元素，这些元素支持 JavaScript 的特性和灵活性。在浏览器中创建类似交互式应用的体验并非易事，从来都不是，但 `Ractive` 是那些罕见的框架之一，它有助于弥合这一差距，并帮助构建更简单的体验。Toptal 的 Eugene Mirotin 深入探讨了 `Ractive` 的功能，并研究了构建一个简单、响应式且交互式的应用的过程。

### Mercury

`Mercury` 是一个轻量、简洁且功能强大的模块化前端框架，提供了众多预构建的网络模块和元素，你可以立即在应用中开始使用。其演示页面展示了诸如函数的响应式反转等功能，例如在一个简单的 Canvas 图像示例中，图像的预设颜色为"蓝色"，在同一浏览器窗口中，你可以实时将颜色更改为"红色"，因为其响应完全是响应式的和即时的，为你提供了更大的空间来开发真正的多维度 Web 应用。

### WebRx

`WebRx` 是一个基于浏览器的 MVVM 框架，专为由 `ReactiveX` 驱动的单页应用而设计。`WebRx` 是一个基于 `RX.js` 构建的模型-视图-视图模型（MVVM）框架，融合了函数式和响应式编程模式，支持可视化和可观察的数据绑定、客户端路由以及模板特性。无论你是想构建一个简单且响应式的 Hello World 应用，还是一个功能完善的单页待办事项应用，`WebRx` 都是为加速现代 Web 应用开发流程而构建的，并且毫不犹豫地兑现了其承诺。此外，它非常轻量，压缩优化后仅约 30kb。

### Deku

`Deku` 是 Segment 团队提出的一种更轻量级的 `React` 替代方案。`Deku` 的主要任务是使用纯 JavaScript 函数和虚拟文档对象模型（DOM）来渲染 UI。使用 `Deku`，你无需依赖类，而是可以直接使用函数将任务委托给 `Redux` 等第三方工具。由于 Segment 希望保持简单，`Deku` 主要只在新型现代浏览器中运行。与当前的 `React` 开发社区兼容良好。

### Riot.js

`Riot.js` 是一个类似 `React` 的用户界面微类库。`React` 无疑对我们当前开发领域中大多数响应式 JavaScript 框架产生了巨大的影响，`Riot.js` 也不例外。用他们自己的话说，`Riot.js` 是一个基于 `React` 的 UI 库，专注于微功能。Streamdata 在他们的博客中对这一方法进行了极为详细的探讨。（阅读完那篇报道后，向下滚动即可了解更多他们发布的 `Riot.js` 文章！）`Riot.js` 由 Muut 的开发人员维护——Muut 是我们目前所见过的最优秀的讨论平台之一，它具有超强的响应性和交互性，因此当你在项目中开始使用 `Riot` 的功能时，可以期待在你的应用中获得同等类型的表现。

### Mithril

`Mithril` 以其灵活的库体积（7kb）以及始终随库本身开发过程更新的前瞻性文档而脱颖而出，文档中不断加入新的上下文和方法。与其他知名 JavaScript 框架的基准测试对比结果令人惊叹，这将激发你亲自尝试的兴趣。

### Vue.js

`Vue.js` 在将自身定位为框架方面非常低调，它更倾向于使用"库"这个词，然后通过与其他工具组合即可构建为一个功能完善的框架。`Vue` 用于创建和开发现代且精美的 Web 界面。直到不久前，它仍是一个测试版项目，然而 2015 年 10 月标志着 V1 的正式发布，因此 `Vue` 已经可以用于实际的生产开发，许多人也已经在分享他们对该框架的看法和体验。如果你喜欢编写从阅读代码那一刻起就逻辑清晰的代码，那么绝对值得尝试一下 `Vue`。

## MVC 与主流框架

MVC 是一种将应用程序逻辑与表现层分离的软件策略。实践中，它使你的网页能够包含最少的脚本，因为展示与 PHP 脚本是分离的。我们即将探讨的 MVC 框架随着时间的推移已经有了显著改进，并且大多数都提供了允许无缝进行移动应用开发的功能。

像 `Angular`（即将推出 V2 版本）和 `React` 这样的互联网框架已经使互联网开发领域向更好的方向发展，并且人们对于未来即将出现的技术充满了期待与热情。

#### AngularJS —— 超级 JavaScript MVW 框架

`Angular 2` 的首个 BETA 版本即将到来，你可以在 `Angular` 开发者团队的最新文章中了解更多。由于 `Angular` 具有广泛的框架特性，它完全支持可扩展的插件和库。

### jQuery

#### jQuery

凭借这个项目已经拥有的生命周期，即使是不常上网的人也听说过 `jQuery`。每当有人想扩展他们的网站（或移动页面）并使其更具交互性时，他们都会依赖 `jQuery` 的性能。这个小库将整个网络变成了一个完全交互和愉快的体验，据记录，全球 70% 以上的顶级网站都使用了与 `jQuery` 相关的技术。`jQuery` 小部件和插件是前端开发者领域最受欢迎的组件之一。

WordPress、Google、IBM 等许多公司都依赖 `jQuery` 为其员工以及庞大的网络用户提供独特的网络浏览体验。`jQuery` 完全兼容移动设备，并且还有一个单独的 `jQuery Mobile` 库来处理所有移动相关的内容。

### React

#### 用于构建用户界面的 JavaScript 库 React

`React` 是互联网编程领域最新加冕的瑰宝，甚至连 `Angular.js` 的忠实用户也已经转向 `React`，因为它允许更简单的后端开发，而无需深入前端框架的复杂性。`React` 是一个由 Facebook 维护的 JavaScript 库，其核心专长是帮助程序员实现一个虚拟 DOM；或者更准确地说，是输出一个被称为虚拟 DOM 的值。然后将虚拟 DOM 与当前的 DOM 状态进行比较（diff），从而生成一系列 DOM 操作列表，这些操作将使当前 DOM 看起来像新的那个。这些操作会在堆中快速执行。

就受欢迎程度而言，一位开发者最近发布了一个关于 Reddit 上 r/React 和 r/Angular 子版块访问量统计的有趣发现——两者目前每天似乎获得了相同的流量，这意味着 `React` 在不止一个方面已经赶上了 `Angular`。

### Socket.IO

#### Socket.IO

`Socket` 在开发者社区中获得了大量关注。使用 `Socket`，你可以享受客户端和服务器之间的全功能实时通信。`Socket` 分为两个不同的部分——第一部分是在浏览器中运行的客户端库，而服务器库则是建立在 `Node.js` 之上。这两个库提供了非常相似的 API，并且也是事件驱动的；类似于 `Node.js`。使用 `Socket`，你可以实现实时的二进制流传输、即时通讯程序、交互式文件协作、为你的程序和项目提供实时统计数据（分析），以及更多功能。

Microsoft Office 和 Yammer 都依赖 `Socket` 来提供其大部分的实时功能。`Socket` 与 WebSocket 协议配合得非常好，提供了流畅的体验。

### Polymer

#### 欢迎使用 Polymer 1.0

Google 的 `Polymer` 项目不仅仅通过使用 Material Design 让事情变得更有趣，这个令人惊叹的 JavaScript 框架是关于通过创建和重用 Web 组件来实现快速和现代的 Web 设计。该项目在 BETA 版本中度过了相当长的一段时间，但在过去一年，我们看到了 V1 的首次发布，此后项目发展势头迅猛。

虽然许多人仍然想知道 `Polymer` 和 `Angular` 之间的真正区别是什么（因为它们共享许多相似的特性，如代码语法和布局属性），但我们确实知道 `Polymer` 带来了一种新的开发体验，这将推动行业其余部分转向基于现代 Web 组件的开发策略。

### Node.js

#### Node.js

`Node.js` 很可能是自 JavaScript 诞生以来我们见过的最有效的框架，并且在过去一两年中，该项目规模增长巨大。尽管许多人曾预言 `Node.js` 的衰落和其他服务器端框架的兴起，但 `Node.js` 至今仍保持着其领导地位。`Node.js` 的功能已经变得非常可扩展和灵活，许多程序员将其排名高于 Java 和 .NET 等专业编程语言！（至少对于 Web 而言）

`Node.js` 建立在 Google 的 V8 JavaScript 引擎之上，该框架的主要用途是帮助构建交互性强的 Web 应用程序，如网络网站、内容加载网站、功能丰富的一页应用以及其他依赖大量数据交互的应用程序。这个开源项目不仅初学者可以学习，而且来自不同语言的程序员也可以轻松上手。每个人的学习曲线都是一样的。

去年，`Node` 与 `IO.js` 进行了完全整合——带来了一系列扩展的特性和可能性。

### Meteor

#### Meteor

`Meteor` 已经从一个简单的灵感概念发展成为一个功能齐全、资金充足、拥有数千名热情开发者的项目。`Meteor` 在许多方面彻底改变了实时移动和互联网应用的开发方式，这些应用可以在单一的开发环境中构建。任何使用 `Meteor` 构建的 Web 应用程序也都能自动兼容移动设备——甚至可以将你现有的 Web 应用程序转换为移动应用程序并发布到最受欢迎的移动应用商店！

随着 Galaxy（云托管平台）的最近发布，`Meteor` 正在将前端和后端开发变成一个统一、无复杂性的体验。`Meteor` 是一个安全的全栈框架，支持原生 JavaScript 语言，帮助你构建可扩展的现代 Web 和移动应用程序。公共包仓库 Atmosphere 拥有数千个已发布的包，使你能够即时构建多路复用应用程序。

### D3.js

#### D3.js 数据驱动文档

视觉效果、动画和图像是网络的基本组成部分。如果在我们的设计中没有应用优秀的图像，我们的设计可能会被归咎于平淡和肤浅（取决于具体情况）。`D3` 是一个数据驱动的可视化组件库，它帮助设计师和开发者使用 JavaScript 构建真正令人惊叹的可视化数据报告，包括艺术作品、交互式子弹图、旭日图，以及各种数据矩阵、词云和许多其他类型的数据可视化，这些都能激发你的客户的灵感并总体展示令人满意。找到适合自己的 `D3.js` 语法用法需要时间，但正如你在本页案例中会注意到的，这是非常值得的。

### Ember.js

#### Ember.js —— 一个用于构建雄心勃勃的 Web 应用程序的框架

`Ember` 是一个面向雄心壮志开发者的现代 Web 开发平台。它以帮助开发者构建复杂的大型客户端软件而闻名——`Ember` 以其简洁性和流畅的性能表现脱颖而出，使 Web 应用开发成为顺畅的体验。入门 `Ember` 轻松快捷，许多开发者不遗余力地制作指南和教程，介绍如何开始使用这个灵活的框架。

`Ember` 成功避开了那些让现代框架脱颖而出的华丽模块和术语，相反，`Ember` 在保持传统功能的同时，带来了构建优秀应用程序所必需的能量和专注，如 Discourse 讨论论坛。

### Aurelia

#### Aurelia

`Aurelia` 是一个自诩为下一代 Web 开发框架的项目，主要专注于让编程（Web 开发）成为一个创造性的过程。也许让 `Aurelia` 称得上"下一代"的是，它完全使用 ES6（最新的 JS 标准）构建，并且目前已经集成了一些可用的 ES7（另一个 JS 标准）特性，同时保持在所有现代浏览器上运行的能力。该框架构建于模块化的框架之上，意味着它由许多小型和大型的库组成，可以根据你正在构建的应用程序类型的需求，一起使用或单独使用。

然而，这些都只是 `Aurelia` 所具备的更有远见的特性中的一小部分，强烈建议你阅读 Rob Eisenberg 关于 `Aurelia` 的撰写文章，以充分理解该框架的目标。

### Knockout.js

#### Knockout.js

`Knockout.js` 的主要特性是声明式绑定、自动 UI 刷新、依赖跟踪和模板功能。使用简单的语法将现有的 DOM 元素与数据单元关联起来。每当你更新数据单元时，UI 的变化会实时反映出来。在你的数据单元之间创建关联以组合和转换它们。创建复杂的 UI 模型作为用于数据单元的函数的一部分。借助原生 JavaScript 的帮助，`Knockout` 可以非常轻松地将自身与任何其他可用的框架集成，包括我们这里汇总的每一个框架。

### KeystoneJS

#### KeystoneJS —— 基于 Express 和 MongoDB 构建的 Node.js CMS 和 Web 应用程序平台

我们或许应该在另一个 `Node.js` 框架清单中提到这个框架（我们会的），但 `Keystone` 的能力在现代前端 Web 开发中确实脱颖而出，而且我们并不经常看到功能完备的**内容管理系统**（CMS）框架。借助 `Express.js` 和 `MongoDB` 的帮助构建，`Keystone` 实现了动态路由、数据库字段管理、交互式和动态的 Admin UI（在你构建应用程序/内容系统时即可使用）、易于操作的代码库、表单处理、电子邮件发送和管理等功能，以及许多其他使优秀 CMS 成为优秀 CMS 的特性！

### Backbone.js

#### Backbone.js

使用最传统的 Web 开发库构建优雅的单页和单页面应用程序，如果你不注意代码的结构和联盟，可能会将你的代码库变成一团彻底的意大利面条。`Backbone` 的构建理念是：所有服务器端功能都应通过 API 流动，从而减少需要编写的代码量，以实现与更复杂的 Web 框架相同的功能。

`Backbone` 是 JavaScript 开发者中最受欢迎的 Web 开发框架之一，部分原因有二——它易于理解的使用模块，以及非常简单的学习曲线。

### Stapes.js

#### Stapes.js —— 做得恰到好处的小型 JavaScript 框架

`Stapes` 可以说是 `Backbone` 的某种继承者，"boasting"（自夸）其能够在仅保持 20 个活跃模块精选的同时提供出色的框架体验。`Stapes` 的主要关注点是路由创建、自定义事件和数据方法。`Stapes` 是帮助你发现传统应用程序和*真正厉害*的应用程序之间差距的构建基石！（用他们自己的话说！）

## 选择最佳 JavaScript 开发框架

选择框架不应该只看特定框架能提供的功能数量。显然，"next generation"这样的词语听起来很有吸引力，但最终关键在于框架的**实际功能**，以及该功能如何在你正在构建的项目、应用、软件中使用。一些框架提供更多经验，体现在框架由拥有多年经验的出色开发者构建；而较小的 Web 框架则侧重于社区导向的特性，可以集成到不同的框架模块中。
