HistoryJava was created by James Gosling and his team at Sun Microsystems in the early 90s. The first version of Java was 1.0\. Oracle acquired Sun Microsystems in 2010\. At the time of writing this, the latest release of Java is Java 14.1.2     Why JavaJava is Object oriented .Earlier programming languages like C were procedural. The downside of a procedural language is that programs become large and complex.To manage this complexity, Object oriented programming was conceived. Object oriented programming organises a program around its data and thus simplifies programming.Java is platform independent.Other programming languages like C or C++ are compiled into files that are operating system specific.Java on the other hand is compiled into bytecode which is run within the Java Virtual Machine or the JVM. The JVM sits on top of the operating system. So, the same compiled file can be run on different operating systems.1.3     Software Installation1.3.1 JDK InstallationJDK stands for Java Development Kit. 17.2 Lambda ExpressionsLambda expressions are anonymous functions. They specify a method without a method name. They are used to implement the abstract method in a functional interface17.2.1                      Lambda Expression SyntaxLambda expressions have the following syntax:![](image_rsrc3RC.jpg)

*   Parameters – A lambda expression can accept zero or more parameters
*   Lambda operator – The -> sign is known as the lambda operator
*   Lambda body – This consists of the code that needs to be executed

Lambda Syntax Points to Remember

*   If a lambda expression does not accept any parameters, empty parentheses need to be specified
*   If a lambda expression accepts a single parameter, the parentheses around the parameter can be skipped
*   If a lambda expression accepts more than one parameter, the parameters need to be specified in parentheses and separated by commas
*   The data type of the parameters need not be specified, it is inferred
*   If the body of the lambda expression consists of a single statement, the curly brackets can be skipped
*   When a lambda expression returns a value, the return keyword maybe skipped if the body of the lambda expression consists of a single statement.
