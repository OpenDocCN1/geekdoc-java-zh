“艾什莉（Ashley）！”外面传来一个男人的尖叫声。“你疯了吗？你在什么？你不知道——”

“求你了，让我去她那里，”夸西再次请求，渴望将他的女人拥在怀里。

格蕾琴发出了声音，像是认同他。科乔（Kojo）已经用绳子系住了那个昏软、无意识的身体，处理了那个潜在的杀手。艾什莉的目光在两人之间游移，随后松开了手中的枪，并点了点头。

他没有浪费时间，爬向格蕾琴并解开了绳子。然后，他将她拉入怀里。“格蕾琴。格蕾琴。你还好吗？跟我说话，宝贝，你还好吗？”

当她同样激烈地回抱他时，她的泪水在他的衬衫上烧出了一个洞。她的抽泣声割着他的心，但他并不在乎。

至少她在他身边身边哭泣。

“我爱你，夸西，”格蕾琴哭道，她在他怀里向后靠去，那如娃娃般的眼睛里泛着泪水，却闪烁着光芒。“我爱你。”

“我也爱你。”

远处传来的警报声像摇篮曲，他紧紧贴住她，下心永远不再让她离开。

# JAVA 裂隙：抢先

一年前

所以，目睹死者复生是什么感觉。

就像空气重新回了你的肺部。你的皮肤在感知中颤抖。当你的目光聚焦在那个你最意想不到再次进入你生活的人时，整个世界从视野中消失了。

格特鲁德·奥辛加（Gertrude Ozinga）上一次见到夸西已经是十九年前，但无论过去多久，她都不会认错他。即使她是瞎了也能认出他。

自从分开以来，时间对他太友好了。他已成长为一个拥有杂志封面那种体魄的男人。强壮的肌肉在他移动时聚在一起显示出支配力。浓密粗糙的金发留着莫霍克头，增添了一种性性的叛逆气息。他的色镜遮挡了脸，但引人注目的是他坚硬的双唇和结实的下巴。

“夸西，”她屏息道。他还活着。猎人终究没有杀死他。

她从拥挤的商场座位上站了起来。这个男人一直是她一生的挚爱。从她从小起。她曾认为没有任何男人能比得上他。

环境使她在那时无法夺回他。她的嘴唇不悦地扭曲了一下。但不再了。这是一个她无法放弃的机会。现在不行。

她的脚在她来得及思考太多之前就动了。然后她开始跑起来。尽力双腿能带的最快速度去跑。

她必须找到夸西！

他停在一家男装店的橱窗前。她滑行停下，用充满爱意的眼睛盯着他。深吸一口气，低下头，然后装作镇定地走过去，接着“意外”地撞了他。

“哎呀，对不起！”她气喘吁吁地说。“我真笨——夸西？”

她让惊讶提高了她的声音，而真心的震惊震动了她的内心。

动物磁力。这是描述他散发出的气场的唯一方式。作为一名黑人白化症患者，他皮肤自然的苍白像大理石一样闪闪发光，但不仅于此。一种磁性的脉动连接通过如蝉丝般的细线向她伸来。一只白虎让她感到畏惧，让她在他存在存在下竖起汗毛。尽管他的墨镜遮住了眼睛，但那镜片后方审视的力量像赤裸裸的抚摸一样拂过她的身体。

她咽了口唾。“是你，夸西。是你，夸西。是你，夸西。”

一只无形的拳头重击了他的腹部。世界上哪个男人会想在自己刚刚吻过的女人口中听到另一个男人的名字？一个都没有，尤其是面对这个刚刚让他魂不魄散的女人。他紧咬着牙关。他比世界上任何人都更爱他的哥哥，但涉及到阿雅瓦（Ayawa）……

他希望自己能把哥哥送到世界的另一端。也许那样，她就能看到他了。

为什么不是奎西（Kwasi）呢？

一想到这里，他僵住了，阿雅瓦抬起头：“奎西，怎么了？和妻子再次在一起你不高兴吗？”

撒谎对阿雅瓦来说一直轻而易举。她撒谎时从不泄露太多。她那双牛眼睛望着他，乳色的眼眼中闪烁着令人怀疑的纯真。即使在他们小时候生活在坦桑尼亚的村庄时，她编出来的故事也能和他和奎西晚上偷偷溜出去听的那些说书人不相上下。

既然撒谎对阿雅瓦来说如此轻易，为什么他不能加入她的游戏呢？小时候，他们喜欢互相玩游戏。竞争是他们关系中不可或缺的一部分。阿雅瓦，是他唯一的朋友，也是他最强的竞争对手。

为什么不成为他的哥哥呢？既然她那么想要他，为什么不把哥哥给她呢？

“是的，阿菲亚（Afia）。我很高兴我们再次在一起了。”

# 帕克（PARKER）的话

我的双胞胎是我另一个半部分。她是我的拉拉，也是我最大的粉丝。我是大她整整一分钟的年长胎，但我们关系非常亲密。作为异性双胞，我们没有同卵双胞胎那种神秘的纽带，但也非常接近。只需一眼，我就知道她在想什么。她也是如此。

2016 年，我的家庭发生了一件极其毁灭性的事情。我的双胞胎姐姐被诊断出有癌症。随之而来是对信仰的考验，也是家庭凝聚力的考验。我踏入了一个从未涉过的未知领域。我看着我深爱的人忍受痛苦，而我却无能为力。

截至今年，她已经康愈了。我祈祷上帝让我们永远不要再次经历这一切。

《Java Blend》和《Java Rift》是对探索双胞胎纽带及其特殊之处的尝试。当我自己的双胞纽带受到威胁时，它让我感激上帝的智慧，让我与她**一起**出生，而不是**没有**她。

显然，我们在一起更好。

下回见，机会难得（carpe diem）！
