# Java 的一些基础知识

首先，让我们看看 Java 到底。Java 是一种为了帮助在你的计算机上创建各种应用程序而开发的编程语言。用户开发需要运行环境的程序并不罕见，你可能已经在计算机上安装了它。也可以作为计算机上的插件，在这些地方运行这些程序。

重要的是，Java 和 JavaScript 不是同一种语言，除了名称之外，它们并不相似。例如，JavaScript 将用于与 HTML 文档配合的网页，而不是用于独立应用程序。这有时会让人困惑，因为 Java 能够在浏览器中运行，但它们之间存在差异。首先，你会发现许多类型的网站使用 JavaScript，而 Java 则更进一步。

在计算机上下载 Java 程序是免费的，而且不需要太长时间。事实上，许多系统已经下载了它以方便操作。但对于还没有 Java 的计算机，你应该采取几个简单的步骤。安装你的程序需要的一些操作包括：

- 选择你的 `IDE`——这是你使用 Java 工作的地方。它允许你构建代码并查看显示效果。你可以选择几种，但对于初学者来说，`NetBeans` 是一个非常有帮助的选择。

- 一旦完成这些操作，你就可以开始编写程序了。这些程序很容易安装，只需几分钟，你不必担心它们会在你的程序中占用过多空间。从一个 `Hello World` 程序是最好的方法，如果你想熟悉这种语言以及你所选择的环境。

正由于所有这些巨大的好处，许多开发者（无论是已经工作一段时间的开发者还是刚开始的人）都选择使用 Java 来满足他们的编码需求。它易于使用、精确，而且这种编程语言并不是难以学习和理解的。

## Java 的缺点

Java 确实存在一些缺点，这就是为什么某些人会选择其他编程语言来完成工作。你会发现的一些问题包括：

这个程序比其他一些编程语言慢一点，但在后续版本中已经进行了一些更改，有助于提高速度。它的优化程度稍低，下载应用程序将需要更多的时间。

## 占用更多内存

与 `C++` 和 `C` 等其他编程语言相比，这些语言可能需要更多的时间来下载应用程序。

## 它仅仅是单范式语言

这主要是一种单范式语言，尽管一些较新的版本正在转向过程范式，以某种程度上解决这个问题。

## 语法

Java 的语法对于确保解释器理解你想要执行的内容非常重要。需要记住的第一点是，当你用这种语言编写文件时，你需要将其保存为 `.java`，而子页面应该被保存为 `.class`。如果你想确保子页面或任何类是私有的（`private`），你只需要将它们保存在同一个 Java 文件夹中即可。如果你将其保存在自己的文件夹中，其他人将拥有对它的访问权限。

## 内存

起初，Java 的内存管理要慢得多，尤其是与其他一些编程语言相比时。最初的内存问题导致用户加载程序需要更长时间，而且在某些平台上并不友好。这是因为 Java 语言使用内存的方式与其他一些语言不同，但这在后续版本中已经发生了更改，以便更容易获得你所需的运行和内存功能。

随着时间的推移，Java 的开发者进行了一些更改，使得 Java 运行得更快。这在一定程度上是因为使用了自动内存管理（`Automatic Memory Management`）。这基本上允许程序员选择对代码进行哪些更改，而他们的运行时完全不会受到影响。

这种类型的内存变化使得程序不再引用某个特定对象。该对象现在不再是程序的一部分，这可以节省大量的内存，让程序更容易运行。

## 注释

某些时候你可能想在代码中留下注释。你可能想更深入地解释代码中正在发生什么，或者告诉用户应该如何处理这些代码以使其运行。如果你使用正确的符号，就可以将注释放入代码中，而不会让解释器读取注释。

注释本身并没有给代码添加任何内容。它不应该在代码中被读取，否则你可能会遇到问题，因此你需要确保使用正确的符号，以确保代码正常的同时防止注释在你的代码中产生问题。

在编写 Java 时，当你想要留下注释时需要使用井号符号。只需将井号放在注释的开头，然后写下你想发生的事情。就这么简单。这里有一个很好的例子：

```
#在下方输入你的年龄
```

然后用户就会知道他们需要在程序上看到的字段中输入他们的年龄。这很简单，你可以在每段代码中使用尽可能多的注释。只需确保将它们保持在需要的数量范围内，并且每条注释都从不同的行开始，以保持代码的整洁。。

## 布尔表达式

你使用 Java 处理的下一个内容是你的布尔逻辑。虽然在编写代码时有很多可用选项，但 Java 以及其他一些编程语言会将它们简化为“假”（false）或“真”（true）的语句。它们还将结合二进制计数系统。这将确保程序根据用户提供的信息做出自己的决策。

布尔表达式将基于真或假。例如，如果你想让输入年龄的人大于 21 岁，那么当人员输入任何大于 21 的数字时会显示真，而每当他们输入 20 或更低的数字时都会显示假。如果出现了真表达式，将会出现特定的语句，例如“恭喜，你符合参加条件。”

现在，取决于你如何执行，可能会发生几情况。在最简单的形式中，程序直接结束为假，或者人员输入 20 岁或以下的年龄。但你可以处理出现假的情况，进行一些更改，这样就不是让程序直接关闭，而是弹出另一个消息。例如，当人员输入 20 岁或以下的数字时，你可以让程序显示如“抱歉，你目前无法参加”之类的语句。

记住，当涉及到你编写的代码时，你才是负责的人。有很多表达式可以放入布尔表达式中，例如“if”、“if else”和“else if”语句，允许你创建精确的语句。

你能够放入布尔表达式中的表达式很多。

## 算术运算符

你有许多可以使用的算术运算符。它们大多数能够帮助你在代码中执行各种数学方程，所以如果你编写这类代码，了解它们是很好的。你会发现的一些算术运算符包括：

- `(+)`符号是加法运算符。它将两个或多个运算符相加。例如，`a + b = 10`。

- `(-)`符号是减法运算符。它将取右侧的操作数并从左侧的操作数中减去它。例如，`a – b = 5`。

- `(/)`符号是除法运算符。它将左侧的操作数除以右侧的操作数。

- `(*)`符号是乘法运算符。它将乘以你想要的两个或多个数字。

- `(//)` 这将是在你寻找商的结果时想要使用的符号，例如当小数被移除时。

- `(**)`符号是指数运算符。

## 赋值运算符

接下来是赋值运算符。当你想要确保两个值被赋值在一起时，这些运算符非常好用。这可以在你的代码中显示，或者你可以使用它来保存你正在编写的函数。你可能在代码中使用的赋值运算符示例包括：

- `(=)`—这会将右侧的值返回给左侧的操作数。例如，如果你有 `c = a + b`，从 `a + b` 得到的值将变为 `c`。

- `(-)=`减法并赋值——这将取右侧的操作数并从左侧的操作数减去它。它会将结果赋值给左侧。例如，`c-=` 等于 `c = c-a`。

- `(+)=`加法并赋值。工作原理与上述相同，但它会将右侧的操作数加到左侧，然后返回左侧的操作的结果。

- `(/)=`除法并赋值。这会将左侧除以右侧的操作数，然后将赋值给左侧。

- `(*)=`乘法并赋值。在将结果赋值左侧的操作数之前，会将右侧的操作数与左侧的操作数相乘。

- `(**)=`幂运算。这将推导出指数符号。`c ** = a` 等于 `c = c** a`。

## 标识运算符

当你想要比较两个不同对象的内存时，这些运算符会非常有帮助，特别是当它们位于不同的位置时。你可能在代码中使用的以保持它们紧密结合的标识运算符包括：

- `Is`。这将确定两侧的变量是否为真。如果不是，该运算符将指向同一个主体。

- `Is not`—如果代码两侧的变量为假，该运算符将指向这些主体并在逻辑上判定为真。

## 成员运算符

这些运算符将用于代码中，以检查在你处理的特定序列中是否存在一致性（或成员关系）。要实现这一点，请尝试以下选项：

- `Is`。这将检查两侧的变量是否为真。例如，`x is y`，如果 `id(x)` 等于 `id(y)`，这里的结果为 1。

- `No in`—这将检查变量是否不在指定的序列中，然后评估其结果为假还是真。

## 比较运算符

这些运算符将进行不同的比较，以确定语句是否为真，以及当语句为真或为假时程序应该做什么。你在 Java 程序中使用的某些比较运算符包括：

- `(==)`—当操作数相等时，条件求值为真。

- `(<>)`—如果值不相等，条件将变为真。

- `(!=)`—如果两个操作数的值不相等，条件将变为真。

- `(<)`—如果左侧的操作数的值小于右侧的操作数，条件将变为真。

- `(>=)`—如果左侧的值大于右侧的操作数，条件将变为真。

- `(<)`—如果左侧的操作数小于右侧的操作数，条件将变为真。

## 用户数据报协议

用户数据报协议（UDP）是一种无连接的协议。它是一个可靠的数据报流（等一下，UDP 实际上是不可靠的）。它是一种面向消息、无连接的传输层协议。它是互联网协议族的一部分。它首次在 1980 年的 RFC 768 中规定。它用于建立实时应用，如 DNS、VoIP、IP 电话和流控制协议（SCMP）。

UDP 是一种数据报协议。与 TCP 不同，它不提供可靠交付、流量控制或拥塞控制。它用于速度比可靠性更重要的应用程序，如在线游戏、流媒体和视频会议。它不提供排序或丢失段的重传。

UDP 的某些特性包括：

- 无连接
- 低开销
- 无流量控制
- 无拥塞控制
- 支持广播和多播

## 传输控制协议

传输控制协议（TCP）是一种面向连接、可靠的全双工流协议。它在应用程序之间提供可靠有序字节流。它是互联网协议族的一部分。它用于需要数据完整性和可靠性的应用程序，如网页浏览（HTTP）、文件传输（FTP）和电子邮件（SMTP）。

TCP 的特性包括：

- 面向连接
- 可靠交付
- 流量控制
- 拥塞控制
- 错误检查

## 地址解析协议

正如你从名称中能得到的那样，这是一种电信协议，可以让网站和应用程序轻松地通信。它用于帮助映射网络地址，并使视频通话和其他消息成为可能。许多优秀的技术都会使用这种协议，包括 IPv4、Xerox PARC Universal数据包、ChaosNet 和 DEC Net。

与 Java 最匹配的协议是互联网协议（Internet Protocol），因为这个程序是为了配合它而创建的。该协议旨在为网络提供正确的边界，并中继数据报，以便互联网上所有的网络操作能够进行。其结构将包含一个负载（payload）和一个头部（header），其中头部被称为主 IP 地址，而接口将在特定参数的帮助下连接在一起。

MyJavaStream* JavaConnector::connect(const char* server, int port)
{
    struct sockaddr_in address;

    address.sin_family = AF_INET;

    struct addrinfo *res;

## 使用 if 和 switch 语句

由于你可以通过这些代码实现许多功能，这些语句将是你代码中独一无二的。在这里我们将讨论如何使用 `if` 语句以及 `if...else` 语句来显示用户可以选择的不同选项，以及可以改变你代码外观的 `switch` 语句。

### if 语句

该语句将基于“真”（true）和“假”（false）的概念运行。它将判断用户输入的内容是真还是假，如果答案结果为真，则给出你设置的相应响应。你需要确定当用户输入真的语句时，你希望程序进入哪条语句。另一方面，如果用户输入的数字根据你设置在程序中的标准结果为假，程序就会结束。

虽然你可能不喜欢程序在用户输入错误数字时结束，但这就是该语句的运行方式。我们稍后会探讨一下如果你希望在用户输入你的代码最初未接受的数字时提供几个备选项，你可以做什么。

假设你想为投票的人编写代码。你可以编写代码，使其包含几种变体。用户将看到的问题是“你的年龄是多少？”他们可以输入他们想要的任何数字，因为这只是他们的年龄。但你需要设置程序以特定的方式做出响应。

你可能选择只在人大于 18 岁时显示一条消息。你需要在代码中使用 `>=18` 符号，然后添加你想要的消息。例如，如果某人的年龄设为 35 岁，程序可以提供“恭喜！你可以参加！”的语句，然后进入你代码的下一次部分。另一方面，如果用户输入的年龄是 16 岁，程序将结束，或者移动到你想在程序中显示的下一个内容。

### if...else 语句

现在，有了上面的选项，你将只有一个真或假的答案。如果根据你输入程序中的内容答案为真，你将获得放置在代码内部的语句。但如果根据你输入代码中的内容答案为假，你什么也得不到。

这对于大多数人来说并不适用。你不希望你的代码在答案变为假后就放弃。在大多数情况下，你希望无论某人的回答是否在某个年龄范围内都显示一条消息。

让我们看看上面那个例子。假设某人回答说他们 16 岁。你仍然希望为回答这个年龄的人在代码中显示一些其他内容。你可以使用 `if...else` 子句来确保第一个语句不是真结束（人不是 18 岁或以上，因此第一个语句为假），代码将移动到你提供的第二个语句。你可以选择像“对不起，你目前没有参加资格。请稍试。”之类的。

因此，通过 `if...else` 语句，如果人是 18 岁或以上，他们将获得你写的原始消息。但如果他们输入的数字低于 18 岁，他们将获得我们刚刚讨论的第二条消息。这仍然基于真和假的概念，但它允许程序无论收到什么答案都能显示示例。

你可以随心所欲地使用 `if...else` 语句。你可以编写许多你需要的此类语句。如果你想将人分成几个不同的组，这很有帮助。假设你想分三组：一组喜欢猫的，一组喜欢狗的，另一组两个都喜欢。你可以在屏幕上列出所有这些选择并允许用户挑选。你可以根据收到的答案添加你想要显示的语句。

在 JavaScript 代码中，你可以使用的 `if...else` 语句数量没有限制。你拥有控制权，所以根据你的想法选择尽可能多的选项，以实现你对这段特定代码的想法。

### switch 语句

另一种你可以使用的选项是 `switch` 语句。它允许你根据一组已知值对变量进行测试。这种测试被称为 `case`。一个示例如下：

```javascript
switch(expression){
  case value:
    //Statements
    break; //
  case value:
    //Statements
    break; //
  default:
    //Statements
}
```

在很多情况下，你都会需要使用 `switch` 语句和 `if` 语句来为程序添加更多定义。你可以测试几次以感受它们是如何运作的。

# 继承

当你编写代码时，继承非常有用。它们允许你从现有的类中提取功能并转移到新类中。你也可以对它们进行更改。

例如，如果你将类 A 的所有元素转移到类 B，你将仍然拥有这两个类。它们中的任何一个都不会消失。在开始时你简单有两个类，尽管大多数使用继承的人都想修改类 B，同时保留类 A 的原始特征。

在处理这类问题时，记住类 A 被视为原始类，而类 B 被称为子类，以保持顺序。一旦执行了继承，第一个类的元素现在可能出现在另一个类中，但你仍然可以追溯回类 A。

## 继承后的概念

大部分情况下，当你查看编程书籍时，它们只是讨论继承是元素具有共同属性的能力。它还将强调这些元素具有某些独特特征，这些特征正是允许新类脱颖而出的原因。

## 传递关系意味着什么？

当你谈论类（class）与子类之间的关系时，你是在谈论一种传递关系。在数学和编程中，这意味着这种关系将追溯到偏序关系以及等价关系。如果一个组被引入到另一个组中，则认为这些组中的所有元素都将相互关联。此外，你继承的传递性质表明它在特征上是包容且扩展的。

与继承相关的有以下两个概念。第一个是类 1 扩展到类 2，类 1 的元素将被包含在类 2 内部。其次，当类 2 扩展到类 3 时，类 1 和类 2 的元素都将被包含在类 3 中。

这基本上意味着，你可以根据意愿在链条中进行任意数量的继承。如果你想从类 A 创建新代码，你可以这样做，之后你可以顺着链路创建一个同时具有类 A 和类 B 特性的类 C。你不能跳跃直接从类 B 到类 C，你需要在其中包含一些来自类 A 的特征，但如果你愿意，你可以在代码中一直持续到类 Z 或更远。

这在多个方面有助于防止浪费。首先，你不需要反复浪费时间重写完全相同的代码特征，即使你想在代码中重用它们。其次，你不会在代码内部浪费大量空间，因为你创建的新子类可以链接回原始代码，而不是在代码中将其重写多次。

当然，一旦你创建了新的子类，如果你想让部分代码的执行方式与原始代码有所不同，你可以进行一些更改，这是没问题的。你可以对该子类进行修改，而不会对你继承体系中的其他类或子类产生任何影响。

## Java 隐藏

在 Java 中，你可以做的另一件与继承相关的操作是隐藏。这是一种处理两个命名相似且作用域重叠变量的技术。它需要一个高位变量和一个低位变量，因为其中一个变量将覆盖另一个。低位变量在元素在此会被隐藏。

例如，你的低位变量可以名为 `theta`，高位变量名为 `beta`。当 `theta` 能够覆盖高位变量时，它会隐藏 `beta` 中所有的元素。但仅仅因为被隐藏变量的元素被隐藏了，并不意味着它们无法工作。它们运行得很好。通常隐藏它们是为了不需要显示长度。

你可能出于几个原因想这样做。一些程序员喜欢在将几个元素组合成新子类之前使用它。这可以节省大量时间；你不需要在这个过程中重写它们中的每一个。两者的元素都将具有完整的功能，因此你可以同时使用它们，但你可以将它们结合，并在你尝试创建的新子类中进行更改。

有时隐藏高位变量的长度也是件好事。当你操作计算机语言时，在长度方面需要对你的操作小心，否则可能会减慢整个系统。隐藏技术将帮助防止这些问题的发生，并让你的整个程序运行得快一点。

### 对象的类、对象和方法

在 Java 中工作时，对象是具有行为和状态的组件。你可以有一个球，并注意状态是颜色、跳动方式和大小，而行为则是滚动和跳动。类语法的良好示例如下：

```
修饰符 返回类型 方法名(参数列表) {

```

#### 修饰符

这些是可选的修饰符，用于告诉编译器如何调用方法。访问类型应如下定义。

#### 返回类型

这是显示方法的某些返回值。返回值类型将定义为方法返回的数据类型。某些操作不需要返回值，你需要使用 `void` 关键字。

#### 方法名

这是方法的实际名称。方法列表和方法名是组成方法签名的两个项。

### 仅仅操作类和对象

当你在 Java 中工作时，这些是组合在一起的。你可以使用 `System.out.println` 命令来显示在屏幕上的语句。

你会有许多类型的变量可以放在类中，以对代码产生一些差异，包括：

- 局部变量：这些是定义在构造函数、代码块或方法中的变量。该变量在方法内部声明并初始化。当优选方法完成后，该变量将被销毁。
- 实例变量：这些是在类内部找到的变量，但在你建立的方法之外。它们在类加载时实例化，并可以在该类中的任何构造函数、代码块或方法中访问。
- 类变量：类变量是在特定类内部、方法外部，使用 `static` 关键字声明的。

## 异常处理

在很多情况下，你需要在代码中使用异常处理以确保安全。你必须使用 `catch` 和 `try` 关键字来处理代码中的异常处理。你可以将这些放置在想要生成异常的代码周围，或者可以将它们放在任何你想要保护的代码周围。

## Throws/Throw 关键字

每当你有一个没有在方法中某种方式处理的检查异常时，你就需要使用 `throws` 关键字对其进行声明。这将会出现在方法签名的最后末尾。

另一方面，如果你有一个新实例化的异常，或者是一个刚刚捕获的异常，你将可以使用 `throw` 关键字来抛出它。这将帮助你在代码中做出一些区分。尝试使用一下这两个关键字，以便你学习它们在代码中使用会有何细微的区别。

## Finally 关键字

接下来，我们将查看 `finally` 关键字。当你有一段将在 `try` 块之后执行的代码时，你就需要使用 `finally` 关键字。即使在没有发生异常的情况下情况也是如此。这是一个非常值得学习的概念，因为 `finally` 块允许运行清理语句，使代码看起来更良好并准时结束，即使你周围有一些保护代码。你可能想要用于 `finally` 关键字的语法包括：

```java
try {
    //Protected code
} catch(ExceptionType1 e1) {
    //Catch block
} catch(ExceptionType2 e2) {
    //Catch block
} catch(ExceptionType3 e3) {
    //Catch block
} finally {
    //The finally block always executes
}
```
