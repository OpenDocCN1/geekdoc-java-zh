# 第一章：编程简介

在开始学习特定语言之前，你应该对编程有良好的理解。编程的绝对基础是必不可少的。它将帮助你更好地理解任何语言的基础。

## 二进制数字

计算机几乎所有基于计算机的设备在运行时都使用二进制系统。该系统仅包含两个数字：1 和 0。每一个被称为一个位（bit）。所有的计算机程序都可以简化为这个系统。事实上，二进制系统在计算机存储各种信息和数据方面起着关键作用。

在基础层，计算机的所有功能无论简单还是复杂都简单地从 1 切换到 0。任何数据（包括文本和图像）都以一系列 1 和 0 的形式存储在计算机中。你看，计算机是电路。在电路中，电流要么沿特定线路流动，要么不。因此，状态可以定义为 1 或 0。换句话说，这是一个二进制状态。

一旦你理解了这个概念，你就会意识到为什么二进制系统对计算机如此基础。在所有的计算机程序和情况下，问题始终可以简化为二进制选择。因此，所有计算机都使用二进制系统处理信息。

## 什么是程序？

让我们先分析计算机的功能。它的主要功能是解决问题。现在，它是如何解决问题的？它是通过程序的帮助来的。计算机程序是指令序列，当它们被计算机执行时会执行特定的任务。

无论计算机是什么，除非它有一组正确的程序，否则它将完全毫无用处。如果你在计算机设备上阅读这本书，那是因为该设备有一个程序允许它这样做。

## 什么是编程语言？

顾名思义，编程语言是一种用于编程的特殊语言，被称为所有计算机都拥有并理解的本地化编程语言。不幸的是，机器代码对人类来说可能极其难以理解。除其他外，机器代码几乎总是以二进制系统表示。此外，机器代码是特定计算机架构所有的。因此，两台计算机可以使用两种机器代码变体。

因此，你需要某种方式与计算机通信。这就是编程语言存在的意义。它们充当人与计算机之间的接口。通过它们，程序可以用人们轻松理解的语言来表达。同时，这种语言对于不同的计算机架构是通用的。更重要的是，程序可以很容易地翻译成机器代码。

为了确保这种情况发生，计算机必须解释或编译用编程语言编写的程序，以便执行程序。你需要理解关于计算机编程的编译和解释。

对于编译型程序，必须使用编译器，以便程序可以翻译成机器代码供计算机使用。然而，在解释型程序的情况下，计算机不会运行源代码。相反，解释器在程序运行时读取程序的每一行并将其修改为机器代码。一旦修改完成，计算机就会执行程序的该行。

编程语言可以使用这些方法中的一种或两者兼具。在编程和软件开发方面，每种都有自己的优势。通常，编译型程序的开发时间可能较长，但它们运行得更快。毕竟，计算机执行的是已经翻译过的程序。解释型程序运行时间较长，因为它们每次执行时都需要翻译。但是，由于语言通常更简单，它们编写得更快。同时，在每次修改或错误测试后，整个程序不需要重新编译。

C 和 C++ 作为编程语言都拥有悠久的历史。C 开发于 20 世纪 70 年代初，并且蒸蒸日上；而 C++ 则在后来的 80 年代问世。

你需要记住，这两种语言在计算机编程的早期阶段就存在了。因此，它们被认为是世界上最基础的编程语言之一。因此，即使你以后不使用它们，学习它们也将获益匪浅。事实上，学习它们就像是获得了对计算机编程初期的无价洞察。

每种语言显然有其优缺点。尽管如此，你将对泛指编程有更好的理解。事实上，你可能会发现开始学习其他编程语言（如 Java）变得更容易。毕竟，C 和 C++ 的特性已经为一些语言提供了灵感。

当然，在 C 和 C++ 之间存在一个选择的问题。现在，C 是两者中较老的，而 C++ 被认为是早期语言的子集。许多程序员还认为 C++ 是两者中更容易学习的。另一方面，如果你希望成为一名专业程序员，对 C 的知识可能证明是有帮助的。尽管如此，在学习 C++ 之后再学习 C，反之亦然，也是完全可能的。

## C 的设计

C 是一种过程化编程语言，它的设计目的是可以使用相对简单的编译器进行编译。它的设计还提供了可以高效映射到机器指令的语言结构。它所需的运行时支持也是最小的。这些特性使得 C 能够应用于许多以前必须用汇编语言编写的应用程序。

尽管 C 具有低级能力，但这种编程语言旨在鼓励跨平台层面的编程。只要 C 程序的编写是可移植的且符合标准的，就可以为一系列操作系统和计算机平台编译 C 程序。

## C 语言中的简单程序

为了说明 C 这种编程语言，有一个示例可以查看会有帮助。这里有一个用该语言编写的简单“Hello World!”程序。

```c
#include <stdio.h>

int main ()
{
    printf("Hello world\n");
    return 0;
}
```

为了更好地理解程序中发生了什么，将它拆分为不同的部分并逐一解决将会有帮助。

### stdio.h

这段代码告诉包含一个名为 `stdio.h` 的文件，代表标准输入/输出头文件。通过它，可以在程序中使用特定的命令进行输入或输出。在例子中，它允许我们输出一条消息并将其打印在屏幕上。

### int main ()

`int` 被称为返回值，在本例中它是整数类型（integer）。接下来的部分是 `main()`，它是主函数。C 中的每个程序都必须有且仅有一个 `main` 函数，它也是所有程序的起点。

### printf("Hello World\n");

当需要在屏幕上打印内容时使用 `printf` 命令，在本程序中的内容是 'Hello World'。数据需要放在圆括号内。在这种情况下，'Hello World' 被放在双引号内，因为它是一个字符串，必须放在引号内。命令的最后部分是 `\n`，它被称为转义序列。`\n` 符号代表换行符，它允许将下次输出打印在下一行。在学习 C 编程期间，你还会学到其他类型的转义序列。

### return 0;

在程序的第二行中，写了 `int main ()` 表示主函数必须返回一个整数。通过使用 `return 0` 命令，会将空值（null）返回给操作系统。通过返回 0，你只是在告诉操作系统运行程序时没有发生错误。

基于这个示例，你对这种语言的编程有几点需要了解。

- 所有编写的程序都应该只有一个 `main` 函数。
- 程序的执行将始终从 `main` 函数开始。
- 程序的执行将始终从函数的左括号开始，并在右括号结束。大括号可以用于语句块。
- 通常，C 中的所有语句都使用小写字母。
- 大写字母留给消息、输出字符串和符号名称。
- 在使用变量之前，必须用正确的数据类型声明变量。
- C 中的所有语句必须以分号结束。

## C 中的数据类型

在 C 中，你会发现一组标准的基础数据类型。由于它们的简单性，它们通常被称为原始数据类型。然而，可以从它们开发出一系列复杂的数据结构。总共有四种基本数据类型：

- 字符 - `char`
- 整数 - `int`
- 浮点型 - `float`
- 双精度浮点型 - `double`

数据类型的实际范围和大小随编译器和处理器类型而异。通过数据类型修饰符，可以修改所应用变量的行为。C 中有一些修饰符。

大小修饰符可以改变数据类型的大小。C 中存在两种大小修饰符。它们是 `short` 和 `long`。它们只是改变声明变量的大小。

符号修饰符决定了变量可以包含什么种数字。“signed”表示变量可以包含正数和负数。然而，“unsigned”变量只能包含正数。没有必要声明变量，因为变量默认是有符号的。这些修饰符可以应用于 `char` 和 `int` 类型。

常量修饰符用于声明标识符的值不变。也就是说，该修饰符的关键字是 `const`。如果你希望变量的值从外部源更改，可以将其声明为 `volatile`。这是另一个你应该熟悉的变量。

### 变量

变量是程序存储数据的内存位置。内存块的大小取决于变量类型。为了标识内存块，你需要为每个变量分配一个唯一的名称。在使用变量之前，需要用其数据类型和名称对其进行声明。C 变量声明的语法如下：

```c
[Storage-class] type data variable name [= initial value];
```

如果不需要，不必为变量定义初始值或存储类。只要你希望它们具有相同的存储类和数据类型，就可以同时声明多个变量。其语法如下：

```c
[Storage-class] type data variable name [= initial value] variable [= initial value];
```

### 语句

在 C 中，语句允许你控制程序的执行流。该编程语言为你提供了多种语句。一些常用的语句如下：

- `if` 语句
- `goto` 语句
- `switch` 语句
- `while` 语句
- `do-while` 语句
- `for` 语句

当你继续使用 C 编程时，你会遇到许多其他概念，如输入输出函数、数组、结构、指针等。一旦你了解了这些，就可以很容易地跳到 C++ 和 Java 等其他编程语言。

# 第 3 章：享受 Java 的多功能

Java 是世界上最有影响力的编程语言之一。它在计算领域依然保持着流行和无处不在。你可以发现 Java 被应用于各种平台，从 Web 到操作系统，甚至是设备。你会发现 Java 充满了各种特性。作为一种编程语言，它是基于类且面向对象的。它的设计使其具有良好的可移植性，因此你可以在各种平台上对其进行开发。这就是为什么在自最初发布二十多年后，它在全球范围内仍然非常受欢迎。

另一方面，Java 有时可能难以理解，并且难以高效、有效地进行编程。然而，它的流行意味着作为程序员，你不缺资源来帮助你理解，也不缺探索的途径。学习 Java 的另一个好处是，它迫使你进行分析性和逻辑思维。换句话说，你将开始像程序员一样思考。你也可以更好地理解计算机如何处理信息。你在 Java 中学的核心概念和基础知识在你开始学习其他编程语言时将会被证明是有用的。

## Java 的特性

Java 最初由 Sun Microsystems 公司于 1991 年开发。现在，它由在 2009 年收购 Sun Microsystems 的 Oracle 公司维护。它的流行取决于其卓越的特性。

- **平台无关性**：与其他某些编程语言不同，Java 是平台无关的。因此，无论你在什么平台上编译它们，都可以在所有平台上运行 Java 程序。
- **面向对象**：虽然 Java 是一种面向对象的编程语言，但它缺乏多重继承、运算符重载和显式内存分配等复杂特性。因此，它是一门易学习的语言。
- **强语言**：运行时错误和内存管理是导致程序失败的两个主要问题。在 Java 中，这些问题可以被高效地处理。异常处理程序可以解决处理错误的运行时错误，而垃圾回收可以处理内存管理错误。
- **安全性**：在编写 Java 时，所有代码都将限制在 Java 运行环境（JRE）内部。因此，不会授予对系统资源的授权访问。
- **多线程**：由于支持多线程，Java 允许你的程序同时执行不同的任务。

## Java 中的数据类型和变量

在 Java 中，有三种变量和几种数据类型。当你想要用这种语言编写程序时，理解它们至关重要。

### 数据类型

Java 中有几种数据类型：基本类型和非基本类型。基本数据类型是由 Java 预定义并提供的。Java 中这些类型的示例包括 `Boolean`、`char`、`int`、`long`、`short` 和 `float`。另一方面，非基本数据类型不是由 Java 定义的。相反，它们由你——程序员来创建。它们引用内存位置，因此它们有时被称为引用变量。`String` 和数组就是一些非基本数据类型。

### 变量

在 Java 中，有三种变量可以用于你的程序。类型取决于你如何声明变量。局部变量是在方法内部声明的变量。另一方面，实例变量定义在方法之外、类之内。静态变量简单来说就是用 `static` 关键字声明的变量，它们不能是局部变量。当你开始认真地学习 Java 编程时，你将学到这些用法。

和其他编程语言一样，你需要在使用变量之前对其进行声明。在 Java 中声明变量的基本语法如下所示。

```
Data type variable [= value];
```

你可以在一个语句中声明多个相同数据类型的变量。你只需要使用逗号来分隔它们。

在 Java 中，声明变量时需要小心，因为那里有相应的规则。变量名是区分大小写的。因此，‘Hi’和‘hi’被视为两个不同的变量。事实上，避免以大写字母开头变量名是一个好习惯，因为这种格式通常用于类名。你可以使用 `$` 和 `_` 符号，但要明智地使用。变量名中不允许有空格，你不能用数字开头。最后，你不能使用保留字或关键字作为变量名。

## 循环和条件语句

在程序中，语句和代码行是按顺序执行的。然而，可以创建复杂的执行路径以使某些程序和函数成为可能。这是通过不同的控制结构（如条件语句和循环）实现的。

当代码块需要执行多次时，就会使用循环语句。Java 中提供了适用于特定情况的不同类型循环语句。它们列举如下：

- **While 循环**：只要给定条件保持为真，一组语句就会重复。一旦条件变为假，循环将不再执行。在执行循环之前会进行条件测试。
- **Do-While 循环**：它的工作方式与 while 循环类似。然而，它会在循环中的代码执行后检查条件。
- **For 循环**：在这里，代码块将执行固定次数。它允许缩短管理循环变量的代码。

### 条件语句

这些结构实际上是伴随着一个或多个条件运行的。这些条件由程序进行评估，并根据求值结果执行语句。如果条件为真，则将执行某个特定的语句或一组语句。如果为假，则将执行另一组语句。换句话说，这些结构允许程序做出决策。Java 提供了几类供使用的条件结构。

- **If 语句**：它包含一个布尔表达式以及当条件为真时要执行的语句。
- **If else 语句**：这是一个与 `else` 语句一起使用的普通 if 语句。如果条件为假，将执行 `else` 语句下的语句。当 `if` 语句返回真时，执行其下的代码。
- **嵌套 if 语句**：这是 `if` 语句的特殊用法。可以将 `if` 语句嵌套彼此内部。它也适用于其他语句。



- **Switch 语句**：该语句用于测试变量与指定值列表的等同性。当变量的值匹配时，每个值都将有一个要执行的语句或代码块。

这些是在学习使用 Java 语言开发程序时应该熟悉的一些基础知识。正如前面提到的，Java 是通往编程世界的一个极佳跳板。一旦学会，你会发现学习其他语言变得更容易了。

### 理解 JavaScript 语法

JavaScript 中还有两种数据类型：未定义（`undefined`）和空（`null`）。这些简单的数据类型每个只定义了一个值。JavaScript 中还有一种复合数据类型，被称为对象（`object`）。


关于 JavaScript 的另一点是，它是一种无类型语言。因此，变量可以包含任何值，无论其在 JavaScript 中的数据类型是什么。换句话说，在声明期间不需要程序变量可以持有什么类型的数据。此外，稍后更改任何变量的值类型也是可能的。JavaScript 会在程序执行期间自动处理更改。

在 JavaScript 中，变量可以有两个作用域。作用域定义了变量定义的程序区域。

- **If else 语句**：这些语句在 if 语句之后包含一个 else 语句。如果 if 表达式被判定为 FALSE，将执行 else 语句下的代码块。

- **If elif 语句**：`elif` 语句用于检查多个条件和表达式。当给定的条件之一被判定为 TRUE 时，将执行与该 `elif` 语句关联的代码块。因此，在一个 if 语句后面可以有多个 `elif` 语句。执行的代码块对应于评估为 TRUE 的那个 `elif` 语句。

## Ruby 编程中的语法

在任何编程语言中，你都需要注意代码的语法。不恰的语法可能会在运行期间导致错误，甚至会破坏程序并产生与预期不符的结果。在 Ruby 中，语法概念非常简单且易于理解。以下是你在使用这种语言进行编程时需要了解的一些语法概念。

### 空格符

在 Ruby 中，像制表符（`tabs`）和空格等空白字符通常会被程序忽略。然而，当它们出现在字符串中时，会被考虑在内。尽管如此，在某些情况下，空白字符被用于解释歧义的语句。如果启用了 `-w` 选项，这些解释可能会产生警告。

### 行结束符

在 Ruby 中，换行符和分号被视为语句的结束。然而，如果将反斜杠 `\` 和加 `+` 等运算符放在行尾，Ruby 将其视为语句将继续的指示。

### 标识符

标识符是赋予方法、常量和变量的名字。在 Ruby 中，标识符始终是区分大小写的。因此，'Hi'、'HI' 和 'hi' 在 Ruby 中被视为不同的标识符。另一方面，你可以使用字母数字以及下划线字符来创建标识符。

### Ruby 中的 BEGIN 和 END 语句

这些是 Ruby 中两个重要的语句。在你用这种语言编程时，你一定会遇到需要使用这些语句的情况。

#### BEGIN 语句

该语句允许在其下方的代码在实际程序执行之前进行声明。因此，`BEGIN` 语句中的代码将首先被执行。你可以使用多个 `BEGIN` 语句，它们将按照它们在程序中出现的顺序执行。该语句的基本语法如下。

```ruby
BEGIN {
#code
}
```

#### END 语句

这是 `BEGIN` 语句的相反，它所声明的代码将在程序结束时执行。该语句的语法如下。

```ruby
END {
#code
}
```

Ruby 中有四种变量。理解它们对 Ruby 编程至关重要。以下是对这些变量的简要介绍。

**类变量（Class Variables）**：如名所示，这些变量属于特定的类，并供该类中的不同对象使用。它们也是该类的一个特征。它们将在定义它们的模块或类的后代之间共享。在方法定义中使用它们之前，你需要对它们进行初始化。如果使用了 `-w` 选项，当类变量被重写时，将产生警告。所有的类变量必须以 `@@` 开头。

**实例变量（Instance Variables）**：这些变量对特定对象或实例的不同方法可用。因此，不同对象的实例变量将是不同的。如果未初始化，实例变量的值将为 `nil`，且如果使用了 `-w` 选项，它将引起警告。



# 局部变量（Local Variables）

这些变量的作用范围从代码块的开始到其结束。换句话说，它们存在于大括号之间。它们在方法外部是不可用的。如果你引用一个未初始化的局部变量，Ruby 将其认为是对一个没有参数的方法调用。可以通过给未初始化的局部变量赋值来声明局部变量。所有的局部变量必须以下划线或小写字母开头。

# 全局变量（Global Variables）

当你需要一个存在于所有类中的变量时，可以使用它们。通过给全局变量赋值，你可以更改全局状态。因此，除非绝对必要，否则不建议使用它们。它们可能会使程序复杂。未初始化的全局变量的值为 `nil`。带有 `-w` 选项，它们会引起警告。所有的全局变量都需要以 `$` 字符开头。

# Ruby 中的条件结构

Ruby 提供了许多条件结构，其中大多数与其他编程语言通用。因此，如果你熟悉其他语言，那么你不会遇到任何问题。即使你不熟悉，学习对你来说也不会困难。

- **If 语句**：该语句用于在条件确定为真时执行代码块。当条件返回假时，将跳过代码的执行。
- **Else 语句**：else 语句与 if 语句配合使用。它在条件求值为假时提供一个待执行的备用代码块。
- **Elsif 语句**：elsif 语句与 if 和 else 语句配合使用，并位于两者之间。可以根据需要添加任意数量的 elsif 语句。当由于需要检查多个条件时使用此语句。elsif 语句对应的条件为真时，其代码块将被执行。
- **Unless 语句**：unless 语句是 if 语句的相反。它用于在你希望在条件返回假时执行代码块时。
- **Case when 语句**：当你需要评估很多选项时，使用 if-els-else 条件结构可能会变得复杂。在这种情况下，当条件返回正确的值时，你可以使用 case 语句。当多个语句应用于 case 语句时，when 下方的多个代码将执行执行。在这个条件结构中，也可能使用 else 语句。当条件没有返回任何被 when 语句接受的值时，else 语句将提供一个待执行的代码块。

# Ruby 中的循环语句

Ruby 中也提供了循环。正如你所知道的，循环允许你多次执行某个代码块。以下是对 Ruby 中可用循环的简要介绍。

- **While 循环**：while 循环允许只要条件为真就执行代码。一旦条件变为假，执行就会停止，程序跳转到下一个语句。
- **Until 循环**：这是 while 循环的反向。只要条件为假，until 循环就会一直执行。当条件变为真时它停止。
- **For 循环**：虽然 Ruby 提供了 for 循环，但它与其他编程语言中的 for 循环不同。相反，Ruby 中的 for 循环功能更像其他编程语言中的 for 循环。结果是，只要给定的表达式中有元素，它就会执行代码。
