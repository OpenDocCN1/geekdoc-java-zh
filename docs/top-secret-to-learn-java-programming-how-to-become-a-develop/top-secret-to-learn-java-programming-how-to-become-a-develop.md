## 引言

目前有很多可接触的编程方言，并且每一种都适用于特定的程序或应用程序。有些人学习了几种编程方言，并因为他们熟悉这些语言而使用它们，但在大多数情况下，开发人员会使用他们正在开发的应用程序所所需的编程语言。Java 可能是最常用的编程语言，而用这种语言编写代码在某种程度上与 Pascal 或任何 C/C++ 形式不同，但这并不意味着学习 Java 代码比学习 Pascal 或 C++ 更困难。如今有许多应用程序是用 Java 编写的，它的语法起初看起来可能有点难，但毫无疑问，任何人都可以用这种语言进行编写。

在研究另一种编程语言时，大多数人都想知道它是否容易学习和工作。如果你将其与 C 或 C++ 进行比较，你可能会发现毫无疑问，很好地使用它可能更加简单。这是因为 Java 与 C 语言相比特性要少得多。C 和 C++ 使用了大量的特性，学习并掌握所有特性可能是一项艰巨的任务（例如，临时因素在创建它们的函数执行完毕后仍然存在）。Java 更加简单，因此更容易学习和也更容易工作。例如，Java 消除了显式的指针解引用和内存分配/回收，这些是 C 和 C++ 软件工程师两个最混乱的 bug 来源。

越界加法并不容易追踪，因为 Java 可以进行数组边界检查。其他人可能认为，由于没有多少使用它执行极其复杂任务的情况，它看起来更容易操作，但公认的观点是，在某种程度上掌握 C 或 C++ 更简单。学习用 Java 编写程序非常容易，特别是如果你了解其他更基础的编程方言，并且毫无疑问知道你需要如何使用它时，它与 C 和 C++ 相比有一系列优势。最重要的是，这种编程语言编写的代码非常紧凑。C 和 C++ 编写的代码则不然，这使得 Java 更可行（例如，在 C 和 C++ 中，每次执行都对基本数据类型的精确度和容量有特定的要求）。

当你需要从一个框架移动到另一个框架时，这将引发问题，因为数值精度的变化会影响计算。然而，Java 规定了所有执行中基本类型的大小（例如，一个框架上的 `int` 大小在每一个给定的框架上都是相同的，并且处理相似的值范围）。

使用浮点数数学的项目实例需要特别考虑：使用浮点计算的程序在不同框架下可能会得出不同的结果（在这种情况下，差异程度会随着特定值经过的计算次数增加而增加）。然而，这是所有浮点数代码的共同问题，而不仅仅是 Java 代码，Java 在其字节码方面同样比 C 或 C++ 灵活。它被编译为假设机器的字节码——最终，解释器模拟了那台机器。这意味着在一台 PC 上收集的代码将在具有 Java 解释器的其他 PC 机器上运行，关于这一点，你将在学习 Java 编程时发现更多信息。

## 学习 Java 编程的最佳方法

一个企业基本上可以被描述为 Java 编程一直是信息技术发展的最前沿。这在组织的 IT 开发中可以更好地看到。通常在企业发展中，Java 正在被使用。使用这种编程语言的一个真实模型是例如飞机订票的企业内部工具。你是否想过航空公司如何通过基本上登录框架让预订行程变得异常快速？正因为了 Java，这成为了可能。在软件工程师中极少数人不同并掌握了 Java 的每一个门道。有些人可能了解它的原理，但只有少部分高级原理。这就是需要在该领域精通的软件工程师应该尽一切学习 Java 编程的地方。当你有机会从每周五天每天 8 小时的工作中抽身并承担一些责任时，这怎么可能呢？幸运的是互联网充满了你可以利用其潜在利益的资源。你只需要找一个懂 Java 的人，可以在你的业余时间一对一向你展示，并且有足够的资源教你关于这种编程语言的知识。

事实上，学习 Java 编写程序的最佳方法是拥有一个有耐心的导师或教练，他们可以为你介绍基础知识并帮助你学习开发工具。准备好支付比预期稍多一点费用，特别是如果你需要从最好的人那里受益。除了从中获得的信息之外，你还可以通过最新的适应来更新自己。

到目前，自 1997 年 2 月 19 日 JDK 1.1 版本首次发布以来共有 7 个 Java 版本。当前版本是 Java SE7，它是于 2011 年 7 月 28 日发布的。Java 7 的更新 9 已于最近 2012 年 10 月 16 日发布。

显而易见，如果你在 1997 年学习了 Java 但没有通过最新的更新刷新自己，你将会落。因此，学习 Java 编程并更新你的知识实际上是一项绝对的要求。不仅是为了基础，而是为了提高你的能力。

## 为什么要学习 Java？

Java 是一种先进的面向对象的编程语言

面向对象编写程序是一种设计风格，它使用称为类的代码单元来表示现实中的对象。这种编程风格已被证明产生既健壮又灵活的代码。除了面向对象之外，Java 还支持其他编程方法，例如多线程、异常和传统的编程。Java 有简洁且可靠的语法结构，Java 语言的设计没有任何准备。它的设计者不需要担心与过去语言的相似性，这为 Java 提供了一个完美且稳定的标法。Java 自带一个巨大的高效的应用程序编程接口（API）。这允许软件工程师可以关注任务的要点，而不是编写更宽泛的代码或在外部库上胡乱尝试。

Java 的设计初衷是多功能性的

大多数 Java 项目可以在各种工作框架和设备阶段上几乎不需要修改即可运行。

Java 是一种由组织驱动的语言

Java 旨在能够在组织环境中良好地运行，其 API 和安全模型使得网络既保护又稳固。

Java 是安全的。Java 是安全的，它允许来自网络的代码在隔离的环境中运行，保护主机框架免受感染等。此外，Java API 提供了管理计算机声明和其他加密方法的计划。Java 是一门卓越语言。

## 如何成为 Java 开发人员？

### 了解 Java 的优势

Java 是 IT 行业中许多编程语言之一。你现在可能已经知道其中几种语言，或者可能了解过它们。

- ASP、C、PHP 仅仅是几个模型。无论如何，有了这些模型，你为什么选择 Java 是一个好主意呢？

我不是来这里说这是一门最棒或最糟糕的语言。我更想表达的是 Java 有它的用武之地，你需要了解它的特性。Java 对于大型框架，以及需要 Java 提供的展示性能和多功能性的项目来说，是一门很好的语言。对于更简单的任务或更简单的网站来说，它可能不是最好的语言选择——虽然这是可能的，但并不是 Java 特性所在之处。

### 下载必要的工具

要开始学习 Java，你必须下载用于创作的工具和软件。你需要两样东西——Java 开发工具包 (JDK) 和开发环境（也称为 IDE，代表集成开发环境）。一些非常著名的 IDE 有 NetBeans 和 Eclipse。

这些都可以从 Java 网站获取。一旦你下载并安装了它们，这就是学习这门语言的绝佳机会。

### 熟悉 Java 语言

要成为 Java 设计师，你需要学会如何用 Java 编程。如果你熟悉其中一部分，那太棒了——这会让这部分变得简单。如果没有，你可以从几个渠道学会如何用 Java 编程：

- 基于网络的教学练习。许多网站提供关于如何创建 Java 最佳实践的教学练习，从初学者想法到尖端主题都有。通过 Google 搜索来找到适合你的练习。

- 教科书——购买一本课程书籍是熟悉该语言的好方法，因为它同样包含了初级和高级思想。许多书中都有实用的活动和模型。

- 大学或学校的课程。许多学校或学院提供短期课程，有些可能包含 Java 开发培训。这种方法的优点是处于群体环境中并有指导老师，而不是从书或网络中自学。

### 开始一个你自己的 Java 项目

一旦你处理好了基础知识，你就可以开始自己的项目来帮助提升 Java 能力。这可以是你喜欢的任何内容。重点是练习和培养你的 Java 能力，以便你更精通 Java 编程语言以及如何使用 IDE。你将在从故障排除、编写自己的代码到遵循最佳实践方面获得实用的经验。这些被认为是从你的练习或其他学习技术中获得的，但将它们投入使用是提高这些能力的好方法。

### 迈出的一一步

当你对自己的 Java 开发能力有信心时，就是迈出下一步的绝佳机会

- 获得一个 Java 开发职位。这可能是整个互动中最困难的部分。许多公司有特定的经验要求，可能包括证书、学位和专业经验。

如果你只是在学习这种语言且没有专业经验，你应该寻找初级 Java 职位。这些职位可能需要某种形式的认证或能力证明。这就是你的侧边项目派上用场的地方——如果你使用 Java 构建了应用程序或网站，可以很好地放在简历中增加机会。

成为 Java 设计师的另一个大建议是获得认证。一个非常好的入门认证是 SCJA - Sun 认证 Java Associate。这项认证非常适合学生或初级 Java 软件工程师，并在寻找 Java 设计师工作时将是一个巨大的优势。查看另一篇关于成为开发人员最佳方法的新文章以获取更多提示。

## Java 语言最重要的优势

Java 自最初出现以来就获得了巨大的普及。它的快速崛起和广泛认可可以归功于它的设计和编程特性，特别是它保证了你可以“一次编写，到处运行”。Java 被选为网络计算机 (NC) 的编程语言，并被视为企业信息库的通用前端。正如 Sun Microsystems 的 Java 语言白皮书中述：

> "Java 是一种简单的、面向对象的、解释的、解释的、强大的、安全的、平台无关的、紧凑的、多线程的动态。" Java(TM) 比其他语言环境具有关键优势，使其适用于任何编程任务。

Java 的优点如下：

- Java 不难学习。Java 设计初衷是易于使用的，因此比其他语言更容易编写、组装、从故障排除和学习。

- Java 是面向对象的。这允许你创建特定的项目和可重用的代码。

- Java 是无平台的。也许 Java 主要优势之一是它可以从一个计算机框架有效率移动到下一个。
