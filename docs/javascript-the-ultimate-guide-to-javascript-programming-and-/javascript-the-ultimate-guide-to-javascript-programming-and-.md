## 编程简述

在继续学习 JavaScript 之前，首先理解什么是编程至关重要。

计算机程序可以是任何东西。你用来阅读这本电子书的软件是一个程序。你使用的互联网浏览器是一个程序。播放你音乐文件的应用程序是一个程序。你正在玩的游戏是一个程序。换句话说，你在计算机中看到和使用的一切都是程序。所有这些都是一个被称为编程的单一过程的产物。

编程是一门艺术。程序员输入一段代码来命令计算机执行特定操作。让我们以人体来类比。

如果你被给出一个数学问题来解决，你的大脑必须处理它。根据等式的规模，你可能会发现自己正在数手指或在纸上解一个公式。简而言之，有几种身体功能在工作。

从编程的角度来看，所有这些身体功能都是程序，你的整个身体就是机器。你大脑的机械对应物是机器的内存。方程式是我们要处理的数据。

我们的首要目标是处理数据。在上面的场景中，那就是为数学问题提供正确答案。为了让我们的身体能够做到这一点，你的眼睛需要看到问题并将其传递给你的大脑。对于机器来说，你需要一个程序来完成这一传递和处理过程。

# 第 1 章 – 认识数字、运算符和字符串

浏览互联网就能接触到数百万行 JavaScript 代码。当你最喜爱的互联网浏览器（例如 `Google Chrome`、`Mozilla Firefox` 和 `Internet Explorer`）开始访问某个网站时，你已经在使用 JavaScript 语言进行通信了。

在这一章中，我们将讨论 JavaScript 语言的基础构建块。这将帮助你在之后转向像 `jQuery` 等高级框架时建立一个坚实的基础。

## 控制台

在一切之前，访问浏览器控制台对你来说至关重要。浏览器控制台是开发者工具之一。它记录了与当前网页相关的信息，这些信息包括 CSS、安全错误和 JavaScript。控制台还允许你通过断言 JavaScript 表达式与网页进行交互。

这就是我们将在书中执行示例 JavaScript 代码的地方。你可以通过按下键盘上的 `F12` 键访问它。寻找 **Console**（控制台）选项卡，你现在准备好开始了。

## 基础数字与提示符

在开始学习 JavaScript 时，你需要熟悉两个符号：

- `>` 大于符号（代表 JavaScript 的提示符）；
- `→` 箭头符号（指代我们输入的代码产生的结果）。

该符号代表 JavaScript 的提示符。我们想要输入控制台的所有代码都将写在这个符号之后。

在 JavaScript 语言中，数字会被自动识别。在提示符后输入数字并按下键盘上的 `Enter` 键，将得到相同的值的结果。尝试在控制台中输入数字 `13`，它将返回相同的值。

```
> 13
→ 13
```

带有小数值的数字也是如此。

```
> 13.29
→ 13.29
```

## 运算符

在 JavaScript 中，数学运算也是允许的。JavaScript 语法中常用的运算如下：

- 加法（`+`）
- 减法（`-`）
- 乘法（`*`）
- 除法（`/`）
- 模/取余（`%`）

### 加法

```
> 1 + 3
→ 4
```

### 减法

```
> 10 - 5
→ 5
```

### 乘法

```
> 2 * 9
→ 18
```

### 除法

```
> 25 / 5
→ 5
```

### 模（取余）

另一方面，模是 JavaScript 语言中的特殊运算。它通过 `%` 符号表示。你得到的结果是两个数字相除后的余数。

```
> 23 % 2
→ 1
```

在上面的模示例中，控制台将 `23` 除以 `2`。即使在 `23` 中可以除 `11` 次，控制台也只显示余数作为结果，即 `1`。

### PEMDAS 顺序

JavaScript 编程遵循流行的数学运算顺序：PEMDAS。这个缩写代表：

- **P** 括号
- **E** 幂
- **M** 乘法
- **D** 除法
- **A** 加法
- **S** 减法

让我们以以下表达式为例。

```
> (10 + 5) * 3
```

按下 `Enter` 键后，控制台将向你返回这个答案。

```
→ 45
```

括号内的运算将首先求解。在我们的情况下，是 `10 + 5`，这给了我们 `15`。之后，该和将与 `3` 相乘。因此，控制台给您 `45`。

让我们尝试一个更长的表达式。

```
> (7 * 2) + 5 - 10/2
```

按照 PEMDAS 顺序，该表达式将如下求解：

```
14 + 5 - 10/2
14 + 5 - 5
19 - 5
```

因此，控制台将向你返回这个答案。

```
→ 14
```

## 比较运算符

除了算术运算符之外，JavaScript 语言也识别逻辑运算符，我们称之为比较运算符。JavaScript 中常用的比较运算符通过以下语法表示：

- `>` 大于
- `<` 小于
- `==` 等于
- `!=` 不等于
- `>=` 大于等于
- `<=` 小于等于

使用这些比较运算符在 JavaScript 中发送表达式就像是在向控制台提一个逻辑问题。你从控制台得到的答案可能是 `true`（真）或 `false`（假）。这些答案被称为布尔值。

让我们尝试将以下表达式发送到控制台。

```
> 10 !== 9
```

这个表达式就像是在询问控制台在 JavaScript 语言中 `10` 是否不等于 `9`。因此，控制台将给你 `true` 作为答案，因为 `10` 在数值上不等于 `9`。

## 字符串

JavaScript 处理字符串、存储并处理纯文本作为字符串。为了通知控制台我们要处理纯文本，我们需要将它们包含在引号内。这将允许控制台将文本识别为字符串并返回字符串。

### 计数字符串长度

在 JavaScript 语言中，你可以轻松地访问字符串的长度。这样做会让控制台计算引号内的所有字符，包括空格以及位于字符串开始和结束引号之间的非字母字符。我们通过在字符串紧后面添加 `.length` 属性来实现这一点。

这是我们的编写方式以及我们将会得到的输出结果。

```
> "Pneumonoultramicroscopicsilicovolcanoconiosis".length
→ 45
```

现在，让我们尝试使用一个带有空格和非字母字符的字符串。

```
> "Pink, Blue, Black, Red, Purple, White, and Green".length
→ 48
```

# 第 2 章 – 发现变量

现在你已经学会了如何在 JavaScript 语言中编写、格式化和处理数据，现在是时候学习变量了。在这一章中，你将学习如何使用变量存储值。如果不先学习如何编写变量，你将无法做到。话不多说，让我们开始变量世界的之旅吧。

```html
<!DOCTYPE HTML>
<html>
<head>
<TITLE>Variables</TITLE>
<SCRIPT LANGUAGE="JavaScript">
var number1 = 21;
var true_or_false = true;
var firstName = 'Kenny';
document.write(number1 + "<BR>");
document.write(true_or_false + "<BR>");
document.write(firstName + "<BR>");
</SCRIPT>
</head>
<body>
</body>
</html>
```

## 值的存储

为了在 JavaScript 语言中管理数据，你必须将它们存储在变量内部。让我向你展示一个变量的基本赋值语法，将其命名为 `learnEasy`。

```javascript
var learnEasy = 6
```

代码中的 `var` 指的是变量关键字。它命令浏览器为此变量预留特定的空间。下一个是 `learnEasy`，指的是变量名。这是我们将分配给此示例变量语法的名称。这里的等号充当赋值运算符。注意，我们在这里只使用一个单等号，这与我们之前用于比较的双等号不同。最后，数字 `6` 充当我们要存储在名为 `learnEasy` 的变量中的值。

现在由于我们已经在变量中存储了一个值，我们现在可以仅通过变量名来调用它。在控制台中输入变量名 `learnEasy` 将带给我们赋值的值作为输出。

```javascript
learnEasy
→ 6
```

在为我们的变量分配名称时，JavaScript 语言中有一些我们需要遵循的规则。这些规则如下：

1. 变量名中不能有空格。（例如：`var learn easy`、`var sweet java`）
2. 变量名开头不能是数字。（例如：`var 4life`、`var 1piece`）

你可以在变量名中使用特殊字符。但最好使用简单的名称以免让 JavaScript 语言变得复杂。

1. 你可以在变量名中使用下划线（`_`）。（例如：`var learn_easy`）
2. 你可以在变量名中使用美元符号（`$`）。（例如：`var learnE$y`）
3. 你可以同时使用下划线和美元符号。（例如：`var learn_ea$y`）

一个良好的变量名应该是这样的。它被称为“驼峰命名法”，以小写字母开头，后续单词的首字母大写。

```javascript
var simpleAndClean
```

如果你喜欢重用变量名来存储不同的值，你可以通过在末尾添加一个数字来简化一切，像这样所示。

```javascript
var simpleAndClean2
```

## 在变量中更改已赋值的值

让我们回到示例变量 `learnEasy`。目前，我们给它分配了数值 `6`（原文此处有笔误为 3，根据上下文应为 6）。假设例如，你想更改分配给该变量的值。你可以通过输入变量名，后跟赋值运算符，然后是你想分配给变量的新值来轻松实现。

```javascript
learnEasy = 13
```

注意，我们在这里不再使用变量关键字 `var`。这是因为控制台记得该值已经存在于它的内存中了。一旦你调用此变量，你现在将获得分配给它的新值。

```javascript
learnEasy
→ 13
```

你也可以在数学表达式中使用其自身的变量名来更改现有变量的值。格式应该是变量名后跟赋值运算符。你在运算符后插入数学表达式。它应该是这样的：

```javascript
learnEasy = learnEasy + 16
```

这将我们的存储的值改为 `29`，因为该表达式调用了当前变量值（即 `13`）加上 `16`。这使得它变成了 `29`。

还有另一种方法可以做到。我们将使用不同的语法来更改存储的值。它如下：

```javascript
learnEasy += 2
```

这里的 `+=` 运算符命令控制台先将变量的当前值加上数字 `2`。然后它命令控制台将新值存储到同一个变量中。由于我们的当前值是 `29`，我们现在将获得 `31` 作为存储在变量 `learnEasy` 中的新值。

所有运算符都可以这样使用（如 `-=`、`*=`、`/=` 等）。

## 存储字符串

除了数值，你还可以存储字符串。它看起来是这样的：

```javascript
var hello = "Welcome to JavaScript!"
```

当变量中有一个字符串时，你可以像使用其他变量一样使用它。例如，你可以拼接（连接）字符串：

```javascript
var str1 = "Hello ";
var str2 = "World";
var message = str1 + str2;
```

这将产生 `"Hello World"`。

如果你想访问字符串中的特定字符，可以使用 `charAt()` 方法。该方法返回指定索引处的字符。记住字符串索引从 `0` 开始。

```javascript
var text = "JavaScript";
text.charAt(0); // 返回 J
text.charAt(4); // 返回 S
```

## 查找字符

`charAt()` 方法允许你在特定位置查找字符。这里是一个示例：

```javascript
var text = "JavaScript";
text.charAt(0)
→ J
text.charAt(1)
→ a
text.charAt(2)
→ v
text.charAt(3)
→ a
text.charAt(4)
→ S
text.charAt(5)
→ c
text.charAt(6)
→ r
text.charAt(7)
→ i
text.charAt(8)
→ p
text.charAt(9)
→ t
text.charAt(10)
→ t
```

如果你想获取字符串的长度，可以使用 `length` 属性。

```javascript
var text = "JavaScript";
text.length
→ 10
```

## 创建消息

现在你已经知道如何在变量中存储值，让我们现在创建消息。这里有一个示例：

```javascript
var hello = "Welcome to website!";
var enjoy = "Enjoy your visit!"
```

现在我们有两个变量，让我们现在合并它们：

```javascript
var message = hello + enjoy
```

这将带给我们输出：

```
Welcome to website! Enjoy your visit!
```

# 第 3 章 – 构建和运行 JavaScript

学习变量很有趣，不是吗？然而，没有人想在控制台中编写 JavaScript。在这一章中，你将学习如何构建文件。你还将学习如何在 HTML 中运行这些文件。所以让我们开始吧。

## 创建源文件



仅在控制台中编写 JavaScript 代码无法打印我们想要传给用户浏览器的内容。因此，我们需要找到一种方法将想要带给用户。为了这样做，我们需要创建 JavaScript 源文件并在 HTML 文件中运行这些文件。这是常见的 HTML 文件 `index.html` 的一个示例。

```html
<html>
<head>
<script src="greetings.js"></script>
</head>
<body>
<h1>WELCOME TO JAVASCRIPT!</h1>
...
</body>
</html>
```

## 将源代码存放在哪里

在浏览你的网站的文件管理器时，你永远不会错过看到一个名为“root”的文件夹。这就是我们找到网站内部所有内容的地方。这也是你网站 `index.html` 的默认所在位置。

根据上面的 `index.html` 文件，我们引导它在同一个文件夹内——即 `root/` 文件夹——寻找 JavaScript 源代码文件。因此，我们应该将 `greetings.js` 存放在相同的位置。

```
+ root/
- index.html
- greetings.js
```

然而，有些网站会将所有的 JavaScript 源代码文件放在子文件夹中。它们源代码最常见的目录是 `scripts/` 文件夹下。以下是它们在你的网站目录中的样子。

```
+ root/
- index.html
+ scripts/
- greetings.js
```

如果你想以这种方式组织你的源代码，那么我们需要修改示例 `index.html` 中的 `<script>` 标签。你的 HTML 代码看起来应该是像这样的：

```html
<html>
<head>
<script src="scripts/greetings.js"></script>
</head>
<body>
<h1>WELCOME TO JAVASCRIPT!</h1>
...
</body>
</html>
```

请注意，在这段代码中，我们正在指示 `index.html` 从 `scripts/` 子文件夹加载 `greetings.js`。

## 在源文件中编写代码

直接在 `greetings.js` 中编写控制台风格的表达式会导致错误。让我们尝试在源文件中编写以下几行作为示例。

```javascript
var hello = "Welcome to my website! ";
var enjoy = "Please enjoy your visit!";
hello + enjoy;
```

一旦我们打开 `index.html` 并进入浏览器控制台，我们将看到错误之外一无所获。这是因为我们对你真正想要显示的内容感到困惑。错误来自我们的 JavaScript 源代码文件。与控制台不同，我们需要在源文件中以方式断言 JavaScript 代码。我们通过在每个语句后添加分号（`;`）来实现这一点。因此，我们应该这样写 JavaScript 代码。

```javascript
var hello = "Welcome to my website! ";
var enjoy = "Please enjoy your visit!";
hello + enjoy;
```

使用带有分号编写的代码后，当你尝试访问控制台时将不再看到错误。但是，你会在控制台中看不到任何内容。这意味着我们的代码尚未被传递到浏览器的控制台中。JavaScript 代码的执行仅发生在源文件本身。为了修复这个问题，我们需要使用 `console.log()` 方法。

我们想要做的是显示来自变量 `hello` 和 `enjoy` 拼接而来的字符串。以下是我们的做法：

```javascript
var hello = "Welcome to my website! ";
var enjoy = "Please enjoy your visit!";
console.log(hello + enjoy);
```

通过使用 `console.log()` 方法，你现在能够在控制台中看到该字符串了。换句话说，我们现在有了一个由 `index.html` 文件运行的正常 JavaScript 编程语言。

赛博朋克对现代黑客概念的影响是巨大的。当我们能够从虚构的表现中认出自己的世界时，科幻小说就尤为有效，而在赛博朋克中，我们可以认出当代技术时代的许多忧虑。劳伦斯·彼森（科幻杂志《新极快报》编辑）描述了赛博朋克中的典型人物：

> “经典的赛博朋克角色是边缘化的、异化的孤独者，他们生活在社会的边缘，通常处于反乌托邦的未来中，那里日常生活受到快速技术变化、无处不在的计算机信息数据领域以及对人体侵入式改造的影响。”

对于现代读者来说，这种对赛博朋克角色的描述让人想起了大众想象和电影中描绘的黑客形象。因此，赛博朋克角色与我们看待现实生活中黑客的方式之间的相互作用是巨大的：在很多方面，我们对黑客的理解是基于小说中对赛博朋克角色的描绘的。一个例子是，赛博朋克角色往往生活在肮脏的环境中，晚上工作白天睡觉，除了聊天室外没有任何社交生活。

在现代的想象中，当我们想起黑客时，往往会想到一个坐在黑暗电脑屏幕后的孤独少年。事实上，作为首批处理赛博朋克的科幻作家之一，迈克尔·布鲁斯·斯特林对理解黑客行为的发展表现出了最大的兴趣。

斯特林将黑客行为以及相关的地下计算机网络的出现追溯到“嬉皮士”（Yippies），这是一群活跃在20世纪60年代的反文化团体，他们曾出版了《技术援助计划》（Technological Assistance Program），这是一本向读者教授未经授权访问电话技术的杂志，被称为“电话欺骗”（phreaking）。

许多参与电话欺骗社区的人也是地下黑客社区的活跃分子，这表明了这两个群体之间存在关系。

# 第二章 – 黑客的不同类型

计算机黑客地下世界包含了各种不同的黑客分支。这主要是由于意识形态的冲突，某些小组通过特定的名称称呼自己，或称他人为特定名称，以强调他们不同意他人的意识形态。

因此，通用词“黑客”（hacker）虽然指的是具有技术知识并能够未经授权访问计算机系统的人，但相当模糊，无法区分那些使用不同方法或持有某些观点的人。

相反，出现了一些独立的名称以区分不同的群体，并表明并非所有黑客都遵循相同的规则或意识形态。正如之前讨论过的，看到这一点的一种方式是埃里克·S·雷蒙德（Eric S. Raymond）在《新黑客字典》（The New Hacker’s Dictionary）中提倡的——黑客与破解者（crackers）之间的区别。

在本书书中，雷蒙德编写了一份黑客计算机编程术语表，但来自黑客社区的人认为这本书太偏向于雷蒙德本人将黑客行为视为恶意行为的观点。

普通黑客社区并没有遵循雷蒙德建议的“黑客/破解者”二分法，而是认为这种划分过于简单，转而主张使用更广泛的名称列表来反映大型黑客社区的信仰和实践全谱。

黑客的一个分支被称为“白帽黑客”，他们在没有恶意动机的情况下突破计算机安全。这样做的例子包括测试自己的安全有效性，或者在开发计算机安全软件时。

这些安全突破发生在作为合同协议的一部分对计算机软件进行漏洞评估期间，因此是合法的。在俚语中，“白帽”指的是为了正当理由采取行动的道德黑客，目的是保护而非破坏。存在一些公认的组织，例如电子电子商务顾问国际委员会（International Council of Electronic Commerce Consultants），为这一领域的伦理黑客提供培训和证书。

另一方面，还有“黑帽黑客”，他们出于恶意目的进入计算机系统。这类黑客通常被称为破解者（crackers），他们出现在电影和电视中，被描绘为了破坏、改变信息或获取利润而违反安全的群体。这些类型的黑客为了造成干扰或窃取数据而破坏安全，这种行为是非法的。通常，黑帽黑客会花费时间寻找并发现程序或计算机系统的漏洞，他们为了个人利益或仅仅为了好玩。

在白帽黑客和黑帽黑客之间，存在“灰帽黑客”。这种人介于两者之间，他们在没有被要求的情况下在互联网上寻找系统安全缺陷，然后通知管理员以修复问题。通过这种方式，他们不像白帽黑客那样（因为他们收费，且其服务从未被请求），也不像黑帽黑客那样糟糕（因为他们不会造成干扰或窃取数据）。灰帽黑客发现漏洞的另一种方式是在网上发布他们的发现，以便公众获取信息。通过这种方式，他们并没有亲自进行恶意黑客行为，但发布了信息，这使得主体面临风险。这种类型的黑客行为是非法的，也被认为是不合道德的，无论灰帽黑客是否为了个人利益获取未经授权的访问并导致系统受到攻击。

除了这基于动机和对信息处理方式的三种主要分类外，还有其他特定的黑客类型。黑客内部存在社会等级制度，根据技能水平获得认可。

地位最高的是精英黑客，他们有时会组成精英小组“欺骗大师”。在尺度的另一端是脚本小子（script kiddie），他们仍在学习中，尚未在突破安全系统方面培养技能。脚本小子使用他人编写的自动化工具，仅仅是遵循更高水平黑客提供的代码，而不需要自己推演。通常，脚本小子对复杂的底层技术概念并没有真正的知识或理解，只是遵循经验丰富的黑客提供的计划。

比脚本小子经验更少的是新手（neophyte），他们是完全的新黑客，对计算机技术或黑客背后的逻辑和概念了解甚少。蓝帽（blue hat）指的是安全咨询公司使用的人，但他们并不是公司的一部分；蓝帽用于在系统发布之前进行测试，以确定其是否存在安全问题或是否容易受到攻击。

黑客活动主义（hackivist，由“黑客”和“活动家”一词组合而成）是指利用其技术知识和黑客技能来传播政治、社会或宗教信息的黑客。黑客活动主义本身有两个分支：网络恐怖主义（网站损坏或服务无法访问）和信息自由（向公众公开此前未披露的信息）。

集体协作的黑客群体可能包括有组织的犯罪团伙、国家间的网络战争等。黑客的不同子类别反映了黑客社区中存在的各种意识形态、动机和技术。

# 第3章 – 计算机安全

在我们开始探索黑客的关键概念和技术之前，首先了解计算机安全的基础知识是有帮助的。由于黑客是指突破计算机系统安全措施的行为，因此对于任何希望渗透这些系统的黑客来说，了解这些系统至关重要。计算机安全应用于计算机、智能手机、计算机网络（公共网络和私有网络）以及整个互联网，以保护设备、数据和服务。

计算机安全保护数字设备免受未经授权的访问，以确保数据不被盗取、更改或删除，并保持系统的顺利运行。在当今社会，数字文化不断发展，保护这些系统至关重要，计算机安全领域也在不断增长和发展。计算机安全的一部分是保护物理设备免受盗窃，而另一部分是信息安全，旨在保护数据本身（这正是黑客发挥作用的地方）。

然而，有时这两个领域会重叠，因为如果物理安全出现漏洞（例如，如果笔记本电脑被盗），那么个人成功突破信息安全就会变得容易得多，因为他们拥有了设备，因此访问数据比远程访问要容易得多。

网络安全涵盖了保护计算机数据的所有安全措施，包括意识培训、渗透测试以及使用密码来确认授权等程序，以确保数据在传输过程中和仅存储时都能得到保护。成为计算机安全漏洞受害者的财务成本是巨大的，因此防病毒和计算机安全保护出现了一个利润丰的市场。

由于我们现在对技术的依赖，计算机安全是一个巨大的领域。几乎每个行业都在或或少程度上使用计算机，因此计算机安全措施的范围和种类非常广泛。然而，在某些领域，计算机安全尤为重要，因为它们特别容易受到安全漏洞的影响。

其中之一就是金融系统领域，因为黑客可以通过窃取数据并随之获取资金来获利。任何要求用户输入信用卡号的网站通常都是目标，因为黑客可以立即将钱转入自己的账户，或在网上花费受害者的钱。

即使黑客本身不直接使用他人的银行详情，他们也可能非法出售这些信息，以与犯罪撇清关系并避免被捕。不仅是在网上个人的数据可能被盗；店内的刷卡机和 ATM 机也可以被动脚以收集个人信息，从而获取资金。

人们在在线购物或输入信用卡详情时对这种风险的认识日益增强，因此已经采取了各种措施，包括使用密码和回答安全问题。航空业是另一个计算机安全至关重要的领域，因为安全漏洞的后果可能从泄露机密到昂贵设备和人类生命的损失不等。

航空业可能受到计算机安全攻击的原因有许多，这取决于犯罪的动机。这些动机包括军事航空业中的破坏活动和间谍活动，以及商业航空业中的工业竞争和恐怖主义。交通管制是航空业最脆弱的系统之一，因为任何攻击都可能难以追源，而且相对简单，因为只需要在无线电中发送伪造的消息即可。

有人寻求利用计算机漏洞（无论是出于追求刺激、为了发表政治/社会表态还是为了财务利益），当然，在另一端也有致力于维护计算机安全以应对此类威胁的人。因此，拥有技术知识并能够黑入计算机系统的人可以参与到非法且不符合道德的黑客行为（又被称为破解/cracking），或者通过识别威胁、改进安全措施以及提醒公司系统中的漏洞来服务另一方。

对于旨在保护计算机安全的目标，有各种针对黑客攻击的反制措施，借此可以减少或消除遭受安全漏洞的风险。这些预防措施在成本和复杂性上各异，包括：

- 入侵检测系统（检测威胁并在事件后分析攻击）
- 使用账户控制（密码和数据加密）
- 安装防火墙（提供对某些形式攻击的硬件和软件包过滤）

防止计算机系统受攻击而破解的预防措施包括采取步骤防止攻击、确保任何潜在攻击都能检测到，以及响应攻击以防止进一步的损害。

然而，尽管有一系列防御措施，计算机系统仍然容易受到攻击，计算机安全被破坏的情况也并不罕见。尝试违反安全措施之所以仍然发生，首要原因是警察通常不熟悉计算机技术，因此既没有技能也没有动力解决犯罪并抓捕负责的犯罪分子。

# 第4章 – 黑客技术

黑客可以使用各种技术来获取计算机系统的未授权访问，以制造混乱、盗取金钱或数据，或阻止系统按预期运行。攻击连接到互联网的系统的三个主要方法是：网络枚举、漏洞分析和利用。

网络枚举器是一种用于从网络计算机中发现用户名和其他信息的程序。该程序发现计算机网络安全中的任何弱点，并将结果报告给黑客，黑客可能会利用这些信息访问网络并造成破坏。

另一方面，伦理黑客可以使用同样的过程来发现其系统中的任何弱点，以加固安全。使用的另一种方法是漏洞分析，它识别系统中的任何漏洞点；这些信息可以被用于攻击系统，也可以用于消除弱点。漏洞分析可以导致利用，即黑客利用漏洞信息突破计算机或系统的安全性。

有很多可以使用的特定技术，但它们都采用了上述描述的主要概念和方法。黑客技术最具体的例子是漏洞扫描器，这是一种用于检查网络是否易受攻击的程序。也可以使用端口扫描器，它可以识别访问计算机的途径，并确定如何绕过防火墙。

除了这些机械设备外，黑客还可以发现这些漏洞它们本身，这可以通过手动搜索计算机代码并测试其是否正确来完成。暴力攻击是黑客获取未经授权访问计算机网络的另一种方法，涉及到猜测密码。密码破解是另一种利用密码的黑客技术，但黑客并不是在猜测密码，而是恢复存储在计算机中或传输的密码信息。

## 互联网局域网

欺骗攻击（又称为钓鱼攻击）是一种伪装成受信任实体的恶意程序、系统或网站。通过伪造数据，黑客能够伪装成受信任的系统，从而欺骗程序或用户披露密码或银行详情等机信息。另一种常用的黑客技术是采用专家级使用的难以检测的方法。

根工具包（root kit）是一种能够成功接管操作系统控制权的难以检测的程序。

特洛马是另一种技术，它是一种能够成功欺骗系统和用户的程序；它的工作方式表面上在做某事，实际上却在做另一件事。通过这种方法，黑客能够获得对系统的未经授权访问，并创建一个访问点，以便他们以后可以通过该建立的路线重新进入。计算机病毒是最广为人知的黑客形式，因为它是大多数公众意识到的计算机威胁。

病毒通过自我复制并将自己植入计算机代码和程序来工作；某些计算机病毒是恶意的，而有些仅仅是烦人的或无害的。计算机虫与病毒相似之处在于它也能自我复制，但它能够在用户无意允许的情况下进入计算机程序，且不需要将其插入到现有的程序中。

最后，键盘记录器（keylogger）是一种记录给定机器上每次击键的工具，黑客随后可以访问并查看。这通常是为了让黑客获取受害者输入的机密信息。事实上，这种技术也有合法用途，例如某些公司使用键盘记录器来检测员工实施的任何不实或欺诈行为。

计算机黑客的一个很大领域涉及社会工程学，为了绕过信息安全，人会被操纵以披露机密信息或授予安全网络的访问权限。这种技术（包括钓鱼攻击）通常只是更广泛计划中复杂流程的一部分，但它也是危险的步骤，因为人类比机器更容易被有说服力的骗子所说服。



# 社会工程学与黑客技术概述

## 社会工程学：心理层面的漏洞

社会工程学依赖于决策的心理行为，可以被认为是计算机安全系统中最重大的漏洞之一。社会工程学有许多不同的应用方式来获取对计算机系统的未经授权访问，包括犯罪分子伪装成技术人员，假装正在修理电脑而实际上在偷取数据。

另一个例子是骗子告诉公司帮助热线的号码已更改，因此当员工拨打该号码时，他们会乐意披露自己的账户详情，认为他们正在与可以信任信息的人交谈。这类场景属于“预设方案”（pretexting）类别，因为编造一个可信的场景让犯罪分子能够获取所需的信息，从而导致受害者披露信息。

黑客参与社会工程学的其他专业人员还可以伪装成警察或银行经理，因为我们认为这些人员有权获得他们所请求的任何信息。诱饵（Baiting）是社会工程学的一个子分支，因为它依赖心理学来运作。诱饵是指在使用受感染设备或 USB 盘时，受害者的计算机安全受到破坏的情况。

诱饵的一个例子是犯罪分子通过一个带有诱人标签的 USB 盘投到某人的门口，只需等待好奇的受害者将其插入笔记本电脑，此时恶意软件将自动安装并感染他们的计算机。这种技术利用了人类大多数对好奇和贪婪的倾向，因为如果标签承诺有色情图片、金钱或八卦，受害者可能会发现很难抵抗查看。

凯文·米特尼克（Kevin Mitnik）曾是一个计算机罪犯，后成为一名安全顾问，他指出，欺骗一个人披露机密信息比利用运气、暴力破解或技术知识破解系统要容易且快速得多得多。克里斯托弗·哈德纳纳基（Christopher Hadnagy）写了一本名为《社会工程学：人类黑客的艺术》的书，强调了人类是任何计算机系统中最脆弱的部分。

## 结论

本书提供了有关黑客攻击的一些关键概念的概述。我们考虑了黑客技术的起源以及它如何受到赛博朋克文学传统的影响。有趣的是，曾经在科幻小说中被描绘为乌托邦社会中想象的活动已经变成现实，并对计算机安全构成了重大威胁，成为信息技术专家关注的焦点。

在这里我们看到了黑客技术的真正起源，曾经的虚构理论概念已成为现实，并对数字文化产生了重大影响。接下来我们查看了不同类型的黑客，并注意了道德黑客（合法执行黑客攻击以提高计算机安全的人，又被称为白帽黑客）与不道德黑客（非法使用其技能制造破坏、中断服务和窃取信息的黑客，又被称为黑帽黑客）之间的区别。

有趣的是，技术技能可以根据动机有不同的使用方式，而且黑客社区并没有被一个清晰一致的意识形态所统一。随后，我们研究了计算机安全，以便更好地理解黑客发生的条件。通过学习计算机安全，可以理解反对安全措施的黑客所面临的挑战，以及寻求维护计算机系统安全的人士所面临的挑战。

任何对黑客攻击的介绍如果没有对计算机安全的检查都是完整的，因为维护计算机安全的价值是道德黑客的动力，也是不道德黑客所反对的。最后，我们查看了可以利用的不同黑客技术，包括发现和利用计算机系统漏洞的自动化软件，以及通过试错发现密码等突破安全措施的人工方法。

在本章中，我们还考虑了黑客攻击的一个巨大领域社会工程学，黑客可以通过非法获取所需信息来访问安全网络。在当今的数字文化中，我们所做的一切都越来越依赖技术。

随着技术的进步，我们的生活在许多方面变得更加简单，但随着这个蓬勃发展的行业，也产生了新类型的犯罪分子。现在的犯罪分子甚至不需要出门就能偷钱，只需通过黑入受害者的计算机并访问机密数据即可。

然而，黑客攻击并不总是非法的，这本书还研究了对计算机专家成为道德黑客的需求日益增长，以进一步促进和保护计算机安全。
