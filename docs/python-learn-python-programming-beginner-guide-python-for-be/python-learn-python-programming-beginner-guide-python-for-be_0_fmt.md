## 什么是 Python？

Python 是最适合初学者的编程语言。它是一种解释型的、高级的、交互式的且面向对象的脚本语言。它的设计旨在具有高度的可读性。它使用的英语关键字比任何其他编程语言都多，因此很容易学习和理解。

### 作为解释型语言的 Python

Python 是一种解释型语言。它不使用编译器；解释器逐行检查代码并创建字节码。字节码是一种中间“语言”，它既不是机器码，也不是源代码。由于这种中间状态，字节码在操作系统之间比机器码更具迁移性；这有助于 Python 实现跨平台运行。

Java 是另一种也使用字节码的语言。然而，由于 Python 使用解释器而不是编译器，代码处理速度可能会慢一些。字节码仍然需要被处理器“解码”后才能使用，这需要额外的时间。但这样做的好处是程序员可以立即看到其代码的结果。他不需要等待编译器来判断某处是否存在导致程序崩溃的语法错误。

由于解释特性，Python 和类似的语言用于快速应用程序开发和程序原型设计。例如，可以在几小时内创建一个简单的程序，并在同一次访问期间展示给客户。程序员可以反复修改程序并快速查看结果。这允许他们尝试不同的想法，并查看哪种是最好的，而不必在死胡同上花费大量时间。

这也适用于创建图形用户界面（GUI）。在几分钟内就可以布局出简单的“草图”，因为 Python 不仅有多种不同的 GUI 库可用，默认还包含了一个简单的库（`Tkinter`）。

### 作为面向对象编程（OOP）的 Python

Python 支持面向对象的编程风格，将代码封装在对象之中。Python 与其他语言不同之处在于，在开发程序时你有两个选择：过程化编程或面向对象。你可以在同一个程序中混合使用两者。

过程化编程是开发程序的逐步过程。函数在需要时由程序调用以执行某些处理，然后将控制权返回给主程序。C 和 BASIC 是过程化语言。

面向对象编程（OOP）意味着使用对象进行编程。对象由不同的编程逻辑单元创建；变量和方法组合成执行特定任务的对象。例如，如果你构建了一个机器人模型，身体的每个部分都是一个分离的对象，能够执行不同的事情，但仍然是对象的一部分。OOP 也广泛用于 GUI 开发。

### 作为初学者语言的 Python

Python 提供了广泛的应用，从简单的文本处理到 WWW 浏览器以及游戏。对于初学者级程序员来说，这是一门很好的语言。

## Python 入门

Python 被认为是解释型语言，因为 Python 程序是由解释器执行的。使用解释器有两种方法：交互式模式和脚本模式。在交互式模式下，你输入 Python 程序，解释器显示结果：

```python
1+1
2
```

大于符号 `>>>` 是解释器用于指示它已就绪的提示符。如果你输入 `1+1`，解释器回复 `2`。或者，你可以将代码存储在文件中并使用解释器执行文件内容，这被称为脚本。惯例上，Python 脚本的文件以 `.py` 扩展名结尾。

要执行脚本，你必须告诉解释器文件名。如果你有一个名为 `mywork.py` 的脚本并且在 UNIX 命令行窗口中工作，你输入 `python mywork.py`。在其他开发环境中，执行脚本的细节不同。你可以在 Python 网站 `http://python.org/` 找到你环境的说明。

程序是代码行或指令的组合，规定了如何执行计算。计算可以是数学上的，例如求解方程或寻找多项式的根，但也可以是符号计算，例如在文档中搜索和替换文本或编译程序。

每种语言中都包含一些指令：

- **输入**：通过键盘或其他输入设备从用户获取数据。
- **输出**：在屏幕或其他输出设备上显示数据。
- **数学**：执行基础数学运算。
- **条件执行**：检查某些条件并执行相应的代码。
- **重复**：反复执行某些操作，通常伴随着某种变化。

## 什么是调试？

编程错误被称为 bug（错误），追踪这些错误的过程被称为调试（debugging）。

编程中有三种类型的错误：

### 语法错误

只有在语法错误正确的情况下，Python 才能执行程序；否则解释器会显示错误信息。语法是关于结构的规则。例如，括号必须成对出现，所以 `(1+3)` 是合法的，但 `3)` 就是语法错误。

在编程的最初几周里，你可能会花费大量时间追踪语法错误。随着经验的增加，你犯的错误会越来越少，并且能更快地找到它们。

### 运行时错误

第二种错误是运行时错误，之所以这么命名是因为错误在程序开始运行后才会出现。这些错误也被称为异常（exceptions），因为它们通常表示发生了某些异常（且糟糕）的情况。

### 逻辑错误

第三种是逻辑错误。如果你的程序中存在逻辑错误，它会成功运行，即计算机不会生成任何错误信息，但它不会做正确的事；它会执行我们没有预料到的事情。具体来说，它会执行你告诉它做的事。它的发生由于程序逻辑编写有误。

## 第一个程序

在所有新语言中，第一个程序被称为“Hello World”，因为它们做的只是显示“Hello World”这两个单词。

在 Python 中：

```python
print 'Hello World'
```

这是 `print` 的一个简单示例，它实际上并没有在纸上打印任何东西。它在屏幕上显示一个值。在这种情况下，结果是 Hello World 单词。程序中的引号标记了要显示的文本的开始和结束；它们不会出现在结果中。

在 Python 3 中，打印的语法略有不同：

```python
print('Hello, World!')
```

括号表示 `print` 是一个函数。如果你使用的是 Python 3，则必须进行这种转换。除此之外，我们需要担心的差异很少。

## 变量命名规则

我们创建变量名遵循以下规则：

- 它不能是关键字。
- 除了下划线（`_`）之外没有特殊字符。
- 变量名内部不允许有空格或空白。
- 第一个字符必须是字母。
- 它可以包含字母和数字。
- 永远不要重复使用相同的名称。
- 可以是大写，但变量名以小写字母开头是个好主意。

优秀的程序员会为他们的变量选择有意义的名称，并在程序中使用它们。

如果你提供一个非法名称，你将得到语法错误。

```python
20level = 'Final round'
SyntaxError: invalid syntax

good@ = 1000000
SyntaxError: invalid syntax

class = 'look good'
SyntaxError: invalid syntax
```

`20level` 是非法的，因为它不是以字母开头。`good@` 是非法的，因为它包含非法字符 `@`。但 `class` 有什么问题呢？事实证明 `class` 是 Python 的关键字之一。解释器使用关键字来识别程序的结构，它们不能用作变量名。

如下例所示：


在 Python 中，没有必要声明。在其他语言中，你必须先声明再初始化，这两个步骤在同一行代码中完成。例如在 C++ 中：

```cpp
int a = 3; // 整数的内联初始化
float b;
b = 4.0 f ; // 浮点数的顺序初始化
```

在这里你可以看到，先声明它是浮点数还是整数是至关重要的。

但在 Python 中这不是必须的，如果你用某个值初始化变量，它就会存储在那种类型中。正如在这个示例中：

```python
a = 3 # integer
b = 4.0 # floating point
```

如你所见，`a` 和 `b` 都是数字，但 Python 可以在不告知的情况下判断出它们是什么类型。在 C++ 示例中，一个浮点值必须被“声明”两次；首先给变量赋予类型（`float`），然后将实际值赋给变量。你还会注意到 Python 中的注释是用井号或磅符号（`#`）隔开，其用法与 C++ 或 Java 中的 `//` 注释完全一样。Python 中的数字就是这些了。

在 Python 2 中，除法运算符可能不符合你的预期：

```python
minute = 59
minute/60
0
```

`minute` 的值为 59，在常规算术中 59 除以 60 等于 0.98333，而不是 0。差异的原因是 Python 正在执行整除 `//`。当两个操作数都是整数时，结果也是整数；整除会切掉小数部分，所以在这个示例中它向下取整为零。

在 Python 3 中，此除法的结果是一个浮点数。新运算符 `//` 执行整除。如果任一操作数是浮点数，Python 将执行浮点除法。结果是一个浮点数：

```python
minute // 60.0
0.98333333333
```

## 运算顺序（优先级）

当我们在一个表达式中使用多个运算符时，求值顺序取决于优先级规则。数学运算符有一套优先级顺序。从上到下的优先级顺序为：

- 括号优先级最高，可以强制表达式按照你想要的顺序进行求值。示例：`3*(5+4)`、`(2**5)+2`。第一个结果是 `27`，第二个是 `34`。
- 幂运算优先级次高。因此 `4**2+1` 是 `17` 而不是 `64`，`3*1**3` 是 `3` 而不是 `27`。
- 在指数和补运算之后，一元加和减（`+` 和 `-`）具有第三高优先级。
- 除法、乘法、取模和整除的优先级相同。因此 `2*3-1` 是 `5` 而不是 `4`，`6+4/8` 是 `8` 而不是 `5`。
- 加法和减法在除法和乘法之后优先级相同。
- `<<`、`>>` 右左移。
- `&` 按位“与”。
- `^`、`|` 按位“异或”和普通“或”。
- `<=`, `<`, `>`, `>=` 比较运算符。
- `<>`, `==`, `!=` 等等运算符。
- `=`, `%=`, `/=`, `//=`, `-=`, `+=`, `*=`, `**=` `=`
- `is`、`is not` 恒等运算符。
- `in`、`not in` 成员运算符。
- `not`、`or`、`and` 逻辑运算符。

相同优先级的运算符从左到右求值。我并不费力去记忆其他运算符的优先级规则。如果通过观察无法判断，我会使用括号让它一目了然。

# Python 中的决策制定

在日常生活中，我们经常根据条件做出决定。例如，如果我们有 $5，我们就买一个板球拍，否则不买。这个例子说明，如果第一个条件为真，我们就可以继续操作；否则我们就执行其他任务。Python 在编程中为我们提供了这种条件语句来做出决策。决策结构评估多个产生真或假结果的表达式。在 Python 编程中，零和空值（null）被视为假，其他值均为真。

在 Python 中，我们有以下类型的决策语句：

## `if` 语句

它类似于 C 语言。在 `if` 语句中，我们提供一些条件对数据进行比较并做出决策。如果满足条件，则执行语句。

### 语法

```
if (condition)
    statement
```

### 示例

```
num1 = 2
if num1:
    print "Expression is true"
    print num1

num2 = 0
if num2:
    print "Expression is False "
    print num2

print "Its Over"
```

如果布尔表达式求值为真，则执行 `if` 语句内部的语句块。如果布尔表达式求值为假，则执行 `if` 语句结束后的后续代码。`if-statement` 可以写在一行中。

### 示例

```
num = 1
if ( num== 1 ) : print "one-line if"
```

## `if-else` 语句

如果其语句的条件为假，则执行控制将跳转到 `if` 语句后的第一个语句。如果我们使用 `else` 语句，它会在 `if` 语句之后执行。`else` 语句与 `if` 语句结合使用。它是一个可选语句，大多数情况下在 `if-else` 语句块中使用一次。

### 语法

```
if (conditon):
    statement
else:
    statement
```

### 示例

```
num1 = 0
if num1:
    print "Expression is true"
else:
    print "Expression is false"
```

## `elif` 语句

如果我们想检查多个表达式是否为真，并在其中一个条件求值为真时立即执行语句块，我们有 `elif` 语句来执行此类任务。

它像 `else` 语句一样是可选的。我们在块中通常使用一个 `else` 语句，但可以有很多 `elif` 语句。

### 语法

```
if (condition1):
    statement
elif(condition2):
    statement
elif(condition3):
    statement
else:
    statement
```

它类似于其他语言中的 `switch case` 语句。

### 示例

```
num = 1
if num == 2:
    print "True Expression 1"
elif num == 3:
    print "True Expression 2"
elif num == 1:
    print "True Expression 3"
elif num == 1:
    print "True Expression 4"
else:
    print "No one match!"
```

如果没有一个可以匹配真表达式，则将打印 `else` 语句。

# 循环

当我们需要多次执行某块代码时，我们在 Python 中使用循环。在编程语言中，有各种控制结构允许更复杂的路径。

简单的循环语句允许我们多次执行某块代码。

为了处理循环需求，Python 提供了以下几种类型的循环：

## `While` 循环

如果给定的条件为真，`while` 循环会重复执行语句，直到它变为假。

### 语法

```
while (condition):
    statement
    increment\decrement
```

首先，我们在 `while` 循环上方声明一个变量。然后在括号中给出条件。在条件中我们可能使用关系运算符。然后我们编写循环语句，如果语句为真，循环就会反复执行，直到为假为止。语句可以是单行的，也可以是语句块。在语句之后，我们在循环的末尾提到递增或递减。如果循环第一次执行，第二次执行将带有该递增或递减进行。这个过程一直持续到条件变为假为止。

### 示例

```
value = 0
while (value <5):
    print 'The value is:', value
    value= value +1
print "Its Over"
```

此块仅包含打印和递增语句，它在每个循环周期后将值增加 1。当值增加 4 时，条件变为假，它停止工作。

### 在 `While` 循环中使用 `else` 语句

Python 支持与 `While` 循环语句关联的 `else` 语句。如果在 `while` 循环中使用 `else` 语句，则在条件变为假时执行 `else` 语句。

`For` 循环具有遍历任何序列项的能力，例如列表或字符串。表达式列表首先被评估，如果序列包含其中任何一个项。然后序列中的第一个项被赋值给该变量。

### 语法

```
for iterating_var in sequence:
    statement
```

### 示例

```

    print letter
```

### 在 `for` 中使用 `else` 语句

在 Python 中我们可以使用 `else` 语句。当循环耗尽时，会执行 `else` 语句。

## 字典

字典是 Python 中最有用的数据类型之一。字典类似于列表，但它具有更通用的属性。在列表中，索引必须是整数，但在字典中，它们可以是几乎任何类型。它们是对象的无序集合，与关键字匹配。相比之下，列表是使用数值偏移的有序集合。

Python 字典提供了索引集合（即键 keys）和值集合之间的映射。每个键都映射到一个值。键和值之间的关系被称为键值对，有时也称为一个项（item）。

## 字典的基本属性

- 它不是偏移量，可以通过关键字轻松访问。它的执行方式与关联数组相同。字典中的所有项都有其自己的关键字；关键字用于调用该项。
- 为了提供更快的查找，存储的对象是随机顺序排列的。在创建时，字典以它选择的任何顺序存储项。使用键即可获取项。字典中没有内置方法对项排序，如果你需要排序，请自行处理。
- 字典是变长的，可以包含任何类型的对象，并支持深度嵌套。
- 它们不能像列表或字符串那样被修改，但它们是可变的（mutable）。
- 它们是唯一支持映射的数据类型。
- 在内部，字典实现为哈希表。
