在阅读本书的过程中，你会发现它分为两个主要部分：学习编码的技巧妙招，以及将所学的编码知识应用于实际编写 `JavaScript` 的技巧妙招。通过这样划分，你能够学习更多并开始更高效地编码。在书的最后三章中，你将学习已经设计并准备好供你使用的编码技巧、快捷方式和模板。确保你知道在哪里找到这些内容以供参考，之后考虑使用我们在上一本书中提到过的笔记本或文档，这样你就始终知道信息在哪里。

### 你的路线图

如果你想去一个你从未去过的地方，你必须使用路线图才能到达。实际上，你可能会使用安装在手机和汽车上的 GPS，但 GPS 是路线图的替代品，如果没有路线图，它们是不可能的。为了到达你想攻克的 `JavaScript` 目标，你需要使用路线图。这并不意味着你要旅行或必须去某个特定的地方，它意味着你需要找到学习 `JavaScript` 的最佳行动方案。

如果你想学习 `JavaScript` 以编写网站甚至成为前端开发人员，在进入 `JavaScript` 部分之前，你需要经过几个步骤。如果你只是想学习它来完成这些工作或教别人如何做，请考虑简单接触路线图中包含的每个步骤。

你至少需要学习基础的 `HTML`。你不需要成为专家，如果你以后要写 `JavaScript`，也不需要只用 `HTML`，但学习它是有帮助的，这样你可以利用所学的 `JavaScript` 和 `HTML` 结合创建一个整个网页。了解这些将为你的网站提供所需的基础，并在进行你网站的 `JavaScript` 部分时，帮助你做出一些更大、更重要的决策。

在学习 `HTML` 之后，你还需要学习一些关于 `CSS` 的知识。这是大多数网站使用的语言，学习这两者可以确保你以正确的方式编码并使用所学的 `JavaScript`。`CSS` 比 `HTML` 和 `JavaScript` 都复杂得多，所以你可能只想了解它的表面。如果你计划成为开发者，你最终需要学习 `CSS` 的所有方面，但如果你只是为了给 `JavaScript` 做准备，就不太需要深入。

在学习了这些语言后，你可以创建一个功能完整的网站。你只需要使用它们即可。不过，你也可以在其中添加一些 `JavaScript`。这正是你学习 `HTML` 和 `CSS` 的原因，不是吗？你的 `JavaScript` 将与你所学的 `HTML` 和 `CSS` 代码完美融合。确保在遇到问题时，检查你的 `JavaScript`、`HTML` 和 `CSS` 是否有错误。

每个人的路线图都不同。你应该确保为你自己创建的路线图是量身定制的。例如，你可能不需要担心 `HTML` 或 `CSS`，因为那是你已经熟悉的内容。你可能不需要了解由于你编写代码可能带来的其他事情，因为你是 `Jquery` 专家。编写代码和开发网站有许多方面，找出哪些适合你，并在开始编写代码时将其付诸实践。

### 高效练习

当你决定学习 `JavaScript` 时，你可能对它非常兴奋，迫不及待要开始编写自己的代码并创建网站。随着时间的推移，这种兴奋可能会消退，特别是当你发现学习编写 `JavaScript` 需要大量的练习和许多步骤时。这可能会令人沮丧，但有些方法可以让练习再次变得有趣。这些只是你在练习 `JavaScript` 时可以使用的一些简单心理技巧。（额外奖励：当你在练习任何你想学的内容时，都可以使用这些技巧）。

不要走捷径。

直接丢进预写好的代码看起来可能很容易，但如果你决定这样做，你只会是在自讨苦吃。这是因为你需要确保自己确实是在学习，而不仅仅是在使用别人已经写好的代码。如果你走捷径或尝试作弊，你将花费更长的时间才能学会你通过 `JavaScript` 所需的知识。这样做可能会带来很多问题，而且你将无法尽可能地学习。

如果你在寻找动力练习 `JavaScript` 方面遇到困难，你只需要做的就是改变心态。想象一下你刚刚学了一些 `JavaScript`，但你无法练习它或将其投入使用。你可能很想能够使用它，对吧？保持这种心态。如果你只是想象自己无法练习它，你会比自己完全有能力随时练习它时更想去练习它。

你可以使用的另一个心理技巧是尝试记住你第一次学习 `JavaScript` 时的感受。你当时充满热情，想要一直做下去。把你的思绪回到那个时刻，为此感到兴奋。即使你必须再次假装自己很兴奋，也要假装直到你真正感到兴奋为止。这将给你一个机会，让你再次像一个拥有新玩具的孩子——渴望并准备好玩你所学的 `JavaScript`。

执行这些每一个心理技巧并不能保证你有更多时间练习，或能让你更高效地练习，但它们将帮助你进入练习 `JavaScript` 的正确心态。如果你处于正确的心态，你更有可能在实际练习以及在学习过程中尝试编写的 `JavaScript` 代码时获得成功。

## 第 2 章：Facebook 与通俗语言

现在你已经处于可以练习的正确心态了，你需要真正开始练习了。即使你对这个过程充满热情，开始和寻找动力可能是最困难的部分之一。确保你在心理上为练习做好准备，然后开始使用这些技巧来完成练习。

本章的第一部分将告诉你如何开始练习，以及你练习和学习你想要通过代码实现的目标时的最简单方法。

### Facebook

当你有空闲，想什么都不做时，你很可能是在看手机浏览 `Facebook` 或你其他喜欢的社交媒体。回想一下你开始浏览的时候。你是怎么做的？你是特意说自己要坐在沙发上看几个小时 `Facebook` 并不断刷新吗？还是，你坐下来心里想，你只想看看某某人在做什么？如果是后者，请举手。现在，放下手，你看起来很傻，但事实是，大多数人并没有特意坐下来浪费 4 或 5 小时去浏览 `Facebook`，但大多数人都这样做过。

如果你上 `Facebook` 只是快速看一眼，很容易陷入不断刷新并获取所有朋友最新消息的螺旋中。如果你正试图完成某些任务，这种螺旋可能是危险的。`Facebook` 是对生产力最不利的事情之一，但有一种方法可以让你化腐为神奇。你可以利用 `Facebook` 螺旋帮助自己开始练习 `JavaScript`。

坐下来告诉自己，你只写一段代码或看一眼与你的 `JavaScript` 练习相关的一件事。开始做那件事吧。你可能会被其他代码分散注意力，并在完成你打算坐下来做的那“仅仅一件”后开始做另一项工作。你现在已经进入了螺旋，可以一次持续工作几个小时，而完全不用考虑它。你通过只完成一个小任务就欺骗了自己去练习 `JavaScript`。

显然，这并不会每次都有效。你做得越频繁，不起作用的可能性就越高，所以确保只有在你真的无法找到动力开始进行 `JavaScript` 练习时才这样做。你不会每次都陷入螺旋，但不要失望。这只意味着你那时真的并不适合开始练习。休息一下，稍后再回来练习，以确保你确实处于开始练习的正确心态状态。

通过使用 `Facebook` 螺旋，你为自己提供了又一种练习方式。你可能会发现，一旦你这样做了，你就会不断回来。你可以陷入练习 `JavaScript` 的螺旋中，这并不是坏事。这正是你所希望的。你总是渴望练习，并在编写 `JavaScript` 代码的过程中随着所学的内容不断进步。确保你已为这种情况发生做好准备，并设定好可以练习的时间。

在刚开始阶段，从日程表中抽出时间可能不是最好的做法，所以确保不要这样做。如果你为它留了时间，你最终可能在那个时间没有练习，从而浪费了那段时间。你只有在进入螺旋并且知道自己喜欢练习后才应该这样做。你执行它的时间应该是一个干扰极少且你可以清晰思考的时间段。

当你开始编写代码和学习 `JavaScript` 时，你可能不知道你的社交媒体习惯能够帮助你学习更多，但你始终可以利用它的优势。一个可以迅速变成益处的事情是减少你在社交媒体上的时间。几乎每个人都需要减少使用 `Facebook` 或 `Instagram` 的时间，而在那个时间保持高效是一个好主意。如果你处于练习螺旋中，你会花更少的时间浏览 `Facebook`，花更多的时间编写对以后有益的优秀代码。

### 通俗语言

当你和朋友交谈时，想要清晰地表达词汇，你不会在开始热情地说话之前停顿，对吧？你在编写代码时也不应该这样做。你应该确保从通俗语言开始，然后利用你对 `JavaScript` 的知识以正确的方式进行编码。

这种想法的一种很好的方法是草稿。中学生和大学生非常熟悉草稿。当他们开始写论文时，被要求写下他们能想到的所有内容。在写草稿时，他们不需要担心句子结构、语法或任何其他事情。他们需要把观点传达并写下他们的想法。

如果你开始编写代码，请从草稿开始。使用 `Notepad` 或你在准备学习 `JavaScript` 时可能下载的其他软件。这将给你一个机会，真正将你所有的想法和你想做的事情都呈现在“纸”上。它还将告诉你，在你开始编写已经安排的代码时，需要做哪些改进。

虽然你可能不会写一篇 10 页的论文来讨论乔治·华盛顿为什么有木牙齿（就像你在高中或大学课程中可能会写的那样），但你仍然会写你想做的事情。先从写下网页将是什么内容、它将包含什么、它长什么样以及具体的细节开始。这将让你有机会写下你对该网页的所有想法。

一旦你写下了所有这些信息，就可以开始编写关于页面内容的信息。它是一个博客页面吗？一个问答区？一个测试网站？还是向人们介绍你的页面？或者是一个导航页？所有这些都可以使用你的编程语言以及 `JavaScript` 实现，所以务必确保你知道你想写什么。在写页面外观信息的同一个地方，用通俗的语言将其写下来。

随着你编写 `JavaScript` 的经验增加，你可能会发现自己实际上正在将代码直接插入到本应该编写的纯白文中。只要代码是随你的思路流出的且不需要查阅，这样做是可以接受的。如果你发现自己停下写作来查阅代码，那么是时候回到只用通俗语言写作了，这样你就不会在准备要编写的代码草稿上浪费时间。

即使是经验丰富的开发者也会使用这个技巧，以便习惯非常复杂代码的样子。编写复杂的代码可能是困难的，所以确保你能够先用通俗的语言将它们写出来。如果你能先用通俗语言写出来，你将对自己正在做什么以及以后想用代码做什么有更好的理解。当你知道自己将编写复杂的代码时，务必确保这样做，以便在你回去检查错误之前就能消除缺陷和错误。

有许多不同的方法可以练习，但将这些每一个原则应用到实践中，将让你有机会确保在你的 `JavaScript` 学习过程中做出了所有正确的决定。务必确保尽可能多练习，并在尝试练习之前尽可能多地学习。有一句古话说“熟能生工”，这完全适用于学习 `JavaScript` 以及它能为你做到的事情。

当你练习时，务必始终记住你刚开始时想做的事情。这样做会让你保持谦逊，并为你提供持续学习更多新知识所需的动力。

## 第 3 章：慢思考，保持谦逊

编写代码可以非常快，尤其是当你清楚自己在做什么，并且对你在 `JavaScript` 字符串中编写的代码有丰富经验时。你可能会进展很快，这可能导致你犯错。如果你变得对 `JavaScript` 非常精通，并且觉得能用它做更多事情时，情况尤为如此。你可能发现，当你编写代码变得更熟练时，你对自己所做的一切都非常有信心。自信并不是坏事，但它可能会导致你忽略一些可能产生错误的地方。为了确保你在编写代码时做到最好（即使在练习时也是如此），你应该确保自己尽可能慢地思考，不要对自己的能力过度自信。

### 慢下来

当你编写脑海中的代码时，确保你尽可能慢。起初这可能花费更多时间，但在回去处理你可能犯的错误以及需要做的不同工作时，这将为你节省大量时间。通过慢下来，你产生错误的概率会更小。

即使在你回看代码并逐行检查每一行 `JavaScript` 时，也要缓慢地观察。阅读每一个字母和符号，这样你就会知道自己在看什么，并能够看到是否漏掉了任何内容。这就像你在高中或大学写论文时可能进行的校对一样。慢下来，逐行校对你写出的作品和编写的代码。这种缓慢的节奏将帮助你发现你可能犯的任何错误。

值得注意的是，慢下来将帮助你避免工作中的任何重大错误。如果你以较慢的速度移动，你会对每一次击键和放入每行代码中的每件事都更加敏感。缓慢的节奏不仅在你回看所写的内容时提供帮助，也能帮助你编写时的状态。确保你已准备好尽可能慢，不要匆忙完成你的工作。

### 休息一下

从你正在做的工作中休息一下总是有益的。在连续看了几小时代码后，你的眼睛不仅会疲劳，大脑也会开始感到疲倦。休息将帮助你刷新正在做的事情，并让你有机会带着大脑中的空白重新开始。在编写代码时，清醒的大脑有很多好处，而休息将为你提供完美的恢复。

通常情况下，每工作代码一小时，你应该花 5-10 分钟移开眼睛，站起来走走，做一些与 `JavaScript` 无关的事情。出去呼吸新鲜空气或简单地走动一下是个好主意。这两项活动都有助于血液循环，并为大脑提供氧气，帮助在你决定坐下重新工作时高效运行。

提醒：在离开电脑屏幕休息期间，尽量不要玩手机。虽然手机屏幕要小得多，但它发出的蓝光与电脑屏幕发出的光一样有害。在工作时留出特定时间使用手机，这样你就不必浪费休息时间和朋友聊天或检查非业务邮件。休息时将手机放在手不到的地方是个好主意。

### 逐步执行

一旦你写好了你想写的代码，你需要确保你正在逐步执行它。执行的速度要像你编写过程一样慢，这样你就能发现你犯的任何错误。你应该在写完最后一行代码之后、在通过不同的测试进行检查之前这样做。确保你缓慢地查看每一行代码总是一个好主意。

一种确保你查看了所写代码的每一个字符的方法是大声读出来。对自己读出每一个字母、数字和字符，这样你就能确保它们的写法是正确的。大声读出来总是一个好主意，因为读出来会展示你实际写了什么。大声读出来比在脑子里读花费更多时间。如果你在脑子里读，可能会遗漏很多东西。

虽然大声朗读你编写的每一行代码看起来可能很复杂，但你仍然应该尝试这样做。这样做将让你有机会发现你可能遗漏掉的内容。如果你擅长阅读并确保自己没有犯任何错误，你就能非常高效地完成任务，而不会浪费大量时间。实际上，这花费的时间比回去修复你所有的错误要短得多。

### 调整信心

虽然在你刚开始或学习代码时可能不会遇到这个问题，但对于那些编写 `JavaScript` 的人来说，过度自信可能是一个大问题。你认为自己对它已经有了充分的了解，本质上，你在编写代码时放松了警备。这是一个问题，因为你在编写代码时发现错误的速度将不再那么快，而且你可能会认为你写的代码没有任何问题。

保持清醒至关重要。即使你觉得自己写代码非常出色，并且永远不会犯错，你犯错的概率仍然很高。在任何时候编写任何类型的代码时，错误都可能发生在任何人身上。确保你清楚自己在做什么，不要对自己的技能自目自大。在编码方面，总有更多可以学习的东西，没有人能掌握一切。

你的自信甚至会误导你忘记已经学过的代码知识。自信告诉你你清楚自己在做什么，并且知道编写代码的最佳方法。它告诉你，对每一行代码反复编写相同的内容没有问题，但它也告诉你，你不需要为你编写的代码尝试不同的方案来变得更加努力。确保你对自己充满信心，但不要让这种信心高到以至于阻碍了你对成功的观察。

### 怀疑你自己

不要相信你自己。当你回看自己编写的代码时，你的大脑会试图告诉你你没有犯错，也没有遗漏任何内容，但事实可能是你实际上遗漏了某些代码行，并且犯了一些错误。务必始终质疑自己是否在完成尽可能最好的编码工作，这样你就能写出你期望的精确代码。不要相信自己能做到，而要始终检查你做的是否正确。

这样做的一种好方法是在编写和检查代码之间休息一下。确保休息时间足够长，让你能够真正刷新大脑。把它当作其中一次放松休息，但要花更长的时间，这样当你开始测试和查看代码时，你才能真正以清空大脑的状态回来。如果你盯着同样的 100 行代码看了 5 小时然后尝试编辑它们，你将很难挑出自己犯的错误。

本书第一部分章节中的所有技巧都涉及实践以及在实践过程中你可以学到的东西。它们本质上是你可以用来让编码实践进行得更好的心理技巧。在书的其余部分中，你将学习在开始编码时如何应用这些每一种技巧。真正的乐趣出现在你在本书的第二部分学习可以直接在这里使用的最佳代码时。

## 第 4 章：基础

在能够真正参与 `JavaScript` 最高级的部分之前，你必须先学习 `JavaScript` 的基础。学习基础是非常重要的，这样当你开始更多地使用它时，你将拥有坚实的基础。学习这些基础技巧并加入你的 `JavaScript` 技能库中，将帮助你获得最大的机会在 `JavaScript` 上成功，并以一种你可以真正创建出优秀网站和网站选项的方式编写代码。

### 变量列表

在编写 `JavaScript` 代码时，你很可能在某时刻列出变量。学习 `JavaScript` 后，将每个变量都列在变量标签下似乎是个好主意，例如：

```
var one thing = ‘a list’;
var differentthing = ‘different list’;
var otherdifferentthing = ‘other different list’;
```

这里的每一行都是不同的代码，并且它们是相互分离的。与其这样做，你可以通过以下方式让你的代码看起来更好、更整洁：

```
var onething = ‘a list’,
var differentthing = ‘different list’,
var other differentthing = ‘other different list’;
```

注意，在上面的每一个变量后面都有一个分号。在底部的，第二个和第三个变量之前有缩进。这表示有一个新变量。第一个和第二个变量之后也有逗号，表示它仍然是一个列表，但也表示它们必须被分开。分号只在每个列出的项的末尾使用，而不是在每个变量之间。

这是一个好主意，并不是因为它比通常的分号能让页面运行更快，而是因为它让代码看起来更漂亮。当你查看它时，它更容易阅读，如果你需要回来编辑它以进行更改，这对你来说会容易得多。你不需要在这一行一行的变量中筛选，因为它们都在同一个地方。

### 分号的困境



在现代浏览器中，`JavaScript`并不一定需要在文本字符串之间有分号，因为浏览器可以直接识别一串文本。这样做的问题在于，它们并不是万无一失的，浏览器经常会识别错误的字符串。这可能会破坏整个代码，无论你是开发者、老师还是仅仅是制作自己页面的人，都会让你看起来很糟糕。无论你做什么，不要创建这样的字符串：

```
var youritem = “this string
function doit () {
  return ‘it’
}
```

这里没有分号，你无法发现其中的错误，因为没有分号。无法识别字符串的系统会让你的网页看起来像崩溃了一样，这会让你看起来很糟糕。始终使用分号分隔是一个好主意，例如：

```
var youritem = ‘this string’ ;
function doit () {
  return ‘it’ ;
```

分号是字符串的开始和结束。它告诉浏览器在何处停止读取。通过确保放置了分号，你就能告诉它哪里需要停止。

如果你正在使用某些测试软件甚至允许编写纯文本的软件，你应该更改设置。你可以选择一种允许程序确保字符串前后不再有分号的设置。系统可以识别分号所在的位置，并告诉你你需要更改字符串并添加分号。

## 制作笔记

如果你读过该系列中任何之前的作品或之前的书籍，你将知道，将你创建的各种代码及其功能记录在编码时参考的文档中是非常重要的，但在代码中写下同样重要。这样做将让你有机会轻松地浏览你的代码，以便你找到你做了什么以及它产生了什么。如果你需要修复特定的问题，比如网站的计时方式，你始终可以回去找到你对此做过注释的代码。

要写注释，你唯一需要做的是在注释前写两个反斜杠，并在结尾写一个句号。你的注释看起来应该是这样：

```
//开启计时器，以跟踪网站加载需要多长时间。
```

```javascript
function time tracker ()
```

不要使用列在注释后面的函数。它仅仅是一行代码的片段，如果你尝试实际寻找一个可以跟踪网站加载耗时的计时器，它将无法运行。显示它仅仅是为了参考，说明你的注释应该放置的位置。

你可以在你写的每一行代码上使用注释功能。虽然在你只写几行代码时，在开头这样做似乎是多此一举，但当你编写了更多代码时，你会很幸自己这样做了，因为你将能够确保在成百上千代码的海洋中，准确地找到你正在寻找的内容。

## Firebug 计时器

在很多情况下，找出你的网页加载需要多长时间，以及还需要多长时间才能完全加载，是一个好主意。无论你是哪种类型的开发者，都可以从学习加载页面所需的时间中受益。然后你可以利用此对其进行改进。虽然这不一定是你自己编写的代码，但它是 Firebug 创建的一个模板，你可以用它来找出加载需要多长时间：

```javascript
function time tracker (){

console.time (“THE TIMER”);

for (x=5000; x > 0; x ---) {}

console.timeend (“THE TIMER”);

}
```

这段代码在你刚开始学习或者只是想找出页面加载需要多长时间时特别有用。

如果你发现页面加载需要很长时间，你有几种不同的选项可以让它运行得更快。你可以通过删掉一些不需要的内容来修改你编写的代码，使其更高效。你也可以花时间将所有内容移动到页面的底部。

### 移动到底部

当你移动到页面底部时，你的文本和内容将加载得更快。虽然你确实需要在页面顶部编写重要信息，但你可以在底部添加一些并不一定需要的内容。这将确保你能够让页面加载。

由于在所有必要信息加载到页面之前，页面无法加载，因此你仍然需要将重要部分添加到页面顶部以便它们加载。之所以在底部添加不那么重要的信息是可以的，是因为它们加载的时间较短。顶部的内容越少，当你访问时，页面加载的速度就越快。

### 消除语言标签

当第一次编写 `JavaScript` 代码时，它们其中包含了“language”标签。这是为了让浏览器能够识别代码的语言并立即获取。由于现在大多数浏览器都具有直观性，且 `JavaScript` 是人们用来编写代码最流行的选项之一，代码的语言标签已不再需要了。事实上，使用它已经过时了，实际上可能会减慢系统并让你的页面加载变慢得多。你可能在 20 年年前看到的常见代码：

```html
<script type= “text/javascript” language=”javascript”> PUT ALL OF YOUR INFORMATION HERE</script>
```

由于语言标签是多余的，你只需要放：

```html
<script type= “text/javascript” PUT ALL OF YOUR INFORMATION HERE</script>
```

这消除了语言标签，让你列表中的代码行数更少，并且实际上可以提高你网页的加载速度。移除语言标签不仅能让你更容易找到所需的信息，还能让你在人们访问时有机会拥有一个更快速的网页。

仅凭一些 `JavaScript` 基础知识你就可以做很多事情。这是你入门和练习的一种极方法，但使用其中的一些简单技巧将让你有机会利用现有的工具做更多事情。在你刚开始时，尝试本节包含的一些技巧，这样当你需要转向针对你的 `JavaScript` 代码的更大、更复杂的技巧时，就不必担心该做什么了。

# 第 5 章：酷炫的 JavaScript 技巧

## 检查 URL

被重定向到非预期的网站并不罕见。黑客、诈骗者和其他恶意人员可能试图让你访问特定的网站，出于许多原因。这可能是为了让他们能够获取你认为自己在真实网站上时在浏览器中输入的各种信息。虽然这段代码不一定能帮助到你自己的网页，但它可以防止你获得可能对计算机有害的恶意病毒。要使用此代码，你需要将其放入浏览器的控制部分。这将让你有机会查看一个网站是否是真实的网站，以及它是否与它所属的部分匹配。使用：

可以将此代码添加到你的代码行中，这样人们就能一直知道自己处于一个合法的网站上。当有人访问你的网站时，不会有任何东西出现，他们甚至不知道你已经在网站中编写了这种代码。除非你的网站被复制了副本，否则他们看不到任何内容。服务器地址和 URL 必须完全匹配，这样才能被正确地使用。你可以采取许多不同的方法来确保你的网站受到保护，但这是你能够编写的最容易的代码之一，而且你的访问者甚至不会察觉到它。

添加这段代码是一个好主意，因为这样你的访问者将始终确定他们正在访问正确的网站。如果由于某种原因出现了警告信息，你应该让访问者知道他们实际上不在你的网站上，并且面临着被黑客或在线攻击者攻击的风险。他们应该知道，如果看到那条信息，需要离开浏览器或跳转到其他网站。

## 第 6 章：排查 JavaScript 故障

你的 `JavaScript` 可能会出现很多问题。最常见的情况包括编写了错误的代码、添加了额外的字符以及放置位置错误。在这里，我们将讨论如何排查你编写的 `JavaScript`。

如果页面没有正确加载、显示不正常或者当人们访问你的页面时可以看到代码，你可能发现 `JavaScript` 存在问题。请确保你在编写过程中不断测试，这样你就能发现你所编写的代码是否存在问题。

如果你使用了错误的代码，可能会破坏掉你在代码中编写的其余字符串。这可能导致你无法继续编写页面的剩余部分，并让你在实际改进页面时变得困难。代码开头可能存在一个容易修复的问题，但如果它一直留在那里，你的其余代码将看起来不正常，你的页面也无法按照你完成后所预期的样子呈现。

## 额外字符

在编写代码时，你可能会发现代码中不小心混入了一些字母，这些字母可能会改变你的代码。这是一个问题，因为你需要确保自己能够充分利用代码的功能，而在代码中包含额外的字符会改变整个事情的走向。除非你希望在代码之外出现额外的字符，否则你需要检查并再检查，以确保你没有混入任何额外内容。

你还应该确保你编写的代码中没有无关字符。这可以是任何内容，从一个多余的逗号到整段完全不需要的单词。

## 缺失的字符

你始终需要在文本字符串后面加一个分号。这一点再怎么强调都不为过，它是确保你每次都能以正确的方式完成正确的代码至关重要。即使你认为不需要分号，在那里加一个分号也是一个好主意。缺少分号可能会对代码的呈现产生严重影响，并可能导致你的页面看起来是不完整的。因此，你需要确保在每次更改文本字符串时都有一个分号。

确保你包含了所有必要的括号和大花括号也是同样重要的，这样你就可以确保你的代码结构良好。如果你想用圆括号代替方括号，你应该确保它们的方向正确，并且放置在正确的位置，以便它们能够支撑代码。

## 错误的位置

如果你想确保你的网页尽可能美观，将代码的一部分放在错误的位置可能会是一个大问题。你应该确保信息包含在正确的位置，无论是在顶部还是底部。通常情况下，加载时间较长的内容应该放在底部，而你需要在页面上首先显示的内容应该放在最后。所有信息都应该包含在 `<script>` 标签内，并位于一个中心位置。

如果你未能将信息包含在 `<script>` 标签中，你可能需要另一个标签，或者能够与初始标签结合使用的标签。你还应该确保你的方法是正确的，并且所有想要包含的信息都已包含在内。留在标签之外的代码将独立显示，并在网页上显得格格不入。它不会被格式化，也不会与页面上的其他信息协调。

## 格式错误

格式在 `JavaScript` 中非常重要。因为这是一门主要用于格式化的语言，所以当你编写网页代码时，需要确保你正在处理格式问题。无论你遇到的是哪种错误，始终检查格式都是一个好主意。`JavaScript` 的格式以及文本，可能在你测试页面以查看是否有问题（如果有的话）时成为问题的罪祸首。

有些东西与不同类型的代码根本不兼容。还有有些事情无论你如何努力确保它们结合在一起，都无法正常。例如，你无法创建一个既是粗体又格式化为加粗的字体。那太极端了，字体将因为太粗而无法阅读。这种错误可能会表现为：它仅显示为纯文本，或者根本不显示。确保你所有的格式化都是正确的，这样你就能在你创建的网页上准确地显示你想展示的内容。
