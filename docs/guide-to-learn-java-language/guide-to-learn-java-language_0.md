
# Java 语言入门指南

## 第一章：历史

Java 的历史背景非常引人注目。Java 最初是为智能电视设计的，但对于当时先进的数字广播业务来说，它的创新过于具有前瞻性了。Java 的历史背景始于 `Green Team`（绿色小组）。Java 的同事们（也被称为 `Green Team`）开始了这项任务，旨在为计算机化设备（例如机顶盒、电视等）开发一种语言。尽管如此，它却非常适用于 Web 编程。随后，Java 的创新被 Netscape 进一步巩固。

使用 Java 编写计算机程序的标准是“简单、健壮、可移植、平台无关、安全、高性能、多线程、架构中立、面向对象、解释型和动态”。Java 是由 `James Gosling`（他誉为 Java 之父）于 1995 年创建的。`James Gosling` 和他的同事们在 20 世纪 90 年代开始了这项任务。

`James Gosling` 是 `java` 的作者。现在 Java 被应用于 Web 编程、手机、游戏、电子商务等领域。有几个关键点描述了 Java 的历史背景。

### 从 Oak 到 Java 的历史

1. `James Gosling`、`Mike Sheridan` 和 `Patrick Naughton` 于 1991 年 6 月启动了 Java 语言项目。这小组来自太阳公司的工程师被称为 `Green Team`。
2. 最初设计用于插入到机顶盒等电子设备中的嵌入式框架。
3. 最初，它被 `James Gosling` 分类为 "Greentalk"，文件扩展名为 `.gt`。
4. 之后，它被命名为 `Oak` 并作为绿色项目的一部分被创建。

### 为什么 Java 命名为 "Oak"?

5. 为什么叫 `Oak`？`Oak` 是团结的象征，被选为美国、法国、德国、罗马尼亚等许多国家的公共树。
6. 1995 年，`Oak` 被更名为 "Java"，因为当时已经是 `Oak Technologies` 的一个品牌名称。

### 为什么 Java 编程命名为 "Java"?

7. 为什么他们为 Java 语言选择了 java 这个名字？小组聚集决定选择另一个名字。建议的词汇有 "dynamic（动态）"、"progressive（渐进）"、"Silk（丝绸）"、"shock（冲击）"、"DNA" 等。他们需要一个能够反映创新体现的东西：渐进、动态、充满活力、酷炫、卓越且易于拼写、读起来悦耳。

正如 `James Gosling` 所指，“Java 是与 Silk 并列的最佳决策之一”。由于 Java 非常卓越，大部分同事倾向于 Java 而不是其他名字。

8. `Java` 是印度尼西亚的一个岛屿，那里产出主要的浓缩咖啡（称为 `java espresso`）。它是一种咖啡豆。`James Gosling` 在他的办公室附近喝着浓缩咖啡时选定了 Java 这个名字。
9. 注意 `Java` 只是一个名字，而不是缩写。
10. 最初由 `James Gosling` 在 `Sun Microsystems`（目前是 `Oracle Corporation` 的子公司）创建，并于 1995 年发布。
11. 1995 年，《时代》杂志将 Java 称为 1995 年十大产品之一。
12. `JDK 1.0` 于（1996 年 1 月 23 日）发布。在 Java 正式发布后，该语言添加了许多额外特性。现在 Java 被应用于 Windows 应用程序、Web 应用程序、企业应用程序、移动应用程序、卡等。每个新版本都为 Java 增加了新特性。

## 第二章：版本

### Java 版本

SUN Microsystem（现为 `Oracle corp`）将 Java 理念分为四类，以便于维护和推广到移动、工作区和 Web 应用程序等广泛领域。在 Java 中，一个分类被称为 `Edition`（版本）。通过这种方式，Java 理念分为四个版本。

#### Java SE (Java 平台标准版)

它包含了创建基于桌面（独立）的 CUI（命令行界面）和 GUI（图形界面）应用程序、Applet、数据集交互应用程序、分发应用程序以及 XML 解析应用程序的理念。

#### Java EE (Java 平台企业版)

它包含了开发 Web 应用程序、企业应用程序和互操作应用程序的理念。这些应用程序被称为大规模应用程序。一些模型包括：银行和安全型应用程序。

#### Java ME (Java 平台微型版)

它包含了开发客户电子设备（意味着嵌入式框架，类似于移动和电子级应用程序）的理念。Java ME 主要用于创建移动游戏应用程序。这个版本被称为微型是因为这些发布程序被安装在小的芯片中。嵌入芯片的程序被称为微型（mini）。

#### Java FX (Java 舞台特效)

Java FX 代表 Java 舞台特效（Eff=F, ects=X）。它提供了创建具有更多图形和动画 Web 应用程序的理念。它是 Java SE 的一个扩展理念。`Java FX API` 作为 Java SE 的功能包含。只要引入 Java SE，我们也将获得 Java FX API。

### Java 版本发布历史

从 Java `1.0` 的适配开始，我们没有相关的发布记录，因为在基础版本中 Java 不支持服务器端编程和企业应用程序。它只支持独立应用程序和 Applet（客户端 Web 编程）。在早期适配时甚至它已经支持 `JDBC`。在随后的版本 Java `1.1` 中，它开始支持 DIA（专用互联网访问）。从 Java `1.2` 开始，通过使用 `servlet` 和 `JSP`，增加了对服务器端编程的支持。大约那时，Java 支持三种用途（移动、工作区和 Web 应用程序）。SUN 选择将 Java 理念分为三个部分以便于维护和开发。从 Java `1.2` 开始 Java 有三个版本：

- `J2SE` (Java 平台标准版)
- `J2EE` (Java 平台企业版)
- `J2ME` (Java 平台微型版)
