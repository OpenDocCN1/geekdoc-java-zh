## 第 1 章：学习准备

当你考虑学习如何编写 `JavaScript` 时，采取的最重要的一步是准备好学习你需要做的事情。准备工作的一部分包括了解 `JavaScript` 究竟是什么以及它是如何起源的。你还应该通过学习 `JavaScript` 相比其他编程语言的优势来做好准备，以确保你确实为你的网站学习了正确的语言。

### 它是什么？

`JavaScript` 是一种语言。它与你了解或听过的大多数语言不同，因为它仅以书面形式存在，并且基于技术。它是与网页另一端的人进行交流的一种方式，让你有机会确保你已经在网站上传达了你的观点。你不能“说” `JavaScript`。如果你这样做，它听起来会断断续续，而且可能没什么意义。

当你从网站的后端用 `JavaScript` 编写内容时，访问你网站的人看到它，看起来就像是你实际上在上面写了东西。如果你不使用编程语言，你的网站看起来就像许多随机的数字、符号和字母，这不仅会让你的访问者感到困惑，而且对任何想要享受你网站的人不利。它可能会损害你试图通过网站实现的目标。

有许多不同的编程语言可以使用，但 `JavaScript` 是最流行的语言之一。它允许你更改字体的外观，添加可点击的按钮，并在人们想要在网站上执行不同的操作时让你的网站具有完全的功能性。它也是你可以学习的最简单的编程语言之一。

### 它从哪里来？

`JavaScript` 于 1995 年正式在操作系统可用。这是它首次在计算机上使用，`Netscape` 是第一个识别出这种代码能够实现的功能。它被用于帮助创建网页以及人们在使用个人和办公计算机时看到的其他内容。

由于该名称与其他不同类型的编码名称非常相似，某些程序选择将其称为 `JScript` 而不是 `JavaScript`。这是制造操作系统者的决定，但这个决定并没有真正流行。现在大多数公司都称之为 `JavaScript`，它们不会与市场上的其他程序混淆，因为它已经与现在提供的某些东西大不相同。

当 `JavaScript` 最初被创建时，是为了让每个人都能使用。在过去，1995 年之前，编程非常困难，很少有人会这样做。它曾是一种稀有物。虽然现在不是所有人都能编程，但 `JavaScript` 让它变得更容易，更多的人可以确保他们以正确的方式完成工作。

### 有什么好处吗？

在使用 `JavaScript` 的许多优点中，易用性是最大的之一。它允许人们利用现有的资源做更多事情，并让他们有比其他任何编程语言更快学习的机会。

`JavaScript` 几乎是万无一失的，因为已经有人先行并创建了必要的开发，人们只需插入代码。虽然如果人们想要一直使用它，学习编写 `JavaScript` 是重要的，但他们也可以直接使用已经编写的代码。任何人都可以这种方式开始学习 `JavaScript`。

其他优点包括让网页上的内容变得可点击、创建交互式网页以及利用 `JavaScript` 平台提供的功能做更多事情。任何知道并想使用 `JavaScript` 的人都可以利用它来提升他们网站的外观。他们还可以利用它来帮助自己营造更加对访问者友好的氛围。

总之，`JavaScript` 是最好的编程语言之一，因为人们可以轻松使用它，并且因为它带来了许多好处。

### 你会使用吗？

几乎每个学习过 `JavaScript` 的人都发现他们确实在使用它。无论是在自己的网站上经常使用它，还是帮助他人处理网站，`JavaScript` 确实非常有用。

一旦你学会了这门语言，你可能就会知道在今后的网络世界里将如何使用它。请务必尽可能地学习它，这样你就能利用所学知识完成更多事情。在涉及 `JavaScript` 以及你如何使用它时，有许多不同的选择。请确保你尽力而为，为你的网站提供可能最好的用户体验。

毫无疑问，如果你学习了 `JavaScript`，你就会使用它。它的设计初衷是用户友好，你可以利用 `JavaScript` 中使用的代码创建几乎你想要的任何内容。请确保你尽力而为，并尝试寻找不同的使用 `JavaScript` 的方法。使用最创新的技术将让你在用 `JavaScript` 编写的选项中，拥有尽可能最好的网站。

尽管它易于使用，但你仍然应该通过为学习过程做好准备，以便开始学习 `JavaScript`。在决定开始学习之前，先明确你想用它做什么，理解使用它的意义，并尽可能多了解它。为自己找一个坚实的起点总是一个好主意，这样你就能利用这门语言以及随 `JavaScript` 而来的代码完成更多事情。

## 第 2 章：基础

几乎任何拥有电脑的人都可以开始学习 `JavaScript`。由于这门语言相对简单，你不需要使用额外的软件。这在你刚开始时尤为如此，因为你初只需要用 `JavaScript` 做一些简单的事情，所以不需要太多的额外工具。当你开始做更多事情时，可以考虑获取不同的软件和额外的程序，但这些基础知识应该让你在刚开始时就能充分发挥 `JavaScript` 的效处。

### 网页浏览器

当这门语言首次提供给程序员使用时，它只能在特定的浏览器中使用。现在它已经发展得如此是唯一可以在每个浏览器中使用的语言。它被每个浏览器和平台支持，并用于创建无论访问者使用何种浏览器都能正常显示的网页。

正因如此，你可以使用任何类型的浏览器来开始你的 `JavaScript` 目标。大多数人选择使用他们最喜欢的浏览器，或者是在他们个人用途浏览网站时经常使用的浏览器。另一些人则选择其他更好或功能更强的浏览器，来查看他们自己创建的网页。

人们最常见的做法之一是直接使用默认浏览器。这种浏览器在你点击网站链接或尝试打开网页时会自动弹出的浏览器。编写 `JavaScript` 的人这样做是为了这样他们就不需要每次打开自己创建的页面时都费心去绕过它。这是一种简单且能让他们完成更多事情的方法。

### 编辑器

在开始阶段，你选择编写 `JavaScript` 的编辑器不会产生太大影响。它仅仅是一个你可以在其中输入所有信息并将其保存的地方，以便你可以在网页上使用，并且它可以与你创建的网页良好配合。

你有几个程序可以下载到电脑上，并用于编辑你的 `JavaScript`。其中大多数都是免费且易于使用的，这样你就不必因为想开始编写 `JavaScript` 而担心需要学习一个全新的程序。你可以在网上找到它们，或者如果你使用的是较新的电脑，可以在电脑自带的应用商店中找到它们。每个程序都有不同的优点，但它们大多数都是简单的纯文本处理器。

如果你运行的是 Windows 系统，你可能会惊讶地发现你已经有一个软件供你开始编辑 `JavaScript` 了。`记事本`（`Notepad`）并不是为此创建的，但它可以用于这个目的。它是纯文本，并且不会在你编写文本时像 `Word` 或其他处理器那样修改文本。你可以使用电脑自带的`记事本` 直接在笔记中编写并保存所有的 `JavaScript`。

### 脚本标签

编写 `JavaScript` 有两种主要方式，第一种是创建 `script` 标签。这些是你在网页上编写的标签，你将代码放入脚本中，这样代码就全部在你的网站上完成了。对于想要基础代码且只需要一个基础网站的初学者来说，这很容易，因为只需将代码放入每个脚本中即可。这对于那些不想频繁编辑网站，或者没有大量改动需要制作网站的人来说是理想的。

要实现这一点，你只需要编写：

```html
<script type= “text/JavaScript">在这里直接写入你想要包含的所有信息，并确保它是纯文本。这就是你的记事本编辑器将要用途的地方，也是为了确保你以正确的方式操作所做的。</script>
```

当人们点击它时，这些信息将出现在你的网站上。如果你只是写了它而没有使用 `script` 标签，文字将不会出现。如果你运气好，它可能只是一串符号和数字，中间夹杂着一些字母。

如果你只想开始练习 `JavaScript`，这是最好的方法。它将让你有机会真正开始编写它，并让它出现在网页上。

### 脚本链接

一旦你更熟悉 `JavaScript` 以及你能用它做什么，你就可以开始链接到你编写的脚本了。如果你计划进行许多更改、拥有大量信息，或者想让你的网站具有交互性以便人们点击并获得结果，那么这是一个非常棒的方法。

要能够使用链接，方法类似。你会在纯文本编辑器（如`记事本`）中编写代码。然后保存你刚刚编写的代码，使其有一个你可以容易识别的名字。确保使用 `.js` 结尾，这样它在被链接时会被转换。

```html
<script type= “text/JavaScript” src= “scripts/choosisfile.js"></script>
```

在 `choosisfile.js` 地方，你需要填写你刚刚保存的文件名。

### 变量

网页有许多变量，这就是网页如何工作以显示不同信息，让人们在不同页面上看到它们。你还可以对你拥有的以及你要展示给访问者的内容进行许多不同的操作。

变量是你向网站传达信息的。它们是代码的“核心”，也是你的访问者来到时所关注的内容。你只需要编写：

```javascript
var grapes= 7;
```

当然，这是在你谈论葡萄的情况下。这会告诉你的代码你有 7 个可用的葡萄。末尾的分号用于告诉你的代码你已经说完了，它可以开始处理代码中写的下一个内容。它就像句末的句号，但它的存在是为了让你的代码知道何时停止。

如果你想告诉你的访问者有 7 个可用的葡萄，你只需要写一个变量警报：

```javascript
alert('我们有’ + grapes + ‘ 个葡萄!');
```

“We have”和第二个“grapes!”是你访问者进入你的网站时看到的内容。他们不会看到里面写的不同标点符号和跟在 `+` 葡萄。这个 `+` 符号告诉代码在里面填入你实际拥有的多少个葡萄。

当你编写代码时，请记住它是区分大小写的。这是因为不同的大小写意味着不同的含义，所以确保你书写的方式与要求的写法完全一致非常重要。这是使用 `Notepad` 的用处之一，因为它不会自动将单词转换为大写。

### 提示符 (Prompts)

现在你已经告诉访问者你的网站上有 7 颗葡萄可用，你现在可以让他们在访问网站时选择他们想吃多少个。显然，他们并不会吃真正的葡萄，但这是当访问者选择在网站上进行操作时，显示互动正在进行的的最简单方法之一。

编写一个提示符：

```javascript
var eat =prompt(‘How many grapes do you want?’, ‘3’)
```

如果你的访问者想吃 3 颗葡萄，就会显示这个，并进行调整让你知道还剩下几个葡萄。如果你写了代码：

```javascript
grapes -=(parseInt(eat);
alert(‘We only have ‘+grapes’ + grapes left!)
```

这就会向你的访问者显示只剩下 4 颗葡萄可用。你可以选择添加另一个提示符，问他们是否想吃更多葡萄或者是否想继续后续。

你可以对网页上的任何内容执行此操作，它将向你的访问者展示不同的可用内容。确保你为他们提供尽可能的信息，并让他们以提示符的形式进行选择始终是一个明智的决定。

当你写下 `-=(parseInt)` 时，你使用了一个运算符。它的作用与在实际数学题中的作用完全一样。可以使用的各种运算符包括 `+`、`-`、`*` 和 `/`。它们被用作加、减、乘、除，并且可以轻松地用在你编写的任何 `JavaScript` 代码中。它们告诉访问者执行了什么操作，并教你的代码在处理网页上提供的各种选项时，应该如何对不同的物品进行加或减法。

## 第 3 章：测试

在编写 `JavaScript` 的不同部分时，你想要对它进行测试，以确保它运行正常。如果你是在网站的 `script>` 标签内编写代码，你需要做的就是保存你所做的更改，并在另一个窗口甚至不同的浏览器中打开它，以确保它看起来正确且没有问题。如果你是将其链接到网站或电脑上的某个位置，你将需要做更多工作来确保它运行正常。你需要将其保存到原先的文件中，然后在不同的浏览器中打开它时尝试查看。

### 充当访问者

测试你的 `JavaScript` 时可以做的最重要的一件事就是假装成网站的访问者。确保你感觉自己是第一次访问它，并点击它的每一个部分，这样你就能知道自己在寻找什么。这样做将让你看到你网站上的许多不同选项，并对你的网站执行不同的操作。

访问网页并环顾。看看哪里可以点击，你可以做什么。如果你设置了变量和提示符，点击它们并确保它们运行正常。留意网站上可能出现的任何错误代码或字母。如果你看到任何，就记录下来，这样你以后就知道回来修改它们。这是你了解自己正在做什么的一种简单方法。

### 出现的问题

如果你正在使用保存到不同文件的方法，你总是需要确保保存了它。除了其他错误（如大小写错误或添加的字母），这是你在查看网页时发现的最常见问题之一。例如，你需要确保你的 `JavaScript` 是正确方式编写的。你的提示符可能没有出现，或者在它出现时出现了问题。

如果你没有保存你刚刚编写代码的文件，不仅会导致你的网页看起来有缺陷，还可能丢失你刚刚完成的所有工作。你需要确保定期保存，并在尝试查看网页之前进行保存。

### 检查错误

人们在编写代码时最常见的错误是他们在不该大写的地方大写，或者忘记在大写的地方写。这种错误不仅会改变你网站的外观，还可能让它完全无法识别。确保你始终检查大小写。

有一些可用程序会自动转换你写的单词，即使它们是专为编写代码和编写 `JavaScript` 设计的程序。一个不会为你自动转换大小写的程序是 `Notepad`。这也是许多其他原因之一，为什么它对初学者来说是一个非常棒的程序。

如果你使用了 `Notepad` 程序并确保所有内容都以正确的方式写，你可以尝试可能出现在错误中的其他问题。某些可能拼写错误，你可能使用了错误的运算符，或者你只是在写法上存在问题。这并不总是意味着你写得不好，而是你可能在其中滑入了一些额外的字母。



直接在标签中编写代码略有不同，但你仍然需要确保尽可能频繁地保存。你可以将其保存在网络浏览器中，也可以将其保存到`different area`（不同的区域），以便你能够尽可能地完成工作。如果你决定直接在标签内编写，你可以始终以方便你的方式保存它，这样你就不用担心各种问题了。

## 尝试更多

当你测试了网站并且发现一切都运行正常后，你可能想向其中添加更多内容。你可以为它添加不同的提示框（`prompts`）和警告框（`alerts`），这会让它看起来更专业。它还将让你有机会扩展页面，使其与你网站上的其他页面相匹配。你甚至可以编写代码将你的页面连接起来，并在访客点击其中一个页面时将他们引导到不同的页面。

当你学会如何编写`JavaScript`时，你可以在网页上做很多更多事情。考虑一下当你尝试为网页添加不同选项时可以做的一切。你可能会发现，如果向网页中添加更多信息，你可以做得更多，并从你的网站中获得更多价值。

即使是最简单的命令，如`alerts`和`prompts`，你也可以让你的页面变得多维度化。尽管如此，始终尽力为页面添加更多内容，并不断学习关于`JavaScript`的知识以便你添加更多功能，这是一个好主意。

## 添加不同的变量

虽然`alerts`和`prompts`非常棒，但你的网站需要的不仅仅是询问人们想吃多少你的葡萄。它需要不同的页面、不同的提示框，甚至是人们可以点击的不同按钮。在这些之中，你可能想更改颜色、字体以及在页面上的位置。幸运的是，这些都是你可以通过`JavaScript`完成的。

一旦你掌握了`JavaScript`的基础及其工作原理，你就可以对其进行重大更改。你可以使用“text color”标签以及“text style”字体来更改文本颜色。你可以使用`<b>`、`<u>`和`<i>`标签对网站上的内容进行加粗、下划线和斜体处理。要停止使用这些标签，你只需要输入`</style>`或`</body>`、`</u>`和`</i>`即可。

这些中的每一项都会让你的文本看起来不同。你甚至可以使用标签来更改警告框的颜色、背景以及文本在页面上的定位方式。

随着你学习到更多`JavaScript`，你会发现网页上执行不同操作的选择是完全无尽的。任何你想在页面上编写或更改的内容都触手可及。是否能够使用这些不同的功能完全取决于你的想象力。

但在你执行这些操作之前，你需要确保自己始终在测试你的网站。测试它以找出哪里出了问题。测试它以确保它看起来良好，测试它以发现你可以为其添加什么。随着你越来越熟悉`JavaScript`，你会发现测试是可以很有趣的，甚至可以让你的页面功能更多。测试是确保你的网站出色的关键。

# 第 4 章：付诸行动

如果没有人有机会看到这些页面，那么了解`JavaScript`并构建网页又有什么用处呢？你用`JavaScript`可以做很多很多事情，但如果你想获得成功并让你的`JavaScript`知识为你服务，你就需要能够将这一切付诸行动。采取以下步骤将你的`JavaScript`能力付诸实践。

## 获取网站

如果你想让人们能够访问你的网站，你需要一个域名。那些没有与你使用同一台电脑的人无法通过点击你创建的文件来查看你用网站创建的内容。即使你使用`Notepad`创建的`JavaScript`是完美的，如果不能通过网站查看，访客也无法看到它。

你可以从许多不同的来源购买域名。有些平台，比如`Godaddy`，以非常低的价格出售域名。这些通常是允许你有机会为自己的网站命名，并通过创建你能够提供给想要访问你网站的人的东西来确保你从中获得最大价值的域名。确保该域名是你和访客都能容易记住的。

某些域名可能因为受欢迎而价格最昂贵。例如，你可以使用你的名字作为域名，但`joseph.com`可能已经被占用，或者可能花费数千美元，因为它是一个非常受欢迎的、一个可能花费大量金钱的东西。网站的变体，如`facebookses.com`也可能很贵。如果你想要一些基础的，比如`ilikocode.com`，价格可能会便宜一些，因为它们并不极端常见。

如果你想让人们能够访问你的网站，你需要一个域名。互联网并不像你的电脑那样。你不能只是打开一个网页就开始打字，除非你有了域名。你需要确保你正在使用托管服务。托管服务将允许你放置信息以及你构建网站的方式。托管服务是信息进入的地方，而页面是人们访问网站时看到的内容。

## 改变事物

改变是`JavaScript`最棒的地方，它将让你能够颜色以及样式看起来都不同。

要在你的`JavaScript`中更改颜色，你只需要做：

```
var color= documentname.col.style.color = “color”
```

你使用的颜色可以是红色、蓝色或黄色等基础颜色。如果你想制作不同的颜色或脱颖而出的自定义颜色，请使用调色轮。你在互联网上和编写`JavaScript`时可能会使用的色轮被称为`hex`（十六进制）。这是你想要使用的颜色代码。每种颜色都有一组独特的字母和数字使其独一无二。它以`FFFFFF`代表白色，以`000000`代表黑色。其间有数百种颜色，最复杂的`hex`代码将包含每种颜色的许多不同深浅。找到你喜欢的那个，并把它放在代码中编写“color”的地方。

当你想要让文本不再显示那种颜色，或者让`JavaScript`标记中的不同对象不再显示那种颜色时，你只需要写`</color>`。通常情况下，在`<>`括号之间使用`/`会停止某些操作并将其恢复为自动颜色。如果你想再次更改颜色，只需编写新的`var color`代码即可。

要更改大小，你只需要做：

```
var str = “你希望具有相同字体的。”
var result = str.fontsize(14)
```

字体大小将具有不同的含义，并且取决于你查看网页时使用的浏览器。务必学习字体大小并跟踪它们的工作方式。拥有一种可以比较字体大小`1`和`14`之间差异的方法好主意。对于很多事情，你会使用`10`到`16`之间的任何数字，标题通常在`20`左右。较小的字体（如`1-6`）将用于你不一定想让人们轻松阅读的小信息。
