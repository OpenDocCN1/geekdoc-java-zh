
# 从丛林到 Java

![封面](img/0.png)

X 先生的印象和一些细微的冒险经历由我着手编辑，他要求我将他的个人介绍缩小到符合对读者礼貌的范围（如果我恰好找到了任何读者的话）。正如他的笔名暗示的那样，他倾向于保持一个无名之士。我只需要解释一下，他是马来半岛某个小国家的一名官员，这些国家（很大程度上）处于海峡殖地殖民政府的保护下。后者为了那些爱好安逸的统治者周周考虑，任命官员来分担他们行政管理的忧虑和职责，并免除他们对政府的责任——因为如果没有这种外部援助，该政府在政策上可能会比东方观念所能接受的进步得多。

正如标题所暗示的，X 先生的职责迫使他必须丛林中定居。“丛林”一词在东方有许多含义，通常用来表达远离文明的地区，尽管那里可能只是荒凉的山脉或没有树的平原。然而，X 先生的丛林却体现了未足迹世界的英国人所想象的模样。那里是一片充满了茂密森林的山丘和山谷，在河流（大自然的干道或人造的主干道）两旁星星分布着小小的耕绿洲。这是一片美丽的土地，气候被住在那里的人——他们是最好的证人——描述为健康且宜人。由欧洲人组成的小型社区成员对他们这个美丽避风港的设施感到由衷自豪，那里有常青的绿意，并为他们的“辉煌的孤立”感到光荣。批评是被反感的，而认为由于气候影响导致不适的建议则被认为无异于叛徒。

所以，正如想象到的，当 X 不仅抱怨身体不适，还表现出长期不满的迹象时，这是一件非寻常的事。对于 X 来说——在那个小圆桌俱乐部里不需要称呼先生了——他确实身体不适。这一点不容置疑，这种身体状况简直无异于对该地特权的滥用。但由于他无法对自己的感受给出真实的解释，在参加俱乐部每天午餐前的台球游戏时只是模糊地叹息，大家认为最好忽视他的新动向，对这个问题闭口不提。

然而，这种明智处理的结果被一位医生的到来完全抵毁了，这位医生带着“驻地医生”这一响亮的官方头衔。这位先生通常对疾病持怀疑态度，只承认那些诚实的、直截了当且值得一位医生关注的疾病，这位医生的名字面前有一连串令人生畏的荣誉头衔，多到他无法一一介绍。但即使真正伟大的人也不总是严格如一，偶尔也会在先例的直径上产生微小的偏差——于是，这位科学家竟然对 X 的病情投射了兴趣的目光。仅仅是值得注意这一点就足以让这位备受推崇的病人的同伴们感到震惊了，但当这位伟人通过赋予一个古典名字来增加关注时，同情的表达变得无止境了，那种不寻常的关怀几乎让受者难以承受，而受者也保持着符合场合的、自觉的庄严态度。

这里发生了一些相当*精致（distingué）*的事情，一些全新的事情。庸的抱怨是受谴责的对象而非同情的对象，因为会损害这个健康避风港的名声；但一个由希腊词典中两个词组成的疾病，却赋予了一种或许关口之外更大社区所不知且令其羡慕的特殊地位。这件事经过了严肃的讨论，得出了结论：X 需要一个改变。并不完全是因为改变对他有好处，而是因为当他回来时，从他去的地方回到他在普拉普拉（Pura Pura）的家，这种改变会对他的健康产生奇迹。由于医生认可了裁决的前半部分，并稍作修改，建议说对于一个辛勤工作的官员来说，很少有种健康状况是不益于改变的，因此剩下的就是选择 X——获得许可后——必须去的地方了。

当然，他去槟城、甚至去香港或日本是不行的，那样的远征太过于平凡和陈调了。大家觉得 X 先生应该做些符合这一场合的事，通过前往一个在人和风景上与其尽可能相似的地方，来表达对他居住之地的感激。因此，当主要相关者在知道大家对他的期望后提议去爪维时，这个想法被接受了，并决定就此去爪维。

那天晚上，俱乐部里进行了一场长时间的聚会，耐心的调酒师 Manop 不得不记录下许多额外的“半杯酒（stengahs）”的消失，因为大家正从各个方面讨论这件事。社区中去过爪维的人回起了对那个国家的经历和回忆，这让另一些人感到恼恼，尽管他们的旅行路程可能更长，但没有走向同一个方向，因此不得不接受沉默倾听者这一不受欢迎的角色。然而，在长期忍耐的刺激下，其中一方（他的故事背景大多在南半球）评论道，当 X 从爪维回来时，他必须写一本关于那里的书，因为如果他交流的信息只有目前发言者的一半，那本书也将充满信息。这句小讽刺完全由于被字面化理解而搞砸了，因为大家立刻决定 X 必须写一本书。他徒劳地抗议说，仅仅访问过一个地方是不可能写书的，因为他只能写下别人已知的内容；他的反对被驳回了，他被提醒说，就在前几天，当总阁下“进展”（这是“旅行过”的官方说法）通过一个邻国时（在场的人对此太痛苦地记得，那是他们在丛林中探索并实际修建这条随后进行这一“进展”的道路时经历的许多疲惫的日子），其中一方写了一本书，宣布了一个新发现的地点，甚至严厉地鄙视那些经历过早期艰辛劳作之人的傲慢，因为某些感激的先驱者在定居的第一几个月里用帮助过他们的朋友命名各种地标。

脚注：[1] “peg”的当地称呼。

在`X.`获得离开丛林的正式许可生效前的这几天里，人们可能会注意到他发生了变化。这位一向很稳重的人变得变得焦躁而不安，`The Community`的成员们一致认为他处于“旅途自豪感”（journey-proud）——这是邻近一位马来领主用来描述一个人在离开自己的避风港、准备出发时心情的一种愉悦表达。

但有很多工作要做——那些衣服自从他们离开山口口彼岸的那些城市以来，就再没被打量过，现在必须进行检查，并将它们所有的破绽暴露无遗——蠹虫在最显眼的地方咬了洞，而在其他地方，老鼠简直直接在上面筑了巢。那些衬衫看起来是白白的假象，它们那样躺着，无非是一排排“假衬衫”（dickeys），因为展开后发现，它们已经失去了下摆，下摆早已沦了蟑螂的猎物，或是小鼠幼崽的垫子；领子从磨损处脱落后，高度也遗憾地缩水了；而对靴子部门的检查发现，没有任何东西能经受`The Community`更挑刻的审视了。然而，面对糟糕的情况只能尽力而为，一位缝制皮革的`Bo Ping`在这件事上确实尽了最大的努力。

## 出发准备

随后，`Usoof`和`Abu`的衣橱也需要同样的准备，他们是被选择陪伴`X.`行走的两个随从。这意味着当地裁缝会多次造访，他们在后房度过很长时间，身边还围着所有的朋友亲戚——因为在`Pura Pura`，正如许多其他东方民族一样，有一个人在工作，总会有十个人在看。

因此，对这些行程的关注并不集中在`X.`身上——对某些人来说，他在这件事中完全处于次要角色，只是与`Usoof`出发相关的插曲。众所周知，他是要去他的出生地`Java`——“Tuan”[[2]](@public@vhost@g@gutenberg@html@files@27749@27749-h@27749-h-0.htm.html_Footnote_2_2)`X.`恰好要去那里。`Usoof`回家是为了寻找亲人并告诉他们关于自己的所有事，而众所周知，他多年前就离开那里了，那时他只是个怀中婴儿。

由于这一事实在每天晚上直到深夜都被广泛报道和讨论，期间朋友们吃着面包加糖的轻便点心，并用粉色的糖水冲服，因此`X.`最后开始感到，已经既定此行主要是去寻找`Usoof`的母亲，那位母亲可能居住在`Java`某个村庄，但她的名字无人知；事实上，她是否还在人世还是一个推测的问题。然而，这项搜寻由于其目标已知的信息极少，反而引起了额外的兴趣，在此处被提及，以便在此后叙述这段搜寻如何引导`X.`离开游客的常路时，人们不会感到惊讶，因为可以理解，如果不尝试完成那些对他期待的事情，他是不可能回到`Pura Pura`的。

## 行程

允许`X.`离开`Pura Pura`的文件如期送达，出发日期也确定了。`Usoof`和`Abu`已经赶着牛车先行出发，`X.`将于第二天早上离开。`The Community`的几位成员好意来送别，坐在长长的“半小时”（stengahs）上显得平静而优越，而这位即将出发的旅行者则试图在十五分钟内完成关于他不在期间事务处理的最后指示。

然而，在写下各种小备忘录，并对马夫和租户们下了许多关于照顾家中马、羊、鹅、狗、熊、驯化的白鹭、豪鼠和其他牲畜的指令后，旅行者坐上了他的双人轻马车，心中涌起了一种所有即将暂时离开`Pura Pura`幽静之地的人都会产生的失落感。就这样，他向着外面广阔的人间出发。第一次远见是在二十四英里之外，在穿过一些想象中最美丽的丛林风景后到达。这片文明的绿洲是他登船港口所在的国家首都。`X.`在此留了一晚，接受了那位好医生的招待，那位医生看过了他的症状，并以科学的方式对其进行了定位和命名。对于一个刚从丛林出来的人来说，由于有陌生的面孔，这个夜晚看起来充满了新奇和活力。伙伴中的一个是一个法国罗马教神父，在各国广为人知是一个实干派且志同道合的伙伴。还有一位带有头衔的绅士——一位刚从英国来的访客——如果不是他在用餐期间感谢天佑，他在那些地区没有遇到那种类型的人，他本该被称为环球旅行者。

这位对没有环球旅行者感到高兴的绅士，要在如此短的时间内前往如此多的地方，`X.`只能困惑而羡慕地看着他。因为他是在经过一个月深思熟虑后才开始旅程，期间关于请假和医学证明的信件已达到了官方规模；而这位旅行者随身带着所有的计划文件，如果得知这位访客真的在规定时间内完成了任务并看到了他所计划的一切，将很有趣。也许，等他回到家，他的圈子——其他有头衔的人——会逼他写一本书，以满足我们合理的好奇心。

## 第三章 新加坡。

我看到`X.`在笔记中写道，这座城市的第一印象是远方中最美的——他指的是进城的路线、景色，还是城市本身？这也许并不重要，但可以肯定，他记录了一个事实：对于像他这样一个贫穷的丛林人来说，当他穿好衣服准备重新回到他离开已久的世界时，这里看起来非常广阔且充满生机。一辆`gharry`——一种四轮近程马车，配着一个看起来脏兮兮的马夫和一匹小马——正将旅客，或者说正准备将其送到一位居住在新加坡的显赫将军的友好家中。

新加坡是一个以难以认路闻名的城市，因为所有的路看起来都一样——它们都非常完美——房子也是如此。如果我不是打算告诉你们`X.`是如何去爪哇的，我很想停下来讲述有一次因为这件事，作者在错的家里吃了晚餐——而且吃得很好——而他的主人（他从未知道对方的名字）保持了极度的`sang-froid`（冷静），从未表现出任何惊讶；但这种自我主义的离题可能会打扰`X.`，而他有权在这段小历史中占据首位。

马夫显然并不知道任何具体的个人住在哪里，完全依赖于只有当地居民才知道的奇特描述，因此，`X.`试图解释他想去哪里是徒劳的。从对路人的质问中得知，没有哪个`gharry`马夫或马来警察听过过那位将军，甚至不知道有这样一位人物存在——`X.`并没有告诉那位将军这件事——于是，载着`X.`的马车以及后面紧随随从和行李的两辆马车，来回穿梭，让路的人感到困惑，因为这种曲折的说明了对当地情况的无知，而对当地的无知意味着是一个环球旅行家，然而并没有邮轮抵达，而且，环球旅行家通常会有两个马来人跟随。

随后，他再次试图用有力的马来语解释他想去的地方——这让问题变得更加困难——直到路人（大多是去菜市场的厨师）放弃了，认为这个问题太深奥或太琐碎，无法解决。早晨的行程一直持续到那些早去上班的欧洲人坐着他们精神抖爽的马车、赶着快马出现。这时，其中一位商业巨头来救援，他向`gharry`马夫解释道：全军指挥官居住在一栋`某某先生`曾经住过的房子里，在著名的`某某先生`卖了他的赛马并搬出那栋房子之后——“难道马夫不记得吗？”“是的，Omad 不就是那位绅士提到的首席马夫吗？”听到这里，马夫大喊道：“当然”，然后鞭起小马，脸上带着轻蔑的眼神（仿佛在说“要是他早点告诉我就好了”），径直驶了小镇上最大、最气派的豪宅之一。

从新加坡的酒店里解脱出来（那里有迷路的旅行者抱怨，还有长相奇异的丛林人来喝酒），`X.`感到所有半沉睡的文明记忆都回到了身上，当他经过哨兵，进入宽敞的大厅时，受到了主人的友善欢迎。

正如书中所说，在去除了旅途的痕迹（在这种情况下并没有明显的迹，因为在`s.s. Malacca`号上洗澡是可行且惯行的）后，`X.`与他的主人共进早餐，并被告知了当天的行程——包括下午游览、傍晚外出用餐，然后去花园听月光下的军乐团演奏。对于`X.`来说，新加坡看起来是多么一个欢快的地方，他每晚都是独自用餐，对他而言，乐队的声响是往日的记忆——而且还是月光下的乐队声。是的，那也有它自己的记忆。在月色光好的夜晚，他习惯于坐在露台上，听着居住在他山下村庄的马来人发出的昏沉而单调的歌声。那种吟唱声在升起时非常悦耳听，诉说着陪伴与知足，尽管正因如此，它让孤独的欧洲人感到更加孤独。当地仆人给他送来晚餐后离开，让他去寻找自己的乐子。他像是一项任务，一件已经完成并在夜里收起来的事，被孤独地遗留在宽阔的台上，几分羡慕那些能在朋友相伴下享受月光的当地人。

在新加坡，`X.`不需要羡慕任何人，因为他难道不是要在晚后出去，在月光下听一支乐队，而且还是欧洲人演奏的乐队吗？现实等同于预期，因为在新加坡美丽的花园里，月光伴着社会`elite`坐在马车里或湖边草地上散步，即使对于比`X.`更`blasé`（厌世嫉俗）的人来说也是一个愉快的夜晚；而此人在看到`Usoof`和`Abu`在这一群陌生人中孤独地站立时，这种感受并不比他在家里孤独沉思时少过，而此时他们正对着月光为朋友们唱歌。

夜晚在军营食堂的华丽宵宴中结束了。这次外出的直接直接结果是愉悦，随之而来的结果——可能是给那个标识`X.`疾病的复合希腊词又增加了一个音节。

## 第四章 通往爪哇的路。

第二天，`X.`记得人们对他的期望，便租了一辆马车（gharry），开始履行礼仪对他这种特殊官方身份所要求的一切义务。其中首要的一点是在殖民秘书处办公室候客室的一本簿子上签下自己的名字。这本书上的名字读起来很有趣，`X.`想想，如果能把这本书带进伦敦俱乐部的吸烟室，并打十比一，赌在场的人中没有三个人能在地图上找到所标注的地点，那么这可能会成为财富的来源。`Perak`[[3]](@public@vhost@g@gutenberg@html@files@27749@27749-h@27749-h-0.htm.html_Footnote_3_3)——或者他们在吸烟室里称其为 Pea rack——雪兰莪（Selangor）、彭亨（Pahang）——在家里被称为 Pahhang——柔佛布（Jelebu）、乌戎江（Sungei Ujong）——在这里被伦敦化为 Sonjeyajang——以及许多其他不熟悉的发音。

官方例行结束了（这应该是半官方的例行，`X.`这样暗示，他担心自己可能对作者的任何错误负责，这可能导致人们认为他在自封任何真实的殖民地官职——然而，很难如此留意这些细微的区别——`X.`接着访问了`Messrs. John Little and Co.`。每个去过新加坡的人都去过`John Little's`，因为它对当地人来说熟悉程度甚至超过了伦敦人对`Whitely`的熟悉程度。`Whitely`有对手，而`John Little`则没有。从这家著名的提供必需品和奢侈品的商店到这家好客的俱乐部仅一步之遥，旅行者就在那里吃了午餐。这家俱乐部是新加坡所有显赫商人的聚会场所。建筑非常精美，有一个俯海的海廊，成员们总是热烈欢迎陌生游客和来自邻近半岛的邻居。说了这么多，我觉得我必须冒着引起`X.`的不悦（他会被归功于我告诉了他这些），并补充道，这家公司比菜肴更好。饮料的质量和数量无可挑剔，但那食物！——那是他们在丛林里处理得更好的事情之一。

下午，将军再次如他所言，带着客人去兜风，让他那惊讶的眼睛目睹了新供水工程的所有美景。中国邮件在早上已经送达，这个喜爱的去处挤满了明显的乘客，其中一些还是环球旅行者。如果这位头衔显赫的旅行者匆忙路过那里，他会说什么呢？晚上，阁下为二十位客人举办了晚宴，这些人选自新加坡最精英的圈子。与这么多欧洲人同桌吃饭对`X.`来说任何时候都是一种新鲜，但突然发现自己处于这样一个显赫的伙伴之中，这种新奇感几乎令人心惊。然而，由于幸运地坐在美女身边，气氛通常变得轻松起来，如果当时社区的任何成员在观察，他可能会认为`X.`背背了这样一个信念：对于一个人来说，没有哪个地方比`Pura Pura`更适合居住。

对其他食客来说是家常事，对他来说既是当下的快乐，也是对过去的一瞥。当然，试图向任何人解释他来自哪里或住在哪里是完全徒劳劳的，因为`Pura Pura`这个名字对他们来说是陌生的，因此有必要假装成一名前往`Java`的*路过的*乘客。公司中的一些人去过`Java`（包括主人），他们对那里的礼节赞誉有加。

早晨，旅行者向他亲切的主人告别，主人于凌晨`5.30`出去参加一场早起的小战争，对那种战争的描述对一个平民来说，可能就像`Pura Pura`的地理位置或`X.`的确切官方身份对前一天晚上公司成员来说那样模糊。这位伟大的士兵身着全制服穿过一群不同国籍、鞠躬的仆从开车离开，`X.`进了他简陋的马车，在`Usoof`和`Abu`的跟随下来到`Messagerie`码头。前往`Batavia`的蒸汽船是`s.s. Godavery`，它与回国邮件相连。票价根据实际行驶距离计算，可能是世界上最昂贵的。航程耗时三十六小时。

## 第五章

### 雅加达。

搭乘`Godavery`号的航程与之前的航程相似，不同之处在于，那里的美食佳肴让 X. 希望过途中的时间能更长一些。唯一感到不满意的是 Usoof 和 Abu，因为他们的雇主每晚只给他们三美元。这几位穆斯林人拒绝触碰被盛给他们的食物——那些食物正被粗旷且简练的中国仆人分给一大群各种肤色和阶层的当地人。在第二天结束时，由于他们一直什么都没吃，显得非常凄惨和难过。然而，在多付了几美元花得当的钱后，他们换来了一顿面包和茶的丰盛晚餐，随后他们露出了笑容。

抵达一个陌生的港口或许没有什么比这更令人愉悦的感受了。对于登陆地之外种种可能，思绪和推测数不胜，想象与期待也同样强烈。当`Godavery`号驶入巴达雅（Batavia）时，天还黑暗，雨倾盆而下。一切看起来相当凄惨，但一旦靠岸码头，日光便开始显现，乘客们纷纷上岸。车站距离登陆点有四分之一英里远，这些可怜的人必须在雨中匆忙赶。



不幸的当地人——提着装有行李的包——被淋透了。欧洲乘客——虽然没那么可怜，因为只有实际穿着的那部分衣服暴露在雨中——也在这场潮湿的抵达中分担了大量的水汽。确实有一条华丽的遮雨走廊，但被货物和其他铁路设备完全堵住了，这些东西似乎比乘客更容易受潮湿影响。行李很快由海关官员礼貌地运过，乘客们进入了一辆装饰豪华的马车——显然，`X.`在爪哇从未见过这种车。

抵达巴达雅留下了良好的第一印象，因为这里没有像新加坡那样纠缠的人群，而且有许多马车供租。前往酒店的旅程很长，穿过了城市的商业区，直到到达住宅区。这里的独栋房屋坐落在主路旁，另一侧是一条运河，赋予了该地恰当的荷兰风情。酒店是一座最宏伟的建筑，外面显然有无数间房间，但 `X.` 立即感到不寻常的是，房间的地板与地面齐平，不像新加坡和半岛地区那样架空。旅客被分配到一个大小适中的房间，面对着一个院子，左右各是其他房间，事实上，在这些房间前坐着身穿便装的人。这里似乎没有隐私，也许在那种情况下这算是幸运的——然而，`X.` 尚未观察到这一点。进入房间后，他关上门，点了他的第一顿饭。

事实证明这是一顿糟糕的晚餐，由一些令人胃口的食物组成：一盘冷菜、两个水煮蛋、三条椰子油炸的小鱼以及一些像火腿的东西。这第一顿饭可以详细描述，但它只是这种苦涩尝试的尝试，会让 `X.` 感到胃部不适。在快速扫过这些毫无食欲的食物表面后，`X.` 的注意力转向了墙上贴着的告示。这些告示用多种语言写着，警告旅客：如果抵达后没有获得居住许可，将面临处罚。读完这些后，`X.` 没有浪费时间叫了一辆交通工具前往英国领事馆。接待他的男士非常有礼貌，提供了他所能的所有信息。似乎如果旅客想了解关于爪哇的事实，该国的官员也同样如此。他不得不填写一份打印好的表格，写下年龄、出生地、居住地和职业等，完成后，为他的辛劳支付了一比半几尔林德。

下一步是去银行，没有什么能比他在那里受到的热情更让他惊讶的了。那位周到的经理帮助这位陌生人决定去哪里能最好观察这个国家，并且最关键的一点，为他写下了地点和酒店的名字。令 `X.` 失望的是，支票取款系统几乎不为人知，总是需要携带现金，如果需要更多，则通过挂号信接收。对于一个多年来遵循东方习俗并依赖支票和“借条”的人来说，携带现金是一个他未准备好的新麻烦。

在穿过泥泞的街道返回酒店的途中，给旅客留下的第一个新印象是许多售卖蔬菜的当地人——那些看起来很健康的品种，尤其是胡萝卜。在多年没有看到除了在锡罐里长期监禁以外的熟悉蔬菜后，这真是一个令人耳目一新的景象。

沿途路上，当地男女都在运河的脏水里洗澡，完全没有一丝马来人特有的那种羞涩感。第二点印象是，当地人没有一个穿靴子或鞋子的，他们都赤脚踩在泥泞中穿行。当坐马车过来时，他已经注意到了这种鞋子的缺失，随后被追随者们穿着整齐靴子的脚吸引了注意力。

难道他们以后也必须在泥泞的街道上赤脚穿行吗？更糟糕的想法是——打破这种局面会落在他头上吗？当地人看起来比半岛的马来人更高、更强壮，但像新加坡一样，他们是混合群体，更显著的是，没有阿拉伯人。对于可能没有访问过我所描述的这个地区的读者，应该解释：新加坡几乎完全由华人居住，而在土著国家，华人的数量远远超过了马来人，以至于人们习惯了随处见到他们，并将他们视为真正的居民。

到达酒店，`X.` 松了一口气，发现 `Usoof` 和 `Abu` 已经脱了靴子，正轻巧地穿过院子。然后他准备自己自己的午餐，接着是洗澡。为了这样做，必须经过许多目光的注视，因为浴室在不远的地方，到达那里必须穿过整条走廊。这条走廊通向卧室的门，坐在门前的人——正如 `Abu` 所评论的——就像市集上摆摊的商贩一样。长椅是豪华款式，有短座垫和长可移动扶手，坐在上面的人们伸着赤脚。女士们也坐在那里，`X.` 事后得知那并不被视为便装，即当地的纱笼（`sarong`）和卡巴雅（`kabaya`）。沿着走廊走第一步需要一些勇气，但除非别人看起来也觉得这很奇怪，否则事情很少持续显得怪异，由于这些斜坐着的游客靠在那里无所事事，甚至不看书，神情无忧无虑，这并不让他感到困难。

他的午餐或许是当地生活的第一次揭示，这顿饭在华丽的餐厅里吃。这种第一顿饭的详细描述在之后是不需要了的。这种饭餐的基础，可以说是米饭，而伴随米饭的是数无数的菜肴，鱼、肉等。当 `X.` 意识到时，这种比例显然有所降低，这只是对马来咖喱的字面且夸张的解释，如果没有那些配菜，咖喱是不完整的。

## 第六章。正式的拜访。

午餐后，`X.` 去兜了车。巴达达的所有最值得关注的特征都在指南书中详述了，因此建议只提到那些与英国殖民地城市不同、且令旅行者认为值得的几点。主要的一点是，所有居民的房屋都建在高马路旁；不像在新加坡那样，有坐落在自己院子里的隐蔽豪宅。所有的房子都*显而易见*，以至于那些社交活跃的人在傍晚开车散步时，通过开启的灯光，一眼就能看出谁在家并准备好接待。而那些未准备好招待的人就坐在半黑暗中。这些房子缺乏隐私的程度，正如酒店的门廊一样。

马路两旁种着高大入云的树，它们的存在证明了这座城市并非雨后春笋般生长。没有遇到任何欧洲人；后来得知，这是因为在这个时间他们都在睡觉。起初看起来这里没有商店，但仔细观察发现，商店就在一些私人住宅的同一个屋顶下，且它们离道路较远。英国教堂显得空冷清清，关闭着且无人问津。也许是司机在告诉旅行者那里从不被使用时，是在诽谤这个社区。普通的马车是一种*双向背坐*（`dos-à-dos`），一种像倒过头的爱尔兰车一样不舒服的交通工具，但酒店提供了优质马车。

随后，我们的旅行者提议去拜访`Resident`（驻守）——当地的权威——并递上介绍信。他被告知在晚上`7.30`之前不能拜访，而且必须穿礼服。在在大天化日之时在酒店里穿上礼服，并在晚餐时间出门拜访，这似乎是一件荒谬的事；而当他召唤`Usoof`来协助他时，那位面色严肃的个人带着一种无声的怜悯，看着自己的主人在一个异国他乡被迫做这些不可思议的事情。

然而，当 `X.` 穿戴得像是要外出用餐一样时，他心下发虚。他觉得，在晚餐时间点这样去一个陌生人的家里，而不表现得像希望被留下来吃晚饭，是不可能的。于是，他羞愧地解开了白色领结，让`Usoof`为他提供了一件晨礼服。然而，这种担心本可以避免的；拜访并未真正发生，因为在通往`Resident`住宅的路上，他遇到一辆迎面而来的马车，里面有一位先生和三位女士。事实证明那是`Resident`和他的妻子女儿们。发现马车停下来真是一个意外的惊喜，旅行者承担了颇为困难的任务：在黑暗中自我介绍并解释自己的装扮。`Resident`英语非常好，他非常热情友善。他很抱歉不在家迎接预中的拜访，但他必须参加一个为纪念`Lomboh War`英雄`General`而举办的招待会。接着，这位高级官员表示希望 `X.`已经获得了他的许可，并告诉他当到达`Buitensug`（那是他管辖范围的边界）时必须更新。`X.` 注意到`Resident`没有穿礼服，心里暗自庆幸也没有穿，否则在马车离开时，他看起来就像个没吃上晚饭而失望的人。

酒店用电光照亮得极其华丽，大理石餐厅更是奢华得有些俗眼。如果 `X.` 考虑到自己的方便，他本该戴上黑色太阳镜，但实际上他担心在来到陌生国家的第一天表现出更多古怪倾向会惊扰他的随从者，因此他在吃整顿饭期间像猫头鹰一样眨着眼睛。没有他习惯的`punkah`（风扇）也是一种考验。然而，不必担心在桌上过度放纵而发热，因为那些冰冷的椰子油菜肴对任何不雅的食欲表现都是很好的克制。

用餐结束时，酒店老板告诉 `X.`，巴达达的`Resident`想通过`telephone`与他交谈。如果说有一个地方让他显得不得光，那就是在那个可怕的、嗡嗡的、含糊不清的仪器面前。在经历了介绍性的“谁在那？”以及重复*令人作呕*的询问身份信息后，你的耳边会响起最令人心恼的轰鸣声，充满了意义却又传不出任何信息，以至于电话那头似乎在嘲笑你，他的语气听起来如此令人生气，你恨不得扔掉电话冲向他。然而，在这一次，`X.` 明智地将整件事交给了老板，老板随后告诉他，`Resident`邀请他参加在`Concordia Club`举办的场外音乐会，以纪念当时的焦点人物`General`，并且如果他愿意的话，一位英国朋友稍后会来酒店接他。对于这样一份热情的邀请，唯一的回答已如期传达。

根据他自己的叙述，`X` 一生都是一个非常幸运的人。无论他去到哪里，他总是能像俗语说的那样，“脚着陆”。在这次探险中，他的运气没有抛弃他，随着他的同胞的出现（准确地说，这一已成为历史的事件发生在晚上`9 p.m.`），了一个新的开始，开启了事件链的第一环，这链链最终幸运地将他带到了见过的最美丽的国家。从以后，`X.` 对电话的看法一直变得友好许多。

## 第七章。Concordia 俱乐部的音乐会。

这位旅行者自然对协和俱乐部（`Concordia Club`）的景象留下了深刻印象。灯火辉煌的美丽园林里，人们漫步或坐着，仿佛置身英国的夏夜一般。但正如在东方，健康和饮食观念在任何在那里居住过一段时间的人心中都占据着极其重要的地位一样，最令这位陌生人惊讶的是，那些在这片危险土地上树下徘徊的`flaneurs`（闲逛者）对发热表现出近乎鲁莽的漠不关心，仿佛这里是家乡赫灵汉姆（`Hurlingham`）无害的草地一样。当他随后从一位女士那里听到这让他让他松了一口气——他向她表达了这种惊讶——医生们宣布这个户外音乐会季节确实是感冒和发热的高发时期。

驻守官及其随同人员坐在通往俱乐部的大理石阶梯顶端的一个圆桌旁。这组中的每人都轮流介绍给`X.`，随后他荣幸坐在主人的右侧，从而充分有机会享受周围的新奇感和乐队出色的音乐。当聚会成员围坐在桌边时，其中包括该国一些声名显赫的人物，这些人对近期事件有深入了解，对话被证明既有趣又富有启发性。

于是，这位英国人听了关于巴里尼战争的故事——在那位将军指挥下荷兰军队遭受的惨重失败和屠杀，那位将军最终扭转了局势，今晚所有人聚在一起是为了向他致敬。`X.`听着人们讲述当地人无与伦比的背叛、士兵的苦难，以及欧洲人进口武器向敌方提供的援助。针对后这一事件，人们发表了严厉的评论，在场的一些人坚持认为罪祸首是一个来自新加坡的英国人。战争的气息在弥漫——每个人都在谈论战争，这件事给`X.`留下了如此深刻印象，以至于在他停留期间，无论走到哪里都能听到人们对战役的讨论，他认为在单独的章节中给出关于近期战争的种种传闻可能会感兴趣。

所有在露台上参加聚会的人都说英语，这让`X.` 感到宽慰——随着新客人加入圈子，他们按照美国流行的精确方式被逐一正式介绍给在场的每位成员。同样，当任何个人起身离开时，他都会向聚会的每个成员逐一道晚安。

当我着手编写关于`X.`如何前往爪哇的小记述时，我本打算按顺序安排他所见和所闻，但从他观察方式的性质来看，我发现是不可能的，因此必须将他接收的每一个印象和听到的有趣事实按照他们出现的方式进行记录，而不考虑它们是否有明显的联系。由于这份草稿的主要目的是帮助那些打算在我们邻国这个美丽岛上度过短假的人，这种小小的原创性可以接受。

因此，在此场合旅行者得知，与他以前对此事的想法相反，文官的薪水非常低，尽管其在考试标准等方面与我们的印度文官团相当，但薪资和养老金的标准远低于其原型。在这里可以提到一点，以说明海军军在荷属东印度预计扮演的重要角色：所有中尉都必须通过马来语考试。在荷属印度水域指挥舰队是该兵种的荣誉，最卓越的海军军都向往这一目标。荷兰在东方殖民地的总督在任期内被称为阁下。在那里担任指挥的将将不仅在指挥期间拥有相同的头衔，还有权终身保留这一头衔。

在交谈中，驻守官友好地告知`X.`，不必因被迫获得旅行许可而感到恼恼，因为事实证明即使是他自己的同胞也必须这样做，他最近已在所有轮船和酒店发布并张贴告示，以免在这件事上产生误解。音乐会结束后，在一个极其愉快的夜晚之后，`X.`被介绍到和谐俱乐部（`Harmonic Club`），并在那里吃了晚餐。

这里和协和俱乐部一样，是一座拥有大石石柱子和地板的宏伟建筑，比旅行者早期对华丽东方的任何想法都更加符合。和谐俱乐部是在爪哇作为英国殖民地期间建造的——他的信息来源，那位英国人叹了口气。没多久，来者也叹了口气，在见证了这片光荣国家的美丽后，他想起如果不是由于以前某些统治者的盲目、不听取当地知情人士的建议，英国本可以拥有另一个印度。但由于国家的自然美景因普遍繁荣和满足的景象得到了增强和完善，一位英国访客发出这样的叹息，是现任所有者能获得的最大赞誉。

`X.`在爪哇的第一天结束了——在丛林中长时间隐居后，他向自己承认这是一个足够愉快的一天——毕竟，他最后的思绪停留在那里，那片快乐的丛林及其友善的居民——在他眼前，是由房间角落里用木箱围成的围栏遮挡后的两个无生命的包裹所代表的。这些是忠诚的`Usoof`和`Abu`，它们早已安息——遗忘了在新国家第一天所有的烦恼。

## 第八章

### 关于 LOMOH 战争。

龙姆赫（`Lomboh`）是爪哇岛东部的一个岛。龙姆赫国王没有按照预期来到巴达维亚（`Batavia`），经过一些往来后，附近地区的驻守官被派去见他。

在——以一种典型的东方方式——承诺接见他，随后未能兑现——让驻守官等了一周后，他终于发来信息拒绝会面。于是，部队被派遣了过去。但在他们出发时，由于引发了贯穿整个后续事件过程的争执，冲突不可避免。负责指挥的将军资历低于他所属的将领。最终通过任命第二位将军达成了妥协。

当远征军到达目的地时，巴厘尼人（`Balineri`）对这种武力展示感到非常惊讶，并假装完全不懂他们为什么要来。这一意想不到的局面转折最终以一场大“套近乎”结束，并演变成了社交活动和拍照，照片中国王的将军和其他远征军的其他首领都出现在一张大合影中。这张照片被送到布滕斯尔格（`Buitenzorg`）——政府所在地——作为恐慌并非真实的证明，并展示了远征军能够如此轻松地抵达、观察并征服的外交手段。

照片现在已无法购买。在庆祝和摄影之后，荷兰军队在宫墙旁扎营，指挥将军正式报告此事已得到解决。收到这一好消息后，总督非常高兴，于当晚举行了一场晚宴，餐后，他站在台球桌上发表了短辞，宣布了龙姆赫事件取得了不血的成功并圆满结束。

部队驻扎的宫殿类似于村庄——一个由巨墙包围的房屋群。荷兰人每天在村外举行阅兵和演习，试图用他们的温彻斯特步枪和野战炮惊呆当地人。对此，当地人表现得非常惊讶，带着极感兴趣的兴趣检查这些现代武器，并对其构造和成本问了无数问题。后者几乎是当地人脑海中浮出的第一个问题。

巴厘尼人一定是高明的演员，因为在那道欺骗性的墙内，他们一直拥有数百支温彻斯特步枪和许多野战炮。那些墙是欺骗性的，因为墙上布满了射击孔，孔洞被砂浆巧妙地封住了。

一个晚上，危机降临了。官兵们在玩斯扑牌时——穿着纱笼等休闲服，光着脚——遭到了袭击并几乎全军阵没。当这些可怜的人向墙下寻求庇护时，敌人投掷手榴弹将他们驱散。随后是大规模的恐慌和逃窜。那些成功实现有序撤退的逃亡者躲在他们营地与另一支部队营地中间的一座庙里。直到那时，他们才充分意识到这场可怕灾难的严重性，因为他们那里遇到了另一支部队的残弱士兵，后者正战斗着向他们求救——他们也遭到了阴险的袭击。

但这还不是全部，留在沿岸的第三支部队尚未收到任何警告。这支队伍对灾难一无所知，向最近的营地出发，还没来得及转身，射击孔里的大炮就开了火，几乎将他们消灭，只有少数人逃回船上。

当这一可怕消息传来时，荷兰人和他们的朋友（整个文明世界）深受影响，这已成为历史事实，在一段时间内，布滕斯尔格和巴达维亚陷入了某种恐慌之中。在与欧洲进行电报通信，以及某封反对采取迅速行动的消息幸运地遗失后，总督采取了一项民意措施，决定派遣所有可用兵力前往战场，并提供一切可能的援助。

这些得到了执行，荷兰军队随后扭转了局面，在某种程度上报了同胞之之仇。但代价并不小，因为爪哇——其政府非常依赖军事展示——几乎已经无兵可可用。作为这一点的说明，据记载在这场战争期间，德里苏丹选择访问巴达维亚。由于只剩下两个营团，人们认为让他知道真相是不明智的，因此当他在首都用餐时，士兵们先从他面前走过，然后乘火车去代表其他营团，并在第二天他访问布滕斯尔格时再次从他面前通过。

关于龙姆赫老苏丹在他美丽的宫殿被毁时流泪描述，以及胜利将军带走珠宝和数百万财宝的神奇故事，听起来更像是《千夜一夜》中的篇，而非当代的史实。相比之下，勇敢的荷兰士兵所遭受的极端苦难的描述听起来更现代，且极易轻信。

战场距离爪哇港苏拉巴雅只有半天路程，爪哇和荷兰筹集的资金足以支付整场战争的费用，但管理如此糟糕，以至于官兵们只有米饭吃，在那个产生疾病的气候中，晚上无遮蔽地在地上露营。

## 第九章

### 布滕斯尔格

在他抵达的周日下午，`X.` 拒绝了一份前往剧院的热情邀请，决定动身前往布滕佐格（`Buitenzorg`）。他觉得自己在一楼的房间里闻到了除了其他明显气味外混杂着发热的味道，而 `Usoof` 和 `Abu` 不仅无法洗澡，甚至无法把衣服送去清洗。各种理由与气味的交织令人十分强烈。

这里可以提一句，这在当地和任何其他地方一样合适：爪哇所有的活动，从总督的招待会到巡回表演，都在周日举行。火车于下午 4:30 离开巴达达，`X.` 于六点到达布滕佐格。

关于布滕佐格的误导性描述太多了——它是爪哇的华盛顿，让 `X.` 被深深地欺骗了。那里确实是一个美丽的地方——事实上精美绝伦，但当一个旅行者付了钱却得不到人类的舒适时，他对自然之美是难以满足的。对于一个长期被半岛茂密丛林所困的陌生人来说，旅途中中最令人愉快的特征无疑是那长片开阔的土地，让他想起了家乡窗外掠过的牧场和田野。牛群和小马增添了这种幻觉，`X.` 几乎无法抑制内心的喜悦赞叹。

### 抵达 Belle Vue 酒店

旅行者被反复告知，务必在 `Belle Vue` 酒店获得一间房间，如果可能，最好是一间能俯瞰后方著名景观的房间。这通过电报达成了。抵达后，一辆由三匹小马拉的马车将他送到酒店——那是一座位于优美位置的简陋建筑，处处充满了可能。

著名的后露台房间位于入口对面的院子深处，安置好后，`X.` 对窗外的景色非常满意。窗户正下方就是铁路线——下方是一条宽大、平缓且浅浅的山河，一半当地人似乎都在那里沐浴。远处延伸着一片连绵不断的、风景如画的村庄景色，散落的红屋房屋在棕榈树和其他优雅的树木间若隐若现。再往外是山——山上有五个明显的糖锥峰，当山峰在悬挂的云层中交替出现和消失时，数数的时候必须时刻盯着。是的，这景色绝没有被高估，`X.` 庆幸自己来了。

### 晚餐体验

`Usoof` 和 `Abu` 拒绝考虑任何美事，只能对河里沐浴的人感到惊恐并惊呼，这些人显然冲击了他们对得体的观念。他们的主人对这些评价并不感到意外，但他自己的观点更开阔，道德直觉或许更迟钝，而且经验教会了他关于罗马和罗马人的禁令在得体上的正确性。但尽管如此，可以肯定的是，即使是最温和的伦敦郡议员，也无法在看到那条河流而不受到心理冲击。



在走廊上尽情欣赏了景色后，他换上一件黑色大外套吃晚餐，随后他发现这让自己显得格外显眼，于是他穿过院子进入餐厅，准备享用鲜鱼、羊肉和其他当地特产大餐。尽管汤已经放在桌上变凉，客人们仍坐在外面的小桌旁，喝着金酒苦味水。`X.` 不想要（正如 `Clark Russell` 会说的那样），他在风中徘徊，几秒钟后——看到晚餐确实准备好了——他坐了下来。这个孤立的行为让他几乎和他的外套一样显眼，那件外套在阴郁的光彩中也显得格外孤独。

不久其他人也效仿这位陌生人的做法，晚餐开始了。紧接着是一段幻灭期。没有蒲扇（风扇），灯光刺得人睁眼，而且食物——所有的食物——都是粗糙、油腻且冰冷的。等在那里的汤是种所谓的罐装汤，这是一个老朋友，`X.` 原本希望把它留在丛林里直到他回来。这些汤和其他菜肴，本不会变得那么重要，但由于酒店的老板——一个傲慢的绅士（`X.` 事后得知他是赛马俱乐部的主席）守在门口，一排仆人端着盘子从那里出来，严密监视着每位客人吃了什么，并用鹰利的眼睛察觉那些失败的食客试图用刀叉掩盖的无法下咽的残渣。

用餐过程中最有趣的事情是一对老英国夫妇的对话，他们以一种典型的英国游客风格似乎以为自己是独处的，而周围的人只是蜡人，既听不见也无法受到他们所说的话的影响。“噢，他们怎么把鱼浸在油脂里，”女士会惊呼道；或者，“这肉不错，但坏了，是的，完全是在烹饪上彻底坏了；看啊，亲爱的，它是（怀疑地嗅了嗅她的盘子），它完全浸透了油脂——噢，真可惜，亲爱的，你怎么能吃得下去——但你什么都吃，”，”说话的人喋喋不休地继续道，“因为你昨天在那艘蒸汽轮上吃那条鱼时，它已经快烂了——在我们出发前，我在舱房里就闻到了，等等，”等等，还有很多类似的话。对于所有这些家常闲话，她的同伴没有回应，而是继续吃他的晚餐，仿佛习惯了这种伴奏一般。

## 咖啡事件

`X.` 忍住不笑已经竭尽全力了，由于担心伤害他人的感受，他在老板看过来时又盛了一份，并对同胞的行为感到异常“火大”。然而，更糟糕的事情在后头，在晚餐结束后，当那些“小伙子”送来按照当地习惯冲泡的咖啡——杯子里只有几滴咖啡精，这种做法在当地很常见——由于杯底只有几滴咖啡，必须用牛奶或水加满——这位英国女士无法抑制自己的愤怒，她大声责备仆人放得太少，因为“咖啡应该是便宜的”，然后把杯子里的内容倒成两份，一份自己的，一份丈夫的，一边笑着说“我们要喝咖啡，不是别的。”

这时当她喝着那满杯咖啡时，不情愿地意识到自己犯了错，女士进一步询问仆人：“你们在爪哇总是这样喝冷咖啡吗？”仆人在这种“抢劫”发生时只能被动接受——因为全场客都在等第二壶咖啡——用他仅有的英语单词回答道：“是的。”`X.` 拥有既能听又能看到一切的优势，在看到自己被剥夺了餐中唯一可能美味的部分时，他狠狠地瞪着，甚至觉得可以用餐巾和面包当作弹弓和石头来引起干扰。那个当地人的“是的”似乎平息了女士开始感尴尬，她胜利地惊呼道：“天哪，什么地方啊。”然后丈夫不舒服地揉鼻子，引起了她的注意，他的贤妻惊呼道：“亲爱的，你感冒了，我们去睡觉吧，”他们走了。`X.` 以及可能的其他人，对人们在吃了像这对夫妇那样的东西后还能睡觉的想法感到满足，但他们绝不会睡着。他们也没有睡，正如后续所示。因为这对夫妇也有一间露台套房，而这间房间与 `X.` 的房间只隔着一层薄墙，尽管他不想听，但第二天早晨迎接他满足的耳朵的第一句话是：“噢，亲爱的，我昨晚过得太糟糕了；我没合过眼。”`X.` 没有再听下去，他小心地把头埋进枕头里，以免被卷入更多的家事；但他已经听够了——他报仇了。

清晨，`X.` 出发去探索。自然而然，他的第一站是那些奇妙的花园，这些花园是世界之首，也是来自世界各地自然学者的聚集地。在这样一份速记中，若试图描述这座花园的奇观将是自妄的，它是东方奇观之一，值得特意前往爪哇岛一游。在散步期间，旅行者在每个转角都对当地人的富足感到惊讶：瓦顶顶的房屋、果实累累的果园和花园，而山羊和羊随处觅食。在街道上，每个人似乎都在卖东西——似乎已经没有人在买东西了——他们卖着最诱人的水果和蔬菜，以及各种花卉。这里人口众多，在城镇四周延伸着一排一排紧密建造的土著房屋，在每个角度和位置上背向而，这表明人们一定生活得团结在一起，*全家人地*或更确说是*成群地*，这与马来村形成了鲜明对比，在马来村，通常每户房子都位于自己的围合院落内。但在那里他们拥有无限的空间，而这里显然他们拥有无限的人口。

由于自己在一个土著族群中过着孤独的生活，`X.` 比普通旅行者更倾向于注意到这个国家及其周围的环境也是自然的。他听过许多关于他们受到荷兰人压迫以及生活条件艰劣的故事，因此当地人的真实面让他感到惊讶，随着他在爪哇岛看到的越多、走得越远，这种惊讶与之增加。至于爪哇的高层生活，对于任何去过那里或了解该国家的人来说，其社会状况是众所周知的。但无论此前听过多少，每当一个普通的英国人第一次在现实中面对这些情况时，难免会感到震惊。与当地人通婚不仅被纵容，而且几乎受到鼓励，在高级社交圈中遇到这些婚姻的后代并不罕见。有些情况是，位居高位的人将其子女合法化，在多年的非正式交往后，送它们的母亲走向祭坛。许多孩子的母亲在荷兰接受过教育，未来可能进入政府部门，而她们仅仅是居住在村子里的土著妇女。出身的偶然在攀升官位时很少被视为阻碍，混血背景对于这种身份来说也不是任何障碍。`X.` 在访问期间观察到了许多此类实例，尽管这种事态在他看来相当奇怪，但他不得不承认，从荷兰人的角度来看，这有许多且有力的理由支持；关于这种问题的*利与弊*显然超出了本书的范畴，因为这本书仅旨在为有意出行的旅行者记录那些值得观察的事物。

据我所了解，从布滕佐博（`Buitenzorg`）出发的远足很少，景点也寥寥；但下午，他开车去看了一块刻有印度教铭文的石碑，这是他注意到的关于如今穆斯林人民真实起源的第一个迹象。

傍晚，`X.` 决定拜访一位职位相当于英国殖民地秘书的官员，并请求他协助获得一张继续进入内陆旅行的通行证。尽管被警告不要在下午 7 点之前拜访，但在黄昏降临时，旅行者感到紧张且坐立不安，无法真正相信自己这么晚拜访是正确的，于是六点时，他正走向那位高级官员居住的看起来非常简朴的住所。一眼就足以证明他错了，而他的信息源是对的，因为在他面前，在走廊旁房间的一个桌子旁，他的主主还穿着睡衣——还没有开始晚洗漱。然而，尽管 `X.` 感到自己犯了*失礼（gaucherie）*，但这种感觉完全源于他自己的意识，完全不是来自被他打扰的绅士，因为对方脸上没有一丝恼怒或惊讶的迹象，就好像一个陌生人和外国人的不期而至是日常发生一样，他以礼貌而热诚的态度欢迎了他。

这位官员像旅行者见过的任何人一样平易近人且知识渊源，`X.` 在谈起他时总是充满热情。他带着真正的礼貌立即放弃了正在进行的工作，没有对桌子最后顾一眼（这种顾一眼往往会破坏类似牺牲的优雅），并立刻对客人的事务表现出极大的兴趣。关于他的通行证，官员很快地安慰了他；在得知他与海峡对岸政府有某种联系后，立即承诺为他办一张特别许可，使他能够随心所欲地旅行，并确保与他接触的人都会提供帮助。尽管此时 `X.` 依靠自己安排行程的能力，可能没有看重这张许可在未来将起的作用，但在旅行结束时，他乐意地承认它证明了极大的用处，并且不止不止一次，他觉得有必要向那位周到提供这种许可的人表达感激之情。

*关于*拜访时间，这里可以提到，这是许多英国人会碰壁的一块社交礁石。我使用这个航海比喻是深思熟虑的，因为不久前，甚至有一位希望遵循习惯时间的英国海军上将，在五点钟拜访了荷兰海军指挥官。那位荷兰海军将当时没有穿正装，且打算等到七点钟才换衣服，他拒绝在这样一个不寻常的时间接待他，而着装问题——这在英国海军中一直是首要问题之一——当时便变成了一个相当棘手的问题，直到通情的调解者为更成功的访问铺平了道路。

正是这种习俗让 `X.` 在第二天感到了窘迫。当时，他收到了承诺中的特别许可证——一份以总督本人名义要求所有官员协助他的文件。他认为，自己应该去拜访签署文件的统治者，并在对方的名册上签名，以示感激和尊重，这样做才是合情合理的。

由于这位旅行者并没有打算会任何人，也没有试图进入那座坐落在著名花园之中的华丽宫殿，因此似乎没必要为拜访的时间感到烦恼，他觉得将此作为散步的借口，并融入下午的闲游中很好。于是，大约下午 5 点，他发现正走在宽阔的大道上，道路旁是成群觅食的鹿——对于任何多年来只见过这种野外生物（除了某一次）的人来说，这是一个非常新奇的景象。但我必须忍住想要离开那条通往面前宏伟建筑的宽阔道的冲动，正如我稍后所做的那样，我希望尽快结束这一段，因为记录下 `X.` 这位一直以自己的 `savoir faire`（处世之道）为自豪的人，现在如此频繁地陷入尴尬境地的情形，确实并不令人愉快。

当他靠近门廊时（那让他不禁想起了赫特福郡郡维卢拉姆勋族的领地戈尔汉伯里），这位陌生人并非真正看到，而是察觉到主阳台上有两个坐着喝茶的身影。他几乎感觉到对方的目光正带着惊讶和戏谑注视着他。随着他在没有丝毫抬头的情况下逐渐靠近台阶，一种神秘的方式向他传达了信息：那两位是女士，而且她们穿着的是纱笼（`sarong`）和卡巴雅（`kabaya`）！

他该怎么办？他不能转身逃跑，也不能偏离宽阔的小径像个普通的闯入者那样穿过草地——而且，在他感到疑惑的同时，他的脚步依然从容地向前迈，感受着字面意义上最真实的局促感。每一秒都在无情地带他走向更近，尽管为了躲避这种尴尬的时刻，他或许连自己都没察觉地放慢了原本从容的散步，直到他的脚步几乎只是在标记缓慢流动的时间。然而，这位访客交替地望向树顶和宫殿的屋顶，仿佛那里正发生着令他着迷的事情，最后，他不得不意识到自己已经到达了那宏伟楼梯的最下台阶。

`X.` 向我保证这是事实，他一次也没有低过头，也没有聚焦于眼前这几个人人，尽管最终茶几距离他只有几码之遥。这位陌生人站在那里，神情空洞，那种表情足以让蜡像馆的演员大获其青；他希望并几乎祈祷能有某位仆人出现，接过他的签名或名片，并让他回到酒店那毫无情趣的隐逸中去。那里没有门铃，也没有仆人来，沉默终于变得无法忍受。最后，茶聚那边传来了解脱，因为一位女士突然尖锐地大喊了一声“男孩”。这一爆发之后，紧张的气氛得到了缓解，传来了椅子被匆忙推开的声音、小脚步声以及纱笼的摩擦声，这让 `X.` 推断出发生了某种撤退。

接着，一个慌乱的当地人出现了，他看起来像是被从工作中匆忙叫来的园丁（也许是负责割草机的），他用一种奇怪的方言滔口吐露，疯狂地指向另一排台阶和另一扇门。跟随这位真正的 `deus ex machina`（机械天神），`X.` 被带下了那些宫廷般的楼梯，绕过转角上了另一段台阶。在那里，园丁推开一扇门，似乎打算放弃对陌生人的监管，准备再次回到他的机器。但 `X.` 坚决拒绝独自进入那座宽敞的大厅，甚至拒绝留下来寻找用来签名的书，因为他感到自己听到的匆忙撤退并没有越过最近的柱子；他每留一刻，那些逃亡者就会在想他在做什么，而哎，他们的茶已经快凉了。

于是，他将名片——他唯一的诚意保证——塞进了这座东方宫殿唯一侍从者肮脏的手里，然后逃了——但他希望自己逃得有尊严。他迈着自省且从容的脚步走在大道上——欣赏着右侧和左侧的风景——头也不回，尽管回头看一眼的欲望如此强烈，以至于后脑颈真的发疼，但他战胜了这种冲动，最终离开了那些大门，没有进一步满足他第一眼无意间看到时引起的好奇心。但只要他留在爪哇答，他就再也没有在黄昏前拜访过，那是更方便的时间，那种 `contretemps`（意外）不太可能发生。

## 第十二章

### 一座示范庄园

`X.` 得知从 `Buitenzorg` 出发的恰当行程是乘坐马车 `via` `Poentjuk` 到达 `Sindanglaya`，在那里确保好一间楼房后，应在 `Gezondleid's` 所稍留。旅程的下一阶段是前往 `Tjandjoer`，然后到达 `Garvet`。在 `Garvet` 呆一周后，再次前往 `Djoedja`、`Solo`、`Semarang` 等地，但旅行者已经对爪哇岛的酒店生活厌倦了，因此决定立即接受收到的一份友善邀请，住在离 `Soekaboemi` 不几英里的一个庄园里。在乘坐头等车厢行驶了几个小时后（这一事实值得记录，因为即使买了了头等票，也很少能有这样的住宿），他如期到达了指示他下车的车站。在这里，他的房主已经派了两匹小马接他，一匹供他自己，一匹供他的仆人用，还有几个苦力搬运他的行李。于是，`Abu` 被留在站长的家中照看剩下的行李（数量惊人，运输费用几乎等同于主人的头等票价），`X.` 在 `Usoof` 的跟随下，开始了通往目的地的十英里骑行。道路非常崎岖，在路程的前半段，穿过一片目力所及、种满了 `padi` 的开阔土地。那些小马并不在意石子路，有力地向前走，仿佛习惯了在坚硬的高公路上驰骋。过山谷后，路线开始攀爬山脊，庄园就坐落在海拔 `2,000` 英尺的山顶。在爬山的几乎整个过程中，景色如此壮丽，以至于旅行者不断惊叹地让同伴停下来观察。正如前文提到的，`Usoof` 是当地人，他装出一副主人般漠不在乎的神情注视着，只是提醒他的主人，他一直说过这里是一片非常好的土地。数英之外，`padi` 田向展开来，在远处逐渐收窄，在这片翠绿色的毯野中，星星分布着一些色调较深的绿色小丛，这些是环绕在幸运的地主们房屋群周围的树木。每隔一段时间，在下方铺开的绿色毯上，就会闪烁的水带在阳光下像银子一样发光。山丘也都种满了 `padi`，看起来像多草的山坡，背景由山顶的梯田组成。它们层层叠叠地连成山脉，直到在最远处，高耸入云的山如巨人般屹立在所有山峰之上。这确实是一个值得远道而去的奇景，一种未旅行过的眼睛甚至无法隐约想象的绿色财富。如果报酬是这样的，那么旅途的劳顿、油腻的菜肴或没有面包的餐食将微不足道。即使通往这里的路只通向一家最简陋的路边旅馆，这景色也让这次远行变得值得，但对即将访问一对以款待外客闻名的夫妇的期待，让这种喜悦倍增了。房主是一位同胞，幸运地娶了一位出身名门显赫的荷兰女士。几乎在山顶上，距离车站约八英里处，立着一座小小的小屋，挂着一个英国风格的招牌，上面写着“猪与哨子”字样。这里有点心等待旅行者，随后行程沿着一条丛林小径继续，不久进入了庄园的耕地坡地。这些坡地覆盖满了 `cinchona` 树，`X.` 后来得知这些树正在被茶树迅速取代。这时，在道路的一处凹洼处，一眼看到了下方的房子。看起来是一座小小的英国小屋，舒适地坐落在一个谷中，紧邻一条山溪。近距离观察发现小屋覆盖满了牵旋花和其他藤类植物，走廊封起来了玻璃。这在某种程度上让他想起了 `Boulter's Lock` 旁的一座著名的小屋，看到这典型的英式家居，心中涌起一阵奇妙的乡乡愁。溪流对岸立着一座独立的小亭，按照东方所有荷兰房屋的风格，专供客人使用。这栋附属楼通常被认为是长子的房子，但更多是建成并用于客房；在一个招待者和宾客都偶尔想要穿着最适合气候的轻便服装休息的国家，这是一个极佳的安排。一座乡村小桥连接了两栋建筑，桥正上方就是浴室，一部分溪水被引入其中，形成了一个天然的淋浴。溪流、桥和小屋，以背景的山丘和前景的玫瑰为衬托，构成了一幅画面，以至于 `X.` 渴望能把它画下来带走并收藏。这间小屋的内部像外面承诺的那样舒适且像家一样，而且，奇迹发生了！墙上竟然贴着真正的墙纸。这种在东方几乎闻所未闻的奢侈是女主人技艺的胜利，并且到目前已成功抵御了霉菌和潮湿的侵蚀。房子的主要特征是它看起来像家，其雅的装饰和陈设表明居住者是打算长留的。东方的大多数房子都有一种明显的临时避难所的气息，主人们只是在那里寄宿，直到他们能回到那些目前储存在“家里”的家具用品中。这是 `X.` 在这个世界上看到的第二个这样的房子，那里的主人看起来就像是住在那里的（另一处在 `Selangor`）。在这片理想之地，旅行者很幸运地度过了几天时光——在庄园里愉快地骑行的日子——他很快开始渴望这种，并看着茶树的种植，希望这最终能让善良的主夫妇带着财富回到故乡。这个海拔处的气候宜人、凉爽且令人精神振奋，可以遵循英国的时间习惯。不需要像在 `Pura Pura` 那样清晨 `5` 点起床骑行，`X.` 发现自己自己在早餐后大约十点开始骑行，不必担心阳光，这种完全的改变提升了他的心情，他在心中默默感谢建议去 `Java` 游玩的人。

## 第十三章

### 玫瑰之中

#### 农小屋生活

在河边的这间小屋里，生活是如此平稳而均匀，日子以一种愉快的节奏流逝，除了一种整体宁静的享受感外，没有什么可记录。然而，有一次远足值得描述：那是访问邻近处挂牌出售的庄园，此行让人窥见了乡间生活的典型侧面。他们在中午左右接到访客，在下过了一座陡峭的山坡后（当地人正忙着种植茶树），两名英国人发现了一座半隐在溪流弯道处的白色小方屋。

这栋建筑透着一种荒凉、凌乱感，而周围花园的状况更加剧了这种感觉；即使在离房子有一段距离的地方也能闻到玫瑰的香气，而在花园本身（如果那片荒地称得上这个名字的话），那股气味几乎令人窒息。那里是一片玫瑰丛构成的微型森林，缀满了迷人的花朵，那些玫瑰是 `X.` 自离开家乡后从未见过的。一切看起来都凌乱、破败且颓废；房屋、藤蔓植物、玫瑰丛、草地、鸽子笼，无不诉说着被疏弃以及缺乏修整的资金——而这种匮乏源于金鸡价格的下跌，这种不幸让许多优良的庄园遭受了，并沦落到如今所访问的这般荒凉荒芜的境地。但即便荒废且无人照看，它构成了一幅何等的画面！那是诗意死亡的实现——一个受害者在歌唱的溪水旁被玫瑰窒息。

#### 出意之外的主人

过了很久才有人人来，两位访客坐在门廊上感到有些局促和不安，因为这是他们对邻居的首次拜访，而那位领他们入座的当地人已经消失了，在错综的花园小径发出怪异的叫声，仿佛在呼唤他的主人回家。终于，在漫长的等待之后，沉默、悬念以及对谁会来、从哪个方向来、何时来的惊奇变得几乎无法忍受，这种荒谬的情境严重冲击了他们的神经，以至于两位访客都发出了短促的笑声，这可能源于同样的让孩子在教堂里表现不佳的紧张感——那是恶魔的直接诱导，诱人生出那种我们明知不该做事的欲望。

终于，在匆促地低语争论是否可以离开后，女主人出现了。她是一位高大、体壮的女士，外表是典型的荷兰人。她穿着常见的白色亚麻外套和短围裙（`sarong`），双腿是裸露的。她用荷兰语表达了热诚的问候，至少对 `X.` 来说是荷兰语，因为他对这种语言一无所知。他的朋友仔细地向他解释了这一点，他推断如此，因为女士发出了各种表示惊讶的喉音感叹，转过头看向他，仿佛他确实是一个值得观察的怪人。

#### 语言障碍

两人的对话随后变得流利起来，`X.` 完全被遗忘了，他感到被冷落并变得坐立不安，意识到自己极度厌恶这种被忽视的新奇感觉，而且还无法通过发言来吸引任何注意力。然而，他很快得知，我们所察觉的那些微小不便通常远比我们未知的不便那么令人不快，因为这时发生了骚动，那位好女士的丈夫从房子走到门廊时，人们纷纷起身。



这位绅士身材高且肤色深，留着灰色的尖胡须，像讽刺画里的美国人。他穿着一种奇怪的居家便装（`deshabille`），光脚松散地插在地毯拖鞋里，当访客的目光及到这里时，他们明白了为什么他的肤色如此深。在第一次问候后，主人（`X.` 后来了解到曾在政府担任过高职，为了种植而放弃了职位）转向他，开始毫无停顿地对他滔演起来。没有其他方式可以描述发生的事情了，因为他不断向客人倾倒语言，完全没有表现出任何回复的意思。

说访客感到不安只是对他感受的轻描描写——他渴望被认可，而现在他确实得到了。如果他允许主人继续说下去，却不告诉对方自己完全听不懂一句荷兰语，主人会怎么想他？他反复尝试阻挡这股词语的洪流，并用英语和法语解释，在徒无果后，冒着显得无礼和不经心的风险，`X.` 转向他的朋友，请求他把事情说清楚。朋友用荷兰语说了什么，但他似乎说错了话，因为这完全没有效果，主人继续他的谈话，可能全是关于他想要出售的庄园的优势。

## 揭示

随后，由于形势已毫无希望，`X.` 将神情固定在理性的关注上，等待他停下。但他并没有那么专注，以至于立刻听到好女士对他的朋友说了什么，导致他惊讶得像一样惊叫了一声，并带着压抑的笑声转向 `X.` 说：“没关系。夫人刚刚告诉我他是全聋，什么话也听不见，所以我说什么都没用，他同样也听不懂你的。”

“但夫人不能告诉他我不懂荷兰语吗？”`X.` 几乎绝望地惊呼道——但太晚了，因为此时他的朋友再次与女主人陷入交谈，除了再次对主人假装专注之外，别无他法。真是一种奇妙的境地，第一次去别人家里却表现得让你确信他很快就会相信你是故意要侮辱并耍弄他。`X.` 永远不会忘记那十分钟。

## 第十四章。加尔维特。

离开`X.` 庄园小屋后，他出发前往加尔维特。当火车到达目的地时，窗外的景色无疑是想象中所及的最美风景之一。绵延的稻田，背景是高强度开垦的丘陵，整片土地被细细的奔涌小溪流环绕，在四周环绕的阳光下显得清凉宜人。言语已无法描述旅行者眼中的景象，也无法以任何方式恰恰呈现它的美。这种景观完全是全新的，与在其他国家看到的任何景象都不同，也许只有锡兰或日本除外，值得从欧洲专程来此一看。

加尔维特的酒店是由许多小建筑组成的，散布在主建筑周围的花园里，或者在路对面的独立围栏内。`X.` 入住了其中一座小屋，本以为会过得相当舒适，直到对沐浴设施的检查令他打了个冷颤。晚餐时间到了，*自助晚餐*（`table d'hote`）也消灭了他的幻象。那里同样没有风扇（`punkah`），同样有刺眼的光线，以及接接一个半熟且湿腻的菜肴。那里只有几位食客，显然大多是住在酒店里的当地住客。这些绅士穿上了黑色大外套，为晚餐做了一番装扮。但他们忍受的苦罚是短暂的，因为在匆忙吃掉足够满足个人需求的食物后，他们就回到了自己的阳台，`X.` 很快就看到他们穿着睡衣、光着脚，正舒服地躺着。显然，文明的外壳并不薄到足以让人感到自在。

早晨，旅行者去拜访助理驻守（`Assistant-Resident`），对方非常友地接待了他，并提供了所需的所有信息。这在某种程度上干扰了办公室的工作，因为每当助理驻守向任何员工询问某地有多远，或者车费标准等时，被问及的人无论多忙，在回答之前都会立即跪在地上。摄政（`The Regent`）也正在拜访政府代表，并向他介绍了这位英国人。这位当地官员胖胖的的长相不错，但看起来并不算聪慧。

助理驻守非常友好地与访客自由讨论了影响当地人的事务，并给了他大量信息，这些信息由于他在 `Pura Pura` 的工作性质，让他产生了极大兴趣。对于对该主题感兴趣的人来说，爪哇的土地制度已广为人知，无需在此评论，但 `X.` 学到了一些事实，可以消除那些未研究过此问题的人对法律残酷或复杂的误解。事实上，这些法律似乎达到了简洁和简单，这正是对待当地农民时的极大追求。因此，在土地产之前之前人们无需支付租金。咖啡是唯一必须向政府出售的产品。所有土地都经过分类并缴纳固定租金，因此有了确保业主的成果不会被征税。任何人如果认为土地定价过高应属于较低等级，都可以投诉，且投诉会得到立即关注。尽管人口众多，但稻田的边界标记很少出现纠纷。所有者满足于长期的习俗和当地知识，他们对当地官员的依赖从没有失败过。所有新土地如果与政府土地相邻，就必须围起来，在所有种植园里，人们必须自己种树作为边界并进行维护。只需一份填满栏目并根据耕作和分类签字的权属登记簿，就能解决所有问题。最后，必须提到有一条金律：当地人不能将土地卖给本国以外的任何人，无论是卖给欧洲人、阿拉伯人还是中国人。因此，任何个人受投机诱惑，都不会通过其自私行为给邻居造成伤害或困扰。上述提到的这份权属登记簿随着土地的开发而逐渐填写并签字，从而对每块当地人土地的实际状况保持了准确记录。当最终签字且土地产出时，就会要求缴纳租金。这种简单的优势只有那些命中注定要扮演报喜者的人才能体会到——他们必须向无知的当地人口解释最后那部新土地法及其众多条款的优点，而这些人人是不理性的，顽强地紧抓着他们已经拥有并认为自己理解的头衔，固执地拒绝无论说话者表现得多么有说服力，去交换现存最先进土地法中能给他们的最新条款。

在与那位礼貌的官员面谈后，`X.` 离开了，思考着他听到的这一切，并带了一份备忘录，上面写着被推荐访问的附近感兴趣的地方。回到酒店时，旅行者经过了一个看起来像当地俱乐部的地方。一个在印度或半岛外站工作的英国官员，对于带着介绍而来的陌生人，做的第一件事就是提议让他入住俱乐部，除非有强力理由反对，否则他可能会邀请他吃晚饭。显然这里没有这种习俗，所以 `X.` 可以自由地在小镇上闲逛探索，没有什么更令人期待的，就是和那些穿着午餐服的受苦租户一起，重温昨晚那顿令人毛骨的晚餐。

## 第十五章。温泉与火山。

加维特（`Garvet`）似乎在夸耀那里的人口众多，因为那里有无尽的房屋——或者说是房群——密密麻麻地挤在一起，面对、背对、并排，给人一种几个村庄随意聚集的感觉。所有这些房屋都收拾得极其整洁利落，周围围着低矮的竹栅栏。几乎每栋房子都盖着瓦顶，而且档次优于半岛内陆地区的大多数房屋。街道干净得简直像经过精细打扫过一样，`X.` 在那次散步中决定，加维特是他见过的最干净的东方城镇——当然，除了 `Pura Pura` 的首之外。

人们对 `Tji Panao` 的温泉有很多议论，因此旅行者决定将那里作为他的第一次远足。他租了一辆由三匹马并排拉引的交通工具——这让他想起了年少时的时光，那时他会对家乡公园里一套时髦的装扮感到惊叹——在双轮小马车和自行车出现之前的，由一位著名的社交界和时尚人物驱着三匹并排的小马，`X.` 告诉司机前往 `Tji Panao`，并期待在像 `New Zealand` 泉水那样的温水中度过美味的半小时，那种泉水会让浴者离开时感到精神振奋、神清气爽。

然而，在这个国家，另一个失望等着他，这里大自然做了很多工作，而人类为了舒适却寥寥无几。温泉位于山坡上的一个小屋里。这间小屋有三个隔间。每个隔间里都有一个浅的砖池，里面可以坐下。热水通过管道引入这些池子，每个池子头部有一个入口。浴池周围的地面很脏，唯一的家具只有一把藤椅。浴池的水深大约有三英寸，在这些湿滑的砖块上，浴者不得不凄惨地坐着，身体下半部分浸在温水中，而上半部分则在上方相对凉爽的空气中保持干燥高干。`X.` 原本准备好在水里泡很久，并带了读物来打时间，但在这种情况下，简短地泡一下就足够了，他很快从椅子背上解下衣服，准备出发。

这些温泉附近有一栋有四间房间的建筑，显然是一座 `政府休息馆`（`Government Rest House`），家具非常齐全且舒适，显然人们是特意来这里使用温泉的。温泉泉具有巨大的潜力，只要花一点精力和金钱，它们就能成为一种享受，并成为一种收入来源。

从加维特出发还有一两个可以进行的远足，但唯一值得一提的是前往 `Tjiseroepan` 火山的行程。一天早晨，`X.` 与 `Usoof` 和 `Abu` 一起出发，因为他厌倦了独自观光；在得到亲切的 `助理居民`（`Assistant-Resident`）许可使用 `政府休息馆` 后，他开车前往 `Tjiseroepan`。道路非常好，路线不用说，穿过了一片美丽的土地。在这里，和处处一样，所有富裕的当地人都骑马。距离有十三英里。`Tjiseroepan` 是山脚处的一个村庄，他们计划第二天登上那座山。

旅行者受到了 `助理土长`（`Assistant Wodena`）的接待，这位当地官员在最后两英里一直疑疑神备地在马车前后骑行。在阅读了陌生人的证明信并发现他能说马来语后，这位当地名流变得非常热诚，并让 `X.` 免费入住 `政府休息馆`。这里配备了床、桌子等家具，但没有提供玻璃器和瓷器。

`助理土长` 带领游客参观了村庄，村庄是整洁的典范。每栋房子都位于花园里，种着咖啡、蔬菜和草莓。村长和其他几个人住在非常好的房子里，似乎有数不完的小马。村庄坐在一个坡上，耕种的山坡与意大利南部的景象有些相似。繁荣和知足的通常迹象随处可见，无论在这个村庄还是其他地方，当 `X.` 与当地人交流时，他找不到任何可以解释那种普遍观点——即爪哇人对他们的统治者具有敌意。

`休息馆` 证明很舒适，`X.` 带了自己的食物，由他的仆人烹饪，他难得享受了一顿热热且可口的午餐。他有很多机会与 `助理土长` 交流，对方非常愿意论述这个国家的习俗，并详细介绍了 `爪哇君公`（`Javanese Rajas`）复杂的礼仪，以及平民对等级所付出的异常尊重。他反过来问了许多关于 `马六甲` 和 `马六甲海峡`的问题，他的对话者能够提供他所需的所有信息。

第二天早晨，观光者和他的随从们骑马上山去看火山。这是一种像地狱般的火炉，恶毒的山口像从地底钻出来的通风口，喷出并嘶嘶着刺眼的蒸汽。整座山体呈硫黄色，空气中散发的气味令人作呕。`Usoof` 和 `Abu` 对这番可怕的经历感到非常恐惧，他们抓住他们的 `主人`（`Tuan`）的手臂，恳求他不要靠近那些他们显然认为是地狱之门的地方。

我觉得在记录风景给旅行者留下的印象时，已经对指令给予了足够的尊重，因此将省略关于他下山时所看到的一切描述。他将其描述为奇妙，一直读到这里的读者应该准备好承认这一描述的准确性。该小组准时到达加维特，赶上了前往 `Tassikmalaja` 的两点钟火车，从而开始前往 `Tjilatjap`。

## 第十六章。寻找母亲之之旅。

前往朱拉恰普（`Tjilatjap`）的程程如此不寻常，以至于单独成章。显然已经多年没有人从加维特（`Garvet`）前往朱拉恰普了，因为那里被称为岛上最不健康的地方之一。旅行者的正确做法是先去塔西马拉雅（`Tassikmalaya`）住一晚，然后从那里乘火车前往乔恰（`Djoeja`），再乘车到达波罗（`Beroboeddoer`），并在政府宾馆住宿。车程二十五英里。第二天早上，旅行者应该再开车十英里到达望格兰（`Magelang`），而行李则通过火车或牛车运。从望格兰出发再开车二十英里到达安伯拉瓦（`Amberawa`），从这里可以乘坐火车前往三宝（`Semerang`）或返回乔恰，然后从那里前往三罗梭（`Solo`），那是一段三小时的路程。

`X.` 被告知大家都走的是这条路线，但他坚持要前往朱拉恰普，尽管酒店的女主人向他保证，那里是该国发热最严重的港口。如果他当时知道像他后来了解的关于该地恶名的那许多信息，这位旅行者可能会改变计划。事实是，他只回答说他对发热已经习惯了，不在意。那时他并没有特别的理由去某个地方而不是另一个地方，因此驱使他朝这个方向走的地方足以满足他的目的了。

`Usoof` 希望开始寻找他的母亲。他不记得出生的村庄，但认为是在海岸附近的某处，考虑到这个国家是一个岛屿，这个说法有些模糊。在协助他的主人（`Tuan`）研究地图后，他惊呼道朱拉恰普这个名字听起来很熟悉，事实证明那确实是沿海的一个大镇。现在，他辩称，除非他以前听过，否则就不可能熟悉，而那只可能是在他在爪哇的时候，由于那时他只不过只是个婴儿，只有出生地附近的地名才是他熟悉的。

对于 `X.` 来说，去哪里并不重要，越是远离偏僻路线，就有越多机会研究当地人并了解他们的生活。因此，他乐意同意前往朱拉恰普。只有在所有计划都确定之后，才听说了那里发热的恶名。

旅程的第一阶段是前往塔西马拉雅（`Tassimalaja`），他们在两点离开加维特，到达那里时正好赶上晚餐。从在黑暗时刻和清晨的短暂逗留来看，这里似乎是一个很小的乡村小镇，但火车走得很早，没什么时间闲逛。第一个重要的停站是马奥斯（`Maos`），在那里必须换乘。乘客中有一位英国人，`X.` 十年前在纽约见过他。他正打算沿着正规路线前往乔恰（`Ojoedja`）和三宝。这两位英国人都是经验丰富的旅行者，交换了对爪哇的各自印象，并一致认为，无论他们去哪里，所得到的礼遇和帮助至少不亚于甚至超过了他们在游历世界其他地方时的遭遇。在马奥斯，他们分道扬扬，但命运让他们在前往新加坡的轮船上再次重聚。

旅途的另一位伴侣是一个学多才的荷兰年轻人，他通多种语言，证明是一个非常好的伴侣。这位先生显然对他在爪哇看到的同胞没有太大的赞赏。他同样无偏见地抨击那里的食物和生活方式，并宣布爪哇的荷兰人既没有消化能力也没有精力。他们实际上已经因为糟糕的食物和过度睡眠而半死了。这位健谈的伴侣还发表他对文官制度的看法，该制度已从那种任何人都可以被塞进去的阶段，逐渐发展到如今既需要大脑又需要兴趣才能进入该阶级的状况。一个人一旦进入（这些是那位健谈的荷兰人的观点），只要他保持安静并满足于在平庸的轨道上滑动，他的财富就有了。他必须盲从地遵循规定的规则并盲目地服从直属上司，放弃所有的个人良知和身份。如果他有自我晋升或帮助民众的打算，如果他节省政府资金并减少道路苦力或警察（这些人实际上在家里担任厨师、园丁或马夫）的数量，如果他试图树立榜样并放弃津贴，“那个人，”演讲者叫道，“完蛋了，最好立刻回荷兰。”

这就是他的旅行伴侣的观点，但他有什么机会形成这些观点的，以及这些观点是否有实际事实的支持，`X.` 并也不知道也不在乎，只要他觉得这个伴侣很有趣，直到他们到达朱拉恰普。在这里他的意见发生了一些变化，因为他那口若悬河的伴侣凭借丰富的经验，预订了酒店里唯一体面的房间，并为自己获得这个房间的計策感到得意。

当 `X.` 第一次在火车上宣布他要去朱拉恰普时，现场爆发了一阵惊叹声，他的同伴们显然认为他很古怪。如果他也解释了去那里的原因，这件事就不会有太大疑问了。那时他得知朱拉恰普曾是一个驻军镇，但由于士兵死亡率过高，发现必须放弃它。直到在马奥斯换乘之后，那个荷兰年轻人才承认朱拉恰普也是他的目的地，可能是不想在留在乔恰车厢里的同胞面前显得太古怪。

## 第十七章。继续探索——朱拉恰普。

中午时分到达了 `Tjilatjap`。这座小镇看起来规模宏大，街道两旁都种满了大树林荫。`X.` 一直走向酒店，在那里被分配了一间像马厩一样的房间，阳光洒了进来。如前文提到的，他随后发现他的旅伴成功抢到了酒店里唯一一个体面的房间，`X.` 对那个陌生人毫无好感，认为他利用自己对当地的无知占了了不公平的便宜。他只希望在控诉对方诽谤自己后，把他交给政府中最强壮、最易怒的那个文员，让他好好受一番“仁慈”的款待。

桌上已经摆好了准备好的午餐，看起来很不错。第二天，他注意到这顿饭每天在 `9.30` 准时摆好，然后一直搁到下午晚些。由于饥饿，远处的餐桌看起来十分引人下饭，`X.` 准备大吃一顿。但当他走近观察发现，每一道菜都固固地凝结在自己的汤汁里，他喜悦的期待便变成了某种厌恶。但其他人似乎并不在意，对面的一家人——父亲、母亲和女儿——吃起这些食物来，就像它们是萨沃酒店或 `Bignon` 厨房里刚出炉的佳肴一样。

稍晚一点，他溜出去抽根烟，试图说服自己已经吃过午饭了，访客发现了酒店的老板、他的家人以及一些受宠的客人在廊台上享受着蛋糕、看起来像是马德拉酒以及水果。由于在这个阳光暴晒的炉子般的房间里无法睡觉，旅人叫来了一辆马车出门兜风。他经过的每栋房子看起来里面里面的人都在睡觉，但这种寂静被在那些奇妙树荫大道上来回穿梭的忙碌当地人所抵消。

当天晚些时候，`X.` 出发拜访助理居民（`Assistant Resident`）。他在酒店得知这位官员在上午 `11 a.m.` 到下午 `7 p.m.` 之间是不见的——这是一个相当漫长的休养时间。

天色渐暗，`X.` 走到那栋房子，那是一个比 `Garvet` 的住所高级得多的。女主人和家人正准备去晚间散步，不敢在这么晚之前出门。助理居民显然是个非常年轻的年轻人，他热情地接待了访客，并提供了他所能所有的信息，承诺如果他想继续去内陆，将提供帮助。

应当说明的是，到达 `Tjilatjap` 后，`Usoof` 的记忆变得活跃起来，他想起不远的 `Jombong` 镇是他家 `kampong` 附近主要的地点。听闻后，助理居民答应给住在 `Soempioet` 的村庄 `Wodena`（当地土著法官）写信，那位法官可以让他住在自己家里。这正合了 `X.` 的心愿，他一直想找机会更多地看看 `Java` 的当地生活，远离那些酒店轨迹和温顺的古董商贩，这些商人在不同小镇之间大同相同。

当旅人正在拜访时，另一位访客到达。这位人物身份不，正是 `Landarad` 的主席。他们离开后，他热情地邀请这位英国人进入俱乐部，他们在那里玩了台球。这位伟人表现得非常好，非常乐意向同伴分享他想听的关于当地政府官员职责的所有信息。他了解到助理居民作为法官的管辖权非常有限，除了最微道的案件外，所有案件都提交给 `Landarad`。这位开朗官员所担任的职位显然非常合适，他满意地解释了自己为何必须经常旅行，以及在此期间可以获得多么丰厚的津贴。听者想，这津贴必须很丰厚才能补偿在 `Java` 酒店吃的一顿顿饭。但这一点上的同情被白费了，因为 `Landarad` 的主席提到了他们似乎都住的那家酒店，并称那里很舒服。

台球结束后，是时候回酒店吃晚餐了。这顿饭可能与其说是归功于灯光而非其内在的优越性，看起来比上一顿有所改进，如果用餐者没有把它当成火车站休息室柜台前的匆忙小吃那样让气氛变得不必要的舒服就好了。例如，在用餐过程中，有三四次访客来见那位礼貌的主席，他愉快地离开餐桌与他们会面，回到座位时，无论盛宴正处于哪个阶段，都能从容地讨论那些冷掉的菜肴。在这场糟糕的晚餐闹剧结束后，桌并没有清理，`X.` 注意到，直到晚十点甚至十点半，还有晚到的食客溜进来享用那些越来越没胃胃的残羹冷炙。`X.` 想起他的同伴在火车上说的话，心想对自己同胞在 `Java` 的消化能力（或说缺乏消化能力）的评价至少是有一定理由的。

打算去 `Java` 的旅行者需要记住的首要点是拿钱困难，因为没有人会看支票，那个国家的人不使用支票。因此，必须携带现金，并依靠银行通过挂号信寄出的定期汇款。在 `Garvet`，`X.` 第一次经历了财务困扰，是因为他信任了自己的那本由荷兰属民印度总督签署的特别许可支持的支票簿。他投资了一些 `Java` 马，以至于支出超出了所有计算。酒店的人不看他的支票，尽管他们确实用一种源于怀疑的谨慎目光审视着持有支票的主人。



他非常困扰，跑了镇上所有的主要商店和营业场所寻求帮助，并向商人们保证`bonaides`，而他们审视着他的支票，并像看奇闻一样把它传传，个人，他们以前从未见过。最后，好运以`Schmidt`的形象出现了。那些试图从支票中读出某些意义的人之一解释道，他相信这种东西在欧洲见过他们最好叫`Schmidt`。`X.`热热地赞同了建议，大家焦急等待他的裁决，尤其是主人，他未来的行程必须取决于这个决定，当目光敏锐的`Schmidt`宣布他确实见过这种东西，并慷慨地提供兑现时，他如释重负。就这样化解了，陌生人得以执行他的安排并偿还债务。记得感激之情的好的`Schmidt`。

# 第十八章 任务的完成——沃德纳的家

沃德纳的房子是一座相对较大的建筑，由`alang-lalang`墙壁筑成，地板与地面齐平。房子的正面完全敞开，尽管屋顶伸出的檐遮挡了刺眼的阳光。在前景，整齐地排列着三张桌子和相应的椅子，显得有些刻板，仿佛在酒店的门廊上。在角落里有一个像储物柜的小隔间，`X.`发现那里就是他的卧室。

这里并没有尝试用席子铺盖裸露的地面，即使是贫穷的马来房屋也会这样做。在那个大客厅的后方立着一张大气派的长桌。房子的窗外是一片长满长草的杂乱荒地——在一个如此处处整洁的国家，这种凌乱是不寻常的迹象。不远处，一座供政府使用的新房子正在施工中。这栋建筑结合了`alang-lalang`墙壁和瓦顶这种有些奇特的组合。

欢迎`X.`入门的主人正如之前提到的，是`沃德纳`，即当地的土著行政事法官。处于这种职位的马来人肯定会有礼貌的风度，并且可能是一个愉快的伴侣。这位官员虽然显然想表现得诚恳，却很笨拙且显得愚蠢。他的马来语很糟糕，对于这个职位来说，似乎是个没受过教育的人。他头上戴着一顶可怕的老遮阳帽，外表怪异。

喝完茶后，主人带`X.`绕着走了一圈向他介绍，当他们经过时，所有人都伏在地上。穿制服的随从跟在他们身后，偶尔对那些没有立即倒地的人大吼，同时用权杖的顶端暗示性地戳着他们加快动作。遇到的少数几个华人像向王室行礼的女士一样低头鞠躬，这对于刚离开新加坡的`X.`来说是一次相当惊人的经历，在新加坡，中国人会在人行道上挤欧洲人，并在路过时向他们脸上吐劣质烟草。*谈及此*，这里可以提到，爪哇的一位高级荷兰官员曾表示，他认为新加坡华人对待欧洲人的方式“简直是文明的耻辱”。在写作当时，新加坡当地报纸上正出现一系列来自雪兰莪一位华人的愤慨信，他署名为`会说话的辫尾`。这位写作者向`编辑先生`抱怨，他没有欧洲人同等的权利。我很奇`会说话的辫尾`会对上述荷兰官员说什么。

然而，在索姆皮耶的这些特定华人对`沃德纳`深深地鞠躬了好几寸，而`X.`则带着一种淡然的自知，将自己标榜为该地唯一的白人。这在索姆皮耶的这次漫步充满了趣味，`沃德纳`还尽所能地回答了所有的提问。眼所及之处，整个地区是一片广大的稻田、山谷和丘陵，在`X.`看来，没有任何人口密度能足够消耗这种看似无尽的供应，但`沃德纳`告诉他并没有。

城镇呈现出一派繁忙的景象，且令人难以忘怀；如果相信`沃德纳`的话，这是任何白人第一次见到这种景象。无论事实是否如此，又或许并非如此，`X.`让自己满足于认为这是任何英国人第一次见到这种景象。集市结束后，旅行者回了家，在那里接到了`Usoof`及其母亲的拜访。他找到了她，前往爪哇之行的目的达成了。看来他在沿着河边的小路行走时遇到了她，这唤醒了他的记忆，那段记忆将引导他带回家。她注意到他不寻常的装束和像陌生人一样的样子，停下来询问他是否有关于她儿子的消息——她的儿子多年前去了新加坡，她曾多次给他写信，但没有收到过回复。她担心他已经死了，但由于这位友善的陌生人来自海外异乡，他可能在新加坡的爪哇人殖民地中听过她失散多年的儿子的消息。

见面就是这样，并为这段看似凄凉的任务画上了一个戏剧性且成功的圆满句号。如果我有`Swettenham`或`Clifford`的笔触——这两个善于编织迷人故事的同情者，他们笔下的种族那种童真的信仰非常适合成为故事——我可能会在这里找到几页迷人浪漫的素材。但现实中，`Usoof`身上并没有什么浪漫，更多的是坚毅的诚实与深情，他带着穿着简陋衣裳的贫母亲将她介绍给他的`Tuan`；而此时的`Tuan`正被善良的主人闷得要命，因为主人一直坐在他身边保持专注的沉默，以此不打扰他，对他来说，任何消遣都是一种恩赐。但那位可怜的夫人根据当地习俗，只能在房子外伏地，不敢靠近十来码，或许她把她那新发现的、直直站着的儿子看作某个自寻死路的恶棍。这种行礼制度让`X.`感到相当尴尬，因为主人的所有随从都弯着腰爬行，而自己的随从一直保持着惯常的姿态，偶尔偏离垂直位置。

因为在夜里有些时候，`Abu`意识到自己显眼的地位，会笨拙地蜷缩着身体走来走去，从桌腿间的某处提供香烟和凉饮，在意想不到的地方像猫一样突然出现让他的主人吃一惊，同时他的眼神里写着：“别指望回到你家后这种事还会持续。”第二天是周日，每周集市在中午十二点达到高潮。成百上千、也许几千的人挤在一排排小棚下，卖着各种颜色的纱笼和布料、帽子以及各种土著饰品。

对于`Usoof`和他的母亲来说，伟大的`Wodena`本身就是善良化身，她用爪语与他们交谈，非常亲切。`X.`渴望看到真正的乡村，并在避开当地当局无处不在的目光下与人们交谈，便承诺那天下午去拜访这位老太太的祖宅。几小时后，他乘上火车前往下一站`Tambak`。显然，以前从未有欧洲人做过这种事，车站里为了找一张一等甚至二等座票而引起了一阵骚动。在寻找过程中，铁路官员表现出最天真的好奇心，毫无顾忌地向这位旅行者提问。`X.`到达`Tambak`后下车，站长立刻迎了上来，礼貌地向他保证他错了，因为大镇`Gombong`是再往一站。他显然无法相信会有欧洲人会特意在`Tambak`下车，并将`X.`礼貌地坚持自己知道要去哪里看作是某种神智异常的表现，并决定视其无害而忽略掉。这位体面的绅士比划着手，惊叹着，吸引了一小群围观者，只见那个白人在`Usoof`的跟随下悠闲地走出车站。一旦消失在视线外，站长看到`X.`——这个其实完全不知道自己要去哪里的人——转身向他的随从问路，将会感到无比欣慰。于是他们向左转，沿着一条喧闹河流的岸绕行，走在水边旁成林道的巨树树荫下。在他们右侧是无边无际的稻田，有初期的翠绿和成熟的金黄，在阳光下同样闪烁着光芒。成熟稻谷与新种秧苗并存的景象，形成了爪哇农业的一个显著特征。当他凝视着这幅温暖的画面，并庆幸有人先见地种了这排宜人的树时，后方传来`Usoof`的声音，宣布现在必须右转。向右转自然意味着穿过那片阳光照射的平原。`X.`的手不由地摸向他僵硬的立领，尽管他看不到随从者的脸，但他通过背部感觉到对方在微笑。爬过一个简陋的木栅后，他们向右转，走过稻田，那里昏黄的光线在玉米上方闪烁。不久，一个村庄的红屋映入眼帘，`Usoof`的声音再次响起，介绍他的出生地。这很有趣，补充信息也如此：他们现在必须跨过的小河就是他祖传土地的边界。他们远道而来看的房子深在无数果树的阴影中，上方耸立着树龄巨大的棕榈树。修剪得如此整齐的绿草坪，以及围绕中心房屋的小的小建筑群，共同构成了一幅如画的风景。



在这些草屋前的绿草坪上是客房——一座方形建筑，四周环绕着长凳，中间放着桌子。在这里，这位异乡人在无数爪哇亲戚、堂兄弟姐妹和婶婶的簇拥迎接下——因为这看起来不像一个家庭，而像是一个聚在一起为他尽荣的部落。然后，客人坐在主位上，面前摆着大铜盆，盛着各种水果。这真是一个令人愉快的地方，一想到在几乎没有引导的情况下，他们没有经过漫长的寻找就找到了这里，便感到格外满足。随后是对话，在此期间，访客得知并传达了许多事情。在得知的信息中，他听到以前在修铁路时，附近曾见过一个白人，但这次是村子里第一次近距离见到白人。而这位陌生人告诉他们关于马来人以及与他们一起的生活，他们的房屋和习俗与他们很相似；而只有`Usoof`勇敢地保持正直，充当翻译，这时一群棕色皮肤的年轻亲戚抓着他的手，无情地抢夺了他的怀表和链条、铜纽扣，以及口袋里所有的零硬币。然后，心怀财产权的`X.`要求查看他们土地的契据，契据被拿出来并检查了，他们被嘱咐了如何办理，以便在时候来临时，缺席的`Usoof`作为长子能获得他应有的继承份额。

接着，随着影子拉长，稻田上的折线光已已被晚风吹拂的柔和醇和的光所取代，`X.`发出了出发的信号，宣布必须告别了。他匆忙完成自己的告别，朝河流走去，这样他就不会目睹那位母亲再次失去失去多年的儿子的痛苦，但他无法逃避身后传来的抽咽声。那两个人的小队伍——那个戴着歪斜领子的欧洲人和失去了所有华服的爪哇人——再次开始穿过平原。但队伍越来越大，因为亲爱的亲戚们一个接一个匆忙跟在后面，只为多看一眼离开的兄弟或多说一句。这时，旅行者开始觉得自己比以前任何时候都像个野兽，便建议`Usoof`向他告别，并永远回到他哭泣的家庭怀抱中。但他拒绝这样做，在那个简陋的木栅处，真正的离别发生了。

到达火车时，那位好心的站长仍在张望并走动，仿佛发生了什么不寻常的事，但由于疲倦又炎热，`X.`有些生地回答了他的提问。但这位采访者非常执着，就像是伦敦晚报的记者一样，在拿出一个倒置的小推车供`X.`坐后，去他屋子里拿了威士忌苏打——当地人称之为“荷兰水”。在阳光下走了之后，由于吞食了奇异的水果和调料导致整个生理和神经系统变得紊乱，加上目睹了令人心碎的家庭告别，这突如其来的威士忌苏打，在那种这种恢复剂似乎像刚刚出现的月亮一样不可得时，实在受欢迎了。站长立刻掌握了局面，而那个此前沉默寡的英国人在口渴得到缓解、四肢得到休息后，变得像职业明星一样健于交流，并像自己律师手中的自愿证人一样，完整且顺从地回答了所有问题。

到达`Wodena`人的家中后，旅行者不得不面对更多的盘问，他的房主直到知道（或被说服知道）`X.`在给`Tjilatjap`副驻员的感谢信中所写的每一个字才肯罢休。那晚天气非常闷热，让失眠的旅行者感到，自己已经耗尽了当地的资源。因此，第二天一早，他的那些杂杂的纪念品被打包好，住宿费用得到了慷慨的偿还并被毫无异议地接受；访客们在诚恳请求对`Tambak`那座风景如画的小村庄进行特别官方保护后，便出发前往车站。

`X.`原本打算现在按惯例行事，游览`Djaokjakerta`、`Solo`和`Semarang`的寺庙，但几乎在要求买票时，一种反叛的情绪感染了他，他对于仅仅因为别人都这样做自己就必须去那里那里的想法感到反感，因为他的内心实际上在召唤他去别的地方——他的意向正要求他回到山上的那座生长茶叶和咖啡的小屋。于是，他毫不犹豫地拿了票，并发了一封电报宣布他打算返回。

`Bandong`将是第一个停靠点，这意味着要在从`6 a.m.`到`6 p.m.`的缓慢列车中旅行，并在途中停下二十八个站。那里没有一等车厢，二等座的座位既硬又窄，几小时后拥挤的空间变得几乎无法忍受。情况看起来明朗了一些，列员通过询问谁要在后面的某个停站买午餐票来抚慰乘客们的希望，这样他就可以电报准备食物。希望是永恒的，而对爪哇岛酒店的经验尚未剥夺旅行者对期待的喜悦乐趣。

到达了线路上的“斯温顿”，果然，那里有一张摆满了食物的桌子。在吃下第一道菜的第一口后，`X.`难过地意识到自己上当了，因为如果不用斧头，就不可能对那块肉留下任何印象。于是，他心不情愿地放弃了自己的那份食物（尽管已经付了钱），可能会再次支付，并再次去讨好和欺骗另一个路过的、饥饿的陌生人。

多亏了一位年轻军官的陪伴，剩下的旅程变得很愉快。这位军官因`Lomboh`战受伤回家，正`en route`前往他的`Buitenzorg`。这位可怜的战士经历了一段艰苦时期，讲述他和士兵们如何无处躲避地睡在湿地上，晚上只有饭吃。而这距离爪哇的主要港口只有半天路程，而且为援助士兵所集的资金如果需要的话，足以支付整个战争费用。

这位伙伴讲述了许多关于战争的有趣轶事，并讲述了一些关于当地人背叛和忘恩的近乎不可信的故事。这位英国人也借此机会了解了一些和平时期的社交礼仪，以及在那些荷兰人和当地人会面的宴会上指导参与者的不成文规定。比例如，当`Djoedja`的苏丹举办舞会时，每位官员必须站在台阶上，高高低低取决于他的等级，而驻员则被迎接并护送到与苏丹同样的高度，就在顶端。然而，对于总督，苏丹必须行礼。

这可能是提到官方对种姓制度的高度尊视的好机会。人们对等级的敬畏是由他们的统治者培养和协助的，如果一个有地位的人被怀疑或指控到需要进行调查，调查必须在闭门和私下进行。

那晚，这团人住在`Bandong`（刚读完《红绒花》，那里的语言似乎是最具描述性的）。火车在黄昏分分了那座规模较大的城镇。在这里，旅行者幸运地再次遇到了他的朋友`Lraad`主席，并由他介绍进了`Club`。被介绍进`Club`意味着要向那里的每一位成员分别介绍，并带着`X.`在`Batavia`观察到的那种严谨的形式主义。

`Bandong`的酒店是旅行者迄为止住过的最好的，而且与意料相反，晚餐是温暖且令人慰藉的。然而，团中的其他人，`Usoof`和`Abu`并不那么幸运，因为他们没有办法找到东西吃。他们被不允许在天黑后没有灯的情况下出去，而他们又没有灯。此外，还下着大雨。酒店显然无法在那个时间为当地人提供食物，他们必须自己去寻找。当`X.`吃完自己的晚餐时，这个悲惨故事迎接了他。但善良的`Lraad`主席化解了这个困境，很快为这对饥饿的伙伴提供了一位餐饮者、保护者和导游。

像常一样，第二天早上规定的火车出发时间非常早，其他火车也开始出发，在这些火车中，`Abu`选择了即将出发前往`Maos`的一班，把所有的便携行李——数量不少——塞了进去，直到火车实际上开始移动时才被救回来。这无疑需要仓促的行动，让那些匆忙的人满头大汗。

然后票窗前的景象简直无法用语言描述。对于一个欧洲人和当地人之间公开存在如此鸿沟的国家来说，发现买票的唯一开口竟然被两个种族嘈闹的人群包围，真是一件奇怪的事，而且没有人想到要排队。`X.`试图挤进那个小窗户，但当他停下来观察西方文明国家行的游戏规则时，他每次都被跳过，而票已经快要到手里了。

最后，厌恶了参与这种场景，他退下了。这时，`Usoof`通过许多肘部的暗示和爪哇语词汇（他的母亲可能不认可的词汇），设法及时拿到了票赶上了火车。这列火车如期将他们送到了熟悉的车站，那里正如之前一样，有马在那里等着他们登上那座风景无限的山丘。
