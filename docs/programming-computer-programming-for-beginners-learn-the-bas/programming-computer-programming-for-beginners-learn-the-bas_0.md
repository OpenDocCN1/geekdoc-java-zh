# 第 1 章：Web 开发简介

网站的创建根据目标受众有不同的目的，有些是为了销售产品，有些仅仅是为了提供信息。Web 开发工具为公司提供了创建网络存在的平台。网站让他们获得了更广泛的观众。根据需求开发网站，企业聘请开发人员。开发网站可以包括从简单的编程到网络安全、内容添加或服务器配置的任何内容。

## 什么是 Web 开发？

Web 开发可以广义地定义为在互联网或内网上托管的网站和 Web 应用程序的开发。实际上，Web 开发被用作一系列活动的组合术语，例如 Web 设计、客户端编码、服务器端脚本、网络安全配置和其他任务。

Web 开发涉及在客户端和服务器端使用脚本语言。它涵盖了从创建纯文本页面到复杂应用程序的范围。Web 开发的层次包括；客户端编码、服务器端编码和数据库技术。

更具体地说，Web 开发可以认为是 Web 编程。这涉及创建 Web 应用程序或网站的代码。通过它，你可以创建一个简单的网页，也可以创建一个像 Facebook 这样的大型社交网络，或像 Amazon 这样的电子商务门户。

## Web 开发流程

在你开始构建网站之前，首要任务是你必须理解你正试图传达给观众或客户的信息或消息。他们在内容方面期待看到什么？你如何能让内容变得对用户友好且易于导航？一旦所有的前端设计方面都确定了，就必须开始着网站的后端工作了，这包括如何托管、使用什么架构、网站预期的流量负载是多少，以及我们如何搭建基础设施以确保网站的整体构建稳健。最后，必须确保网站可以在各种类型的浏览器/设备（如智能手机、平板电脑等）上打开，并且能够通过搜索引擎轻松搜索。

Web 开发过程中涉及许多步骤，但大来说可以分为五个阶段。

1. **需求发现 (Discovery)** - 开发网站的第一步是理解业务需求，包括：创建网站的目的、目标受众以及网站内容。

2. **定义 (Definition)** - 必须将第一步收集的信息汇总，以定义网站地图或网站计划。这涉及创建一个易于导航的系统或用户界面。

3. **设计 (Design)** - 这一步涉及构建用户体验。网站的视觉吸引取决于你选择的模板，并且应该始终考虑到目标受众。例如：针对青少年的网站性元素与针对金融机构的网站会有不同。

4. **开发 (Development)** - 在这一步中，实现最终设计以创建一个实际的功能性网站。使用内容管理系统和编程代码来开发网站。

5. **部署 (Deployment)** - 对网站的所有功能进行测试，一旦客户对最终产品满意，就会将网站文件上传到客户的服务器。

## Web 开发的方面

Web 开发可以大致分为两个独立的部分。它们是前端开发和后端开发。为了拥有一个功能完整的网站，这两个过程需要并并进行。

### 前端开发 (Front-end Development)

也被称为客户端编码，在这种开发中，你将创建用户在加载 Web 应用时将看到的内容。这包括设计和内容，以及用户将如何与之交互。对于前端开发，你需要使用`HTML`、`JavaScript`和`CSS`。

`HTML`是用于将文本转换为网页的代码。所有网页都是用`HTML`编写的，这种语言对于所有 Web 应用也至关重要。`CSS`用于设置样式规则，它决定了网页外观。`JavaScript`用于为网页添加功能并使其更具交互性。

### 后端开发 (Back-end Development)

这也被称为服务器端编码。它决定了网页服务器上发生了什么。换句话说，用户看不到这些活动，但它们会影响网站。后端开发中的一项常见活动是为前端生成创建一个数据库。

后端开发使用了多种编码语言和框架。`PHP`、`ASP.NET`、`Ruby on Rails`、`Python`、`Node.js`和`Java`就是其中一些。

## 使用编程语言的优缺点

编程语言用于创建构建网站或 Web 应用的程序。大多数编程语言都是容易学习的。它们帮助你向网页添加动态和交互式的活动。复杂的任务可以在相对较少的步骤内完成。

编程语言的缺点是编码过程中产生的漏洞（bugs）有时会令人烦恼且难以解决。Web 开发人员需要像如掌一样熟悉编程语言的语法。因此，大量的努力和良好的记忆是必不可少的。此外，需要建立编程速度，否则这是一项非常耗时的活动。

## 为什么要学习 Web 开发？

当然，开始学习 Web 开发的最常见原因是成为一名 Web 开发人员。你将能够为人们创建网页和网站供他们在互联网上查看。然而，这并不是学习 Web 开发的唯一理由。有很多理由，我们列出了其中几个：

1. Web 开发的特点之一是相对容易学习。事实上，许多程序员声称，Web 开发是那些想要开始学习编程的人的极佳选择。如果你兴趣成为程序员，Web 开发可以为你提供基础。

2. 学习 Web 开发可以给你良好的就业前景。企业希望建立有效的影响力，为此他们面临压力提供具有电子商务和通信能力的高质量网站。因此，越来越多的公司寻找能够交付最佳内容的 Web 开发人员。

3. 作为一名 Web 开发人员，你有机会创造新的酷事物。你只需要笔记本电脑和互联网连接，具备编程语言知识，就可以根据你的想象力创造。

4. Web 开发不再仅仅关于网络。当现在的公司考虑创建网站时，他们还会考虑社交媒体和移动技术。智能手机、网络电视、平板电脑等许多设备的使用量激增，因此开发者需要考虑到所有这些。这扩展了开发者的影响力。

5. Web 开发非常灵活，具有许多方面，如前端、后端、内容管理系统、电子商务、移动 Web 等。这为专业人士提供了广泛的机会，同时新工具正在让提升技能的过程变得更加简单。

# 第 2 章：学习 HTML5：Web 语言

`HTML`是 Web 的核心。它是一个被所有人接受的标准。因此，理解它将是开发网页和 Web 应用的关键。

## 什么是 HTML？

`HTML`是超文本标记语言的缩写。它是用于创建网页的语言。事实上，`HTML`是现代互联网的石。除了网页，它还用于创建 Web 和移动应用的用户界面。

它由一组插入网页中的代码或标记符号组成。代码告知网页浏览器网页上的文字和图像应该如何显示给用户。每一个标记代码被称为元素或标签。网页浏览器可以读取`HTML`文件并将其渲染为可见的网页。它还以语义方式描述网站的结构。

### HTML 的历史

互联网和`HTML`的历史完全交织在一起，是共同开发的。Tim Berners-Lee 开发了被称为`HTML`的语言，用于世界上第一个网站和第一个 Web 服务器。它编写于 1990 年左右，并在 1991 年向公众开放。多年来，`HTML`经历了多次迭代。在 2000 年，`HTML`正式标准化为用于开发网页的标记语言。

尽管语言发生了变化，但 HTML5 中仍然有一些在 HTML 第一版本中就存在的特性。这是 HTML 的最新版本，于 2014 年 10 月发布。当你想要学习 HTML 时，你实际上学习的是 HTML5。

## HTML 基础

所有的 HTML 文档都以文档类型声明开始，即`<!DOCTYPE html>`。

HTML 文档仅以`<html>`开始，并以`</html>`结束。

HTML 文档的可见部分位于`<body>`和`</body>`之间。

让我们来看下面这个简单的 HTML 文档示例，以便更好地理解这种语言：

```html
<!DOCTYPE html>--------------定义文档
<html>--------------------------标记 HTML 页面的根元素
<head>---------------------------包含关于文档的元数据
<title>Page Title</title>---指定文档标题
</head>
<body>---------------------------包含可见的页面内容
<h1>My First Heading</h1>-定义一个大级标题
<p>My First paragraph.</p>-定义一个段落
```

```html
<body>
<html>
```

## 创建 HTML 网页的元素

为了创建一个简单的网页，你需要了解基础元素和标签，例如用于定义布局的元素等。这些元素几乎用于所有的网页中，为放置在其上的内容提供结构。以下是你开始创建简单网页时需要了解的知识。

### 页面标题

所有的 HTML 页面必须有自己的页面标题。它作为文档的名称。页面标题帮助用户理解他们对该页面的预期。此外，当页面被保存到浏览器书签时，它将作为默认标题。页面标题不会显示在网页的实际内容主体中。

标题元素的语法所示。

```html
<title>...</title>
```

标题元素始终放置在`<head>`元素内部。示例：

```html
<!DOCTYPE html>
<html>
<body>
<h2>The title attribute</h2>
<p title="These are the tooltips"></p>
</body>
</html>
```

### 段落

页面标题不会影响放在网页上的实际内容。然而，段落元素无疑会影响。你可以在 HTML 中分行输入消息。但是，除非你使用段落元素，否则浏览器始终会将它们打印在同一行上。毕竟，HTML 并不关乎表现形式，而是关乎含义。该元素的语法如下。

```html
<p>...</p>
```

在这些标签内插入文本时，你可以确保文本被视为一个独立的文本块。它将显示为一个新段落。其用法示例所示。

```html
<!DOCTYPE html>
<html>
<head>
<title>List of Animals</title>
</head>
<body>
<p>this is a list of animals.</p>
<p>it is quite interesting.</p>
</body>
</html>
```

### 换行

换行标签用于将单行拆分为两行。与其他元素不同，换行没有任何闭合标签，因为在拆分行时不涉及任何内容。你可能会发现经常使用换行非常容易。但是，你必须避免这样做，特别是当两段文本应该完全分开时。在这种情况下，段落元素会更适合你。换行的标签是`<br>`，其用法示例所示。

```html
A List of Animals<br>
And Other Animals
```

### 列表

HTML 允许将内容组织成列表，使内容在网页上更具表现力。HTML 中实际上有三种列表：有序列表、无序列表以及最后是定义列表。其中，定义列表稍微高级一点。因此，我们在这里只考虑有序和无序列表。这两种列表的工作方式相似。然而，当列表项目没有顺序时，使用无序列表。它们前面通常有项目符号。而当项目必须按顺序列出时，使用有序列表。因此，它们前面有递增的数字。

无序列表元素可以通过以下语法定义。

```html
<ul>
<li>Li...</li>
<li>Li...</li>
<li>Li...</li>
</ul>
```

有序列表的语法类似。唯一的区别在于使用的标签，如下所示。

```html
<ol>
<li>Li...</li>
<li>Li...</li>
<li>Li...</li>
</ol>
```

（注：原文示例中标签大小写不统一，翻译/转换时已按标准规范修正为小写）

`<li>...</li>`标签用于定义放置在该列表中的每个项目。

为了理解 HTML 中的有序列表和无序列表，你可以参考以下示例。

```html
<!DOCTYPE html>
<html>
<head>
<title>my first web page</title>
</head>
<body>
<h1>A Short List of Animals</h1>
<ul>
<li>Cat.</li>
<li>Dog.</li>
<li>Horse.</li>
</ul>
</body>
</html>
```

如示例所示，当你创建一个列表时，可以同时使用无序列表和有序列表。你可以使用任意数量层级的列表。

## 链接

链接是我们使用任何网站或网页的核心。因此，了解你如何在 HTML 中实现它们是有帮助的。毕竟，链接是互联网能够将一切结合在一起的原因。

在 HTML 中创建链接时，你需要理解几点。锚点标签（anchor tag）将用于定义链接。你需要将链接的目标地址添加到锚点标签中，以便在 HTML 中创建功能性链接。链接的目标可以通过`href`属性定义。

链接可以是绝对路径的，这意味着它将带你进入特定的网站。例如，你可以链接到`http://www.amazon.com`或`http://www.google.com`。在这种情况下，语法如下。

```html
<a href="http://www.amazon.com">Amazon</a>
```

或者，它可以指向位于同一目录下的另一个文件。例如，假设你在同一目录下创建了名为`bird.html`的另一个 HTML 文件并将其保存在那里。在这种情况下，你可以使用以下语法创建指向该文件的链接。

```html
<a href="bird.html">The List of Birds</a>
```

你也可以将链接指向同一页面的其他部分。如果你使用过维基百科，可能已经见过这种用法了。为了创建这样的链接，你需要在标签上添加一个`id`属性。几乎所有的标签都可以添加此类属性。请看下方的示例以理解它的工作原理。

```html
<p id="bird">The List of Birds</p>
...
<a href="#bird">Check the List of the Birds</a>
```

一旦点击链接，页面将滚动到该元素（在本例中是一个包含相应`id`标签的段落）。

### 创建 HTML 页面的步骤

既然我们已经学习了 HTML 语言的基础知识，让我们来看一下创建 HTML 页面的具体步骤。

1. 文本编辑器 - 打开一个你喜欢的文本编辑器，例如-记事本（notepad），并创建一个空的文本文件。

2. HTML 代码 - 将 HTML 代码复制并粘贴到你的新文本文件中。

3. 保存 – 点击文件并以 HTML 文件扩展名保存，例如“nameyoulike.html”。

4. 演示 - 双击文件以在任何网络浏览器中查看它。

### Hello World 示例

为了帮助你更好地理解 HTML5 中使用的结构和语法，你应该查看以下示例。毕竟，没有比实践更好的学习方法了。以下是一个 hello world 示例，这种类型的程序通常在编程中用于介绍语言的基础性知识。

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="utf-8">
<title>HTML5: Hello World Example</title>
</head>
<body>
<h1>Hello World</h1>
</body>
</html>
```

如你所见，这实际上是一个非常简单的程序。执行此代码后，将打开一个网页并显示文本“Hello World”。由于 HTML5 中代码的简单易懂性，你实际上可以理解程序中正在发生什么。



首先，定义了在网页上显示的文本语言为英语。然后，通过`charset`属性定义 HTML 文档的字符编码。最后，在`body`标签内部提到了要显示的文本。

## HTML 文档的结构

HTML 文档是一个包含超文本标记语言的文件。HTML 代码基于标签，标签提供了用于格式化文档的指令。在任何 HTML 文档中，都会提到文档类型元素，也称为`doctype`。它的目的是确保浏览器以标准模式渲染 HTML，以便以正确的方式运行。`doctype`的使用还允许验证软件知道应该针对哪个版本的 HTML 代码进行验证。

在`doctype`之后，使用了起始`HTML`标签。它打开 HTML 代码并用闭合的`HTML`标签关闭。它们作为整个文档的容器。因此，闭合`HTML`标签始终是任何 HTML 文档中的最后一个内容。

在`HTML`元素之后，插入了`head`元素。这个容器包含了文档的所有信息或元数据。接下来是`title`元素，它用于定义页面的标题，标题将显示在菜单栏中。

在闭合`head`元素之后，使用了`body`元素。它包含了出现在页面上的实际内容。如你所见，Hello World 示例的`body`元素中只有一个头部（header）元素。

## HTML 的类型

正如上面提到的，最新版本是 HTML 5。这个版本可以分为三类。这些类型定义了 HTML 的使用方式。

1. Transitional（过渡型）- 这是最常见的 HTML 类型，具有灵活的语法、拼写和语法组件。这种类型的 HTML 在没有语法限制的情况下一直被使用。浏览器对标签支持尽力而为的方法，因此如果标签拼写不正确，浏览器不会纠正错误，而是会显示内容。

2. Strict（严格型）- 这种类型要求关闭所有打开的标签。严格的 HTML 对手机至关重要，因为手机的处理能力有限。此外，如果代码整洁无错误，页面加载速度会更快。

3. Frameset（框架型）- 它允许开发者创建 HTML 文档的合集，即多个文档连接到单个屏幕。这种类型通常用于创建网站的菜单系统。

## HTML 中的元素

在 HTML 中，一个基础元素会在文本块周围有两个标记。元素内部包含其他元素也是可能的。事实上，所有的 HTML 文档都是如此的。毕竟，代码的主要部分总是被放在 HTML 元素内部。然而，也有极少数例外，某些元素不能包含任何文本或其他元素。`img`元素就是其中一个例子。

## 常见问题解答 (FAQ)

### HTML5 的用途是什么？

答：HTML5 是为了克服`XHTML`、`HTML4`和`HTML DOM` 2 级的缺陷。该语言专注于在不使用额外插件的情况下提供高质量内容。该语言新的结构化元素标签为整个网页结构提供了更好的语义支持。错误处理被简化，并且还提供了向后兼容性。HTML5 可以在平板电脑、智能手机和电脑等平台上实现。

### HTML5 规范可以在所有类型的浏览器上实现吗？

答：到目前，还没有浏览器支持该语言的所有方面。因此，开发者必须确保他可能使用的特性将被显示该内容的浏览器所支持。

### HTML 标签（tags）和元素（elements）有什么区别？

答：HTML 中的元素（elements）告诉浏览器如何呈现文本。而当元素被`<>`（尖括号）包裹时，它们就变成了标签（tags）。

### 你说的 DOCTYPE 是什么意思？它的新形式是什么？

答：这个术语告诉浏览器网页上使用了哪种 HTML。浏览器使用`DOCTYPE`来决定如何制作网页。新形式是`<!doctype html>`。

### 描述 HTML5 中 header、section、article 和 footer 的正确用法？

答：Header - 它用于包含给定页面某个部分的导航和介绍性信息。这些信息可以是作者姓名、日期、时间、章节标题、目录或任何其他导航信息。

Section - 它是一个灵活的容器，用于存放内容并共享共同信息。

Article - 它包含自包含的成分/作品，这些作品可以在页面之外独立地重新创建，而不会丢失其含义。例如：博客文章、新闻故事等。

Footer - 它包含要显示在内容末尾的信息，也可能包含关于该部分的额外信息。例如：版权信息、相关链接等。

### HTML5 支持哪些多媒体元素？

答：它支持`audio`和`video`标签。

### HTML5 中包含任何新的图像元素吗？

答：是的，有两个新的图像元素，它们是：`WebGl`和`Canvas`。`Canvas`图形，而 Web 图形语言 (`WebGL`) 是一种免费的跨平台技术，用于在浏览器中生成 3D 图形。

### 为什么我们需要 data--attributes（数据属性）？

答：该属性是该语言的新新增，用于为元素分配自定义数据。该元素适合存储应用程序或页面独有的私有或敏感数据，并且这些数据没有匹配的元素和属性。

### HTML5 带有哪些标准 API？

答：其中一些：`Text Track`、`Media`、`Application Cache`、`Command`、`User Interaction`、`Data Transfer`、`Constraint Validation`和`History API`。

### HTML 浏览器缓存和 HTML5 应用缓存（application cache）有什么区别？

答：HTML5 缓存创建一个离线版本，并将图像、HTML 文件、CSS 和 JavaScript 等文件存储在本地，与传统的 HTML 缓存相比，这提高了网站的速度。

总的来说，HTML 5 是一种用于创建强大的浏览器应用程序的令人印象深刻的编程语言。它允许你格式化文本、创建链接、添加图形、输入表格、表单、框架等，并将其保存到文本文件中，任何浏览器都可以读取并显示。

# 第 3 章：理解 CSS：样式化互联网

HTML 的功能是创建网页。然而，它无法确保内容的恰当呈现。为了让网页样式化并改进其呈现方面，你需要使用如`CSS`的样式表语言。

## 什么是 CSS？

CSS 代表 Cascading Style Sheets（级联样式表），是一种简化确保你的网页可呈现过程的设计语言。它负责网页的外观。通过它，你可以控制页面的各个方面，如字体样式、文本颜色、列宽、段落间距、布局、背景图像或颜色或其他设计。你还可以启用显示变化以适应不同的屏幕尺寸和设备。

`CSS`通常用于指定用`HTML`或`XHTML`编写的网页以及用户界视觉样式。你也可以将该语言用于所有的 XML 文档类型。

`CSS`的创建允许文档内容与文档呈现（包括颜色、字体和布局）分离。通过将它们分离，可以改进某些方面，例如内容的可访问性。它还为呈现的各个方面提供了增强的控制和灵活性。它还允许多个`HTML`文件共享相同的格式。

分离使得能够以一系列样式交付相同的页面，以适应不同的渲染方法，例如打印、屏幕显示和语音。用户创建一个不同的`CSS`文件来覆盖网页创建者指定的样式也变得可能了。

目前，正在使用的`CSS`最新版本是`CSS3`。`CSS3`在之前版本的基础上为该语言引入了许多新功能。我们在本书中将只关注`CSS3`。

### CSS 历史



Hakon Wium Lie 在 1994 年 10 月 10 日首次提出了 `CSS`。在同一时期还提出了许多其他样式表语言。最后 `CSS1` 于 1996 年发布，微软 Internet Explorer 成为第一个支持 `CSS` 的浏览器。这种语言是专门为在网络上存放内容而开发的，而 HTML 是为了在网络上创建文档。

样式表的概念并不新。然而，现有的语言要求样式表来自不同的来源，而另一方面，`CSS` 通过级联的方式影响文档样式。级联意味着能够结合多个 `CSS` 文件来决定页面的样式。

让我们来看看 CSS 的一些优点和缺点。

## CSS 提供的优势

使用 `CSS` 有一些明显的优势。其中一些提到如下：

- **节省时间 (Timesaver)**：`CSS` 的最大优势之一是它在 Web 开发中节省了大量时间。`CSS` 只需要为 `HTML` 页面编写一次。它可以重复用于多个 `HTML` 页面。可以为 `HTML` 中的每个元素定义样式，然后应用于各种网页。

- **易于维护 (Easy Maintenance)**：`CSS` 允许你轻松地维护多个页面。你可以通过更改 `CSS` 中的样式来进行全局更改。所有 `HTML` 页面中相应的元素将自动更新。

- **快速加载 (Faster Loading Pages)**：使用 `CSS` 时，无需在 `HTML` 中多次定义标签属性。只需要为标签编写一条 `CSS` 规则即可适用于该特定标签的所有之处。这大大减少了你的代码，从而加快每个页面的下载速度。

- **更好的样式 (Better Styles)**：与 `HTML` 相比，`CSS` 提供了范围更大的属性。这允许你改进 `HTML` 页面外观的效果比只使用 HTML 属性大得多。

- **缓存 (Caching)**：`CSS` 允许通过本地缓存存储 Web 应用程序。允许你离线查看网站。缓存还可以加快页面的加载并提高网站的整体性能。

- **多设备兼容性**：你可以使用样式表为各种设备优化你的内容。

- **全球标准**：事实是，`HTML` 中可用的属性正在减少。相反，推荐使用 `CSS` 作为替代方案。因此，`CSS` 正被用于所有网页，以确保与未来的网络浏览器具有兼容性。

## CSS 的缺点

1. **CSS 的不同级别** - 该语言有从 `CSS1` 到 `CSS3` 的不同级别，这导致开发人员对于应该使用哪一个版本感到困惑。

2. **碎片化** - 在 `CSS` 中，在某个浏览器中可能有效的代码在另一个浏览器中可能无效。因此，Web 开发人员必须在网站上线之前，先通过在多个浏览器中运行程序来测试兼容性。

3. **缺乏安全性** - `CSS` 没有内置的安全系统，因为它是一个开放的基于文本的系统。因此，任何对网站具有读写权限的人都可以无意或刻意地更改 `CSS` 文件、链接或格式。

## 开始使用 CSS

要开始使用 `CSS`，需要一个文本编辑器、一个现代浏览器以及一些经验。让我们来看看 `CSS` 是如何工作的：

当文档在浏览器中显示时，它必须将样式信息与文档中的内容相结合。文档通过两个阶段处理：

1. 浏览器将 `CSS` 和标记语言转换为 `Document Object Model`（文档对象模型），它在计算机内存中表示文档。

2. 浏览器显示文档的内容。

在标记语言中，元素被用于定义文档的结构。正如我们在上一节中学到的，元素是使用标签标记的。`CSS` 中的大多数元素都有起始标签和结束标签。标签以符号 `<` 开始，以 `>` 结束。

然而，取决于标记语言，少数元素的 `/` 位于元素名称之后，且它们只有一个自闭标签或起始标签。每个属性、元素和文本段都成为 `DOM` 树形结构中的节点。这些节点由它们与其他 `DOM` 节点的关系来定义，即某些元素作为子节点的父节点，而子节点可能有一些兄弟节点。

理解文档对象模型将帮助你调试、设计和维护 `CSS`。让我们来看一个例子来解释这个模型——

在文档中，`<p>` 标签及其结束标签创建了一个容器：

```html
<p>
 <strong>C</strong>ascading
 <strong>S</strong>tyle
 <strong>S</strong>heets
</p>
```

在 `DOM` 中，`P` 节点是父节点，其子节点是文本节点和 `strong` 节点，其中 `strong` 节点同样是文本节点的父节点。

## CSS 中的 Hello World 程序

与其他语言一样，hello world 程序可以作为 `CSS` 的良好介绍。你可以在下面的示例中看到 `CSS` 的运行。

```css
<style type="text/css">
  h1 {
    Color: DeepSkyBlue;
  }
</style>
<h1>Hello, world! </h1>
```

你可以看到，这条 `CSS` 规则针对的是 `HTML` 页面的 `H1` 标签。在这种情况下，我们通过名为 `DeepSkyBlue` 的颜色值更改了 `H1` 文字的颜色。

## 创建并将 CSS 应用到 HTML 文件

在开始为你的 `HTML` 文件创建自己的 `CSS` 之前，你需要知道如何在 `HTML` 中实现 `CSS`。为了实现这一点，你有四种可用方案。它们列在下方。

### 1. 内联 (Inline)

在此方法中，样式规则直接放置在 `HTML` 文件中。在需要更改样式的标签中使用 `style` 属性。这里有一个显示内联方法的示例。

```html
<p style="color: blue">…</p>
```

这条规则的结果将是该段落的文字变为蓝色。使用这种方法也有缺点，因为它会让 `HTML` 膨肿，网站维护变得有些困难。然而，它在某些情况下效果良好。例如，当你使用的系统没有访问 `CSS` 文件的权限时，你可以简单地将样式规则添加到元素中。

### 2. 内部 (Internal)

如果你想为整个页面实现特定的样式规则，你应该选择内部方法。它也被称为嵌入方法。规则放置在 `head` 元素内部。你可以在下面的示例看到它是如何工作的。

```html
<!DOCTYPE html>
<Html>
<Head>
<Title>CSS Example</title>
<Style>
  P {
    Color: green;
  }
  A {
    Color: blue;
  }
</Style>
</head>
</html>
```

当你使用这种方法时，你会发现所有段落都是绿色的，而所有链接都显示为蓝色。

这种方法的缺点是，当有人访问网页时，样式都必须下载。这会给用户带来缓慢的浏览体验。然而，这种方法也有自己的优势。由于 `CSS` 是 `HTML` 文档的一部分，整个页面仅作为一个文件存在。在通过电子邮件向某人发送网页或作为博客模板时非常有用。嵌入方法的另一个优势是，当使用数据库生成页面内容时，可以同时生成动态样式。标题和其他元素的颜色被插入到嵌入页面的 `CSS` 规则中。

### 3. 外部 (External)

顾其名，这种方法涉及创建一个完全独立的 `CSS` 文件。这使其可以被应用于整个网站。这就是为什么通常避免使用内联和内部方法。下面给了一个基础的 `CSS` 文件示例。

```css
P {
  Color: green;
}
A {
  Color: blue;
}
```

此文件需要保存在与 `HTML` 页面相同的目录下。你可以为 `CSS` 文件选择任何名称，但常见的命名约定规定应将其命名为 `style.css`。一旦文件保存，你就可以将 `HTML` 文件链接到它。下面的代码显示了如何链接 `HTML` 文件和相应的 `CSS` 文件。

```html
<!DOCTYPE html>
<Html>
<Head>
<Title>Example</title>
<link rel="stylesheet" href="style.css">
...
```

保存 `HTML` 文件后，它将链接到相同目录下的名为 `style.css` 文件。你对 `CSS` 文件的任何更改在打开相应的 `HTML` 文件时都会反映出来。

### 从 CSS 内部导入 CSS 文件

此 `import` 规则允许从 `CSS` 内部附加新的 `CSS` 文件。要实现这一点，只需执行以下操作：

```css
@import "newstyles.css";
```

在这里，你可以编写你的 `CSS` 文件名代替 `newstyles`，并确保包含正确的路径。例如，我们有一个 500 页的网站，想要为所有页面添加第二个 `CSS` 文件。这样，我们不需要编辑所有 500 个 `HTML` 文件来添加另一个 `CSS` 链接，只需从第一个文件中导入第二个 `CSS` 文件，从而节省了大量时间。

在 CSS 中，我们并不是从意义上在编写程序。毕竟，它是一种样式表语言。相反，我们编写的是规则。CSS 将包含一组样式规则，浏览器会在将这些规则应用于 HTML 文档中的关联元素之前，对其进行解释。正如你所看到的，一条样式规则由三部分组成。

- **选择器 (Selector)**：这是将应用样式的 HTML 标签。

- **属性 (Property)**：这是 HTML 标签的一种属性。所有的 HTML 属性都会被转换为它们各自对应的 CSS 属性。

- **值 (Value)**：每个属性都有一个与之对应的值。

例如：

```css
h1 {color:brown;font-size:12px;}
```

在上面的示例中：

- `h1` 是选择器

- `color` 是属性

- `brown` 是值

- `font-size` 是属性

- `12px` 是值

选择器指向你想要样式的元素。声明块包含多个声明，它们之间用分号隔开，每个声明包含一个 CSS 值和属性名，它们之间用冒号分隔。CSS 声明必须以分号结束。声明块被包含在大括号中。

所有 CSS 规则的基本语法所示。

```css
Selector {property: value}
```

CSS 选择器根据它们的名称、类、ID、属性等查找 HTML 元素。CSS 选择器可以用多种方式定义。事实上，你可以轻松地选择一种你觉得方便使用的。这里是几种选择器及其使用方法。

### 1. 类型选择器 (Type Selectors)

你可能已经在之前的示例中注意到这种选择器的用法了。它允许规则应用于所有相同类型的元素。在下面的示例中，绿色被应用于页面上所有的一级标题。

```css
h1 {
Color: #36CFFF;
}
```

### 2. 通用选择器 (Universal Selectors)

与其选择特定类型的元素，不如使用通用选择器。这允许你将规则应用于任何可以使用给定属性的元素类型。下面的示例说明了通用选择器的用法。在其中，文档的所有内容将以黑色显示。

```css
* {
Color: #000000;
}
```

### 3. 后代选择器 (Descendant Selectors)

在某些情况下，你可能希望只有当某个元素位于另一个特定元素内部时，才对其应用样式规则。在后代选择器的帮助下，这完全可行。你可以查看下面的示例。在其中，只有当 `em` 元素出现在 `ul` 标签内部时，样式规则才会应用。

```css
ul em {
Color: #000000;
}
```

### 4. 类选择器 (Class Selectors)

可以使用类属性为元素定义样式规则。通过类选择器，具有该类的元素将按照定义的规则进行样式化。看看下方的示例。

```css
.black {
Color: #000000;
}
```

使用这条规则后，你会发现文档中所有类属性设置为 `black` 的元素其内容都将以黑色显示。同时，未来可以精炼该规则并指定特定的元素。查看下面的示例。

```css
h1.black {
Color: #000000;
}
```

在上面的规则中，内容将被样式化为黑色，但仅对于类属性设置为 `black` 的 `h1` 元素。也可以对特定元素应用多个类选择器。查看下面的示例以了解它是如何工作的。

```html
<p class="center bold">
Text
</p>
```

### 5. ID 选择器 (ID Selectors)

在为元素定义样式规则时，也可以考虑 ID 属性。在这种情况下，所有具有该特定 ID 的元素将按照你定义的规则进行样式化。

```css
#black {
Color: #000000;
}
```

使用这条 CSS 规则，你会发现所有 id 属性为 `black` 的元素其内容都将以黑色显示。还可以进一步完善这条规则并针对特定类型的元素。在下面的示例中，只有属性为 `black` 的 `h1` 标签会受到规则的影响。

```css
h1#black {
Color: #000000;
}
```

ID 选择器在配合后代选择器使用时非常有用。在下面的示例中，你会看到，只有当这些二级标题出现在 ID 属性为 `black` 的标签内部时，所有的 `h2` 标签才会以黑色显示。

```css
#black h2 {
Color: #000000;
}
```

### 6. 子选择器 (Child Selectors)

子选择器与后代选择器相似。然而，它们的功能非常不同。下面的示例说明了子选择器的用法。在该 CSS 规则中，只有当段落是 `body` 元素的直接子时，才会以黑色显示。如果段落存在任何其他元素（如 `td` 或 `div`）内部，则不会。

```css
body > p {
Color: #000000;
}
```

### 7. 属性选择器 (Attribute Selectors)

通过属性选择器，你可以为具有特定属性的元素应用样式。在给出的示例中，`input` 将不受影响。

```css
input[type="text"] {
Color: #000000;
}
```

属性选择器有一个主要的优势。在这些情况下，遵循某些规则：

- `p[lang]` – 在这种情况下，段落具有 `lang` 属性。

- `p[lang="en"]` – 具有精确的值 "en"。

- `p[lang~="en"]` – 包含单词 "en"。

- `p[lang|="en"]` – 恰好为 "en"，或以 "en-" 开头。

### 8. 多样式规则 (Multiple Style Rules)

在某些情况下，你可能需要为特定元素设置多个样式规则。CSS 允许将不同的属性及其值组合成一个代码块。你可以从示例中看到。

```css
h1 {
Color: #000000;
Font-weight: normal;
Letter-spacing: .3em;
Margin-bottom: 2em;
Text-transform: lowercase;
}
```

如示例所示，所有的属性值对都用分号隔开。如果你愿意，可以将规则写在一行而不是多行。

### 9. 选择器组 (Selector Groups)

如果你想或需要，也可以为多个选择器应用同一个样式规则。在这种情况下，选择器之间必须用逗号隔开。你可以在示例中看到这种用法。

```css
h1, h2, h3 {
Color: #000000;
Font-weight: normal;
Letter-spacing: .4em;
Margin-bottom: 1em;
Text-transform: lowercase;
}
```

列表的顺序不会影响规则。

## 在 CSS 中使用颜色

当你对 HTML 文档进行样式化时，颜色无疑是你实现的内容之一。在 CSS 中，你有能力从 16,777,216 种颜色中为文本选择颜色。以下是你如何在样式规则中实现它们的方法。

### 颜色属性的值

## 简介

在 CSS 中，`color` 属性的值可以使用名称来指定。或者，你也可以使用十六进制代码或 RGB 代码。下面列出了将红色作为该属性的值的几种使用方法。换句话说，当配合 `color` 属性使用以下代码时，你会发现文本将以红色显示。

* `red`

* `rgb` (100%, 0%, and 0%)

* `rgb(255,0,0)`

* `#f00`

* `#ff0000`

CSS 中预定义了某些颜色名称。它们包括黄色、蓝色、洋红色、柠檬绿、绿色、海军蓝、红色、白色、黑色、青色和橄榄绿等。CSS 还认为 `transparent`（透明）是一个有效值。除了黑色和白色之外，你会发现 CSS 样式规则很少使用颜色名称。这是由于这些名称具有很高的特异性，导致灵活性受到限制。

RGB 代码由三个值组成，每个值代表一种原色。值的范围从 0 到 255，阴色的最低色级用 0 表示。255 是最高可能值。以百分比的形式表示这些值也是可行的。

十六进制代码使用 16 进制体系。每个十六进制数字前面都有一个井号符号。在 CSS 中，它们的长度可以是三位或六位。三位数版本只是六位版本的简写形式。你会发现后版本允许你对颜色进行更大的控制。

## 使用 Color 属性

当你想要为文档应用颜色时，可以使用下面两个属性中的一个或两个。

* `Color`: 用于给文本应用颜色。

* `Background-color`: 用于给背景应用颜色。

在使用这些命令时，请确保你已正确输入了 `color`。浏览器不识别 `color.`。相反，它们可以理解 `color`。这些属性可以应用于几乎所有的 HTML 元素。

## 在 CSS 中样式化文本

文本是另一个常见的样式化项目，用于提高可读性等。CSS 为你提供了许多属性，可以使用它们来更改网页上文本的外观和布局。下面是文本中一些常用的属性。

### 1. font-family 属性

该属性定义文本的字体，例如 Verdana 和 Times New Roman。当你使用此属性时，需要确保浏览器能够找到指定为值的字体。这意味着该字体必须在用户的计算机上可用。如果你使用稀有或不常用的字体，你的用户可能无法使用该文件，因为他们的计算机上没有该字体。有很多字体在计算机上总是可用的，如上面的 Verdana、Times New Roman 以及 Arial 和 Calibri。



另一方面，你有能力将多个字体作为此属性的值。你需要借助逗号来分隔值。这允许浏览器在用户的计算机上搜索列表提到的字体之一。一旦找到正确的字体，该字体将用于显示文本。

请记住，浏览器将按照顺序遵循列表。因此，在你指定为`Arial, Verdana, serif`的列表中，浏览器将首先搜索`Arial`，如果找到它则使用它。如果没有，它将搜索`Verdana`字体，依此类推。你需要记住的另一点是，如果名称由两个或多个单词组成，则需要将字体名称放在引号中。

这里有一个显示如何使用该属性的简单示例。

```css
Font-family: Verdana, Arial, "Times New Roman", serif
```

## 2. Font-size

该属性设置文本的大小。当然，你可以设置任何想要的值。然而，你需要考虑内容的可读性。因此，你想要作为标题的文本应该具有较高的`font-size`值，但同时也应该具有适当的标题标签，如`<h1>`。你不应该简单地使用 HTML 段落元素并给它们设置更高的`font-size`。用于文本大小的常用单位有：

- **a) px (像素)** - 它是一个绝对单位，可以根据需要增加或减少文本的像素大小。
- **b) ems** – 父元素设置的字体大小等于`1em`。它可以用于任何内容的大小，而不只是文本。整个网站可以使用`ems`进行调整，从而使维护变得容易。
- **c) rems** - 它们的工作方式与`ems`类似，但文档根元素设置的字体大小等于`1rem`而不是父元素。这使得计算字体大小变得更容易。然而，Internet explorer 8 或更低版本不支持`rems`。

元素的`font-size`与父元素一致。在所有浏览器中，根元素的字体大小默认被设置为`16px`。因此，根元素内的任何段落都具有`16px`的`font-size`。

让我们来看这个简单的尺寸示例：

当你调整文本大小时，最好始终将文档的`font-size`设置为`10px`，这样计算就会容易得多。现在，当你这样做时，所需的`rem`或`ems`值将是像素字体大小除以 10，而不是除以其他数字。

## 3. Font-weight

该属性用于检查文本是否加粗。通常，此属性的值为 100 到 900 之间的任何值。这种增量确保了与旧浏览器的兼容性。

## 4. Font-style

该属性用于将文本样式化为斜体。此属性的可用值为`italic`或`normal`。

## 5. Text-decoration

该属性用于文本是否应该有下划线、删除线。如果你不需要这些效果，可以使用值`normal`。其他可用值如下：

- `Underline`: 给文本加下划线。
- `Line-Through`: 在文本上添加一条线。
- `Overline`: 在文本上方添加一条线。

## 6. Text drop shadows

文本投影有四个属性：

- **a) 水平偏移** - 它接受大多数可用的 CSS 大小长度单位。然而，通常使用`px`。此值必须包含。
- **b) 垂直偏移** - 阴影上下移动而不是左右移动。此值必须包含。
- **c) 模糊半径** - 阴影散得更开。在这种情况下如果没有包含此值，默认变为 0，这意味着没有模糊。此属性也接受大多数长度和大小单位。
- **d) 颜色** - 阴影的基础颜色，可以是任何 CSS 颜色单位。如果不包含，默认保持为黑色。

也可以通过逗号分隔多个投影值为文本设置多个投影。

## 7. Text Color

该属性用于设置文本的颜色。

## 8. Text Alignment

`text align`属性用于水平对齐文本。文本可以右对、左对、居中或两端。

```css
h1{text-align:right;}
```

当使用两端对齐时，文本每行都获得相同的宽度，左右边距是平直的。

```css
div{text-align:justify;}
```

## 9. Text transformation

这指定文本中的小写和大写字母。通过使用此属性，单词的首字母也可以写成大写。

```css
p.captitalize{text-transform:capitalize;}
```

## 10. Text Indentation

它指定第一行的缩进。

```css
p{text-indent:40px:}
```

## 12. 字间距 (Letter Spacing)

用于指定给定文本字符之间的间距。下面的示例展示了如何减少或增加间距

```css
h1 {letter-spacing: 5px;}
h2 {letter-spacing: -5px;}
```

## 13. 行高 (Line Height)

指定每行之间的间距。示例：

```css
p.small {line-height: 0.6;}
p.big {line-height: 1.6;}
```

## 12. 文本方向 (Text direction)

用于更改元素的方向。示例：

```css
div {direction: rtl;}
```

## 14. 词间距 (Word Spacing)

定义单词之间的间距。示例：

```css
H1 {word-spacing: 15px;}
H2 {word-spacing: -10px}
```

上述属性可以让你对如何在网页上样式化文本有一个大致了解。除此之外，当你熟悉了基础属性后，还有许多可以使用。下面列出了其中一些：

### 字体样式 (Font Style)

a) 字体变体 (Font variant)—在普通字体变体和小大写字母之间切换

b) 字体变体连字 (Font variant ligatures)—控制文本中使用哪些上下文形式和连字。

c) 字体变体数字 (Font variant numeric)—控制分数、数字和序数标记的替代字形的使用。

d) 字体伸缩 (Font stretch)—通过此选项可以在给定字体的所有可能的伸缩版本之间切换。

### 文本布局样式 (Text layout Styles)

a) 空白 (White space)—定义了如何处理元素内的空白和相关的换行。

b) 单词断行 (Word break)—指定是否要在单词内部进行断行。

c) 自动换行 (Word wrap)—定义浏览器是否可以在单词内部进行断行以避免溢出。

d) 编写模式 (Writing mode)—指定文本行是垂直布局还是水平布局，以及后续行的方向。

### CSS 快捷写 (Shortcuts in CSS)

既然我们已经学习了 CSS 的基础，我们正在编写该语言的某些快捷写，可以通过练习来。这些快捷写可以使你的代码更易读、加载更快且质量更高。快捷写是加快进程极极方法。然而，在使用它们时应该留心，因为如果使用不当，可能会产生负面结果。因此，始终要分析使用此类快捷写是否有益。

#### 属性分组 (Property Grouping)

此快捷写允许在一行中定义一组属性的一组值，而不是分行。

示例：使用字体

| 未分组 | 分组后 |
| :--- | :--- |
| `h1{font-weight: normal;font-size: 20px;line-height: 12px;font-family: georgia, tahoma, verdana;}` | `h1 {font: normal 20px/12px Georgia, Tahoma, verdana;}` |

#### 单行输入 (Typing on one line)

每个人编写代码的方法都不同，但有一个共同点：你使用的制表符和空格越少，你的代码加载就越快。其核心思想是创建没有过多空白的高可读性代码。在行内输入一组属性可以是此解决方案。

示例：

| 多行输入 | 单行输入 |
| :--- | :--- |
| `p{color: #4f39ac;background: #f4f4f4;line-height: 16px;}` | `P{color: 4f39ac; background: #f4f4f4; line-height: 16px;}` |

#### 颜色值缩写 (Color value shortening)

在为元素声明十六进制颜色值时，与其使用完整的 6 位值，你可以将其缩短为三个。如果颜色代码由三对重复的数字组成，这是可能的。

示例：

| | 颜色值缩写快捷写 |
| :--- | :--- |
| `body {background: #gggggg;}h1 {background: #aa5566;}p {background: #112233;}#menu {background: #ggaa44;}` | `body {background: #ggg}h1 {background: #a23;}p (background: #123;}#menu {background: #ga4;}` |

#### 使用零 (Using zeros)

当你使用零时，不需要使用`pt`, `px`, `em`或任何其他测量类型

示例：

```css
#menu {margin:20px 0;}
```

# 第 4 章：学习 JavaScript：让网页更具交互性

到目前为止，你已经学习了如何使用 HTML 创建基础网页。你还知道如何在 CSS 的帮助下让你的网页变得美观。然而，对于现代网页来说，这远远不够的。如今，网站需要具有交互性。为了实现这一点，你需要引入`JavaScript`。

## 什么是 JavaScript？

`JavaScript`是一种动态编程语言。当与 HTML 配合使用时，它可以为网页提供动态交互性。然而，`JavaScript`（简称`JS`）主要用作 HTML 文档中的脚本语言。这种语言不需要不断下载，并且可以轻松运行。它通常用于测验和投票。

## 理解脚本语言

在我们学习所有`JavaScript`之前，我们需要理解什么是脚本。它是一系列语句，为执行某些特定任务提供指令。通常情况下，脚本语言比结构化语言更容易学习，代码编写速度也更快。其他脚本语言的示例还有：`Python`、`PHP`、`Tcl`等。这些语言可以根植于 HTML 中，通常用于为网页添加功能，如图形显示或不同的菜单样式。脚本语言可以是客户端的，也可以是服务器端的。在客户端脚本语言下，用户看到的数据会受到影响；而在服务端脚本语言中，数据是在服务器的数据库中进行处理的。

`JavaScript`可用于向用户提供响应，甚至启动幻灯片。通过像`JavaScript`这样的脚本语言，基础网页可以转变为面向用户的生动平台。

## JavaScript 的历史

`JavaScript`创建于 1995 年，用于在网页浏览器`Netscape Navigator`中。这种语言的原始名称是`Mocha`，由 Netscape 创始人 Marc Andreessen 命名。在当年的晚些时候，名称被更改为`LiveScript`，在获得商标许可后，被命名为`JavaScript`。该语言的第一个商标版本于 1997 年发布，名称为`ECMAScript`。

今天，`JavaScript`已进入了完全全新的演进阶段。根据现代浏览器的发展，有了许多创新、标准化和新开发。

## JavaScript 的特性

1. **浏览器支持** - 大多数浏览器都接受这种脚本语言，因此不需要额外的插件。
2. **可以在服务器端和客户端同时使用** - 用户实际上可以在运行时更改网页的结构，因为`JavaScript`能够访问`DOM`（文档对象模型）。因此，它可以用于为网页添加不同的效果。此外，它也可以在服务器端使用。
3. **函数式编程语言** - 在这种语言中，函数可以像其他数据类型一样赋值给变量。此外，函数可以接受另一个函数作为参数。
4. **支持对象** - 它是一种面向对象的语言，使其易于学习和使用。
5. **其他特性 –**
   a) 它是一种区分大小的脚本语言。
   b) 它可以根据计算机的时钟时间显示信息或提取正确数据。
   c) 可以在自定义的窗口中打开页面，在其中你可以指定是否显示菜单行、浏览器按钮、状态栏或其他任何内容。
   d) 可以在不使用服务器程序的情况下随机显示内容。
   e) `JavaScript`中的所有语句都以分号结束。

## JavaScript 提供的优势

`JavaScript`是最多功能且又简单有效的语言。在我们学习了它广泛的用途和扩展功能之后，现在我们将看看该语言提供的一些优势。`JavaScript`为用户提供了一系列利益，其中一些如下：

1. **简单性**：`JavaScript`与`HTML`和`CSS`一样，非常容易学习。此外，你也可以同样轻松地开始实现`JavaScript`代码。它的语法非常简单，并且接近编写英语。`JavaScript`使用`DOM`模型，该模型对页面上的各种对象有许多预定义的功能。因此，为特定目的开发脚本变得非常容易。
2. **速度**：`JavaScript`在客户端执行。结果是所有代码函数都可以立即执行。不需要联系服务器并等待响应。这使得`JavaScript`运行得非常快。
3. **多功能性**：`JavaScript`与许多其他语言兼容。事实上，无论文件扩展名如何，将`JavaScript`插入到任何网页中都是可行的。你还可以在用`PHP`、`Perl`和其他语言编写的脚本中使用`JavaScript`。因此，`JavaScript`可用于广泛的领域。
4. **API 可用性**：应用程序编程接口（简称`APIs`）的存在为`JavaScript`提供了一系列功能。这包括设置`CSS`样式、生成音频样本以及动态创建`HTML`等。虽然这些`APIs`内置在不同的网络浏览器中，但也有第三方`APIs`，允许你整合来自其他网络属性的功能，如`Facebook`这样的社交网络。
5. **扩展功能 –**：`JavaScript`有第三方插件，如`Greasemonkey`。该插件允许开发者编写该语言的片段，这些片段可以在所需的页面上执行以扩展其功能。例如，如果你想为网站添加一个功能，你可以自己编写并使用此插件实现在网页上。

## JavaScript 的缺点

从理论上讲，这种语言对开发者非常有益，但在实践中它也有缺点：

1. **安全性** – 一旦编写好的`JavaScript`代码段附加到网页上，它们就会在客户端立即执行，因此可能被用来过度利用用户的系统。虽然根据现代网页标准设置了某些限制，但恶意代码仍然可以执行。
2. **不一致性 –** `JavaScript`可能会由不同的布局引擎进行渲染，导致在界面和功能方面存在不一致。然而，最新版本的`JavaScript`已根据通用标准进行了调整，但仍然存在某些差异。
3. **执行速度慢**：该语言中复杂的脚本需要较长的启动和运行时间。

## JavaScript 基础

JavaScript 已经成为互联网上最突出的语言之一。它可以跨平台并在各种浏览器中运行。因此，为了在现实世界中使用这种语言，我们需要首先学习它的基础知识。这将使你对 JavaScript 有基础的理解。

### 1. 变量

如你所知，变量是存储数据的容器。存储在变量中的数据可以是表达式或值。在 JavaScript 语言中，表达式有三种类型。

| 表达式 | 描述 |
| :--- | :--- |
| 逻辑 | 评估为布尔值，即 `true` 或 `false` |
| 算术 | 评估为数字 |
| 字符串 | 评估为字符串 |

#### JavaScript 中变量的作用域

变量作用域是指定义变量的程序区域。JavaScript 中的变量可以是两种作用域之一。

**全局变量：** 由于其全局作用域，这些变量可以在代码的任何地方定义。

**局部变量：** 这些变量仅存在于定义它的函数内部。函数参数始终是该特定函数的局部变量。

可以使用 `var` 关键字声明局部变量，而全局变量应该在不使用 `var` 关键字的情况下使用。例如：如果在函数内部声明局部变量，则它无法在函数外部访问，因此它是该函数的局部的。如果你在不使用 `var` 关键字的情况下声明相同的变量，它对整个脚本可见，而不仅仅是在函数内部。

在 JavaScript 中，如果存在具有相同名的全局变量，则局部变量在函数体内部具有优先级。通过声明一个与全局变量同名的局部变量，你实际上在函数内部隐藏了该全局变量。

让我们来看一个局部变量的示例：

```javascript
var num= 20;
```

如果你想在脚本的其他地方访问 `num` 变量的值，只需引用变量名即可。`document.write` 函数将数据写入网页。

查看下面的语法：

```javascript
document.write("The value of num is: " +num);
```

我们将得到的结果是“The value of num is: 20”。

为了在变量中存储算术表达式，我们只需要将变量赋值为计算后的值。存储在变量中的不是计算过程，而是计算的结果。因此，我们再次将得到结果“The value of num is 20”。看下面的示例：

```javascript
var num = (10+10);
document.write( " The value of num is: "+ num);
```

如果你想更改变量的值，请通过分配给它的名称引用变量，然后使用等号为其分配新值。唯一的区别是你不再需要使用 `var` 关键字，因为变量已经声明过了。

```javascript
var num =20
document.write( " The value of num is: " +num);
//update the value of num to 30
num=30;
document.write( " The new value of num is: "+ num);
```

因此此脚本的结果将是“The value of num is 20”，然后是“The value of num is 30”。

这里是另一个变量的示例，以便更好地理解该概念。

```html
<script type="text/javascript">
<!---->
var money;
var name;
//-->
</script>
```

在上面的示例中，使用了两次 `var` 关键字来声明两个变量 `money` 和 `name`。然而，JavaScript 允许使用一个 `var` 关键字声明多个变量。你可以在下面的示例中看到这种操作。

```html
<script type="text/javascript">
<!--
var money, name;
//-->
</script>
```

当值存储在变量中时发生变量初始化。在 JavaScript 中，可以在声明变量时进行初始化。或者，你可以在需要该变量时再进行初始化。你可以在下面的示例中看到这种操作。

```html
<script type="text/javascript">
<!--
var name = "John";
var money;
money = 12.30;
//-->
</script>
```

使用变量时，有两点需要记住。

- `var` 关键字必须用于声明或初始化。因此，在单个程序的任何变量生命周期内，它只会被使用一次。同一个变量不能声明两次，否则可能会导致错误。
- 由于 JavaScript 是一种弱类型语言，变量可以持有任何值，无论数据类型如何。也就是说，在声明时不需要指定该变量应该包含什么类型的值。

### 变量命名规则

当你给变量命名时，需要记住以下规则：

- 所有 JavaScript 变量都有唯一的名称，称为标识符。这些可以是短名称如 `a` 和 `b`，也可以是描述性名称如 `sum`、`age` 等。
- JavaScript 关键字不能作为名称。
- 变量名不能以数字开头。必须以字母或下划线开头。名称也可以以 `$` 符号开头。
- 如前，JavaScript 对大小写敏感。因此，必须相应使用变量名。

除了所有关键字外，某些词不能作为 JavaScript 函数、变量、循环标签、方法或对象名称。列举如下：

| Abstract | Boolean | Break | Switch | Else |
| :--- | :--- | :--- | :--- | :--- |
| Extends | Long | Interface | throw | This |
| Byte | False | Case | New | null |
| Class | Final | with | True | float |

### 2. 数据类型

如你所知，数据类型表示编程语言中使用的值的种类。JavaScript 中有两种数据类型：

b) 非原始

## 数组

它们与变量非常相似，不同之处在于可以在一个名称下存储多个表达式和值，因此成为一种强大的数据类型。只要在作用范围内，数组中可以存储的数据量没有限制。只要在脚本中进行了声明，就可以访问任何时间点的任何项的任何值。相同类型的数据可以存储在同一个数组中，并且该特定数组可以被分配一个与其所包含的项相关的名称。

让我们来看一个例子：

```javascript
var shapes = new Array("rectangle", "square", "triangle");
var colors = new Array( "red", "pink", "orange");
```

要访问数组中的任何项，你必须使用它的 ID。它是该项在数组中的位置。数组的 ID 始终从 0 开始而不是 1，这在开始可能会让人困惑，但通过练习，你会发现这个概念很容易学习。ID 按升顺序工作；例如 0,1,2,3 等。下面是一个用于理解这一概念的示例——

```javascript
var colors = new Array( "red", "pink", "green");
document.write( "red: "+colors[0]);
document.write( "pink: "+colors[1]);
document.write( "green: "+colors[2]);
```

在数组中，你也可以给特定位置赋值。例如：

```javascript
var colors = new Array ();
colors [0] = "red";
colors [1] = "pink";
colors [2] = "green";
document.write ("pink: "+colors [2]);
//将 pink 更新为 blue
colors [1] = "blue";
document.write ("blue: "+ colors [2]);
```

## 3. 条件语句

与其他编程语言一样，JavaScript 中提供了不同类型的条件语句。它们允许你定义一个条件，其结果决定了将执行的操作。它们允许你的程序根据条件的结果做出决定并执行相关操作。

为了在编程语言中创建任何类型的逻辑，条件语句是其基础。在 JavaScript 中，条件语句可以用四种方式编写。

| 语句 | 描述 |
| :--- | :--- |
| `Switch` | 在多个脚本中执行一个 |
| `If` | 如果特定条件的 Result 为真，则执行脚本 |
| `If..else` | 此条件语句中有两段代码。如果条件为真，`if` 语句执行脚本，而当条件为假时，执行 `else` 语句下的代码 |
| `If..else if..else` | 如果无限个条件中的某一个为真，则执行脚本；如果所有条件都为假，则执行另一个脚本。 |

`if…else` 语句的基本语法如下所示。

```javascript
if (expression) {
    如果 expression 为真，则执行的语句
}
```

示例：

**if**

```javascript
var num=20;
if (num==10)
{
  document.write( "num is equal to 10");
}
```

**if..else**

```javascript
var num=20;
if (num==10)
{
  document.write( "num is equal to 10");
}
else
{
  document.write( "num is not equal to 10");
}
```

**if..else if..else**

```javascript
var num=20;
if (num==10)
{
  document.write( "num is equal to 10");
}
else if (num==20)
{
  document.write( "num is equal to 20");
}
else
{
  document.write( "num is not equal to 10 or 20");
}
```

**switch**

```javascript
var num=20;
switch (num)
{
  case 10:
    document.write("num is equal to 10");
    break;
  case 20:
    document.write("num is equal to 20");
    break;
  default:
    document.write("num is not 10 or 20");
}
```

结构化函数时使用 `function` 单词后跟一个空格。函数的名称可以是任何内容；然而，应确保给定的名称与其将执行的任务相关。示例：

## 6. 循环

循环用于迭代数组并在访问值的同时执行脚本。循环通常包含一个分配了数值的变量。该变量随后比较运算符与其他值进行比较。之后，数值增加或减少。循环中的比较通常决定变量的初始值是大于还是小于另一个数值。因此，只要条件为真，循环就会运行，变量的值增加或减少，直到条件变为假。

### a) for 循环

`for` 循环允许在满足特定条件时重复执行相同的代码块语句。`for` 循环的语法如下。

```javascript
for (初始表达式; 条件表达式; 循环表达式)
{
    语句
}
```

**示例：**

```javascript
var colors = new array( "red", "pink", "green");

for var (i=0; i<colors.length; i++)

{

document.write( "The color is: "+ colors[i] +"<br/>");

}
```

上面的示例展示了一个 `for` 循环，该循环一直运行到数值小于数组长度为止。

### b) while 循环

通过 `while` 循环，可以控制循环执行的次数。换句话说，当你知道循环需要执行的次数时，就会使用这种循环。因此，你需要确保循环写得正确，以免导致无限循环。`while` 循环的语法如下所示。

```javascript
while (expression) {
    如果表达式为真，则执行的语句(s)
}
```

**示例：**

```javascript
var i =0;

while (i<10)

{

document.write(i + "<br/>");

i++;
}
```

在上面的示例脚本中，这种类型的循环包含一行代码，它会重复该数值，直到 `while` 循环中的条件为假。所以，如果没有这一行，它将变成死循环。

## 如何在 HTML 文档中放置 JavaScript？

JavaScript 的优点之一是你可以灵活地在 HTML 文档的任何地方添加代码。尽管如此，遵循首选方法是一个极好的主意。这可以提高 HTML 文档中 JavaScript 代码的可读性和执行效率。以下是将 JavaScript 包含在 HTML 中的最佳方法。

### 在 `<head>` 标签内部

这种选项通常用于你想在事件发生时运行脚本的情况。例如，你可能希望在用户点击某处的内容时运行脚本。在这些情况下，脚本将放置在 `<head>` 标签内部，如下例所示。

```html
<html>
<head>
<script type="text/javascript">
<!--
function sayHello () {
alert ("Hello World")
}
//-->
</script>
</head>
<body>
<input type="button" onclick="sayHello ()" value="Say Hello" />
</body>
</html>
```

### 在 `<body>` 标签内部

在某些情况下，你可能需要脚本在页面加载时运行。这样做是为了允许脚本生成页面中的内容。在这种情况下，脚本必须放置在 `<body>` 标签内部。在这种方法中，你将不会使用任何用 JavaScript 定义的函数。你可以看到下面提供的此类 JavaScript 包含的示例。

```html
<html>
<head>
</head>
<body>
<script type="text/javascript">
<!--
document.write ("Hello World")
//-->
</script>
<p>Web Page</p>
</body>
</html>
```

### 在 `<head>` 和 `<body>` 标签内部

如果你愿意，可以结合上述方法。换句话说，你可以将 JavaScript 同时放置在 `<head>` 和 `<body>` 中。下面的示例展示了它是如何工作的。

### 在外部文件中

当你创建简单的网页时，将 JavaScript 包含在 HTML 文档内部是一个好主意。然而，当你创建网站或复杂的网页时，可能会发现自己在多个地方重复相同的代码。你甚至会在多个网页中使用相同的代码。

## JavaScript 中的事件

事件是导致 JavaScript 代码执行的操作。事件通常由用户触发。例如，鼠标的点击可以是一种事件。基于事件，你可以在 JavaScript 中编写响应。例如，显示消息可以是对事件的响应。这些响应可以认为是事件处理器，因为它们处理了发生的事件。在 JavaScript 中，可以以多种方式对事件进行分类。毕竟，它们非常多。

### onClick 事件

常见的事件类型是 `onClick` 事件。每当用户左键点击网页时，该事件就会发生。针对这种事件，你可以做出相应的响应，例如显示消息或进行你的验证。下面的示例展示了如何使用此类事件来显示消息。

```html
<html>
<head>
<script type="text/javascript">
<!--
function sayHello () {
alert ("Hello World")
}
//-->
</script>
</head>
<body>
<p>点击下方按钮并查看结果</p>
<form>
<input type="button" onclick="sayHello ()" value="Say Hello" />
</form>
</body>
</html>
```

### onSubmit 事件类型

此类型的事件在表单提交时发生。可以将表单验证绑定到此事件上。让我们来看一个示例——

如果下文示例中的 `validate()` 函数返回 `true`，则表单会被提交；否则表单将不会提交。

```html
<html>
<head>
<script type="text/javascript">
<!--

// 所有的验证逻辑都写在这里
// ……
// 返回 true 或 false
}
//-->

</head>
<body>

……
<input type="submit" value="Submit"/>
</form>
</body>
</html>
```

### onmouseover 和 onmouseout

此事件对图像和文本都有很好的效果。当你的鼠标悬停在元素上时，会触发 `onmouseover` 事件；当鼠标移出时，会触发 `onmouseout` 事件。示例：

```html
</div>
</body>
</html>
```

## 关于使用 JavaScript 的一些提示

1. 确保 JavaScript 能帮助用户高效、快速地实现目标。如果不能这样做，说明你可能用法不当。

2. 你提供给用户的 JavaScript 解决方案应该比之前的交互更自然。然而，解决方案不应过于独特，以至于用户无法根据以往经验产生联系。目标是确保终端用户对解决方案感到满意。

3. 如果你在处理敏感数据，请不要依赖 JavaScript，因为所有代码都易于被读取。此外，用户可能会在浏览器中关闭 JavaScript。

我们可以说，这种简单但丰富的脚本语言有许多可能性。JavaScript 提供了工具，允许终端用户在页面下载后与其进行交互。在本章中，我们学习了 JavaScript 的基础知识，现在让我们来看一些关于这种编程语言的常见问题。

## 常见问题 (FAQ)

**JavaScript 和 Java 相同吗？**

答：不同，它们是不同的编程语言。Java 是一种通用编程语言，而 JavaScript 用于使网站更具交互性。

**哪些浏览器支持 JavaScript？**

答：大多数浏览器都支持 JavaScript。列出部分：

* Microsoft Internet Explorer 3.0 及以上版本
* Netscape Navigator 2.0 及以上版本
* Safari
* Firefox
* Google Chrome
* Opera

**如何在 JavaScript 中添加注释？**

答：JavaScript 支持三种不同类型的注释：

a) 多行 C 风格注释，`/*` 和 `*/` 之间的所有内容都是注释

b) C++ 风格的单行注释。此类注释以 `//` 开头，并持续到下一行结束。

c) HTML 风格注释以 `<!--` 开头

**当用户无法执行 JavaScript 代码时，可以向用户显示警告吗？**

答：可以，可以向不支持 JavaScript 的浏览器用户显示警告。警告文本可以放置在 `<NOSCRIPT>` 和 `</NOSCRIPT>` 标签之间。

因此，启用了 JavaScript 的浏览器将忽略这些标签之间的所有内容，而无法执行的浏览器将在页面上显示你的消息。该消息将显示给禁用了 JavaScript 的用户，以及那些浏览器不支持 JavaScript 的用户。

**可以删除 JavaScript 变量吗？**

答：你不能总是删除 JavaScript 变量，这取决于以下条件：

a) 如果 JavaScript 变量第一次是使用关键字 `var x;` 声明的，则无法删除。但作为变通方法，可以将变量设置为 `null` 或 `undefined`。但这不等同于删除变量。

b) 如果变量 `x` 第一次在脚本中出现时没有任何声明，可以使用 `delete` 操作符，即 `delete x`。

**JavaScript 程序不能做什么？**

答：使用 JavaScript 代码无法完成以下操作：

a) 不能在客户端局域网或用户系统上打印机或其他设备。

b) 直接访问用户系统或客户端局域网上的文件。唯一的例外是 cookie 文件。

c) 实现多线程或多进程是不可能的。

**删除数组元素的方法是什么？**

答：在 JavaScript 中删除数组元素有两种方法，它们是：

a) `myArray.splice(n,1)`。这是一个较慢的方法，但会留下空格。

b) `delete myArray[n]`。

**有方法判断用户是否点击了右键吗？可以使用 onclick 事件处理器吗？**

答：对于左键，会触发点击事件。然而，取决于浏览器，右键可能不会发生点击事件。因此，`onclick` 事件处理器不是处理右键的可靠方法。相反，我们应该使用 `mousedown` 事件。大多数浏览器支持任何按钮的 `mouseup` 和 `mousedown` 事件。

**JavaScript 可以使用什么样的数字格式？**

答：JavaScript 代码中可以使用多种方式编写数学常量和数字字面量，例如：

a) 指数形式的十进制，例如 `5.57e-11`

b) 常规十进制数，例如 `5,7,137`

c) 八进制数，例如 `-0550124`

d) 以零开头的正八进制和以零开头的负八进制。

e) 十六进制，例如 `0xFF,-0xFF`。正十六进制以 `0x` 开头，负十六进制以 `-0x` 开头。

f) 预定义的数学常量，例如 `Math.PI` //pi = 3.14159…

**如何测试特定变量持有字符串还是数字？**

答：测试变量持有字符串还是数字是通过使用 `typeof` 操作符。如果变量持有字符串，`typeof(variable)` 将返回 `"string"`；如果它持有数字，则返回 `"number"`。

这三种语言是交织在一起的：`HTML` 提供了网站的基本结构，并通过 `JavaScript` 和 `CSS` 对其进行了增强和修改。`CSS` 告诉 `HTML` 应该使用什么颜色、字体和其他样式，而 `JavaScript` 则告诉 `HTML` 如何执行某些任务，如弹出窗口等。

在学习 Web 开发时，最需要记住的两个点是：

a) 使用正确的 `HTML` 标签 – 内容结构由不同的 `HTML` 标签来描述，每个标签都有其特定的含义和定义的位置。

b) 保持你的 `JavaScript`、`HTML` 和 `CSS` 代码分离 - 始终将 `JavaScript` 和 `CSS` 放在于 `HTML` 文件之外的独立文件中。这将让你的工作变得简单，并且你能够更好地进行管理。因此，将所有的样式和功能性代码放在一个地方会让事情变得轻松。
