# (399) 总体观察

《提姆王爵》是一部家庭悲剧，因此强烈地抓住了读者的注意力。在计划上并没有太多技巧，但情节是自然的，人物是多样且精确的。结局提供了一种强有力的警告，反对这种——它消散了慷慨，没有产生任何好处，且带有谄媚，而非友谊。

剧中许多段落错综复杂、晦涩，且可能是错误的，我已努力对其修正或解释；但由于只有一个副本，无法保证我的努力会受到广泛赞誉。

# IV.iv.90 (472,4)

用更甜美的话，却更危险，比鱼饵或诱羊的蜜茎更危险。蜜源是三叶草花，含有甜汁。牲畜会过度负荷并死亡。

我不知道，但在二十五岁这一年纪，去偷鹿已经太晚了。拉文斯克罗夫（Ravenscroft）在查理二世统治时期修订了这部剧并将其重新投入舞台，他在序言中告诉我们（我想是基于他那个时代可能具有足够权威性的戏剧传统），这部剧的不同部分由莎士比亚修改过，但是由另一位诗人创作的。我并没有发现莎士比亚的笔迹非常明显（见 1765, VI, 364）（重订于 1778, VIII, 559）。

# 《特洛罗斯与克丽西达》

# 序言。(4,2)

我已来到此处

一个身披甲胄的序言；并非得信作者的笔触或演员的嗓；而是根据我们的情节调整了行文条件。

我来到这里是为了朗读序言，并穿着盔甲；并非挑战观众，也不是得信作者或演员的能力，而是仅仅为了一个符合主题的角色，穿着战争的服饰，在一场战争剧之前登场。

# II.12 (8,3)

像毫无经验的童年一样笨拙！德莱登（Mr. Dryden）在修改此剧时保留了这段话的原样，他说他将“skill-less”（笨拙的）改为“artless”（天真的），这并非为了变得更好，因为“skill-less”指的是技巧和技艺。

# II.58 (10,4)

天鹅歌是刺耳的，感官的精神/像农夫的手掌一样坚硬！他说，随着克丽西达的手，感觉的精神——最高境界、最细腻的感知（暗示了一只柔软的手，因为正如斯卡利格（Scaliger）在《练习集》中所说，触觉主要集中在手指上）——像农夫老茧且无知的手掌一样坚硬。沃伯顿（WARBURTON）读作：

- 违背理（SPITE of sense）：针对感觉的精神。

让一个情人宣称违背理智赞美他的情人是不恰当的；因为尽管他是出于别人的感受这样做，但他自己的感官已经屈服于欲望。
