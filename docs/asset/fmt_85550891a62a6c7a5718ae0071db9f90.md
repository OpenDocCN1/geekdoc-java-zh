
## 图 10.4 | Employee 父类（第一部分）

为什么我们将 `earnings` 声明为抽象方法？在 `Employee` 类中提供该方法的特定实现可能没有意义。我们无法为通用 `Employee` 计算收益——我们必须先知道具体的类型。通过将此方法声明为抽象，我们指示每个子类必须提供实现，并且程序可以使用父类 `Employee` 变量多态地调用方法。

## 10.5.2 具体子类 SalariedEmployee

`SalariedEmployee` 类（图 10.5）扩展 `Employee`（第 4 行）并重写抽象方法 `earnings`（第 38–42 行），这使得 `SalariedEmployee` 是具体的。该类包含一个构造函数（第 9–19 行），需要名、姓、社会安全号码和周薪；一个为实例变量 `weeklySalary` 设置非负值的方法（第 22–29 行）；一个返回 `weeklySalary` 的方法（第 32–35 行）；计算 `SalariedEmployee` 收益的 `earnings`（第 38–42 行）；以及一个 `toString` 方法（第 45–50 行），它返回一个包含“salaried employee: ”以及由父类 `toString` 方法生成的特定信息和 `SalariedEmployee` `weeklySalary` 的字符串。`SalariedEmployee` 构造函数将名、姓和社会安全号码传递给 `Employee` 构造函数（第 12 行），以初始化父类的私有变量。

> **错误预防提示 10.1**
> 我们说过不要在构造函数中调用静态方法——你可以调用静态方法并对父类的任何构造函数进行调用。如果你遵循这一建议，将能够避免直接或间接调用类重写方法的问题，这会导致运行时错误。

`earnings` 方法重写了 `Employee` 的抽象方法，以提供一个具体的实现，返回 `SalariedEmployee` 的周薪。如果我们不实现 `earnings` 方法，`SalariedEmployee` 类必须声明为抽象类——否则，`SalariedEmployee` 类将无法编译。当然，我们希望在这个例子中 `SalariedEmployee` 是一个具体类。

方法 `toString`（第 45–50 行）重写了 `Employee` 的 `toString` 方法。如果 `SalariedEmployee` 类没有重写 `toString`，那么 `SalariedEmployee` 将继承 `Employee` 版本的 `toString`。在这种情况下，`SalariedEmployee` 的 `toString` 方法将隐式地返回 `Employee` 的全名和社会安全号，这并不能体现一个 `SalariedEmployee` 的特征。子类的 `toString` 返回 "salaried employee"，随后是父类 `Employee` 的特有信息（即通过调用父类 `toString` 方法（第 49 行）获取的名、姓和社会安全号）——这是代码重用的一个示例。`SalariedEmployee` 的字符串表示还包含了通过调用类的 `getWeeklySalary` 方法获取的员工薪资。

```java
// 图 10.5: SalariedEmployee.java
// SalariedEmployee 具体类继承抽象类 Employee

public class SalariedEmployee extends Employee {

    private double weeklySalary;

    // 构造函数
    public SalariedEmployee(String firstName, String lastName,
        String socialSecurityNumber, double weeklySalary) {

        super(firstName, lastName, socialSecurityNumber);

        if (weeklySalary < 0.0)
            throw new IllegalArgumentException(
                "每周薪必须 >= 0.0"
            );

        this.weeklySalary = weeklySalary;
    }

    // 设置周薪
    public void setWeeklySalary(double weeklySalary) {
        if (weeklySalary < 0.0)
            throw new IllegalArgumentException(
                "每周薪必须 >= 0.0"
            );
        this.weeklySalary = weeklySalary;
    }

    // 返回周薪
    public double getWeeklySalary() {
        return weeklySalary;
    }

    // 计算收益；重写 Employee 中的抽象方法 earnings
    @Override
    public double earnings() {
        return getWeeklySalary();
    }

    // 返回 SalariedEmployee对象的字符串表示
    @Override
    public String toString() {
        return String.format("salaried employee: %s%s: $%.2f",
            super.toString(), "weekly salary", getWeeklySalary());
    }
} // 结束类 SalariedEmployee
```

## 10.5 案例研究：使用多态的薪资系统

### 10.5.3 子类 HourlyEmployee

`HourlyEmployee`（图 10.6）继承自 `Employee`（第 4 行）。该类包含一个构造函数（第 10–25 行），接收名字、姓、社会安全号、每小时工资和工作小时数。第 28–35 行和 44–51 行设置了设置方法，分别为实例变量 `wage` 和 `hours` 分配新值。`setWage` 方法（第 28–35 行）确保值不为负，而 `setHours` 方法（第 44–51 行）确保小时数的值在 0 到 168 之间（一周的总小时数），包含边界。`HourlyEmployee` 还包括 `get` 方法（第 38–41 行和 54–57 行）用于返回小时数和工资的值；一个 `earnings` 方法和一个 `toString` 方法（第 60–67 行）用于计算 `HourlyEmployee` 的收益；包含员工类型（"hourly employee"）和员工特有信息。

`HourlyEmployee` 构造函数与 `SalariedEmployee` 构造函数一样，将名字、姓和社会安全号传递给父类 `Employee` 构造函数（第 13 行），以初始化私有实例变量。此外，`toString` 方法调用了父类 `Employee` 特有信息（即名、姓和社会安全号）——这是另一个代码重用的示例。

```java
// 图 10.6: HourlyEmployee.java
// HourlyEmployee 类继承 Employee。

public class HourlyEmployee extends Employee {

    private double wage; // 每小时工资
    private double hours; // 工作小时数

    // 构造函数
    public HourlyEmployee(String firstName, String lastName,
        String socialSecurityNumber, double wage, double hours) {

        super(firstName, lastName, socialSecurityNumber);

        if (wage < 0.0) // 验证
            throw new IllegalArgumentException(
                "工资必须 >= 0.0");

        if (hours < 0.0 || hours > 168) // 验证
            throw new IllegalArgumentException(
                "小时数必须在 0 到 168 之间");

        this.wage = wage;
        this.hours = hours;
    }

    // 设置工资
    public void setWage(double wage) {
        if (wage < 0.0)
            throw new IllegalArgumentException(
                "工资必须 >= 0.0");
        this.wage = wage;
    }

    // 返回工资
    public double getWage() {
        return wage;
    }

    // 设置小时数
    public void setHours(double hours) {
        if (hours < 0.0 || hours > 168)
            throw new IllegalArgumentException(
                "小时数必须在 0 到 168 之间");
        this.hours = hours;
    }

    // 返回小时数
    public double getHours() {
        return hours;
    }

    // 计算收益；重写 Employee 中的抽象方法 earnings
    @Override
    public double earnings() {
        if (getHours() <= 40)
            return getWage() * getHours();
        else
            return 40 * getWage() + (getHours() - 40) * getWage() * 1.5;
    }

    // 返回 HourlyEmployee 字符串表示
    @Override
    public String toString() {
        return String.format("hourly employee: %s%s: $%.2f, %s: $%.2f",
            super.toString(), "hourly wage", getWage(), "hours", getHours());
    }
} // 结束类 HourlyEmployee
```

### 10.5.4 具体子类 CommissionEmployee

`CommissionEmployee`（图 10.7）继承自 `Employee`。该类包含一个构造函数（第 10–25 行），接收名字、姓、社会安全号、金额和佣金率；设置方法（第 28–34 行和 43–50 行）为实例变量 `commissionRate` 和 `grossSales` 赋值；`get` 方法（第 37–40 行）获取这些实例变量的值；`earnings` 方法（第 59–63 行）计算 `CommissionEmployee` 的收益；`toString` 方法返回员工类型，即 "commission employee:" 以及员工特有信息。构造函数还将名、姓和社会安全号传递给 `Employee` 的构造函数（第 14 行），以初始化 `Employee` 的私有实例变量。`toString` 方法调用父类 `toString` 方法（第 70 行）获取 `Employee` 特有信息（即名、姓和社会安全号）。

```java
// 图 10.7: CommissionEmployee.java
// CommissionEmployee extends Employee。

public class CommissionEmployee extends Employee {

    private double grossSales; // 每周总销售额
    private double commissionRate; // 佣金比例

    // 构造函数
    public CommissionEmployee(String firstName, String lastName,
        String socialSecurityNumber, double grossSales,
        double commissionRate) {

        super(firstName, lastName, socialSecurityNumber);

        if (commissionRate < 0.0 || commissionRate >= 1.0) // 验证
            throw new IllegalArgumentException(
                "佣金率必须大于 0.0 且小于 1.0");

        if (grossSales < 0.0) // 验证
            throw new IllegalArgumentException("销售额必须 >= 0.0");

        this.grossSales = grossSales;
        this.commissionRate = commissionRate;
    }

    // 设置销售额
    public void setGrossSales(double grossSales) {
        if (grossSales < 0.0)
            throw new IllegalArgumentException("销售额必须 >= 0.0");
        this.grossSales = grossSales;
    }

    // 返回销售额
    public double getGrossSales() {
        return grossSales;
    }

    // 设置佣金率
    public void setCommissionRate(double commissionRate) {
        if (commissionRate < 0.0 || commissionRate >= 1.0)
            throw new IllegalArgumentException(
                "佣金率必须大于 0.0 且小于 1.0");
        this.commissionRate = commissionRate;
    }

    // 返回佣金率
    public double getCommissionRate() {
        return commissionRate;
    }

    // 计算收益；重写 Employee 中的抽象方法
    @Override
    public double earnings() {
        return grossSales * commissionRate;
    }

    // 返回 CommissionEmployee 字符串表示
    @Override
    public String toString() {
        return String.format("commission employee: %s%s: $%.2f",
            super.toString(), "gross sales", grossSales);
    }
} // 结束类 CommissionEmployee
```
