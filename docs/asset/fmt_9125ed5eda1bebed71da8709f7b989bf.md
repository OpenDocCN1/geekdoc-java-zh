# 10.10 Java 8 增强

本节介绍了 Java 8 的新特性。我们将详细讨论这些特性。

### 10.10.1 默认方法

在 Java 8 之前，接口方法只能是抽象的。这意味着接口规定了实现类必须执行哪些操作，但没有规定如何执行。在 Java 8 中，接口也可以包含具有具体实现的默认方法。要声明默认方法，请在方法返回类型之前使用 `default` 关键字。

### 10.10.2 向现有接口添加方法

在 Java 8 之前，向接口添加方法会破坏实现该接口的类。在 Java 8 中，默认方法允许你在不破坏现有代码的情况下演进接口。

#### 接口 vs 抽象类

在 Java 8 之前，通常使用抽象类来创建接口方法的实现。在 Java 8 中，默认方法允许你在接口中直接声明实现，提供了更大的灵活性。

### 10.10.3 静态方法

在 Java 8 之前，通常将静态方法放在单独的工具类中与接口相关联。在 Java 8 中，接口现在可以包含带有具体实现的静态方法。我们在第 16 章中学习关于 `Collections`。

### 10.10.4 函数式接口

在 Java 8 中，仅包含一个抽象方法的接口被称为函数式接口。整个 Java SE 有许多此类接口，你将在书中经常使用它们：

- `ActionListener`（第 12 章）——实现此接口以定义点击按钮时的方法。
- `Comparator`（第 16 章）——实现此接口以定义两个给定类型对象的第一个是否小于第二个。
- `Runnable`（第 23 章）——实现此接口以定义可以与其他部分并行运行的任务。

函数式接口通过 Java 8 引入的 `lambda` 功能被广泛使用，它们会被编译器自动转换为匿名内部类。

如果你知道空间中的两个点，就可以绘制直线、矩形和椭圆。直线需要 `x1`、`y1`、`x2` 和 `y2` 坐标。`Graphics` 类的 `drawLine()` 方法将用直线连接所提供的两个点。如果你有椭圆和矩形的四个坐标（`x1`, `y1`, `x2` 和 `y2`），你就可以计算出绘制（`draw`）所需的四个参数。每个参数需要一个左上 `x` 坐标（两个 `x` 坐标中较小的一个）、一个左上 `y` 坐标值、宽度（两个 `x` 坐标值差的绝对值）和一个高度（两个 `y` 坐标值差的绝对值）。矩形和椭圆还应该有一个填充标志位，用于决定是否以填充方式绘制形状。

允许用户（通过输入）指定生成的形状数量。程序将生成并绘制这些形状，并带有状态栏通知用户创建了多少个形状。
