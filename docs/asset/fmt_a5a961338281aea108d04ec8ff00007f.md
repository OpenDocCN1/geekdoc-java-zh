## 第 5 章：方法链调用

Python 和 Java 都允许方法链调用，即可以在同一个对象按顺序调用多个方法。

**Python 示例：**

```python
class Calculator:
    def __init__(self):
        self.value = 0

    def add(self, num):
        self.value += num
        return self

    def multiply(self, num):
        self.value *= num
        return self

calc = Calculator()
result = calc.add(10).multiply(5).value
print(result) # Output: 50
```

**Java 示例：**

```java
public class Calculator {
    private int value;

    public Calculator() {
        this.value = 0;
    }

    public Calculator add(int num) {
        this.value += num;
        return this;
    }

    public Calculator multiply(int num) {
        this.value *= num;
        return this;
    }

    public int getValue() {
        return value;
    }

    public static void main(String[] args) {
        Calculator calc = new Calculator();
        int result = calc.add(10).multiply(5).getValue();
        System.out.println(result); // Output: 50
    }
}
```

## 第 6 章：异常处理

异常处理是编程中至关重要的一部分，允许开发者优雅地处理意外或错误情况。当程序执行过程中发生错误时会抛出异常，适当处理这些异常可以防止程序崩溃并为调试提供有用的信息。在本章中，我们将探索 Java 和 Python 中的异常处理，并结合实际示例演示如何处理各种类型的异常。

### 第 1 节：异常处理基础

#### 异常类体系

在 Java 和 Python 中，异常都按照类层次结构组织。基类通常命名为 `Exception`，各种特定的异常都派生自它。这种层次结构允许开发者根据异常类型更有效地处理异常。

#### Java 示例：

```java
try {
    // 可能会抛出异常的代码
} catch (Exception e) {
    // 异常处理代码
}
```

#### Python 示例：

```python
try:
    # 可能会抛出异常的代码
except Exception as e:
    # 异常处理代码
```

### 第 2 节：处理特定异常

Java 和 Python 都允许开发者单独或分组处理特定异常。

#### Java 示例：

```java
try {
    int result = divide(10, 0);
    System.out.println("Result: " + result);
} catch (ArithmeticException e) {
    System.out.println("不能除以零.");
} catch (Exception e) {
    System.out.println("发生了意外错误.");
}
```

#### Python 示例：

```python
try:
    result = divide(10, 0)
    print("Result:", result)
except ZeroDivisionError:
    print("不能除以零.")
except Exception as e:
    print("发生了意外错误.")
```

### 第 3 节：finally 块

Java 和 Python 都提供了一个 `finally` 块，无论是否抛出异常都会执行。该块用于执行清理工作，例如关闭文件或释放资源。

#### Java 示例：

```java
try {
    // 可能会抛出异常的代码
} catch (Exception e) {
    // 异常处理代码
} finally {
    // 清理代码（始终执行）
}
```

#### Python 示例：

```python
try:
    # 可能会抛出异常的代码
except Exception as e:
    # 异常处理代码
finally:
    # 清理代码（始终执行）
```

## 第 2 节：Java 中的文件处理

### 文件的读取与写入

在 Java 中，文件处理涉及使用 `File`、`FileReader`、`FileWriter`、`BufferedReader` 和 `BufferedWriter` 等类来执行文件操作。

**Java 示例：**

```java
import java.io.File;
import java.io.FileReader;
import java.io.FileWriter;
import java.io.BufferedReader;
import java.io.IOException;

public class FileHandler {
    public static void main(String[] args) {
        try {
            // 向文件中写入数据
            FileWriter writer = new FileWriter("data.txt");
            writer.write("Hello, world!\n");
            writer.write("This is a sample text.\n");
            writer.close();

            // 从文件中读取数据
            FileReader reader = new FileReader("data.txt");
            BufferedReader bufferedReader = new BufferedReader(reader);

            String line;
            while ((line = bufferedReader.readLine()) != null) {
                System.out.println(line);
            }

            bufferReader.close();
            reader.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```
