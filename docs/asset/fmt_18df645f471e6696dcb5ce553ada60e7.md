
# 水手的故事

水手是我们第一个也是最受期待的人；因为他比庄主还要富有。他在女性面前是如此笨拙和害羞，以至于我们断定他与婚姻无缘；他欢迎我去他家里时那种嘈杂的热情，让我们以为他不会再寻找其他继承人，而我们只需要静候他的去世即可。在我们得意之时，我叔叔在一天早晨用一声惊喜的欢呼将我们惊醒了，他拍着我的肩膀告诉我，在这个世界上有他这样的朋友真是个幸运的人，因为他正要同他的一位老朋友为我准备航行。我脸色苍白，颤抖起来；我父亲告诉他，认为我的体质不适合航海；我母亲泪流而出，大喊如果她失去了我，她的心会碎掉。这一切都没有影响；水手完全不感这些感性的情感，也无顾泪水或辩论，坚持他的决定要把我培养成一个男子。我们被迫在表面上顺从，并就此做了准备。我非常乐快地告别了朋友，用最热诚的感激赞扬了我叔叔的恩慈，并为现在获得了一个满足知识渴求的机会感到高兴。但在预定出发日期的一周前，我在母亲的指示下病了，拒绝了她私下送给我的以外的所有食物；每当叔叔探望我时，我不是昏昏欲睡就是神志不清，但在胡语发作时不停地谈论旅行和贸易。房间里保持着黑暗；桌子上满了药瓶和药罐；我费力才说服母亲不要彻夜守候而危及她的生命；我父亲哀叹航行利润的损失；而使用了如此多的心机，或许能让一个洞察力敏的人识破骗局。但水手不通狡巧和诡计，很容易被欺骗；由于船不能等我康复，他卖掉了货物，留我独自悠闲地恢复健康。

我被送到一个空气清新的地方去养身体，以免显得那些钱从未被浪费；几个月后我回来为自己的失望感到哀叹。我叔叔怜悯我的消沉，并让我明年做好准备，因为笨手脚不应该碰他的钱。

获得了一次缓刑，也许在另一个春天新的诡计会取得成功；但我的叔叔单方面向我母亲的侍女发起了追求，而她为了促成这段有利的婚事，揭露了只有她被信任的秘密。他勃然大怒，大叫着，宣称他要有自己的后代，而不会把财产留给骗子和胆小鬼，并在两天内娶了那个女孩，现在有四个孩子了。

胆小总是被鄙视的，欺诈普遍受到憎恶。我发现我的朋友虽然没有完全疏远，但至少情感也变淡了；庄主虽然没有完全疏远，但也没那么喜欢了，经常询问我什么时候出海。我不得不忍受他的侮辱，并试图通过谦卑和尊重来重新激发他的善意；但我所有的努力都是徒劳的；他在没有留遗嘱的情况下去世了，财产由法定继承人。

就这样，我父母的愚蠢使我被迫在奉承和侍奉中度过了那些几年，而那些几年我本可以让自己凌驾于希望或恐惧之上。我成年时没有任何有用的技艺，也没有慷慨的情感；如果那个老女人最终也欺骗了我，我将同时面临贫穷和无知的危险。

我，等等。

## 漫游者（THE RAMBLER）

先生：

尽管你很少偏离道德主题，但我认为你并不严苛到会否定哲学的价值或用处。因此，出于相信你的无知并未让你成为知识的敌人，我荣幸地向公众介绍一位专家，他长期以来为了人类的利益努力，却像他的许多先辈一样，将秘密带入坟墓。

许多人通过在熔炉中熔掉财产来成名。我出生时并没有财富，因此只有我的大脑和身体可以献给知识，后世的感激将证明我从未吝啬。我曾在熔埚炉旁坐了数周不睡，观察投影的时刻；我在新结构的潜水装置上进行了首次实验；我曾十次在电击下失去言语；在尝试飞行时，我曾两次脱臼，一次骨折头骨；并四次通过接受输血而危及自己的生命。

在学习的早期，我付出的体力多于大脑精力，并且并不认为通过几块骨头换取名声；但在由于剧烈实验受损后，被迫局限于书籍，我花了三十六年寻找古代智慧的宝藏，但我的坚持终于得到了丰厚的回报。

当代哲学家的好奇心长期集中在电学上，最近转向了磁学；磁石的性质已经过研究，虽然益处不大，但赢得了广泛赞誉；由于艺术的最高赞誉是模仿自然，我希望没有人会认为人工磁石的制造者比他们更值得崇敬。

我已经在同样的实践中投入一段时间，但拥有更深的知识和更广阔的视野。当我的同龄人在摆弄磁针或忙于倾角和变化时，我一直在研究可以应用于普通生活的便利和幸福的磁性质。我将引导水手穿过海洋危险的任务留给了理解浅的人，而为自己保留了更困难、更显赫的领域：保护婚姻契约不受侵犯，并让人类永远摆脱假后子的危险，以及徒劳警觉和怀疑的痛苦。

剥夺任何人应有的赞誉是不配为哲学家的；因此，我将公开承认，我对这一宝贵秘密的最初提示归功于拉比亚伯拉罕·本·汉纳，他在关于宝石的书中留下了关于磁石的这段记载：[希伯来语: chalamalta],&c. “这磁石，即吸引铁的矿石，会在人类心中产生许多糟糕的幻象。女性会远离这种石头。因此，如果任何丈夫因嫉妒而感到不安，担心妻子与其他人交谈，可以在她睡觉时将这种石头放在她身上。如果她是纯洁的，醒来后会深情地搂住丈夫；但如果她是有罪的，她就会掉下床逃跑。”

当我第一次读到这段精彩的文字时，我无法想象为什么在那样对磁石声誉的激烈竞争中，它竟然没有被注意到。如果怀疑任何对亚伯拉罕拉比（Abraham）的名字或作品不陌生的候选人，或者根据皇家学会最近的一项有利于英语的法令，就断定哲学与文学不再协同作用，这显然是不公正的。然而，一种如此无用的特性为何能逃过流传，难道不是因为传达它的语言太晦涩了吗？为什么各地的男仆和女仆都要付钱保守秘密，而这些秘密是任何警惕或恐惧费用都无法从无处不在的磁石手中保护的？或者，为什么要召集这么多证人，并采取许多手段来发现一个如此容易的实验就能必然揭示的事实？

满腹困惑，我将亚伯拉罕的这些文字读给一个朋友听，他建议我不要为了对名声盲目追求而暴露生命：他用奥尔甫斯的命运警告我，知识或天才不能为侵犯女性特权的人提供保护；他向我保证，无论是阿喀琉斯的盔甲还是米特里达特斯的解毒药都无法保护我；并建议我，如果我没有名声无法生存，就尝试获取普世帝国，在那里，荣誉或许是平等的，而危险无疑更小。

我，作为一个孤独的学生，假装对世界并不了解甚多，但不认为世界是如此普遍地腐败，以至于一种检测不检行为的方案会给发明者带来任何危险。我的朋友确实告诉我，所有的女性将是我的敌人，无论我如何自我慰藉希望能得到男人的保护，我肯定会在白天发现自己被世界抛弃。他说，在年轻人中，有些人会害怕分担母亲的耻辱，有些人会害怕陷入情人的危险；而已婚的人，已经深信妻子的谎言，并睁一只眼闭一只眼以避免定罪；很少有人在婚姻中寻求美德，也很少有人尝试自己是否找到了它。几乎每个男人都是粗心或胆怯的，信任比检查更容易也更安全。

这些观察令我感到灰心，直到我开始考虑我在女士们中可能会得到什么样的反响，我将她们分为女仆、妻子和寡妇三类，并进行了审视，我不禁希望我能在她们中获得一些认同。我想，单身女士普遍准备支持我的方法，通过这种方法可以检测出婚姻中的邪恶，因为没有女性在结婚时会预先计划要对丈夫忠实。为了让她们在我的事业中保持坚定，我承诺绝不将我的磁石卖给那些从学校偷走女孩的男人；嫁给比自己小四十岁的妇女；或利用父母的权威在违背妻子同意的情况下获得妻子的男人。

在已婚妇女中，尽管有诽谤的暗示，但我开始相信，大多数人是我的朋友，至少她们坚信需要这种测试，并站在我这边；她们将用自己的精神来弥补人数上的不足，而她们的敌人看到磁石就会退缩发抖，就像斯基提亚的奴隶逃避鞭笞一样。

寡妇们会因为好奇（而非美德）而站在我这边；因为可以观察到，丈夫去世的女性总是认为自己有权监督年轻妻子的行为；而且她们本身面对这种磁性测试并无危险，我预计她们会极其且一致地热心推荐它。

带着这些希望，我将在不久后出售配有特殊金属成分的磁石，这种成分能集中它们的效力并决定其作用。众所周知，磁石在普通操作中的效力很大程度上取决于它的铁心，无法想象一块裸露或普通状态的石头能发现出亚伯拉罕拉比所赋予它的美德。这种金属的秘密我将仔细隐藏，因此我不必担心模仿者，也不会为了申请专利而打扰办公室。

我将出售不同尺寸、不同程度的磁石。我有一些大块头的，适合挂在床头像稻草人一样；也有一些非常小，可以被轻易隐藏。我把一些磨成椭圆形挂在表链上；而对于好奇的人，我将一些镶在结婚戒指里，让女士们永远不缺少对其清白的证明。

我可以生产一些迟钝、惰性的磁石，它们在第三次失败之前不会起作用；另一些则非常有活力、灵动，如果人们自愿且蓄意地放纵欲望，它们就会对不法的愿望产生影响。由于我习惯诚实地告诉客户磁石的特性，我可以通过他们的选择来判断他们情感的细腻程度。许多人满足于通过购买最低效力的产品来节省费用，而所有人在面对那些作用于思想的磁石时感到惊恐。只有一位年轻女士根据她的行为配了一枚戒指，或者允许自己去想她被禁止做的事。我，等等。

# 艾斯珀（ASPER）

尽管我对我的来信人受到的挑衅并非完全无感，但我无法完全理解他怨恨之深，也不鼓励他坚持切断与熟人所有交往的决定。毕达哥拉斯的准则之一指示，朋友不应因为小过而产生仇恨；无疑，他并没有被指责有更糟糕的事，除了他修理他的楼梯，盖他的地毯，并展示他的华丽服饰给那些他不准许使用的人看之外，他并没有犯任何应当被排除在普通善良程度之外的行为。这些不妥往往是源于愚蠢而非恶意。那些仅仅为了炫耀而闪光的人，仅仅受习俗和典范的影响，既没有也没有能力检查自己行为的动机，或去陈述优雅与张扬之间的细微界限。他们往往对自己的虚荣所产生的痛苦是无辜的，当他们没有比取悦自己更好的目的时，便侮辱他人。

那过度精致自己细腻的人总会危及自己的安宁。那些由于本性和美德迫使与之交往的人，有些人不懂取悦的艺术，并在他们打算留意时冒犯他人；有些人很疏忽，在不顾他人安宁的情况下给予他们满足；有些人，也许是恶意的，在繁荣中获得的满足并不如激起嫉妒和践踏劣者大。但是，无论侮辱的动机是什么，最好的总是忽视它，因为愚蠢几乎不值得怨恨，而恶意会被忽视所惩罚。

## 第201号。1752年2月18日，周二。

> Sanctus haberi
> Justitiæque tenat factis dictisque mereris,
> Adnosco procerem. — JUV. Sat. Lib. viii. 24.

向世界证明你是虔诚且真真的；
在你所说的一切、在你所做的一切中皆公正的；
无论你的出身如何，对我来说无疑是
一位头等地位的同仁。— 斯特特尼（STEPNEY）。

波义尔曾观察到，如果各种权宜和发明不再隐藏在私人手中，而是通过互惠交流广为人知，制造业的卓越性和劳动的便利性将得到极大促进；因为有些操作并非由一方凭借某些特殊优势完成的，这些操作虽然微不足道，但通过结合和共事，将开启知识的新途径。

有些操作并非由其中一方凭借某些特殊优势完成的，这些操作虽然微不足道，但通过结合和共事，将开启知识的新途径。

有些美德以类似的方式，分布在不同的阶层中。卡卡提斯（Cacatius）曾说，他从未读过超过一本书；而热心且关注地寻求美德的人，很少发现一个可以通过榜样来改进的人。

每个职业都有某种必不可少且适当的美德，没有它就无法希望荣誉或成功，且这种美德在其活跃范围内赋予了不同程度的成就。正如占星家根据他们认为的影响力划分人类一样，道德学家可以根据他们实践的各种美德来划分审慎或坚毅。

卓越的模式在很大程度上由时间和地点决定，以至于人们可能在一条街道炫耀，在另一条街道隐藏。蔑视和尊敬的理由，赞美和讽刺的主题，根据生活轨迹引导人们钦仰或厌恶的各种美德而异；但一个关心自己进步的人，不能局限于局部声誉。

每个人每天都有机会因为这种欺骗他人的权利而烦恼。活跃活泼的人长期以来轻视信任的约束，以至于承诺和安排已经失去了效力，因为双方都推断对方会违约。

疏忽首先在小事中被允许，并在微小的纵容中加强。那未被习俗硬化的人，在财产或危险的情况下用自己的话做担保，尽管他允许自己忘记何时去公园见女士，或在何家酒馆朋友正等着他。

这种荣誉的松散如果能限制在剧院、舞会厅或牌桌上，将是可以忍受的；然而即便在那里，它也足够困扰，并让那些时刻充满了期待、悬和怨恨，而这些时刻是预留给快乐的，我们自然希望获得纯粹的享受和完全的放松。但一个在道德上允许细微裂缝的人，很少能知道进入了什么，或会有多宽；当通道开启时，腐败的流入每刻都在破坏反对，并逐渐侵入心灵。

艾利格进入了一个充满活跃想象力、广阔视野和纯洁原则的世界。他的好奇心促使他四处奔波，尝试各种样的对话；他谈吐的优雅和思想的丰富无论出现在哪里都能为他赢得朋友；或者至少他发现，一个出生和财富让他获得关注的年轻人总是得到普遍的善待，且他并没有恶习破坏他的特权。阿里格尔（Aliger）对人类这种普遍的微笑感到满意，并努力通过顺从和奉承来维护它，但他并未让取悦他人的欲望损害他的正直。他有一条固定的准则：言出必信；当他一次因为另一个聚会的机会而让自己从一个节日约会中抽身时，也并非没有长久的挣扎。

他像恶习初期的常态那样，在不安和不完全的享受中度过夜晚，清晨带着困惑和借口面对那些失望的朋友。他的同伴们并不习惯这种严谨的焦虑，对他的不安付之一笑，用一瓶酒加剧了他的过错，给他再次背弃承诺的勇气，并一次又付出代价。他在另一个圈子里尝试了同样的实验，发现他们同样乐意将其视为一种可以原谅的过错，是机敏和快乐的人常有的事；直到渐渐地，他开始认为自己可以自由地遵循最后的邀请，不再对谎言的卑劣感到震惊。他对于承诺参加远方的活动并不觉得困难，如果感到百无聊赖，他就会非常平静地坐在家里，经常在椅子上睡着，而他的十张桌子都在等待他的到来。

生活在永久的空虚是如此愉快，以至于他很快就把注意力视为一种无用的负担，听任自己粗心和消散，不顾未来或过去，也不顾突发欲望的冲动或即时快乐的吸引等任何其他动机。缺席的人立即被遗忘，他人感受到的希望或恐惧对他的行为没有产生影响。他在推测上是公正的，但从未对债主遵守承诺；他很仁慈，但总是欺骗那些他承诺要照顾或帮助的朋友；他很谨慎，但因为没有按时结算账目而导致自己的事务陷入困境。他追求一位年轻女士，当定亲协议拟好时，他在约定的签约当天去乡下游荡。他决定旅行，把箱子寄船，结果拖延到错过了船。他被传唤作为重大案件的证人，却一直磨蹭，直到审判结束。据说，当他花费巨资在某个选区建立起影响力时，他的对手通过一些了解他性格的代理人，在选举当天把他引走了。

他的仁慈让他陷入了成千上万罪行之中，而那些不那么仁慈或文雅的人会避开这些。他的礼貌引来了求助；他的承诺产生了依赖；他的口袋里满了请愿书，他打算某时递交并执行，他的桌子上也满了请求信，他打算予以照办；但时间在不知不觉中流逝了，而他要么在闲散，要么在忙碌；他的朋友们失去了机会，并将他们的失败和灾难归咎在他身上。

然而，这种性格虽然卑鄙，却并非阿里格尔所独特。那些想象力活跃、经常变换预期场景的人，往往受到这种心血来潮的影响，使他们所有的行动都变得偶然，破坏了他们友谊的价值，阻碍了他们美德的效力，并使他们低于那些坚持决定的、执行所计划并履行承诺的平庸之人。

译者注：原文如此（sic）。

在那些致力于促进学习和纠正判断的人中，长期以来一直抱怨词语的滥用。词语往往被用来表示截然不同的事物，它们并没有作为知识的载体辅助理解，反而制造了错误、分歧和困惑，因为在一种意义上肯定的内容，在另一种意义上被接受。
