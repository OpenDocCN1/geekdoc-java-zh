
# Python 中的目录操作

```python
import os

# 创建目录
os.mkdir("my_folder")

# 检查目录是否存在
if os.path.exists("my_folder"):
    print("Directory exists")

# 切换当前目录
os.chdir("my_folder")

# 列出目录中的文件
files = os.listdir(".")
print("Files in directory:", files)

# 回到父级目录
os.chdir("..")

# 删除目录
os.rmdir("my_folder")
```

# Java 中的目录操作

**Java 示例：**

```java
import java.io.File;

public class DirectoryHandler {
    public static void main(String[] args) {
        // 创建目录
        File dir = new File("my_folder");
        if (dir.mkdir()) {
            System.out.println("Directory created");
        }

        // 检查目录是否存在
        if (dir.exists()) {
            System.out.println("Directory exists");
        }

        // 切换当前目录（注意：Java 使用绝对路径实现此操作）

        // 列出目录中的文件
        File folder = new File(".");
        File[] files = folder.listFiles();
        if (files != null) {
            for (File file : files) {
                System.out.println(file.getName());
            }
        }

        // 回到父级目录
        File parentDir = dir.getParentFile();

        // 删除目录
        if (dir.delete()) {
            System.out.println("Directory deleted");
        }
    }
}
```

# Java 中的 HashSet

**Java 示例：**

```java
import java.util.HashSet;

public class HashSetExample {
    public static void main(String[] args) {
        // 创建一个字符串 HashSet
        HashSet<String> names = new HashSet<>();

        // 向 HashSet 中添加元素
        names.add("Alice");
        names.add("Bob");
        names.add("Alice"); // 重复，未添加

        // 从 HashSet 中访问元素
        System.out.println("Set size: " + names.size());

        // 从 HashSet 中移除元素 Bob
        names.remove("Bob");
        System.out.println("移除后: " + names);
    }
}
```

# HashMap

`HashMap` 是 `Map` 接口的一种实现，它存储键值对，并允许根据其键快速检索值。

**Java 示例：**

```java
import java.util.HashMap;

public class HashMapExample {
    public static void main(String[] args) {
        // 创建一个整数 HashMap (ID -> Name)
        HashMap<Integer, String> students = new HashMap<>();

        // 向 HashMap 中添加键值对
        students.put(1, "Alice");
        students.put(2, "Bob");
        students.put(3, "Charlie");

        // 根据键快速检索值
        System.out.println("Student 1: " + students.get(1));

        // 从 HashMap 中移除键为 2 的元素
        students.remove(2);
        System.out.println("移除后: " + students);
    }
}
```

# 第2部分：Python 中的集合

## List

`List` 是一种基于数组的数据结构，可以存储不同类型的元素并动态伸缩。

**Python 示例：**

```python
# 创建一个列表
names = ["Alice", "Bob", "Charlie"]

# 向列表添加元素
names.append("David")

# 访问列表元素
print("First element:", names[0])

# 从列表中移除元素
names.pop(1)
print("移除后:", names)
```

## Set

`Set` 是一个无序的集合，存储不重复的元素。

**Python 示例：**

```python
# 创建一个集合
names = {"Alice", "Bob", "Charlie"}

# 向集合添加元素（重复元素不会添加）
names.add("Alice")

# 集合的大小
print("Set size:", len(names))

# 从集合中移除元素
names.remove("Bob")
print("移除后:", names)
```

## Dictionary

`Dictionary`（字典）是一种关联数组数据结构，存储键值对，允许根据键快速检索值。

**Python 示例：**

```python
# 创建一个字典
students = {1: "Alice", 2: "Bob", 3: "Charlie"}

# 向字典添加键值对
students[4] = "David"

# 根据键快速检索值
print("Student 1:", students[1])

# 从字典中移除键为 2 的元素
del students[2]
print("移除后:", students)
```

# 第3部分：Java 中的泛型

泛型允许创建参数化的类、接口和方法，在确保类型安全的同时处理不同的数据类型。

## 泛型类

**Java 示例：**

```java
public class Box<T> {
    private T content;

    public Box(T content) {
        this.content = content;
    }

    public T getContent() {
        return content;
    }

    public void setContent(T content) {
        this.content = content;
    }

    public static void main(String[] args) {
        Box<Integer> integerBox = new Box<>(10);
        Box<String> stringBox = new Box<>("Hello");

        System.out.println("整数值: " + integerBox.getContent());
        System.out.println("字符串值: " + stringBox.getContent());
    }
}
```

## 泛型方法

**Java 示例：**

```java
public class ArrayUtil {
    public static <T> void printArray(T[] array) {
        for (T element : array) {
            System.out.print(element + " ");
        }
        System.out.println();
    }

    public static void main(String[] args) {
        Integer[] intArray = {1, 2, 3, 4, 5};
        String[] stringArray = {"A", "B", "C"};

        printArray(intArray); // 输出: 1 2 3 4 5 
        printArray(stringArray); // 输出: A B C 
    }
}
```

# Java 流（Stream）

```java
List<String> names = List.of("Alice", "Bob", "Charlie", "David");

// 从列表创建一个流
Stream<String> namesStream = names.stream();
namesStream.forEach(System.out::println);
```

## 生成流

可以使用静态方法如`Stream.of()`或`Stream.iterate()`来生成流。

**示例：**

```java
import java.util.stream.Stream;

public class StreamExample {
    public static void main(String[] args) {
        // 使用 Stream.of() 创建流
        Stream<Integer> numbersStream = Stream.of(1, 2, 3, 4, 5);
        numbersStream.forEach(System.out::println);
    }
}
```

```java
// 使用 Stream.iterate() 创建流
Stream<Integer> evenNumbersStream = 
Stream.iterate(0, n -> n + 2).limit(5);
evenNumbersStream.forEach(System.out::println);
```

# 第 3 部分：中间操作

## 过滤元素

流支持使用`filter()`方法根据指定条件对元素进行过滤。

**示例：**

```java
import java.util.List;
import java.util.stream.Stream;

public class StreamExample {
    public static void main(String[] args) {
        List<String> names = List.of("Alice", "Bob", "Charlie", "David");

        // 过滤以 'A' 开头的名称
        Stream<String> filteredNames =
                names.stream().filter(name -> name.startsWith("A"));

        filteredNames.forEach(System.out::println);
    }
}
```

## 映射元素

使用`map()`方法将流中的每个元素转换为另一个对象。

**示例：**

```java
import java.util.List;
import java.util.stream.Stream;

public class StreamExample {
    public static void main(String[] args) {
        List<String> names = List.of("Alice", "Bob", "Charlie", "David");

        // 将名称映射为它们的长度
        Stream<Integer> nameLengths =
                names.stream().map(String::length);
        nameLengths.forEach(System.out::println);
    }
}
```

## 排序元素

可以使用`sorted()`方法对流进行排序。

**示例：**

```java
import java.util.List;
import java.util.stream.Stream;

public class StreamExample {
    public static void main(String[] args) {
        List<String> names = List.of("Alice", "Bob", "Charlie", "David");

        // 按字母顺序排序名称
        Stream<String> sortedNames = names.stream().sorted();
        sortedNames.forEach(System.out::println);
    }
}
```

# 第 4 部分：终端操作

## 收集元素

终端操作使用`collect()`方法将流的元素收集到集合中。

**示例：**

```java
import java.util.List;
import java.util.stream.Collectors;
import java.util.stream.Stream;

public class StreamExample {
    public static void main(String[] args) {
        List<String> names = List.of("Alice", "Bob", "Charlie", "David");

        // 将以 'A' 开头的名称收集到新列表中
        List<String> filteredNames = names.stream()
            .filter(name -> name.startsWith("A"))
            .collect(Collectors.toList());

        System.out.println(filteredNames);
    }
}
```

## 归约元素

`reduce()`方法对流元素执行归约操作。

**示例：**

```java
import java.util.List;
import java.util.Optional;
import java.util.stream.Stream;

public class StreamExample {
    public static void main(String[] args) {
        List<Integer> numbers = List.of(1, 2, 3, 4, 5);

        // 将数字归约为和
        Optional<Integer> sum = numbers.stream().reduce(Integer::sum);
        sum.ifPresent(System.out::println);
    }
}
```

## 计数元素

`count()`方法返回流中元素的数量。

**示例：**

```java
import java.util.List;
import java.util.stream.Stream;

public class StreamExample {
    public static void main(String[] args) {
        List<String> names = List.of("Alice", "Bob", "Charlie", "David");

        // 计算名称的数量
        long count = names.stream().count();
        System.out.println("Number of names: " + count);
    }
}
```
