## GUI 组件的事件处理

当用户在 `JTextField` 或 `JPasswordField` 中输入并按下回车键时，就会发生一个事件。我们的下一个示例将演示程序如何响应该事件执行任务。这里展示的技术适用于所有产生事件的 GUI 组件。

图 12.9–10 应用使用了 `JTextField` 和 `JPasswordField` 类来创建和操作文本字段。当用户在其中一个文本字段中输入内容时，应用程序创建一个包含用户输入内容的对话框。你只能在文本字段“获得焦点”时进行输入。当你点击它时，它就会接收焦点。这是因为获得焦点的文本字段是会在你按下回车键时产生事件的那个。在这个示例中，当你在 `JPasswordField` 中按下回车键时，密码将会显示。我们首先讨论 GUI 的设置，然后是事件处理程序代码。

在 GUI 组件中设置事件的步骤：

- 创建一个实现 `ActionListener` 接口的类。
- 在事件发生时，该类执行相应的任务。

### 使用嵌套类实现事件

用于处理事件的嵌套类通常位于外部类内部。嵌套类可以是静态的或非静态的。为了 GUI 组件设置事件，你需要：

1. 创建实现 `ActionListener` 接口的类。
2. 在应用程序中注册该类作为事件处理程序。

### JTextFieldHandler 内部类

`JTextFieldHandler` 内部类处理了所有字段的事件（第 50–80 行）。该类是私有的，因为它只在 `JTextFieldFrame` 内部使用。当用户在 `JTextField` 中按下回车键时，`actionPerformed` 方法（第 53–80 行）会被调用。

在这个示例中，我们使用一个 `JTextFieldHandler` 对象的 `actionPerformed` 方法（第 53–80 行）来处理事件。

### 为每个文本字段注册事件处理器

在 `JTextFieldFrame` 构造函数中，第 42 行创建了一个 `JTextFieldHandler` 对象并将其赋值给变量。该对象的 `actionPerformed` 方法会在用户在 GUI 的文本字段中按下回车键时自动调用。然而，在此之前，程序必须将该对象注册为每个文本字段的事件处理器。第 43–46 行是事件注册语句，指定了三个 `JTextField` 和 `JPasswordField` 使用哪个处理器。应用程序调用 `addActionListener` 为每个组件注册事件处理器。该方法接收一个 `ActionListener` 对象，它可以是任何实现 `ActionListener` 的类。该对象处理器是一个 `ActionListener`，因为 `handler` 实现了 `ActionListener`。在第 44–46 行之后，该对象开始监听事件。现在，当用户在四个文本字段中的任何一个中按下回车键时，`JTextFieldHandler` 类中的 `actionPerformed` 方法（第 53–80 行）会被调用以处理事件。如果没有为某个文本字段注册事件处理器，该文本将被忽略——即它简单地被应用程序忽略了。

## 事件处理详解

每当调用 `actionPerformed` 时都会生成事件。事件源是用户与之交互的组件。当用户在文本字段或密码字段获得焦点时按下回车键，系统会创建一个唯一的 `ActionEvent`，其中包含有关发生事件的信息，例如事件源和文本字段中的文本。系统将此 `ActionEvent` 传递给事件监听器的 `actionPerformed` 方法。第 56 行声明了将要显示的 `String`。该变量初始化为空字符串——包含没有任何字符的 `String`。编译器要求对其进行初始化，以防第 59–76 行中的嵌套 `if` 没有任何一个分支被执行。

`ActionEvent` 方法 `getSource()`（在第 59、64、69 和 74 行中被调用）返回事件源的引用。条件位于第 59 行。“事件源是 textField1 吗？”该条件使用 `==` 运算符比较引用，以确定它们是否指向同一个对象。如果两者都指向 `textField1`，则用户在 `textField1` 中按了回车键。然后，第 60–61 行创建一个包含消息的 `String`，该消息由第 79 行在对话框中显示。第 61 行使用 `ActionEvent` 方法 `getCommand()` 获取用户在生成事件字段中输入的文本。

在这个示例中，当用户在该字段中按下回车键时，我们在 `JPasswordField` 中显示密码。有时有必要通过程序处理密码中的字符。`JPasswordField` 类的方法 `getPassword()` 将密码字符作为 `char` 类型的数组返回。
