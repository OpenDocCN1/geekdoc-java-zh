# III.ii.206 (285,8)

[一刻的延误就是一片发现的大海]

这句话被注释者 [W] 正确地标记为胡话，但又被幸运地恢复了意义。我将其读作：

一刻的延误就是一片发现的大海。发现吧，求你了；告诉我什么是很快的；——当抄写员把`discover`（发现）误写为`discovery`（发现）时，他轻易地在`South-sea`（大海）后面加了一个词。

但或许可以用更少的修改：每一次延误都是一次发现之旅：然而，无论延误多短，对我来说都既冗长又烦，就像最长的航行，就像一次南南海的航行。可以想象，那些英国首次尝试的南南海航行是如何成为当时的话题的。

我们必须读成“两小时内”。

# V.iii.160 (321,6)

[表哥——甘尼米德!]

西莉亚在第一次受惊时忘记了罗莎林德的身份和伪装，所有的“表亲”让她回想起了自己和甘尼米德。

# V.ii.21 (325,9)

[还有你，美丽的姐姐]

我知道奥利弗为什么要当罗莎林德的姐姐。他认为她是个男人。假设我们读成“你，还有你美丽的姐姐”。

# V.ii.45 (326,1)

[犬之斗无法分（它们）]

暗指狗在愤怒时分道扬。

# V.ii.74 (327,2)

[尽管她是凡人]

那不是幻影，而是真实的罗莎林德，并没有通常认为伴随咒语仪式而带来的任何危险。

# V.iii.17 (329,3)

[是一个爱人和他的姑娘]

这首歌的各歌节在所有版本中显然都调换了位置：早期抄本中的第二节，现在是最后一节。

这些歌节的调换是由蒂尔比博士（Dr. Thirlby）完成的，他在一个带有边旁注释的抄本中这样做了，我由于爱德华·沃尔波爵士（Sir Edward Walpole）的恩惠。（见 1765, II,97,3）

# V.iii.36 (330,4)

[音调非常不和谐]

[T: 不合时的] 这一修订得到了认可。我认为沃伯顿博士（Dr. Warburton）给此奖励是非常不公平的。

# V.iv.4 (331,5)

[正如那些恐惧的人，他们希望，而他们知道恐惧]

[W: 他们的运气，并知道他们的] 不去修订这一行是合理的，但我不认为这位博学评论者的用词用得并不理想。我将其读作：“正如那些带着希望恐惧，以及带着恐惧希望的人。”

或者这样，改动更小：

“正如那些恐惧、希望的人，而现在他们恐惧了。”

# V.iv.36 (332,6)

[来了一对奇怪的野兽]

[W: 不洁的野兽] “奇怪的野兽”只是我们所谓的奇特动物。不需要任何修改。

# V.iv.51 (333,7)

[发现争端是因为第七个原因]

所有的抄本都是如此；但从后文显然，我们必须读成“争端是因为第七个原因”。
