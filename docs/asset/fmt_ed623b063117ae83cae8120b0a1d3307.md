图 22.2–22.4 中的程序允许用户调整在名为 `OvalPanel` 的 `JPanel` 子类上绘制圆的大小（图 22.2）。用户通过水平的 `JSlider` 指定圆的直径。`OvalPanel` 知道如何在自身上绘制圆，使用其实例变量 `diameter` 来确定圆的直径——直径被用作显示圆的边界框的宽度和高度。当用户与 `JSlider` 交互时会设置直径值。事件处理器调用方法 `repaint()` 来绘制新圆。`repaint()` 调用将请求发送给 `OvalPanel` 的 `paintComponent()`。

```java
// 图 22.2: OvalPanel.java
// 一个自定义的 JPanel 类。
import java.awt.Graphics;
import java.awt.Dimension;
import javax.swing.JPanel;

public class OvalPanel extends JPanel {
    private int diameter = 10; // 默认直径

    // 绘制指定直径的椭圆
    @Override
    public void paintComponent(Graphics g) {
        super.paintComponent(g);
        g.fillOval(10, 10, diameter, diameter);
    }

    // 验证并设置直径，然后重绘
    public void setDiameter(int newDiameter) {
        // 如果直径无效，默认为 10
        diameter = (newDiameter >= 0 ? newDiameter : 10);
        repaint(); // 重绘面板
    }

    // 布局管理器用于确定首选尺寸
    public Dimension getPreferredSize() {
        return new Dimension(200, 200);
    }

    // 布局管理器用于确定最小尺寸
    public Dimension getMinimumSize() {
        return getPreferredSize();
    } // 类 OvalPanel 结束
}
```

## 22.3 理解 Java 中的窗口

`JFrame` 是一个带有标题栏和边界的 `Frame` 子类。`JFrame` 类是 `Frame`（package `java.awt`）的子类，而 `Frame` 是 `Window`（package `java.awt`）的子类。作为 `JFrame`，它是重量级 Swing 组件之一。当你关闭 `JFrame` 时，它会被隐藏（即从屏幕上移除），你可以通过 `JFrame` 方法 `setDefaultCloseOperation()` 来控制此行为。`WindowConstants`（package `javax.swing`）由 `JFrame` 实现，它声明了三个常量——`DISPOSE_ON_CLOSE`、`DO_NOTHING_ON_CLOSE` 和 `HIDE_ON_CLOSE`（默认值），用于此方法。某些平台允许的窗口数量有限。

### 向系统返回资源

显示在屏幕上。因此，窗口是一个宝贵的资源，当不再需要时应该将其归还给系统。`Window` 类（`JFrame` 的间接超父类）为此目的声明了 `dispose()` 方法。当应用程序不再需要某个窗口时，你应该显式地释放它。这可以通过调用 `setDefaultCloseOperation()` 方法并传入 `WindowConstants.DISPOSE_ON_CLOSE` 来实现。终止应用程序也会将资源返回给系统。使用 `DO_NOTHING_ON_CLOSE` 表示程序将在用户尝试关闭窗口时决定执行什么。例如，程序可能想在关闭窗口之前询问是否保存文件的更改。

## 显示和定位窗口

默认情况下，在程序调用其 `setVisible()` 方法（继承自 `java.awt.Component` 类）并传入 `true` 参数之前，窗口不会显示在屏幕上。窗口的大小应该通过调用 `setSize()` 方法（继承自 `java.awt.Component` 类）来设置。窗口出现在屏幕上的位置通过 `setLocation()` 方法（继承自 `java.awt.Component` 类）指定。

当用户操作窗口时，通过 `addWindowListener()` 方法为窗口事件注册事件监听器。`WindowListener` 提供了七个窗口事件处理方法——`windowActivated()`（当用户激活窗口时调用）、`windowClosed()`（当窗口关闭后调用）、`windowClosing()`（当用户启动关闭窗口时调用）、`windowDeactivated()`（当用户激活另一个窗口时调用）、`windowDeiconified()`（当用户最小化窗口时调用）以及 `windowOpened()`（当程序首次在屏幕上显示窗口时调用）。
