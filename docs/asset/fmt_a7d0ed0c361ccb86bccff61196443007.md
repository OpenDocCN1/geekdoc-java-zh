邻居潘达的秘密。[波普曾将 Fol叶本的“自然的秘密”修改为目前的读法]——波普先生的读法见于旧四刻本中。“Secret”意味着比对的巨大必要性。

# IV.iv.3 (99,1)

Fol叶本写道：“这种痛苦是精妙的、完美的，我所感受到的，/ 在某种意义上并不像/产生它的痛苦那样强烈。” 四刻本则为：“这种痛苦是精妙的、完美的，我所感受到的，/ 在某种意义上剧烈正如/产生它的痛苦那样强烈。“Violent”是一个我不熟悉的词，但它可能是正确的。文本的读法没有权威性。

# IV.iv.65 (101,3)

因为我将向死亡挑战手套；也就是说，我将为了你的忠诚挑战死亡本身。

# IV.iv.105 (103,5)

当其他人通过权术为了巨大的名声时，我凭借巨大的真诚，捕捉更多的单纯。我认为意义是，当其他人通过他们的技巧获得高度的评价时，我通过诚实获得一个平实的证明。我理解的指导原则，是让你拥有她本该具有的样子；我会让你完全理解。这正是词的意义在作者那里经常出现。

# IV.iv.134 (104,9)

我将按照我的清单回答；我认为这是正确的，尽管旧法典是那样读的。

# IV.v.8 (105)

删去偏见。我会寻找我的对等物以生存——你接受的吻比你给出的更好；我会做出那些能让我生存的交易，为了那些能带给我利润的人，因此不会给出一个比我给出的更糟糕的吻。
