### Pattern 类与 Matcher 类

除了 String 类的正则表达式功能外，Java 还提供了 `java.util.regex` 包中的其他类，帮助开发和操作正则表达式。`Pattern` 类代表正则表达式模式以及用于搜索该模式的 `CharSequence`。

`CharSequence`（位于 `java.lang` 包）是一个允许对字符序列进行读取的接口。该接口提供了 `charAt`、`length`、`subsequence` 和 `toString` 方法。`String` 和 `StringBuilder` 都实现了 `CharSequence`，这两个类中的任一实例都可以与 `Matcher` 类配合使用。

如果正则表达式只使用一次，可以使用静态的 `Pattern` 方法 `matches`。该方法接收一个指定正则表达式的 String 和一个执行匹配的 `CharSequence`。该方法返回一个布尔值，表示搜索对象（第二个参数）是否匹配正则表达式。

如果正则表达式将使用多次（例如，在循环中），使用静态的 `Pattern` 方法 `compile` 来为该正则表达式创建一个特定的 `Pattern` 对象会更高效。该方法接收一个代表模式的 String 并返回一个新的 `Pattern` 对象，然后可以使用它调用 `matcher` 方法。该方法接收一个用于搜索的 `CharSequence` 并返回一个 `Matcher` 对象。

`Matcher` 提供了 `matches` 方法，它执行的操作与 `Pattern.matches` 相同，但不需要参数。`Matcher` 还提供了 `find`、`group` 以及 `replaceAll` 等方法。

### 14.7 节 正则表达式、Pattern 类和 Matcher 类

- 正则表达式 (p. 624) 是字符和符号的序列，用于定义一组字符串。它们对于验证输入和确保数据格式正确非常有用。
- String 方法 `matches` (p. 624) 接收一个指定正则表达式的字符串，并在调用该正则表达式方法时匹配 String 对象的内容。该方法返回一个布尔值，指示匹配是否成功。
- 字符类是一个转义序列，表示一组字符。每个字符类匹配我们尝试用正则表达式匹配的字符串中的单个字符。
- 单词类 (`\w`) 是任何字母（大写或小写）、任何数字或下划线字符。
- 空白类 (`\s`) 是任何空格、制表符、回车、换行符或分页符。
- 数字类 (`\d`) 是任何数字字符。
- 运算符 `+` 匹配其前一个子表达式一次或多次出现。
- 字符 `|` 允许匹配其左侧或右侧的表达式。
- 括号 `()` 用于分组正则表达式的部分。
- 星号 `*` 和加号 `+` 在形式上称为量词。它们修饰紧邻的前子表达式。
- 量词只影响它修饰的子表达式。
- 量词问号 `?` 匹配其修饰的表达式零次或一次。
- 大括号 `{n}` 匹配 n 次。
- 大括号 `{n,m}` 匹配 n 到 m 次。
- 量词是贪婪的，意味着它们尽可能多地匹配。
- 量词后跟问号 `?` 是懒惰的，意味着尽可能少地匹配。
- String 方法 `replaceAll` (p. 629) 将所有出现的模式替换为指定的替换字符串。
- String 方法 `replaceFirst` (p. 629) 替换第一次出现的模式。
- String 方法 `matches` (p. 629) 确定字符串是否匹配正则表达式。
- String 方法 `split` (p. 629) 根据分隔符将字符串分割为子字符串。

**14.20 (支票保护)** 计算机经常用于支票打印系统，例如工资单和应付账款。有很多关于周薪支票（错误）打印超过 100 万美元金额的奇故事。由于人为错误或机器故障，计算机支票打印系统会打印错误的金额。系统设计人员在系统中建立控制措施，以防止此类错误支票的发行。另一个问题是故意更改支票金额，支票打印系统使用了一种称为支票保护的技术。为计算机打印设计的支票留有固定数量的空格，计算机可以在其中打印金额。假设一张工资单包含八个空白空格，计算机应该在其中打印周薪的金额。如果金额很大，那么所有八个空格都将被填充。例如，

```
1,230.60 (支票金额)
n12345678 (位置数字)
```

另一方面，如果金额小于 $1000，通常会留出几个空白处。例如，

```
99.87
---
12345678
```
包含三个空白空格。如果打印支票时留有空格，别人更容易更改金额。为了防止更改，许多支票打印系统会在金额前插入前导星号，如下：

```
***99.87
12345678
```
