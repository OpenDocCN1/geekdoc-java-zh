# 7.13 可变长度参数列表

使用可变长度参数列表，你可以创建接收未指定数量参数的方法。参数列表中类型后跟一个省略号（`...`）表示该方法接收任意数量的特定类型。这种省略号的使用在参数列表中只能出现一次，且省略号及其类型和参数必须放在参数列表的末尾。虽然你可以通过方法重载和数组传递来实现许多可变长度参数列表完成的功能，但在方法参数列表中使用省略号更加简洁。

图 7.20 展示了 `average()` 方法（第 7–16 行），它接收一个可变长度的 `double` 序列。Java 将可变长度参数处理为一个元素类型与 `double` 数组相同的数组。第 12–13 行使用增强 `for` 循环遍历数组并计算数组中 `double` 的总和。第 15 行访问 `length` 以获取平均计算中使用的 `numbers` 数组的大小。`main()` 方法中的第 29、31 和 33 行分别带有两个、四个参数调用 `average()` 方法。`average()` 方法具有可变长度参数列表（第 7 行），因此它可以处理调用者传递的任意数量 `double` 参数。输出显示每次调用 `average()` 方法都返回正确的值。

## 7.15 Arrays 类

`Arrays` 类通过提供用于常见数组操作的静态方法，帮助你避免重复造轮子。这些方法包括：用于排序数组（即按升序排列元素）的 `sort()`、用于搜索已排序数组（即确定数组是否包含特定值，如果包含则确定该值的位置）的 `binarySearch()`、用于比较数组的 `equals()` 以及用于向数组填充值的 `fill()`。这些方法针对基本数据类型数组和对象数组进行了重载。我们本节的重点是使用 Java API 提供的内置功能。第 19 章“搜索、排序与大 O”展示了如何实现你的排序和搜索算法，这是计算机科学研究人员和学生非常感兴趣的话题。

图 7.22 使用了 `Arrays.sort()`、`binarySearch()`、`equals()` 和 `fill()`，并展示了如何使用类静态方法 `System.arraycopy()` 复制数组。在 `main()` 方法中，第 11 行对 `doubleArray` 的元素进行排序。`Arrays` 类的静态方法 `sort()` 默认按升序排列数组元素。我们将在章稍后的部分讨论如何进行降序排序。`sort()` 的重载版本允许你对数组内特定范围的元素进行排序。第 12–15 行输出排序后的数组。

```java
// 图 7.22: ArrayManipulations.java
// Arrays 类方法和 System.arraycopy.
import java.util.Arrays;

public class ArrayManipulations {
    public static void main(String[] args) {
        // 将 doubleArray 按升序排序
        double[] doubleArray = {8.4, 9.3, 0.2, 7.9, 3.4 };
        Arrays.sort(doubleArray);
        System.out.printf("%ndoubleArray: %s\n", doubleArray);
        for (double value : doubleArray)
            System.out.printf("%1f ", value);
        // 用 7 填充 10 个元素的数组
        int[] filledInt = new int[10];
        Arrays.fill(filledInt, 7);
        displayArray(filledInt, "filledIntArray");
        // 将 intArray 复制到 int 数组 intArrayCopy
        int[] intArray = {1, 2, 3, 4, 5, 6};
        int[] intArrayCopy = new int[intArray.length];
        System.arraycopy(intArray, 0, intArrayCopy, 0, intArray.length);
        displayArray(intArray, "intArray");
        displayArray(intArrayCopy, "intArrayCopy");
        // 比较 intArray 和 intArrayCopy 是否相等
        boolean b = Arrays.equals(intArray, intArrayCopy);
        System.out.printf("%nintArray equals intArrayCopy: %s\n", b ? "true" : "false");
    }
}
```

Java API 提供了若干预定义的数据结构，称为集合（collections），用于在内存中存储一组对象。这些类提供了高效的方法来组织、存储和检索你的数据，而无需了解数据是如何存储的。这缩短了应用程序的开发时间。

用于存储对象序列。数组在执行期间不会自动更改大小以容纳额外的元素。集合类 `ArrayList<T>` (package `java.util`) 为此问题提供了一个方便的解决方案——它可以动态改变大小以容纳更多元素。`T`（根据惯例）是一个占位符——在声明新的 `ArrayList` 时，将其替换为你希望 `ArrayList` 存储的元素类型。例如：

```java
ArrayList<String>;
```

这会将列表声明为只能存储 `String` 的 `ArrayList` 集合。带有此类占位符的类可以与任何类型配合使用声明泛型类。只有非基本类型可以用于声明变量和创建泛型类的对象。然而，Java 提供了一种名为装箱（boxing）的机制，允许将基本类型值包装为泛型类的对象。因此，例如：

```java
ArrayList<Integer>;
```

将整数声明为只能存储 `Integer` 的 `ArrayList`。当你将一个 `int` 值放入 `ArrayList<Integer>` 时，该 `int` 会被装箱（包装）为 `Integer` 对象；当从 `ArrayList<Integer>` 中获取 `Integer` 对象并将其赋值给 `int` 变量时，对象内部的值会被拆箱（解包）。

图 7.24 演示了 `ArrayList` 的一些功能。第 10 行创建了一个默认初始容量为 10 个元素的 `String` 类型的 `ArrayList`。容量表示在不进行增长的情况下可以容纳多少个元素。`ArrayList` 在后台是使用常规数组实现的。当 `ArrayList` 增长时，它必须创建一个更大的数组并将每个元素复制到新数组中。这是一个耗时的操作。如果每次添加元素时 `ArrayList` 都增长，将是极其低效的。相反，它只在添加元素且元素数量等于容量时才增长——即没有空间容纳新元素。
