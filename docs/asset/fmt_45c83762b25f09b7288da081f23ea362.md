编译器可以使用 `StringBuilder` 和 `append` 方法来实现 `+` 和 `+=` 拼接运算符。例如，假设声明如下：

```java
String string1 = "hello";
String string2 = "BC";
int value = 22;
```

语句 `String s = string1 + string2 + value;` 将 "hello"、"BC" 和 22 拼接。拼接可以按如下方式执行：

```java
String s = new StringBuilder().append("hello").append("BC").append(22).toString();
```

上述语句创建了一个空的 `StringBuilder`，然后将字符串 "hello"、"BC" 和整数 22 附加在其后面。接下来，`StringBuilder` 的 `toString` 方法将 `StringBuilder` 转换为 `String` 对象并赋值给 `s`。语句

## 14.4.5 StringBuilder 插入和删除方法

`StringBuilder` 提供了重载方法，可以在 `StringBuilder` 的任何位置插入各种类型的值。针对基本类型、字符数组、`String`、`Object` 和 `CharSequence` 都提供了相应的版本。每个方法接收其第二个参数，并将其插入到第一个参数指定的索引处。如果第一个参数小于 0 或大于 `StringBuilder` 的长度，则会抛出 `StringIndexOutOfBoundsException`。`StringBuilder` 类还提供了在 `StringBuilder` 的任何位置执行 `delete` 和 `deleteCharAt` 方法。`delete` 方法接收两个参数——起始索引和字符结束位置的下一个索引。将删除从起始索引开始到但不包含结束索引的字符。`deleteCharAt` 方法接收一个参数——要删除的字符的索引。无效索引会导致这两个方法都抛出 `StringIndexOutOfBoundsException`。图 14.14 演示了 `insert`、`delete` 和 `deleteCharAt` 方法。

```java
// Fig. 14.14: StringBuilderInsertDelete.java
// StringBuilder 方法 insert, delete 和 deleteCharAt.
public class StringBuilderInsertDelete {
    public static void main(String[] args) {
        Object objectRef = "hello";
        String string = "goodbye";
        char[] arrayOf = {'a', 'b', 'c', 'd', 'e', 'f'};
        boolean booleanValue = true;
        char charValue = 'K';
        int intValue = 7;
        long longValue = 10000000;
        float floatValue = 2.5f; // f 后缀表示 2.5 是 float
        double doubleValue = 33.333;

}
```

图 14.16 展示了静态 `Character` 方法 `digit` 和 `forDigit`，它们用于在不同的数字系统中将字符转换为数字和字符。常见的数字系统包括十进制（10 进制）、八进制（8 进制）、十六进制（16 进制）和二进制（2 进制）。基数也称为基数（radix）。有关数字系统之间转换的更多信息，请参见在线附录 J。

```java
// Fig. 14.16: StaticCharMethods2.java
// Character 类静态转换方法.
import java.util.Scanner;

public class StaticCharMethods2 {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        // 获取基数
        System.out.println("Please enter a radix:");
        int radix = scanner.nextInt();
        // 获取用户选择
        System.out.printf("Please choose one:%n1 -- %s%n2 -- %s%n", "Convert to digit", "Convert character to digit");
        int choice = scanner.nextInt();
        // 处理请求
        switch (choice) {
            case 1: // 将数字转换为字符
                System.out.println("Enter a digit:");
                int digit = scanner.nextInt();
                System.out.printf("Convert digit to character: %s%n", Character.forDigit(digit, radix));
                break;
            case 2: // 将字符转换为数字
                System.out.println("Enter a character:");
                char character = scanner.next().charAt(0);
                System.out.printf("Convert character to digit: %s%n", Character.digit(character, radix));
                break;
        }
    }
} // StaticCharMethods2 类结束
```

第 28 行使用 `forDigit` 方法将整数转换为由整数基数（数字的底）指定的数字系统。例如，16 进制（基数）中的十进制数字 13 对应的字符值为 'd'。在数字系统中，小写和大写字母代表*相同的值*。第 35 行使用 `digit` 方法将变量字符转换为由整数基数（数字的底）指定的数字系统中的整数。例如，字符 'A' 是十进制 10 的 16 进制（基数）表示。基数必须在 2 到 26 之间（包含边界）。

图 14.17 展示了 `Character` 的构造函数和几个实例方法——`charValue`、`toString` 和 `equals`。第 7–8 行通过将字符常量 'A' 和 'a' 赋值给 `Character` 变量实例化两个 `Character` 对象。Java 自动将这些字面量转换为 `Character` 对象——这一过程称为装箱（autoboxing），我们在第 16.4 节中详细讨论。第 11 行使用 `charValue` 返回存储在 `Character c1` 中的 `char` 值。第 11 行使用 `toString` 返回 `Character` 对象 `c2` 的字符串表示。第 13 行中的条件使用 `equals` 方法判断对象 `c1` 是否与对象 `c2` 内容相同（即每个字符是否相等）。
