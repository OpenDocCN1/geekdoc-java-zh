
# 引言：革命理论与实践重构的三个基本前提

今天，任何有意义的革命理论与实践重构项目都必须以三个基本前提为出发点：物理意义上“细胞-组织社会”的重建，作为一个政治实体，即其授权机构的制度；消除所有形式的统治——而不仅仅是经济剥削；以及实现这一成就的显而易见的决，消除所有形式的等级制度——而不仅仅是社会阶级。马克思主义的还原论态度用“公共领域”这一模糊术语定义了统治性的政治实体，用经济剥削定义剥削，用经济阶级定义等级制度，这掩盖并消解了这些概念之间的差异。我们很容易就能实现一个声称不受阶级统治和经济剥削的“公共领域”，但它却充斥着父权制、官僚体制以及一套基于职业、种族和年龄的统治者与被统治者系统；如果我们从“社会主义轨道”的经验来判断，这一点是痛苦而显而易见的。回到有机社会的需求——一个真实的政治实体的形成和社会活跃的公民阶层——就是将社会恢复为真正的“细胞-组织”。实际上，社会必须成为字面意义上的政治实体，即公民必须在物理上控制社会过程，成为社会政策制定和执行中的生动存在。

# 政治实体与人民主权

卢梭（Rousseau）过分地准确地认识到，一个失去了作为公民大会之体现的政治实体，是对人民的否定。如果“人民”缺乏一种展示其物理存在并赋予这种存在以决定性社会意义的制度结构，那么“人民”这个词就没有意义——如果他们不能集会辩论、制定并决定塑造社会生活的政策。政策的制定越是通过中介和授权机构而偏离了议会中人民面对面的决策过程，人民作为社会生活和社会唯一真实的构性力量的地位就越是是被颠覆的，主权被赋予了少数人，人民被还原为一种抽象，一个没有人民参与的“公共领域”或仅仅是“公共空间”。每一个消解政治实体的企图背后，无形的主权源于对“选民”的隐秘信仰，认为只有他们被赋予了统治和命令的能力。最终，这种观点等同于否定了人类自我管理的可能性，否定了每个个体内心实现那些特权少数自认为拥有的社会智慧力量的火花。无论环境如何被还原为对教育、空闲时间、文化机会和职业处境的否定，都掩盖了“大众”内部的这种火花，但这不能作为社会生活（特别是涉及个人的方面）本可以不同的论据。

# 授权权威与自我管理

授权权威实际上不仅否定了人民，也否定了大众自我管理概念底下的自我性主张。正如我在其他地方强调的样，一个声称是自我管理的社会如果没有自我活动（self-activity）是不可想象的。事实上，革命可以被定义为自我活动的最先进形式，即直接行动提升到土地、工厂、乃至街道都由自治的人民直接接管的水平。在缺乏这种水平活动的情况下，社会意识更多是大众意识，很容易被等级制度所操纵。授权权威损害了“大众”发展为具有自我意识主体的个体化，使他们能够直接地、不受中介地将社会掌握在自己手中。它不仅否定了“公共领域”和政治的构成，也否定了个人成为社会代理人——成为雅典意义上的“公民”。

# 雅典民主与公民美德

我们今天生活在当下的暴政下，这种当下往往比过去更具压迫，尽管萨特（Sartre）对过去的“污泥”的意象恰恰相反。我们自由的社会“模型”一直是俄国革命，但由于缺乏足够的自我控制，无论是雅典民主还是通过无限权利的议会、苏维埃和委员会的这种“民主”，都无法防止方面的混乱或方面的暴权。这些特征结合在一起，使得更广泛的社会成为可能。尽管雅典民主存在缺陷，陪审法和人民议会的实践，芬利（Finley）观察到，“将普通公民的智力水平提高远超古代或现代任何人的例子”。雅典公民有义务权衡非自己的利益；在利益主张冲突时，受一种比私人偏见不同的规则的引导；在心灵自然的这种程度上，在柏图式的这种带有色彩的对话中找到了表达。自由的人拥有独特定义人类的`techne`（芬利翻译为“判断的艺术”）和`dike`（我们翻译为正义）。但对于这些特征，他们拥有`philia`（我们是否应该翻译为“团结”而非“友谊”？）和`dike`之外，还有一种共同体感，注定了他们生活在城邦。这些公民的特征结合在一起，构成了我们所说的自我控制的人性，这使得`koinonia`（共同体生活）成为可能。此外，这种自我控制是一种活跃的人性形式，而非我们经常与当代公民权联系的`pathia`（情感缺失）。在去中心化的“权利”和“义务”制度内，有一种传统（亚里士多德《雅典宪法》8.5），公元前六世纪的梭伦（Solon）针对冷漠通过了以下法律：“当城市发生内战时，任何不为一方拿起武器的人都将被剥夺公民权利和政府参与权。”法律的真实性值得怀疑，但这种情感并非如此。伯里克（Pericles）在他的葬礼辞中表达了这一点，他注意到贫困并非障碍，并说道（西西西德2.40.3）：“任何人都可以兼顾自己的事务和国家的事务。我们认为不参与公民生活的人是只顾自己的事，是无用的。”25

# 直接参与与人性发展

讽刺的是，我们必须转向约翰·斯图亚特·米尔（John Stuart Mill），而不是他的同时代，来评价直接参与社会生活和人性的发展如何相互促进，从而形成活跃公民的美德和承诺，人性的最高表现。尽管雅典民主存在缺陷，陪审法和人民议会的实践，米尔观察到，“将普通雅典公民的智力水平提高远超古代或现代任何人的例子”。雅典公民有义务权衡非自己的利益；在主张冲突时，受一种比私人偏见不同的规则的引导；在每一个时刻，应用以公共利益为存在理由的原则和格言。汉娜·阿伦特（Hannah Arendt）将把这一教育过程——古希腊人称为`paideia`的个体精神塑造的要素特征——表述为一种“扩大心态”，这使得真实的判断成为可能。26 城邦不仅是一个目的，更是一个使政治可能的手段。27

# 实践与自我形成

实践（“参与”是一个软弱的词汇）是一种自我形成的模式。在这一层面上，人们仅仅达到一种“普遍兴趣”，但开始超越“兴趣”本身。“兴趣”这一由资产阶级启蒙运动滋养的术语，在马克思主义文献中处处表现为“阶级利益”，在新马克思主义中表现为“知识兴趣”，而它正被一种基于希腊概念“友谊爱”（`philia`）或基督教传统中“博爱”（`agape`）的互惠性与结社的可能性所取代。

# 年轻黑格尔的博爱愿景

年轻的黑格尔尽管蔑视奴隶为“主人的兄弟”，但他深植于一种新人类联盟的千禧年理想和约阿希尼式的对于实现时代的愿景。在这种三位一体的愿景中，爱（作为圣灵体现的爱）超越了标志着子时代的信仰和标志着父时代的法律。对于年轻的格格尔而言，“真爱，或正义上的爱，存在于力量相等、因此在彼此眼中各方面都平等的生命者之间”——同样，为了实现这种对“被爱的生命者”的倒数承认，他们必须力量相等。（我的M.-B.）黑格尔在其末世愿景中构想的博爱，不再有“兴趣”的驱动；事实上，它剥夺了人所有的外在特征，并在没有任何进一步在此的基础上发现了生命本身。这不是一个在灰色之上涂抹灰色的世界。“在爱中，个体依然存在，但作为某种统一体而非孤立体；（在主体中）感知生命（在客体中）。”事实上，爱取代了法律，人们完全理直气壮地问，在这个所有生命者力量相等的时代，还需要中介和国家吗？²⁸

# 扩大心态与判断

在一个“兴趣”让位给友谊爱和博爱的世界上，在一个判断产生于“扩大心态”的自我形成交流和精神教育的世界里，装配体达到了它的完满。被赋予这种心态的，阿伦特说：“即使当我避开任何聚会，或在形成观点时完全孤立，我并非仅仅是在哲学思考的孤独中与自己待在一起，”。“我仍然留在这个相互依赖的世界里，在这里我可以使自己成为他人的代表。诚然，我可以拒绝这样做，形成一个只考虑我个人利益或我所属群体利益的观点……但一个观点作为判断的特质，取决于其不公正的程度.³⁹ 如果阿伦特的观点要有意义，“不公正性”必须被字面化地理解——作为一种超越了“局部的”、或单面的，以及某种预设承诺的“偏见性”的条件。“普遍兴趣”的出现，实际上是废除了根根于“兴趣”和单方面社会的自我的“偏见性”。

# 物质前提与无产阶级公共领域

这种这样形成的“观点”和判断具有物质前提和历史背景，这已经得到了充分强调，以至于在此处进行讨论是不言而喻的。但阿伦特的“扩大心态”必须产生于一个在物质上与“阶级利益”的形成及其作为“阶级意识”的意识形态不兼容的领域。但一旦强调了这些物质前提，我们必须补充一点，“无产阶级公共领域”是一个时代错误，因为无产阶级作为一种无产阶级，作为公共领域的虚构表达，是一种反对“兴趣”的普遍化、废除以及公共体形成的“兴趣”。马克思在追随资产阶级现实的同时，剥夺了无产阶级和社会个人形式，如果没有这些形式，它无法作为普遍化人性的一部分来发展其存在，这并非偶然。马克思的著作对无产阶级的“掏空”是无情的，正如资本主义掏空“细胞组织社会”一样。正如抽象劳动很重要，抽象阶级在一种超越他们意志甚至超越他们清晰理解的“利益”冲突中相互冲突。马克思将无产阶级视为政治经济学的一个范畴——作为劳动力的“所有者”、资产阶级剥削的对象以及工厂制的产物——这反映并意识形态化了它在资本主义下作为“生产力”而非革命力量的真实单面状态。马克思对这一构想毫无怀疑。作为最完全去人性化的阶级，无产阶级超越了其去人性化的状态，通过“一种紧迫的、不再不可区分的、绝对命令的需求”嵌入了人类的整体。因此，问题不是这个或那个无产阶级，甚至是整个无产阶级此刻将什么视为其目标。问题是无产阶级是什么，以及根据其存在，它将被迫做什么.³30（贯穿的重点是马克思以及他对无产阶级的去主体化。）我将搁开这一公式为精英组织提供的理论依据。目前，重要的是，马克思遵循古典资产阶级政治经济学的传统，完全将无产阶级客体化，并将其作为真正的主体移除。无产阶级的反抗，甚至其人性化，不再是一种人类现象；相反，它变成了不可避免的经济规律和命令需求的功能。无产阶级作为无产阶级的本质是其非人性，是其作为“绝对命令的需求”——“兴趣”产物的生物性。它的主体性落入了严苛必然性的范畴，可以用经济规律来解释。无产阶级的心理学实际上就是政治经济学。

# 无产阶级的主体性与欲望

真正的无产阶级抵抗这种将其主体性还原为需求产品的做法，并日益生活在欲望领域，在成为自身之外者的可能领域。具体而言，工人反抗工作伦理，因为考虑到非层级社会的可能性，这种伦理已变得不理性。从这个意义上说，工人超越了她的生物性，并日益成为主体而非客体；非无产阶级者而非无产阶级者。欲望而非仅仅是需要的，可能而非必然的，进入了她的自我形成和自我活动。当无产阶级的人性开始取代工厂时，工人现在可以作为女性或男性、父母、城市居民、青年或老年人、环境的受害者（这个名单几乎无尽）被触及，并日益凸显出来。个人和社会关注开始与作为“扩大心态”的工厂相竞争。任何“工人群体”如果不处理工厂环境中的诉求，就不可能具有革命性。在真正变革的情况下，工人阶级是因为自身而非反对自身而具有革命性的这确实值得怀疑，³¹

# 亚里士多德与马克思论人的本质

对于亚里士多德来说，“人天生是政治性动物；因此，即使人们不需要帮助，他们也渴望生活在一起。”由于他们对美好生活有“共同兴趣”，他们也聚在一起，为了生命而维持政治伙伴关系（即`politiken koinonia`，M.-B.）³² 对于马克思来说，“人可以通过意识、宗教或你喜欢的任何其他东西与动物区分。只要他们开始生产生存资料，就开始与动物区分开来，这受到物理组织的限制。通过生产生存资料，我们间接地生产了他们的现实条件。”³

# 智慧与教化：黑格尔论苏格拉底与耶稣

再次是年轻的黑格尔，最清晰地阐述了智慧作为“教化”（`paideia`）的地位，特别是在教师与受教者之间富有成果互动，而非领导者与被领导者之间——这种教化既能影响革命性文化或“运动”的发展，正如它能影响革命性情感一样。年龄、经验和个人天赋可能会赋予智慧，但没有理由认为它们应该赋予权力。黑格尔对耶稣与苏格拉底的区分，在其真实的社会土壤上准确无误地指出了这一点。基督徒门徒仅仅是追随者。黑格尔观察道，“由于缺乏任何自身的精神能量储备，他们发现自己信念的基础主要建立在与耶稣的友谊以及对他的依赖之上。他们并没有通过自己的努力获得真理和自由；通过艰苦的学习，他们获得了对这些事物的模糊感知和某些特定的公式。他们的野心是忠实地保持这套教义，并忠实地传给他人，而不进行任何增添，任由其在他们自己的工作中产生任何变异。”

相比之下，苏格拉底的朋友们“从年轻起 . . 已经在许多方面发展了自己的能力。他们吸收了那种民主精神，这种精神赋予了个人更大的独立性，使得任何可以容忍的首领都不可能完全绝对地依赖某一个人。在他们的国家，拥有政治兴趣是值得的，而且这种兴趣永远不会被牺牲。他们中的大多数人已经是其他哲学家和其他老师的弟子了。他们爱苏格拉底是因为他的德行和哲学，而不是因为他而爱他的德行和哲学。正如苏格拉底为他的家乡而战，在战争中作为勇敢的士兵履行了自由公民的所有职责，在和平时期作为公正的法官一样，他所有的朋友都不仅仅是消极的哲学家，而不仅仅仅仅是苏格拉底的弟子。”^24

# 城邦与会众的对立

城邦（`polis`）强调自由和活动，与强调敬畏和静修主义的会众（`congregation`）形成对立。黑格尔恰恰触及了产生不同的社会背景，这些背景产生了希腊的门徒和犹太的信徒、教师与领袖、城邦的民主共同体（`koinonia`）以及教会的阶级基础设施。在这两个极端之间的张力中，涌现出不同的自我感：由精神、理性和团结之光构成的受控自我，以及由理性化社会、教条和碎片化的鞭笞所构成的受控自我。在现实，无论是在革命运动中还是在社会中，都不再有中间地带的空间了。这一世纪的历史已被无止尽的“收益”和“中介”所毒害，这些东西威胁着社会自身的篝火——这些“改进”被服务于一种无处不在的统治，这种统治无处不在以使自我与其自身的奴役同谋。近四十年前，维尔克海默（Wirkheimer）本可以写：“革命运动从负面反映了正在遭受攻击的局面。”这些话似乎很温和。“革命性”运动——作为左翼本身——积极地支持着它声称要攻击的局面。大众党是大众社会存在的先决条件，左翼的整个未来取决于它是寻求恢复一个政治体——面对面公民的共同体（`koinonia`），还是以“实用主义”、“权宜”以及适当“中介”的名义，通过进步、规划——甚至“革命”的修辞来助长日益增长的理性化。

# 市政传统与革命运动

在左翼内部的争端之外，是历史和社会进步的更广泛的社会问题。然而，市政传统尽管微乎其微，在当今西方社会中作为一种美国传统延续，这种传统对于革命运动可能具有比欧洲强调集权更大的意义。刘易·蒙福德（Lewis Mumford）观察到，“新英格兰通过中心核心分裂为新的细胞并持续增长，这些细胞拥有自己的独立生活，这回起了早期希腊的模式，但新英格兰的城镇增加了一个新特征，这一特征从未得到过充分的赞赏，也没有像它应当那样被广泛复制：镇区（`township`）是一个政治组织，它包围了一个城镇、村庄以及它们周围的开放农村地区：它履行了地方政府的功能。”

阅读了马塞斯的文章，并认为诸如《在马德里之死》这类令人反感的“纪录片”的人必须接受关于西班牙真实事实的教育，更不用说诸如毛泽东的“自由主义”倾向和“外部无产阶级”理论等神话了，这一立场后来成为了西方宣传的基石。
