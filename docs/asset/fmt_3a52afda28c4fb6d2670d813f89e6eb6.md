
# 珊瑚礁的危机

珊瑚礁是海洋海岸线每个当地社区的重要部分。世界上三分之一的珊瑚礁——以及四分之一的鱼类——分布在印度尼西亚海域。印度尼西亚90%以上的珊瑚礁正面临困难。²¹

在菲律宾，只有5%的珊瑚礁处于“良好状态”。台湾沿岸的珊瑚礁已经超出了白化的范围，并因疾病真的变黑。

加勒比地区超过50%的珊瑚覆盖已经消失。联合国最近的一份报告显示，加勒比大部分珊瑚礁覆盖区将在未来二十年内消失。²²暖水、过度捕捞和局部污染的共同作用预示着那里的珊瑚礁正在灭绝。

联合国环境指出：“沿海人口爆炸、过度捕捞、沿海地区污染、全球变暖和入侵物种……使加勒比珊瑚礁面临灭绝危险。”

联合国两年前的一份报告是详尽的。它是基于对加勒比地区90个不同地点3万5千份调查的分析。研究得出，受损最严重的珊瑚位于加民加、佛罗里达州沿岸和维尔京群岛。

尽管我们大多数人可能永远不会潜海去访问或拍摄那些沿我们海岸线生长了千年的生动多彩的珊瑚礁，但它们的灭绝仍将深远影响我们所有人。

珊瑚礁为养活数千人的鱼类提供了家园。它们支撑着数百亿美元的旅游业。它们的崩溃将首先影响处于这一灭绝前线的人，随后将影响我们其他人。

这就是为什么科学家和其他专家正在密切关注气候变化复杂且隐蔽的影响。随着北极、萨赫勒和大堡礁等地明显发生政权转变，行动的时机就是现在，在这些问题变成不可逆转的转折点之前。

# 影响

毁灭性的变化正在全球范围内发生，改变着物种、城市、农业以及我们所知的生活的其他方面。

灭绝级的危险正面临着多种物种，包括人类和消失的动物种，这是气候变化的结果。“影响”讲述了这些毁灭性变化的有力故事。

更频繁的热浪正威胁着全球各地的人的生命——无论是在美国西部、西欧、俄罗斯还是马哈什。随着地球变暖，动荡和暴力正在蔓延，特别是在中东等地。

在创纪录海洋温度、海平面上升和降水变化的推动下，风暴的频率和强度增加到可能需要产生新类别的超级风暴。这些“六级”风暴（风速超过175英里）有能力摧毁城市——甚至是迪拜和坦帕——并破坏渔民和农民的生存。

极端事件——无论是袭击海岸线的风暴、洪水还是水资源短缺——正在产生一种尚未被承认的新难民。这些流离失所的人是人道主义者和他们迁入国日益关注的焦点。

哈萨克斯坦中部的亚洲马鹿等标志性物种一直受到偷猎、土地开发和掠食性狼的威胁。然而，它们生存了数千年——直到一夜之间发生了近20万只的大规模死亡。非洲象和中国的大熊猫也面临灭绝级的威胁——很大程度上是因为环境景观的变化，这些它们可能无法应对。

毫无疑问，这四个地区不断增加的影响将改变我们的地球及其居民，但如果我们现在从当地、国家和全球范围内通过可持续策略进行准备，我们就可以减少热浪、风暴和洪水的损害，并保护标志性物种的残存。

# 热

《邮报》文章说：“地球将发生足够的变化——在此过程中将伤害足够的人——即使是共和党也必须承认这个问题必须得到解决。问题是国家和世界将付出什么样的代价，以金钱、生命和生态灾难来衡量，因为我们的领导人在期间疏于职守。”

一个研究人员和民社会团体组成的财团报告得出，尽管美国人可能不受珊瑚死亡的影响，但世界其他地区渔业社区的数十正处于危险之中。

国际自然保护联盟表示：“全球有超过5亿人依赖[珊瑚礁]获取食物、风暴保护、工作和娱乐。”珊瑚礁的死亡威胁着这整个群体。²⁰

湿球球温度每年在世界许多地区出现十、二十或三十天，其意味着无论怎么强调都不为过。在过去，仅仅在这样的湿球温度持续的一天内，整个城市就陷入了几乎无法管理的混乱。仅仅因为这种无法生存的情况持续一天，就爆发了暴乱。当这些湿球日以十或二十倍的频率降临密集地区时，会发生什么？不幸的是，我们可能很快就会发现答案。²

这就是为什么2015年班达尔马哈沙尔（Bandar Mahshahr）的夏天可能具有如此致命性。当热指数测量达到华氏165度时，人类没有任何种真实的方法可以降温。对于长时间来说，这种温度对人类生命（或几乎任何其他生命）来说实在太热了。如果温度持续高温几天，且没有在一天中大部分时间里保持凉爽的手段，生命将面临威胁。

当极端热浪持续数日时——这种情况在包括中东和非洲部分地区的亚热带地区发生得越来越频繁——在热浪发生期间，人类能做的并不多。警察和军方在热浪期间也会进入高度戒备，因为历史表明，暴力在这些时期爆发得快得多。

政府已敦促居民避免阳光并大量饮水，但对于那300万多因暴力冲突流离失所的伊拉克人来说，这构成了一个困境。伊拉克和其他饱受冲突的国家长期停电停水使得热浪变得……无法忍受——特别是对于该地区超过1400万因暴力流离失所的人来说。

本月早些时候，在伊拉克南部城市巴斯拉（Basrah），抗议者为了争取更好的电力服务与警察发生，发生冲突，导致一人死亡。与该地区的其他国家不同，伊拉克缺乏海滩，且旅行限制使人们难以逃离酷暑，导致许多人——即使是那些幸运能住在家里的人——降温的选择也非常有限。

有些人在河流和灌溉渠中游泳，而另一些人则在有空调的商场里度过几天。³

正如也门的水源暴乱是两年后爆发暴力残酷战争的清晰、不容忽视的预言一样，正如叙利亚毁灭性的干旱和极端降水模式迫使成千上万的农民逃往没有工作的城市并导致了那里的动荡一样，这些致命的热浪也是中东即将发生情况的早期变暖闪现（预兆）。

现在地球几乎每一年都变得更热。在人类有记录的历史中，最热的十年都发生在2000年以后。在厄尔尼诺/拉尼娜循环影响较大的年份，偶尔会有波动。趋势，这一唯一有意义的科学故事，正朝着一个方向发展——

但让公共卫生和军事领导者担忧的，并不是全球温度的渐进式增量增长。而是像湿球温度达到荒谬水平的致命热浪（这正是我们在2015年夏天在中东看到的）这样的极端事件变得越来越常见。

美国国家航空航天局（NASA）科学家在2012年报告说，在整个世纪，地球表面不到1%的区域经常发生我们在班达尔马哈沙尔看到的这类“极热”事件。⁴但NASA表示，自2006年以来，北半球约10%的陆地每年都会经历这些温度。在如此短的时间内，这种两倍的增长是一个巨大的变化。

> NASA对2012年发表在《美国国家科学院纪报》上的研究表示：“全球温度异常图显示，2011年得克萨斯州、俄克拉荷马州和墨西哥的热浪，以及2010年中东、西亚和东欧的热浪，属于新的‘极热’类别。”

这意味着“极热”事件正变得越来越常见和常态，并影响着全球大量的人。在中东等地区，这些事件可能更加极端，但这些事件将迅速影响亚热带地区以外的人。

衡量发生情况的另一个标准是，现在全球各城市经常性地创下温度新高——而创纪录低温的频率只有其的一半。仅在美国，以十年为单位，创纪录高温与创纪录低温的平均比例为2:1。在世界其他地方，这个比例更加失衡。在一个温度没有上升的正常世界里，这个比例应该是1:1.5⁵

即使是“干热”温度（仅衡量纯热量，不考虑其他任何因素）也在某些城市定期刷新令人难以置信的记录。干热温度是我们所有人最常听到的温度。它是官方记录测量的温度。

科威特的米特里巴（Mitribah）的官方温度为2016年夏季记录的最热温度。历史上的第二高温度于第二天在伊拉克巴斯拉记录。2016年7月21日，米特里巴达到了华氏129.2度。第二天，巴斯拉达到了129.0度。

这项记录存在某种竞争。加利福尼亚的死亡谷——这是许多美国人与窒息的夏天联系在一起的地方——夺得了多项记录，与米特里巴和巴斯拉的人在2016年夏天看到的情况相仿。死亡谷在那个夏年的6月也达到了129度。

> “虽然中东最高温度出现在干燥的内陆地区，但位于更潮湿的波斯湾和阿曼湾沿岸的地区面临着最令人压抑的热湿结合，”气象学家杰森·萨梅诺（Jason Samenow）在《华盛顿邮报》中写道。“约100度（30摄氏度）的空气温度结合天文级的湿度水平，使得反映空气体感的的热指数值简直冲破了图表。”⁶

萨梅诺写道，现在的事实是，中东极高温度结合湿度已经如此高，以至于我们没有足够的指数来衡量它。

“这种温度和湿度的结合如此极端，以超了用于测量的热指数范围，”他说。“这个由R. G. Steadman在1979年开发的指数，实际上只打算计算到约136度的值。” 2015年科威特、伊拉克、伊朗等地的热指数比专家自1970年代以来使用的上限还*高*了30度。

虽然这应该是一个警告，但中东以外的人可能尚未意识到这意味着什么。极热将成为那里的常态，并将蔓延到地球其他部分。

“中东过去两个夏天观察到的恶劣状况可能是未来更酷热的预兆，”萨梅诺为《邮报》的博客读者们总结道。“10月发表的一项研究警告说，到世纪末，由于气候变化，温度可能变得人类无法生存。”

能够明确地将如致命热浪等单一极端事件与气候变化联系起来的（研究方法），正在同行评审的科学文献中变得越来越常见。

研究人员汇聚在一起，产生了一系列非凡的研究，专门调查了2015年全球各地的极端天气事件。他们表示，所有这些与地球变化的的气候都有坚固的联系，且很可能是由气候变化引起。极端高温尤为明显。

“正如过去几年观察到的那样，所有研究全球热事件的论文——从埃及、澳大利亚、欧洲、印度尼西亚、亚洲、印度和巴基斯坦——都发现气候变化在加剧这些事件严重性方面起了作用，”他们在发表在《美国气象学会公报》上的这系列研究结论中写道。⁵

科学家们将澳大利亚席卷的“热穹”、滚动的温度和热浪与变化的的气候坚定地联系在一起。

科学家们现在有机会更详细地研究2003年的欧洲热浪，那场热浪导致了四万五千人。地球变化的气候系统使得那场热浪发生的概率至少增加了一倍.¹¹⁰

同样，科学家们得出结论，2010年俄罗斯的一场热浪——导致了五万四千人死亡，损失了150亿美元的小麦作物，并直接导致了埃及革命中的面包骚乱——由地球系统整体变化引起的可能是三倍。这一单一事件导致了欧洲过去五百年来最炎热的夏天.¹¹¹

从今以后，这一切只会变得更加糟糕。杀死成千上万（或者更有可能是数十万）人的超级超级热浪将每十年至少发生一次。来自葡萄牙、德国、瑞士和西班牙的研究人员在《科学》杂志上报告说，在未来几十年里，任何给定时间内发生此类事件的概率将增加十倍。

“像2003年和2010年事件那样的超级热浪打破了欧洲[一半]地区500年的季节性温度记录，”他们写道.¹²

对于生活在澳大利亚的人来说，这些并不特别意外。澳大利亚内陆从未是一个宜居的地方。澳大利亚1900万人口中的大多数人住在海岸附近，因此内陆大部分是沙漠，但在过去几年里，澳大利亚内陆夏季的升温程度已处于过热而无法维持生命的边缘。这时，新闻媒体在其之前的气象图表上方增加了新的“紫色区域”，以解释中澳从未出现过的极高温度。

“严重和极端热浪夺夺的生命数量比澳大利亚任何其他自然灾害都多，”作家雷伊·约翰斯顿（Rae Johnston）说，“例如，在2009年维多利亚州火灾期间，有173人直接死于火灾；37人死于野火之前发生的热浪中。”^13

但从2013年开始，情况呈指数级恶化，当时新闻评论员首次提到一个“热穹顶”，其强度之大，以至于字面面上在整个大陆上制造了滚腾的热浪和肆虐的野火。气象局表示，澳大利亚中部地区每个夏天可能经常看到超过120华度的温度。澳大利亚的历史最高气温是1960年创下的123华度。随着紫色区域变得常态，自2013年以来的每年都出现了新纪录。

目前，这些致命的热浪正频繁地发生在几乎无人居住或人们习惯在酷热变得无法忍受时进入室内避暑的地方，但情况并非总是如此。而且，在世界某些地区，极端高温将成为动荡和冲突的火药桶。

例如，位于南部部的巴斯拉是伊斯兰国最渴望的奖品之一。巴斯拉目前是稳定的，但如果它开始成为紫色区域的常态部分，那么这种不确定性增加国家安全专家已预期多年的复杂性，将只是时间问题。

过去几个夏天在中东观察到的酷热和恶劣条件，可能是未来更极端高温的预兆。2015年印度的热浪导致2500人死亡。同年巴基斯坦的一场热浪夺走了2000生命。在未来的某一点，世界某些地区可能仅仅是热到无法居住。2015年发表在《自然气候变化》杂志上的一项研究利用复杂的超级计算机气候模型显示，在本世纪的某个时期，温度可能会变得令人类无法生存。^14

现在，紫色区域仅局限于澳大利亚中部和死亡谷等地。在最近的几个夏天里，中东连续几天经历了它自己的“紫色区域未来”。印度和巴基斯坦也是如此。它们都是致命的。极端热浪一次就会造成数万人的死亡。它们将变得越来越频繁，直到达到我们视其为常态的程度。

这就是我们的未来。其中一些正在发生。

“随着地球持续变暖，这些热浪只会变得更加常见。它们不仅影响热带发展中国家；它们是全球范围内的威胁，”三位地球科学教授和研究人员在《纽约时报》上关于2015年致命热浪的文中写道。“由于我们无法承受这种极端天气，”地球科学家写道，“我们必须让我们的社区更具韧性。一步是为那些负担不起的人扩大空调的使用。我们必须在温度和湿度达到危险水平时加强预警，并愿意调整工作时间。

对于像美国这样的富裕国家，夏天平均每年会有这种酷热的天气，一个健康人在户外活动不到小时内就会中暑。”⁵

大西洋上空出现了惊人的风速，直到它们登陆陆地才减慢。我们从未在大西洋飓风季节的如此晚阶段，见过过如此持续的风速。我们也从未在如此短的时间内见过曾导致休斯顿洪水淹没的极端降水。

以下是我们对像哈维（Harvey）、艾尔玛（Irma）和玛丽亚（Maria）这类飓风的了解。记录性风暴是由打破纪录的海洋温度驱动的，而海水上升和强雨引发了洪水。哈维、艾尔玛和玛丽亚都在高于平均水平的暖洋上增强。2016年和2017年的全球海洋温度创了历史新高。在艾尔玛案例中，异常暖的水水推动了风暴打破纪录的风速。艾尔玛维持超过180英里的风速持续了37小时，比地球历史上记录过的任何风暴都要长。至于哈维和玛丽亚，更温暖的气气为这两场风暴注入了额外的水分，增加了让休斯顿被淹没数日的雨量，并导致了波多黎各的洪水和滑坡。玛丽亚是登陆美国的第三强风风暴，它以155英里的风速袭击了波多黎各——仅比5级标准差2英里每小时。

风暴变得越来越难以预测，且强度日益加剧。极其罕见的“百年一遇”和“千年一遇”事件发生得越来越频繁……甚至在连续多年。关于大西洋飓风的大量研究表明海水上升正在大幅扩大沿海社区风暴潮的影响范围。2016年飓风马期间，佛罗里达州、乔治亚州、卡罗来来纳州和弗吉尼亚州发生的严重洪水只是这一趋势的一个例子¹。这种现象正在世界各地涌现。它对美国来说变成现实——在一个短暂的时刻——是因为四场飓风在两周时间内威胁了我们的整个海岸。但直到最近，我们通常不会听到关于超级台风或毁灭性飓风的因果联系——至少，还没有——因为科学家们一直在争论，究竟有多少飓风和台风与变化的气候系统真正有关。

然而，最近，同行评审的科学研究已果断地转向将飓风和台风与变化的地球系统联系起来。简而言之，飓风在暖洋水面上形成得更早也更晚，而且现在可能比以往任何时候都更强。

巨大热带风暴的成分已经非常明确：预先存在的天气扰动（例如常见的风暴）、热带海洋的暖水、水分和微风。这些元素随后结合成一个大事件——飓风或台风。如果这在大西洋或东北太平洋发生，它被称为*飓风*（hurricane）。在西北太平洋被称为台风（typhoon）。如果发生在南太平洋或印度洋，它被称为*气旋*（cyclone）。

一旦热带气旋的最大风速达到每小时74英里或更高，它就被分类为飓风、台风或气旋。此时，该天气事件可能包括剧烈的风风、惊人的海浪、暴雨和巨大的洪水。天气预报员根据风力对飓风进行分级。1级飓风的风速较慢。5级飓风很罕见，风速超过每小时155英里。²

不存在所谓的6级飓风或热带风暴。最高等级——即能够摧毁新奥尔良或纽约等整个城市的最强、最具破坏性的飓风或热带风暴的等级上限——是5级风暴。气象学家和科学家从未想象过会有6级风暴，其持续风速超过每小时两百英里，横扫路径上的一切东西。直到现在，这种风暴是不可能的，因此没有必要在5级之上设立新等级。

然而，现在大气中循环的水汽比一个世代前多出5到8%。这加上更暖的温度（这种温度正在驱动飓风通常形成的地方从深海抽出水分），创造了我们从未见过且未做好准备的超级风暴的可能。

这种暖洋与地球大气中更多水分的结合——在世界范围内产生超级风暴的地区在持续干旱和潮湿状况交替的拉扯下——现在开始产生条件看起来完全像6级飓风那样的风暴。我们现在可能不会*称*它为6级飓风，或者不知道将其置于分尺的哪个位置，但并不意味着这种此前不可想象的超级风暴将不会开始摧毁直接处于其路径上的国家的文明部分。

事实是，我们可能在过去的三十年里已经见过6级飓风，因为有证据表明，飓风在那段时间内变得更加极端。全球范围内飓风的数量在近年来可能趋于平缓，但变暖加速了它们在这一时代的强度。气象学家追踪了其中几场风暴，它们在海洋上循环期间的某一点风速曾超过每小时两百英里。

- 等级随后以每小时20英里的幅度递增。
