## 前言

本书涵盖了三类面向对象设计模式，即创建型、结构型和行为设计模式。书分为五个部分，第一部分有一章专门介绍设计模式及其类型的“是什么”和“为什么”。其他三部分每部分有四章，以“一章一模式”的形式关注这些设计模式。最后一部分侧重于设计原则和反模式。

在本书中，我们将讨论软件设计的基础知识以及在全球范围内许多不同软件应用程序中使用的标准设计模式。今天几乎每个功能软件应用程序都使用一种或多种设计模式来完成它们被构建的各种任务。

本书专注于一些最常用的面向对象设计模式及其使用 `Java` 的实现。书中的每一章都专门介绍一种设计模式，以确保更好的可读性和理解。各个章节采用以问题为中心的方法，讨论可以解决的问题。本书将使对软件开发有良好理解并熟悉中大型规模的人士受益。

### 引言

软件开发不仅是为了解决问题，更是为了高效地解决问题。问题解决是一个涉及多个步骤的过程。从识别问题开始，开发相应的算法，最后通过实现。软件可以通过许多不同的方式实现，从设计算法到使用正确的数据对象及其整合；这些都是实现软件的一部分。然而，如果没有良好的设计，即使是最好的实现也可能崩溃。

设计软件并不是一项容易的任务；它需要大量的努力和知识才能给出易于实现、可行且在本质上可扩展的设计解决方案。如今，软件处理的数据量在存储方面不仅更大，而且更加复杂。由于软件系统中存储了这么多信息，检查系统的当前设计并过渡到能够适应增加使用和快速处理的更好设计变得非常重要。软件设计不仅是为了以定义的方式放置物品，而且是为了建立互连的路径，帮助在多个可控制结构之间传输数据，形成执行时以高效方式完成任务的流。

用有趣的方式来说，软件设计赋予了它生命。它不仅支持底层框架，还让开发者能够扩展系统并为未来的变化做好准备，即使有时他们并没有意识到这些变化。良好的设计确保软件是健壮的，并且能够更容易地适应新功能，所需时间比没有适当设计时要短。如果你今天在读这本书，意味着你已经有一定的编程经验，现在希望进一步探索并学习各种设计技术，这些技术不仅将帮助你编写更好的软件，还将帮助你轻松地管理它。在书中，我们将讨论软件设计的基础知识以及在全球许多不同软件应用程序中使用的标准模式。今天几乎每个功能软件应用程序都使用一种或多种设计模式来完成它们被构建的各种任务。我们还将讨论使用一种设计模式而非另一种模式的优缺点，以及何时使用哪种设计模式。

### 设计模式

软件工程中的设计模式是从良好设计的练习中得出的蓝图或模板，用于解决通常具有重复性的典型问题。设计模式也可以被视为有效克服软件设计问题的最佳实践：图 1.1 展示了设计模式的一些核心属性。

图 1.1 设计模式

设计模式遵循系统的方法，并可以在各种情况下重复使用，因为它们提供了解决特定问题的想法。它们本身不是实际代码，而是帮助我们通过方式解决问题的蓝图或通用解决方案。设计模式可以包含一个或多个对于成功实现是必要的接口。

设计模式大致分为三类，即创建型、结构型和行为型。
