旭酒集团将于2021年底前禁止食品饮料动物实验

旭酒集团将立即停止化妆品动物实验

自2020年1月起，JAVA一直要求旭酒集团控股有限公司（以下简称“旭酒集团”）禁止动物实验。旭酒集团在给JAVA的回复书中明确表示，他们将在2021年底前禁止食品饮料的动物实验，并立即停止化妆品和准药品的动物实验。

结果，旭酒集团的动物实验政策如下：

旭酒集团明确：

- 1) 将在2021年底前完全禁止食品饮料领域的动物实验。
- 2) 已于2020年6月30日完全禁止化妆品领域的动物实验。
- 3) 已于2020年2月完全禁止日用品领域的动物实验。
- 4) 将加强对替代动物实验开发与推广的人力及资金投入：将人力投入增加到以前的三倍以上，增加研发费用，并于2020年5月加入日本替代动物实验学会等。

然而，在以下例外情况下仍可能进行动物实验：

1. 如上市后的事故等涉及公共卫生责任的情况。
2. 受其他国家法律体系强制要求的情况。

尽管距离2021年底还有一年时间，但JAVA欢迎旭酒集团采取这一果断措施，这表明他们认真对待了不希望动物实验的消费者声音，并决定全面禁止动物实验。

在今年2月21日JAVA与旭酒集团会议后的短短约五个月内，我们成功促成了旭酒集团完全禁止动物实验的决定，包括针对健康保健用食品（FOSHU）和功能性标识食品（FFC）的实验。感谢所有参与此次活动的人。感谢你们的支持！

## 好消息！

世田谷市的青蛙解剖课将取消！

“青蛙解剖”原本是世田谷市教育中心为初中学生计划的暑期活动。

### 关于解剖课

- 世田谷市教育中心计划作为初中生的暑期活动开展科学实验课。
- 该地区的教师将对课程进行指导。
- 通知单上写道：
  > “青蛙是两栖动物，人类是哺乳动物，但我们都是脊椎动物。让我们从两栖类和哺乳类的相似性中学习结构。通过解剖青蛙学习生命的重要性。”

### 解剖的问题与替代方法的优点

切开动物身体在伦理上是不可接受的。我们无法通过残酷的行为学习“生命的重要性”。当青少年参加市里计划的解剖课时，他们可能会认为切开并杀掉它们是好事。

有很多方法可以学习动物机制，例如计算机模拟、视频、精密的3D模型等。使用替代方法有许多优点：学生可以反复学习实验过程；可以按照自己的进度进行。一些论文表明，通过替代方法学习的学生优于通过解剖学习的学生。

通过不使用动物的方法，学生学习了伦理态度：例如“不要夺走生命”、“生命是宝贵的”。换句话说，为了让学生获得知识并培养尊重生命的态度，应该使用替代方法而非解剖。

### 回复：世田谷市取消解剖课的决定

JAVA向世田谷市提出了解剖问题，世田谷市提交了请求取消解剖课的方案。JAVA成员和世田谷初中学生的家长向市长表达了意见。

7月31日，世田谷教育委员会回复JAVA，决定取消青蛙解剖课。

该论文中的研究基于对 172 种候选药物的评估，并发现了一个重要事实：三分之二的候选药物在长期毒理学测试中可以仅使用一种动物物种而非两种物种进行开发。

因此，JAVA 和 CFI 将该论文的信息提供给了日本负责制药行业和新开发药物审批审查的两个相关机构，并要求他们计划、应对、辩论并开发使用单一物种而非两种物种的测试方案，同时声称这将在不久后大幅减少动物实验。

## 在欧日经济伙伴关系协定（EPA）背景下鼓励动物福利的信函

7 月，日本动物协会（JAVA）、日本动物权利中心（Animal Rights Center Japan）以及比利时动物权利团体欧洲动物小组（Eurogroup for Animals）向欧盟委员会和日本外务省共同名义提交了《在欧日经济伙伴关系协定背景下为动物做更多努力的呼吁》。

JAVA NEWS 第 104 期英文版已报道，这三个小组参加了由欧盟举办的 EPA 研讨会。

EPA 已于 2019 年 2 月 1 日生效。该协议为欧盟和日本提供了建立动物福利工作组的可能性，并通过通过工作计划来定义这一合作领域的优先事项（第 18.17.2 条）。在“贸易与可持续发展”章节中，双方还应采取有效措施打击野生动物濒危物种的非法贸易，并就此主题交换信息（第 16.6.2(b) 和 (d) 条）。

然而，截至今日，欧盟和日本在该领域尚未取得进展。因此，这三个机构提交了这一呼吁，这是我们利用 EPA 改善动物福利的努力之一。

## 修改后的动物福利管理法已生效

### “适当饲养与管理标准”正在制定中

自 2016 年秋季以来，JAVA、日本动物权利中心和 PEACE 一直开展合作活动以修订《动物福利管理法》。修订后的《动物福利管理法》于 2019 年 6 月 12 日颁布，并于今年 6 月 1 日施行（部分内容于 2021 年或 2022 年实施）。

因此，旧法规的部分内容变得严格得多，例如，“杀害或伤害动物的，处五年以下有期徒刑或五万日以下罚款”取代了“处两年以下有期徒刑或两万日以下罚款”；对于忽视、虐待或遗弃的处罚也更加严格，例如“处一年以下有期徒刑或万日以下罚款”取代了“处万日以下罚款”。动物处理业务的注册要求变得更加严格，对于特定动物（即所谓的猛兽），我们不再允许将此类危险动物作为宠物饲养。

我们在上期 JAVA NEWS 中宣布，《动物福利管理法》修订后，相关的标准和其他内容也必须进行修订或制定，其中一些已经完成。

目前，环境省正在进行讨论和谈判，以制定动物处理业务需要遵守的“适当饲养与管理标准”，这是新修订的《动物福利管理法》中新规定的。

这一标准引起了关注。因为对于涉及猫狗的饲养业务（如猫咖啡馆、非营利组织以及宠物店和育种场），标准包含了笼具尺寸、饲养人员人数以及寿命内的数字等具体规定。JAVA、日本动物权利中心和 PEACE 这三个机构通过在政党举办的会议上发表意见，向议员递请，要求制定“适当饲养与管理标准”。

## 灭虫公司设置的陷阱，JAVA 呼吁防止捕猫

3 月，东京东区的居民向 JAVA 反映，西环境有限公司（以下简称“西环境”）在其公寓区域安装了用于捕鼬等小型动物的陷阱。

- 陷阱在公寓区域已放置长时间。
- 陷阱上写有“西环境”的公司名称及其联系方式。
- 公寓周围有几只流浪猫，居民担心陷阱是为了捕捉这些流浪猫。
- 针对居民的询问，西环境表示他们不从事捕猫业务，但租赁陷阱。

### 阻碍我们的法律之墙

西环境是一家管理设施设备卫生的公司，同时也消灭蟑螂、白蚁、老鼠、果子狸、浣熊等被视为害虫的动物。将它们视为害虫是人类的便利，当然动物本身没有错。JAVA 渴望消除任何生命的牺牲。然而，从法律上讲，消灭上述动物并不违法（消灭果子狸和浣熊需要野生动物保护法的许可）。因此，遗憾的是，JAVA 无法阻止西环境从事这些动物的消灭业务。

### 捕猫的问题

但捕猫时情况不同。如果你抓了属于别人的猫，就犯盗窃罪。显然，捕猫违反了《动物福利管理法》。此外，如果是他人的宠物猫，则构成刑事破坏财产罪。据称，如果捕流浪猫不是为了保护而是为了消灭，则可能被视为“虐待”。因此，如果西环境租赁或安装了捕兽器，西环境有责任采取充分措施防止客户非法捕猫。

### 请求停止陷阱的请求

JAVA 指出了捕猫问题，要求西环境停止陷阱租赁服务。然而，西环境回应道：“租赁陷阱是为了法律允许的捕猎野生动物。我们无法停止陷阱租赁服务。”因此，JAVA 要求采取以下改进措施：

1. 不要出于法律允许捕猎野生动物以外的目的租赁或安装陷阱。
2. 确保租赁者使用陷阱的目的不是为了消灭、虐待或遗弃猫。
3. 让所有员工都意识到诱捕猫类是违法行为。
4. 在租赁陷阱之前，确保承租者承诺在安装和诱捕期间全程监控，且不无人看管陷阱。
5. 在发给承租者的传单上注明以下内容：
   - 杀害、虐待和遗弃猫类是违反《动物福利管理法》的犯罪。
   - 捕捕猫类可能违反《动物福利管理法》，或可能被视为盗窃。
   - 如果不小心抓到了猫，必须立即释放。
