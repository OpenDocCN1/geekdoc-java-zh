## 编写计算机程序

编写一组指令或算法，帮助计算机轻松地执行该任务。

你无法用英语或任何其他语言编写这些指令。大多数科幻电影和小说将机器人描绘成能够理解它们所说的每一个单词的机器。然而，事实并非如此；由于以下原因，口语语言无法与机器进行通信：

- 句子经常会被误解
- 没有简单的方法使用任何语言来编织复杂的命令
- 英语中的大多数句子包含不必要的单词

你需要使用一种不同的语言与计算机通信。这些语言被称为计算机编程语言。使用这种语言编写的一组指令被称为程序。多个程序构成软件（或代码）。

你可以学习编写计算机程序，也可以使用他人的程序。如果你更倾向于后者，你就需要使用那个人编写的任何程序。然而，当你自己编写程序时，你就可以根据自己的需求对其进行定制。

编写计算机代码从一开始就很流行。大公司有不同部门的团队、部门和员工为他们编写代码。但你可以为自己或为他人编写代码来以此为生，或者仅仅是为了好玩。最近估计，美国编写的代码行超过了木星上甲烷分子的数量。这可能是真的，也可能不是。然而，事实是，如果你花费足够的时间编写你自己的代码，你就可以让你的计算机做任何事情。当然，编写代码花费的时间可能只有几分钟，也可能是几年，但不要让这击退你。你只需要几分钟就可以写出一些最有趣的代码！

## 面向对象的编程

`Java` 是一种面向对象的语言。你可能在想这意味着什么。早期的一些机器语言（如 `FORTRAN`）只关注于向计算机指示需要完成哪些任务。面向对象的语言（如 `Java`）更多地关注数据。当然，这些语言仍然指示计算机需要做什么。然而，在向机器发出命令之前，数据已经过组织了。

`Java` 比 `FORTRAN` 更好，因为它组织数据的方式有助于用户在数据上执行多个功能。如果你想改变数据的组织方式，你就不需要从头开始。你只需要修改正在使用的程序即可。

数据通常使用对象和类来组织。假设你正在编写一个程序，用来跟踪新公寓楼中建造的房屋。这些房屋之间略有不同。每栋房子都有不同的室内油漆、独特的外墙颜色、厨房柜风格、卧室风格等。当你编写面向对象的程序时，每栋房屋就变成一个对象。

对象并不构成整个故事。虽然房屋之间略有不同，但每栋房屋具有相同的一组特征。例如，每栋房子都有一个名为外墙颜色、厨房柜风格、卧室风格等的特征。你的面向对象程序需要一个主列表，由每栋房屋可以拥有的特征组成。这个主列表被称为“类”。就是这样。然而，面向对象的编程应该被命名为“使用类和对象的编程”。

你可能注意到我先使用了“类”这个词，你一定在想这怎么可能行得通。让我们考虑一个公寓开发项目。在施工正中间，可能有一个摇摇晃晃的拖车，上面有一份被称为“蓝图”的特征列表。面向对象程序中的类可以比作蓝图。蓝图包含了每栋房屋都将拥有的特征列表，以及房屋应该是什么样子的清晰图片。蓝图会写着外墙，但实际的房屋可能有蓝色或黄色的外墙。房屋的每一个其他特征也是如此。

这种类比并不总是结束于特征列表。类和蓝图之间还存在另一种平行关系。一旦创建了蓝图，就可以根据它来建造房屋。

## 为什么面向对象的语言是好的？

让我们以上一节的公寓开发为例，假设你已经编写了一个程序来跟踪这个新开发项目。现在老板决定对计划做出更改——他决定一半将是双层住宅，另一半是四卧室。如果你使用旧的 `C` 语言或 `FORTRAN` 风格，你需要编写的指令如下：

挖基坑。在基坑周围浇混凝土。在基坑周围放置二四木，等等。更糟糕的是，这些指令可能散落在数页纸上。如果建筑师处理这些指令，任务将变得困难十倍。

从类开始类似于从蓝图开始。如果你决定建造双层住宅和四卧室房屋，你可以开始使用一个名为房屋的蓝图，它拥有地面层和楼层，且没有任何墙壁。然后你可以制作两个类似的蓝图——一个用于顶层，一个用于四卧室——并重命名这些蓝图。你的同事会对你所做的一切感到惊讶，但他们会有顾虑。他们可能会问以下问题：“你重命名了所有蓝图，如果使用的蓝图几乎相同，你该如何这样做？”

这时你就会说：“双层房屋蓝图可以写道‘关于楼层的更多信息，请查看原始蓝图。’”四卧室蓝图也可以这样说。我们可以利用已经制作的蓝图，并通过这种设置节省大量金钱。

当涉及到面向对象编程时，双层住宅和四卧室类继承了原始房屋类的特征。你也可以说这两个类是原始房屋类的扩展。

原始类被称为目前设置的两个类的超类（`superclass`）。这两个类被称为原始类的子类（`subclasses`），因为它们继承了原始类或超类的特性。这些类在技术术语中被称为父类和子类。

这时你就可以很有信心地告诉他们，你永远不需要动原始房屋的蓝图了。你只需要创建另一个小蓝图并重命名即可。如果有人想在底层添加一个花园，你可以为那个花园准备一份蓝图，并将其重命名为“客厅里的花园”（`Garden-in-living-room`）蓝图。你可以使用原始蓝图处理房屋的其他部分，并将新蓝图作为原始房屋蓝图的扩展。在面向对象编程的语言中，客厅花园计划图是原始房屋蓝图的扩展。“客厅里的花园”蓝图仍然是原始类的子类。超类、父类和子类的所有术语仍然适用于这个新蓝图。唯一的新的一点是，花园将成为原始蓝图的一个新功能。

在面向对象编程语言开发之前，编程世界在开发软件方面经历了一场巨大的危机。程序员编写了新代码，然后发现他们需要一些不同的东西。他们不得不放弃代码并重新编写新代码。这个问题反复发生，大多数所编写的代码都无法重用。面向对象编程彻底改善了这一局面。

## 第 4 章：理解一个简单的 Java 程序

本章分析并解释了上一章展示的 Java 程序。

### Java 类

由于 Java 是一门面向对象的编程语言，你始终需要创建并描述类和对象。如果你对此还不确定，那么你需要重新阅读一遍第 1 章。

与任何其他面向对象的编程语言相比，Java 是最纯正的面向对象编程语言之一。这是因为一旦你创建了某种类，你就可以在 Java 中做任何事情。这就像你在看《危险一答》（Jeopardy）节目，听到 Alex Trebek 说：“让我们进入广告时间！”然后你打断他并说：“抱歉，如果你不向你的类中添加一条指令，你不能那样发布任何指令。”

记住，你编写的整个程序都是一个类。当你编写程序时，可以为你的类命名。最好使用一个描述该类功能的名称。该程序使用了 `Displayer` 这个名字（因为该程序在屏幕上显示一行）。这就是为什么上一章的程序将类命名为“Example”。

程序前两个单词是 `public` 和 `class`，它们是 Java 的关键字。无论你正在编写什么程序或由谁编写程序，`public` 和 `class` 这两个词的使用方式完全相同。另一方面，`Displayer` 被用作标识符，因为它标识了程序中的特定类。`public` 意味着 Java 中的其他所有程序都可以使用声明的函数功能。

Java 编程语言是区分大小写的。如果你在 Java 中将一个小写字母改为大写字母，你就改变了整个单词的含义。有时这些单词会变得毫无用处。在程序的第一行中，你不能将单词 `class` 替换为 `Class`。如果你这样做，整个程序将停止工作。包含该特定类的文件名也是如此。例如，上一章程序中的类使用了一个名称以大写字母 D 开头的类。如果你在任何其他程序中调用此类，你需要使用完全相同的名称——“Displayer”。

如果你定义了任何类，它的代码将进入一个与类名同名的文件。例如，`Displayer` 类中的代码将进入以下文件——`Displayer.java`。类名的拼写与程序中类名完全相同。记住这个文件命名约定很重要。

### Java 方法

你在一家高档修理厂担任汽车修理技师。你的老板总是风风火火，并且有单词连在一起说的习惯，他说：“`fixTheAlternator on junkyOldFord`（给那辆旧福特修理发电机）”。你在脑海中过了一遍任务清单：“开车进维修间，打开引擎盖，拿一把扳手，松开发电机带”，等等。这里发生了三件事：

- 你对需要做的事情有一个名字。这个名字是 `fixTheAlternator`。
- 在你的脑海中，你有一份与 `fixTheAlternator` 相关的任务列表。列表包括“开车进维修间，打开引擎盖，拿一把扳手，松开发电机带”等等。
- 你有一个脾气暴躁的老板让你做所有这些工作。你的老板通过说“`fixTheAlternator`”让你开始工作。换句话说，你的老板通过说出你必须要做的名称让你开始工作。

在这种情况下，使用“方法（method）”一词并不算牵强。你有一个处理发电机的方法。你的老板启动了这个方法，而你通过执行与该方法相关的指令列表中的所有事情来响应。

如果你相信这一切（我希望你相信），那么你就准备好阅读关于 Java 方法的内容。在 Java 中，方法是一份待办事项列表。每个方法都有一个名字，你通过在程序中使用方法的名称告诉计算机执行列表中的事项。

**示例：方法声明**

```java
void fixTheAlternator() {

}
```

在我的 Java 代码的某处（示例之外），我需要一条指令来调用我的 `fixTheAlternator` 方法。调用 `fixTheAlternator` 方法的指令看起来可能像示例中的行。

现在你已经对方法是什么以及它是如何工作的有了基本了解，你可以进一步深入研究一些实用的术语：

- 如果我偷懒，我会把示例中的代码称为方法（method）。如果不偷懒，我会把这段代码称为方法声明（method declaration）。
- 示例中的方法声明包含两个部分。第一行（包含 `fixTheAlternator` 的部分，但不包括左大括号）是方法头（method header）。示例的其余部分（被大括号包裹的部分）是方法体（method body）。
- 有一个对 `System.out.println` 方法的调用。`System.out.println` 方法的调用是 `main` 方法体中唯一的语句。换句话说，调用 `System.out.println` 方法是 `main` 方法待办列表上的唯一事项。`System.out.println` 方法的定义隐藏在官方 Java API 内部。如需复习 Java API，请参阅本章前面的“语法和常用名称”以及“Java 程序中的词汇”部分。

像 `System.out.println` 这样的语句隐藏在 API 内部，这并不能充分体现所用 API 的价值。你可以始终忽略 API 内部的 Java 代码。你只需要记住函数 `System.out.println` 已经在 API 的某处定义了。需要注意的是，API 不仅仅是一个包含大量 Java 代码的库。API 内部的语句始终在告诉计算机，当调用 `System.out.println` 函数时，它需要做什么。

在 Java 中，每条语句都以分号结尾。上一个示例中的其他行没有以分号结尾，这是因为它们不能被归类为语句。例如，方法头（method header）并没有告诉计算机它需要做什么。方法头会宣告：“如果你想使用 `main` 方法函数，可以执行下一组语句。”

记住在 Java 中每条语句都必须使用分号结束，是非常重要的。

### 大括号

你可能在美术课上学过大纲有多么重要。当你有一个大纲时，你可以确保自己只在大纲内上色。想法也是如此——当你有一个大纲时，你就能组织你的想法和思绪，帮助人们看到整个森林，而不仅仅是单棵树。Java 程序也是如此——它就是一个大纲。上一章中的程序以一行代码“这是一个名为 Display 的类”开始。在那个第一个大标题之后，一个子标题宣布：“接下来是一个名为 main 的方法。”

既然 Java 程序就像一个大纲，为什么程序看起来却从不像一个大纲呢？是什么取代了黑色墨水和大写字母？这里可以给出的答案有两点：

- Java 中使用的大括号 `{}` 总是包含一个有意义的代码单元。
- 程序员可以使用这些括号对代码行进行缩进，以帮助其他程序员在浏览代码时识别出代码的大纲。

在大纲中，所有内容都隶属于罗马数字 I 项。在 Java 程序中，所有内容都隶属于顶行（包含 `class` 的那行）。为了表示代码中的其他所有内容都属于该类行，你需要使用大括号。代码中的其他所有内容都放在这些大括号内部。

永远不要忘记，Java 程序首先、最重要的就是一个大纲。

如果你在不该出现括号的地方放错了大括号，你的程序可能完全无法运行。不过，如果你的程序运行了，它很可能会运行错误。

如果你不以提供信息的方式对代码行进行缩进，你的程序仍然可以正常运行，但你或其他任何程序员都无法理解你在编写代码时在想什么。

如果你是一个视觉思考者，可以在脑海中勾勒 Java 程序的大纲。我的一个朋友甚至想象了一个真实的带编号大纲变成了一个 Java 程序！

### 在代码中添加注释

注释是程序内部的文本；其目的是帮助查看者理解程序。注释是记录程序的好方法。Java 中三种注释，将在后续章节介绍。

#### 传统注释

注释始终以 `/*` 开始，以 `*/` 结束。它们之间的所有内容只供人类眼睛阅读——计算机不会读取。如果你喜欢，可以添加更多的星号；这不会影响注释，因为计算机不读取这些。

#### 行尾注释

如果你使用 `//`，你是在表示该行已结束。行尾注释以两个反斜杠开始，一直到行尾。编译器和计算机不会翻译注释中的文本。

#### Javadoc 注释

Javadoc 注释以一个反斜杠和两个星号 `/**` 开始。这是一种特殊的传统注释，始终旨在供那些从未费力读过 Java 代码的人阅读。这听起来不合逻辑，不是吗？你怎么能看到注释却从不读代码代码呢？

有一个名为 Javadoc 的程序，它会使用程序中所有的 Javadoc 注释，并将这些注释转换为网页。

Javadoc 注释非常棒，原因如下：

- 唯一需要查看和编写代码的人是程序员。使用代码的其他人员只需要通过查看自动生成的网页来理解代码的功能即可。
- 由于其他人不需要查看 Java 代码，因此没有需要对该代码进行任何更改。这样一来，程序员可以确保代码不被改动。
- 人们不需要破解 Java 代码的工作原理，因为他们将通过网页学习关于代码的所有所需知识。
- 程序员不需要创建两个独立的东西：关于代码的文档和代码本身。程序员只需要创建那段将 Javadoc 注释形式的文档直接嵌入代码内部的代码即可。
- 使用 Javadoc 注释最棒的部分是，网页是根据它们自动生成的。

## 第 5 章：你的第一个程序

在进入你的第一个程序之前，我们需要查看一些基础语法。每个程序被认为是一个对象的集合，每个对象通过调用方法来彼此通信。让我们来看看这些到底是什么：

- **对象（Object）：** 每个对象都具有行为和状态。例如，狗有状态，如颜色、品种和名字，还有行为，如哀叫、吃东西、摇尾巴。每个对象都是类的实例。
- **类（Class）：** 类就像是一份蓝图，用于描述与该类类型相同的对象的行为和状态。
- **方法（Methods）：** 方法是行为。每个类可以有很多方法，逻辑在方法中编写，数据在方法中处理，所有操作都在方法中执行。
- **实例变量（Instance variables）：** 每个对象都有组唯一的实例变量。对象的状态是通过赋值给实例变量的值创建的。


这绝对是最简单的入门程序，唯一的输出是“Hello Java.”。让我们逐行查看这个程序程序：

- **第 1 行：** 我们声明了一个类，它是由用户定义的数据类型。与其他程序不同，我们必须始终将 Java 函数或变量写在类内部。这个类被标记为公共类（`public class`），这意味着它可以从任何地方访问，且它的名字是 `HelloJava`。在编写 Java 类时请记住这些规则——一个文件可以包含多个类，但其中只能有一个是公共的。在有公共类的情况下，文件名必须与公共类名相同。
- **第 2 行：** 我们在这里使用了 `main()` 函数，这是程序执行开始的地方。该函数无法返回任何类型。`main()` 函数的参数（或参数）必须是一个字符串数组。我们稍后会学习更多，重要的是记住 Java 字符串不是字符数组，与其他语言不同。`[]` 直接跟在数据类型之后。名字 `args` 应该会提示你字符串数组的用途——它们保存命令行的参数。
- **第 3 行：** `print()` 命令只是在控制台上打印输出并将光标移动到下一行。

在这种情况下，输出是：


## 第 6 章：对象与类

### 对象

想想你周围的世界；有很多不同类型的对象，例如狗、人类、建筑、房屋等。每一个这些对象都有自己的行为和状态。以狗为例；它有名称、颜色、品种等状态，以及跑步、吠叫和摇尾巴等行为。将其与软件对象进行比较，你会发现没有太大区别，因为软件对象也有状态和行为。状态存储在字段中，行为通过方法表示。

### 类

类是蓝图，我们可以从它创建对象。每个类可以包含以下类型变量的一个或全部：

- **局部变量**：在方法、块或构造函数内部定义的变量被称为局部变量。它在方法内部声明并初始化，当方法完成后，该变量会被销毁。
- **实例变量**：这是在类内部但在方法外部定义的变量。它们在类实例化时初始化，可以在类的方法、块或构造函数中被访问。
- **类变量**：这些是在类内部、方法外部使用 `static` 关键字声明的变量。

Java 还支持单例类，你可以创建该类的一个实例。

### 创建对象

- **实例化**：我们使用 `new` 关键字来创建对象。
- **初始化**：在 `new` 关键字之后调用构造函数，这将初始化对象。

## 第 7 章：数据类型

变量是用于存储值的保留位置。当你创建一个新变量时，你就在内存中自动预留了该空间。内存的大小由变量类型决定；操作系统分配内存并决定其中可以存储的内容。通过为变量分配不同的类型，你可以存储小数、整数或字符。Java 有两种主要数据类型：

- 原始类型
- 引用或对象类型

### 原始类型

Java 包含八种原始数据类型。这些是由 Java 语言预定义的，并用关键字命名。这八种类型是：

- **Byte**：字节是一种默认值为 0（零）的数据类型。最小值为 -128，最大值为 127。它通常用于节省较大数组的空间，通常代替整数，因为整数是字节的四倍大。
- **Short**：短整型是一种默认值为 0 的数据类型。最小值为 -32768，最大值为 32767。为了节省内存，也可以作为字节数据类型。整数是短整型的两倍大。
- **Int**：`int` 的默认值为 0。最小值为 -2,147,483,648，最大值为 2,147,483,647。除非内存短缺，否则它通常作为整型值的默认类型。
- **Long**：`long` 的默认值为 0L。最小值为 -9,223,372,036,854,775,808，最大值为 9,223,372,036,854,775,807。当你需要比 `int` 提供的更广泛的范围时使用它。
- **Float**：`float` 的默认值为 0f，通常用于在拥有包含浮点数的大型数组时节省某些内存。当你需要精确值（例如货币）时，永远不会使用它。
- **Double**：`double` 的默认值为 0.0。它通常作为小数数值类型使用，且不应被用于任何精确的值，例如货币。
- **Boolean**：`boolean` 用于表示单条信息，只有两个值：`true`（真）或 `false`（假）。当你需要跟踪为真为假的条件时使用它。它的默认值为 `false`。
- **Char**：`char` 数据类型可存储任何字符。

### 引用数据类型

为了创建引用变量，我们定义了类的构造函数。引用变量用于访问对象，并被声明为特定类型，称为不可变类型——这意味着它们一旦声明就无法更改。引用对象包括类对象和各种数组变量。所有引用变量的默认值为 `null`，它们可以指向所声明类型的对象，或任何兼容的类型对象。

### Java 字面量

字面量是固定值的源代码表示，直接表示在代码中，不需要任何计算。它们可以被赋值给任何基本类型变量，例如：

```java
byte a = 67;
```


```java
int decimal = 100;
int octal = 0144;
int hexa = 0x64;
```

Java 字符串字面量的指定方式与其他语言几乎相同——一组包含在双引号中的字符序列。

## 第 10 章：Number 类

我们在 Java 中处理数字时，通常处理的是 `int`、`byte`、`double`、`long` 等原始数据类型。然而，偶尔你可能需要使用对象包装类而不是这些数据类型，为了实现这一点，Java 为我们提供了包装类。包装类有：

- `Integer`
- `Long`
- `Byte`
- `Float`
- `Double`
- `Short`

这些中的每一个都是 `Number` 类的子类，而 `Number` 是一个抽象类。

每个包装类的对象将封装或包含其各自的原始数据类型。将原始数据类型转换为对象被称为“装箱”（boxing），编译器会为你完成操作。因此，当你使用包装类时，只需要将相关数据类型的值传递给包装类的构造函数即可。要将包装对象转换回原始数据类型，我们使用一种被称为“拆箱”（unboxing）的过程。

这是一个装箱和拆箱的示例：

```java
public class Test {
    public static void main(String args[]) {
        Integer x = 5; // 将 int 装箱为 Integer 对象
        x = x + 10; // 将 Integer 拆箱为 int
        System.out.println(x);
    }
}
```

该代码的输出是：

```
15
```

当我们给 `x` 赋值一个整数值时，编译器会对该整数进行装箱，因为 `x` 现在是一个整数对象。随后，`x` 被拆箱以便可以作为整数进行加法。

## 第 12 章：Java 数组

数组是一种用于在顺序集合中存储固定大小元素的数据结构。更简单的理解方式是，数组存储了一个所有类型相同的数据集合（变量的集合）。你不需要逐个声明变量（如 `number1`、`number2` 等），而是声明单个数组变量（如 `numbers`），然后使用 `numbers[1]`、`numbers[2]` 等表示每个单独的变量。

### 声明数组变量

如果你想在程序中使用数组，首先必须声明一个引用该数组的变量；你还需要指定该变量可能引用的数组类型。要声明数组变量，请使用以下语法：

```java
dataType[] arrayRefVar; // 首选方式
```

或者

```java
dataType arrayRefVar[]; // 可用但不是最佳方式
```

注意：第一个示例是首选方法。第二个示例你有时会看到，但它是 Java 从 C 语言采纳的，以适应那些习惯 C 或 C++ 的程序员。

### 创建数组

可以使用以下语法创建数组：

```java
arrayRefVar = new dataType[arraySize];
```

此语句将完成两件事：

- 它将使用 `new dataType[arraySize]` 创建一个数组。
- 它将新数组的引用赋值给名为 `arrayRefVar` 的变量。

如果你想一次性声明数组变量、创建数组并把数组引用赋值给变量，可以使用这个：

```java
dataType[] arrayRefVar = new dataType[arraySize];
```

或者你可以这样创建数组：

```java
dataType[] arrayRefVar = {value0, value1, ..., valuek};
```

我们使用索引来访问数组元素。数组索引是从 0 开始的；这意味着第一个索引是 0，第二个是 1，依此类推。一个包含 10 个元素的数组将从 0 运行到 9。

### 处理数组

当你处理数组中的元素时，通常会使用 `for` 循环或 `foreach` 循环。这是因为所有元素都是相同类型，且数组大小是已知的。我们在前一章中讨论过 `foreach` 循环（也称为增强型 for 循环）。

### 将数组传递给方法

与基本数据类型的值传递给方法一样，我们可以将数组传递给方法。它是通过传递数组来调用的。例如，此语句正在调用 `printArray` 方法来显示 4, 2, 3, 7, 1 和 5：

```java
printArray(new int[]{4, 2, 3, 7, 1, 5});
```

### Arrays 类

`Arrays` 类包含几个静态方法，可以对数组进行排序和搜索、比较数组以及填充数组。

每个方法都针对所有基本数据类型进行了重载。

- `public static int binarySearch(Object[] a, Object key)`：使用二分查找算法在给定的对象数组中搜索指定值。在执行之前，必须对数组进行排序。返回值为搜索索引（前提是它在列表中）。如果不在，则返回 `(-(插入点 + 1))`。
- `public static boolean equals(long[] a, long[] a2)`：如果给定的 `long` 类型数组相等，则返回 `true`。如果两个数组具有相同数量的元素，且数组中所有对应的元素对也相等，则认为这两个数组是相等。相同的方法适用于所有基本数据类型。
- `public static void fill(int[] a, int val)`：将给定的 `int` 值赋值给 `int` 数组中的每个元素。这也可以用于所有其他基本数据类型。
- `public static void sort(Object[] a)`：按照元素的自然顺序将给定的对象数组升序。这也可以用于其他基本数据类型。

## 第 13 章：Java 方法

Java 方法是分组在一起的语句集合，用于执行指定的操作。例如，调用 `System.out.println()` 方法将导致系统执行若干语句以在控制台上显示输出。

现在我们将观察如何创建方法（无论有返回值还是没有返回值）、如何调用方法（带参数还是不带参数）以及如何应用方法抽象。

### 创建方法

创建方法的语法为：

```java
public static int methodName(int a, int b) {
    // method体
}
```

让我们看看这每个部分的含义：

- `public static`：这是修饰符
- `int`：这是返回类型
- `methodName`：这是方法名
- `a, b`：这些是形式参数
- `int a, int b`：这是参数列表

根据此语法，方法有一个方法头和方法体：

```java
modifier returnType nameOfMethod (Parameter List) {
    // method body
}
```

此语法显示了：

- `modifier`：用于定义方法的访问类型
- `returnType`：方法可能会返回一个值
- `nameMethod`：方法名
- `parameter list`：参数列表，这些是可选的
- `method body`：方法体

### 调用方法

与基本数据类型的值传递给方法一样，我们可以将数组传递给方法。它是通过传递数组来调用的。例如，此语句正在调用 `printArray` 方法来显示 4, 2, 3, 7, 1 和 5：

```java
printArray(new int[]{4, 2, 3, 7, 1, 5});
```

### 按值传递参数

当我们处理调用过程时，可以传递参数。这些参数的顺序应该与各自的参数相同。参数可以按引用或按值传递。当你按值传递参数时，你正是在调用一个带有参数的方法。

### 方法重载

如果一个类包含多个名称相同但参数不同的方法，我们称为方法重载。这不要与方法重写混淆，后者是两个方法具有相同的名称、参数、类型等。

### 使用命令行参数

你可能有时想在程序运行时向程序传递信息，我们通过向 `main()` 方法传递一些命令行参数来实现。这种类型的参数是在执行程序时在程序名称后面显示的准确信息。在 Java 中访问命令行参数很容易，因为这些参数存储在传递给 `main` 的字符串数组中（以字符串形式存储）。

### Java 构造函数

构造函数用于在创建对象时初始化。它们的名称与类相同，语法与方法相似。然而，构造函数没有显式的返回类型。

无论你是否专门定义，每个类都有构造函数。这是因为 Java 会自动提供默认构造函数来初始化所有成员变量。然而，如果你定义了构造函数，默认的就会被丢弃。

通常，你可能需要至少带一个参数的构造函数，称为参数化构造函数。这些参数添加到构造函数的方式与参数添加到方法的方式相同——只需在构造函数名称后跟的一组括号内声明参数即可。

### 使用 `this` 关键字

`this` 关键字在 Java 中被保留，用于在通过构造函数或实例方法时引用当前类的对象。通过 `this` 关键字，你可以引用类成员，如变量、构造函数和方法。

注意：`this` 关键字**仅**可以在实例方法或构造函数中使用。我们通常使用 `this` 关键字是为了：

- 在方法或构造函数内部，当实例变量与局部变量同同时，区分它们。

```java
class Pupil {
    int age;
    Pupil(int age) {
        this.age = age;
    }
}
```

- 在类内部调用另一个默认构造函数或带参数构造函数。这被称为显式构造函数调用。

```java
class Pupil {
    int age;
    Pupil() {
        this(15);
    }

    Pupil(int age) {
        this.age = age;
    }
}
```

### 可变参数

也称为 var-args，向方法传递可变数量的参数（只要它们的类型都相同）这一功能是在 JDK 1.5 中引入的。我们像这样声明方法参数：

```java
typeName... parameterName
```

在方法声明内部，你必须指定类型并在后跟一组括号。你只能在方法中指定一个可变长度的参数，且该参数必须是最后一个参数。所有普通参数必须先声明。

### 使用 `finalize()` 方法

可以定义在垃圾回收器销毁对象之前调的方法，这被称为 `finalize()` 方法。它被用于确保对象能够正确且干净地终止。例如，你可以使用 `finalize()` 方法来确保对象所拥有的打开文件被正确关闭。

要向你的类中添加终结器（finalizer），你只需定义 `finalize()` 方法，Java 运行时在准备好回收指定类的对象时就会调用该方法。

在 `finalize()` 方法内部，我们指定在对象销毁之前要执行的操作。`finalize()` 方法的一般语法为：

```java
protected void finalize() {
    // 在此处编写 finalize 代码
}
```

注意 `protected` 关键字的使用——这是一个访问修饰符，用于限制对 `finalize()` 方法的访问。

这里，`protected` 关键字是一个指示符，防止定义在对象类之外的代码访问 `finalize()` 方法。这意味着你永远不知道 `finalize()` 方法何时执行，或者是否会执行——例如，如果你的程序在垃圾回收发生之前就结束了，那么 `finalize()` 方法将不会被执行。

## 第 14 章：Java 异常

异常事件，或者用计算机编程术语所说的异常，是在程序执行时出现的问题。每当这些异常之一发生时，正常的程序流就会停止并终止。异常可能由于任何原因发生，包括：

- 用户输入了无效数据
- 找不到所需的文件
- 网络通信失败或 Java 虚拟机内存耗尽

有些是用户错误，另一些是程序员错误，而另一些可能是物理资源故障。这把异常分为三类，为了理解异常处理，你必须理解这些类别：

- **检出异常（Checked Exceptions）**：这种情况发生在编译时，且无法忽略——程序员必须在当时处理它们。

  例如，假设你使用 `FileReader` 类从指定文件读取数据。如果该文件不存在，你将看到 `FileNotFoundException`，并且你必须立即处理它。

- **未检出异常（Unchecked exceptions）**：这种情况发生在执行时（也称为运行时异常）。这些在编译时被忽略。

  例如，如果你在程序中声明了一个大小为 6 的数组，并尝试调用第 7 个元素，你将得到 `ArrayIndexOutOfBoundsException` 异常。

- **错误（Errors）**：这些不是异常；而是程序员或用户无法控制的问题。这些往往会被忽略，因为你通常对它们无能为力。

### 层次结构

每个异常类都是 `java.lang.Exception` 类的子类，而这又是 `Throwable` 类的子类。还有一个还有一个名为 `Error` 的类，它也是 `Throwable` 类的子类。

`Exception` 类有两个主要的子类：`IOException` 和 `RuntimeException`。

### 异常方法

这些是 `Throwable` 类中更重要的方法：

- `public String getMessage()`：返回包含错误详情的消息，在 `Throwable` 的构造函数中初始化
- `public Throwable getCause()`：返回异常原因，由对象表示
- `public String toString()`：返回类名与 `getMessage()` 结果的拼接
- `public void printStackTrace()`：将带有堆栈跟踪的 `toString()` 结果打印到错误输出流
- `public StackTraceElement[] getStackTrace()`：返回包含每个堆栈跟踪元素的数组，索引 0 表示栈顶，最后一个索引表示调用栈的底
- `public Throwable fillInStackTrace()`：用当前跟踪填充 `Throwable` 对象的堆栈跟踪，添加之前的信息

### 捕获异常

使用同时包含 `try` 和 `catch` 关键字的方法来捕获异常。我们在可能抛出异常的代码周围放置一个 `try/catch` 块。这就是受保护的代码。`try/catch` 的语法为：

```java
try {
    // 受保护的代码
} catch(ExceptionName e1) {
    // 捕获块
}
```

每个 `try` 块必须后续 `catch` 或 `finally` 块。`catch` 语句用于声明你想捕获的异常类型。如果指定的异常列在捕获块中，它就像我们传递方法参数一样被传递。

### 多个 catch 块

`try` 块可以由多个 `catch` 块后续。使用多个 `catch` 块的语法为：

```java
try {
    // 受保护的代码
} catch(ExceptionType1 e1) {
    // 捕获块
} catch(ExceptionType2 e2) {
    // 捕获块
} catch(ExceptionType3 e3) {
    // 捕获块
}
```

这里显示了三个块，但只要跟在一个 `try` 块后面，可以使用任意。如果异常发生在保护代码中，它将传递给第一个 `catch` 块；如果异常类型与 `ExceptionType` 匹配，它将被捕获；否则，将传递给下一个 `catch` 块。这将一直持续，直到异常被捕获或所有 `catch` 块执行完毕。在这种情况下，方法将停止执行并将异常抛给调用栈上之前的方法。

### 捕获多种异常类型

Java 现在允许在一个 `catch` 块中捕获多种异常，从而简化你的代码。这是要使用的语法：

```java
catch (IOException|FileNotFoundException ex) {
    logger.log(ex);
    throw ex;
}
```

### throws/throw 关键字



如果一个检出异常没有被方法处理，该方法必须使用 `throws` 关键字来声明它。这出现在方法签的末尾。可以使用 `throw` 关键字抛出异常。理解 `throws` 和 `throw` 关键字非常重要：

- **throws**：推迟检出异常的处理
- **throw**：显式地抛出一个或多个异常

方法可以声明它抛出一个或多个异常；如果声明了多个，这些异常将用逗号分隔列出。

## finally 块

`finally` 块必须紧跟在 `try` 或 `catch` 块之后，无论是否发生异常，它始终会被执行。`finally` 块允许你运行用于清理目的的语句，该语句无论如何都必须执行。`finally` 块使用的语法如下：

```java
try {
  // 受保护的代码
} catch(ExceptionType1 e1) {
  // catch 块
} catch(ExceptionType2 e2) {
  // catch 块
} catch(ExceptionType3 e3) {
  // catch 块
} finally {
  // finally 块始终会执行。
}
```

请注意以下规则：

- 不可以在没有 `try` 语句的情况下使用 `catch` 句。
- 当使用 `try/catch` 块时，`finally` 句不是强制性的。
- 你不能在没有 `catch` 或 `finally` 句的情况下拥有 `try` 块。
- `try`、`catch` 和 `finally` 块之间不能有任何代码。

## 用户自定义异常

用户可以创建自己的 Java 异常。在创建异常类时，请记住这些点：

- 每个异常都必须是父类 `Throwable` 的子类。
- 如果你想要一个由 Handle 或 Declare 规则自动强制的检查异常，则必须扩展 `Exception` 类。
- 如果你想要一个运行时异常，则必须扩展 `RuntimeException`。

要定义异常类，请使用以下语法：

```java

}
```

只需确保在创建异常时扩展了已定义的 `Exception` 类即可。用户自定义异常被归类为检查异常，它们与其他任何类都很相似，都包含了有用的方法和字段。

## 常见异常

## 跳出 switch 语句

如果你忘记从 `switch` 语句中跳出，你的编译器将不会跳过 `switch` 语句继续执行。例如：

```java

switch (verse) {
  case 3:
    out.print("Please remember, ");
    out.println("please remember,");
    break;
  case 2:
    out.print("I am in pain, ");
    out.println("i am in pain,");
    break;
  case 1:
    out.print("I need medicine, ");
    out.println("i need medicine,");
    break;
}
```

```java
    private Color aveOfNeighbors(Color[][] image, int row, int col, int neighborhoodSize) {
        int numNeighbors = 0;
        int red = 0;
        int green = 0;
        int blue = 0;

        for (int r = row - neighborhoodSize; r <= row + neighborhoodSize; r++) {
            for (int c = col - neighborhoodSize; c <= col + neighborhoodSize; c++) {
                if (inBounds(image, r, c)) {
                    numNeighbors++;
                    // 注意：OCR 中的此处逻辑是碎片化的，已重构
                    red += image[r][c].getRed();
                    green += image[r][c].getGreen();
                    blue += image[r][c].getBlue();
                }
            }
        }

        assert numNeighbors > 0;
        return new Color(red, green, blue);
    }

    // 辅助方法，判断给定坐标是否在边界
    private boolean inBounds(Color[][] image, int row, int col) {
        return (row >= 0) && (row < image.length) &&
            (col >= 0) && (col < image[0].length);
    }

    // 确保 mat 是矩形的方法
    private boolean rectangularMatrix(Color[][] mat) {
        boolean isRectangular = true;
        int row = 1;
        final int COLUMNS = mat[0].length;

        while (isRectangular && row < mat.length) {
            isRectangular = (mat[row].length == COLUMNS);
            row++;
        }

        return isRectangular;
    }
```

```java
public class LinkedList implements Iterable {
    private Node head;
    private Node tail;
    private int size;

    public Iterator iterator() {
        return new LLIterator();
    }

    private class LLIterator implements Iterator {
        private Node nextNode;
        private boolean removeOK;
        private int posToRemove;

        private LLIterator() {
            nextNode = head;
            removeOK = false;
            posToRemove = -1;
        }

        public boolean hasNext() {
            return nextNode != null;
        }

        public Object next() {
            assert hasNext();
            Object result = nextNode.getData();
            nextNode = nextNode.getNext();
            removeOK = true;
            posToRemove++;
            return result;
        }

        public void remove() {
            assert removeOK;
            removeOK = false;
            LinkedList.this.remove(posToRemove);
            posToRemove--;
        }

        public void makeEmpty() {
            // 让垃圾回收完成工作吧!!!!!!
            head = tail = null;
            size = 0;
        }

        public Object remove(int pos) {
            assert pos >= 0 && pos < size;
            Object result;
            if (pos == 0) {
                result = head.getData();
                head = head.getNext().Next();
                if (size == 1) {
                    tail = null;
                }
            } else {
                Node temp = head;
                for (int i = 1; i < pos; i++)
                    temp = temp.getNext();
                result = temp.getNext().getData();
                temp.setNext(temp.getNext().getNext());
                if (pos == size - 1)
                    tail = temp;
            }
            size--;
            return result;
        }

        public Object get(int pos) {
            assert pos >= 0 && pos < size;
            // 基于数组的列表
            // 返回 myCon[pos]
            Object result;
            if (pos == size - 1)
                result = tail.getData(); // O(1)
            else {
                Node temp = head;
                for (int i = 0; i < pos; i++)
                    temp = temp.getNext();
                result = temp.getData();
                // 平均情况 O(N) :(((
            }
            return result;
        }

        public void insert(int pos, Object obj) {
            assert pos >= 0 && pos <= size;

            // 头部插入?
            if (pos == 0)
                addFirst(obj); // O(1)
            // 尾部插入?
            else if (pos == size)
                add(obj); // 在末尾 O(1)
            else {
                // 通用情况
                Node temp = head;
                for (int i = 1; i < pos; i++)
                    temp = temp.getNext();
                // 我知道 temp 指向的是
                // 位置 pos - 1 的节点
                Node newNode = new Node(obj, temp.getNext());
                temp.setNext(newNode);
                size++;
            }
        }
    }

    public void add(Object obj) {
        Node newNode = new Node(obj, null);
        if (size == 0)
            head = newNode;
        else
            tail.setNext(newNode);
        tail = newNode;
        size++;
    }
```
