# 第 1 章 – Java 基础

`Java` 是一种具有许多应用的计算平台和编程语言。这种编程和计算软件无处不在。它存在于各种计算机和数据中心，包括简单的笔记本电脑。平板电脑和手机等移动设备都使用 `Java`。互联网也使用 `Java` 进行运行。事实上，`Java` 是几乎每种网络应用程序的核心。

在设备上安装 `Java` 允许用户在互联网上聊天、玩在线游戏和查看 3D 。它是允许计算（如抵押贷款计算和简单算术）的程序中不可或缺的。它还是各种企业计算需求的基础，例如电子商务解决方案和内网应用。

### Java 的起源是什么？

20 世纪 90 年代初，一个由詹姆斯·高斯林（James Gosling）领导的太阳微系统公司团队开发了这种计算机编程语言。最初的设计旨在用于手机、机顶盒和其他数字移动设备。该编程语言最初被命名为 `OAK`。第一个版本未能吸引大量的赞助，这促使公司进行了一些修改。该语言经过了修改以适应互联网，名称也更改为今天所看到的 `Java`。1996 年，`Java 1.0` 向公众发布。这次公开发布将其主要用途从移动设备转移到了蓬勃发展的互联网。

### 谁在使用 Java？

`Java` 也是嵌入式和移动应用开发与交付的全球标准。它也是 Web 内容、企业级和游戏领域的标准。约 97% 的企业在运行 `Java` 的桌面电脑上运营。仅在美国，约有 89% 的计算机或桌面电脑也使用 `Java` 程序运行。

超过 900 万名开发者正在使用 `Java` 进行所有所需的应用程序和服务。在全球范围内，还有惊人的 30 亿部手机也使用 `Java` 作为其核心操作和应用程序。所有的蓝光播放机都配备了 `Java` 程序。约 1.25 亿台电视设备在其基础操作中使用 `Java`。目前有高达 50 亿张 `Java` 卡正在使用。各种电气设备的前 5 大原始制造商都出货 `Java ME`。这些数字显示了 `Java` 的使用多么广泛。

`Java` 为用户提供了更多的交互性。这允许开发者制作动画网页，从而增加了网站对在线用户的吸引力。随着时间的推移，`Java` 演变成了一个全球性的成功。它的使用扩展到了涵盖互联网用途之外的应用程序和服务。即使在向公众发布多年后，`Java` 仍然流行。截至今天，全球约有 65 亿开发者正在使用它，从简单的桌面应用程序到复杂的、敏感的科学超级计算机。

修改包括对 `C++` 编程语言的简化。消除了一些语言特性，减少了许多常见的编程错误。

`Java` 使用源代码文件，即使用 `.java` 扩展名的文件。这些源代码由编译器汇装并分组，然后格式化为字节码。字节码是一个具有 `.class` 扩展的文件，由 `Java` 解释器执行。所有编译的 `Java` 代码都可以由于 `VMs`（或 `Java 虚拟机`）而运行在任何计算机上。这些是存在 Windows、Macintosh OS 和 UNIX 等大多数操作系统中的运行时环境和 `Java` 解释器。字节码可以由 `JIT`（即时编译器）直接转换为机器语言指令。

### 使用 Java 的核心原则

`Java` 的设计包含了 4 个核心原则，即易用性、可靠性、安全性和平台无关。

#### 易用性

`Java` 的基础源于 `C++`，这是一种强大的编程语言。然而，它的语法被认为非常复杂。`Java` 构建在 `C++` 语言之上并对其改进。结果是一个既强大又简单的编程平台。

#### 可靠性

`Java` 开发的主要原则之一是减少产生常见编程错误的可能性，这些错误可能会严重阻碍程序高效运行。为了消除常见的编程错误，`Java` 引入了一种面向对象的编程方法。数据及其操作方法被方便地封装在一个地方。这种技术使 `Java` 编程变得更加健壮和可靠。

#### 安全性

如前所述，`Java` 最初是为预期在各种网络上交换数据的移动设备开发的。这一功能需要高水平的安全措施，而 `Java` 能够提供这些措施。到目前，`Java` 被高度认为是所有可用编程语言中最安全的。

#### 平台无关

`Java` 是一种可移植的语言。它不区分各种平台。这意味着无论存在什么种类型的硬件或什么种操作系统，它都能运行得完美且保持一致。

# 第 2 章 – Java 语言基础

在开始使用 Java 之前，你应该先学习这门语言。这项基础技能将极大地帮助你充分利用软件。它也能让通信变得简单得多。作为一种编程语言，Java 语言主要关于字符串。它包含变量、对象、参数、表达式、控制流语句和块。理解这些元素就像学习一种外语言，以便更好地与当地人交流。

这种语言允许程序员和开发者编写基于英语的命令作为计算机指令。Java 不需要他们像其他计算机编程语言那样使用数字代码。这被认为是一种“高级”语言，因为它允许人类易地读写这种语言。程序指令是根据称为语法（syntax）的规则编写的，就像适用于人类语言的语法规则一样基本上，人类开发者或程序员使用英语输入指令，一旦完成，计算机会将这些指令翻译成计算机容易理解和执行的代码。在大多数其他计算机语言中，开发者或程序员必须在计算机理解指令之前自己完成翻译。

学习 Java 语言对日后创建程序将极有帮助。

Java 使用的是静态类型编程语言。变量在使用之前必须先声明。要做到这一点，必须说明变量名和类型，例如例所示：

```java
int gear = 1;
```

该语句通知程序存在一个名为 `gear` 的字段，其功能是存储数值类型的数据，初始值为 1。

变量中声明的数据类型非常重要，因为它决定了该字段可以包含什么值，以及可以对其执行哪些操作。

## 注释

这些是添加到程序中的描述，为了便于理解代码。编译器会自动忽略这些注释。它们不会准确影响程序的输出。注释主要用作程序文档的一部分，让想要阅读程序的人更容易。

在 Java 中，有 3 种支持的注释样式。这些是块样式、行样式和文档样式。

块样式以 `/*` 开头，以 `*/` 结束。这些注释跨多行。

行样式以 `//` 开头，并在行结束处自然结束。

文档样式以 `/**` 开头，以 `*/` 结束。这些注释也跨多行。文档样式注释通常是使用自动文档生成工具创建。这种工具的一个示例是 `javadoc`。

## 原生数据

原生数据是由程序语言预定义的一种数据类型。这种数据类型由关键字保留名称。这些值与其他值不共享状态。

Java 支持 8 种不同的原生数据类型：

### byte

`byte` 是 8 位带符号补码整数。最小值为 -128，最大值为 127。这种数据类型在保存大数组中的节省内存时非常有用，在这些情况下，节省内存空间至关重要。`byte` 数据类型也可以替代 `int`。`byte` 提供的限制有助于进一步明确代码。取值范围也作为文档的手段。

### short

这种数据是 16 位带符号补码整数。最小值是 -32,768，最大值是 32,767。`short` 数据类型可以与大数组一起使用以节省更多内存。

### int

`int` 是 32 位带符号补码整数。最小值是 -2³¹，最大值是 2³¹-1。这种数据类型在 Java SE 8 及更高版本中被用作从 0 到 2³¹-1 的无符号 32 位整数的手段。

`int` 数据类型可以作为无符号整数使用。为了这样做，必须使用变量的 `Integer` 类。整数类整合了 `compareUnsigned` 和 `divideUnsigned` 等方法，以支持涉及无符号整数的算术操作。

### long

这种数据是 64 位补码整数。带符号 `long` 数据的最小值为 -2⁶³，最大值为 2⁶³-1。对于 Java SE 8 及更高版本，`long` 数据类型可以用于表示无符号 64 位长型。它们的最小值为 0，最大值为 2⁶⁴-1。当需要比数据类型 `int` 提供的更宽的值范围时使用这些。

### float

这种数据是单精度 32 位 IEEE 754 浮点数。`float` 经常用于替代 `double` 以节省某些内存。

### double

这种数据类型是 64 位双精度 IEEE 754 浮点数。`double` 在处理浮点数值时是默认选择。

### boolean

`boolean` 数据类型只有 2 个可能的值：`true` 和 `false`。`boolean` 用于创建简单的布尔标志。这种数据类型对应 1 位信息。

### char

`char` 是单个 16 位 Unicode 字符。最小值为 0 或 `\u0000`，最大值为 65535 或 `\uffff`。

## 默认值

声明字段并不总是赋值。编译器会自动为声明但未初始化的字段设置合理的默认值。通常，默认值为 0 或 null，这取决于数据类型。虽然可以这样做，但依赖默认值被广泛认为是不好的编程风格。

原生类型字段的默认值为：

- `byte`: 0
- `int`: 0
- `short`: 0
- `long`: 0l
- `double`: 0.0d
- `float`: 0.0f
- `string`: null
- `char`: `\u0000`
- `boolean`: false

尽管局部变量略有不同。对于局部变量，编译器从不会分配默认值。如果局部变量在声明处无法初始化，请确保在使用之前为其赋值。否则，在访问未初始化的局部变量时会出现编译错误。

对于 `int`、`long`、`short` 和 `byte` 等整数类型数据，可以使用 `int` 字面量创建值。对于超出 `int` 范围的 `long` 类型值，可以使用 `long` 字面量代替。

整数字面量以多种数字系统表示，例如：

- 十进制：这种数字系统是我们在编程之外的现实生活中每天都在使用的系统。数字为 10 进制，由数字 `0` 到 `9` 的数字组成。
- 十六进制：这种数字系统使用字母和数字。使用 16 进制，数字由字母 `A` 到 `Z` 和数字 `0` 到 `9` 的组合组成。
- 二进制：这种数字系统是 2 进制。数字是数字 `0` 和 `1` 的各种组合。在 Java SE 7 及更高版本中可以创建二进制字面量。

在进行通用编程时使用十进制。以下是使用这些任一种数字系统时如何使用正确语法的示例。对于十六进制，使用前缀 `0x`。对于二进制，使用前缀 `0b`。

```java
// 十进制的数字 35
int decVal = 35;

// 十六进制的数字 26
int hexVal = 0x1a;

// 二进制的数字 26
int binVal = 0b11010;
```

### 浮点字面量

如果字面量以 `F` 或 `f` 结尾，则是 `float` 类型。如果不是，则被视为 `double` 数据类型，可选结尾为 `D` 或 `d`。对于两种浮点类型（`double` 和 `float`），科学计数法用字母 `E` 或 `e` 表示。对于 32 位 float 字面量，使用字母 `F` 或 `f`。64 位 double 字面量使用 `D` 或 `d`，尽管这已经是默认值且按照习惯被省略了。

例如：

```java
double d1 = 456.4;

// 与 d1 相同的值，但使用科学计数法
double d2 = 4.564e2;

float f1 = 456.4f;
```

### 字符和字符串字面量

字符串和 `char` 类型的字面量通常包含 Unicode 字符（UTF-16）。如果文件系统和编辑器允许，这些字符可以直接在代码中使用。否则，可以使用 Unicode 转义，例如 `\u0108`（用于带有密音符号的大写 C）或 `S\u00ED Se\u00Flor`（用于西班牙语的 Si Señor）。对于 `char` 字面量，使用单引号（`'`）。对于字符串字面量，使用双引号（`"`）。程序中字符串或 char 字面量之外也会使用 Unicode 转义，例如在字段名中。

Java 语言还支持字符串和 char 字面量的其他特殊转义序列。这些是：

- 退格 `\b`
- 制表符 `\t`
- 换行符 `\n`
- 换符 `\f`
- 回车符 `\r`
- 双引号 `\"`
- 单引号 `\'`
- 反斜杠 `\\`

特殊的字面量 `null` 可作为任何引用类型的值。`null` 字面量可以赋值给任何类型的变量，但基本数据类型除外。除了测试其是否存在外，对 `null` 字面量可以的操作很少。大多数情况下，程序使用 `null` 作为指示某些对象不可用的标记。

类字面量是另一种特殊的字面量类型。它通过使用类型并在末尾附加 `.class` 来形成。例如，`String.class`，引用表示类型的对象。

### 数值字面量中的下划线字符

Java SE 7 及更高版本中出现了几个下划线字符（`_`）。这些字符出现在组成数值字面量的数字之间。这是一个提高代码可读性的功能。它通过将数字组隔成特定的数值字面量来实现。一个示例是将数字分组成每组 3 个数字，就像人们在日常使用长串数字时会使用逗号或空格一样。

看这个示例：

```java
float pi = 3.14_15F;

long socialSecurityNumber = 998_89_9799L;

long creditCardNumber = 1734_5978_9812_3256L;

long hexBytes = 0xFF_BC_DE_5F;

long maxLong = 0x7fff_ffff_ffff_ffffL;

long hexWords = 0xCAFE_BABE;

long bytes = 0b10010100_00101101_10110110_11010100;

byte nybbles = 0b0110_0111;
```

下划线只能放在数字之间。它不能放在以下位置：

- 数字的开头或结尾
- 浮点字面量中小数点旁边
- `L` 或 `F` 后缀之前
- 应该放置数字字符串的位置

以下示例显示了下划线的有效和无效放置：



```java
// 无效：不能在小数点旁边
// 放置下划线
float pi1 = 3_.1415F;
float pi2 = 3._1415F;

// 无效：不能在后缀 L 之前
// 放置下划线
long socialSecurityNumber1 = 919_97_9599_L;

// 有效（十进制字面量）
int x1 = 5_4;

// 无效：不能在字面量的最后部分
// 放置下划线
int x2 = 54_;

// 有效（十进制字面量）
int x3 = 5_4;
```

## 声明对象 (Declaring Objects)

声明包括带有对象类型的变量名进行变量声明。`type name;` 编写的代码集是将变量名与对象类型关联的变量声明。

在声明变量时，写为：

`type name;`

此声明告诉编译器 `name` 将被用于引用数据类型 `type`。如果使用原始变量，这种声明会为特定变量预留正确的内存。

引用变量可以单独另一行声明，例如所示：

`Point sourceOne;`

在此声明中，在创建对象并将其赋值之前，`sourceOne` 将具有不确定的值。引用变量的简单声明不会自动从中创建对象。要从引用变量创建对象，必须使用运算符 `new`。此外，在代码中使用之前，必须将对象赋值给 `sourceOne`。否则将发生编译器错误。

在此状态下，声明的变量没有引用任何对象。

## 实例化对象 (Instantiating objects)

实例化基本上就是创建对象。这是因为这一基本上是从类创建一个实例，并从实例创建对象。在创建对象的这一使用了关键字 `new`。它通过为新对象分配内存空间来实例化类，并返回该特定内存的引用。`new` 还会调用对象的构造函数并使其工作。

在使用 `new` 运算符时，参数应该是单个后缀，这是对构造函数的调用或信号。构造函数的名称即为将被实例化的类名。

然后，`new` 运算符将返回创建对象的引用。该引用通常被赋值给相应的变量类型。例如：

`Point sourceOne = new Point(56, 87);`

运算符返回的引用并不总是赋值给变量。它也可以直接在表达式中使用，如本例所示：

`int length1 = new Triangle().length1;`

## 初始化对象 (Initializing Objects)

调用构造函数位于关键字 `new` 之后。该调用是必要的，以便初始化对象。来看这个示例，使用了 `Point` 类：

```java

    public int a = 0;
    public int d = 0;
    //构造函数
    public Point(int x, int z) {
        a = x;
        d = z;
    }
}
```

`Point` 类只有 1 个构造函数，这是因为它的名称与声明时的类名相同。它也没有返回类型。在此类中，构造函数接受 2 个 `int` 参数，通过代码 `(int x, int z)` 声明。

在随后的语句中，提供了构造函数参数的值：

`Point sourceOne = new Point(56, 87);`

考虑以下关于 `Rectangle1` 类的代码，它包含了 4 个构造函数：

```java

    public int height1 = 0;

    // 四个构造函数
    public Rectangle1() {
        origin = new Point(0, 0);
    }

    public Rectangle1(Point a) {
        origin = a;
    }

    public Rectangle1(int w, int h) {

        origin.z = z;

}
```

每个构造函数都允许通过引用和原始类型为矩形的 `origin` 以及高度和宽度提供初始值。如果一个类有多个构造函数，则需要不同的签名。通过这样，Java 编译器能够根据参数的类型和数量来区分构造函数。因此，当编译器遇到此代码时：

`Rectangle1 rectOne = new Rectangle(originOne, 150, 250);`

调用了位于 `Rectangle` 类中的构造函数，它需要 `Point` 参数，随后是 2 个 `int` 参数。

此代码调用了用于将 `origin` 初始化为 `originOne` 的构造函数之一。该构造函数将高度设置为 250，宽度设置为 150。

## 垃圾回收

其他面向对象的语言需要对创建的进行进行定期跟踪。用户必须一个一个地检查对象，并费力地删除每个不再使用的对象。这花费了大量时间和精力。这种方法还存在巨大的风险，可能会意外删除未来可能需要的或当前程序仍在使用的对象。在 Java 中，删除对象变得简单得多且不容易发生删除错误。Java 允许用户创建大量对象，只要系统能够处理所有数据并为所有内容提供足够的内存空间。好处在于，无需担心通过删除未使用的对象来清理各种程序。不需要翻阅长长的对象列表以寻找本应该被删除的对象。Java 提供了一个名为垃圾回收器的整洁过程。Java 编程语言实现的运行时环境会检测并自动删除任何不再使用的对象。

垃圾回收器只删除不再具有任何引用的对象。当变量超出范围时，该特定变量持有的引用将丢失。一旦引用丢失，垃圾回收器就会自动删除它。

要诱导垃圾回收器删除对象，用户需要显式地丢弃对该对象的引用。要这样做，可以访问变量并将其赋值为 `null`，这是一个特殊值。一旦赋值为 `null` 值，引用就会被删除，垃圾回收器就会删除该对象。此外，重要的是，要让对象被成功删除，其所有现有的引用都必须被删除。否则，程序将继续持有该对象并保持可用。

# 第 4 章 – Java 语言：变量

Java 编程使用变量。这些是可以通过程序操纵的命名存储空间。这些变量具有以下参数决定的特定类型：

* 变量占据的内存大小
* 变量占据的内存布局
* 变量内存空间可以容纳的值范围
* 变量允许的操作操作集

## 变量类型

### 实例变量

这些也被称为“非静态字段”。对象的个体状态存储在非静态字段中。这些是未用 `static` 关键字定义的字段。它们也被称为实例变量，因为对于每个实例或每个对象，其值是唯一的。

实例变量用于存储对象的状态。从类创建的每个对象都有该变量的副本。只要相应的对象保留在内存中，该副本就是有效的并占据分配的存储空间。

### 参数（Arguments or Parameters）

这种类型的变量是传递到方法签名中的变量，例如 `parameter`。另一个例子是之前示例中使用的 `args`。这些与 `static`、`protected` 或 `public` 等修饰符没有关联。然而，它们可以在方法的其他任何地方使用。它们在方法执行期间保留在内存中。当再次使用该方法时，这些变量将无法再次被使用。

### 局部变量

局部变量是定义并用于特定方法的变量。函数位于方法级的作用域内，但它们对方法签名起不起太大作用。局部变量不包含任何修饰符。此外，这些变量在方法返回时就会不再存在。

### 类变量

也称为静态字段（static fields），类变量是指任何由 `static` 修饰符定义的字段。它告诉编译器，无论类被引用或表示多少次，该特定变量都只有 1 个副本。

类变量是在类级别通过静态修饰符明确定义的变量。这种特定的静态修饰符不应与任何其他变量一起使用。附加的静态修饰符将为每个变量产生单个副本。

## 声明变量

在使用任何变量之前，必须先对其声明。基本的变量声明格式如下：

`数据类型 变量 [ = 值][, 变量 [=值] …];`

数据类型部分指 Java 中任何不同的数据类型，例如 `int`。变量部分是指给该特定变量的名称。在声明时，可以使用逗号来分隔属于相同数据类型的多个变量。

有效的变量声明格式如下：

```java
int d, e, f; // 当声明 d、e 和 f 这三个变量时，它们都是同一种数据类型 int
int g = 10, h = 10; // 初始化的一种示例形式
byte E = 76; // 初始化变量 E，它是一个字节类型
double pi = 3.14159; // 声明并分配 pi 的值
char j = ‘j’; // char 变量 j 以‘j’ 为值初始化
```

### 局部变量

局部变量的作用是方法临时状态的存储，就像字段存储对象状态的作用一样。声明局部变量与声明字段相同。看这个示例：

```java
int count = 5;
```

不需要关键字即可将任何变量声明为局部。完全取决于变量声明的位置。它位于方法的左括号和右括号之间，存储其临时状态。由于这种，局部变量对声明它们的方法可见。然而，它们与类的其他部分相比是不可见的。

在声明局部变量时，使用了块、构造函数和方法。这些没有默认值，因此应该进行赋值。在使用它们之前必须分配初始值。要创建局部变量，进入特定的块、方法或构造函数。一旦变量离开块、构造函数或方法，就会被销毁。

对于局部变量，不能使用修饰符。它们在声明它们的块、方法或构造函数内部可见。为了实现这些声明的局部变量，它们在内部的栈级别实现。

看这个示例：

局部变量是 age，定义在 `catArea()` 方法内部。该声明变量的作用范围仅在该特定方法内。

```java
public class Test{

        age = age + 9;
        System.out.println("Cat age is : " + age);
    }
    public static void main(String args[]){
        Test test = new Test();
        test.catArea();
    }
}
```

此的结果是：

Cat age is: 9

实例变量在创建对象时通过 `new` 关键字进行构造。销毁该对象也会销毁实例变量。实例变量所持有的值必须通过多于 1 个方法、块或构造函数进行引用。否则，对象状态的关键部分必须在整个类中包含。

这些变量在类中声明。然而，声明这些变量时应该在块、构造函数或方法之外。当堆中的对象被分配了特定空间时，会为每个实例变量创建一个空位。

实例变量的声明应该在类级别完成，在类它之前或之后。一旦声明，这些变量就对类中的所有块、构造函数或方法可见了。通常建议将这些实例变量在访问级别内保持为私有（private）。可以为实例变量添加访问修饰符。这样做将允许子类具有其可见性。

实例变量有默认值可用。数字的默认值为 `0`。布尔值的默认值是 `false`。对象引用的默认值为 `null`。赋值可以在变量声明期间或在构造函数内部完成。

要访问实例变量，请在类内部直接调用该变量名。在不同的类和静态方法中访问实例变量时，使用完全限定名 `ObjectReference VariableName`。

## 类/静态变量

类变量或静态变量在类中使用 `static` 关键字声明。然而，这是在块、方法或构造函数之外的。无论从它产生多少个对象，声明都会为每个类只创建一个类变量副本。

然而，这种类型的变量很少使用，除非被声明为常量。常量变量被声明为 `private/public`、`static` 和 `final`。它们永远不会改变初始值，且存储在静态内存中。这些变量在程序启动时创建。一旦程序停止，静态变量就会被销毁。可见性与实例变量相似，虽然大多数静态变量被声明为公共（public），因为它们必须对类用户可用。

## 变量命名

每种编程语言在命名时都遵循不同的惯例和规则。在 Java 中，也有需要遵守的事项：

*   变量名是区分大小写的。名称可以是合法的标识符，由数字和 Unicode 字母组成的无限长度序列。名称应该始终以字母、下划线字符或美元符号（`$`）开头。然而，惯例是以字母开始变量名。根据惯例，美元符号从不用于任何变量名的开头。然而，自动生成的名称有时会以“$”开头，但强烈建议程序员不要这样做。下划线也是如此。这在技术上是合法的，但在实际编程中不是一个值得遵循的做法。也不允许以空格开始变量名。
*   随后的字符可以包括美元符号、下划线、数字和字母。惯例在变量名的这部分仍然适用。命名变量时使用完整的单词，而不是晦涩的词。这将使事情变得简单得多，因为代码将更容易阅读并理解其用途。
*   当变量名是单个单词时，使用全小写。如果变量名是多个单词，请将每个单词的首字母大写。例如 `gradeAverage`、`gearParts` 和 `concentrationRatios`。如果变量用于存储常量值，这种惯例可能稍微修改。例如，静态变量 `int AMT_TUBES = 85`。名称全大写，单词之间用下划线分隔。根据惯例，下划线从不出现在其他地方。

# 第 5 章 Java 语言：运算符

在 Java 编程中，运算符是一组特殊符号。它们的功能是对 1、2 或 3 个操作数执行精确操作并提供结果。它们用于创建表达式，表达式进而计算值。

## 运算符的类型

Java 中基本上有 6 种类型的运算符。

## 算术运算符

这些用于数学表达式的运算符，类似于普通代数。

例如，整数变量 `X` 存储 15，变量 `Y` 存储 25。以下是使用不同的算术运算符在这两个整数变量上将获得的结果示例。

*   `+` 加法：该运算符相加两侧的值 `X + Y` 得到 `40`。
*   `-` 减法：该运算符从左侧减去右侧的操作数 `X - Y` 得到 `-10`。
*   `*` 乘法：该运算符乘以两侧的值 `X * Y` 得到 `375`。
*   `/` 除法：该运算符将左侧的操作数除以右侧的操作数 `X / Y` 得到 `1.67`。
*   `%` 取模：该运算符将左侧的操作数除以右侧的操作数并返回余数。它也被称为余数运算符。`X % Y` 得到 `0.67`。
*   `++` 递增：该运算符将操作数的值增加 1。
    *   `Y++` 产生 26
    *   `X++` 产生 16
*   `--` 递减：将操作数的值减 1
    *   `Y--` 产生 24
    *   `X--` 产生 14

## 关系运算符

这些运算符显示了操作数之间的关系。

假设整数值 `X` 值为 20，整数值 `Y` 值为 40。

*   `==` 测试两个操作数所持的值是否相等。如果两个操作数相等，则条件返回“true”。
    *   `(X == Y)` 为假。
*   `!=` 测试两个操作数所持的值是否相等。如果两个操作数的值不相等，则结果为真。
    *   `(X != Y)` 为真。
*   `>` 测试左操作数的值是否大于右操作数的值。如果左侧大于右侧，则条件变为真。
    *   `(X > Y)` 为假。
*   `<` 测试左操作数的值是否小于右侧操作数的值。如果是这种情况，则该条件被认为是真。
    *   `(X < Y)` 为真。
*   `>=` 测试左操作数的值是否大于或等于右操作数的值。如果是这种情况，则该条件变为真。
    *   `(X >= Y)` 为假。
*   `<=` 测试左操作数的值是否小于或等于右操作数的值。如果是这种情况，则该条件变为真。
    *   `(X <= Y)` 为真。

## 位运算符

Java 支持几种位运算符。这些运算符可以应用于如 `byte`、`long`、`char`、`int` 和 `short` 等整数类型。

如名所示，这些运算符对位进行操作，执行的操作是逐位进行的。

例如，`m = 60` 且 `p = 13`。在二进制格式下，`m = 0011 1100`，`p = 0000 1101`。

```
m & p = 0000 1100
m | p = 0011 1101
m ^ p = 0011 0001
~m = 1100 0011
```

根据这些值，以下内容说明了应用不同的位运算符时会发生什么。

*   `&` 二进制与运算符：如果某位在两个操作数都存在，则将其复制到结果中。
    *   `(m & p)` 产生 12，二进制为 `1100`。
*   `|` 二进制或运算符：如果某位在两个操作数之一中存在，则复制该位。
    *   `(m | p)` 产生 61，二进制为 `0011 1101`。
*   `^` 二进制异或运算符：如果某位在两个操作数之一中设置为 1 但并非都设置，则复制该位。
    *   `(m ^ p)` 产生 49，二进制为 `0011 0001`。
*   `~` 二进制取反运算符：这是一个单元运算符。它的作用是“翻转”位。
    *   `(~m)` 产生 -61，在二进制形式下，在补码形式下为 `1100 0011`。这是因为单元数是有符号的。
*   `<<` 二进制左移运算符：根据右操作数指定的位数移动左操作数的值。
    *   `m << 2` 产生 240，二进制形式为 `1111 0000`。
*   `>>` 二进制右移运算符：根据右操作数指定的位数将左操作数的值右移。
    *   `m >> 2` 产生 15，二进制形式为 `1111`。
*   `>>>` 右移零填充运算符：根据右操作数的位数将左操作数的值右移。移出的值用零填充。
    *   `m >>> 2` 产生 15，二进制形式为 `0000 1111`。

## 逻辑运算符

为了说明逻辑运算符的功能以及如何工作，请考虑以下示例：

布尔变量 `x` 持有真值，布尔变量 `y` 持有假值。

*   `&&` 逻辑与运算符：通过测试两侧的操作数是否为非零来工作。如果是，条件变为真。
    *   `(x && y)` 为假。
*   `||` 逻辑或运算符：检查两个操作数是否任何一个是非零。如果是，条件为真。
    *   `(x || y)` 为真。
*   `!` 逻辑非运算符：该运算符用于反转操作数的逻辑状态。也就是说，如果条件为真，逻辑非运算符使其为假。
    *   `!(x && y)` 为真。

## 赋值运算符

这些与代数中使用的非常相似。这些也是最常用的运算符。

*   `=` 简单赋值运算符：该运算符将右侧操作数的值赋值给左侧。
    *   `Z = X + Y`，其中，`X + Y` 的值被赋值为 `Z` 的值。
*   `+=` 加并赋值运算符：该运算符将左右操作数相加，然后将结果赋值给左操作数。
    *   `Z += X` 变为 `Z = Z + X`。
*   `-=` 减并赋值运算符：当满足时，从左操作数中减去右操作数。
    *   `Z -= X` 变为 `Z = Z - X`。
*   `*=` 乘并赋值运算符：当满足时，将左右操作数相乘，并将结果赋值给左操作数。
    *   `Z *= X` 变为 `Z = Z * X`。
*   `/=` 除并赋值运算符：当满足时，将左操作数除以右操作数，并将结果赋值给左操作数。
    *   `Z /= X` 变为 `Z = Z / X`。
*   `%=` 取模赋值运算符：当满足时，将左操作数对右操作数取模，并将结果赋值给左操作数。
    *   `Z %= X` 变为 `Z = Z % X`。
*   `<<=` 左移赋值运算符：根据右操作数指定的位数将左操作数左移。
    *   `Z <<= X` 变为 `Z = Z << X`。
*   `>>=` 右移赋值运算符：根据右操作数指定的位数将左操作数右移。
    *   `Z >>= X` 变为 `Z = Z >> X`。
*   `>>>=` 右移零填充赋值运算符：根据右操作数的位数将左操作数右移并补零。
    *   `Z >>>= X` 变为 `Z = Z >>> X`。
*   `&=` 位与赋值运算符：当满足时，对左右操作数进行位与运算，并将结果赋值给左操作数。
    *   `Z &= X` 变为 `Z = Z & X`。
*   `|=` 位或赋值运算符：当满足时，对左右操作数进行位或运算，并将结果赋值给左操作数。
    *   `Z |= X` 变为 `Z = Z | X`。
*   `^=` 位异或赋值运算符：当满足时，对左右操作数进行位异或运算，并将结果赋值给左操作数。
    *   `Z ^= X` 变为 `Z = Z ^ X`。

## 杂项运算符

除了主要运算符，Java 还支持其他几种类型：

### 条件运算符 `?:`

该运算符被称为三元运算符。它由三个操作数组成。用于决策。格式如下：

`变量 = (条件) ? 值如果真 : 值如果假`

考虑以下：

```java
public class Test {
    public static void main(String args[]){
        int x, y;
        x = 10;
        y = (x == 1) ? 20 : 30;
        System.out.println("Value of y is " + y);
    }
}
```

### `instanceof` 运算符

`instanceof` 运算符仅用于引用变量。它检查对象的特定类型，是接口还是类。格式如下：

`(引用变量) instanceof (类类型)`

如果运算符左侧的对象通过了右侧类型的检查（IS-A），结果为真。例如：

```java
public class Test {
    public static void main(String args[]){
        String name = "Andrea";
        boolean result = name instanceof String;
        System.out.println(result);
    }
}
```

结果将为真。

即使对象匹配运算符右侧的类型，结果仍然返回真。另一个例子：

```java
class Clothes {}
public class Dress extends Clothes {
    public static void main(String args[]){
        Clothes a = new Dress();
        boolean result = a instanceof Dress;
        System.out.println(result);
    }
}
```

结果将为真。

## 运算符优先级

Java 中的不同运算符具有不同的优先级。高优先级运算符先于优先级相对较低的运算符执行。出现在同一行的相等运算符被认为具有相同的优先级。对于所有二元运算符，评估从左到右进行。对于赋值运算符，评估从右到左进行。

以下是从高优先级到最低优先级的运算符列表：

| 运算符 | 优先级 |
| :--- | :--- |
| 后置 `expr++`, `expr--` | 最高 |
| 单元 `++expr`, `--expr`, `+expr`, `-expr`, `~`, `!` | |
| 乘法 `*`, `/`, `%` | |
| 加法 `+`, `-` | |
| 移位 `<<`, `>>`, `>>>` | |
| 关系 `<`, `>`, `<=`, `>=`, `instanceof` | |
| 相等 `==`, `!=` | |
| 按位与 `&` | |
| 按位异或 `^` | |
| 按位或 `|` | |
| 逻辑与 `&&` | |
| 逻辑或 `||` | |
| 三元运算符 `? :` | |
| 赋值运算符 `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `^=`, `|=`, `<<=`, `>>=`, `>>>=` | 最低 |

## 算术运算符示例

考虑以下关于如何执行算术运算符的示例。

```java
class BasicMathDemo {
    public static void main (String[] args) {
        int result = 5 + 1;
        // result is now 6
        System.out.println("5 + 1 = " + result);
        int original_result = result;
        result = result - 3;
        // result is now 3
        System.out.println(original_result + " - 3 = " + result);
        original_result = result;
        result = result * 4;
        // result is now 12
        System.out.println(original_result + " * 4 = " + result);
        original_result = result;
        result = result / 2;
        // result is now 6
        System.out.println(original_result + " / 2 = " + result);
        original_result = result;
        result = result + 5;
        // result is now 11
        System.out.println(original_result + " + 5 = " + result);
        original_result = result;
        result = result % 3;
        // result is now 2
        System.out.println(original_result + " % 3 = " + result);
    }
}
```

在上述程序完成后，打印的结果将为：

```
5 + 1 = 6
6 - 3 = 3
3 * 4 = 12
12 / 2 = 6
6 + 5 = 11
11 % 3 = 2
```

包含简单赋值运算符的算术运算符可以组合创建复合赋值。一个例子是 `x += 5;` 和 `x = x + 5;`。两者将 `x` 的值增加 5。

## 元运算符

这种运算符使用单个操作数。它用于各种功能，例如表达式取反、布尔值反转或将值加减 1。

- `+` 一元加运算符：用于表示正值。
- `-` 一元减运算符：用于对表达式取反。
- `++` 递增运算符：使值增加 1。
- `--` 递减运算符：使值减少 1。
- `!` 逻辑取反运算符：用于反转布尔值。

考虑以下测试元运算符的示例：

```java
class UnaryDemo {
    public static void main(String[] args) {
        int result = +2;
        // result is now 2
        System.out.println(result);
        result--;
        // result is now 1
        System.out.println(result);
        result++;
        // result is now 2
        System.out.println(result);
        result = -result;
        // result is now -2
        System.out.println(result);
        boolean success = false;
        // false
        System.out.println(success);
        // true
        System.out.println(!success);
    }
}
```

递减/递增运算符可以作为操作数的前缀（之前）或后缀（之后）。代码 `++result;`（前缀）和 `result++;`（后缀）都会产生增加 1 的结果。区别在于评估的是哪个值。前缀 `(++result)` 根据增加后的值进行评估。后缀 `result++` 根据原始值进行评估。如果程序执行递增/递减，两种版本均可行。然而，较大的表达式需要更具体的选择，因为不同的结果会给最终结果产生显著差异。

考虑以下示例：

```java
class PrePostDemo {
    public static void main(String[] args){
        int g = 1;
        g++;
        // prints 2
        System.out.println(g);
        ++g;
        // prints 3
        System.out.println(g);
        // prints 4
        System.out.println(++g);
        // prints 4
        System.out.println(g++);
        // prints 5
        System.out.println(g);
    }
}
```
