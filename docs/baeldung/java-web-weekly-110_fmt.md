## 3. 沉思

#### [>> 我们不是野兽，所以我们不要表现得像它一样](https://web.archive.org/web/20220810163353/http://www.daedtech.com/were-not-beasts-so-lets-not-act-like-it/)【daedtech.com】

做员工和做顾问是两码事。不仅在财务和组织上不同，而且在根本层面上，这与心态有很大关系。

这篇文章以一种实用而有趣的方式探索了这种差异——如果你避开了员工和顾问之间的界限（或者在思考这个问题），那么一定要读一读。

#### [>> `P1` 的暴政](https://web.archive.org/web/20220810163353/http://dandreamsofcoding.com/2016/02/01/the-tyranny-of-the-p1/)【dandreamsofcoding.com】

丹正在从艾米·霍伊的剧本中吸取经验，回归产品基础。

当然，问题是这些并不是内置到产品中的有趣特性，远离它们需要太多的训练。

#### [>> 无限 PTO 对我来说划算吗？](https://web.archive.org/web/20220810163353/http://www.daedtech.com/is-unlimited-pto-a-good-deal-for-me/)【daedtech.com】

我第一次读到无限假期的概念时，我对这个想法兴奋了大约五分钟，然后开始理解其实际含义的细微差别和含义。

这篇文章以清晰而深刻的方式探索了这些细微差别。

#### [>> 软件工程师在工作场所维护优势的指南](https://web.archive.org/web/20220810163353/https://medium.com/hacker-daily/the-software-engineer-s-guide-to-asserting-office-dominance-ddea7b598df7#.kbuxq6ouz)【medium.com】
