## 1. Spring 和 Java

### [新手使用 JPA / Hibernate / EclipseLink 之前需要知道的 5 件事](https://web.archive.org/web/20220628053112/https://www.thoughts-on-java.org/5-things-beginners-need-to-know-before-using-jpa-hibernate-eclipselink/)（thoughts-on-java.org）

对于考虑实现 JPA 解决方案的开发人员来说，这是一本很好的入门书。

### [功能 Bean 注册在 Spring Cloud 功能](https://web.archive.org/web/20220628053112/https://spring.io/blog/2018/10/22/functional-bean-registrations-in-spring-cloud-function)（Spring.io）

快速浏览 Spring Cloud 2.0 带来的几项改进，包括**更快的启动和“全功能”**的能力。而且，因为它构建在 Spring Boot 之上，所以不再需要 servlet 容器。

### [Java 中的被动 HTTP/2 请求和响应 11](https://web.archive.org/web/20220628053112/https://blog.codefx.org/java/reactive-http-2-requests-responses/)（blog.codefx.org）

**基于 Java 9 中引入的 Flow API，现在可以通过 HTTP/2 使用反应流来**实现异步的发布-订阅应用程序。

### [如何用 JPA 和 Hibernate 映射 `java.time.Year` 和 `java.time.Month`](https://web.archive.org/web/20220628053112/https://vladmihalcea.com/java-time-year-month-jpa-hibernate/)（vladmihalcea.com）

也是上周关于映射 `YearMonth` 类型的文章的逻辑后续。
