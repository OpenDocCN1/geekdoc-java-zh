去年年初，我决定跟踪我的阅读习惯，并在 Baeldung 上分享最好的东西。从那以后就没错过一篇评论。

## 1. Spring 和 Java

### 高性能 Java 持久化——第二部分

- [高性能 Java 持久性——第二部分](https://web.archive.org/web/20220812065443/https://vladmihalcea.com/2016/06/17/high-performance-java-persistence-part-two/)【vladmihalcea.com】

我已经关注这本书有一段时间了，很明显，在未来的许多年里，它将成为那些打算学习 `Hibernate` 和 `JPA` 的开发人员的参考资料。终于差不多可以出去兴风作浪了，这很酷。

### Bean 验证与 Jigsaw 联络员

- [Bean 验证与 Jigsaw 联络员](https://web.archive.org/web/20220812065443/http://in.relation.to/2016/06/17/bean-validation-and-the-jigsaw-liaison/)

非常好的、代码量很大的对 Java 未来的展望，特别是**模块化工作将如何与 Bean 验证**一起进行。

### Java 9 新增流

- [Java 9 中的新流](https://web.archive.org/web/20220812065443/http://blog.codefx.org/java/dev/java-9-stream/)【codefx.org】

Java 9 即将推出，对 `Stream` API 和一般功能的改进看起来肯定很有趣。

### Java vs .NET vs Python vs Ruby vs Node——谁主宰着就业市场？

- [Java vs .NET vs Python vs Ruby vs Node——谁主宰着就业市场？](https://web.archive.org/web/20220812065443/http://blog.takipi.com/java-vs-net-vs-python-vs-ruby-vs-node-js-who-reigns-the-job-market/)【takipi.com】

另一篇有趣的数据驱动的文章，这次是关于就业市场的状况。来自 Takipi 的男孩女孩们最近一直在疯狂地计算数字。我最大的猜测是，他们雇佣了一个非常擅长从数据中挖掘洞察力的人。

### 我们罐子里的错：为什么我们停止制造肥罐子

- [我们罐子里的错：为什么我们停止制造肥罐子](https://web.archive.org/web/20220812065443/https://product.hubspot.com/blog/the-fault-in-our-jars-why-we-stopped-building-fat-jars)【product.hubspot.com】

与打包和部署应用程序的 `fat jar` 方法不同的视角，这在实际规模中很有意义。

### Java EE 守护者联合起来拯救 Java EE

- [Java EE 守护者联合起来拯救 Java EE](https://web.archive.org/web/20220812065443/https://www.infoq.com/news/2016/06/JavaEEGuardians)【infoq.com】

一个很好的、快速的关于 `Java EE` 守护者组织的介绍，当然还有现在 `Java EE` 生态系统的一般状态。

### 我不使用调试器

- [我不使用调试器](https://web.archive.org/web/20220812065443/http://lemire.me/blog/2016/06/21/i-do-not-use-a-debugger/)【lemire.me】
