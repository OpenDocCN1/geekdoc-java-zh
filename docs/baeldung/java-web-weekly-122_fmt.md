## 4. 本周精选

大约一年前，当我开始着手我的第一个球场时，我写道，在我们的生态系统中，坚实的球场是如此之少。我从经验中知道，组织一个好的、高质量的课程需要很长时间——大约 6 个月的持续工作——这也解释了为什么很少有这样的课程。

这种情况正在慢慢改变——**Petri 新宣布的测试课程**肯定会成为参考资料：

#### [>>测试用 Spring](https://web.archive.org/web/20220810172651/https://www.testwithspring.com/)

**整个星期（截止到今天）**套餐都是五折优惠，所以如果你喜欢测试，就选这个吧。如果你真的不喜欢测试，那么一定要选这个。

我对这个很兴奋，不仅仅是因为它是关于测试的，也是关于 Spring 的（这非常酷）。
