## `&` 语法

`&` 作为关系运算符使用：

当两个条件都为真时返回真，其中一个条件为假时返回假。

```java
public class Main {
    public static void main(String[] args){
        int x = 100, y = 90, z = 60;
        if ((x > y) & (x > z))
            System.out.println("The value of x is " + x);
    }
}
```

输出：`The value of x is 100`

### 按位与

`&` 用于按位与：

如果对应的位都为 1，则返回 1，否则返回 0。

示例：

```java
public class Main {
    public static void main(String[] args){
        int x= 4;
        int y = 6;
        int z = x & y;
        System.out.println(x + " & " + y + " = " + z);
    }
}
```

输出：`4 & 6 = 4`

## `|` 语法

`|` 用于按位或：

如果其中一个位为 1，返回 1，所有位都为 0 时返回 0。

示例：

```java
public class Main {
    public static void main(String[] args){
        int x= 4;
        int y = 6;
        int z = x | y;
        System.out.println(x + " | " + y + " = " + z);
    }
}
```

输出：`4 | 6 = 6`

## `^` 语法

`^` 用于按位异异：

如果对应的位不同，则返回 1，相同则返回 0。

示例：

```java
public class Main {
    public static void main(String[] args){
        int x= 4;
        int y = 6;
        int z = x ^ y;
        System.out.println(x + " ^ " + y + " = " + z);
    }
}
```

输出：`4 ^ 6 = 2`

## `<<` 语法

`operand << bits`

根据给定的位数位数左移所有位。

示例：

```java
public class Main {
    public static void main (String[] args) {
        int operand = 2;
        // 左移 2 位
        int n = operand << 2;
        System.out.println(n);
    }
}
```

输出：`8`

## 无符号右移 (`>>>`)

语法：`operand >>> bits`

根据给定的位数右移所有位。

最左侧的空缺将用 0 填充。

无符号右移。

例如：假设 `-2 = 11111110`

`-2 >>> 1` // 返回 `01111111`

# 抽象类与方法

## `abstract` 语法

`abstract class/method`

`abstract` 用于类或方法。

抽象类作为父类工作，会被其子类扩展。子类的方法将重写抽象类的抽象方法。

`abstract class` 不能创建任何对象。

`abstract method` 仅用于抽象类。

`abstract method` 是一个没有方法体的空方法。

例如：

```java
abstract class Book{ // 创建一个抽象类
    abstract void reading(); // 创建一个抽象方法
}
class eBook extends Book{ // 扩展父类
    void reading(){ // 重写抽象方法
        System.out.println("I override that abstract method.");
    }
}
public class AbstractDemo {
    public static void main(String[] args){
        eBook obj =new eBook();
        obj.reading();
    }
}
```

// 输出: I override that abstract method.

## `ArrayList` 函数

- `obj.add()`: 添加元素
- `obj.get()`: 获取元素值
- `obj.set()`: 设置元素值
- `obj.size()`: 返回元素数量
- `obj.remove()`: 移除元素
- `obj.clear()`: 清除所有元素

e.g.

```java
import java.util.ArrayList;
public class Main {
    public static void main(String[] args) {
        ArrayList<String> colors = new ArrayList<String>();
        colors.add("Red"); // 添加项
        colors.add("Yellow");
        colors.add("Green");
        System.out.println(colors);
        for (int i = 0; i < colors.size(); i++) { // 遍历
            System.out.print(colors.get(i) + " "); // 获取元素值
        }
        colors.set(1, "White"); // 设置项值
        System.out.println(colors);
        colors.remove(2); // 移除元素值
        System.out.println(colors);
        colors.clear(); // 清除所有项
        System.out.println(colors);
    }
}
// 输出:
// [Red, Yellow, Green]
// Red White Green 
// [Red, White]
// [Red]
// []
```

# `assertion` 断言语法

```java
assert condition: "message";
```

// 断言通过检查我们假设为真的代码来帮助检测任何问题。

// 如果条件返回假，JVM 将抛出消息并停止。

// 在运行带断言的文件时，我们需要在命令中使用 `java -ea` 来启用断言。

e.g.

```java
import java.util.Scanner;
public class Assertion{
    public static void main( String args ){
```

```java
public class Main {
```

```java
        System.out.println(s2);
        System.out.println(s3);
        System.out.println(s4);
        System.out.println(s5);
    }
}
```

```
R in 8 Hours
2.900000
64
W
```

## `hasNext()`语法


// 检查集合中是否有下一个元素

// 如果对象有下一个元素，则返回 true

```java
import java.util.LinkedList;
import java.util.Iterator;

    public static void main(String[] args) {
        LinkedList<String> colors = new LinkedList<String>();

        colors.add("Yellow");
        colors.add("Green");
        System.out.println(colors); // 显示值
        Iterator<String> it = colors.iterator(); // 创建 LinkedList 迭代器

        }
    }
}
```

e.g.

```java
import java.util.*;
```

```java
    public static void main(String args[ ]){
        LinkedList myList = new LinkedList(); // 创建一个 LinkedList 对象
        myList.add("Hello! "); // 向 myList 中添加元素
        myList.add("My ");
        myList.add("Friend. ");

    }

    static void showList(LinkedList myList){
        Iterator i = myList.iterator(); // 创建 "myList" 的迭代器对象
        while(i.hasNext()){ // 检查 myList 是否有元素
            Object obj = i.next();
            System.out.print(obj.toString());
        }
    }
}
```

- `"public"` 成员可以在任何包和类中访问。
- `"protected"` 成员不能在非父类或非子类中访问。
- `"default"` 成员不能在不同的包访问。
- `"private"` 成员不能在不同的类中访问。
