## 引言

Web 组件开发者考试是 Java 世界的高级认证之一。但这并不意味着它必须比程序员考试更难。这是因为它的重点在于测试你对 API 的了解。具体来说，就是 `servlet` API 和 JSP 相关的技术。

你还需要理解 Web 和网络相关的概念、容器如何工作，以及某些 XML 配置文件的元素。在当今世界中，随着 JavaServer Faces 和 Spring MVC 等 Web 框架使得 Web 应用开发变得更加简单，许多人并不了解基础或低层知识，而这些知识有助于理解为什么情况是现在这样，以及解决非常具体的问题。这确实是一个问题。

考虑到这一点，本书重点关注考试中的 `servlet` 和 JSP 部分，因为根据我的经验，这些部分的权重更大。因此，本书展示了 120 个问题，分布在考试涵盖的 12 个主要主题中，分布如下：

| 部分 | 题目数量 |

### 如何使用本书

如果你计划参加 Java EE 6 Web 组件开发者考试，那么这本书不应该是你的唯一资源。它只是旨在作为补充。通过考试的良好策略将是：

1. 参加一个涵盖所有考试主题的课程，或者按照良好的策略进行学习。
2. 尽可能地通过模拟考试进行练习。

本书的目的是帮助你完成第二点。许多公司提供了许多模拟考试和模拟器，声称有大量的题目和练习。大多数模拟题的问题在于，其中许多题目与考试涵盖的主题无关，含义模糊、重复，或者仅仅与真实测试相比太简单了。
