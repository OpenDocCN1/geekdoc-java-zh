
# Java 8 新概念

## 行为参数化

行为参数化是一种软件开发模式，允许你处理频繁的需求变更。

行为参数化意味着获取一段代码（该代码稍后可以由程序的其他部分调用），并在不执行它的情况下使其可用。

行为参数化是指方法能够接受多个不同的行为作为参数，并在内部使用它们来完成不同的行为。

例如，你可以将代码块作为参数传递给另一个方法，该方法稍后执行它，使得方法的行为基于该代码块进行参数化。

行为参数化是一种非常有用的模式，它允许你封装行为，并通过传递和使用创建的行为来实现方法的行为参数化，从而轻松适应变化的客户需求。

Java API 中许多经常与匿名类一起使用的方法都可以用行为进行参数化，包括：

- 使用`Comparator`进行排序：这是一种反复的编程任务。
- 使用`Runnable`执行代码块：你可以使用`Runnable`接口表示一段不返回结果的待执行代码块。
- 处理 GUI 事件：GUI 编程中的一种典型模式是响应特定事件（如点击按钮或悬停在文本上）来执行操作。

## Lambda 表达式

通过行为参数化传递代码（这允许你定义一个表示行为的代码块并将其在各处传递），对于应对代码中频繁的需求变更非常有用。你可以决定在特定事件发生时或算法的某个特定点运行该代码块。

使用匿名类来表示不同的行为是繁琐的，这不会鼓励程序员在实践中使用行为参数化。

Java 8 中的 Lambda 表达式允许你以一种简洁的方式表示行为或传递代码块。

Java 8 中的 Lambda 表达式可以理解为匿名函数的简洁表示，它没有名称，但有一个参数列表、方法体、返回类型，以及可能抛出的异常列表，这些是可以传递的。

一个 Lambda 表达式由以下部分组成：

- 参数列表：此列表反映了`Comparator`中`compare`方法的参数。
- 箭头：箭头`->`将参数列表与 Lambda 表达式的体隔离开。
- Lambda 表达式的体：该表达式被视为 Lambda 的返回值。

Java 8 中的 Lambda 表达式允许你直接内联地提供函数式接口中抽象方法的实现，然后将整个表达式视为函数式接口的实例。

## 函数式接口

函数式接口无非仅指定了 1 个抽象方法的接口。

Java API 中有多个函数式接口，例如`Comparator`和`Runnable`。

在 Java 8 中，如果一个接口具有许多默认方法，它仍然是函数式接口（默认方法是带有体的方法，在类未实现方法时提供某些默认实现），只要它只有 1 个抽象方法。

函数式接口中抽象方法的签名本质上描述了 Lambda 表达式的签名。

在 Java 8 中，函数式接口带有`@FunctionalInterface`注解，用于该接口是一个函数式接口。

函数式接口非常有用，因为函数式接口中抽象方法的签名被称为函数描述符。因此，如果你想使用不同的 lambda 表达式，你需要一组能够描述通用函数描述符的函数式接口。

## Predicate

在 Java 8 中，`java.util.function.Predicate<T>`接口定义了一个名为`test`的抽象方法，该方法接受一个泛型类型`T`的对象并返回布尔值。

如果你需要表示一个使用类型`T`对象的布尔表达式，则使用此接口。

## Consumer

在 Java 8 中，`java.util.function.Consumer<T>`接口定义了一个名为`accept`的抽象方法，它接受一个泛型类型`T`的对象并返回 void。

如果你需要访问类型`T`的对象并对其执行某些操作，必须使用`Consumer`接口。

## Streams

在 Java 8 中，流（stream）无非来自源的元素序列，它支持数据处理操作。

### 什么是元素序列？

它类似于集合，流提供了一个针对特定元素类型的有序值集的接口。流表达了计算，如`filter`、`sorted`和`map`。集合关注数据，而流关注计算。

### 什么是源？

流从数据提供源（如集合、数组或 I/O 资源）消耗数据。

### 什么是数据处理操作？

流支持类似数据库的操作以及函数式编程语言中的常用操作，用于操作数据，例如`filter`、`map`、`reduce`、`find`、`match`、`sort`等。

流支持`filter`方法，该操作接受`Predicate`作为参数，然后返回包含所有匹配`Predicate`元素的流。

流还支持`map`方法，它接受一个函数作为参数。

### 如何构建流？

- 从值构建流：你可以使用静态方法`Stream.of()`创建带有显式值的流，它可以接受任意数量的参数。
- 从数组构建流：你还可以使用名为`Arrays.stream()`的静态方法从数组创建流，该方法接受数组作为参数。
- 从文件构建流：你还可以使用名为`Files.lines()`的方法从文件创建流，它返回来自给定文件的字符串流。
- 从函数构建流：你还可以使用两个静态方法从函数创建流，分别为`Stream.iterate()`和`Stream.generate()`。
