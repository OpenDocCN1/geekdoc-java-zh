
# 摩卡杀案（Java 探探探系列，#5）

我大笑出声。“我才不要。”自从一年多年前他离开我之后，我就再也没有见过或和斯科特谈过话。我不想现在开始。

“我是认真的。在你揍他之前，你听听他说什么了吗？”

“不太清楚。”

“他说你需要他的帮助。”

“我会送他出门。”

莱德露笑了。“行了。我所认识的那个`Juliet Langley`永远不会拒绝需要帮助的人。”

“斯科特不是人。他是个卑鄙、骗子、没出息的蛋——”

他举起一只手。“我知道。你提到过了。”

我双手抱在胸前。“我不想理他说话。讨论结束。”

“好，那我去跟他谈。”

“随你的便吧！”他溜出门门时，我冲他吼道。“啊！”我大叫着，抓起最近的东西——沙发上的一个枕头——朝着房间另一头扔了。

天到底为什么斯科特·奥马利会在千百万人中偏跑回来向我寻求帮助？他是不是蠢到以为我会为他做`anything`事情？他毁了我的生活。在他和我共同经营的咖啡馆的一名女员出轨后，他掏空了我们的银行账户和咖啡馆的账户，偷走了我所有的财物，然后逃了。。我留下一个仍然要付房租的空公寓，以及一家没有资金购买物资或支付员工工资的咖啡馆。我不得不关闭咖啡馆，这比任何事情都让我痛苦。雪上加霜的是，如果我最好的朋友`Pete Bennett`没有在当时伸出来并为我提供`Java Jive`的经理职位，我就得搬回父母家住了。这也是为什么我起初会在纳什维尔。如果这一切没有发生，我本应该回到老家，可能已经和那个鼠类一样的斯科特结婚了。

想到这里，我不禁打了个冷颤，给自己倒了一小杯伏特加，我和皮特存在办公室里用来庆祝和应急的。酒液一直灼烧到喉咙，但稍微缓解了一些压力。当我把酒瓶收回写字抽屉时，莱德回来了，看了一眼瓶子和我用过的小酒杯，但什么也没说。

“怎么样？”我问。“你们聊得愉快吗？”

莱德的嘴角微微撇了一下。“那家伙真是个彻头彻尾的混蛋。”

“你觉得呢？”

“他还带包。”

我笑了一下。自从我认识斯科特，他就总是单肩挎着一个小邮差包。而且是的，它看起来确实像个包。如果你非要从技术角度来说，由于他把钱包、钥匙、手机、零钱和润唇膏都放在里面，那它确确是一个包。“他喜欢别人称它为单肩包。”

“随他吧。他似乎很坚持要和你谈。他没告诉我任何细节，但他说他遇到了麻烦，而你是唯一信任会帮助他的人。”

“你传达了我的信息吗？我一点也不在乎他的问题？”

莱德笑了笑。“我很确定他的鼻子被打断了。我觉得你的意思已经传达了。”

“很好。他走了吗？”

他忍着脸说：“算吧。等你有时间消气后，他今晚上会回来。”

“什么？”我大叫道。

莱德双手挡在脸上。“别打打信使。”

我翻了个白眼。“哈，哈。”

他的表情变得严肃。“嘿，我觉得你应该听听他的。他看起来是真的很难过。我晚点要带玛雅去看电影，所以我没法当裁判。你觉得没有我的情况下能控制住你愤怒的拳头吗？皮特会在这里支持你吗？”

“他应该会。尽管我得提醒你——他认识斯科特，而且他讨厌他的程度并不比我少。”

“你们两个完全可以像大人一样处理这件事。”

“我和皮特？很难。”

他沮丧地按了按山根。“如果我在约会期间接到电话要来从监狱里保你出来……”

我甚至不想考虑被关进监狱（再次）的事，换了个话题。“所以你打算去看什么电影？”

他耸耸肩回答道：“不知道。某部爱情片。玛雅选的。”

我惊讶得掉了下巴。“看吧？女孩电影！”

“你抱怨什么？你压根就不喜欢那种电影。”

好吧，我被说得没错。

***

我无法摆脱斯科特突然出现在`Java Jive`带来的不安感，于是先回家了一会儿试着让自己冷静。我走着生锈的楼梯回到我二楼的公寓，一边自言嘀咕，想着这一切都是斯科特的错，才导致我付不起更好的房子，不得不住在这个到处是吵闹的大学生的破旧建筑里。

当我经过新邻居`Cooper`开开的窗户时，他喊道：“嘿，朱莉特！”

我给了他敷衍的微笑并挥了挥手，继续往前走。

库珀在门口赶上我。“你还好吗？你看起来并不开心。”他伸手捏了捏我的肩膀，担忧地看着我。我意味深地看了他的手，他很快收了回去。“抱歉。我没过脑。想聊聊困扰你的事吗？”

我叹了口气。“我只是在想斯科特。”

“啊，是的。那个臭名昭著的红发女鬼。很久没见到她了。我曾一度以为她彻底消失了。”他压低声音补充道，“老实说，我很高兴她还在某个地方活着。我喜欢她的风格。”

听到他提到我那个在火脾气发作时给自己起的‘第二人格’，我不禁笑了起来，说道：“我希望她从现在起一直冬眠。我想在斯考特（Scott）今晚回来时，我能保持冷静。”

“我会支持你的，绝不会离开你身边。不过，如果我们都清楚他还需要再挨一记重拳的话，我可能会在那个时候移开视线。”

我笑了。皮特（Pete）总是站在我这一边的。从我大一第一天走进`Java Jive`起，我们就一直是最好的朋友了。他的父亲是这家店的主人，去世后把店给了皮特。但由于皮特已经在纳什维尔的一家大型`Music Row`录音室担任音效工程师了，他需要有人来打理店面。我整个大学期间一直和皮特在这里工作，所以我对这里了如指掌，这完全是理所当然的。这也是唯一我不埋怪斯考特的地方——能再次和皮特一起工作、相处真是一件乐事。

“谢谢。既然他跟我算是‘两清了’了，我不想让自己看起来像个可怜、被抛弃的落魄女人。因为……你知道的……我并不是……”我不确定地收住了声音。

皮特笑了起来。“你远非如此。你最近在感情生活上可能有些起伏，但那是每个人都会经历的。你看起来总是能脱颖而出。”

我不太确定这一点。我最近的几次约会尝试中波折多于顺遂，这可能就是为什么我几乎放弃了在可预见的未来建立真正关系的可能。至少在这一方面，我的年轻朋友库珀（Cooper）对我来说是完美的人选，尽管我知道其他方面都是错的。我甚至没脸告诉任何朋友我们的安排。我把一切都告诉了皮特，但唯独没有这件事。

我吐了口气。“如果你这么说的话。”

“我知道我是真的。想想你过去一年的经历和成就，然后告诉我你不是你认识的最最棒的女人。”

我脸红了。“噢，皮特。”

他握住我的手。“你是*我*所认识的最棒的女人。”

我内心一阵悸动。皮特和我之间有着超越朋友的情感，而且已经持续了一段时间，但由于这种原因或那种原因，我们的时机总是不对。此外，尝试建立浪漫关系还有可能毁掉友谊的风险，而这是我们任何一个都无法接受的。所以我们没有尝试。于是，导致了我那看似不可注定的单身宿命。

谢天谢地，一阵敲门声打破了我们的小时刻。皮特和我彼此拉开了距离。

科尔（Cole），我们晚班的一位咖啡师，探头进了门。“朱丽特（Juliet），你下午收拾的那个哥们又回来了。你是想让我把他轰出去，还是已经准备好迎接第二回合了？噢天呐，皮特，你真该看看的。她就像*砰*的一声，那哥们就直接倒地了。整个下午大家都在谈论这件事。”

皮特咯笑了一下，我低下了头。我可以想象我的员工在讨论和剖析我糟糕的决定时有多尽兴。为什么这种事情总是发生在我身上？

“我马上就过去，”我低声说。

科尔离开后，皮特和蔼地说：“你会没事的。解决完这事，你就再也不用去想那个卢蛋一眼了。”

我点了点头，走出办公室。斯考特坐在桌子旁，看起来又紧张又坐立不安。他的鼻子上贴了块胶布，眼睛周围已经开始淤青。我确实狠狠揍了他了一顿。

我觉得在重塑了他的脸型之后，用“嘿，斯考特”来问候并不合适，于是我默默地坐在他的桌对面。他的“挎包”横在我们之间，当我想起莱德（Ryder）之前吐槽过那个包时，我差点没笑出来。

他叹了口气。“我知道我无权要求你任何事情。我也不怪你揍我。”

我忍住了一句刻薄的回应，讽刺*他*竟然不怪*我*做一件他完全自受的事。相反，我说：“你为什么来这里？”

他环顾四周，确保没有人在偷听我们的对话。房间另一头只有几个人，远在听力范围之外。“我大麻烦了，朱丽特。我不知道该信任谁……但尽管你恨我入骨髓，我知道我可以信任你。我没有别的地方可去了。”

“*曼迪（Mandi）*呢？”我问道，指的是那个为了她抛下我的服务员。我没忍住问出了。

我注意到他在流汗。流很多。而且脸色苍白。他那平时打理得（过）完美的金发，此刻凌散地垂在脸边。他的手甚至在抖。我可以把这种苍白解释为断鼻事件的副作用，但其他症状不是。我还恰好注意到他左手戴着一枚婚戒，这让我很恼火，但我努力不去想它。

我忍着呻出了一声。典型的斯科特，当对话变得对他来说有点太真实时，他就开始转移话题。我指了指咖啡馆另一侧的洗手间。“在那边。”

他跳了起来，冲向店前部，这让我不禁怀疑，他突然想上厕所的愿望是不是真的。我溜过去，坐在了皮特站立的柜台对面的高凳上。

“你没有在他的咖啡里加`Ex-Lax`吧？”我问他，希望那不是斯科特紧急去洗手间的原因。

皮特啪地了一下手指。“该死，我怎么没往这方面想呢？你知道，即使不加任何泻药，一个华夫饼塔可能也会产生同样的效果。要我为他弄一个吗？”

我笑着说：“不用了，谢谢。也许如果我们再也不被打扰，这段对话很快就会结束。”

他耸了耸肩。“我不做保证。”

“噢，顺便把他那个蠢的提包带回来。”

“好的，女士。”

斯科特从洗手间出来，脸色比进去的时候苍白得多。他看起来不太对劲。

我在桌旁接了他。“我们谈谈正事吧，这样你就可以去个地方躺一会儿。我觉得你需要休息。”

他点了点头。“好的，朱莉叶。情况是这样的：曼迪不仅失踪了，她是被……绑架了。”

“什么？”我叫道，“为什么？”

他低下眼睛继续说道：“我最近和一些危险人物做……生意时出了问题。我受到了多次威胁。而这次——”他的呼吸因抽泣而卡住了，“这次他们真的实施了他们的威胁。”

我惊得掉了下巴。“有些‘危险人物’带走了你的妻子，然后呢？他们是在向她索赎金吗？他们会伤害她吗？你现在为什么不报警？”

他再次捂住肚子呻吟道。“他们说不准找警察。如果警察介入，他们就会杀了她。”

“他们为什么要带走她？他们从你这里想要什么？”

“我某种……非法获取了一些敏感信息。我手里有可以毁掉很多人生活的证据。”

“真的吗？”我抱怨道。我怎么没意识到这家伙是个人人渣呢？

“我需要你的帮助。你是私家探，对吧？”

我揉着太阳穴，试图理解他的话。“斯科特，这太`insane`了。你必须去报警。他们可以在不引起他人注意的情况下帮助你。而且，私家探根本不接这种业务。我们只负责查查人是否对配偶或生意伙伴不忠。我们不搞绑架或赎金的事。”

斯科特越过桌子抓住我的手。“我打交道的人富有且有势。他们有关系。如果我去报警被他们发现，曼迪就死定了。除了你，我不信任我认识的任何人。请，你必须帮帮我。我们必须找到她。”

他提出的是不不可能的任务。“你是想让你和我单枪匹马去对抗一群强大且危险的绑架犯吗？”我质问道，“你想象在什么情况下这`不会`有坏下场？”我生活中最不需要的就是再和另一群暴力的流氓分子纠缠在一起。

“我知道这要求很大。我很抱歉。但我需要你，”他恳求道。

“听着，我有几个当警察的朋友。我们可以去找他们——”

“不！”他大喊着跳了起来。他的眼神变得呆滞，开始摇晃。“房间在转吗？”

我扑向他，引导他回到座位上。皮特已经在路来帮忙了。幸运的是，现在是周六深夜，店里相当空旷。我们不需要一双窥探的眼睛盯着我们。皮特和我把斯科特安顿好，皮特跑去给他拿了杯水。

斯科特喝了一口水，用手背擦了擦嘴。“好了，我好些了。求你了，你会帮我救她吗？”

我瘫回椅子上。“斯科特……理智点。你我并不具备人质救援的技能。如果你不去报警，你就不能直接给那些人他们想要的东西吗？而且，他们到底是谁？”

他的眼神看起来很不对，完全不像他自己。“这很复杂。朱莉叶，我求你了。你至少能帮我查查我妻子被关在哪里吗？”

我叹了口气。我可以尝试，但我必须比他给我的那些晦涩的碎片了解更多信息。他有些话没告诉我，如果让我猜的话，我敢打赌他隐瞒着，是因为整个真相会让他自陷罪名。他那些所谓的“非法获取”的信息一定非常惊人。

“如果你开始给我一些我能用的实际信息的话。”

“我想她可能就在城里。她昨天下午开车过来出差，然后今天一早我接到电话说她被绑架了。”

“谁给你的电话？是谁带走了她？”

他的回答是靠在桌子侧面在地上吐了。

皮特像往常一样表现成年人，嘟囔道：“呃。我不我不清理那个。”

我看了一眼硬木地板上那一小滩深褐色的液体。“没多少东西，皮特。”

# 章

我处在一片迷雾中。皮特让我坐在一张面对墙的桌旁，跑去给我了一些水。除此之外，他没有离开过我的身边，即使我坚持要从后门出去，试图逃跑再也不回来。他成功地劝我回到室内，警察和法医几分钟后到达了。我能听到他们在商量，但我太恍了，无法集中注意力听他们在说什么。我只想快离开这里，我知道这在几个小时内不会发生。我有一个漫长的夜晚要过，皮特也是如此。因此，我用尽了能集到的全部能量让自己冷静下来，并把对斯科特的个人情感推到一边。在警察审问我时，我必须保持清醒。

非自然死亡（“非自然”指并非在医疗监护下发生，例如在医院等地）都必须由谋杀组进行调查。在发现了几具尸体后，我以前经历过这种情况。但我从未见过有人去世。我做梦也没想到`Scott`会是那个让我目睹他生命流逝的人。

警察先将`Pete`带回我们的办公室审问，因为他是`Java Jive`的老板。随后，我不被允许和他交谈。在顾客和其他员工接受审问期间，我独自坐着思考。我知道为什么我被留到最后，如果我是这个案件的调查员，我也会采用同样的方法。通过与`Pete`对话，`MNPD`的侦探（我不巧认识他）会发现我和`Scott`之间的关系。然后，当他采访其他证人时，他会对所发生的事情形成一个理论。

这就像在拼拼图。我是那个被`Scott`伤害过的抛弃女人。今天早些时候我打断了他的鼻子，我的员工和几十名顾客目睹这一切。下次`Scott`靠近我时，他就倒地了。除非他患有某种贪婪且见效的疾病，否则他的猝死看起来非常可疑。那块拼图迅速拼合在一起，形成了一个巨大的红箭头，直指我。

最后，轮到我了。警察放走了顾客和员工——唯独`Pete`。这让我开始担心他们留下他的理由是什么。

侦探向我走来，伸出一只肉乎乎的手。“侦探`Tom Delaney`，谋杀组。”

我站起来握了他的手。“我是`Juliet Langley`。”

他指了指我的椅子。“坐吧。”

我的胃一阵收缩。“我以为你们是在办公室进行谈话。”

侦探耸了耸肩。“我不介意在这里对你说。”

这是一个高明的手段，尽管很残忍，让我坐在和尸体在同一个房间里接受审问。我已经不喜欢这家伙了。我慢慢坐回椅子上。

“Langley 小士，你是如何认识 O’Malley 先生的？”

噢，又来了。“我们曾经订过婚。”

“曾经过？但现在没有了。结束得不愉快吗？”

他已经知道了，因为我所有的员工都听过关于“混蛋`Scott`”的故事，那是我偶尔（好吧，不比偶尔）称呼他的方式。`Delaney`侦探知道他问题的答案。他只是想让我说出来。

“是的。他离开了我。”

他眯起那双小小的、靠得太近的眼睛看着我。“然后呢？”

我叹了口气。“然后偷走了我的钱和财物，导致我的咖啡馆倒闭了。”

“你为此向他提起了控或试图起诉他吗？”

“用什么钱？他拿走了一切。此外，我蠢到和他开了联名银行账户，所以他有权花光所有的钱。而且我怎么能证明我们的沙发是用我的退税款买的，或者床边的灯是从曾祖母那里传给我的？这不可能。”

他的嘴角向上扬起。“听起来你还在为此感到生气。”

我没有回答。

“所以也许你决定采取个人行动来向他报复。”

这一次，我没有回答。我没有必要。这是一次谈话，而不是审讯，尽管它似乎正朝着那个方向快速发展。

“我听说你今天下午袭击了他。”

“我打了他的鼻子。”

侦探向后靠在椅子上，导致他的衬衫扣子绷着他那隆起的啤酒肚。“像你这样的好女孩为什么会做那种事？”

皮特平静地说：“我不想惹麻烦，我也不需要更多女孩了。满意了吗？”

那个皮条子盯着他良久。他哼了一声：“滚出这儿，”然后抓起命运（Destiny）朝另一个方向走开了。

当我们冲向他的车时，皮特紧紧握住我的手。一进车内，他挂上挡，冲出停车场，一直没有减速，直到我们离了几个街之远。

皮特仍在努力让自己冷静，让沉重的呼吸恢复正常，他说道：“看到吧？告诉过你带枪是个好主意。”

我摇了摇头。“皮特，我甚至都无法……”

“对于那个扇屁股的事我真的很抱歉。不会有下次了。”他转向我，露出一个顽皮的微笑，补充道，“除非你想让我那样。”

# 第五章

Java Jive 咖啡馆周日不休息（虽然这周末休息也没关系，因为警察还没把店面还给皮特让他重新营业），所以皮特和我决定一大早就开始着手处理案子。但在他出现在我公寓之前，我又迎来了另一位访客。

我打开门，发现库珀（Cooper）站在那儿，脸上面色凝重。他毫无预兆地闯了进来，双臂环住我，用力捏得我吱的一声叫了出来：“我喘不过气了，库珀。”

他松了松手，但没有放开我。“我在新闻上听到 Java Jive 发生的事了，社交媒体也因此炸锅了。我昨晚敲了你几次门，但你似乎不在。我试着熬夜等你回家，结果还是睡着了。对不起我没能陪在你身边。事情发生时你在现场吗？你卷入了吗？那个叫 Scott 的人是你昨天提到的那个人吗？”

我叹了口气。在喝晨咖啡之前，这超出了我的承受范围。“嗯……是的。”

“针对我说的哪一个问题？”

我缩着脸回答道：“全部？”

库珀放开了我，俯视着我。“他……去世的时候，你在场？”

我点了点头。

“那个你今天早些时候还对他泄过气的未婚夫？”

我又点了一下头。

他的表情非常震惊。“你是怎么熬过来的，朱丽叶特（Juliet）？”

我忍住了翻白眼的冲动。我今天不需要——尤其是因为我计划把清醒的每一秒都花在调查上——去做心理医生，被迫挖掘并处理我的情绪。我没时间做那些。

幸运的是，另一声敲门声救了我，不用回答他的问题。但当我打开门时，我意识到我目前的访客状况将为我的生活开启全新的剧剧模式。

皮特提着一个蛋糕盒和两大杯外带咖啡走了。“嘿，朱尔（Jules），我想我们需要大量的咖啡因和糖来开始——”当他的目光落在库珀身上时突然停住了，库珀竟然穿着睡衣，而且还是光着脚进来的。“我打扰你们了吗？”

我在心里哀嚎着，希望皮特想的不是我所想的。“没有。皮特，这是我的邻居库珀·米尔菲斯。库珀，这是皮特·本内特，我的死党。”

库珀出手。“皮特。我听过很多关于你的事。”

皮特握了他的手，意味地看了我一眼。“真巧，我可没听过你一点。”

库珀眼中闪过一丝受伤，这让我的心一紧。我们现在的安排简直愚蠢。更糟的是，我怀疑库珀对这件事的情感投入比我多得多。

“好了，”我大声说了一句，“库珀，感谢你今天早上过来来看我，但我和皮特有一些……工作上的事需要……处理。我们晚点见？”

库珀领了会并朝门口走去，但就在我要关门时，他低声说道：“朱丽叶特，我很想和你聊些事情。我什么时候能见到你？”

“可能需要一段时间。我会通知你的，好吗？”

他点了点头，看起来非常沮丧。*这就是*为什么你不该和一个二十多岁的男的扯在一起。他还没有那种随着生活经验增长的脸皮。他还是个孩子。一个帅气的孩子，但仍是个孩子。

“哇，朱尔。我没看你是个母狼狗，”皮特说道，完全没有掩饰他的好笑之。

我咬着牙撒谎道：“我*不是*母狼狗。他只是个朋友。”

“他知道这吗？”

“闭嘴，皮特。”

他依然笑着，举了起手。“好吧，好。闭嘴。那么，老板——今天的侦查日程安排是什么？”

“我打算对 Scott 和曼迪（Mandi）进行背景调查，并让崔沃（Trevor）破解平板电脑和手机。一旦拿到那些东西，我们就有很多可以做的了。”

吃完咖啡和甜甜圈后，我们隔壁去了特雷沃·威尔斯（Trevor Wells）的公寓。他有几个朋友在一起，但他还是欢迎了皮特和我进去。

特雷沃说：“抱歉这里很乱。我们这为期十二小时的游戏赛快结束了。希望我们半夜时候没吵到你们。”

回到家后，我透过薄薄的公寓墙听到了他们吵闹的声音，但我太累了，立刻就睡着了。“没。没吵到我。”

赖安·哈特（Ryan Hart）盯着电视，坐在沙发上向我们挥了挥手。“嘿，哥们儿。”赖安也来自自由镇（Liberty），尽管我是通过特雷沃在纳什维见到他的。

“嘿，赖安，”我和皮特一起回答道。

特雷沃说：“什么事？我知道你们不是来迟到加入我们比赛的。”

“我们不是。我有个黑客方面的忙想请你。”我把`Scott`的平板电脑和`phone`给了他。

他的嘴角露出一丝微笑。“我以为你现在已经不屑于搞黑客了。”

“当我们是我前未婚夫谋杀案的首要嫌疑人时，可就不了。”

特雷沃瞪大了眼睛。

赖安猛地转看向我们。“斯科特·奥马利（Scott O’Malley）死了？”

皮特点头。“而且发生在咖啡馆（Java Jive）。”

赖安吐了口气。“那太糟了。抱歉了，哥们儿。发生了什么？”

“警察认为他可能被中毒了，”我回答道，“你们一直处于静音状态吗？我们听新闻和社交媒体上都在报道。”

特雷沃指向他柜台上的一叠`cellphones。“实际上，我们确实是这样。比赛期间不与外界交流是为了确保不作弊。”他转向另一个男孩，补充道：“倒不是作弊会有问题，`Tyler`。”

泰勒举起双手表示防御。“你们什么也证明不了。”

特雷沃摇了摇头。“反正，我假设这些属于那个死者？”

“是的，”皮特回答道。“都设置了密码保护。我们获取它们的方式并不合法——”

“完全非法，”我纠正他。

“我们需要进入这些设备来获取一些信息。”

“等我一下，”特雷沃说着，带着设备回了他的卧室。

赖安离开了沙发上的位置来到我们这边。“我挺认识斯科特的。我想他家里搬到这个镇上时他在上大学，所以他没怎么出现过。他的弟弟和我跟我一起毕业的。”

“亚伦（Aaron）。没错。”我甚至没有想过`Scott`的家人会如何面对他的死。在斯科特离开我之后，他们就背弃了我，但我仍然不想看到他们痛苦。

“所以我推测，既然你们两个是嫌疑人，警察就不相信这是意外中毒。你们为什么觉得会有人想杀他？”赖安问。

皮特耸了耸肩。“他来这里时一直在编一个他妻子被绑架的故事，说他遇到了麻烦。”

“绑架？这故事变得越来越离谱了。”

我回答道：“你说得对。我们处理完这里的事情就会去自由镇一日游，看看能不能从当地人那里打听出什么。”



“自由镇，是吧？我从今年夏天起没去过那里了。”赖安给了我们一个希望的微笑。“我不认为你们会考虑带上一个搭车客吧？我妹妹不久前发现怀孕了，所以我这几周一直想开车过去当面祝贺她。遗憾的是，我的那辆破车在进行重大维修之前没法应这段路程。”

“可以。人越多热闹。对吧，皮特？”我问。

他的眼神中闪过一丝异样，但接着笑了。“绝对。”

赖安在前往自由镇的两个小时车程中不断进行着现场旁白，告诉我们关于斯科特的事应该找谁谈谈，以及谁可能有关于他最劲爆的内幕八卦。我一辈子都生活在自由镇，除了大学期间在纳什维尔短暂的时光，以及当我尝试（并失败）开启歌唱生涯后的那几年，当然还有去年搬回来之后。我已经认识镇上所有的八卦爱好者和闲事妈。然而，我任由他唠叨，因为我得处理`Scott`电子设备里的文件工作要忙，没时间闲聊。

`Scott`的平板电脑似乎全是与业务相关的。他的`calendar`显示了他访问过的医生诊所的旅行行程。他的`contacts app`挤满了名字，我甚至不知道该从何处开始。除此之外，他还有许多关于各种药物的演示文稿，一份按地理区域和分配的银杉镇（Silver Spruce）代表分类的医生名单表格，`email folder`中有很多业务相关的邮件，没别的了。

而他的`phone`则完全相反。他在人类已知的每一个社交媒体应用上至少有一个活跃的账号。在某些应用上，他有多个账号，使用不同的名字，但用的是他的照片，这超级诡异。更糟糕的是，他似乎利用这些账号通过`private messaging`向女性发送色情信息。令人作呕，但不违法。

他下载了目前存在的所有热门游戏应用。他还有许多付费的娱乐应用——谁需要`Netflix`、`Hulu`和`Crackle`呢？然后是情。噢，色情。他有一整页页面专门放色情应用。我到底是怎么爱上这个卢瑟的？因为我无法停止自己继续研究这片烂摊，我打开了`Scott`的照片。

# 第 6 章

“那么糟？”皮特问。

我皱了皱鼻子。“我想这不是一个长故事，只是一个可怜的故事。他是那个在《自由镇纪报》（Liberty Chronicle）上写的文章让我的咖啡馆彻底关门大吉的记者。你记得我给你看过那条评论吗？”

“是的。据我记得，评价相当糟糕。”

“对，而且由于这里的人会相信他们在镇报上看到的一切，在故事报道出来后，我基本上没法经营了。”

事实上，我确实有杀掉那个男人的动机。坦率地说，德兰尼侦探对我的理论并不那么荒谱。如果我是这个案件的调查员，我会把所有的精力放在寻找受害者那个被极度抛弃的前妻的证据上。无论德兰尼是否能力无缺，他都会火力全开地向我（以及连带皮特）袭来。这就是为什么皮特和我有很多工作要做，而且动作要快。

## 进入自由山丘

我们决定从斯克的家里开始。我们手里有他的钥匙，而且在从犯罪现场偷了他的提包并搜查了他的旅馆房间后，在我们的罪行清单上再增加一次非法闯入又算什么呢？

皮特转进自由山丘的入口时，发出一声低沉的口哨。这是一个高档高尔夫球社区，也是利伯蒂市理想的居住地。房子都是大宅，与它们所在的狭小地块显得格格不入。无论我如何努力，我都无法想象斯克会住在这里。他总是嘲笑这个小区——管它叫“斯蒂福德山丘”。

皮特把车停在斯克的房子前面。“你真的觉得好吗？翻那个男人的随身包和行李箱不算太没隐私，但这里可是他的家。”

我点了点头。“我觉得没事的。我目前更多处于愤怒阶段，而不是悲伤阶段。我可以应付这种情绪。”

我们戴上手套（皮特这次从家里带了些更有男子气的手套），朝向正门走去，仿佛我们完全有权进入这栋房子一样。进屋后，我必须花点时间来压制涌上心头并威胁要吞没我的怒火。这个地方摆满了属于我的东西。诚然，这里有一些新家具和一些似乎是专门为这栋房子挑选的新摆件，但到处散落着我买的东西、别人送给我的东西，以及我从家里继承来的。我感到一阵恶心。

“朱尔，你都不眨眼，”皮特不安地说道。

“我知道，”我咬着牙低声说。

“呃……那我先开始到处看看，等你准备好加入我时再过来。”他匆忙走开了，根据经验，在我这种状态下最好不要试图跟我说话。

我吐出一口积压已久的呼吸。我必须提醒自己，对斯克产生杀意是没有意义的，尤其是他已经死了。一旦我把注意力集中在寻找信息而不是关注屋里的物品上，我就能回到厨房和皮特会合了。他正在翻找一个杂物抽屉。我在座电话旁发现了一些笔记本，并开始翻阅。他对我露出了浅浅的微笑，但没有试图开启话题。

过了几分钟，我终于开口道：“这里有很多我的东西。”

他走过来，把手放在我的肩膀上。“我知道。我认出了这里有几件是我送给你的东西。但我们必须保持专注。我们的任务是查出斯克到底发生了什么——不是为了那个混蛋伸雪正义，而是为了保护我们自己。”

我笑了。指出这里真正重要的事情，这种事交给皮特就好。“谢谢你的鼓励。”

“我们越快完成这件事，就能越快送你离开这里。”

我们找到了斯克的家庭办公室，但里面没多少东西。电脑有密码保护，所以我和皮特没法进去。我们都翻遍了他的桌抽屉，但里面大部分是个人物品，如房屋和车辆保险单、保修文件、信用卡账单、银行流水和账单。

皮特看了几张信用卡账单，发了口哨。“这家哥们是个购物狂。或者也许他妻子才是购物狂。账单上有许多在卖昂贵玩具的商店的大额消费……还有几次付给医生的大额付款。你敢打赌有人做过手术？”

我正忙着翻看一叠银行流水单，但在斯克和曼迪的存款或取款中没有发现任何异常。我发现他们有独立的银行账户很有趣。在曼迪看到斯克对我所做之后，也许她足够聪明，把钱和他的分开，以防万一他动了把她换成新款的念头。

## 关于曼迪的问题

“提到他的妻子，我在想警察对她的失踪有什么线索吗。”我轻笑一声。“如果我了解曼迪，她肯定会让那个绑架她的人吃苦头的。”

“怎么说？”

“嗯，如果不止一个绑架犯，她可能已经找到了办法让他们内斗，让他们自相残杀。这就是她在无聊时对咖啡馆其他员工所做的事。除此之外，她是一个非常出色的女服务。她能让最挑剔的顾客都听命于指尖。”

“是的，我记得在你的咖啡馆见过她几次，她很有魅力。而且她长得像超模，这也很加分。”我皱眉回答道，“是的，也是。”

## 莱恩的电话

我的手机响了，是莱恩。“嘿，”我说，开了扬声器模式，把手机放在桌子上，以便继续我的搜寻。

“嘿……我知道你不喜欢和记者聊天，但你愿意给我姐夫提供一个关于斯克遭遇的独家消息吗？”莱恩问道。

我看着皮特，做了一个鬼脸。（由于原文中存在大量重复性错误，此处已按逻辑整合翻译）。

我再次戴上手套，对着皮特低声说：“你守着门，我来到处找找。”

他照做了，我尽可能安静地拉开了旅行包的拉链。它看起来和我们在斯科特酒店房间看到的那个一模一样，果真里面装满了药物样本，就像另一个一样。但当我拨开宣传材料向下挖时，情况变得有趣起来。这里没有廉价的赠品笔，全是高端货。有几盒宝丽仕、菲拉力（Ferragamo）和阿玛尼（Armani）的设计围巾和领带，全部由精美的鲜艳丝绸制成。下面是几盒闪闪发光的耳环和亮袖扣，来自卡地亚（Cartier）和宝龙（Montblanc）等设计师。

## 对峙

忙于挖掘，我没有注意到门外安静了——不再有脚步声或关门声。皮特低声说：“你觉得他们走了吗？”

我耸了耸肩，摘掉手套，走到门边偷听。外面没有声音，但我并没有放弃我们的藏身之处，以防有人在短时间内来过又离开了。接着，我开始听到细微的脚步声，像是踩在厚地毯上——就像我们所在的卧室里那种蓬松的白色地毯。皮特一定也听到了，因为他抓住了我的手并紧紧握。时候到了。

突然门被猛地推开，一把黑色手枪出现在我们面前。一个女性的声音质问道：“在我房子里干什么？”

当我聚焦在声音的主人身上时，我的下巴都掉掉了。“`曼迪？我以为你被绑架了。`”

真该，曼迪甚至比以前更美了，她那头曾经是深色的长发现在变成了完美融合的多色调金金色。从样子看，斯科特的挥霍购物还包括为他那原本平胸的妻子做了隆胸手术。

曼迪盯着我看了一会儿，然后把枪垂在身侧。“朱莉特？你搞什么……”她摇了摇头像是要清醒一下，然后再次将枪指向我们的脸。“说真的，你们不该在这儿。你们在我房子里干什么？”

## 反击

皮特和我慢慢举起手。曼迪并不是我见过最精明的女人，她手持枪的位置离我足够近，我的手只有几英寸之遥。她只用一只手握枪，这告诉我她并没有真的打算对我们动手，或者至少对准确性并不感兴趣。她并不知道，在几个月前我被枪口威胁之后，莱德已经将教我几招在这种情况下反击的战术视为他的使命。

“从衣子里滚出来，婊娘们，”她尖刻道，在后退一步时移开了看向我们的目光。

在那瞬间，我用左手抓住她手枪的枪侧，用右手掌猛击她的手腕下方。她的手腕弯曲，导致她握枪的手松动了。我从她手中夺过枪并反准了她。她瞪大眼睛，嘴巴张着，双手举着向我后退。

我对着她冷笑。“现在谁是谁的婊娘？”

皮特在我耳边低声说：“朱尔，那太酷了！”

曼迪声音颤抖着说：“你会因为闯入我的房子并射向我而坐牢的。”

“这就是为什么我不会这样做，”我回答道。

我拔出枪里的弹匣，拉动撞机排空了膛室（那里已经是空的，另一个迹象说明她压根没打算射击我们）。我把枪扔在她脚下，把弹匣放进口袋。

曼迪显得很委屈，但还是捡起枪扔在床上，然后向后退，让我和皮特离开衣柜。

## 怀疑

我说：“让我们重新试一次。你好，曼迪。好久不见。你还记得我的朋友皮特吗？”

皮特不在意地挥了挥手。“嘿，曼迪。”

她朝我们翻了个白眼。“你们想要什么？”

她不太对。我们面前这个女人并不是一个悲伤的遗孀。我不认为她还没有收到关于斯科特去世的消息，尤其是她一直呆在家里，显然没有被绑架。斯科特去世已经超过十二小时了，尽管警察还没有他的执照来进行快速身份确认，但我给了他们他的名字、妻子的名字以及他们居住的镇。利伯蒂（Liberty）可并没有一大堆曼迪·奥马利供他们追踪。

我温柔地说：“你听过斯科特的事了吗？”

她的表情阴沉，但看起来更多是愤怒而不是悲伤。“听了。警察问我是否觉得你有理由杀他。”她冷笑了一下。“我告诉他们当然。”

我瞥了皮特一眼，努力不让自己吼出来。“我没有杀他。我们试图救他，但……显然他中毒了。我们无能为力。对你的损失表示哀悼。”

“你当然了。在我们对你做了那些之后，你一定恨死那家伙了。”

皮特察觉到我心中积聚的愤怒，说道：“我们先放过这事，好吗？斯科特告诉我们你被绑架了。你看起来似乎没被绑架。你是逃脱了还是怎么？”

## 真相大白

她摇了摇头。“我从未被绑架过。斯科特最近状态不太好。他变得幻幻又偏执。他坚信所有人都在害他。”

我盯着她看了一，试图判断她是否给了我全部真相——以及她的故事是否属实。尽管昨晚斯科特在告诉我他所面临的麻烦时表现有些反常，但我并不觉得他在幻觉或在编造。除了在涉及某些秘密交易时刻意含糊外，他看起来很诚实。

“斯科特以前不是那种人。为什么现在开始这样？”我问道，很想补充道，“难道是你逼他变成那样的吗？”

曼迪皱眉看着我。“我怎么知道？”

“嗯，因为你和他结婚。”

她耸了耸肩，显得完全不在乎。“我是和他结婚过。你可能不知道这一点，因为你从未结婚过，但婚后依然是两个独立的个体。我无法控制他做什么，我也没有尝试过。”

当我默默地生着闷气时，皮特说道：“没错，但你至少应该知道他生活里发生了什么。他在想什么，感受些什么。你们从来没互相交流过吗？如果你看到他需要帮助，为什么不给他找点呢？”

她从床上跳起来，大喊道：“我不需要向你交代！我觉得是时候你滚滚出我的房子了。”

我说：“行。我告诉过斯科特我会试着找到你，而且我已经找到了。我在这儿完事了。”

当皮特和我跟着她走到门口时，我向他低声说：“问问她，斯科特说他从某些危险人物那里偷了重要东西是什么意思。拖住她的，好吗？”

皮特点了点头。“所以，曼迪，为什么从餐饮服务业转行卖毒品？薪水有那么高吗？”

她转过身，狠狠地瞪他一眼。“废话。看看周围。我挣得比某些医生还多。”

“哇。印象深刻。如果有两份那样的收入，你们的进账相当可观啊。”

我跟在他们后面。当我路过走廊的一张桌子时，抓了那里展示的一个物品并塞进了兜里。皮特设法让曼迪喋个不停，所以我走得更远了，这次我拿了一件之前我们在看客厅时发现躲在书架书本背后的物品。我把它塞进裤子的后腰带里，然后拉下衬衫盖住它。当我经过一个边几时，我又顺手牵了一个小东西。

到这时，曼迪已经开了门。“我本想说和你重聚很愉快，朱莉叶特，但其实并不可爱。出去。”

我路过她时露出了虚假的微笑，努力不让她看到我那明显凹凸不平的屁股。“我也是。你保重。”

门在我们身后砰地一声关上了。

皮特问：“我应付曼迪的时候，你在干什么？”

我从口袋里掏出曾祖父的怀表，递给他看。“把一些东西还给它们所属的主人。”

他的眉毛挑了起来。“你偷了东西？”

“如果这原本就是我的东西，怎么可能被看作偷窃呢？”

# 第七章

我们进皮特的车后，我从裤腰里掏出一个小吉他形状的音乐盒。

当皮特看到它时，他的表情柔和了。“你冒险拿回了我多年前送给你的东西？”

我耸了耸肩。“这是我最喜欢的东西之一。你离开纳什维尔时送给我的。记得吗？”

他的目光直视着。“我说过这是为了提醒你你真正要做的事。”

“我说过，有一天，我会确保你回来并实现你的梦想。”

我把手放在他的手臂上，笑了。“你确实做到了。因为有你，我才上过舞台。”

在一次完全忘记了某首歌词的表演后，我患上了严重的舞台恐惧症，因此完全放弃了音乐事业。表演本是我计划要做的，所以我变得无可依靠。我回到父母家里，认命于餐饮服务业，诚然这并不糟，但并不是我计划的人生。当我回到纳什维尔处理斯科特的事物时，他慢慢说服我去参加那些咖啡馆的开放麦之夜。他一直鼓励我多表演，我对此感到非常紧张，但皮特是我的吉他手，所以他一直在我身边。

他的手盖住我的手。“也许曼迪给了你一些推动，但当你表演时，这一切都是因为你。”

听到他的话，我心里很不舒服，但和曼迪聊天让事情变得更复杂了，我觉得我们的调查比之前更糟。我从口袋里掏出最后一件物品。

皮特盯着它看了会儿。“一个电视遥控器有什么特别的？”

“没什么。我拿它是为了惹怒她。”

他是对的。从技术上来说这是偷窃。我摇下窗把它扔了出去。它落在人行道上撞碎了。“现在我要做的就是离开这里。”

“而且把它毁掉。”人行道把它撞碎了。他笑了笑继续开车。“我不该知道去跟你争论的——我们在一家当地冰淇淋摊停下，买了冷饮并制定下午的计划。瑞德和玛雅来电告诉我们，他们也发现曼迪没有失踪。通过调查她的背景和财务状况，他们一无所获，就像我们对斯科特一样。他们承诺会继续挖掘，但我开始觉得他们找不到任何东西。

坐在户外餐馆旁边的长椅上，皮特说道：“你知道的，斯科特疯了并不是没有可能。曼迪说她不知道他从那些所谓的‘危险人物’那里拿了什么。他的死可能并不那么神秘。可能是一场意外。”

我的直觉并不认同。“我明白你的观点，我觉得我们应该继续找下去。既然都在这儿了，不如利用今天剩下的时间把基础工作做全。我们需要和他的一些同事以及朋友聊聊。这应该能为我们勾出一个更真实的画像。噢，我还要读读他手机里的短信和个人邮件。如果我受得了的话。”

皮特笑了起来。“如果让你独自忍受这些，我算什么朋友？”他向我靠了靠，手臂放在我身后的长椅靠背上。“我们并肩作战。”

我笑了，拿出斯科特的手机，把它拿在两人中间，让皮特和我一起读。我翻阅了他的邮件，发现大部分是垃圾邮件，松了口气，但有一封引起了我的注意。它来自斯科特前雇主银杉制药公司的一个名叫`道格·麦凯`的人。

一旦我打开邮件，皮特读道：“亲爱的奥马利先生，此时我们必须要求您在任何情况下都不要进入银杉制药所在的办公楼。您的聘用已于本周终止，根据安全规定，您不再拥有进入大楼的权限。如果您继续违反补偿条款，将对您提起刑事诉讼。此外，请注意，如果您不归还属于银杉制药的药品和平板电脑，也可能对您提起民事诉讼。诚挚地，道格·麦凯，俄亥河谷地区经理，银杉制药公司。”

我摇了摇头。“哇。他的经理给他发了一封正式的停止函。斯科特一定把他惹火了。”

皮特滑到斯科特的回信。“噢，这回复真不错。全大写的‘去你的蛋’。你确定这是你订婚的那个人吗，朱莉？我一直觉得他是个笨蛋，但我从未从他身上感觉到过那种疯癫劲。”

## 调查

我叹了口气，回答道：“我同感。有些东西让他发生了变化。也许是药物的原因。或者……也许他说的是真话，无论他卷入了什么麻烦，导致他在压力下崩溃了。如果他说的话是真的，那可能会让他彻底失控。”

“是啊，只不过曼迪（Mandi）并没有被绑架。”

“她是这么说的。”

他向后靠了靠，困惑地看着我。“她为什么要对被绑架这件事撒谎呢？”

我耸了耸肩。曼迪的故事里有些地方让我觉得不对劲，但我又说不上具体在哪里。我嘟囔道：“我不知道，”继续向下滑动。过去几个月收到的邮件里没什么值得注意的，于是我进入了他的发送箱，然后是垃圾邮件箱。那里也什么也没有。至于电话，没发现太多可挖掘的。他的语音信箱是空的。大部分来电和电话都来自他联系人列表里的人，除了他在去世前最后几天反复出现的一个未知号码。我把它记下来，让`Ryder`和`Maya`去追踪。

“那看短信了？”皮特（Pete）问。

这些是我最害怕的——斯科特（Scott）与所有亲近的人每天进行的、毫无过滤的交流。尽管我在感情上已经放下他了，但翻看他的个人信息仍然让我痛苦。我不想知道他与妻子之间那些内部的小笑话。我不想读他与朋友之间的打趣，以及他们计划去哪里、做什么——他基本上就过着自己的生活，好像我根本没有存在过一样。除了他昨晚那句糟糕的道歉（那是在我提起他的过错*之后*才提供的），没有什么能证明他对他对我所的一切存有哪怕一丁点点悔意。

我清了清嗓子。“开始看短信吧。”

皮特从我手中拿过手机。“再仔细想想，让我来分担这部分吧。”

我长舒了一口气，随口说：“谢谢。”

“噢。斯科特和他老婆一直在发短信吵架。”他滑动了很长一段。“持续一段时间了。”

“多久了？”

“嗯……”他又往下滑了一点。“在我看来，事情是从三个月前开始变得糟糕的。”

“三个月前……嗯……那不是他开始欠交房贷和车贷的时候吗？”

皮特点了点头。“‘听着：我知道你正和那个该死的贾雷德（Jared）该死的背叛我。下一次看到那个该死的家伙时，我要该死的揍扁他那张该死的、该死的脸。’”他看向我，笑了笑。“顺便说一下，我加了那些星号。斯科特的嘴巴其实很脏。”

又一个新发现的特质。“好吧，所以这个叫`Jared`的家伙现在也在我们今天的追踪名单上了。斯科特那个害羞的新娘对他对他出轨的指控是怎么回的？”

“她告诉他去死自己吧。”

“真高雅。看看他是不是也和`Jared`爆发过短信战。”

皮特滑动着短信列表。“这里有一个`Jared`。`Jared Fisher`（贾雷德·菲舍）。”他的眼睛瞪大了。“哇。我想我们找到了那个正确的`Jared`。斯科特和这家伙从三个月前开始就进行了一场单方面的短信战。`Jared`对任何挑衅短信都没有回应，不过我并不怪他。这太太丑了。在这一切之前，他们之间的短信似乎是和工作相关的。”



“那`Jared Fisher`是个同事。这就能解释他是如何接近`Mandi`的，以及斯科特是如何发现这件事的。”

“而且斯科特的妻子竟然在他眼皮子底下和同事出轨，这倒也是种讽刺的报应。听起来熟悉吗？”

“`太`熟悉了。继续找。”

皮特又翻看了一些短信，时不时做个鬼脸。“除了发给妻子和她情人的短信，斯科特给其他所有人的短信都很正常。他跟朋友之间有很多幼稚的直男对话，工作内容，还有几条给父母和兄弟的，之类的。但在过去的两周里，斯科特和哥们儿或家人的互动少了很多。他关于工作的短信变短了，也没那么随性。过去这一周除了给妻子和`Jared`发愤怒短信外，几乎没发过其他短信。”

“如果他陷入了某种困境，无论是财务、婚姻、工作还是这些因素的结合，他对每个人变得易躁并疏远朋友是正常的人类反应。”

“对。检查一下他的社交媒体账号怎么样——我记得你开车来这儿看其中几个时恶心作呕。你觉得他是不是外面有个不稳定的外遇，然后决定杀了他？”

我耸了耸肩。“我觉得这是一种可能。我没看到任何关于和他那些网恋对象见面的私信。从他们个人资料上列出的地点来看，他的那些网恋都是外地人，但检查一下也无害处。”

“嗯。网恋。你敢打赌其中一些是假装成女孩的老大叔，好让他们能钻进斯科蒂的网裤里？”

“谢谢你给我提供`这种`心理阴影画面。”

他笑着，手臂搭在长椅背上拍了拍我。“抱歉，`Jules`。我只是想活跃一下气氛。我不忍看到你还在为那个混蛋对你做的事而痛苦。我们去聊聊那些失败的哥们儿吧。”

“没什么好说的。我没有和曼迪睡在一起，从来没有。我爱我的妻子。”贾拉德用手抓了抓修剪得昂贵的头发。

噢，没错，他绝对是个出轨男。

这种发诚的“我爱我的妻子”的策略一直是出轨者的第一道防线。当玛雅在我刚开始为你工作时告诉我这件事时，我曾以为是个玩笑，但该的是，我很快自己发现，丈夫出轨得越频繁，对妻子的爱表白得就越响亮。

他继续说道：“几个月前我遇到过这种事。她在工作中主动搭讪我，我拒绝了。我把这一切都告诉了妻子，但我尽量在公司保持低调，以免影响我们的工作。”

“这样她的丈夫就不会发现并来找你算账了？”皮特问。

“是的，我想这也是一个担心的问题。不知道怎么的，他脑子里认定我们真的发生过偷情，他在办公室里让我的生活变得极度痛苦。坦率地说，他疯了。”

“所以你不会说看到他被开除感到难过？”我问。

“并不特别。事实上，他丢掉工作部分是因为他对我出的威胁。”

皮特推了推我。

我问：“他威胁过你以外的人吗？比如你那可爱的家人？”

贾拉德的脸因为愤怒而变得苍。“我明白你想表达什么。所以为了回答你那个隐晦的问题——不，我没有为了杀死斯特来防止他威胁我和我的家人。”他站了起来，“我觉得你们该离开了。”

当他送我们出门时，我转过头问：“你昨晚晚在哪儿？”

他咬着牙回答道：“我在路易维尔招待客户。如果你不信我，可以去问我的雇主。”

贾拉德站在门廊上皱着脸盯着我们，直到我们坐进皮特的车离去。

皮特谨慎地开口：“嗯，朱尔，下次也许可以把火药调低一点？”

我重重地吐出一口憋了的气。“抱歉。我只是意识到，我真的很不想再去挖掘斯特的生活了。”

他停下车，握住我的手。“我们不必这样做。我们可以回家，面对明尼苏波利警察局（MNPD）想对我们提出的任何指控——一起。也许并不会那么糟。”

我笑着说：“你愿意冒再次被关进监狱的风险，就为了让我不用忍受几次尴尬的对话？”

“愿意。”

我感到浑身暖流。“好吧，那就这样定了。我会拿出女人的气概来完成这项调查。但仅仅是因为我再也不想看到你——或者我——再入大牢。”

他咯笑道。“我的提议依然有效，但我很高兴你想坚持下去。监狱可不是开玩笑的。那里无聊透了，而且我决定生活中没有什么比在一群大汉面前公开拉大便更严重的耻辱了。”

我呻吟着，抽开了手。“你比我认识的任何人都更会破坏气氛。”

## 第八章

斯特最好的哥们丹尼尔·史蒂文森不在家里。他也没有接皮特和我拨向斯特联系人中列出的那个电话。在和斯特相处的这些年里，我对他很了解，但当然，在那场分手的灾难中他站在了斯特那一边，所以从那时起我们就没有联系。我不确定他是否愿意和我交谈。

当我们开车去找名单上的下一个人时，皮特有了一个主意。“用斯特的手机打给他。”

“呃。不。太变态了。”

“怎么？也许那家伙看到熟悉的号码会接听。”

“早安，格特，”他说，手在柜台上敲击着。

“你今天早上心情真不错，”她评论道。

他向我眨眨眼。“那是因为我今晚有一个火辣约会。”

这一次，我不得不转过身去掩盖涌遍满脸的热浪。我把咖啡壶放在加热器上，试着在回到柜台前调整好情绪。

“你正看着她呢，”皮特回答道，声音溢满了幸福，“嗯，某种吧。”

我吸了一口气转过头，发现他们都在盯着我。我挥了挥小手。“我是那个幸运女孩。”

“噢，真是该是时候了，”这是她唯一的回答，尽管她正笑得合不拢嘴。格蒂一直希望我们在一起，她对此并不害羞，还经常向我们提起。

在那之后，我的局促感消失了，我们三个人像每天早晨一样聊天大笑。我觉得今天会是很棒的一天。我的手机在口袋里震动。那是一个我不熟悉的号码，但从区号和前缀来看，我假设那是利伯蒂（Liberty）的一个人。

我道了歉，走到柜台边缘接电话。“喂？”

“朱丽叶？”一个女声音问道。

“是的。”

“嗨，我是莉兹·哈特·摩根。贝塞尼·麦库尔给了我你的号码。希望这没关系。”

我想我晚后得和贝塞尼谈谈她给出我号码的事，尤其是给她的同事，于是回答道：“抱歉，对于……嗯，任何事，我都没有评论。”

“噢，我不是在为《编年史》（Chronicle）要独家采访。我只是这里一个卑微的校对。我打电话是因为我有些消息，我想你可能想听。曼迪·奥马利失踪了。”

# 第 13 章

我挥了挥手引起皮特的注意，示意他跟我回办公室。在路上，我说：“莉兹，你介意我开免提吗，让我的，嗯，伴侣也能听到这个？”

“没问题，”她回答道。

当皮特在我们身后关门时，我切换到了免提。我对他说：“这是瑞恩的姐姐，莉兹。她说曼迪失踪了。”

他的眉毛挑了起来。“又？”

莉兹问：“你刚说‘又’吗？”

我回答道：“是的。她去世的丈夫斯蒂一直以为她上个周末失踪了一段时间。他一定是搞混了，因为事实证明她并没有真的失踪。”我踮起脚在皮特的耳边低声说，“记得她在报社工作，而且和首席调查记者结婚了。什么都别说。”

他点了点头。“嗯，”莉兹说，“斯蒂的妈妈有点是个戏精。你确定她不是因为曼迪没去参加葬礼而故意大惊小怪的？”

皮特转向我，脸色阴沉。“这意味着我所想真的一样吗？”

“意思是，极有可能是斯科特在周六冲进这里大喊曼迪失踪时，他*并不是*像个疯子一样胡言乱语？是的。如果曼迪真的失踪了一段时间，但由于某种原因，她觉得必须对我们隐瞒并撒谎呢？”

他舒了一口气。“如果她处于危险之中，这可能意味着我们关于斯科特意外过量的理论也是**错的**。”

“没错。”

“这意味着当`Detective Delaney`听到这件事时——他会听说的——他可能会有同样的想法，而我们又回到了嫌疑人的名单上。”

“也是如此。”

“我们打算怎么处理？”

我做了一个鬼脸。“打算再来一次公路旅行吗？”



他叹了口气，走向桌子，开始摆弄那个吉他形状的音乐盒，那是我从斯科特那里抢回来的。我把它摆在桌子上，是因为我在这里比在我的公寓里更能看到它。“我很抱歉，朱莉斯，但我现在没法请假。我这周会有大笔的乡村音乐版税入账，我必须在场。”

“我知道你忙。我是个大人了。我会自己去的。”

他转过身，脸上的忧虑锁住了眉头。“我也不喜欢这个主意。”

门口传来敲门声。当我打开门时，莱德站在那里，表情和皮特差不多。他说：“我在`Liberty PD`的线人刚刚告诉我，有人报了关于曼迪·奥马利的失踪报告。”

皮特和我异口同声道：“我们知道。”

莱德说：“坏消息传得快。你们觉得这让斯科特的死有了新的解释吗？或者你们认为这又是另一个关于他妻子行踪的误导信息？”

我叹了口气。“我们正要讨论这个。”

“我觉得你俩应该在去利伯的路上讨论一下。”

他愿意帮忙的意让我非常感动。“谢谢你的提议，但这是我的战斗。你不必掺进来。”

“我不想看到你因为你没做过的事而被我的那些同事们骚扰。”

“这可能又是一次徒劳功。”

他耸耸肩回答道：“也许吧。或者这么想吧——如果那个女人真的失踪了，也许我们可以帮上忙。如果没有，那么进行调查对你来说也是很好的练习，对我来说今天也有事可做了。”

“如果你觉得去一趟利伯会有趣，那你一定是无聊透极了。”

皮特插话道：“朱莉斯，既然你现在有了支援，我完全支持。如果曼迪真的发生了什么事，警察会重新审视斯科特的案件，这可能意味着给我们带来更多头疼。罗达可以在这里守着，我今晚就不去凑了。去做你该做的事吧。”

我点头，知道他们都是对的。“好。这意味着我们要公路旅行了。”

莱德笑了。“出发吧。”

等莱德出门后，皮特抓住了我的手臂。“要安全点，好吗？不要承担任何不必要的风险。”

我咧笑着。“我什么时候做过那种事？”

他把我拉近了。“我是认真的。快点回来。”他向我倾身，在我脸颊轻轻吻了一下，这足以让我感到一阵酥麻的颤栗。

“我会的，”我回答道。我拿起手包和斯科特的平板电脑，我之前把它藏在`Java Jive`的保险箱里，因为我不知道该怎么处理它。给皮特挥了挥手后，我赶紧追上莱德，他离走廊尽头并没有我预想的那么远。“我开车，”我说，伸手去拿钥匙。

“不，我来。”

“嘿，你这可是帮了我大忙了。我起码可以开车。”

他为我推开了咖啡馆的前门。“不用，谢谢。”

“为什么不？”

“你是个糟糕的司机。”

我在停车场停下，盯着他看。“什么？我*不是*。”

“你就是，你完全是。你知道你每次握住方向盘会违反多少条交通法吗？你超速，不在停止标志处停车，在错误的一侧超越，而且每次我坐你的车，你通常都会把我吓得半死。上次你载我去某个地方，我本可以给你开七张罚单。”

“七张罚单？随便吧。你是个白领犯罪侦探，又不是田纳西州版的`CHiPs`。你上一次拦截别人是什么时候？你可能甚至都不会操作雷达枪。”

“也许不会，但我可以过去看到你的速度表。”他打开他车的副驾驶门。“上来。”

“行吧，”我哼了一声，心里暗自庆幸不用开车。莱德跟我一起坐车时会没完没了地抱怨，过去几个月里因为他受伤，这种情况下更多。在去印第安纳的路上一路上听他的唠叨也不是什么坏事。

“我送你回公寓，这样你可以收拾一个过夜包。”

我皱了脸。“过夜？我们要呆那么久吗？谁来帮你照顾麦克斯？”

好吧，现在我感觉很糟糕。在我的内心深处，我从不相信库珀会坏到破坏我的公寓，尽管时机和动机看起来完全合情合理。更糟糕的是，既然不是库珀干的，说明外面还有人为了完全不同的原因闯入此处，而我完全不知道那个理由是什么。

莱德并不像我这样坚信库珀是无辜的。“昨晚朱丽叶表演完后你去哪儿了？”

“我给几个哥们打了电话，让他们在市中心见我。我们关掉了一家酒吧，我两点左右回这里。如果你不信我，可以去问问他们。”

莱德想说些什么，但我打断了他。“这没必要，库珀。我相信你。我很抱歉指责了你。”

为了留住一点尊严，库珀理了理皱皱的 T 恤，一言不发地出了门。

我对着莱德皱起眉。“你非得对他用这种坏警察那一招吗？”

他无视了我的话，忙着在我的客厅里转转，检查损坏情况。过了一会儿，他说：“如果你的男玩偶没干这事，我真担心是谁干的。你昨晚为什么不报警？”

“我以为我知道是谁干的。而且，我没被抢劫。我的电视和珠宝都在这儿。我带着吉他，笔记本电脑在`Java Jive`。除了这些，我没别的东西可以被偷了。”

“如果没有什么值钱的东西被偷，那要么有人在传递信息，要么是在寻找某种东西。你最近得罪了谁？”

“只有库珀。可能还有利伯蒂的几个人。但谁会大老远跑过来就为了我问了几个尴尬的问题向我报仇？”

“一个觉得你查得太近的人。你和谁进行过尴尬谈话？”

“首先是曼迪。但我想，如果她这次真的被绑架了，她可能会有不在场证明。还有她的情人贾德·菲舍尔，基本上把我从他家里赶了出来。”

“看来我们在这堆乱麻中找到了第一个可靠的嫌疑人。”

# 第 14 章

莱德和我在前往利伯蒂的路上制定了当天的计划。我们决定从曼迪的家开始。当我们停在路边时，那个地方看起来和皮特和我本周早些时候在这里时一模一样。看起来没有任何异样，尽管其中一个住户死了，另一个则消失得无影无踪。

我们下车开始环顾。我希望自己没有那么快就交出斯科特的钥匙，但我没料到莱德会同意非法闯入，所以无论如何那都是没意义。

莱德透过车库门上小小的装饰窗向里看。“里面有一辆车。”

“一定是曼迪的，因为斯科特的可能还在纳什维尔。”

莱德走到正门口敲了敲门并等待。“曼迪？曼迪·奥马利？我是莱德·汉密尔警探。请开门好吗？”他转向我。“既然车还在这里，如果她是自愿离开，要么是在步行范围内，要么就是有人开车送她。但你说斯科特的妈妈叫的人没人知道在哪儿？”

“没错。不过有两个问题。曼迪是个马拉松运动员——真正的实力派。我想她参加过波士顿马拉松。所以，对她来说‘步行距离’大概是 26 英里。而且，斯科特的妈妈可能并不认识她儿媳的所有朋友，尤其是如果其中一个是她的情人。我觉得我们需要去查查贾德·菲舍尔。”

“没问题。”

当我们走在两片盛满色彩斑斓秋菊、修剪整齐的花坛之间的行道上，我说：“我在想银杉制药公司是否会理我们。”银杉制药办公室位于市郊一个新办公园区综合体内的众多办公室之一。

“他们为什么不理我们？”莱德问。

“我们在这里没有影响力。你没有管辖权，而在印第安纳州，我的田纳西州私家侦探执照跟纸都不值钱。”

他笑了笑，为我开着门。“我赌办公室里那群穿西装的人不知道这一点。我绝不会告诉他们这些。”

银杉制药的办公室在二楼，所以我们乘电梯上去，只需沿走廊走一小段路。当我们推开门时，一个和曼迪一样漂亮的年轻接待员从办公桌前抬头问：“请问有什么可以帮您的吗？”

莱德向她展示了警徽，动作快到让她没注意到上面写着：`metropolitan nashville police department`（纳什维尔大都会警察局）。然后他露出了招牌式的性感微笑。“我希望如此。我是莱德·汉密尔警探，这是我的搭档朱丽叶·兰格。我们来见见贾德·菲舍尔。”

她给了他一个抱歉的微笑。“抱歉，警探。贾德今天上午外勤去了。”

我脑中一闪，绞尽脑汁想那个我读过的那封给斯科特邮件的人。“也许和经理谈谈会有帮助……”名字终于响起来了。“道格·麦凯在吗？”

当接待员匆忙离开办公桌去叫道格·麦凯时，莱德低声说：“你那名字是从哪个屁股里掏出来的？”

“斯科特上周收到一封语气严厉的邮件，”我回答道，“我需要知道他最近有没有和谁联系过。”

莱德看着我。“我们会知道的。”

接待员带着道格·麦凯回来了。“麦凯先生准备好了。”

麦凯叹了口气回答道：“可能没什么，但当曼迪昨天下午跑完业务回到办公室时，她看起来……很难过。甚至很动摇。我当时正去茶水间拿咖啡，看到她哭着躲进了女洗手间。”

我问：“你查出是怎么什么事了吗？”

他摇了摇头。“我……我以为这和她丈夫的去世有关。对我来说，她可能会崩溃是完全正常的，尤其是刚开始来这里的时候。”

“换句话说，你什么都没有尝试去安慰一个刚刚失去丈夫的员工——一个同类的人类。”

“这个，没有……但是——”

“你知道的，麦凯先生，当我的员工明显很难过时，我会尝试帮助他们。你不觉得这是你作为经理工作的重要部分吗？要确保你监管的员工过得还好？”

莱德用手抹了把脸，试图掩住脸上呼之欲出的冷笑意。

从麦凯额头上渗出的汗珠来看，我判断自己触碰到他的神经了。“我的工作不是每次办公室里有女人哭泣我就得担心，”他大声反驳道。

莱德低声咕哝道：“这招下错了，伙计。”

我盯着麦凯。“哇。一个厌女者。我最喜欢的类型。”

麦凯在我的目光下缩了缩脖。

我继续道：“我们还需要你核实一下曼迪上周五和周六在哪儿。她说她去外地出差了。对吗？”

麦凯抓起鼠标点了几次，皱着眉头看着电脑屏幕。“是的，从周五下午到周六中午左右，她一直都在纳什维尔。”

这条信息证实了她和斯科特告诉我的话。这同时也说明了，在斯科特去世后的几小时内，她就在斯科特附近，这令人不安。

“你知道她周六几回到镇上的吗？”我问。

他再次盯着屏幕。“她在路易斯维尔停下来和几个客户吃晚饭，所以时间会很晚。”

莱德说：“我想你不会给我们提供那些客户的名字好让我们核实一下吧？”

“不，没有搜查令不行。但你可以和贾德·费舍尔谈谈，我们的另一位代表。他也参加了那顿晚餐。”

太巧了。曼迪的男朋友是唯一能就她丈夫去世时的她的不在场证明与我们交谈的人。真方便。

我说：“我们来谈谈斯科特·奥马利。你给他发了一封警告函，不让他再进入大楼。到底是什么促使你威胁要刑事指控的？”

麦凯松了松领带。“他失控了。他会冲进来，大吼大闹说要毁掉这个地方。我以为他可能会进来伤害人，所以我不得不采取果断的行动。”

莱德问：“他真的因为失去工作而气成那种程度吗？”

“他当时完全疯了。作为经理，我是那个负责解雇他的人。让我告诉你，那可不是一次愉快的会面。在我告诉他他的聘用终止——并给出了充分的理由之后——他开始大喊，乱说着各种疯狂的话。”

“些什么疯狂的话？”

麦凯停顿了一下，目光移开。“噢，只是一些胡语而已。”

“全都是胡语？你一个字也听不出来吗？”我问。

麦凯的脸涨红了。“大意就是他对丢工作感到难过。他变得非常好斗，我立刻让保安人员把他护送出去，没让他得及伤害任何人的机会。”

“或者没得及偷更多药物的机会？”莱德问，“那是他被解雇的原因之一，对吧？”

麦凯皱着脸回答道：“是的。他就在我们眼皮底下从其他代表的包里偷样品。现在有几十份样品没法交代。”

“具体是什么药？”我问。

“多巴胺、苯二卓西类和 H2 受体阻剂。”

“请用大白话翻译。”

麦凯制止了翻白眼的动作，只是勉强忍住。“多巴胺用于治疗帕金森病，苯二卓西类是抗焦虑药物，H2 受体阻剂缓解胃热。噢，还有一位当地神经科医生抱怨，上周早些时候在斯科特突然给他办公室打电话后，他发现丢了一些乙酸钠。乙酸钠是用来治疗嗜睡症的药物。银杉林公司不生产这种药，所以我猜这就是为什么斯科特不得不找其他办法获取它。”

“你知道为什么斯科特会偷那些特定的药物吗？”

麦凯耸耸肩回答道：“代表总是存在决定从公司拿药并在黑市出售的风险。现在的药太贵了，人们被迫转而寻找其他渠道。”

我想起早些从丹尼尔那里收到的短信，坐直了身子。“你是说给回扣吗？”也许斯考特确实发现了什么端倪。

“是的。在最近一次打击之前，回扣是行业内一个严重的问题。代表们会发放各种东西，包括性便利。现在，除了药物样品本身，代表们不被允许发放信息手册以外的任何东西。即使是像纸巾盒、鼠标垫之类的廉价物品也不行。迪隆认为银杉松并没有遵守新规矩。”

我问道：“他们以前都发什么东西？”

“个人礼物，比如高尔夫球包或昂贵的酒。笔记本电脑、办公用品。有时还有医疗用品。旅行、昂贵的晚餐。妓女。任何可能让医生们惊艳的东西。”

“也许有设计师领带、袖扣和耳环？”

“绝对有。”

“你丈夫有证明银杉松还在发放这些赠品吗？”我有证据——或者至少我知道某些证据在哪里。曼迪的工作公文提包里装满了我列举的那些不再被允许接受的赠品。

“从技术上来说不是。医生们并没有在抱怨收到免费东西，而且当然，银杉松的员工没有人会自揭身份。镇上某位医生的前前台接待告诉迪隆，她见过礼物易手交易。但她是不愉快地被解雇的，所以我们不知道她的信誉如何。此外，最近几个月来突然有几位医生不让绿地的代表进门。”

我耸耸肩说：“也许他们厌倦了和销售打交道。”

朱莉亚皱起眉。“迪隆最初认为有可能是这种情况。但随后他和同事们开始看到医生们和银杉松的代表一起出去派对，戴着新的手表和领带。不久前，其中一个医生被抓到和妓女在一起。那个案较难与银杉松联系起来，但迪隆认为他们不排除这种可能。”

“这些弹药足够你写一篇文章了吗？”

朱莉亚似乎只有推测。我开始对那些银杉松的代表和医生们感到同情，因为我知道《编年史》上一篇刻薄的文章（无论真假）会对这个城市的商业声誉造成什么样的打击。

她叹了口气。“没有，但我们希望你能为此提供帮助。”

我在心里哀鸣着。我知道会有这一刻的。“我？”

朱莉亚皱着眉说：“如果你在调查斯考特的死，你一定和他工作的人谈过。”

“我谈过了，”我只能这样回答。

莉兹插进来：“既然你对所有参与者都很熟悉，而且是从相反的角度切入——就像布莱克一样，他正在写一篇关于曼迪失踪的文章——我们希望可以通过整合资源来互相帮助。”

我很确定她那句意思是整合我们的信息。

我说：“我最大的问题是——你们为什么认为回扣和斯考特有关？”

一直保持沉默的布莱克插道。“鉴于回扣问题似乎正在升级，银杉松的一名员工这周去世了，他的妻子失踪了，我们认为这很合理。”

朱莉亚亮了起来。“所以回扣的事是真的。但我们如何证明它？你有照片吗？”

我摇了摇头。“没有。而且如果不是从丹尼尔那里听说的，我可能不会给这个理论任何价值。但现在我有了更多拼图碎片，它开始变得合情合理。”

我吐了一口气，准备好和这些家伙在一起。我准备好付出一切努力来彻底解决这个问题。“好。我们可以合作。”

布莱克缓缓点头，说道：“没错，因为如果他参与了其中，他就不会威胁银杉杉公司（Silver Spruce），说他会因为这事毁了他们。”

“可能吧。现在，我没法知道这是否与我们讨论的任何事情有关，或者斯特是否也参与了另一桩下当交易。但他死前设告诉我的一件事是，他从他口中某些‘危险人物’那里拿了了东西。”

“你是指他偷的那些药物吗？”

“我不知道。他说由于他所做的事，那些人多次威胁过他。他来找我是因为他坚信他们绑架了曼迪（Mandi），如果他去报警，他们就会杀了她。然而，第二天我在家里发现曼迪正完好无事地活着，她说自己是去出差了，并坚持说斯特是因为吃了太多药快疯了。我不确定该信哪一个。但考虑到这些反常的情况——以及对斯特被谋杀的挥之不去的感觉——我认为我们需要开始调查银杉杉公司，看看这桩回扣交易是否值得为了它杀人或绑架。”

莉莉皱了皱鼻子。“但如果曼迪也参与了，她为什么要被绑架或受到威胁呢？”

我皱着眉回答道：“看，这就是我觉得最不合逻辑的地方。我不明白曼迪为什么会参与其中。”

朱莉亚说：“所以我们需要找到曼迪。”

“即使我们找到了，可能也无法从她那里得到真相。我认为我们应该从查出是谁在给回扣、以及是谁在收回扣开始。”

布莱克说：“既然你发现了曼迪的藏钱处，我们可以假设至少她的部分客户中有人在拿回扣。”

“是的，而且既然曼迪还在培训中，我们是否也可以假设她的导师贾瑞德·菲舍尔（Jared Fisher）也参与了其中？”我问。

朱莉亚点头说道：“如果由他在训练她，我怀疑他一定参与了，或者至少察觉到了某些阴暗的事情发生。”

“顺便说一下，贾瑞德·菲舍尔今天也失踪了。莱德（Ryder）和我今天早上在镇上到处找他，但他无处无踪。根据办公室的八卦，曼迪和贾瑞德有私情，所以这也有可能。”

布莱克看起来很兴奋，由于不安地坐动着。“这个案子每分钟都变得更有趣了。我喜欢这种错综复杂的。”

我讨厌讨厌这种错综复杂的。“这个案子现在的参与者太多了。从给医生提供回扣的代表，到收回扣的医生，再到银杉杉的高层，任何人都可能通过让斯特来获利。我们需要开始排除这些人。我认为我们今天下午分头去见几位医生。我想在再次与任何银杉杉代表交话之前等一下。我不想让他们觉得我们把注意力转到了他们身上。朱莉亚，你丈夫能帮我们要一份曾和银杉杉代表一起露面的医生名单吗？还有其他他怀疑可能在拿回扣的人？”

“没问题。”她拿出手机，快速发了条短信。

我站起来，突然想起我掌握着一个关键信息。“我去设弄一份银杉杉公司当地客户的名单。”

布莱克皱起眉。“你认为银杉杉会直接把那个交给你吗？还是说你有什么留着自己的内部线人？”

我眨了眨眼回答道：“我会告诉你，但那样我就得杀你了。”

***

我发现莱德在汽车修理店外踱步，修理店离镇广场的《纪事报》（*Chronicle*）办公室只有几个街之遥。

“进展如何？”我温柔地问，从他僵硬的姿态和习惯性的白眼中就知道答案。

“这些笨蛋在同一时间吃午饭，所以所有工作都停了。他们甚至还没开始修我的车，”他气愤道。

我忍不禁。“行了。这里的节奏比你习惯的要慢一点。这里的老实人可不像你们这些城里男孩那样急躁。”

“你是怎么在这里在这里了这么久的？”

我忽略了他的问题，说道：“如果他们去吃午饭了，你为什么不去呢？”

“我气得吃不下饭。”

“不，你不是。你是饿极了（hangry）。你已经在生气了，而且过了午饭时间，这让你变得脾气暴躁，所以一切都像雪球一样。如果我们不给你吃点东西，你可能会爆炸的。”

他的嘴角上扬了。“你怎么这么了解我？”

我轻笑道。“经验。此外，男人只有两个基本需求——食物和性。我猜对的概率有百分五十。”

“那是性别歧视的态度。”

“你说我是错。”当他没想出反驳理由时，我换了话题。“我需要从你的后备箱里拿东西。”

他指了指停在店停车场里的车，我们朝那个方向走去。“你从那些新朋友那里发现了什么？”

我取出了塞在我包里的莱德那套备用车钥匙，打开后备箱，翻找我的一夜包找到了斯特的平板。“长话。等午饭时我告诉你。好消息是，我们有一些线索。坏消息是，线索有很多。”

# 第 17 章

莱德和我穿过广场回到萨姆酒馆（Sam’s Tavern）。我们吃饭时，我向莱德介绍了我学的一切。

“我们需要找到曼迪，”莱德说。

“还有贾瑞德·菲舍尔，”朱莉亚补充道。

“我觉得她惹麻烦了，”我回答道。“我们要回办公室了。”

我的手机响了。看到皮特的名字，我的烦躁感消失了。“我要接一下电话，”我喊道。

“嘿，朱莉，”他气喘吁吁地说。“嘿，朱莉。希望你不介意我边吃饭边说话。我有三分钟吃午饭，然后就得回录音室。我们今天合作的那个尖酸女星不吃，所以她也不要求别人吃。”

我笑了，很高兴能想些案子之外的事。“噢，她听起来很有趣。”

我犹豫了。告诉他今天早晨发生的事只会让他担心，而且事情已经结束了，我们现在很好。“嗯，进展得还可以。今天早上没取得什么突破，但我们对下午有了计划。”

“找到曼迪了吗？”

“还没有。她的男朋友也无处不踪。”

“我敢打赌他们私私私跑路了。”

我笑了笑。“我就是这么说的。”

皮特呻吟了一声。“噢，该死。‘妈王’回来了。我得走了。等会儿回电话给你。”

“好的，玩得开心。”

“朱尔斯？”

“怎么？”

“小心点。”

“我会的。”

我挂了电话回到萨姆店里，结果发现莱德还在那里坏笑。“怎么了？”我问。

“你确实很喜欢他。非常喜欢。”

“什么？谁？”

“皮特。电话是他打来的，对吧？”

是时候再次转移话题了。我绝不可能一边谈论我对皮特的感情（而且还是在莱德面前），一边还指望能成功完成对我未婚夫谋杀案的调查。这对任何人来说都要求过高了。“是的，既然他是我的死党，我难道不应该喜欢他吗？”

莱德摇了摇头。“你懂我的意思。”

“我们这儿结束了吗？”我指指空盘子问。

“噢，我才刚开始。你没发现你跟他说话时在咯咯笑吗？”

我咬着牙说：“我不咯咯笑。”

“你确实在咯咯笑。”他朝餐厅前方点了点头。“我透过窗户看到你了。”

我站起身，往桌上丢了一些钱。“我们正在浪费光阴，侦探。”

他耸了耸肩，站起来也自己丢了一些现金。“好的，女士。”

***

朱莉亚的丈夫列出了六个他认为可能收回扣的医生，她把这些名字发给了我。我们决定平分他们，每个小组（莱德/我，布莱克/莉莉/朱莉亚）负责三个。我从斯科特的电脑上给朱莉亚发送了银杉镇（Silver Spruce）客户的总名单，希望在我们用完她的名单后，她可能对尝试找谁有个主意。

当莱德和我到达理德森博士的办公室时，我们发现他正在休长午假，也就是打高尔夫，晚些时候回来看今天剩下的患者。名单上的另一位医生德沃博士在同一栋建筑里也有办公室。这是一场我并不期待的访谈。德沃博士直到我十岁时一直是我的儿科医生。他曾做过一次严重的误诊，坚持认为我患了持续几周的流感，而实际上我是被蜱虫咬后感染了莱姆病。不用说，我父母对他失去了信心，并为我找了另一位医生，并确保在事后让德沃博士知道对他的看法。

我们走进去时，德沃博士没空和我们说话，所以莱德和我不得不在一个候诊室里坐了似乎好几个小时，那里里挤满了满容憔悴的妈妈和流着鼻涕、患有婴儿性咳嗽的孩子。对我来说，那个地方简直是地狱，不仅是因为它勾起了我童年看医的糟糕回忆。奇怪的是，莱德神如如醉地看着孩子们跑跑嬉闹，当他们有时（简直是恐之又恐）停下来用脏兮兮的手碰我们，然后抬头发现我们不是妈妈或爸爸时，他露出了笑意。

我俯身对他低声说：“你看起来很享受其中。这怎么了？”

他转看向我，很困惑。“这些小家伙可爱极了。你不觉得吗？”

“不。”

“噢，对。你是那个不想生孩子的人。”

“是我。”

“为什么不要呢？”

看着一个小男孩抓住妈妈的裙角，用它擦掉流了一出来的鼻涕，我不禁作了一口作呕。“我在工作中已经接触了够恶心的东西了。我不想在家里也弄这些。”

“他们很快就会度过恶心阶段的。”

“然后他们会进入烦人的问题阶段，接着是阴郁的青少年阶段——”

“我觉得你跳过了中间的几个阶段。”

“看到吧？我对比孩子一无所知。我不生自己的孩子简直是在为世界尽忙。”

他忍着笑问道：“皮特怎么看你的反孩子倾向？”

我耸了耸肩。“他知道。”

“然后呢？”

“然后我知道你正试图把我们的谈话引向另一个窥探我私生活的机会。住手，否则你就轮到去坐那边那把禁闭椅上了。”我用拇指指了指角落里坐在小椅子上的一个脸脸脸女孩。她刚刚无缘无故打了她弟弟，所以他们妈妈在候诊室里设了一个临时的惩罚区。

“汉密尔顿侦探，兰格小姐，德沃博士现在可以见你们了。”

莱德没有错过，当接待员叫出“汉密尔顿侦探”时，房间里的每个男孩都转头赞慕地盯着他。我没没到莱德在孩子问题上是个这么软的人。

德沃博士在办公室里等我们。当我们推门而入时，他抬头，立刻认出了我。我好奇他是否还记得我妈妈打给他的那通愤怒电话，告诉她他对那个虚假诊断的看法。“小朱莉亚·兰格。你长大了。”

莱德和我走出了他的办公室，不得不穿过人群才呼吸到新鲜空气。



莱德问：“你刚才为什么要揪着他不放？”

“我正试着让他招供收回扣的事。”

他给了我一个困惑的眼神。“你把你的理论建立在他身上？那包包他在哪儿都能买到。”

“不是的。在这一带买不到那种名牌包。那是博伯利。我不知道你有没有听说过，现在有一种叫作互联网的酷炫东西。你可以在世界上任何地方买东西，然后让他们寄给你。”我在上车时低吼了一句，“闭嘴。如果他是在网上买的，他为什么要撒谎是在商场买的？我在这件事上是对的。”

莱德启动引擎，说道：“你的理论还是站不住脚。他是个医生，我确定他付得起，或者类似的钱。”

“第一，他是一个小镇上的儿科医生，那里每个人都有保险。他的收入很可观，但还没到富得流油的地步，不够花几百美元买一个博伯利。”

“随你怎么说，朱丽特。”

“我打算假装没听到那句话并继续下去。第三，我在曼迪家里看到了那个完全一模一样的包，还有好几个类似的。包是从她那儿来的。”他皱起眉。“你是怎么弄到曼迪工作用的那个包的？”

噢，糟。当我告诉他我之前去利伯蒂（Liberty）的旅行时，我隐瞒了彼特和我闯入曼迪家的事实。我只是告诉莱德我和她通过话。当我没回答时，他揉了揉山根，这说明我快耗尽了他的最后一点耐心。“告诉我你没偷她的东西。”我也没法说我没偷她的东西。“我没偷她的包。”

“继续说。统统说出来。”

当彼特和我去她家里时，我看了包内部。现在他紧紧锁着牙关。他不喜欢我含糊其辞。“你到底做了什么？”

我叹了口气。“我们那个……我们自己溜进了她家。因为你知道的，我们手里有斯科特的提包，里面有房子钥匙。我找到了她的包并翻找了。”

他猛地把车停在路边，我猜他是想把所有的怒火都发在我身上。“先是斯科特的包，然后是平板电脑，现在又是非法闯入和搜查别人的家？你到底在想什么？”他咆哮道。

“我和彼特都是嫌疑人，我们需要证明自己的清白。”

“得了，朱丽特。作为一个私家侦探，你应该知道不要玩这种业余把戏。”我皱起眉。“嘿，你以前在调查中也用过创意手段。”

“我们现在不是在说我。是在说你。你可能会因为这周干的蠢事被捕，现在也可能被捕。”

“总比因为一起我没犯的谋杀案被捕好。”他还在发气，但他承认道：“好吧，至少你没被抓。”关于这一点，我保持了沉默。

# 第 18 章

当我们到达下一个目的地时，莱德已经冷静下来，至少能和我进行文明的对话了。他准备下车，但我把手按在他的手臂上。“考虑到直接攻势对德沃医生（Dr. Devaux）效果并不好，你觉得我们能不能对格兰塔姆医生（Dr. Grantham）尝试不同的方法？”

“你想怎么做？”他问。

“嗯，格兰塔姆医生是个四十岁的离婚女性，正在寻找第四个丈夫。也许是时候祭出塞斯·戴斯（Seth Davis）和他的魅力了。我听说他很擅长赢得女性的心。”

那个目光又回来了。塞斯·戴斯是我们第一次见面时莱德最初给我的名字，因为他当时正在卧底工作。我最后自己查出了他的真名，这无疑在我们本就火星烹油的关系中引起了波澜。每当我想在诚实问题上刺他时，往往会提起这件事。

“塞斯·戴斯能从她那里得到汉密尔顿探员勋章给不了的东西？”我耸耸肩。“也许是一个直接的回答。我在想你可以假装一个医药代表，试图赢得她的好感。”

“用什么？我没什么可以送给她。”

“你完全可以给她一张晚宴邀请函，并不含蓄地暗示更多的关系。”他皱起眉。“我说过我会帮你调查，不是让你替团队背锅。而且，我觉得玛雅（Maya）不会喜欢我那样做。”

“我不是说你必须执行到底。告诉医生你是一个银杉林（Silver Spruce）的新代表就行。”

莱德的声音听起来很紧。“我不是那个——”

“听我说，大个子。我今天行程排得很满，但我保证今晚喝酒时会全神贯注陪你。你觉得晚上八点在`Vecchio's`见怎么样？”

沉默片刻，他回答道：“没问题，医生。”

几分钟后，我看到莱德大步走出办公室，姿态僵硬。他把自己甩进驾驶座并启动汽车，然后冲出了停车场。

“我从没想过会看到——或者说，听过——塞斯·戴维斯在一个女人面前碰钉子。”

他皱起眉。“我今晚不是和她约了会吗？”

“是，但她在其他方面很明确地拒绝了你。很明显，她并不想要推销的东西——当然，除了性以外。”

“而她又得不到。”

我轻笑一声，但在他开车回理查德森博士的办公室时，我保持了沉默。

莱德似乎对约会这件事依然耿耿于怀，刷卡要求立即与理查德森博士会面，他那套硬汉的戏码把可怜的老女接待员吓得半死。不到一分钟，我们进了医生狭小的办公室，我们手里都拿着一瓶冰水，那是那位神经过敏的接待员提供的。

理查德森博士走了进来，满脸笑容，但有些戒备。“今天有什么能帮你们的吗？玛丽说你们和警察在一起？”

莱德点点头。“我们正在调查斯科特·奥马利的死亡。他是一个银杉松——”

医生皱了皱眉。“一个银杉松的代表。我认识他。他从我办公室里偷了一些药。我本该报警的，但那个像地鼠一样的`McKay`恳求我让他内部处理。现在，当然了，那个男人死了，很可能是因为偷的那些药过量导致的，所以他已经受到了足够的惩罚了。”他摇了摇头。“你知道的，这种阴暗、不专业的行为正是我拒绝与银杉松代表会面的原因。我没时间理这些胡闹。如果他们想留下药物样本，就留给我的接待员。他们不再有面见我了。”

我问道：“你注意到银杉松代表除了和斯科特的事件外，还做过其他阴暗的事情吗？”

理查德森博士嫌恶地哼了一声。“我该从何说起？镇上的几个同事医生似乎对银杉松代表喜欢提供的那些小好处印象深刻。单我个人而言，我比他们更有正直。”

莱德说：“所以你知道其他医生在收回扣。”

“在某些人身上这显而易见。比如这栋楼里的某个医生，突然收集了一堆贵领带，其中任何一条都够付他那辆破车的月供了。”

我对着莱德低声说：“早告诉过你了。”

理查德森博士继续道：“还有那些白痴，周末大摇大摆地和他们的代表跑出去喝醉。世界上没有免费的酒。”

“确实如此，”我回答道。“上次斯科特进你办公室时，他表现如何？”

“我本人没见到他。玛丽和他聊过。她说他很无礼且好斗。”

莱德问道：“他是怎么偷走你的药的？”

医生叹了口气。“他坚持要洗手间，那里就在我们的物资室旁边。玛丽，保佑她那老心肠，让他进了这里，尽管即使她想拦，也拦不住他。当天晚些时候，我们发现我放药物样本的柜子被撬了。不需要天才也能看出是谁干的。”

我点了点头，希望理查德森博士能为我们解开斯科特行为之谜。“从你办公室丢失的`sodium oxybate`并不是斯科特被指控偷窃的唯一药物。根据他的经理说，最近其他药物代表的包里也丢失了`levodopa`、`benzodiazepine`和`H2 抑制剂`的样本。使用其中任何药物是否会导致一个人的性格变得特别焦躁和愤怒，甚至可能产生幻觉？”

“绝对会。`levodopa`很容易就能做到。那些是非常常见的副作用。”

“任何这些药物的过量会死人吗？”

“`H2 抑制剂`可能不会，但其他的可能会。将`levodopa`或`苯二唑西平`与`sodium oxybate`混合几乎可以确保死亡。在为睡眠障碍患者配发`sodium oxybate`时，我必须非常小心，以确保他们与其他服用的药物之间不会发生任何相互作用。”

“有人可能摄入这些药物却不知道吗？”

理查德森博士打量着我。“你是问我是否有人可以在不被察觉的情况下把其中任何一种加入别人的食物或饮料中？”

“是的。”

“我想可以。它们都有液态，所以我认为非常简单。”

我瞥了一眼莱德，他正担心地看着我。

莱德转向医生。“感谢你的时间，先生。既然你的接待员处理了斯科特的事，我们在这里想和她谈谈。”

“当然。我让她进来。”理查德森博士走出了门。

莱德低声说：“我知道你还在执着于谋杀案，但斯科特完全可以自己这样做，甚至没有意识到潜在的后果。”

我低声回答：“或者他妻子完全可以轻易毒死他。”

“为什么要在纳什尔做？”

“为了制造不在场证明。你在家里死掉，警察会盯着你妻子；而在你妻子明明在几小时车程的地方，你在另一个地方死掉。”

她笑了笑，脸微微泛红。“他说如果不来，他会非常想念我。理查森博士不介意接受银杉杉的产品，只要不用听他推销就行了。所以，我让贾德把他的样品加入了我们的收藏，这似乎让他觉得很心满意。”

“那贾德除了药物样本，从没在这儿留下过任何东西吗？”

她移开了看向我们的视线。“我不知道你什么意思。”

玛丽给我的印象是一个温顺、老实的老太太。从她穿的那几件不合身的开襟外套、过时的连衣裙和松垮的丝袜来看，她在这里工作并没有赚到大钱。然而，就像戴着波马领带的德沃博士一样，她有一件可能超出她经济能力的高级配饰。

“你戴的那只手镯真漂亮。”

她的手再次颤抖起来。“这是……我女儿圣诞节送给我的。”

赖德捕捉到了我的眼神，微微摇了摇头，示意我们需要退一步。他再次对玛丽露出一个和蔼的微笑。“真好。回到斯考在这里的那个一天，既然他不是你们普通的银杉杉代表，而且跑进这里给你们惹了麻烦，你跟贾德提过吗？”

“当然了。我立刻给他打了电话，他直接就过来道歉了。”

我用脚轻轻顶了顶赖德。

他问：“所以贾德在斯考特离开后就到了这里？”

“是的，他没有浪费时间。他想确保斯考特没有完全破坏银杉杉和这个办公室的关系。”

“你告诉贾德关于斯考特偷了样品的事了吗？”

“没有，我当时并不知道。”

破案了。

我问：“那天贾德带了什么样品过来吗？”

“带了，他这人真好。他带了一些平时不带在身上的新药和昂贵药物。”

我点了点头。“他那样做很体贴。他听起来是个很棒的人。所以他把带过来的样品放在了柜子里，然后就上路了？”

“是这样。他很乐于助人。”

赖德说：“贾德提到过坏掉的柜子吗？”

玛丽的眼睛睁大了。“什么？”

“你说贾德把他那天带的样品放在了柜子里给你。他在斯考特离开后就在这里。所以他一定发现了那个坏掉的柜子。”

她吸了一口气。“噢……噢，当然了。”

我指出：“几分钟前你告诉这儿的侦探是你发现了柜子坏了和样品丢失了。现在你又说贾德是发现它的人。到底是哪一个，玛丽？”

玛丽努力保持镇定，但没能忍住下唇的颤抖。“我……我忘了。毕竟我是个老太婆了。”

赖德温柔地说：“玛丽，贾德是不是在送你礼物——比如你戴的这只手镯——让你对他做的一些事情闭口？也许是关于他知道理查森博士不喜欢的事情？”

一滴泪水顺着她布满皱纹的脸滑落。“他是个好孩子。”

“他偷了丙受酸钠样本，对吧？”

她咽了口唾沫，摇头。“没有。”

“你想让我们把你的老板叫进来再问一遍这个问题吗？”

这下击中了她。她的眼睛里充满了泪水。“求你了，不要。我需要这份工作。我必须工作来养我的孙子们。请不要告诉理查森博士。只要你们想知道的，我什么都说。”

赖德说：“我们想知道是谁拿了丙受酸钠。”

她叹了口气，低声说：“贾德。”

“他让你伪装成是斯考特拿的？”

“有。”

“贾德有没有给过你什么东西让你闭嘴？”

她点了点头，伸出手腕。“这只手镯。”

“他给过你其他东西吗，还是这是第一次？”

玛丽的脸皱在一起。“不是第一次。我的孙女有哮喘，她参加的政府资助保险计划只支付吸入器成本的一半。那是我负担不起的每月百美元。贾德能够免费为我提供她需要的东西，作为他让我确保他在办公室里有一足之地的回报。”

我没料到会看到这种回扣计划的另一面。除了手镯，玛丽并没有像其他受贿者那样从廉价的礼物和好处中获利。她得到的是能救她孙女命的东西。

我吐了一口气。“好了，玛丽。问完最后一个问题后我们就不打扰你了。贾德定在今天来这里。他出现过吗？”

她摇了摇头。“没有。我有点担心，因为他没打电话告诉我他不会来。这不像他的作风。而且，该是他给我的孙女带另一个吸入器了。她上一个快用完了，我们没有备用了。”

在留下玛丽在理查森博士的办公室里静静哭泣后，我们回到了赖德的车上。

“情况不妙，”我说。

“是啊，让你那个可怜的老太太哭了。”

“嘿，你刚才也说对了，哥们儿。我的意思是贾德·菲舍尔极有可能参与了斯考特的死亡。”

“我们需要找到那家伙。现在就。”

# 第 22 章

在填完堆积如山的文件（使用了化名`Leslie Kaufman`，这是玛雅我和每次卧底时都会用的名字），我开始觉得莱德的直接攻法或许是明智之举。但正如“分钟诊所”的名字所言，我们只等了几分钟就看到了医生，我们要求看的是`Dr. Muniz`。带我们回检查室的护士叫我脱掉衣服，但我没有——正如莱德说的那样，不会到那一步的。

环顾着这间陈旧、肮脏的房间，我注意到那里有很多看起来很新的设备——特种灯、除颤器、一台心率监护仪和一台高级电脑。“你发现这里有什么不寻常的吗？”

莱德敲了敲除颤器。“所有的新设备吗？”

“没错。这地方已经存在很久了，而我从未见过它有任何什么先进的设备。我一直听这间诊所随时都会关门大吉。镇上有些全科医生不接受政府提供的保险，所以人们如果没有家庭医生，就得来这里。这地方可不是什么摇钱树。”

“所以这里的医生如果想要好东西，就得拿回扣。”

“我是想——”

“咚，咚。早上好，考夫曼女士，”一个欢快的女性声音响起。一位美丽的年轻女医生走了进来，脸上带着微笑。“我是`Dr. Sophie Miller`。你们今天感觉怎么样？”

“嗯……我以为我是要见`Dr. Muniz`的，”我说。

她示意我坐在检查台上。“抱歉，`Dr. Muniz`正在忙一个病人，我们不想让你等太久。”她看了看我的病历。“噢，看起来我们今天可能会得到一些兴奋的消息。”她转向莱德问道：“你是爸爸吗？”

在候诊室填表单时，我脑中灵光一闪。我打算‘怀上’了斯考特的孩子，这样我就可以为他去世的事实而崩溃，为我们谈论他提供完美的切入点。绝妙的计划，除了我们没有考虑到可能会错医生。

莱德并没有放弃任务，而是坚持了剧本。他摇了摇头，显得很沮丧。“不，是舅舅。舅父亲是……”

好吧，既然他要坚持下去，我也一样。也许我们能从`Doctor Miller`那那里得到点什么，即使她没有直接参与。

我发出一声抽泣。“死了。他*死了*了。”

米勒博士的脸垮了，她飞冲过来用手臂搂住我。“噢，我的亲爱的。听到这个消息我太难过了。我看到你在这里有支持，但请知道，诊所在咨询和其他服务方面可以为你做很多事。”

我吸了吸鼻子。“我确实需要一些咨询，尤其是……自从我的斯考特已经……”我崩溃了，揉着眼睛试图挤出眼泪。

莱德神色严峻地说道：“他被谋杀了。”

米勒博士拍着我的背。“那太糟糕了。我深表哀悼。”

莱德说：“你可能认识他。`Scott O’Malley`。他是`Silver Spruce`的一个医药代表。”

当她的手在我的背上僵住时，我刚好抬头看到她脸上的认出感。

“是的，我认识他。”

如果她认识他，她可能知道他结婚了，这也许是她不安的来源。或者她知道一些我们需要发现的事情。

我说：“如果她认识他，她可能知道他结婚了，这也许是她不安的来源。或者她知道一些我们需要发现的事情。”

我说：“皮特，那是个玩笑。我正在执行一项卧底任务，为了和医生单独待一会儿。”

“那一点也不好笑，朱尔。”

“挺好笑的。”

“不，不好笑。”

“反正，我打电话不是为了让你心烦意乱。我只是打个招呼。”

他的声音柔和了。“嗯，我很高兴你打了。我今晚想见你。”

我收到莱德的一条短信，内容是：`如果你不想做那个宫颈检查，最好现在离开那里。我们稍后和 Muniz 谈。`

我对皮特说：“我也是。我得走了，回头再给你打电话，”然后挂了电话，溜出诊室朝大门匆走去。

我比莱德早几分钟到了他的车旁。我们上了车，他在街上开了一段路才停下来，让我们交换一下情况。

他说：“医生打了两个电话。从听她通话的内容来看，我想第一个电话打给了`Scott`的一个朋友或熟人。她告诉对方，有个病人进来时大喊大道说`Mandi`杀了`Scott`。他们一定问了她的名字，但她没给，尽管她对你和我的外貌都做了描述。之后，她打了报警并做了陈述，这次没有提供任何关于你的其他信息，只称你为‘一位女性患者’。”

我缓缓点头。“嗯。听起来她对`Scott`非常熟悉，以至于知道谁会对杀掉他的人感兴趣。”

莱德耸了耸肩。“那可能是任何一个人。”

“没错。好吧，至少警察有理由开始把`Mandi`视为凶手了。至少起码，这可能会促使他们花点时间去找她，无论怎么看都不是坏事。”

“不，不是的。我觉得这件事进展得还不错，尽管我们还需要尝试追到`Muniz`。我们可以守在那个地方，希望他离开诊所去吃午饭。”

“噢，这正是我今天想做的——坐在闷热的车里外面。”

“比做宫颈检查好。我想是吧。”

“呵。勉强吧。”



他轻笑道。“顺说一下，我觉得你需要练练你的卧底技巧了。刚才那戏简直是过头的肥皂剧演技。”

我低下了头。“我知道很糟。我没法在‘我孩子的爹死了！’和‘你从哪儿弄来这么多酷的新医疗用品？’之间找到一个自然的过渡。”

“这就是为什么我主张简单粗暴的方法。”

我皱了皱鼻子说：“这是不是我得告诉你你是对的，而我是错的地方？”

“是的。没错就是这里。”

我的手机这时响了，是`Lizzie`。我对莱德说：“噢，来得及时。”我开了免提，说：“嘿，`Lizzie`。莱德和我开着免提。”

“嘿，伙计们。我们谈过`Jason Brooks`了。听起来他鼓励代表们私下发放回扣，但`McKay`并不对此感兴趣。不过，由于公司对此相当松懈，而且根据`Jason`的说法，`McKay`是——他的原话——一个‘软蛋经理’，代表们基本上想做什么就做什么，而`McKay`则视而不见。”

莱德笑着对我低声说：“`Jason Brooks`对`McKay`的评价太准确了。”

`Lizzie`继续说道：“还有一个趣事——根据`Jason`的说法，`Scott`并不是偷样本的人，至少在他那里的时候不是。是`Chandra Thomas`。”

“什么？”我惊呼道。“`Chandra`？”

“她的母亲和她住在一起，患帕金森症，那种药物的费用是天文数字。如果这听起来好受一点，她只偷了那种药。总之，`Jason`降了`Chandra`的职，但没有解雇她，也没有因盗窃罪起诉她，因为他知道她是她母亲唯一的照顾者。”

我吐出一口厌恶的息。“甜美的`Chandra`对我们满口谎言。”

“听起来是这样。`Jason`还说他离开时，所有样本都在且记录在，所以`Chandra`在被发现后确实停止了偷窃。”

莱德说：“不错。别的吗？”

“没有了，”`Lizzie`回答。

“好的，我们再说。谢谢，”我说着挂了电话。

莱德皱起眉头。“所以现在又有帕金森药物丢失了，加上抗焦虑和胃胃心药。`Chandra`可能清醒过来了，决定这次更好地掩盖她的盗窃行为，偷了好几类药来分散新老板的注意力。”

“如果是`Chandra`在偷东西，那么药物盗窃和`Scott`的死真的有关系吗？”

“可能没有。”

“那`Jared`从`Dr. Richardson`那里偷氧化丙钠又是呢？”

“可能无关，`Scott`的死只和勒索有关。”

我皱起脸，陷入了深思。“但大家都说`Scott`在用毒。那是怎么回事？”

“你说的‘每个人’是指在整个调查过程中一直在对你撒谎的人吗？”

“加上几个没撒谎的人。”

“买药的地方不止一个，斯鲁比。”

我翻了翻白眼。“你知道，你这套反方观点者的套路已经老了。”

莱德冲我一笑。“这叫客观性，是调查员最好的工具。”

“那么，侦探，你有什么建议？”

没有听到回应，我几乎要转身离开。但我的直觉一阵紧，我觉得自己至少应该看看。我走下摇摇欲坠的阶梯，那股标本味立刻扑面而来。在倒数第二个台阶上，我停下脚步，倒吸了一口气。`Mandi`挂在天花板上的一根金属管上，舌头伸出，眼神呆死，一不动。

# 第 23 章

我忍住哭声，避开了`Mandi`挂在不知是在哪里发现的旧绳子上的景象。她为什么不能再等几分钟呢？我们本可以救她的。结局不该是这样的。

我的脚步重得像铅，但我设法爬回楼梯，正好看到`Ryder`踢开了木屋的大门。在他进去之前，我大声喊：“`Ryder`！”

看了一眼我的脸后，他冲过来，双手按在我的肩膀上。“你找到她了吗？”

我点头，泪水顺着脸颊流下。“她走了。”

他双臂环住我，抱了时间并不长。“抱歉。我讨厌你必须成为发现她的人。但从以后你很清楚规矩。我得去检查脉搏并汇报这件事。你一个人在这里还好吗？”

我再次点头，害怕如果我开口，我会彻底崩溃。

`Ryder`最后用力捏了捏我，然后走进了地下室。我独自度过了几分钟煎熬的时光，身体抖得我不得不坐在门廊的台阶上，恶心到无法直视景物。他终于出来，手机贴着耳朵，已经在和当地警方通了电话。

当他进入我的听力范围内时，我听到了他对话的最后。“不，不用急。我没有发现脉搏。”停顿了一下，他说：“不，除了她的手腕，我什么都没碰过。怎么，你觉得我不知道怎么做？”又停顿了一下，他说：“我们哪儿也不去。我们会留在这里。”

我甚至无法想象要接受轮关于发现另一具尸体的审讯，而且还是另一个我跟我关系并不愉快的人。

`Ryder`站在我面前。“你还好吗？”

“当然。我为什么不好呢？”

他坐在台阶上我身身边。“至少你还没糟到没法说风话。这总归不错。”

我叹了口气，双手抱住头。“我不敢相信她会这样做。”

“真的吗？我以为她是你的头号嫌疑人。”

“嗯，确实是，但……我不知道。我的意思是，是的，在她身上的证据确实很有说服力。只是……我想我想责备她，但同时我不想相信她真的有那种胆去做这一切。”

“我理解。你和她并肩工作了很长时间，对吧？”

我点头。“就像我和`Java Jive`的一些员工一起工作一样。如果他们中任何一个人做了这种事，我同样会感到震惊。这不是一个你认为非常了解的人会做出来的事。”我吐了一口气，补充道，“当她已经为自己的行为付出了惩罚时，很难对她生气。”

他伸手搂住我，在我们等待自由市警察局到达时一直没有放开。几分钟后，我们就听到了警笛的鸣鸣声逼近。马戏就要开始了。

两名便衣侦探从第一辆警车下下来朝我们走来。其中一个是我几乎一辈子认识的人。

“`Jack`，”我说，站起身走过去迎接他们。`Ryder`走在我身后。

`Jack Harrison`从幼儿园起就是我的同学，他笑了。“`Juliet`。我从没梦过会在这里找到你。你怎么样？”

“我以前好过。”

“这样，我很抱歉。”他指向另一名侦探。“这是我的搭档，`William Johnson`侦探。”

`William`挥了挥手。我也是另一个记得学校比我晚几个级的人。

我说：“这是`Ryder Hamilton`侦探。”

三个男人握了手，`Jack`说：“很高兴见到如面。你在纳什维尔管得好`Callahan`吗？”

`Ryder`的同事`MNPD`侦探`Brody Callahan`曾在`Liberty PD`短暂工作过，并给了`Ryder`一个那里的联系人，我猜那个人就是`Jack`。

`Ryder`笑了。“他很好。”

`Jack`点点头。“知道就好。我们在这里很想他。现在我很讨厌打破寒暄，但我听说有一起命案要处理。等会儿我们会回来做笔录的。”他指了指`Ryder`的车，车被几辆应急车辆堵住了。“看来你想走也去不了了。”

`Ryder`指了他们地下室的方向，他们出发了，后面跟着几名制服警察，把我们推离木屋并开始用犯罪现场封带封锁周边。法医也跟了上来。

`Ryder`和我找到了一棵偏僻的大树，背着树坐在树叶留下的阴影里。

他说：“你对这事有意见吗？”

我转头看向他。“我对这事有各种意见。”

“我不是那个意思。我的意思是，`Mandi`发短信说她要结束这一切，然后。”

我挑了挑眉毛。“好像是有人杀了她？”

由于我们从小一起长大，杰克免了对我的质问，将我交给了威廉。威廉看起来人不错，尽管行事相当公事化。威廉带我来到地下室一个狭小得令人窒息的房间，我模糊记得小时候也来过这里。他离开了似乎有几个小时，等他终于回来时，他坐在我对面的金属桌旁，房间里安静得诡异，他正仔细审阅着带过来的文件。

“所以你是个私家侦探，兰格利小姐，”他说。

我忍住了叹息，还没准备好再次经历一遍这种事。“是的。你可以叫我朱莉特。我们确实一起上过高中，尽管只有了一年左右。”

“抱歉，习惯性动作。朱莉特，你来这里是为了调查斯科特·奥马利的死亡，对吧？”

“是的。”

停顿后，他问道：“是谁雇你做这件事的？”

“没有人。这是我的私事。”

“是因为你曾和受害者订过婚，还是因为你是最后一个见到他还活着的人？”

“听着，威廉，我知道你已经知道这些问题的答案了。这还不是我第一次接受审讯。”

他的嘴角向上动了动，但并没有微笑。“这只是个面试。”

“对。他们都是这么这么说的。你为什么不直奔主题呢？我确定你已经和德兰尼探员谈过我了。”

他点头回答道：“谈过了。他可不是你的铁粉丝。”

“彼此彼此吧。”

“他说你是斯科特·奥马利死亡案的嫌疑人。今天你发现了他妻子的尸体。我无法想象在去年她跟着你的未婚夫私奔后，你们之间还会有来来。”

“不，我们没那么亲密。”

“然而，她是决定通知她‘即将结束这一切’的唯一一个人。”

是啊，我也觉得这有点奇怪。“她知道我想查明到底是谁杀了斯科特，所以也许这正是她向我弥补的方式。”

“我不这么认为。”

“那么，你觉得呢？”

威廉打量了我片刻。“在我告诉我的想法之前，我们再多聊聊。在你的调查中，你有没有发现任何证据表明曼迪·奥马利杀了她的丈夫，就像她发给你的短信里说的那样？”

我信任杰克，但我不知道是否信任这个哥们。他是杰克的搭档，这总归说明了分量。此外，如果我不交出信息，只会让我陷入更大的麻烦，而杰克正在审讯莱德，莱德可能觉得有义务向同僚分享他所知的一切。我只希望我说的话以后不会被用来对付我。

于是，我从头说起，把一切都告诉了他。好吧，几乎是一切。我不打算包含任何会反过来噬咬我的敏感事实，比如偷取证据、多次破门搜查（`B and E's`），以及曼迪因我闯入她家而持枪威胁我，我不得不让她缴械的那件小事。从我打中斯科特的鼻子，到不久前找到曼迪，我向他描述了我的调查过程，并列出了我们目前为止发现的所有黑料，包括斯科特卷入的勒索和毒品走私案。

威廉吐了口气，靠在椅子上，用手抓了抓他修剪得很短的金黄色头发。“信息量很大。”

“可不是嘛。我们一直在纠结的是哪些与斯科特的死亡有关，哪些无关。”

他翻阅着文件，仔细看了其中一份报告。“他们倾向于认为药物过量或中毒是他的死因（`COD`）。我跟他的几个朋友和家人谈过，他们似乎并没有对发现是过量感到震惊。你调查这件事仅仅是为了证明自己的清白，还是因为你知道某些别人不知道的事？”

“我知道斯科特来找我说话时的样子。他坚信曼迪被那些他偷了某些信息的‘危险且强大的人士’劫架了。如果他是故意过量，为什么要来找我寻求帮助呢？当人到了那个份上时，他们不是直接呆在家里等死吗？”

他耸耸肩回答道：“在这方面我同意你。但关于意外过量的可能性呢？”

“我想这不能排除，但拜托。他是个药剂，肯定懂剂量。他是个很聪明的家伙。”

“除非他用了太久，导致必须增加剂量才能获得快感。”

“那不是在更长时间用药之后才会吗？根据他的朋友说，他表现异常的时间并不长。最多几个月吧。”

“好吧，假设这不是过量。假设是中毒，而且是他妻子做的。如果她失踪了——至少他以为她是失踪了——她如何在不被他发现的情况下把杀死他的物质递给他的？那东西得加在他的食物或饮料里，而且必须在他出现在你咖啡馆之前不久完成。”

我盯着他。那个念头并没有闪过我的脑海，但他是对的。曼迪可以很容易地把她想要的任何东西放入家里的食物或饮料中，甚至是在办公室，而不被发现。但他当时在纳什寻找她，所以她是如何能近距离到对他下毒而不被他发现的？

# 第 24 章

在结束与约翰森探员的谈话并交出斯科特的平板电脑后，我终于可以走了。莱德在车里等我。当我一到停车场，一辆黑色保捷车进了场，布莱克和莉莉都从车上跳了出来。老天，我真的不想再次重复这个故事了。

布莱克质问道：“你发现曼迪时为什么没联系我们？”

莱德也下了车，走过来站在我身边。“告知你们执法并不是我们的工作。”

布莱克直起身体，双手交叉在胸前。“我以为我们正在合作。”

莱德也学着做了。“别忘了你是媒体人，伙计。我们报了一起无人死亡。这不是我们需要向你们通报的事。”

“主意得不错。拿个平底锅之类的东西，把它砸断。”

皮特皱着眉说：“我觉得我想那样做，因为那样我们就出不来了。”

丹尼尔朝我走了几步路，依然保持在遥不可及的距离，枪指着我的头。“快做，自大狂的。”

皮特的眼神里充满了恐惧和痛苦，听从了他的指令，在准备台下找到了一个巨大的铸铁煎锅。他慢慢走到冷冻室前，像挥斧头一样举起锅，将锅边砸在旋钮顶部。塑料旋钮裂开并断成两半，穿过门的金属杆轻微弯曲。

丹尼尔说：“再来。”

皮特扭着脸又击了一下，这次把金属杆弯得更厉害。内部的紧急释放装置现在没用了。如果我们进去，除非有外力帮助，否则我们出不来。

丹尼尔说：“你可以放下平底锅了。我看得出来你恨不得立刻把它砸在我的脸上。”

皮特把它扔在地上。

丹尼尔用枪指着皮特说：“好了，你们两个。进箱子里。”

我向水池后退去，注意到我们的员工还留了一些没洗的碗筷——包括一把随手扔在里面的小水果刀，正等着某个毫无防备的手伸下去拿时被刺伤。通常情况下我会大发雷霆，但这次有人要加薪了。

我犹豫了一下。“等等，丹尼尔。没有什么我们可以做做来改变你的主意吗？比如……你可以付钱让我们保持沉默。你知道斯斯科拿走了我所有的钱，你也见过我的公寓了。买下我并不需要多少钱。”

从他的表情中，我看出丹尼尔正在考虑。他用下巴朝向皮特。“这地方是你的？”

“是。”

丹尼尔摇摇头。“买你代价太高了。”

我靠在水池旁说：“好吧，你可以只买我一个。”

“我不认为你这里的男朋友会太喜欢那样。你们两个，进箱子里。”

皮特咬着牙说：“如果你放她走……我自愿进冷冻室。”

“噢，那是我听过最动听的话了。”丹尼尔对我说道，“老斯斯科永远不会为你做那事的，对吧？”

我对着皮特笑了，尽管泪水几乎要夺眶而出。我的一部分在担心他的承受得如何（看起来并不太妙），但我需要保持清醒，试图想办法找到生路。

“不，他不会那样的，”我回答道，硬化了表情。“不过，他得到了应得的因果报应，对吧？”

丹尼尔耸了耸肩。“他惹恼了很多人。时候到了了。”

“我想知道是谁杀了他。如果你打算杀我，我至少应该知道这件事。”

“好。是曼迪……主要是她。”

“你是怎么‘大部分’杀掉一个人的？”

“她把药加进了他的饮料里，由我递给他的。”

“是左多巴胺和乙丙酸钠的致命配方吗？”

丹尼尔似乎被惊艳到了。“你做过功。”

皮特插话道，“嗯……那意味着你某种程度上也杀了他。”

我盯着丹尼尔。“等等。你和曼迪在斯斯科来看我之前，就在纳什维尔和他在一起，还为了着曼迪被绑架的事哀哭流涕？那到底是怎么回事？斯斯科从一开始就在欺骗我吗？”

“所谓的绑架是曼迪和我想出的一个诡计，为了让斯斯科交出他的勒索信息。当他拒绝用他的信息换取她的命，并试图自己去找她时，她生气了。我同意帮她做一件她一直想做的事。我安排在酒吧和斯斯科见面，敦促他对勒索的事做出更好的决定，但他根本不听。。曼迪也在酒吧，但她避开了他的视线。斯斯科不知道她在那儿，他完全不知道发生了什么。”

Java Jive 厨房墙上的电话响了，丹尼尔目光从我们身上移开了一秒。我迅速夺过那把小而锋利的刀，将其滑进我的后口袋。

他的气焰有些动摇，他问道：“谁知道你们在这里？”

希望他没听到我和莱德对话的末尾，我无辜地说：“才过十点几。这个时间总有人在这里打扫。我们经常在下班后接到电话。”在他纠结电话时，我继续道，“嘿，为了满足我自己的好奇，曼迪第二次消失是她自己离开的——还是你参与了？”

他对我冷笑了一下，这给了我所需的全部答案。“她在小屋里。当然，处于昏迷状态。乙丙酸钠让人变得非常顺从和安静。但如果你在第一个早上找得仔细一点，你可能就会发现她，这就是为什么我必须分散你的注意力。”

真个变态。“好吧，我得佩服你——把我们关在兰迪叔叔阴森的地窖室确实是个很好的注意力分散。”

“我是这么认为的。”

他咆哮道：“我不会失去我的——”发出一声压抑的闷哼，他低了声音，语气变得尖锐，“如果你在十秒内没进那个冷冻库，我就射死你。十，九……”

当丹尼尔倒计时时，我向皮特退去，一只手背在身后抓住了刀子。问题是，丹尼尔并没有像我希望的那样向我们走来。突然，丹尼尔附近传来嘶嘶声，这让他停下了计数，看了眼旁边的油炸锅。油开始沸腾，在丹尼尔离开之前，砰的一声巨大的巨响。烟雾腾起，热油向四个方向喷溅了两英尺远。

丹尼尔像女鬼一样尖叫起来，掉了枪。皮特和我面面相觑，丹尼尔的双只手都捂住脸部，持续在痛苦中哀嚎着。热油只喷溅了几秒钟，所以一旦停止，皮特就走过去夺走了枪。他躲开那个还在咕嘟作响的油炸锅，将枪指向了跪在地上的丹尼尔。

我说：“皮特，打 911。我们需要警察和救护车。我会处理丹尼尔，但如果他敢尝试任何动作，射死他。”

当我小心地关掉油炸锅，以免再次发生热油喷射事故时，皮特一直对准丹尼尔，一边用厨房电话打 911。丹尼尔陷入了自己的世界，此时在地板上扭动并抽泣，他脸部、手臂和手的皮肤每过几秒钟就起越来越多大面积斑块。我判断他已经没有能力对我们构成威胁，于是拿过急救箱，找到一些无菌敷垫，并在凉水下冲洗。

我跪在丹尼尔身边，尽可能温柔地处理他的伤口。他那张英俊的脸布满了斑块和水泡，我不确定它是否能完全愈合。我所能做的只是让他保持不动，以便在灼伤处倒一些清水，并盖上湿敷料。糟糕的是，皮特在打完 911 电话后，一直站在丹尼尔面前，枪口对着那个可怜人的头。

皮特努力不直盯着丹尼尔痛苦的伤口，说道：“几分钟前他还在拼命想杀我们，你现在怎么做到的？”

我耸了耸肩。“仅仅因为他是个坏蛋，并不意味着我也得变得很坏。而且，我受过足够的油烫伤，知道那种疼有多要命。相信我——他现在正在受到他`自己的`因果报应。”

“我想确实如此。嘿，但那场爆炸很酷，对吧？我的意思是，不是对他而言，但其他方面确实令人印象。热油渗了我那台破旧的手机，直接烧坏了电池。那本可以是一个很棒的热搜视频——”

莱德冲进厨房，拔出枪，准备大干一场。

皮特和我面对都很淡定地回了一句：“嘿。”

当他审视了局面时，他那张严肃的警察脸变成了困惑。“这里到底发生了什么？你们没去局里上班，也不接任何电话，所以我想你们俩又惹上麻烦了。我是来救你们的，但……”他看了眼丹尼尔，后者已经陷入了抽泣和发抖中。“看来你们自己搞定了那个坏蛋。”

从技术上讲，是皮特手机里的电池爆炸搞定了那个坏蛋，但我并没有纠正他。撇开好运气不谈，我们已经完全控制了局面。事实是，皮特和我终于不需要救援了。

莱德没有忽略这一事实。他带着自豪的微笑，补充道：“是时候了。”

# 结记

## 四周后

当我们正为明天早晨巡演出发收拾最后一次乐队练习的装备时，皮特对我说：“我们为什么不在 Java Jive 喝最后一杯咖啡呢？我担心我们在路上要受到的劣质咖啡，无法达到我们对‘滴滤完美’的高标准。”

我笑了起来。“好吧，但之后我们直接回家。你的行李箱还没收拾好呢。”

他用一只手臂搂住我的肩膀，领着我走向他的车。“好的，亲爱的。你知道吗，我没意识到和你住在一起的一个好处是，你会管得我规矩。”

我眯起眼睛看着他。“你是在说我强势吗？”

“我会那样吗？”

我调皮地推了他一把，快步绕到副驾驶位坐进去。对于这次巡演我感到兴奋不已。当然，我快被吓死了，但更重要的是，想到能和皮特共度一个月，我感到无比激动。自从我们决定尝试以来，我们的关系以一种我从未预过且无法解释的方式开花结果。我从未如此快乐，我很确定皮特也是同感。生活不能再更完美了。

我们在 Java Jive 关门前几分钟到达。罗纳达是我们新任命的助理经理，我们决定在我们离开期间让她负责，她此时正忙着指挥每一个人（就像我会做的一样），并准备让咖啡馆打烊。皮特和我给自己取了浓缩咖啡，带到沙发上。我们坐在一起，像往常一样聊天、大笑，当我意识到会有很长一段时间分离时，我感到一丝哀伤。

他再次微笑，松开了我的手，从口袋里掏出某样东西。等我反应过来他在做什么时，他已经单膝跪地，举起一枚华丽的古董钻戒（如果我没记错，那是葛蒂的结婚戒），脸上带着最甜的表情看着我。我的呼吸凝滞了。

“嫁给我吧，朱尔。我想和你共度余生，一直这样爱你。我想和你一起创作音乐，每天在这里和你一起喝咖啡，让你为你开笑。我想和你一起变老、变胖、长满皱纹。你是我遇过的最好的朋友，而现在，我比任何事情都想成为你的丈夫。成为你的家人。我爱你。”

那些此前呼溢而出的泪水此刻真情地流过我的脸颊。我点了点头：“好。是的，我当然愿意嫁给你！”等他站起来并将戒指套进我的手指后，我双臂环住他，说道：“我爱你，皮特。从见到你的那刻起我就爱上你了，从未停止过。哪怕是一分钟也没有。”

致 Julia Maguire
