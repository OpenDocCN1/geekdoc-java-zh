## 序言

C++ 是一门新兴的编程语言，它基于对象和编译。如果你是一个从未编写过程序的人，可能会对“对象”和“编译”这些词汇感到困惑。

利用编译的程序是由计算机的 CPU 读取的，而不是通过安装在计算机上运行该程序的程序进行解释的。因此，该程序更多的是与计算机的处理系统直接对话，而不是与某个程序对话。

你可能已经知道这一点，但计算机无法读取字母，必须读取二进制代码，因此代码必须翻译成计算机可读的形式。现在，面向对象的代码只是代码的组织方式。你将在接下来的章节中更更好地理解这一小知识。

那么，这一切意味着什么，你为什么需要知道它呢？作为一名使用 C++ 的程序员，你需要的不仅仅是普通的文本编辑器。只有少数编程语言只需要编辑器，而它们实际上并不是真正的编程语言。你将需要的工具之一是编译器。

另一个你可能想要的是集成开发环境，也称为 IDE。这是一种面向程序员的文本编辑器，具有语法高亮功能并集成了编译器。对于 Windows 和 Linux，你可以使用几种不同的选项。

你并不真的需要 IDE，因为基础的文本编辑器也可以，但像记事本这样的工具会让事情变得有点困难。文字处理软件也是一个糟糕的选择，因为它们带有拼写和语法的自动纠正功能，如果不小心，会搞乱你的代码。

开始学习 C++ 之前，你应该理解它的语法是严格的。这意味着代码对大小写敏感，所以输入 `Hello` 会和输入 `hello` 不同。此外，你应该知道这种编程语言并不在乎空格，所以不用担心它。

以上就是你初学 C++ 时需要知道的所有内容。让我们进入实际代码阶段让你上手吧！

## 第一章——你的第一个程序

由于这是一个关于如何开始 C++ 的简短教程，我们将在第一章让你开始一个程序。你的第一个程序将非常简单。你所做的就是在屏幕上写一个短语，这不像在 Word 文档中写那么简单。首先，看一眼代码，我们将进一步探讨它的含义。

```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "Hello, world!";
    return 0;
}
```

这一行将告诉编译器，它必须将 `iostream` 库链接到程序。库是一个存储代码片段的地方，这些片段被称为函数。库还存储其他内容，如变量和运算符。

`iostream` 库的代码允许你将字符发送到文本流中，然后将其输入到屏幕上。把它想象成一条河流。你是源头，屏幕是海洋。从源头进入河流的任何东西都会显示在屏幕上。

接下来的第二行让编译器知道你想使用名为 `std` 的命名空间，这是一个标准命名空间。命名空间是存储代码的区域。如果你有两个名称相同的代码，这非常有用。通常情况下，代码不能共享相同的名称，但如果其中一个在独立的命名空间中，它们就可以有相同的名称。

代码的第三行是代码的开头。它是主块（`main` block），正如名称所示。大括号内的所有内容都将被编译器翻译。你需要那行代码，因为没有它什么都不会发生。

现在是打印短语“Hello World!”的时候。为了实现这一点，你使用了存储在 `iostream` 库中的代码。代码的这部分被称为 `cout`，它向流发送信息。紧接在 `cout` 之后的 `<<` 是一个运算符。这意味着输出。

接下来的流是“Hello, World!”，被称为字符串。字符串是字符序列，通过用双引号括起来来显示。它以分号结束，表示语句的结束。如果没有使用分号，程序将无法编译。

```cpp
}
```

最后一行，即右大括号，非常简单但非常重要。它放置在 `main` 的末尾，告诉计算机主块已结束。它将向 CPU 返回一个值 0。非零值将产生错误，所以它是必须的一行。现在你已经有了程序的源代码，你必须编译它。在了解了如何创建第一个程序以及它是什么样子后，让我们来看看变量吧！

## 第二章——变量

在上一章中，提到了变量，并说将讨论它们。现在是讨论它们了。变量是存储值的东西。想象每个变量都是一个盒子。每个变量都是一个盒子，并贴有标签。

变量类型可以存储很多东西，但现在你只需要使用几个。变量类型是整数。

例如，整数 `int` 的类型是赋值。等号是赋值运算符，它是它所执行的操作。左边的变量被赋予右边的值，赋值是二进制运算符，因为它有两个操作数。右边的操作数不必须是一个值，它可以是另一个变量。把剩下的留给以后。

这里是你可以使用的变量类型。

| C++ 类型 | 存储 |
| :--- | :--- |
| `int` | 整数（整数型） |
| `bool` | 真或假（0 或 1） |
| `float` | 浮点数（实数） |
| `double` | 双精度浮点数 |
| `char` | 单个 ASCII 字符 |

有几种不同的变量类型。当你编写程序时可能会使用所有类型，但现在你只需要几个。

### 使用变量

看看下面的程序：

```cpp
1 #include <iostream>
2 using namespace std;
3
4 int variable;
5
6 int main()
7 {
8
9 variable = 42;
10
11 cout << variable;
12 return 0;
13
14 }
```

程序的其他部分看起来很熟悉，除了第四行部分声明了变量。这告诉编译器你将使用一个变量。在声明中，变量类型在前。在示例中，它使用的是 `int` 类型。接下来是变量的名字，被称为 `var`。

这很简单很方便。变量名可以是任何内容，但要确保它是相关的，而不是 C++ 中保留且具有含义的名称，并且不以数字或特殊字符开头。你应该从小写字母开始，并用分号结束语句。

你可以看到 `cout` 语句变量名周围没有加引号。这是因为你想输出变量的值，而不是显示字符串“var”。如果你编译该程序，它将打印“42”，因为那是 `var` 拥有的值。通过将其改为另一个整数并查看输出。

```text
C:\WINDOWS\system32\cmd.exe
OUTPUT PROGRAM
Maths = 28
Physics = 77
Chemistry = 69
```

变量还有添加在声明中的前缀，这会改变它们的行为。某些前缀会改变大小，另一些则不允许负数，而另一些可能会执行完全不同的操作。

现在你已经了解了变量，让我们来讨论如何扩展程序吧！

## 第三章 - 扩展你的程序

现在你已经知道如何使用变量以及如何将它们放入程序中，让我们来看看如何扩展程序。你实际上所知道的只是使用变量并将它们放入程序中，因此你实际上能做的就是设置变量的输出和值。这在创建一个真实的程序时是并不可用的。

你需要的是一种操作变量并接收用户输入的方法。所以，让我们来看下一个！

### iostream 库

你已经知道 `iostream` 库可以输出数据，但它也可以获取输入数据。该命令与 `cout` 语句非常相似。命令是 `cin`。不过，有一点不同。当你使用 `cin` 时，它后面的运算符是反向的。

不是 `<<`，而是 `>>`。这在刚开始很难记忆，但你最终会学会的。注意，当你运行程序时，你需要按下回车键（enter key）来输入你想要的信息，就像在终端/`cmd` 提示符一样。

查看以下程序中的 `<<` 以了解两者之间的区别。

```cpp
1 cout << "string";
2 cout << var;
3
4 cin >> var;
```

你可能已经看出使用 `iostream` 库获取用户输入非常简单，这可以产生更有用的程序。不过，`iostream` 要强大得多。你可以将许多语句合并为一个。

例如，要输出两个字符串或变量，你通常需要两条语句，但你可以合并多个 `cout` 语句并产生短得多的代码。你只需要为你正在输出或输入的项添加另一个运算符即可。

例如：

```cpp
1 cout << "Hello, " << "World!";
```

你也可以同样地合并 `cin` 语句，就像连续接收几部分输入一样。每个语句后都必须按回车，而且你不能在一行代码中混合输入和输出。

现在你已经知道如何合并代码并扩展你的程序，让我们更多更多运算符。

## 第四章 – 运算符

你已经学会了如何输出文本、声明变量和获取输入，但你无法对变量做任何事情。当然，你可以给它们赋值，但这在现实世界中有什么用呢？你真正需要的是一种在不费力气的情况下操作变量的方法。幸运的是，运算符将救你！

你已经研究了两个与 `iostream` 库相关的运算符，即输入和输出 `>>` 和 `<<`。

| 运算符 | 用途 | 示例 | 结果 |
|---|---|---|---|
| `+` | 相加两个数字 | `i=3+2` | 5 |
| `-` | 减法 | `i=3-2` | 1 |
| `*` | 乘法 | `i=3*2` | 6 |
| `/` | 除法 | `i=3/2` | 1 |
| `%` | 取模（除法后的余数） | `i=10%3` | 1 |

这些运算符可以归为几类，第一类是算术运算符。它们是 `-`、`+`、`/` 和 `*`。你可以像在数学中使用它们一样使用它们。例如，这段代码会将两个数字相加并显示结果。

```cpp
#include <iostream>
using namespace std;
int sum = 0;
int main() {
sum = 64 + 32;
cout << sum;
return 0;
}
```

现在你已经知道如何使用运算符，让我们来看看条件判断！

## 第五章 – 条件判断

拥有一个执行单一线性任务的程序（比如说“Hello”）是很棒的，但你很少遇到需要只执行线性任务的程序。程序通常使用被称为“条件”的东西，或者根据条件是否为真将代码分支到不同路径的语句。这基本上就像路上的叉路口。

C++ 条件判断采用 `if` 语句的形式。例如，如果某些情况为真，则执行这行代码；如果为假，则执行另一行代码。查看以下代码段作为示例。

```cpp
1 int a;
2
3 if (a<2)
4 {
5 cout<<"a is less than 2\n";
6 }
```

到这里，第一到五行对你来说应该显而易见，但第三行是你可能需要一点解释的地方。这是 `if` 语句的示例。它的运行方式是首先获取事项（matter）。

```cpp
int i = 0;

for(i = 2; i < 10; ++i)
{
    cout<<i<<"\n";
}
```

这段代码告诉程序从将变量 `i` 设置为 2 开始，只要 `i` 小于 10，就将其值输出到屏幕并递增。你可以轻松地使用 `while` 循环来复制这个循环，但它会使用更多的代码行，而且非常不整洁。

你还应该知道，`for` 循环第一行使用的变量必须是同一个变量。你还应该记住，第一个语句不是条件，而是赋值。

当你想要遍历各种数据段时，这种循环会非常有用，当你在下一章学习数组时，就会看到这一点。

## 第七章 – 数组

数组是一组具有共同用途而归类在一起的变量列表。它们并不非要有什么共同点，把互无关的东西放在一起并不是一个好主意。这就像向你的文件柜里塞满随机纸张而从不整理它们一样。如果你打算这样做，那要文件柜还有什么意义呢？

这里是一个整数变量数组的声明。

```cpp
int a [5];
```

你可以看到数组看起来像普通变量，但它们在末尾有一些方括号。当你声明数组时，括号内将填充你所需要的数组的大小。在这种情况下，你将存储五个整数变量。

| a: | `a[0]` | `a[1]` | ... | ... | `a[9]` |
| --- | --- | --- | --- | --- | --- |

只要你有足够的剩余 RAM（随机存储内存），数组可以是你想要的任何大小，但它一次只能存储一种类型的变量。变量类型可以是你通常使用的任何类型。

访问数组中的特定变量非常简单。你只需要将想要的变量数字放在方括号中。所以，对于你想要的第一个变量使用 `[0]`，对于第二个使用 `[1]`，并以此此类推。请看下面的示例。

```cpp
int a[5];

// 将 a 的第一个变量设置为 1
a[0] = 1;

// 将 a 的第二个变量设置为 4
a[1] = 4;

// 输出第一个变量
cout << a[0];
```

你不应该做的一件事是访问数组中不存在的变量，例如在一个只有五个位置的数组中访问第十个变量，或者访问一个没有被赋值的变量。如果没有变量被赋值，你将得到所谓的“垃圾值”，因为它返回的值是不可用的。

如果变量不存在，你可能会得到段错误（segmentation fault），因为程序将尝试访问它无权访问的内存段。这可能导致程序意外终止。

现在你已经知道了如何创建数组，让我们来看看如何创建函数吧！

## 第八章 – 函数

函数是编写复杂程序的极佳方法，不需要重复代码。例如，假设你有一段复杂的代码，从用户处获取输入并对其进行解析。现在，假设你需要运行这段代码几次，但不是通过循环。在此之前，你每次都必须写一遍它。

```cpp
main () {
  function1 () {
    function2 () {
      function3 () {
      }
    }
  }
}
```

在现代的复制粘贴功能下，这并不是什么大问题，但它看起来很糟糕，而且当你需要修复错误时，重复的代码可能会成为问题。为了解决这个问题，你可以创建函数，即是你能够反复调用的代码段而不需要每次都写一遍。

实际上，你已经使用过函数了。`main` 就是一个函数。所以让我们来看看它看看它是如何工作的。

```cpp
int main () {
    cout << "I'm in a function!\n";

    return 0;
}
```

让我们检查第一行，即包含 `main` 单词的这一行。它开始定义一个没有参数的名为 `main` 函数，并返回一个 `int` 类型的值。你已经知道 `int` 是什么（一种变量类型），但“返回一个值”是什么意思？

C++ 中的函数就像数学中的函数，你输入一个数字并对其进行某些操作，然后得到一个答案。在这里，`int` 是输出函数将要产生的变量。参数是放入函数的变量，然后函数在返回结果之前会执行操作。

让我们来看带有 `main` 的函数。

```cpp
// 这是编写 main 的另一种方式
int main(int argc, char*argv[])
{
    cout << "I'm in a function!\n";

    return 0;
}
```

参数的写法类似于变量定义，并用逗号隔开。它们写在括号后面。它们是 `argc` 和 `argv`。

`argc` 是参数的数量，`argv` 是包含参数的字符串数组。这些用于命令行参数。

现在你已经知道了如何创建数组，让我们转向指针。

## 第九章 – 指针

指针是一个存储另一个变量地址的变量。它们不存储值，而是存储该值所在的内存位置。要声明指针，你在变量名之前使用星号 `*` 符号。

```cpp
int x = 10;
int *ptr = &x;
```

在这个示例中，`x` 是一个值为 10 的整数变量。`ptr` 是存储 `x` 地址的指针。`&` 运算符是“取地址”运算符，用于获取变量的内存地址。要访问存储在地址处的值，你使用解引用运算符 `*`。

```cpp
cout << *ptr; // 输出 10
```

指针非常强大，但也可能很复杂。它们被用于动态内存分配、链表和树等数据结构，以及高效地将大对象传递给函数而不进行复制。

## 第十章 - 动态内存

到目前为止，你已经能够在编译时创建变量并在运行时修改它们；然而，当你使用动态内存分配时，你也可以在运行时创建它们。这种方法在程序运行期间使用 RAM 的分配和释放。由于你正在访问 RAM，自然会假设你将使用指针来操作，但 C++ 中的动态内存使用方式与 C 不同。

请看下面的代码块。

```cpp
int* i = new int;

*i = 5;

cout <<*i << "at address"<<i
<< "which itself is at address " <<&i << std::endl;
delete i;
```

在这里，你创建了一个指向整数的指针并为它分配了一些内存。由于 `i` 仍然是指针而不是变量，你必须将 `i` 所指向的值设置为五，而不是设置 `i` 本身。这改变了 `i` 指向的位置，并导致 RAM 中某处预留的内存变成了孤儿。这种被遗忘的内存被称为内存泄漏。为了防止这种情况，请务必使用 `delete` 运算符来释放你最初分配的内存。

不过，为单个变量分配内存并没有多大帮助。如果你知道该变量将会存在，就可以正常进行声明。这种做法创建了在编译时不可知的变长大小数组。但实际上，你怎么可能预先知道呢？你无法创建一个指针数组并在需要时访问它们，那仅仅是创建一个巨大数组并希望一切顺利的一种更耗费内存（RAM）的实现方式而已。

现在你已经了解了什么是动态内存以及如何使用它，让我们在下一章中看看类和对象。

这实际上是 C++ 设计的初衷：支持类和对象。没有了它们，C++ 只是一个真正的 C 语言。但是之前提到的类和对象到底是什么呢？类是一种模具，而对象就是从模具中产生的实体。这些模具是灵活的，可以用于制作你任何类型的对象。模具可以是通用的，也可以是具体的。
