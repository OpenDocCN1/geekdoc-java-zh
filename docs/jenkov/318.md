
# Java 列表

> 原文：<https://jenkov.com/tutorials/java-collections/list.html>

`Java List`接口`java.util.List`，表示有序的对象序列。Java `List`中包含的元素可以根据它们在 Java `List`中出现的顺序被插入、访问、迭代和删除。元素的排序是这个数据结构被称为*列表*的原因。

Java 中的每个元素都有一个索引。`List`中的第一个元素的索引为 0，第二个元素的索引为 1，依此类推。索引的意思是“距离列表开头多少个元素”。因此，第一个元素距离列表的开头 0 个元素——因为它在列表的开头。

您可以将任何 Java 对象添加到`List`中。如果`List`没有类型化，使用 [Java 泛型](/java-generics/index.html)，那么你甚至可以在同一个`List`中混合不同类型(类)的对象。然而，在实践中，在同一个`List`中混合不同类型的对象并不常见。

Java `List`接口是标准的 [Java 接口](/java/interfaces.html)，是 [Java 集合](collection.html)接口的子类型，意思是`List`继承自`Collection`。

## 列表与集合

Java `List`和[Java Set](set.html)接口非常相似，因为它们都表示元素的集合。然而，有一些显著的差异。这些差异反映在`List`和`Set`接口提供的方法中。

Java `List`和 Java `Set`接口的第一个区别是，同一个元素可以在 Java `List`中出现不止一次。这与 Java `Set`不同，在 Java 中每个元素只能出现一次。

Java `List`和 Java `Set`接口的第二个区别是，`List`中的元素是有顺序的，元素可以按照这个顺序迭代。Java `Set`对内部保存的元素的顺序不做任何承诺。

## 列出实现

作为`Collection`子类型，`Collection`接口中的所有方法在`List`接口中也是可用的。

因为`List`是一个接口，为了使用它，你需要实例化该接口的一个具体实现。您可以在 Java Collections API 的以下`List`实现中进行选择:

- `java.util.ArrayList`
- `java.util.LinkedList`
- `java.util.Vector`
- `java.util.Stack`

在这些实现中，`ArrayList`是最常用的。

在`java.util.concurrent`包中也有并发的`List`实现。这些`List`实现在我的[java.util.concurrent 教程](/java-util-concurrent/index.html)中有更详细的解释。

## 通用列表

默认情况下，您可以将任何`Object`放入`List`中，但是从 Java 5 开始，Java 泛型使得限制您可以插入到`List`中的对象类型成为可能。这里有一个例子:

```
List<MyObject> list = new ArrayList<MyObject>();
```

这个`List`现在只能插入`MyObject`个实例。然后，您可以访问和迭代它的元素，而无需强制转换它们。这是它的样子:

```
List<MyObject> list = new ArrayList<MyObject>();
list.add(new MyObject("First MyObject"));
MyObject myObject = list.get(0);
for(MyObject anObject : list){
    //do someting to anObject...
}
```

如果没有泛型，上面的例子应该是这样的:

```
List list = new ArrayList(); //no generic type specified
list.add(new MyObject("First MyObject"));
MyObject myObject = (MyObject) list.get(0); //cast needed
for(Object anObject : list){
    //cast needed
    MyObject theMyObject = (MyObject) anObject;
    //do someting to anObject...
}
```

请注意将从列表中检索到的`MyObject`实例转换为`MyObject`是多么必要。如果没有在列表变量声明中设置泛型类型，Java 编译器只知道列表包含`Object`实例。因此，您需要将它们转换为您知道该对象所属的具体类(或接口)。

尽可能为列表变量指定一个泛型类型是一个好习惯。它帮助您避免将错误类型的对象插入列表。它使您能够从列表中检索对象，而不必将它们转换为实际类型。它帮助你的代码的读者看到列表应该包含什么类型的对象。只有在有充分理由的情况下，才应该省略泛型类型。

在本 Java List 教程的剩余部分，我将尽可能多地使用通用列表示例。

关于 Java 泛型的更多信息，请参见[Java 泛型教程](/java-generics/index.html)。

## 在 Java 列表中插入元素

使用 Java 的`add()`方法将元素(对象)插入到 Java `List`中。下面是一个使用`add()`方法向 Java `List`添加元素的例子:

```
List<String> listA = new ArrayList<>();
listA.add("element 1");
listA.add("element 2");
listA.add("element 3");
```

前三个`add()`调用将一个`String`实例添加到列表的末尾。

### 插入空值

实际上可以将`null`值插入到 Java `List`中。下面是一个将`null`值插入 Java `List`的例子:

```
Object element = null;
List<Object> list = new ArrayList<>();
list.add(element);
```

### 在特定索引处插入元素

可以在 Java `List`的特定索引处插入一个元素。`List`接口有一个版本的`add()`方法，它将索引作为第一个参数，将要插入的元素作为第二个参数。下面是一个将索引 0 处的元素插入 Java `List`的例子:

```
list.add(0, "element 4");
```

如果`List`已经包含了元素，那么这些元素将会在`List`的内部序列中被下推。在新元素被插入到索引 0 之前具有索引 0 的元素将被推到索引 1，依此类推。

## 将一个列表中的所有元素插入另一个列表

可以将一个 Java `List`中的所有元素添加到另一个`List`中。你可以使用`List`和`addAll()`的方法。由此产生的`List`是两个列表的*并集*。以下是将一个`List`中的所有元素添加到另一个中的示例:

```
List<String> listSource = new ArrayList<>();
listSource.add("123");
listSource.add("456");

List<String> listDest = new ArrayList<>();
listDest.addAll(listSource);
```

此示例将所有元素从`listSource`添加到`listDest`。

`addAll()`方法接受一个`Collection`作为参数，因此您可以传递一个`List`或[Java Set](set.html)作为参数。换句话说，你可以用`addAll()`将`List`或`Set`中的所有元素添加到`List`中。

## 从 Java 列表中获取元素

您可以使用元素的索引从 Java `List`中获取元素。您可以使用`get(int index)`方法来完成。下面是一个使用元素索引访问 Java `List`元素的例子:

```
List<String> listA = new ArrayList<>();
listA.add("element 0");
listA.add("element 1");
listA.add("element 2");

//access via index
String element0 = listA.get(0);
String element1 = listA.get(1);
String element3 = listA.get(2);
```

也可以按照内部存储的顺序迭代 Java `List`的元素。在本 Java List 教程的后面，我将向您展示如何做到这一点。

## 在列表中查找元素

您可以使用以下两种方法之一在 Java `List`中找到元素:

- `indexOf()`
- `lastIndexOf()`

`indexOf()`方法查找给定元素在`List`中第一次出现的索引。下面是一个在 Java `List`中查找两个元素的索引的例子:

```
List<String> list = new ArrayList<>();

String element1 = "element 1";
String element2 = "element 2";

list.add(element1);
list.add(element2);

int index1 = list.indexOf(element1);
int index2 = list.indexOf(element2);

System.out.println("index1 = " + index1);
System.out.println("index2 = " + index2);
```

运行此代码将产生以下输出:

```
index1 = 0
index2 = 1
```

### 查找列表中最后一个出现的元素

`lastIndexOf()`方法查找给定元素在`List`中最后一次出现的索引。下面的例子展示了如何在 Java `List`中找到给定元素最后一次出现的索引:

```
List<String> list = new ArrayList<>();

String element1 = "element 1";
String element2 = "element 2";

list.add(element1);
list.add(element2);
list.add(element1);

int lastIndex = list.lastIndexOf(element1);

System.out.println("lastIndex = " + lastIndex);
```

运行上述 Java 示例的输出将是:

```
lastIndex = 2
```

元素`element 1`在`List`中出现 2 次。最后一次出现的索引是 2。

## 检查列表是否包含元素

您可以使用`List` `contains()`方法检查 Java `List`是否包含给定的元素。下面是一个使用`contains()`方法检查 Java `List`是否包含元素的例子:

```
List<String> list = new ArrayList<>();

String element1 = "element 1";
list.add(element1);

boolean containsElement = list.contains("element 1");
System.out.println(containsElement);
```

运行这个 Java `List`示例的输出将是:

```
true
```

...因为`List`实际上包含了元素。

为了确定`List`是否包含元素，`List`将在内部迭代它的元素，并将每个元素与作为参数传递的对象进行比较。比较使用元素的[Java equals](hashcode-equals.html)方法来检查元素是否等于参数。

因为可以将`null`值加到`List`上，所以实际上可以检查`List`是否包含`null`值。下面是如何检查一个`List`是否包含一个`null`值:

```
list.add(null);

containsElement = list.contains(null);

System.out.println(containsElement);
```

显然，如果`contains()`的输入参数是`null`，`contains()`方法不会使用`equals()`方法来比较每个元素，而是使用`==`操作符。

## 从 Java 列表中删除元素

您可以通过以下两种方法从 Java `List`中移除元素:

1. `remove(Object element)`
2. `remove(int index)`

删除列表中的元素，如果它存在的话。然后，列表中的所有后续元素在列表中上移。他们的指数因此减少了 1。下面是一个基于元素本身从 Java `List`中删除元素的例子:

```
List<String> list = new ArrayList<>();

String element = "first element";

list.add(element);

list.remove(element);
```

这个例子首先向一个`List`添加一个元素，然后再次删除它。

`List` `remove(int index)`方法删除给定索引处的元素。然后，列表中的所有后续元素在列表中上移。他们的指数因此减少了 1。下面是一个通过索引从 Java `List`中删除元素的例子:

```
List<String> list = new ArrayList<>();

list.add("element 0");
list.add("element 1");
list.add("element 2");

list.remove(0);
```

运行这个 Java 示例代码后，`List`将包含索引 0 和 1 处的[Java 字符串](/java/strings.html)元素`element 1`和`element 2`。第一个元素(`element 0`)已经从`List`中移除。

## 从 Java 列表中移除所有元素

Java `List`接口包含一个`clear()`方法，该方法在被调用时从列表中删除所有元素。从`List`中移除所有元素也被称为*清除*和`List`。下面是用`clear()`方法从`List`(清除)中移除所有元素的简单示例:

```
List<String> list = new ArrayList<>();

list.add("object 1");
list.add("object 2");

//etc.
list.clear();
```

首先，创建一个新的`List`。其次，两个元素被添加到`List`中。第三，调用`clear()`方法。在调用了`clear()`方法之后，`List`将完全为空。

## 将一个列表中的所有元素保留在另一个列表中

Java `List`接口有一个名为`retainAll()`的方法，它能够保留一个`List`中的所有元素，这些元素也存在于另一个`List`中。换句话说，`retainAll()`方法从目标`List`中移除所有在另一个`List`中没有的元素。得到的`List`是两个列表的*交集*。下面是一个调用`List` `retainAll()`方法的 Java 示例:

```
List<String> list = new ArrayList<>();
List<String> otherList = new ArrayList<>();

String element1 = "element 1";
String element2 = "element 2";
String element3 = "element 3";
String element4 = "element 4";

list.add(element1);
list.add(element2);
list.add(element3);

otherList.add(element1);
otherList.add(element3);
otherList.add(element4);

list.retainAll(otherList);
```

首先创建两个列表。其次，`list`增加 3 个元素，`otherList`增加 3 个元素。第三，在`list`上调用`retainAll()`方法，将`otherList`作为参数传递。在`list.retainAll(otherList)`执行完毕后，`list`将只包含那些在`retainAll()`被调用之前在`list`和`otherList`中都存在的元素。更确切的说，那就是`element1`和`element3`。

## 列表的子列表

Java `List`接口有一个名为`subList()`的方法，它可以用原始`List`中的元素子集创建一个新的`List`。

`subList()`方法有两个参数:开始索引和结束索引。起始索引是原始`List`中要包含在子列表中的第一个元素的索引。结束索引是子列表的最后一个索引，但是最后一个索引处的元素不包含在子列表中。这类似于[Java String substring](/java/strings.html#substring)方法的工作方式。

下面是一个使用`subList()`方法从另一个`List`创建元素子列表的 Java 示例:

```
List<String> list = new ArrayList<>();

list.add("element 1");
list.add("element 2");
list.add("element 3");
list.add("element 4");

List<String> sublist = list.subList(1, 3);
```

执行完`list.subList(1,3)`指令后，`sublist`将包含索引 1 和 2 处的元素。记住，原始列表有 4 个元素，索引从 0 到 3。`list.subList(1,3)`调用将包括索引 1，但排除索引 3，从而保持元素在索引 1 和 2。

## 将列表转换为集合

您可以通过创建一个新的`Set`并将`List`中的所有元素添加到其中，将 Java `List`转换成 Java `Set`。`Set`将删除所有重复的内容。因此，得到的`Set`将包含来自`List`的所有元素，但只包含一次。下面是一个将 Java `List`转换成`Set`的例子:

```
List<String> list = new ArrayList<>();

list.add("element 1");
list.add("element 2");
list.add("element 3");
list.add("element 3");

Set<String> set = new HashSet<>();
set.addAll(list);
```

请注意，`List`包含了字符串`element 3`两次。`Set`将只包含该字符串一次。因此，结果集将包含字符串`element 1`、`element 2`和`element 3`。

## 排序列表

您可以使用`Collections` `sort()`方法对 Java `List`进行排序。我已经在我的[排序 Java 集合教程](sorting.html)中解释了它是如何工作的，但是在接下来的章节中我将只向你展示几种排序 Java 的方法`List`。

### 可比较对象的排序列表

如果`List`包含实现`Comparable`接口(`java.lang.Comparable`)的对象，那么这些对象可以相互比较。在这种情况下，您可以像这样对`List`进行排序:

```
List<String> list = new ArrayList<>();

list.add("c");
list.add("b");
list.add("a");

Collections.sort(list);
```

Java `String`类实现了`Comparable`接口，你可以使用`Collections` `sort()`方法将它们按自然顺序排序。

### 使用比较器排序列表

如果 Java `List`中的对象没有实现`Comparable`接口，或者如果您想以不同于它们的`compare()`实现的另一种顺序对对象进行排序，那么您需要使用一个`Comparator`实现(`java.util.Comparator`)。下面是一个使用`Comparator`对`Car`对象列表进行排序的例子。这里首先是`Car`类:

```
public class Car{

    public String brand;
    public String numberPlate;
    public int noOfDoors;

    public Car(String brand, String numberPlate, int noOfDoors) {
        this.brand = brand;
        this.numberPlate = numberPlate;
        this.noOfDoors = noOfDoors;
    }
}
```

下面是对上述`Car`对象的 Java `List`进行排序的代码:

```
List<Car> list = new ArrayList<>();

list.add(new Car("Volvo V40" , "XYZ 201845", 5));
list.add(new Car("Citroen C1", "ABC 164521", 4));
list.add(new Car("Dodge Ram" , "KLM 845990", 2));

Comparator<Car> carBrandComparator = new Comparator<Car>() {
    @Override
    public int compare(Car car1, Car car2) {
        return car1.brand.compareTo(car2.brand);
    }
};

Collections.sort(list, carBrandComparator);
```

注意上面例子中的`Comparator`实现。这个实现只比较`Car`对象的`brand`字段。可以创建另一个`Comparator`实现来比较汽车的车牌，甚至是门的数量。

还要注意，使用一个[Java Lambda](/java/lambda-expressions.html)来实现一个`Comparator`是可能的。下面是一个例子，它使用`Comparator`接口的三种不同的 Java lambda 实现对`Car`对象的`List`进行排序，每种实现都通过不同的字段比较`Car`实例:

```
List<Car> list = new ArrayList<>();

list.add(new Car("Volvo V40" , "XYZ 201845", 5));
list.add(new Car("Citroen C1", "ABC 164521", 4));
list.add(new Car("Dodge Ram" , "KLM 845990", 2));

Comparator<Car> carBrandComparatorLambda = (car1, car2) -> car1.brand.compareTo(car2.brand);
Comparator<Car> carNumberPlatComparatorLambda = (car1, car2) -> car1.numberPlate.compareTo(car2.numberPlate);
Comparator<Car> carNoOfDoorsComparatorLambda = (car1, car2) -> car1.noOfDoors - car2.noOfDoors;

Collections.sort(list, carBrandComparatorLambda);
Collections.sort(list, carNumberPlatComparatorLambda);
Collections.sort(list, carNoOfDoorsComparatorLambda);
```

## 迭代列表

您可以用几种不同的方式迭代 Java `List`。三种最常见的方式是:

- 使用`Iterator`
- 使用 for-each 循环
- 使用 for 循环
- 使用 Java 流 API

我将在接下来的章节中解释这些迭代 Java `List`的方法。

### 使用迭代器迭代列表

迭代一个`List`的第一种方法是使用一个[Java 迭代器](iterator.html)。下面是一个用`Iterator`迭代`List`的例子:

```
List<String> list = new ArrayList<>();

list.add("first");
list.add("second");
list.add("third");

Iterator<String> iterator = list.iterator();

while(iterator.hasNext()) {
    String next = iterator.next();
}
```

您通过调用`List`接口的`iterator()`方法获得一个`Iterator`。

一旦你获得了一个`Iterator`，你可以继续调用它的`hasNext()`方法，直到它返回`false`。如你所见，调用`hasNext()`是在一个`while`循环中完成的。

在`while`循环中，您调用`Iterator`接口的`Iterator` `next()`方法来获取由`Iterator`指向的下一个元素。

如果使用[Java 泛型](/java-generics/index.html)对`List`进行类型化，你可以在`while`循环中保存一些对象转换。这里有一个例子:

```
List<String> list = new ArrayList<>();

list.add("first");
list.add("second");
list.add("third");

Iterator<String> iterator = list.iterator();

while(iterator.hasNext()){
    String obj = iterator.next();
}
```

### 使用 For-Each 循环迭代列表

迭代`List`的第二种方法是使用 Java 5 中添加的`for`循环(也称为"for each"循环)。下面是一个使用`for`循环迭代`List`的例子:

```
List list = new ArrayList();

list.add("first");
list.add("second");
list.add("third");

for(Object element : list) {
    System.out.println(element);
}
```

`for`循环对`List`中的每个元素执行一次。在`for`循环中，每个元素依次绑定到`obj`变量。

如果列表是类型化的(一个*泛型* `List`)，你可以在`for`循环中改变变量的类型。下面是键入的`List`迭代示例:

```
List<String> list = new ArrayList<String>();

//add elements to list

for(String element : list) {
    System.out.println(element);
}
```

注意`List`是如何被输入到`String`的。因此，您可以将`for`循环中的变量类型设置为`String`。

### 使用 For 循环迭代列表

迭代`List`的第三种方法是使用标准的`for`循环，如下所示:

```
List list = new ArrayList();

list.add("first");
list.add("second");
list.add("third");

for(int i=0; i < list.size(); i++) {
    Object element = list.get(i);
}
```

`for`循环创建一个`int`变量并将其初始化为 0。然后，只要 int 变量`i`小于列表的大小，它就会循环。对于每次迭代，变量`i`递增。

在`for`循环中，该示例通过其`get()`方法访问`List`中的元素，并将递增变量`i`作为参数传递。

同样，如果使用 Java 泛型将`List`类型化为例如`String`，那么您可以使用`List`的泛型类型作为局部变量的类型，该变量在迭代过程中被分配给`List`中的每个元素。一个例子将使这一点更加清楚:

```
List<String> list = new ArrayList<String>();

list.add("first");
list.add("second");
list.add("third");

for(int i=0; i < list.size(); i++) {
    String element = list.get(i);
}
```

注意`for`循环中的局部变量类型现在是`String`。因为`List`一般被类型化为`String`，所以它只能包含`String`对象。因此，编译器知道只有一个`String`可以从`get()`方法返回。因此，您不需要将由`get()`返回的元素强制转换为`String`。

### 使用 Java 流 API 迭代列表

迭代 Java `List`的第四种方式是通过[Java Stream](/java-functional-programming/streams.html) API。要迭代一个 Java `List`，你必须首先从`List`获得一个`Stream`。从 Java 中的`List`获取一个`Stream`是通过调用`List` `stream()`方法来完成的。下面是一个从 Java `List`获得 Java `Stream`的例子:

```
List<String> stringList = new ArrayList<String>();

stringList.add("abc");
stringList.add("def");

Stream<String> stream = stringList.stream();
```

这个例子的最后一行调用了`List` `stream()`方法来获得代表`List`中元素的`Stream`。

一旦从`List`中获得了`Stream`，就可以通过调用`forEach()`方法来迭代`Stream`。下面是一个使用`Stream` `forEach()`方法迭代`List`元素的例子:

```
List<String> stringList = new ArrayList<String>();

stringList.add("one");
stringList.add("two");
stringList.add("three");

Stream<String> stream = stringList.stream();

stream
    .forEach( element -> { System.out.println(element); });
```

调用`forEach()`方法将使`Stream`内部迭代`Stream`的所有元素，并为`Stream`中的每个元素调用作为参数传递给`forEach()`方法的`Consumer`。

你可以在我的[Java 流 API 教程](/java-functional-programming/streams.html)中阅读更多关于通过 Java 流 API 处理`List`元素的不同选项。
