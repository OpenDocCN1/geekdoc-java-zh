
# SVG 多边形元素

> 原文：<https://jenkov.com/tutorials/svg/polygon-element.html>

SVG `<polygon>`元素用于绘制有多个（3 个或更多）边的形状。

## SVG 多边形示例

下面是一个简单的 SVG 多边形示例：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
    <polygon points="10,0 60,0 35,50" style="stroke:#660000; fill:#cc3333;"/>
</svg>
```

以下是生成的图像：

<svg width="320" height="70">
    <polygon points="10,2 60,2 35,52" style="stroke:#660000; fill:#cc3333;"/>
</svg>

您可能会注意到，即使只列出了 3 个点，也绘制了所有 3 条边。这是因为`<polygon>`元素在所有点之间画了线，包括从最后一个点到第一个点的线。`<polyline>`不从最后一个点到第一个点画一条线。这似乎是`<polygon>`和`<polyline>`元素的唯一区别。

这里有一个更大的例子——一个八边形（八角形？）：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
    <polygon points="50,5 100,5 125,30 125,80 100,105 50,105 25,80 25, 30" style="stroke:#660000; fill:#cc3333; stroke-width: 3;"/>
</svg>
```

<svg width="320" height="150">
    <polygon points="50,05 100,5 125,30 125,80 100,105 50,105 25,80 25, 30" style="stroke:#660000; fill:#cc3333; stroke-width: 3;"/>
</svg>
