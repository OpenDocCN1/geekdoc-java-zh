
# SVG 路径元素

> 原文：<https://jenkov.com/tutorials/svg/path-element.html>

SVG `<path>`元素用于绘制由直线、弧线、曲线等组合而成的高级形状。有或没有填充物。`<path>`元素可能是所有 SVG 形状中最高级和最通用的。这可能也是最难掌握的元素。

# 路径示例

让我们首先从一个简单的 SVG `<path>` 例子开始：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
  <path d="M50,50 A30,30 0 0,1 35,20 L100,100 M110,110 L100,0" style="stroke:#660000; fill:none;"/>
</svg>
```

以下是生成的图像：

请注意该图像如何包含一条弧和两条线，以及第二条线如何没有与第一条弧和线连接。

所有带有 `<path>` 元素的绘图都在 `d` 属性中指定。`d` 属性包含绘图命令。在上面的例子中，`M` 表示“移动到”命令，`A` 表示“弧形”命令，`L` 表示“直线”命令。命令被发送给“虚拟笔”。这支笔可以移动，用来画形状等。

## 设置和移动笔

`<path>` `d` 属性内的第一个绘图命令应该始终是一个移动命令。在你画任何东西之前，你应该把虚拟笔移动到某个位置。这是使用 `M` 命令完成的。这里有一个简单的例子：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
  <path d="M50,50" style="stroke:#660000; fill:none;"/>
</svg>
```

该示例将虚拟笔移动到点 `50,50`。下一个绘图命令将从该点开始。

## 线

画一条线可能是你能给 `<path>` 元素的最简单的命令。使用 `L` 和 `l`（小写 L）命令画线。这里有一个例子：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
  <path d="M50,50 L100,100" style="stroke:#660000; fill:none;"/>
</svg>
```

本例从点 `50,50`（`M` 命令的点）到点 `100,100`（`L` 命令的点）画一条线。以下是生成的图像：

`L` 和 `l` 命令的区别在于大写版本（`L`）画一条线到传递给命令的绝对点，而小写版本（`l`）画一条线到传递给命令的相对点。相对点是线开始前虚拟笔的点加上给 `l` 命令的坐标。

如果虚拟笔位于 `50,50` 并且您使用了一个 `l100,100` 命令，该线将被绘制到 `50+100,50+100` = `150,150`。使用一个 `L100,100` 命令将会准确地画出到 `100,100` 的线，而不管虚拟笔的位置。

## 绘图会移动虚拟笔

路径形状总是从最后一个虚拟笔尖到新点绘制。每个绘图命令都有一个端点。执行该命令后，虚拟笔尖将位于该绘图命令的终点。下一个绘图命令将从该点开始。

## 弧

使用 `<path>` 元素绘制圆弧是通过使用 `A` 和 `a` 命令完成的。与线条一样，大写命令（`A`）使用绝对坐标作为其端点，而小写命令（`a`）使用相对坐标（相对于起点）。这里有一个例子：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
  <path d="M50,50 A30,50 0 0,1 100,100" style="stroke:#660000; fill:none;"/>
</svg>
```

以下是生成的图像：

该示例从点 `50,50` 到点 `100,100`（在 `A` 命令中最后指定）画一条弧。

圆弧的半径由 `A` 命令的前两个参数设置。第一个参数是 `rx`（x 方向的半径），第二个是 `ry`（y 方向的半径）。将 `rx` 和 `ry` 设置为相同的值会产生一个圆弧。将 `rx` 和 `ry` 设置为不同的值将产生椭圆弧。在上面的例子中，`rx` 被设置为 `30`，而 `ry` 被设置为 `50`。

在 `A` 命令上设置的第三个参数是 `x-axis-rotation`。这将设置圆弧 x 轴相对于法线 x 轴的旋转。在上面的例子中，`x-axis-rotation` 被设置为 `0`。大多数情况下，您不需要更改该参数。

第四个和第五个参数是 `large-arc-flag` 和 `sweep-flag` 参数。`large-arc-flag` 决定是否画满足起点、终点和 `rx` 与 `ry` 的较小或较大的圆弧。这里有一个例子，画了 4 个弧，每个弧都有不同的 `large-arc-flag` 和 `sweep-flag` 组合：

```
<path d="M40,20 A30,30 0 0,0 70,70" style="stroke: #cccc00; stroke-width:2; fill:none;"/>
<path d="M40,20 A30,30 0 1,0 70,70" style="stroke: #ff0000; stroke-width:2; fill:none;"/>
<path d="M40,20 A30,30 0 1,1 70,70" style="stroke: #00ff00; stroke-width:2; fill:none;"/>
<path d="M40,20 A30,30 0 0,1 70,70" style="stroke: #0000ff; stroke-width:2; fill:none;"/>
```

以下是生成的图像：

从 `40,20` 到点 `60,70` 可以画出四条不同的弧线。一个长弧、一个小弧和每个小/大弧的两个镜像版本。`large-arc-flag` 决定是画大弧还是小弧。`sweep-flag` 决定从起点到终点，圆弧是否围绕轴镜像。实际上，`sweep-flag` 控制着弧线的绘制方向（顺时针或逆时针），从而产生“镜像”效果。

绘制的第一条弧线是黄色弧线。将 `large-arc-flag` 设置为 0 意味着将绘制较小的可能圆弧。`sweep-flag` 也被设置为 0，表示弧没有被镜像。这是黄色的弧线：

绘制的第二条弧线是红色弧线。将 `large-arc-flag` 设置为 `1` 意味着从 `40,20` 到 `60,70` 绘制两个可能圆弧中较大的一个。下面是一起显示的黄色和红色弧线，以说明区别：

绿色和蓝色弧线（来自前面的例子，有四条弧线）与黄色和红色弧线相同，但是是在 `sweep-flag` 设置为 `1` 的情况下绘制的。这意味着它们将绘制相同的弧，但在从起点到终点的轴上镜像。

## 二次贝塞尔曲线

也可以使用 `<path>` 元素绘制二次贝塞尔曲线。用 `Q` 和 `q` 命令绘制二次贝塞尔曲线。与线条一样，大写命令（`Q`）使用绝对坐标作为其端点，而小写命令（`q`）使用相对坐标（相对于起点）。下面是一个简单的二次曲线示例：

```
<path d="M50,50 Q50,100 100,100" style="stroke: #006666; fill:none;"/>
```

该示例绘制了一条从 `50,50` 到点 `100,100` 的二次贝塞尔曲线，控制点在 `50,200`。控制点是在 `Q` 命令上设置的两个参数中的第一个。

控制点像磁铁一样拉动曲线。曲线上的点离控制点越近，控制点就越靠近它，这意味着它离控制点越近。以下是一些在图像上绘制控制点的示例：

## 三次贝塞尔曲线

使用 `C` 和 `c` 命令绘制三次贝塞尔曲线。三次贝塞尔曲线类似于二次贝塞尔曲线，只是它们有两个控制点，而不是一个。与直线一样，大写命令（`C`）使用绝对坐标作为其端点，而小写命令（`c`）使用相对坐标（相对于起点）。这里有一个例子：

```
<path d="M50,50 C75,80 125,20 150,50" style="stroke: #006666; fill:none;"/>
```

## 关闭路径

`<path>` 元素有一个关闭路径的快捷命令，意思是从最后一点画一条线回到第一点。命令是 `Z`（或 `z`——关闭路径命令的大小写没有区别）。这里有一个例子：

## 组合命令

您可以在同一个 `<path>` 元素中组合路径命令。这里有一个例子：

## 标记

您可以在 `<path>` 元素上使用标记。标记是位于路径起点、中间和终点的小符号，显示路径的方向。例如，路径的起点是圆形或方形，终点是箭头。

标记在[标记元素](marker-element.html)文本中有更详细的解释。

## 符号快捷键

如果需要多次使用同一个命令，可以省略命令字母，只需提供一组额外的参数，就好像命令就在那里一样。这里有一个例子：

```
<path d="M10,10 l100,0 0,50 -100,0 0,-50" style="stroke: #000000; fill:none;" />
```

这个例子显示了附加参数是如何传递给 `l` 命令的，就好像一个 `l` 位于每个参数对的前面一样。这也适用于其他路径命令。以下是生成的图像：

## 路径命令

下面是 SVG `path` 元素可能的笔命令列表。每个命令由一个字母和一组数字（坐标等）组成，是该命令的参数。大写命令通常将坐标参数解释为绝对坐标。小写命令通常将坐标参数解释为相对于当前笔位置。

| 命令 | 参数 | 名称 | 描述 |
|------|------|------|------|
| `M` | `x,y` | 移至 | 在不绘制的情况下，将笔移动到指定的点 `x,y`。 |
| `m` | `x,y` | 移至 | 将笔移动到相对于当前笔位置的指定点 `x,y`，而不进行绘制。 |
| `L` | `x,y` | 线到 | 从当前笔位置到指定点 `x,y` 绘制一条直线。 |
| `l` | `x,y` | 线到 | 从当前笔位置到相对于当前笔位置的指定点 `x,y` 绘制一条直线。 |
| `H` | `x` | 水平线到 | 画一条水平线到由 `x` 定义的点（指定 x，笔当前 y）。 |
| `h` | `x` | 水平线到 | 画一条水平线到由 `x` 定义的点（笔当前 x + 指定 x，笔当前 y）。`x` 相对于当前笔的 x 位置。 |
| `V` | `y` | 垂直线到 | 画一条垂直线到由 `y` 定义的点（笔当前 x，指定 y）。 |
| `v` | `y` | 垂直线到 | 画一条垂直线到由 `y` 定义的点（笔电流 x，笔电流 y + 指定的 y）。`y` 相对于笔的当前 y 位置。 |
| `C` | `x1,y1 x2,y2 x,y` | 曲线到 | 从当前笔点到 `x,y` 绘制一条三次贝塞尔曲线。`x1,y1` 和 `x2,y2` 是曲线的开始和结束控制点，控制曲线的弯曲方式。 |
| `c` | `x1,y1 x2,y2 x,y` | 曲线到 | 与 `C` 相同，但解释相对于当前笔尖的坐标。 |
| `S` | `x2,y2 x,y` | 速记/平滑曲线 | 从当前笔尖到 `x,y` 绘制一条三次贝塞尔曲线。`x2,y2` 是结束控制点。假设开始控制点与前一条曲线的结束控制点相同。 |
| `s` | `x2,y2 x,y` | 平滑的曲线 | 与 `S` 相同，但解释相对于当前笔尖的坐标。 |
| `Q` | `x1,y1 x,y` | 二次贝塞尔曲线到 | 从当前笔尖到 `x,y` 绘制二次贝塞尔曲线。`x1,y1` 是控制曲线弯曲方式的控制点。 |
| `q` | `x1,y1 x,y` | 二次贝塞尔曲线到 | 与 `Q` 相同，但解释相对于当前笔尖的坐标。 |
| `T` | `x,y` | 速记/平滑二次贝塞尔曲线 | 从当前笔点到 `x,y` 绘制一条二次贝塞尔曲线。控制点被假定为与最后使用的控制点相同。 |
| `t` | `x,y` | 速记/平滑二次贝塞尔曲线 | 与 `T` 相同，但解释相对于当前笔尖的坐标。 |
| `A` | `rx,ry x-axis-rotation large-arc-flag, sweep-flag x,y` | 椭圆弧 | 绘制从当前点到 `x,y` 点的椭圆弧。`rx` 和 `ry` 是 x 和 y 方向的椭圆半径。`x-axis-rotation` 决定了圆弧围绕 x 轴旋转的角度。只有当 `rx` 和 `ry` 的值不同时，它才会起作用。似乎没有使用大圆弧标志（可以是 0 或 1）。值（0 或 1）都不会改变弧。扫描标志决定了画弧线的方向。 |
| `a` | `rx,ry x-axis-rotation large-arc-flag, sweep-flag x,y` | 椭圆弧 | 与 `A` 相同，但解释相对于当前笔尖的坐标。 |
| `Z` | — | 封闭路径 | 通过从当前点到第一点绘制一条线来闭合路径。 |
| `z` | — | 封闭路径 | 通过从当前点到第一点绘制一条线来闭合路径。 |
