## 数学/笛卡尔坐标系

在正常的笛卡尔坐标系中，点`x=0`，`y=0`位于图的左下角处。随着`x`的增加，点在坐标系中向右移动。随着`x`的减小，点在坐标系中向左移动。随着`y`的增加，点在坐标系中向上移动。随着`y`的减小，点在坐标系中向下移动。

## SVG 坐标系

在 SVG 坐标系中，点`x=0`，`y=0`就是左上角。因此，与正常的图形坐标系相比，`y`轴是反向的。随着 SVG 中`y`的增加，点、形状等向下移动，而不是向上。

下图是左上角为`0，0`的 SVG 坐标系：

  <line x1="15" y1="105" x2="10" y2="110" style="stroke:#006600;"/>

</svg>

## 坐标系单位

可以指定`1`在 SVG 坐标系中对应的单位。你可以在任何地方指定一个坐标（`x`和`y`位置，`width`和`height`等）。在数值后指定单位，例如`10cm`或`125mm`。

如果在坐标值后没有指定任何单位，则单位被假定为像素（`px`）。

以下是 SVG 元素可以使用的单位列表：

| 单位 | 描述 |
|------|------|
| `em` | 默认字体大小——通常是字符的高度。 |
| `ex` | 字符`x`的高度 |
| `px` | 像素 |
| `pt` | 点（1 / 72 英寸） |
| `pc` | 十二点活字（1 / 6 英寸） |
| `cm` | 厘米 |
| `mm` | 毫米 |
| `in` | 英寸 |

您在`width`和`height`属性中的`<svg>`元素上设置的单位仅影响`<svg>`元素（视口）。`<svg>`元素中的形状必须有自己的单位集。同样，如果没有指定单位，单位默认为像素。
