
# SVG 椭圆元素

> 原文：<https://jenkov.com/tutorials/svg/ellipse-element.html>

SVG `<ellipse>`元素用于绘制椭圆。椭圆是一个高度和宽度不等的圆。换句话说，它在 x 和 y 方向的半径是不同的。

## SVG 椭圆示例

下面是一个 SVG 椭圆示例：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
  <ellipse cx="40" cy="40" rx="30" ry="15" style="stroke:#006600; fill:#00cc00"/>
</svg>
```

以下是生成的图像：

<svg width="320" height="70">
  <ellipse cx="40" cy="40" rx="30" ry="15" style="stroke:#006600; fill:#00cc00"/>
</svg>

椭圆像圆一样以`cx`、`cy`为中心。但是 x 和 y 方向的半径是由两个属性指定的，而不是一个：属性`rx`和`ry`。如您所见，`rx`属性的值比`ry`属性的值高，这使得椭圆的宽度大于高度。将`rx`和`ry`属性设置为相同的数字会产生一个规则的圆。

## 笔画宽度

您可以使用`stroke-width`样式属性设置椭圆的笔画宽度。这里有一个例子：

```
<ellipse cx="50" cy="50" rx="40" ry="30" style="stroke: #ff0000; stroke-width: 5; fill: none; "/>
```

以下是渲染时生成的椭圆的外观：

<svg height="100">
  <ellipse cx="50" cy="50" rx="40" ry="30" style="stroke: #ff0000; stroke-width: 5; fill: none; "/>
</svg>

## 笔画-仪表板阵列

您可以使用[`stroke-dasharray`](/svg/stroke.html#stroke-dasharray-stroke-dashoffset)样式属性使椭圆的线条变为虚线。这里有一个例子：

```
<ellipse cx="50" cy="50" rx="40" ry="30" style="stroke: #ff0000; stroke-width: 5; stroke-dasharray: 10 5; fill: none; "/>
```

本示例将破折号宽度设置为 10，破折号间距（破折号之间的间距）设置为 5。下面是椭圆渲染后的样子：

<svg height="100">
  <ellipse cx="50" cy="50" rx="40" ry="30" style="stroke: #ff0000; stroke-width: 5; stroke-dasharray: 10 5; fill: none; "/>
</svg>

## 笔画不透明度

您可以使用[`stroke-opacity`样式属性](/svg/stroke.html#stroke-opacity)使 SVG 椭圆的描边半透明。这里有一个例子：

```
<ellipse cx="50" cy="50" rx="40" ry="30" style="stroke: #ff0000; stroke-width: 5; fill: none; "/>
<ellipse cx="60" cy="60" rx="40" ry="30" style="stroke: #0000ff; stroke-width: 5; stroke-opacity: 0.5; fill: none; "/>
```

下面是这些 SVG 椭圆呈现时的样子：

<svg height="120">
  <ellipse cx="50" cy="50" rx="40" ry="30" style="stroke: #ff0000; stroke-width: 5; fill: none; "/>
  <ellipse cx="60" cy="60" rx="40" ry="30" style="stroke: #0000ff; stroke-width: 5; stroke-opacity: 0.5; fill: none; "/>
</svg>

请注意第二个（蓝色）椭圆是如何透明的，以及如何透过它的描边看到红色椭圆。

## 充满

`fill`样式属性用于设置如何填充椭圆。这里有一个例子：

```
<ellipse cx="50" cy="50" rx="40" ry="30" style="stroke: #ff0000; stroke-width: 5; fill: #ff6666; "/>
```

下面是这个 SVG 椭圆渲染后的样子：

<svg height="120">
  <ellipse cx="50" cy="50" rx="40" ry="30" style="stroke: #ff0000; stroke-width: 5; fill: #ff6666; "/>
</svg>

## 填充-不透明度

[`fill-opacity`样式属性](/svg/fill.html#fill-opacity)可用于设置椭圆填充颜色的不透明度。这里有一个例子：

```
<ellipse cx="50" cy="50" rx="40" ry="30" style="stroke: #ff0000; stroke-width: 5; fill: none; "/>
<ellipse cx="60" cy="60" rx="40" ry="30" style="stroke: none; fill: #0000ff; fill-opacity: 0.5; "/>
```

下面是这些椭圆渲染后的样子：

<svg height="120">
  <ellipse cx="50" cy="50" rx="40" ry="30" style="stroke: #ff0000; stroke-width: 5; fill: none; "/>
  <ellipse cx="60" cy="60" rx="40" ry="30" style="stroke: none; fill: #0000ff; fill-opacity: 0.5; "/>
</svg>

注意第二个（蓝色）椭圆是半透明的，使红色椭圆透过它可见。
