
# Java 枚举

> 原文：<https://jenkov.com/tutorials/java/enums.html>

Java 枚举是一种特殊的 Java 类型，用于定义常量集合。更准确地说，Java 枚举类型是一种特殊的 Java 类。枚举可以包含常量、方法等。Java 5 中增加了 Java 枚举。

## 枚举示例

下面是一个简单的 Java 枚举示例：

```java
public enum Level {
    HIGH,
    MEDIUM,
    LOW
}
```

注意用于代替`class`或`interface`的关键词`enum`。Java `enum`关键字通知 Java 编译器这个类型定义是一个枚举。

您可以像这样引用上面枚举中的常量：

```java
Level level = Level.HIGH;
```

注意`level`变量是如何属于类型`Level`的，这是上面例子中定义的 Java 枚举类型。`level`变量可以将`Level`个枚举常量之一作为值（`HIGH`、`MEDIUM`或`LOW`）。在这种情况下，`level`被设置为`HIGH`。

## if 语句中的枚举

因为 Java 枚举是常量，所以您经常需要将指向枚举常量的变量与枚举类型中可能的常量进行比较。下面是一个在`if`语句中使用 Java 枚举的例子：

```java
Level level = ... //assign some Level constant to it

if( level == Level.HIGH) {

} else if( level == Level.MEDIUM) {

} else if( level == Level.LOW) {

}
```

这段代码将`level`变量与`Level`枚举中每个可能的枚举常量进行比较。

如果某个枚举值比其他值出现得更频繁，那么在第一个`if`语句中检查该值将会获得更好的性能，因为平均来说执行的比较更少。不过，这并不是一个很大的区别，除非经常进行比较。

## switch 语句中的枚举

如果您的 Java 枚举类型包含许多常量，并且您需要检查变量的值，如前一节所示，那么使用 Java `switch`语句可能是个好主意。

可以在 switch 语句中使用枚举，如下所示：

```java
Level level = ... //assign some Level constant to it

switch (level) {
    case HIGH : ...; break;
    case MEDIUM : ...; break;
    case LOW : ...; break;
}
```

如果`level`变量与给定的级别常量值匹配，则用要执行的代码替换`...`。代码可以是简单的 Java 操作、方法调用等。

## 枚举迭代

通过调用 Java enum 类型的静态`values()`方法，可以获得该类型所有可能值的数组。所有枚举类型都由 Java 编译器自动获得一个静态的`values()`方法。以下是迭代枚举的所有值的示例：

```java
for (Level level : Level.values()) {
    System.out.println(level);
}
```

运行这段 Java 代码将打印出所有的枚举值。以下是输出：

```java
HIGH
MEDIUM
LOW
```

注意常量本身的名称是如何打印出来的。这是 Java 枚举不同于`static final`常量的一个方面。

## Enum toString()

一个枚举类在编译时会自动获取该类中的一个`toString()`方法。`toString()`方法返回给定枚举实例名称的字符串值。这里有一个例子：

```java
String levelText = Level.HIGH.toString();
```

执行上述语句后，`levelText`变量的值将是文本`HIGH`。

## 枚举打印

如果打印一个枚举，如下所示：

```java
System.out.println(Level.HIGH);
```

然后会在后台调用`toString()`方法，所以输出的值是枚举实例的文本名称。换句话说，在上面的例子中，文本`HIGH`将被打印出来。

## 枚举 valueOf()

enum 类在编译时会自动获取类中的静态`valueOf()`方法。`valueOf()`方法可用于获取给定字符串值的枚举类的实例。这里有一个例子：

```java
Level level = Level.valueOf("HIGH");
```

执行完这一行后，`level`变量将指向`Level.HIGH`。

## 枚举字段

您可以向 Java 枚举添加字段。因此，每个常量枚举值都会得到这些字段。定义常数时，必须将字段值提供给枚举的构造函数。这里有一个例子：

```java
public enum Level {
    HIGH  (3),  //calls constructor with value 3
    MEDIUM(2),  //calls constructor with value 2
    LOW   (1)   //calls constructor with value 1
    ; // semicolon needed when fields / methods follow

    private final int levelCode;

    private Level(int levelCode) {
        this.levelCode = levelCode;
    }
}
```

注意上面例子中的 Java enum 有一个带`int`的构造函数。枚举构造器设置`int`字段。当常量枚举值被定义时，一个`int`值被传递给枚举构造函数。

`enum`构造函数必须是`private`。你不能为一个 Java `enum`使用`public`或`protected`构造函数。如果你没有指定一个访问修饰符`enum`构造函数，它将被隐式地`private`。

## 枚举方法

您也可以向 Java 枚举添加方法。这里有一个例子：

```java
public enum Level {
    HIGH  (3),  //calls constructor with value 3
    MEDIUM(2),  //calls constructor with value 2
    LOW   (1)   //calls constructor with value 1
    ; // semicolon needed when fields / methods follow

    private final int levelCode;

    Level(int levelCode) {
        this.levelCode = levelCode;
    }

    public int getLevelCode() {
        return this.levelCode;
    }
}
```

通过引用一个常量值来调用 Java enum 方法。以下是 Java enum 方法调用示例：

```java
Level level = Level.HIGH;
System.out.println(level.getLevelCode());
```

这段代码将打印出值`3`，它是枚举常量`HIGH`的`levelCode`字段的值。

您并不局限于简单的 getter 和 setter 方法。还可以创建基于 enum 常量的字段值进行计算的方法。如果您的字段没有声明`final`，您甚至可以修改字段的值（尽管这可能不是一个好主意，考虑到枚举应该是常量）。

## 枚举抽象方法

Java 枚举类也可能有抽象方法。如果一个枚举类有一个抽象方法，那么该枚举类的每个实例都必须实现它。下面是一个 Java enum 抽象方法示例：

```java
public enum Level {
    HIGH {
        @Override
        public String asLowerCase() {
            return HIGH.toString().toLowerCase();
        }
    },
    MEDIUM {
        @Override
        public String asLowerCase() {
            return MEDIUM.toString().toLowerCase();
        }
    },
    LOW {
        @Override
        public String asLowerCase() {
            return LOW.toString().toLowerCase();
        }
    };

    public abstract String asLowerCase();
}
```

注意 enum 类底部的抽象方法声明。还要注意每个枚举实例（每个常量）是如何定义这个抽象方法的自己的实现的。当您需要为 Java 枚举的每个实例使用不同的方法实现时，使用抽象方法非常有用。

## 枚举实现接口

一个 Java `Enum`可以实现一个 [Java 接口](interfaces.html)，如果你觉得在你的情况下有意义的话。下面是一个 Java `Enum`实现接口的例子：

```java
public enum EnumImplementingInterface implements MyInterface {
    FIRST("First Value"),
    SECOND("Second Value");

    private String description = null;

    private EnumImplementingInterface(String desc){
        this.description = desc;
    }

    @Override
    public String getDescription() {
        return this.description;
    }
}
```

就是来自接口`MyInterface`的方法`getDescription()`。

用一个`Enum`实现一个接口可以用来实现一组不同的`Comparator`常量，这些常量可以用来对对象集合进行排序。Java 中对象的排序在 [Java 集合排序教程](/java-collections/sorting.html)中有更详细的解释。

## EnumSet

Java 包含一个名为`EnumSet`的特殊的 [Java Set](/java-collections/set.html) 实现，它可以比标准的 Java Set 实现更有效地保存枚举。下面是如何创建一个`EnumSet`的实例：

```java
EnumSet<Level> enumSet = EnumSet.of(Level.HIGH, Level.MEDIUM);
```

一旦创建，您就可以像使用其他集合一样使用`EnumSet`。

## EnumMap

Java 还包含一个特殊的 [Java Map](/java-collection/map.html) 实现，它可以使用 Java enum 实例作为键。下面是一个 Java `EnumMap`的例子：

```java
EnumMap<Level, String> enumMap = new EnumMap<Level, String>(Level.class);
enumMap.put(Level.HIGH  , "High level");
enumMap.put(Level.MEDIUM, "Medium level");
enumMap.put(Level.LOW   , "Low level");

String levelValue = enumMap.get(Level.HIGH);
```

## 枚举杂项详细信息

Java 枚举隐式扩展了`java.lang.Enum`类，所以你的枚举类型不能扩展另一个类。

如果 Java enum 包含字段和方法，那么字段和方法的定义必须总是在 enum 中常量列表的后面。此外，枚举常量列表必须以分号结束。
