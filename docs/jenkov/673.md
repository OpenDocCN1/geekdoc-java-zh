
# Java switch 语句

> 原文：<https://jenkov.com/tutorials/java/switch.html>

一个 *Java* *switch* 语句使你能够根据某个变量的值选择一组要执行的语句。这实际上有点类似于一个 [Java if](if.html) 语句，尽管 Java *switch* 语句提供了一个更加压缩的语法，以及稍微不同的行为和可能性。在这篇 *Java switch 教程*中，我将解释最初的 Java *switch* 指令是如何工作的，以及对 switch 指令的修改，它能够打开 [Java 枚举](enums.html)、 [Java 字符串](strings.html)，最后是在 Java 12 中添加并在 Java 13 中改进的新的 *switch 表达式*语法。

## Java Switch 语句示例

让我们从一个 Java `switch`语句代码示例开始:

```
int amount = 9;
switch(amount) {
    case 0 : System.out.println("amount is 0"); break;
    case 5 : System.out.println("amount is 5"); break;
    case 10 : System.out.println("amount is 10"); break;
    default : System.out.println("amount is something else");
}
```

这个 `switch` 示例首先创建一个名为`amount`的变量，并将值`9`赋给它。

其次，这个例子“打开”了变量`amount`的值。在`switch`语句中有 3 个`case`语句和一个`default`语句。

每个`case`语句将`amount`变量的值与一个常量值进行比较。如果`amount`变量值等于常量值，则执行冒号(:)后的代码。注意每条语句后的`break`关键字。如果这里没有放置`break`关键字，执行可以继续沿着剩余的`case`语句，直到遇到`break`，或者到达`switch`语句的结尾。`break`关键字使执行跳出`switch`语句。

如果没有`case`语句与`amount`变量的值匹配，则执行`default`语句。如果之前的`case`语句最后没有`break`命令，也可以执行`default`语句。不需要`default`语句。它是可选的。

## 等效的 if 语句

开头所示的 Java `switch`示例相当于下面一组 [Java if 语句](if.html):

```
int amount = 9;
if (amount == 0) {
    System.out.println("amount is 0");
} else if(amount == 5) {
    System.out.println("amount is 5");
} else if(amount == 10){
    System.out.println("amount is 10");
} else {
    System.out.println("amount is something else";
}
```

虽然看起来几乎一样，但有些情况下使用 Java `switch`语句更容易、更快。此外，Java 12 中添加的新的 Java `switch`表达式(见本教程后面的内容)使得 `switch`语句可以实现一些 `if`语句无法实现的结构。

## 打开参数

在本 Java `switch`教程开头所示的例子中，我们声明了一个`int`变量，并立即将 is 值设置为 9。在真实的 Java 应用程序中，您很可能不会这样做。相反，你可以打开一个方法的输入参数的值，或者打开一个通过网络从文件中读取的值。下面是一个打开方法参数的示例:

```
private static void switchOnIntegers(int size) {
    switch(size) {
        case 0 : {
            System.out.println("size is small");
            break;
        }
        case 1 : {
            System.out.println("size is medium");
            break;
        }
        case 2 : {
            System.out.println("size is large");
            break;
        }
        case 3 : {
            System.out.println("size is X-large");
            break;
        }
        default : {
            System.out.println("size is not S,M,L or XL: " + size);
        }
    }
}
```

### 打开 Java 枚举

也可以打开一个 [Java enum](enums.html)。下面是一个 Java 示例，它创建了一个 Java `enum`，然后在一个 `switch`语句中使用它:

```
public class SwitchOnEnum{

    private static void switchOnEnum(Size size) {
        switch(size) {

                System.out.println("size is small");
                break;
            }
            case MEDIUM : {
                System.out.println("size is medium");
                break;
            }
            case LARGE : {
                System.out.println("size is large");
                break;
            }
            case X_LARGE : {
                System.out.println("size is X-large");
                break;
            }

                default : {
                    System.out.println("size is not S,M,L or XL: " + size);

        }

}
```

## 同一操作的多个 case 语句

如果您希望对多个`case`语句执行相同的操作，您可以这样写:

```
char key = '\t'
switch(key) {
    case ' ' :
    case '\t' :
        System.out.println("white space char");
        break;
    default :
        System.out.println("char is something else");
}
```

注意第一个`case`语句在冒号后没有任何操作。这样做的结果是，执行只是"落到"下一个 `case`语句(以及下一个等等)的操作。)直到遇到一个`break`为止。下一个`break`语句在第二个`case`语句之后。这意味着，对于第一个和第二个`case`语句，执行相同的操作——第二个`case`语句的操作。

### 每个 Case 语句有多个值

从 Java 13 开始，每个`case`语句也可以有多个值，而不是多个 `case`语句一直到下一个。下面是上一节中的示例，该示例被改写为在单个`state`语句中使用多个值:

```
char key = '\t'
switch(key) {
    case ' ', '\t' :
        System.out.println("white space char");
        break;
    default:
        System.out.println("char is something else");
}
```

注意第一个 `case`语句的多个值是如何用逗号分隔的。

## Java 开关表达式

Java 12 增加了开关表达式作为实验特性。一个 Java `switch`表达式一个可以返回值的 `switch`语句。因此，它可以作为一个表达式来计算，就像其他 Java 表达式一样(也可以计算一个值)。在这一节中，我将向您展示 Java 12 的 Java 开关表达式是如何工作的。

记住，我这里有本教程 Java `switch`表达式部分的视频版本:

<iframe width="560" height="315" src="https://www.youtube.com/embed/-vsd3IAD81U" frameborder="0" allow="accelerometer; autoplay; encrypted-media; gyroscope; picture-in-picture" allowfullscreen=""/>

这里首先是一个 Java 开关表达式的例子:

```
int digitInDecimal = 12;
char digitInHex = switch(digitInDecimal){
    case 0 -> '0';
    case 1 -> '1';
    case 2 -> '2';
    case 3 -> '3';
    case 4 -> '4';
    case 5 -> '5';
    case 6 -> '6';
    case 7 -> '7';
    case 8 -> '8';
    case 9 -> '9';
    case 10 -> 'A';
    case 11 -> 'B';
    case 12 -> 'C';
    case 13 -> 'D';
    case 14 -> 'E';
    case 15 -> 'F';
    default -> '?';
};
System.out.println(digitInHex);
```

这个 Java `switch`表达式示例将 0 到 15 之间的值转换为十六进制数字字符。

注意每个`case`语句后面的冒号(`:`)是如何被一个`->`操作符替换的。这个操作符用在 `switch`表达式中，向 Java 编译器发出信号，表明这个`case`语句选择了 `switch`表达式的返回值，而不是选择要执行的代码块。

还要注意，`case`语句后面没有`break`关键字。因为用`->`操作符选择的值被解释为开关表达式的返回值，所以每个语句后面的`break`是隐式的(实际上是不必要的)。您也可以将`->`视为一个`return`语句，它从 `switch`表达式返回一个值，从而中断 `switch`表达式的执行。

最后，注意如何将`switch`表达式的返回值赋给`digitInHex`变量。这就是如何捕获 Java 开关表达式的输出。您也可以将其值作为方法的返回值返回，如下所示:

```
public char toHexDigit(int digitInDecimal) {
    return switch(digitInDecimal){
        case 0 -> '0';
        case 1 -> '1';
        case 2 -> '2';
        case 3 -> '3';
        case 4 -> '4';
        case 5 -> '5';
        case 6 -> '6';
        case 7 -> '7';
        case 8 -> '8';
        case 9 -> '9';
        case 10 -> 'A';
        case 11 -> 'B';
        case 12 -> 'C';
        case 13 -> 'D';
        case 14 -> 'E';
        case 15 -> 'F';
        default -> '?';
    };
}
```

Java 开关表达式也适用于 [Java 字符串](strings.html)值。下面是一个使用字符串打开的 Java 开关表达式示例:

```
String token = "123";
int tokenType = switch(token) {
    case "123" -> 0;
    case "abc" -> 1;
    default -> -1;
};
```

此示例基于字符串标记的值解析标记类型(整数值)。

### Java 开关产出指令

在 Java 13 中，您可以使用 Java `switch` yield 指令从 Java `switch`表达式中返回值，而不是使用箭头运算符(`->`)。下面是一个 Java `switch` yield 指令的例子:

```
String token = "123";
int tokenType = switch(token) {
    case "123" : yield 0;
    case "abc" : yield 1;
    default : yield -1;
};
```
