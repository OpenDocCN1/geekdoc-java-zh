
# 区块链项目和资源

> 原文：<https://jenkov.com/tutorials/blockchain/projects-and-resources.html>

自 2008 年比特币论文发布以来，出现了许多区块链和加密货币项目和资源。在这个页面上，我列出了一些最突出和最有用的区块链项目和资源，供您开始您的区块链之旅。

## 区块链项目

| 项目 | 描述 |
| --- | --- |
| [比特币](https://bitcoin.org/) | 比特币的网站——开启整个区块链产业的第一个加密货币项目。 |
| [以太坊](https://ethereum.org/) | 以太坊是第一个拥有智能合约的区块链项目（据我所知）。 |
| [Monero](https://www.getmonero.org/) | Monero 是早期关注隐私的加密货币之一，现在仍然很受欢迎。 |
| [Discreet](https://discreet.net/) | Discreet 是一种专注于隐私的新型加密货币，与 Monero 相比，旨在提高隐私和速度。 |
| [NXT / Ignis / Ardor](https://www.jelurida.com/) | NXT 是一种加密货币，声称是第一个使用权益证明作为共识算法的加密货币。Ignis 和 Ardor 是相关的产品。 |
| [Dash](https://www.dash.org/) | Dash 是一种加密货币，似乎在南美和其他地方都很流行。Dash 甚至可以在那里的商店里使用。 |
| [Solana](https://solana.com/) | Solana 是一个具有更高性能的较新的区块链项目，使用权益证明作为共识算法。 |
| [Avalanche](https://www.avax.network/) | Avalanche 是一个更新的区块链项目，性能更高。 |
| [Brave](https://brave.com/) | Brave 是一款内置加密货币的网络浏览器，名为 BAT - Basic Attention Token。 |
| [LBRY](https://lbry.com/) | LBRY 是一个用于视频、音频、文本等的分散式数字内容平台，内置加密货币 LBC。LBRY 是一款 P2P 桌面和移动应用。 |
| [Odysee](https://odysee.com/) | Odysee 是一个更传统的网络应用程序，提供对 LBRY 网络上的大量内容的访问（见上文）。 |
| [Dfinity](https://dfinity.org/) | Dfinity 的目标是创建一个基于区块链的分布式计算平台，用加密货币作为支付计算资源的机制。 |
| [Metamask](https://metamask.io/) | Metamask 是一个加密货币钱包，能够容纳不同的加密货币。 |
| [Cake Wallet](https://cakewallet.com/) | Cake Wallet 是一个加密货币钱包，能够容纳 Monero、比特币和莱特币。 |
| [Ledger](https://www.ledger.com/) | Ledger 是一个硬件加密货币钱包，能够容纳不同的加密货币。 |

## 加密货币交易所

加密货币交易所是一个在线服务，你可以购买和出售加密货币。

| 交易所 | 描述 |
| --- | --- |
| [Uniswap](https://uniswap.org/) | 一个分散的加密货币交易所。 |
| [Coinbase](https://coinbase.com/) | 一个更大的、总部设在美国的加密货币交易所。 |
| [KuCoin](https://www.kucoin.com/) | 一个更大的、总部设在美国的加密货币交易所。 |
| [Binance](https://www.binance.com/en) | 一个更大的、位于开曼群岛（以前位于中国）的加密货币交易所。 |
