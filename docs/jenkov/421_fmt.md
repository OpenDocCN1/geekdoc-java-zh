# Java 流定义

Java *流*是一个能够对其元素进行*内部迭代*的组件，这意味着它可以自己迭代其元素。相反，当你使用 [Java 集合](/java-collections/index.html)迭代特性（例如 [Java 迭代器](/java-collections/iterator.html)或 Java for-each 循环使用与 [Java Iterable](/java-collections/iterable.html)）时，你必须自己实现元素的迭代。

# 流处理

您可以将*监听器*附加到`Stream`上。当`Stream`在内部迭代元素时，调用这些监听器。针对流中的每个元素调用一次侦听器。这样，每个监听器都可以处理流中的每个元素。这被称为*流处理*。

流的侦听器形成一个链。链中的第一个侦听器可以处理流中的元素，然后返回一个新元素供链中的下一个侦听器处理。监听器可以返回相同的元素或新的，这取决于监听器（处理器）的用途。

# 获得一个流

有很多方法可以获得 Java *流*。获得`Stream`最常见的方法之一是从 [Java 集合](/java-collections/index.html)中获得。下面是一个从 [Java 列表](/java-collections/list.html)中获取`Stream`的例子：

```java
List<String> items = new ArrayList<String>();

items.add("one");
items.add("two");
items.add("three");

Stream<String> stream = items.stream();
```

这个例子首先创建一个 Java `List`，然后向它添加三个 [Java 字符串](/java/strings.html)。最后，该示例调用`stream()`方法来获得一个`Stream`实例。

# 终端和非终端操作

`Stream`界面有*终端*和*非终端*操作的选择。一个*非终结流操作*是一个向流中添加监听器而不做任何其他事情的操作。一个*终端流操作*是启动元素内部迭代，调用所有监听器，并返回结果的操作。

下面是一个 Java 流示例，其中包含非终端和终端操作：

```java
import java.util.ArrayList;
import java.util.List;
import java.util.stream.Stream;

public class StreamExamples {

    public static void main(String[] args) {
        List<String> stringList = new ArrayList<String>();

        stringList.add("ONE");
        stringList.add("TWO");
        stringList.add("THREE");

        Stream<String> stream = stringList.stream();

        long count = stream
            .map((value) -> { return value.toLowerCase(); })
            .count();

        System.out.println("count = " + count);

    }
}
```

对`Stream`接口的`map()`方法的调用是非终结操作。它只是在流上设置一个 lambda 表达式，将每个元素转换成小写。`map()`方法将在后面详细介绍。

对`count()`方法的调用是一个终端操作。这个调用在内部开始迭代，这将导致每个元素被转换成小写，然后被计数。

将元素转换为小写实际上不会影响元素的数量。转换部分只是作为一个非终结操作的例子。

# 非终点操作

Java 流 API 的非终结流操作是转换或过滤流中元素的操作。当您向流中添加一个非终结操作时，您会得到一个新的流作为结果。新流表示由应用了非终结符操作的原始流产生的元素流。下面是一个添加到流中的非终结符操作的例子，它产生了一个新的流：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("ONE");
stringList.add("TWO");
stringList.add("THREE");

Stream<String> stream = stringList.stream();

Stream<String> stringStream =
    stream.map((value) -> { return value.toLowerCase(); });
```

注意对`stream`的调用`map()`。这个调用实际上返回了一个新的`Stream`实例，代表应用了映射操作的原始字符串流。

您只能向给定的`Stream`实例添加一个操作。如果您需要将多个操作串联起来，您需要将第二个操作应用于第一个操作产生的`Stream`操作。下面是它的样子：

```java
Stream<String> stringStream1 =
    stream.map((value) -> { return value.toLowerCase(); });

Stream<String> stringStream2 =
    stringStream1.map((value) -> { return value.toUpperCase(); });
```

注意第二个对`Stream` `map()`的调用是如何在第一个`map()`调用返回的`Stream`上被调用的。

在 Java `Stream`上，将调用链接到非终结操作是很常见的。下面是一个在 Java 流上链接非终结操作调用的示例：

```java
Stream<String> stream1 = stream
    .map((value) -> { return value.toLowerCase(); })
    .map((value) -> { return value.toUpperCase(); })
    .map((value) -> { return value.substring(0,3); });
```

许多非终结流操作可以将一个 [Java Lambda 表达式](/java/lambda-expressions.html)作为参数。这个 lambda 表达式实现了一个适合给定非终结操作的 [Java 函数接口](/java-functional-programming/functional-interfaces.html)。例如，`Function`或`Predicate`接口。非终结操作方法参数的参数通常是一个函数接口——这就是为什么它也可以由 Java lambda 表达式实现的原因。

## 过滤器()

Java `Stream` `filter()`可以用来从 Java `Stream`中过滤出元素。`filter`方法采用了一个`Predicate`，它被流中的每个元素调用。如果元素要包含在结果`Stream`中，`Predicate`应该返回`true`。如果元素不应该被包含，那么`Predicate`应该返回`false`。

下面是一个调用 Java `Stream` `filter()`方法的例子：

```java
Stream<String> longStringsStream = stream.filter((value) -> {
    return value.length() >= 3;
});
```

## 地图()

Java `Stream` `map()`方法将一个元素转换（映射）为另一个对象。例如，如果你有一个字符串列表，它可以将每个字符串转换成小写、大写，或者转换成原始字符串的子串，或者其他完全不同的东西。下面是一个 Java `Stream` `map()`的例子：

```java
List<String> list = new ArrayList<String>();
Stream<String> stream = list.stream();

Stream<String> streamMapped = stream.map((value) -> value.toUpperCase());
```

## 平面地图()

Java `Stream` `flatMap()`方法将单个元素映射成多个元素。这个想法是你将每个元素从一个包含多个内部元素的复杂结构中“扁平化”，变成一个只包含这些内部元素的“扁平”流。

例如，假设您有一个包含嵌套对象（子对象）的对象。然后，您可以将该对象映射到一个“平面”流中，该流由它自己加上它的嵌套对象组成——或者只有嵌套对象。您还可以将一系列`List`元素映射到元素本身。或者将一串字符串映射到这些字符串中的一串单词——或者映射到这些字符串中的单个`Character`实例。

下面是一个将一个`List`字符串平面映射到每个字符串中的单词的例子。这个例子应该给你一个关于如何使用`flatMap()`将一个元素映射到多个元素的想法。

```java
List<String> stringList = new ArrayList<String>();

stringList.add("One flew over the cuckoo's nest");
stringList.add("To kill a muckingbird");
stringList.add("Gone with the wind");

Stream<String> stream = stringList.stream();

stream.flatMap((value) -> {
    String[] split = value.split(" ");
    return (Stream<String>) Arrays.asList(split).stream();
})
.forEach((value) -> System.out.println(value))
;
```

这个 Java `Stream` `flatMap()`示例首先创建一个包含书籍标题的`List`，它有 3 个字符串。然后为`List`获得一个`Stream`，并调用`flatMap()`。

在`Stream`上调用的`flatMap()`操作必须返回另一个代表平面映射元素的`Stream`。在上面的例子中，每个原始字符串被拆分成单词，转换成`List`，流从`List`获得并返回。

注意，这个例子以调用`forEach()`结束，这是一个终端操作。这个调用仅仅是为了触发内部迭代，从而触发平面图操作。如果在`Stream`链上没有调用终端操作，就不会发生任何事情。实际上不会发生平面映射。

## 独特()

Java `Stream` `distinct()`方法是一个非终结操作，它返回一个新的`Stream`，其中只包含来自原始流的不同元素。任何重复的元素都将被删除。下面是一个 Java `Stream` `distinct()`方法的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("one");
stringList.add("two");
stringList.add("three");
stringList.add("one");

Stream<String> stream = stringList.stream();

List<String> distinctStrings = stream
    .distinct()
    .collect(Collectors.toList());

System.out.println(distinctStrings);
```

在这个例子中，元素`one`在原始流中出现了 2 次。只有该元素的第一次出现才会被包含在`distinct()`返回的`Stream`中。因此，产生的`List`（调用`collect()`）将只包含`one`、`two`和`three`。该示例打印的输出将是：

```java
[one, two, three]
```

## 极限()

Java `Stream` `limit()`方法可以将流中的元素数量限制为一个作为参数提供给`limit()`方法的数字。`limit()`方法返回一个新的`Stream`，它最多包含给定数量的元素。下面是一个 Java `Stream` `limit()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("one");
stringList.add("two");
stringList.add("three");
stringList.add("one");

Stream<String> stream = stringList.stream();
stream
    .limit(2)
    .forEach( element -> { System.out.println(element); });
```

这个例子首先创建一个`Stream`，然后对它调用`limit()`，然后用一个输出流中元素的 lambda 调用`forEach()`。由于`limit(2)`调用，只有两个第一个元素将被打印。

## peek()

Java `Stream` `peek()`方法是一个以`Consumer`（`java.util.function.Consumer`）为参数的非终结操作。对于流中的每个元素，`Consumer`都将被调用。`peek()`方法返回一个新的`Stream`，它包含原始流中的所有元素。

正如该方法所说，`peek()`方法的目的是查看流中的元素，而不是转换它们。请记住，`peek`方法不会开始流中元素的内部迭代。为此，您需要调用一个终端操作。下面是一个 Java `Stream` `peek()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("abc");
stringList.add("def");

Stream<String> stream = stringList.stream();

Stream<String> streamPeeked = stream.peek((value) -> {
    System.out.println("value");
});
```

# 终端操作

Java `Stream`接口的终端操作通常返回一个值。一旦在一个`Stream`上调用了终端操作，`Stream`和链接流的任何非终结操作的迭代将开始。一旦迭代完成，就返回终端操作的结果。

终端操作通常不会返回新的`Stream`实例。因此，一旦您在流上调用了终端操作，来自非终端操作的`Stream`实例链就结束了。下面是一个在 Java `Stream`上调用终端操作的例子：

```java
long count = stream
    .map((value) -> { return value.toLowerCase(); })
    .map((value) -> { return value.toUpperCase(); })
    .map((value) -> { return value.substring(0,3); })
    .count();
```

例子最后对`count()`的调用就是终端操作。由于`count()`返回一个`long`，所以`Stream`非终结操作链（`map()`调用）结束。

## 任意匹配()

Java `Stream` `anyMatch()`方法是一个终端操作，它将单个`Predicate`作为参数，开始`Stream`的内部迭代，将`Predicate`参数应用于每个元素。如果`Predicate`为任何元素返回真，则`anyMatch()`方法返回`true`。如果没有元素与`Predicate`匹配，`anyMatch()`将返回`false`。下面是一个 Java `Stream` `anyMatch()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("One flew over the cuckoo's nest");
stringList.add("To kill a muckingbird");
stringList.add("Gone with the wind");

Stream<String> stream = stringList.stream();

boolean anyMatch = stream.anyMatch((value) -> { return value.startsWith("One"); });
System.out.println(anyMatch);
```

在上面的例子中，`anyMatch()`方法调用将返回`true`，因为流中的第一个字符串元素以“一”开始。

## allMatch()

Java `Stream` `allMatch()`方法是一个终端操作，它将单个`Predicate`作为参数，启动`Stream`中元素的内部迭代，并将`Predicate`参数应用于每个元素。如果`Predicate`为`Stream`中的所有元素返回`true`，则`allMatch()`将返回`true`。如果不是所有元素都与`Predicate`匹配，`allMatch()`方法返回`false`。下面是一个 Java `Stream` `allMatch()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("One flew over the cuckoo's nest");
stringList.add("To kill a muckingbird");
stringList.add("Gone with the wind");

Stream<String> stream = stringList.stream();

boolean allMatch = stream.allMatch((value) -> { return value.startsWith("One"); });
System.out.println(allMatch);
```

在上面的例子中，`allMatch()`方法将返回`false`，因为`Stream`中只有一个字符串以“1”开头。

## 无匹配()

Java `Stream` `noneMatch()`方法是一个终端操作，它将迭代流中的元素并返回`true`或`false`，这取决于流中是否没有元素与作为参数传递给`noneMatch()`的`Predicate`相匹配。如果和`Predicate`没有匹配的元素，则`noneMatch()`方法将返回`true`，如果匹配了一个或多个元素，则返回`false`。下面是一个 Java `Stream` `noneMatch()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("abc");
stringList.add("def");

Stream<String> stream = stringList.stream();

boolean noneMatch = stream.noneMatch((element) -> {
    return "xyz".equals(element);
});

System.out.println("noneMatch = " + noneMatch);
```

## 收集()

Java `Stream` `collect()`方法是一个终端操作，它启动元素的内部迭代，并将流中的元素收集到某种集合或对象中。下面是一个简单的 Java `Stream` `collect()`方法示例：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("One flew over the cuckoo's nest");
stringList.add("To kill a muckingbird");
stringList.add("Gone with the wind");

Stream<String> stream = stringList.stream();

List<String> stringsAsUppercaseList = stream
    .map(value -> value.toUpperCase())
    .collect(Collectors.toList());

System.out.println(stringsAsUppercaseList);
```

`collect()`方法将一个`Collector`（`java.util.stream.Collector`）作为参数。实现一个`Collector`需要对`Collector`接口进行一些研究。幸运的是，Java 类`java.util.stream.Collectors`包含一组预实现的`Collector`实现，您可以使用它们来完成最常见的操作。在上面的例子中，使用的是由`Collectors.toList()`返回的`Collector`实现。这个`Collector`简单地收集了一个标准 Java `List`流中的所有元素。

## 计数()

Java `Stream` `count()`方法是一个终端操作，它启动`Stream`中元素的内部迭代，并对元素进行计数。下面是一个 Java `Stream` `count()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("One flew over the cuckoo's nest");
stringList.add("To kill a muckingbird");
stringList.add("Gone with the wind");

Stream<String> stream = stringList.stream();

long count = stream.flatMap((value) -> {
    String[] split = value.split(" ");
    return (Stream<String>) Arrays.asList(split).stream();
})
.count();

System.out.println("count = " + count);
```

这个例子首先创建一个字符串的`List`，然后获取那个`List`的`Stream`，为其添加一个`flatMap()`操作，然后以对`count()`的调用结束。`count()`方法将开始迭代`Stream`中的元素，这将导致`Stream`中的字符串元素在`flatMap()`操作中被拆分成单词，然后被计数。打印出来的最终结果是 14。

## findAny()

Java `Stream` `findAny()`方法可以从流中找到单个元素。找到的元素可以来自`Stream`的任何地方。不能保证元素是从流中的什么地方获取的。下面是一个 Java `Stream` `findAny()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("one");
stringList.add("two");
stringList.add("three");
stringList.add("one");

Stream<String> stream = stringList.stream();

Optional<String> anyElement = stream.findAny();

System.out.println(anyElement.get());
```

注意`findAny()`方法是如何返回一个`Optional`的。`Stream`可能为空——因此没有元素可以返回。你可以通过`Optional`的`isPresent()`方法检查一个元素是否被找到。

## findFirst()

Java `Stream` `findFirst()`方法查找`Stream`中的第一个元素，如果`Stream`中存在任何元素的话。`findFirst()`方法返回一个`Optional`，从中可以获取元素（如果存在的话）。下面是一个 Java `Stream` `findFirst()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("one");
stringList.add("two");
stringList.add("three");
stringList.add("one");

Stream<String> stream = stringList.stream();

Optional<String> result = stream.findFirst();

System.out.println(result.get());
```

您可以通过其`isPresent()`方法检查返回的`Optional`是否包含元素。

## forEach()

Java `Stream` `forEach()`方法是一个终端操作，它启动`Stream`中元素的内部迭代，并将`Consumer`（`java.util.function.Consumer`）应用于`Stream`中的每个元素。`forEach()`方法返回`void`。下面是一个 Java `Stream` `forEach()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("one");
stringList.add("two");
stringList.add("three");
stringList.add("one");

Stream<String> stream = stringList.stream();

stream.forEach( element -> { System.out.println(element); });
```

## 最小值()

Java `Stream` `min()`方法是一个终端操作，它返回`Stream`中最小的元素。哪个元素最小是由传递给`min()`方法的`Comparator`实现决定的。我已经在关于对 Java 集合排序的教程中解释了接口如何工作。下面是一个 Java `Stream` `min()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("abc");
stringList.add("def");

Stream<String> stream = stringList.stream();

Optional<String> min = stream.min((val1, val2) -> {
    return val1.compareTo(val2);
});

String minString = min.get();

System.out.println(minString);
```

注意`min()`方法如何返回一个`Optional`，它可能包含也可能不包含结果。如果`Stream`为空，`Optional`的`get()`方法将抛出一个`NoSuchElementException`。

## 最大()

Java `Stream` `max()`方法是一个终端操作，它返回`Stream`中最大的元素。哪个元素最大是由传递给`max()`方法的`Comparator`实现决定的。我已经在关于对 Java 集合排序的教程中解释了接口如何工作。下面是一个 Java `Stream` `max()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("abc");
stringList.add("def");

Stream<String> stream = stringList.stream();

Optional<String> max = stream.max((val1, val2) -> {
    return val1.compareTo(val2);
});

String maxString = max.get();

System.out.println(maxString);
```

注意`max()`方法如何返回一个`Optional`，它可能包含也可能不包含结果。如果`Stream`为空，`Optional`的`get()`方法将抛出一个`NoSuchElementException`。

## 减少()

Java `Stream` `reduce()`方法是一个终端操作，可以将流中的所有元素简化为一个单独的元素。下面是一个 Java `Stream` `reduce()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("One flew over the cuckoo's nest");
stringList.add("To kill a muckingbird");
stringList.add("Gone with the wind");

Stream<String> stream = stringList.stream();

Optional<String> reduced = stream.reduce((value, combinedValue) -> {
    return combinedValue + " + " + value;
});

System.out.println(reduced.get());
```

注意由`reduce()`方法返回的`Optional`。这个`Optional`包含传递给`reduce()`方法的 lambda 表达式返回的值（如果有的话）。您通过调用`Optional`的`get()`方法来获取该值。

## 托阵列()

Java `Stream` `toArray()`方法是一个终端操作，它启动流中元素的内部迭代，并返回包含所有元素的数组`Object`。下面是一个 Java `Stream` `toArray()`的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("One flew over the cuckoo's nest");
stringList.add("To kill a muckingbird");
stringList.add("Gone with the wind");

Stream<String> stream = stringList.stream();

Object[] objects = stream.toArray();
```

# 串联流

Java `Stream`接口包含一个名为`concat()`的静态方法，它可以将两个流连接成一个流。结果是一个新的`Stream`，它包含第一个流中的所有元素，后面是第二个流中的所有元素。下面是一个使用 Java `Stream` `concat()`方法的例子：

```java
List<String> stringList = new ArrayList<String>();

stringList.add("One flew over the cuckoo's nest");
stringList.add("To kill a muckingbird");
stringList.add("Gone with the wind");

Stream<String> stream1 = stringList.stream();

List<String> stringList2 = new ArrayList<>();
stringList2.add("Lord of the Rings");
stringList2.add("Planet of the Rats");
stringList2.add("Phantom Menace");

Stream<String> stream2 = stringList2.stream();

Stream<String> concatStream = Stream.concat(stream1, stream2);

List<String> stringsAsUppercaseList = concatStream
    .collect(Collectors.toList());

System.out.println(stringsAsUppercaseList);
```

# 从数组创建流

Java `Stream`接口包含一个名为`of()`的静态方法，可以使用从一个或多个对象创建一个`Stream`。下面是一个使用 Java `Stream` `of()`方法的例子：

```java
Stream<String> streamOf = Stream.of("one", "two", "three");
```

# Java 流 API 评论

在使用过其他数据流 API（如 Apache Kafka Streams API）之后，我对 Java Stream API 有一些评论，我将与您分享。它们不是很重要的评论点，但是当你冒险进入流处理时，它们是有用的。

## 批处理，非流式

尽管名为 Java Stream API，但它并不是真正的流处理 API。Java Stream API 的终端操作返回遍历流中所有元素的最终结果，并向元素提供非终端和终端操作。处理完流中的最后一个元素后，将返回终端操作的结果。

在处理完一个流的最后一个元素后返回一个*最终结果*只有在你**知道**流中最后一个元素是什么的情况下才有可能。知道一个给定元素是否是一个流中的最后一个元素的唯一方法是，如果你正在处理一个*批处理*，它有一个*最后一个元素*。相反，真正的流没有最后的元素。你永远不知道一个给定的元素是否是最后一个。因此，不可能在流上执行终端操作。您所能做的最好的事情是在给定元素的处理之后收集临时结果，但是这将是*采样*，而不是*最终结果*。

## 链，不是图

Java 流 API 被设计成一个`Stream`实例只能被操作一次。换句话说，你只能给一个`Stream`增加一个非终结操作，从而产生一个新的`Stream`对象。您可以向生成的`Stream`对象添加另一个非终结操作，但不能先向添加。非终结`Stream`实例的结果结构形成了一个链。

在真正的流处理 API 中，根流和事件监听器通常可以形成一个图，而不仅仅是一个链。多个侦听器可以侦听根流，并且每个侦听器可以用自己的方式处理流中的元素，并且可以转发转换后的元素作为结果。因此，每个监听器（非终端操作）通常可以充当流本身，其他监听器可以监听其结果。Apache Kafka Streams 就是这样设计的。每个侦听器（中间流）也可以有多个侦听器。由此产生的结构形成了监听器与监听器之间的图，等等。

使用流处理图而不是链，在图中没有单一的最终操作。我所说的最后一道工序是指保证是加工链中的最后一道工序。相反，可以有多个最终操作。图中的每一片“叶子”都是最后一道工序。

当您的流处理结构可以是具有多个最终操作的图时，流 API 不能像 Java 流 API 那样容易地支持终端操作。为了方便地支持终端操作，必须有一个返回最终结果的最终操作。基于图的流处理 API 可以替代地支持“采样”操作，其中流处理图中的每个节点被要求它可能在内部保存的任何值（例如，总和），如果有的话（纯转换监听器节点将不具有任何内部状态）。

## 内部迭代，而不是外部迭代

Java 流 API 被特意设计成在一个`Stream`中有元素的内部迭代。当在`Stream`上调用终端操作时，迭代开始。事实上，为了让终端操作能够返回结果，终端操作必须启动`Stream`中元素的迭代。

一些基于图形的流处理 API 也被设计成对 API 的用户隐藏元素的迭代（例如 Apache Kafka Streams 和 RxJava）。然而，就我个人而言，我更喜欢这样一种设计，其中每个流节点（根流和侦听器）都可以通过方法调用将元素传递给它们，并让元素通过完整的图进行处理。这样的设计将使测试图中的每个侦听器变得更加容易，因为您可以配置图，然后通过它推送元素，最后检查结果（图的采样状态）。这种设计还将使流处理图能够通过图中的多个节点将元素推入其中，而不仅仅是通过根流。
