
# HTML 表单

> 原文：<https://jenkov.com/tutorials/html4/forms.html>

HTML 表单使得从 HTML 文档的读者那里获得输入成为可能。这对于很多事情都很有用，比如用户注册一封新闻信，或者提供关于某个网站的反馈，或者输入在线购买产品的送货地址。

本教程涵盖了 HTML 4 中的表单域。我有一个关于 HTML 5 中新的[表单字段的单独教程。](/html5/form-fields.html)

顺便说一下，作为我的 CSS 教程的一部分，我还有一个关于用 CSS 设计表单样式的教程。

## 表单元素

HTML 表单包含在`form`元素中。这是它的样子：

```
<form>
</form>
```

HTML4 有一组您可以使用的表单域。有：

*   文本字段
*   文本区域
*   检验盒
*   单选按钮
*   选择框
*   文件字段
*   纽扣
*   图像按钮
*   提交按钮

大多数表单域使用`input`元素，但是有些表单域有自己的元素。下面是一个显示所有表单字段的快速示例：

```
<form>
    <input type="text">              <br>
    <textarea></textarea>            <br>
    <input type="checkbox">          <br>
    <input type="radio">             <br>
    <select>
        <option>Choose this</option>
        <option>Or this</option>
    </select>                        <br>
    <input type="file">              <br>
    <input type="button" value="Click Me" >               <br>
    <input type="submit" value="Submit Form">             <br>
    <input type="image"  src="/images/html4/forms-image-button.png">  <br>
</form>
```

上面的例子创建了一个包含每个 HTML 表单域的表单。注意如何在每个表单域后添加一个`br`（换行符）元素。这样做是为了让每个表单域出现在自己的行上。为了更好地格式化表单，你可以把它放到一个 HTML 表格中。

以下是表单域在浏览器中的外观：

<form><input type="text">



# HTML 表单域

以下是一个包含各种表单域的 HTML 表单示例：

```
<form>
  <input type="checkbox"/>
  <input type="radio"/>
  <select>
    <option>Choose this</option>
    <option>Or this</option>
  </select>
  <input type="file"/>
  <input type="button" value="Click Me"/>
  <input type="submit" value="Submit Form"/>
  <input type="image" src="/images/html4/forms-image-button.png"/>
</form>
```

每个表单域将在下面的章节中详细描述。

HTML5 中有几个新的表单域。你可以在我的 [HTML5 表单域](/html5/form-fields.html) 教程中看到它们。

## 文本字段

文本字段可用于输入单行文本。以下是文本字段 HTML 元素的外观：

```
<input type="text">
```

这是它在浏览器中的样子：

`<input type="text"/>`

该文本字段具有以下属性：

| 名字 | 描述 |
|------|------|
| `name` | 该文本字段的名称。这在向服务器提交表单时使用。当从 JavaScript 引用表单字段时，也可以使用这个名称。 |
| `value` | 将文本字段中显示的文本值设置为默认文本。 |
| `size` | 此文本字段的近似字符大小。请注意，大小并不总是适合给定的字符数，并且在不同的浏览器中通常是不同的。 |
| `maxlength` | 允许在此文本字段中键入的最大字符数。该值必须是一个数字。 |
| `readonly` | 将文本字段设置为只读模式，这意味着您不能更改文本字段中显示的文本。有效值为`true`和`false`。 |
| `disabled` | 将文本字段设置为禁用模式，这意味着您不能更改文本区域中显示的文本。此外，当提交表单时，文本字段的值不会被提交。有效值为`true`和`false`。 |

下面是一个使用这些属性的文本字段示例：

```
<input type="text" value="Default Text" size="20" maxlength="15" >
```

以下是文本栏在浏览器中的外观：

`<input type="text" value="Default Text" size="20" maxlength="15"/>`

注意最初显示时文本字段中显示的默认文本。另请注意，您不能在文本字段中输入超过 15 个字符。

## 文本区域

`textarea` 元素用于创建类似于文本字段的文本表单字段。文本字段和文本区域的区别在于，文本区域可以包含多行文本。这里有一个例子：

```
<textarea></textarea>
```

以下是文本区域在浏览器中的外观：

`<textarea/>`

`textarea` 元素具有以下属性：

| 名字 | 描述 |
|------|------|
| `name` | 该文本字段的名称。这在向服务器提交表单时使用。当从 JavaScript 引用表单字段时，也可以使用这个名称。 |
| `rows` | 设置文本区域应显示的文本行数。您可以键入比这更多的行，但一次只能显示这个数量的行。 |
| `cols` | 设置要显示的列数（字符数）。 |
| `wrap` | 设置文本区域的文本环绕模式。<br/> `soft` = 文本在浏览器中换行，但提交给服务器时不换行。<br/> `hard` = 文本在浏览器中换行，提交给服务器时也是如此。<br/> `off` = 不自动换行。 |
| `readonly` | 将文本区域设置为只读模式，这意味着您不能更改文本区域中显示的文本。有效值为`true`和`false`。 |
| `disabled` | 将文本区域设置为禁用模式，这意味着您不能更改文本区域中显示的文本。此外，当提交表单时，文本区域的值不会被提交。有效值为`true`和`false`。 |

下面是一个使用`rows`和`cols`属性的例子：

```
<textarea rows="5" cols="20" wrap="off"></textarea>
```

下面是文本区域在浏览器中的外观：

`<textarea rows="5" cols="20" wrap="off"/>`

## 复选框

复选框是 HTML 文档的读者可以点击的小方块。单击复选框一次，框中会出现一个小复选标记。然后该复选框被"选中"。如果您单击选中的复选框，复选标记会再次消失。以下是 HTML 中复选框的示例：

```
<input type="checkbox">
```

以下是复选框在浏览器中的外观：

`<input type="checkbox"/>`

尝试点击复选框，看看会发生什么。

该复选框具有以下属性：

| 名字 | 描述 |
|------|------|
| `name` | 此复选框的名称。这在向服务器提交表单时使用。当从 JavaScript 引用表单字段时，也可以使用这个名称。 |
| `value` | 此文本字段的值。这在向服务器提交表单时使用。如果在提交表单时选中该复选框，则提交 `value` 属性中的值。如果提交表单时未选中复选框，则复选框字段根本不会发送到服务器。 |
| `checked` | 如果此属性存在，复选框开始时为选中状态。这个属性不需要值，虽然允许写`checked="true"`。 |
| `disabled` | 将复选框设置为禁用模式，这意味着您不能更改复选框的初始状态。此外，当提交表单时，复选框的值不会被提交。有效值为`true`和`false`。 |

下面是一个使用上述一些属性的复选框：

```
<input name="receiveEmail" type="checkbox" checked>
```

下面是复选框在浏览器中的外观：

`<input name="receiveEmail" type="checkbox" checked="checked"/>`

## 单选按钮

单选按钮看起来有点像复选框，只是单选按钮是圆形的。此外，单选按钮通常以组的形式出现，在组中您只能选择一个单选按钮。以下是 HTML 中一组单选按钮的示例：

```
<input type="radio" name="theChoice" value="1"> No 1.
<input type="radio" name="theChoice" value="2"> No 2.
<input type="radio" name="theChoice" value="3"> No 3.
```

以下是浏览器中单选按钮的外观：

`<input type="radio" name="theChoice" value="1"/>` No 1.
`<input type="radio" name="theChoice" value="2"/>` No 2.
`<input type="radio" name="theChoice" value="3"/>` No 3.

尝试单击单选按钮，注意一次只能选择一个按钮。

是`name`属性定义了哪些单选按钮属于一个组。所有同名的单选按钮都属于同一个单选按钮组。在属于同一组的单选按钮中，任何时候都只能选择一个。

单选按钮元素具有以下属性：

| 名字 | 描述 |
|------|------|
| `name` | 该单选按钮的名称。这在向服务器提交表单时使用。当从 JavaScript 引用表单字段时，也可以使用这个名称。 |
| `value` | 这台收音机的价值。这在向服务器提交表单时使用。如果在提交表单时选中了单选按钮，则提交 `value` 属性中的值。如果在提交表单时没有从单选按钮组中选择单选按钮，则不会提交任何单选按钮参数。 |
| `checked` | 如果该属性存在，单选按钮开始时为选中状态。这个属性不需要值，虽然允许写`checked="true"`。 |
| `disabled` | 将单选按钮设置为禁用模式，这意味着您不能更改单选按钮的初始状态。此外，当提交表单时，单选按钮的值不会被提交。有效值为`true`和`false`。 |

## 选择框

选择框（也称为下拉框）是可以从中选择一个或多个项目的项目列表。以下是 HTML 中选择框的外观：

```
<select>
  <option>Choice 1</option>
  <option>Choice 2</option>
  <option>Choice 3</option>
</select>
```

以下是浏览器中选择框的外观：

`<select> <option>Choice 1</option> <option>Choice 2</option> <option>Choice 3</option> </select>`

选择框中的每一项都包含在嵌入的`option`元素中。如果您想要预先选择其中一个选项，只需将`selected`属性放在相应的`option`元素中。这里有一个例子：

```
<select>
  <option value="1">Choice 1</option>
  <option value="2">Choice 2</option>
  <option value="3" selected>Choice 3</option>
</select>
```

以下是浏览器中选择框的外观。请注意，第三个选项已被预选：

`<select> <option value="1">Choice 1</option> <option value="2">Choice 2</option> <option value="3" selected="selected">Choice 3</option> </select>`

`select` 元素具有以下属性：

| 名字 | 描述 |
|------|------|
| `name` | 选择框的名称。这在向服务器提交表单时使用。当从 JavaScript 引用表单字段时，也可以使用这个名称。 |
| `disabled` | 将选择框设置为禁用模式，这意味着您不能更改在选择框中选择的初始值。此外，提交表单时，不会提交选择框的值。有效值为`true`和`false`。 |

`option` 元素具有以下属性：

| 名字 | 描述 |
|------|------|
| `value` | 如果选择了此选项，则为选择框指定值。 |

## 文件字段

将文件上传到服务器时会使用文件字段。以下是表单域的外观：

```
<input type="file" >
```

以下是浏览器中文件栏的外观：

`<input type="file"/>`

如果您单击"浏览"按钮，将会打开一个文件对话框，您可以在其中选择要上传的文件。

为了上传文件，`form` 元素需要将其`enctype`属性设置为`multipart/form-data`。这是它在 HTML 中的样子：

```
<form action="fileReceiver.jsp" method="post" enctype="multipart/form-data">
  <input type="file" name="theFile">
</form>
```

如您所见，`form` 元素现在已经设置了`enctype`属性。还要注意，文件字段有一个名称。这用于标识服务器端的文件字段。

文件字段具有以下属性：

| 名字 | 描述 |
|------|------|
| `name` | 该文件字段的名称。这在向服务器提交表单时使用。当从 JavaScript 引用表单字段时，也可以使用这个名称。 |
| `accept` | 设置服务器将接受的文件的 mime 类型。比如`image/gif`或者`image/*`。 |
| `disabled` | 将文件字段设置为禁用模式，这意味着您不能更改文件字段的初始值。此外，提交表单时，不会提交字段 field 的值。有效值为`true`和`false`。 |

请注意`accept`属性。这个属性可以用来告诉文件对话框服务器可以接受哪些文件类型（mime 类型），从而在文件对话框中显示哪些文件类型。要获得完整的 mime 类型列表，请看 [IANA 的 Mime 媒体类型列表](http://www.iana.org/assignments/media-types/index.html)。

## 按钮

按钮表单域创建一个按钮，HTML 文档的读者可以按下该按钮。为了在按钮表单字段被按下时发生一些事情，您需要附加一个 JavaScript 事件监听器。下面是一个按钮 HTML 示例：

```
<input type="button" value="Click me" onclick="alert('you clicked me!');">
```

这是按钮在浏览器中的外观。试着点击它。

`<input type="button" value="Click me" onclick="alert('you clicked me!');"/>`

如果你点击了这个按钮，它会显示一个 JavaScript 警告框，并显示"你点击了我！"。

如果您没有将 JavaScript click 处理程序附加到按钮上，那么当您单击它时不会发生任何事情。

该按钮具有以下属性：

| 名字 | 描述 |
|------|------|
| `name` | 此按钮的名称。当从 JavaScript 引用按钮时，也可以使用这个名称。 |
| `value` | 设置按钮上使用的文本。 |
| `disabled` | 将按钮设置为禁用模式，这意味着您不能单击它。有效值为`true`和`false`。 |

## 提交按钮

提交按钮是将表单及其所有值提交给服务器的按钮。以下是 HTML 中提交按钮的外观：

```
<input type="submit" value="Submit Form">
```

下面是提交按钮在浏览器中的外观：

`<input type="submit" value="Submit Form"/>`

当您单击上面的"提交"按钮时，不会发生任何事情，因为"提交"按钮不在表单内。如果 submit 按钮位于表单内部，表单将被提交给服务器，通常会显示一个新页面。

提交按钮具有以下属性：

| 名字 | 描述 |
|------|------|
| `name` | 此提交按钮的名称。这在向服务器提交表单时使用。当从 JavaScript 引用提交按钮时，也可以使用这个名称。 |
| `value` | 设置提交按钮上使用的文本。 |
| `disabled` | 将提交按钮设置为禁用模式，这意味着您不能单击它。有效值为`true`和`false`。 |

## 图像按钮

图像按钮是一个提交按钮，它显示一个可点击的图像，而不是标准的 HTML 按钮。您可以使用任何图像作为按钮，但是您应该选择一个对 HTML 文档的读者有意义的图像。以下是 HTML 中图像按钮的外观：

```
<input type="image" src="/images/html4/forms-image-button.png">
```

以下是图像按钮在浏览器中的外观：

`<input type="image" src="/images/html4/forms-image-button.png"/>`

请注意，当鼠标光标悬停在图像上时会发生变化，就像悬停在链接上一样。那是因为你可以点击图片。但是，当您单击图像时，什么也不会发生，因为图像按钮没有嵌套在表单中。如果是的话，表单应该已经被提交了，就像 submit 按钮一样。

注意：一些浏览器在使用图片按钮而不是提交按钮时会有轻微的不同。使用提交按钮，当表单字段有焦点时，通常也可以按键盘上的 enter 键，让浏览器提交表单。如果您使用图像按钮，这不起作用。

图像按钮具有以下属性：

| 名字 | 描述 |
|------|------|
| `name` | 此图像按钮的名称。这在向服务器提交表单时使用。当从 JavaScript 引用图像按钮时，也可以使用这个名称。 |
| `disabled` | 将图像按钮设置为禁用模式，这意味着您不能单击它。有效值为`true`和`false`。 |

## 提交表单

您可以通过三种不同的方式提交表单：

1. 通过单击提交按钮或图像按钮。
2. 当表单域（文本区域除外）有焦点时，单击 enter。
3. 通过 JavaScript 调用`form.submit()`函数。

提交表单时，表单字段被发送到列在`form` 元素`action`属性中的 URL。这里有一个例子：

```
<form action="http://tutorials.jenov.com/html4/submit-form.jsp">
</form>
```

提交表单时，表单字段的值被打包成名称、值对，并发送到 URL `http://tutorials.jenov.com/html4/submit-form.jsp`

有两种方法可以用来提交表单。实际上，还有更多，但这两个是最常见的：

### GET 和 POST

- GET
- POST

当您使用 GET 时，表单域被附加到表单`action`属性中列出的 URL。

使用 POST 时，表单字段被打包到发送给服务器的 HTTP 请求的正文中。因此，在浏览器将表单发送到的 URL 中，表单字段（参数）是不可见的。

您指定在 forms `method`属性中使用什么方法。这里有一个例子：

```
<form method="POST" action="http://tutorials.jenov.com/html4/submit-form.jsp">
</form>
```

在服务器端，你需要一些动态脚本（Java、C#.NET、PHP 等）接收表单并对其进行处理。这样一个脚本的外观超出了本文的范围。

## 带有表格的表单布局

默认情况下，`form` 元素不提供表单的任何布局。但是，您可以使用 HTML 表格来布局表单，这样表单看起来会更好。下面是一个表单示例：

```
<form action="..." method="POST">
  <table cellpadding="5" cellspacing="0">
    <tr>
      <td>名字</td>
      <td><input type="text" name="name"/></td>
    </tr>
    <tr>
      <td>电子邮件</td>
      <td><input type="text" name="email"/></td>
    </tr>
    <tr>
      <td valign="top">性别</td>
      <td>
        <input type="radio" name="gender" value="male"/>男<br/>
        <input type="radio" name="gender" value="female"/>女<br/>
      </td>
    </tr>
    <tr>
      <td/>
      <td><input type="submit" value="Submit Form"/></td>
    </tr>
  </table>
</form>
```

下面是生成该表单所需的 HTML：

```
<form action="..." method="POST">
  <table cellpadding="5" cellspacing="0">
    <tr>
      <td>Name</td>
      <td><input type="text" name="name"></td>
    </tr>
    <tr>
      <td>Email</td>
      <td><input type="text" name="email"></td>
    </tr>
    <tr>
      <td valign="top">Gender</td>
      <td>
        <input type="radio" name="gender" value="male"> Male <br/>
        <input type="radio" name="gender" value="female"> Female <br/>
      </td>
    </tr>
    <tr>
      <td></td>
      <td>
        <input type="submit" value="Submit Form">
      </td>
    </tr>
  </table>
</form>
```

每个表单域都显示在自己的表格行中，并带有一个标签，描述要在该表单域中键入的内容。标签显示在表格的第一列，表单域显示在表格的第二列。
