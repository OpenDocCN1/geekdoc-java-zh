
# SVG text element

> 原文：<https://jenkov.com/tutorials/svg/text-element.html>

SVG `<text>`元素用于在 SVG 图像中绘制文本。

# 文本示例

这里有一个简单的例子：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
  <text x="20" y="40">Example SVG text 1</text>
</svg>
```

本示例定义了一个位于 `x = 10`，`y = 40` 的文本。要显示的文本是“示例 SVG 文本 1”。

以下是生成的图像：

<svg width="320" height="70"><text x="20" y="40">Example SVG text 1</text></svg>

# 文本定义

在深入研究 SVG 文本之前，这里有三个值得了解的定义：

- **字形**
  字形是字母或符号的视觉表现。因此，字母“a”可以使用许多不同的字形来绘制，因为字母“a”有许多不同的视觉表示。

- **字体**
  字体是能够可视化一组字母和符号的字形集合。

- **字符**
  字符是一个字母或符号的数字（二进制）表示。一个字符可以用一个或多个字节来表示。当计算机渲染字符时，它会将这些字符映射到字体中的字形。

# 定位文本

文本的**位置**由`<text>`元素的`x`和`y`属性决定。`x`属性决定了文本左边缘的位置（文本的开始）。`y`属性决定了文本底部的位置（不是顶部）。因此，文本的`y`位置与线条、矩形或其他形状的`y`位置是不同的。此示例显示了一个文本和一行，它们都具有`y`位置 40：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
  <text x="20" y="40">Example SVG text 1</text>
  <line x1="10" y1="40" x2="150" y2="40" style="stroke: #000000"/>
</svg>
```

<svg width="320" height="70"><text x="20" y="40">Example SVG text 1</text><line x1="10" y1="40" x2="150" y2="40" style="stroke: #000000"/></svg>

注意文本的`y`位置是如何指向文本的底部而不是顶部的。

# 文本锚

文本的锚点决定了文本的哪一部分位于在`text`元素的`x`属性中指定的`x`位置。默认情况下，文本的锚点是文本的左边缘，即正文的开头。但是你也可以用文本的中间作为锚点，或者右边——文本的结尾。

可以设置`text-anchor` CSS 属性来设置文本的锚点。可以取三个值：`start`、`middle`和`end`。下面是一个 SVG `text-anchor`示例，展示了三种不同的文本锚选项：

<svg width="500" height="100"><line x1="50" y1="0" x2="50" y2="100" style="stroke: #000000;"/><text x="50" y="20" style="text-anchor: start"> Start </text><text x="50" y="40" style="text-anchor: middle"> Middle </text><text x="50" y="60" style="text-anchor: end"> End </text></svg>

垂直线显示所有三个文本的`X`位置。三篇课文都有`x="50"`。你可以看到这三个文本是如何被不同地锚定的。

下面是用于上面三个文本的 SVG 代码：

```
<text x="50" y="20" style="text-anchor: start"> Start </text>
<text x="50" y="40" style="text-anchor: middle"> Middle </text>
<text x="50" y="60" style="text-anchor: end"> End </text>
```

# 文本描边和填充

像其他 SVG 形状一样，文本上可以设置描边和填充。如果只指定一个笔画，文本将显示为文本的轮廓。如果仅指定填充，文本将看起来像正常呈现的文本。下面是三个显示`stroke`和`fill`组合的例子：

<svg width="500" height="200"><text x="20" y="40" style="fill: #000000; stroke: none; font-size: 48px;"> Fill only </text><text x="20" y="100" style="fill: none; stroke: #000000; font-size: 48px;"> Stroke only </text><text x="20" y="150" style="fill: #999999; stroke: #000000; font-size: 48px;"> Fill and stroke </text></svg>

第一行文本仅设置了填充。第二行只设置了笔画。请注意，只画出了文本的轮廓。第三行同时设置了描边和填充。请注意填充颜色是灰色的。

下面是用于生成该图像的 SVG 代码：

```
<text x="20" y="40" style="fill: #000000; stroke: none; font-size: 48px;"> Fill only </text>
<text x="20" y="100" style="fill: none; stroke: #000000; font-size: 48px;"> Stroke only </text>
<text x="20" y="150" style="fill: #999999; stroke: #000000; font-size: 48px;"> Fill and stroke </text>
```

请注意，我已经将`font-size`设置为`48px`以更好地说明描边和填充的效果。

当然，如果您希望轮廓更大，也可以设置`stroke-width`属性。下面是一个将`stroke-width`设置为 2 的示例：

<svg width="500" height="80"><text x="20" y="40" style="fill: #999999; stroke: #000000; stroke-width: 2px; font-size: 48px;"> Stroke-width 2 </text></svg>

你可以在 [SVG stroke](stroke.html) 的文本中阅读更多关于如何设计文本（和任何其他 SVG 形状）的样式的信息。

你也可以在 [SVG 填充](fill.html) 的文本中，以及 [SVG 渐变](svg-gradients.html)、[SVG 填充图案](fill-patterns.html)和 [SVG 蒙版](mask.html) 的文本中了解如何填充文本。

# 字母间距和字距

可以使用样式属性`letter-spacing`和`kerning`来控制字母间距和字距（字形之间的距离）。我不知道哪一个最好用。这里有两个简单的例子：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
  <text x="20" y="20" >Example SVG text</text>
  <text x="20" y="40" style="kerning:2;">Example SVG text</text>
  <text x="20" y="60" style="letter-spacing:2;">Example SVG text</text>
</svg>
```

以下是生成的图像：

<svg width="320" height="70"><text x="20" y="20">Example SVG text</text><text x="20" y="40" style="kerning:2;">Example SVG text</text><text x="20" y="60" style="letter-spacing:2;">Example SVG text</text></svg>

在`letter-spacing`或`kerning`中使用的数值被添加到正常的字母间距或字距中。如果使用负数，间距会减小。

# 单词间距

您可以使用`word-spacing` CSS 属性设置文本的单词间距。单词间距是文本中单词之间的空白量。这里有一个例子：

```
<text x="20" y="20"> Word spacing is normal </text>
<text x="20" y="40" style="word-spacing: 4;"> Word spacing is 4 </text>
<text x="20" y="60" style="word-spacing: 8;"> Word spacing is 8 </text>
```

这是生成的图像。注意：在撰写本文时，Firefox 还不支持`word-spacing` CSS 属性。

<svg width="500" height="100"><text x="20" y="20"> Word spacing is normal </text><text x="20" y="40" style="word-spacing: 4;"> Word spacing is 4 </text><text x="20" y="60" style="word-spacing: 8"> Word spacing is 8 </text></svg>

在`word-spacing`属性中指定的数值被添加到正常字间距中。如果您使用值`normal`或完全省略`word-spacing`属性，则不会添加任何内容。如果指定负数，单词之间的间距将会减小。

# 文本布局 - 无自动换行

SVG 中没有自动换行。您必须自己定位文本，并将其分成多行。您可以从`<tspan>`元素的相对定位中获得一些帮助。

也可以沿路径布局文本，例如沿圆或样条线。您可以使用`<textpath>`元素来做到这一点。

# 旋转文本

可以像旋转任何其他 SVG 形状一样旋转 SVG 文本。你使用 [SVG 变换](svg-transformation.html) 旋转文本和形状。这里有一个例子：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
  <text x="20" y="40" transform="rotate(30 20,40)" style="stroke:none; fill:#000000;" >Rotated SVG text</text>
</svg>
```

这是生成的图像：

<svg width="320" height="170"><text x="20" y="40" transform="rotate(30 20,40)" style="stroke:none; fill:#000000;">Rotated SVG text</text></svg>

旋转是由`transform`属性引起的，这在 [SVG 转换](svg-transformation.html) 中有解释。

# 文字垂直排列

可以通过旋转文本来显示竖排文本，但还有另一种方法来显示竖排文本。您可以通过将`writing-mode` CSS 属性设置为`tb`（从上到下）来实现。在写这篇文章的时候，Firefox (22) 还不支持这个特性。

下面是一个 SVG `writing-mode`示例：

```
<text x="10" y="20" style="writing-mode: tb;"> Vertical </text>
```

以下是生成的图像：

<svg width="500" height="100"><text x="10" y="20" style="writing-mode: tb;"> Vertical </text></svg>

如果您希望字母显示时不旋转，但仍然彼此垂直重叠，您可以通过将`glyph-orientation-vertical` CSS 属性设置为 0 来实现。此属性设置标志符号的旋转。默认值为 90。

以下是一些例子：

```
<text x="10" y="10" style="writing-mode: tb; glyph-orientation-vertical: 0;"> Vertical </text>
<text x="110" y="10" style="writing-mode: tb; glyph-orientation-vertical: 90;"> Vertical </text>
```

以下是生成的图像：

<svg width="500" height="160"><text x="10" y="10" style="writing-mode: tb; glyph-orientation-vertical: 0;"> Vertical </text><text x="110" y="10" style="writing-mode: tb; glyph-orientation-vertical: 90;"> Vertical </text></svg>

您也可以使用`letter-spacing` CSS 属性调整字母间距。这里有两个`letter-spacing`不同的例子：

```
<text x="10" y="10" style="writing-mode: tb; glyph-orientation-vertical: 0;"> Vertical </text>
<text x="50" y="10" style="writing-mode: tb; glyph-orientation-vertical: 0; letter-spacing: -3;"> Vertical </text>
```

这是生成的图像。请注意，带有负数`letter-spacing`的文本在字形之间的垂直间距变小了。

<svg width="500" height="160"><text x="10" y="10" style="writing-mode: tb; glyph-orientation-vertical: 0;"> Vertical </text><text x="50" y="10" style="writing-mode: tb; glyph-orientation-vertical: 0; letter-spacing: -3;"> Vertical </text></svg>

# 文本方向

您可以使用`direction` CSS 属性设置文本呈现的方向。属性可以有两个值：`ltr`和`rtl`。这些值表示“从左到右”和“从右到左”。您还必须将`unicode-bidi` CSS 属性设置为`bidi-override`。

下面是一个 SVG 文本`direction`的例子：

```
<text x="100" y="40" style="direction: rtl; unicode-bidi: bidi-override;"> Left to right </text>
```

本示例将`direction` CSS 属性设置为`rtl`（从右向左）。以下是生成的图像：

<svg width="500" height="70"><text x="100" y="40" style="direction: rtl; unicode-bidi: bidi-override;"> Left to right </text></svg>

# 样式文本

下面是可以用来设置文本样式的特定于文本的 CSS 属性列表。记住，你也可以设计文本的 [笔画](stroke.html) 和 [填充](fill.html)，并使用 [渐变](svg-gradients)、[填充图案](fill-patterns.html) 和 [蒙版](mask.html) 来设计文本。

您必须像表中一样用小写字母书写属性名，否则 SVG 查看器会忽略它们！

| 属性 | 描述 |
| --- | --- |
| 字体系列 | 要使用的字体，例如“Arial”或“Verdana”。 |
| 字体大小 | 字体的大小，例如“12px”或“24px”。 |
| 字距调整 | 字母之间的间距，例如“2”或“3”（默认值=1）。 |
| 字母间距 | 字母之间的间距，例如“2”或“3”。类似于字距调整。 |
| 字间距 | 单词之间的间距，例如“2”或“3”。 |
| 文字装饰 | 可以是`none`、`underline`、`overline`、`line-through`中的任意一种。 |
| 中风 | 字体的轮廓颜色。默认情况下，文本只有填充颜色，没有描边。添加笔画会使字体显得加粗。 |
| 笔画宽度 | 字体轮廓颜色的宽度。 |
| 充满 | 字体的填充颜色。 |

下面是一个使用这些属性的示例：

```
<svg xmlns:xlink="http://www.w3.org/1999/xlink">
  <text x="20" y="40" style="font-family: Arial; font-size : 34; stroke : #000000; fill : #00ff00; " >Styled SVG text</text>
</svg>
```

<svg width="320" height="70"><text x="20" y="40" style="font-family: Arial; font-size : 34; stroke : #000000; fill : #00ff00; ">Styled SVG text</text></svg>

# 文本长度

您可以使用`<text>`元素的`textLength`属性来设置文本的长度。然后，通过调整字符之间的间距和字形的大小，使文本的长度适合指定的长度。使用`lengthAdjust`属性你可以指定字母间距和字形大小是否需要调整。

下面是三个 SVG `textLength`和`lengthAdjust`的例子：

```
<text x="5" y="20" textLength="140" lengthAdjust="spacing"> A long, long, long text. </text>
<text x="5" y="40" textLength="200" lengthAdjust="spacing"> A long, long, long text. </text>
<text x="5" y="60" textLength="200" lengthAdjust="spacingAndGlyphs"> A long, long, long text. </text>
```

这是生成的图像。请注意最后两个文本中不同类型的间距。

<svg width="500" height="100"><text x="5" y="20" textlength="140" lengthadjust="spacing"> A long, long, long text. </text><text x="5" y="40" textlength="200" lengthadjust="spacing"> A long, long, long text. </text><text x="5" y="60" textlength="200" lengthadjust="spacingAndGlyphs"> A long, long, long text. </text></svg>

在撰写本文时，Firefox 还不支持这些属性。
