
# HTML iframe

> 原文：<https://jenkov.com/tutorials/html4/iframe.html>

`iframe`元素用于将其他 HTML 页面包含在另一个 HTML 页面的框架中。这里有一个简单的例子：

```
<iframe width="500" height="200" src="http://tutorials.jenkov.com/"></iframe>
```

`width`和`height`属性设置使用`iframe`元素的 HTML 文档中该元素的大小。

`src`属性设置 HTML 页面的 URL 以显示在元素中。

下面是上面的`iframe`代码包含在 HTML 页面中时的样子：

<iframe width="500" height="200" src="http://tutorials.jenkov.com/" seamless="true">

## 允许的 iframe 内容

您可以在`iframe`元素中显示 HTML 文件以外的其他文件。事实上，所有可以在浏览器中显示的文件都可以包含在一个`iframe`中，例如`.gif`、`.jpg`、`.png`和`.svg`文件。一个`iframe`也可以用来在你的 HTML 页面中包含来自 YouTube 的视频（要了解如何做，去 YouTube，找到一个视频并获得它的嵌入代码）。

## iframe 属性

`iframe`元素具有以下属性：

| 属性 | 描述 |
|------|------|
| `width` | 设置 iframe 在使用它的 HTML 文档中的宽度。 |
| `height` | 设置 iframe 在使用它的 HTML 文档中的高度。 |
| `name` | 设置 iframe 的名称。通过 JavaScript 引用这个 iframe 时会用到这个名称。 |
| `sandbox` | `iframe`元素的安全设置。可能的值有：`""`、`allow-forms`、`allow-same-origin`、`allow-scripts`、`allow-top-navigation`。这些值告诉 iframe 中是否允许表单，是否允许来自与加载页面相同来源的内容，是否允许 JavaScript 在`iframe`中运行，以及`iframe`是否可以引导用户离开包含`iframe`的页面。 |
| `seamless` | 指定 iframe 看起来应该是包含页的一部分。 |
| `src` | 设置要在此`iframe`中显示的 HTML 文档的 URL。 |
| `srcdoc` | 设置要在此`iframe`中显示的 HTML。可以用来代替`src`属性。 |

</iframe>
