
# Java 三元运算符

> 原文：<https://jenkov.com/tutorials/java/ternary-operator.html>

*Java* *三元运算符*的功能类似于简化的 [Java if](if.html) 语句。三元运算符由一个条件组成，该条件评估为`true`或`false`，加上一个如果条件为`true`则返回的值，以及另一个如果条件为`false`则返回的值。下面是一个简单的 Java 三元运算符示例：

```
String case = ... // get this string from somewhere, e.g. a parameter or program arg

String name = case.equals("uppercase") ? "JOHN" : "john";
```

我们将在本 Java 三元运算符教程的剩余部分剖析这个三元运算符示例。

## 三元算子条件

上面语句的三元运算符部分是这个部分：

```
case.equals("uppercase") ? "JOHN" : "john"
```

上述三元运算符表达式的条件部分是这样的：

```
case.equals("uppercase")
```

该条件是一个计算结果为`true`或`false`的 Java 表达式。如果`case`变量等于 [Java 字符串](strings.html)值`uppercase`，则上述条件将评估为`true`，否则评估为`false`。

条件可以是任何计算结果为`boolean`值的 Java 表达式，就像可以在`if`语句或`while`循环中使用的表达式一样。

## 三元运算符值

三元运算符的条件部分后跟一个问号（`?`）。问号后面是三元运算符可以返回的两个值，用冒号（`:`）隔开。前面显示的三元运算符的值部分是：

```
"JOHN" : "john";
```

值部分由两个值组成。如果条件部分（见上文）评估为`true`，则返回第一个值。如果条件部分评估为`false`，则返回第二个值。

在上面的例子中，如果`case.equals("uppercase")`评估为`true`，那么三元运算符表达式作为一个整体返回字符串值`JOHN`。如果`case.equals("uppercase")`评估为`false`，那么三元运算符表达式返回字符串值`john`。这意味着，字符串变量`name`将最终具有值`JOHN`或`john`，这取决于表达式`case.equals("uppercase")`的计算结果是`true`还是`false`。

返回值可以是任何 Java 表达式的结果，该表达式返回的值可以在语句开始时赋给变量。因为本文开头的三元运算符示例中的 Java 变量是`String`类型，所以 values 部分返回的值必须是`String`类型。

## 作为空检查的三元运算符

在调用对象上的方法之前，可以使用 Java 三元运算符作为空检查的简写。这里有一个例子：

```
String value = object != null ? object.getValue() : null;
```

这等效于以下代码，但比它短：

```
String value = null;
if(object != null) {
    value = object.getValue();
}
```

正如您所看到的，如果`object`引用是`null`，这两个代码示例都避免调用`object.getValue()`，但是第一个代码示例更短更优雅。

## 作为最大函数的三元运算符

您可以使用 Java 三元运算符实现与 [Java Math max()函数](math-operators-and-math-class.html#math-max)相同的功能。下面是一个使用 Java 三元运算符实现`Math.max()`功能的例子：

```
int val1 = 10;
int val2 = 20;

int max = val1 >= val2 ? val1 : val2;
```

注意三元运算符条件如何检查`val1`值是否大于或等于值`val2`。如果是，三元运算符返回`val1`值。否则它返回`val2`值。

## 作为最小函数的三元运算符

Java 三元运算符也可以用来实现与 [Java Math min()函数](math-operators-and-math-class.html#math-min)相同的效果。下面是一个使用 Java 三元运算符实现`Math.min()`功能的例子：

```
int val1 = 10;
int val2 = 20;

int max = val1 <= val2 ? val1 : val2;
```

注意三元运算符条件如何检查`val1`值是否小于或等于值`val2`。如果是，三元运算符返回`val1`值。否则它返回`val2`值。

## 作为 abs 函数的三元算子

Java 三元运算符也可以用来实现与 [Java Math abs()函数](math-operators-and-math-class.html#math-abs)相同的效果。下面是一个使用 Java 三元运算符实现`Math.abs()`功能的例子：

```
int val1 = 10;

int max = val1 >= 0? val1 : -val1;
```

注意三元运算符条件如何检查`val1`值是否大于或等于 0。如果是，三元运算符返回`val1`值。否则返回`-val1`，对应否定一个负数，使其为正。

## 链式三元算子

可以将多个 Java 三元运算符链接在一起。为此，可以让三元运算符返回的值之一成为另一个三元运算符。以下是 Java 中链式三元运算符的一个示例：

```
String input = ... // get input parameter String from somewhere.

int value = input == null ? 0 : input.equals("") ? 0 : Integer.parseInt(input);
```

注意第一个三元运算符条件如何检查输入字符串是否为`null`。如果有，第一个三元运算符立即返回 0。如果输入字符串不是`null`，第一个三元运算符返回第二个三元运算符的值。第二个三元运算符检查输入字符串是否等于空字符串。如果是，第二个三元运算符立即返回 0。如果输入字符串不等于空字符串，第二个三元运算符返回`Integer.parseInt(input)`的值。

只要每个三元操作符返回单个值，并且每个三元操作符用于代替单个值（Java 三元操作符是一个表达式，因此计算为单个值），就可以任意地链接和嵌套 Java 三元操作符。

当然，您可以简化上面的三元运算符示例。您可以将返回 0 的两个条件组合成一个条件，而不是链接三元运算符，如下所示：

```
int value = input == null || input.equals("") ? 0 : Integer.parseInt(input);
```

然而，这仅仅是可能的，因为值`null`和空字符串都返回相同的值（0）。总之，重点是向你展示如何*链接* *Java* *三元运算符*。这就是为什么例子是这样写的。
