一旦你有时间下载了 Java 及其环境，就是时候通过编写第一段代码来尝试一下了。为了成功完成任务，你需要学习一些 Java 中常用的命令。这些命令可以输入到你的文本编辑器中，然后告诉程序你想执行的操作。

在 Java 中编写代码可以很简单，你只需要获得在系统内部和文本编辑器中工作的经验。要在 Java 中开始你的第一段代码，请采取以下步骤。

**步骤 2**：环境启动后，打开你想要使用的文本编辑器。如果你有 Windows 电脑，记事本是一个很好的选择，但任何类似的工具都可以很好工作。

现在我们将创建 `Hello World` 程序。对于你任何想要工作的编程语言来说，这都是一个易于使用的程序，因为你将掌握语法的工作原理，并让“Hello World”字样出现在屏幕上。

要开始这个，只需进入你的文本编辑器，点击新建文件，然后将此文档保存为 `HelloWorld.java`。`HelloWorld` 将是你的类名，请记住这一点，因为类名必须与文件名相同。

文件创建后，就是时候声明类和主方法了。无论你在 Java 程序中创建什么种类的程序，主方法在方法声明方面都是相同的。此时，你应该已经有了以下语法：

```java
public class HelloWorld {
    public static void main(String[] args) {
    }
}
```

将这部分写到你的文本编辑器中。接下来，你需要编写代码部分，以告诉你的文本编辑器你想打印什么内容。对于这一点，你需要输入：

`System.out.println("Hello World");`

这将告诉系统你想在屏幕上打印“Hello World”这个短语。

你可以尝试这段代码，并根据你想显示的内容更改程序中的消息。对于这部分，有一些内容可以帮助以正确的方式完成，让我们看看它们是如何工作的：

- `System`：这部分将提醒系统它需要执行某些操作。
- `Out`：这告诉系统你正在创建一个想要打印在屏幕上的输出。
- `println`：这部分在系统中代表打印行。你基本上是在告诉系统打印后面的语句。
- **括号**：在“Hello World”部分周围有一些括号。这意味着它前面的代码接收了一个参数，或者说是 `Hello World` 字符串。

所以基本上这段代码的作用是提醒系统你需要它执行某些操作，你想创建一个输出，并且你想将“Hello World”行打印到你的屏幕上。

在继续之前，在 Java 中制作这些代码时，你应该遵循一些规则。首先，在行尾添加分号是一个好习惯。这是一个良好的编程习惯，有助于编辑器正确打印。Java 也是一种大小敏感的语言，因此在编写类名、变量名和方法名时，注意使用的是大写字母还是小写字母。最后，任何针对特定循环或方法的代码块将用大括号括起来。

所以让我们把这些代码整合在一起，你可以将其放在文本编辑器的正确位置：

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }

```

一旦将这些内容写入代码，就是时候保存你的文件，然后打开一个命令提示符（也称为终端）来编译程序。你可以导航到 `HelloWorld.java` 所在的文件夹。输入 `javac HelloWorld.java`。这会告诉你的编译器你想编译 `HelloWorld.java`。

如果你的代码中出现错误，编译器将能够告诉你你的代码中可能出了什么问题。否则，编译器将不会显示任何信息。然后你可以查看存储 `HelloWorld.java` 的目录，里面应该就是我们设计的 `HelloWorld` 类。这个文件在你想要运行程序时会被用到。

现在我们已经写好了一个程序，你可能想尝试一下并看看它是否可以运行。打开终端或命令提示符并输入 `java HelloWorld`。如果一切都正常进入程序，控制台上将显示出“Hello World”字符串，你就写出了你的第一段 Java 代码！

### 扩展 Hello World 程序：用户交互

操作 `Hello World` 程序非常简单，这让你对这个程序将如何工作有了一些经验。在这里我们将对 `Hello World` 程序进行稍微的扩展。在 `Hello World` 程序中，我们打印了一个字符串供用户查看，但现在我们将扩展程序，让用户能够输入自己的名字，然后程序将用他们的名字问候他们。

首先，我们将导入 `Scanner` 类。在 Java 中，有几个你可以访问的库，但你首先需要导入它们。我们需要的库中一个包含 `Scanner` 对象的库是 `java.util`。要导入这个 `Scanner` 类，请使用以下代码：

```java
import java.util.Scanner;
```

这告诉程序你想要使用位于 `java.util` 包中的 `Scanner` 对象。在方法内部，我们将使用这个 `Scanner` 对象实例化（`new`）一个新的实例。要使用这个 `Scanner` 类，我们只需要创建一个新的 `Scanner` 对象，并对其填充以及使用它的方法。为了让这些 `Scanner` 对象为我们工作，我们需要使用以下代码：

```java
Scanner userInputScanner = new Scanner(System.in);
```

那么这段代码是什么意思？它将告诉计算机做什么？以下是关于不同部分如何运作的解释：

- `userInputScanner`：这是我们使用的 `Scanner` 对象的名称。注意，它是使用所谓的驼峰命名法编写的；这是 Java 中编写变量的习惯方式。
- `new` 运算符将帮助为你的对象创建一个全新的实例。对于这个实例，我们通过 `new Scanner(System.in)` 部分在 `Scanner` 对象中创建了一个新实例。
- 这个新对象将接收一个参数，告诉对象它们需要什么。`System.in` 将为此工作，它告诉程序你想从系统扫描输入，这基本上就是用户的名字。

现在我们可以处理提示用户输入的内容了。我们需要要求用户输入，以便我们知道他们应该在控制台中输入某些内容。否则，程序将一直停留在那里，因为没有任何内容输入。你可以通过以下代码实现这一点：

```java
System.out.print("What's your name?");
```

你应该做的下一部分是让 `Scanner` 对象接收用户输入的信息，然后将这些信息存储在一个新变量中。`Scanner` 负责接收用户正在输入的数据，此时这应该是他们的名字。要做到这一点，请使用以下代码：

```java
String userInputName = userInputScanner.nextLine();
```

这应该告诉 `Scanner` 对象你想将用户输入读入系统中，并将其作为后续部分的变量。它现在可以用作显示给用户的问候语。由于你拥有了用户的名字，你可以将其写出来，让程序在提到名字的同时留下另一个消息。下一步是编写下面的代码：

```java
System.out.println("Hello " + userInputName + "!");
```

到此为止，我们已经将代码分成了不同的步骤并进行了讨论，但让我们把它们整合在一起，帮助你看到这段代码应该是如何写的：

```java
import java.util.Scanner;

public class HelloWorld {
    public static void main(String[] args) {
        Scanner userScanner = new Scanner(System.in);
        System.out.print("What's your name?");
        String userName = userScanner.nextLine();
        System.out.println("Hello " + userName + "!");
    }
}
```

一旦这段代码进入系统，你就可以编译并运行程序了。进入你的命令提示符或终端窗口，然后运行与上一节中 `HelloWorld.java` 相同的命令。你可以通过输入 `javac HelloWorld.java` 来编译此程序。

当你输入 `java HelloWorld` 时，你的程序应该询问“What's your Name?”。你可以输入名字 Jane。一旦你在名字处按下回车键，程序将打印出 `Hello Jane!`，然后程序结束。

虽然这部分可能需要多几行来完成，但它仍然非常基础。它利用你在第一部分中学到的原始技能，并将其扩展为带有几个额外部分的代码。尽管需要更多的部分，但你会发现这是一种基础代码，它为你编写的代码增加了一点个性化特征。

### 实例变量

通过 `new` 关键字创建并在其对象被销毁时被销毁。它们对于声明它的类内部的所有块、构造函数和方法都是可见的。如果你希望类中的子类可以访问实例变量，也可以给实例变量加上 `public` 关键字，但建议尽可能将访问性设置为 `private`。你还应该注意，与局部变量不同，你所有的实例变量都将有一个默认值。

实例变量的示例包含以下内容：

```java
public class Test {
    public int num; // 名为 num 的整数

    public void dog() {
        num = 3;
    }
}
```

通过这个示例，我们在方法之外声明了整数 `num`，你可以在 `Test` 类内部的所有方法中随时访问它。



这些变量需要使用 `static` 关键字来声明，并且可以在任何块、构造函数或方法之外声明。如果你的变量是静态的，那么该变量只会存在一个实例；无论调用了多少个对象实例。大多数情况下，除非你正在处理常量值（基本上是不会改变的变量），否则静态变量将不会被使用。

静态或类变量的一个良好例子是：

```java
public class Test
{
    public static final int num = 3; // 名为 num 的整数

    public void dog()
    {
        System.out.println(num)
    }
}
```

通过这个示例，我们声明了名为“num”的 `int`，然后将其设置为 `public`（公共）、`static`（静态），以及 `final`（最终）。这基本上意味着你只需要操作一次且值永远不改变，就可以在子类内部访问名为 number 的 `int`。

## 局部变量

你的局部变量只会在构造函数、块或方法内部声明，并且只有在创建其中一个时它们才会被创建。一旦方法结束，局部变量就会被销毁。这些变量只出现在一个地方，所以如果你尝试从创建位置之外调用它，你将无法获得成功，而且它们在调用区域之外也是不可见的。

局部变量如何调用的良好示例包括：

```java
public void cat() { // 名为 cat 方法
    int x = 0; // 值为 0 的 int
}
```

通过这个示例，名为“x”的变量是在“cat”方法内部被调用的。这个特定的变量只存在于 cat 的上下文中，你无法使用任何其他方法来访问或调用这个特定的变量。

这三种类型的变量将帮助你准备好编写所需的最佳代码。无论你是想从系统中的任何类或方法中调用该变量，还是希望保留局部变量以便你的变量只在需要时显示，变量在你的努力中将被证明非常有价值。

## 数据类型

现在你对变量有了更多的了解，是时候看看它们能够持载的不同数据类型了。Java 有许多内置在程序中的数据类型，用于存储预定义的不同类型的数据。在 Java 中，这些被称为基数据数据类型，它们是语言中最基础的数据类型。你也可以创建一些你自己的数据类型，但我们现在只需查看一些数据类型，包括：

- `Byte`（字节）
- `Short`（短整型）
- `Int`（整数）
- `Boolean`（布尔）
- `Char`（字符）
- `String`（字符串）

所有这些类型都将使在 Java 中编写你所需的代码变得更容易。字节是其中最基础的，允许你开始；而当你想要处理数字时，整数非常好；布尔值基本上是真和假的选项；而字符串就像是你代码内部的语句。

所有这些都将使在 Java 中编写你所需的代码变得更容易。

当你准备好在代码中声明变量时，将包含三个部分：存储的值、变量名和数据类型。首先，在命名变量时，你应该遵循一些规则。你的变量名可以根据你的意愿任意长或短，但它必须以字母、下划线或美元符号开头，否则你将在代码中遇到错误。一旦确定了第一个字符，你可以使用任何你喜欢的字母、数字、下划线或美元符号来命名变量的其余部分。通常在使用多个单词命名变量时，会将第一个单词设为小写，随后的单词以大写字母开头。

变量声明后，就是时候读取或更改它的值了。请记住，一旦声明了变量，你就只能通过这个名称来引用它，并且只需要在声明变量时声明数据类型。变量在代码内部的示例如下：

```java
int a; // 无值
int b = 1; // 值为 1
int c = 2; // 值为 2

a = b+c; // 将 a 设置为 b+c 的值
```

在这个示例中，你更改了 `a` 的值，使其等于 `b` 和 `c` 相加的和。当你开始时，有一个 `b` 值，但当所有变量在代码内部使用后，你的 `a` 将是 3。

现在我们已经学习了如何使用变量，让我们看看赋值是如何工作的。赋值是给变量赋予值的方式。我们使用等号 (`=`) 来执行操作。例如，如果我们想将值 5 赋值给变量 `a`，我们将编写 `a = 5;`。

这里是赋值在代码中的示例：

```java
int a;
a = 10; // 将 10 赋值给 a
a = a + 5; // 将 a 增加 5 并结果赋值回 a
```

你也可以使用快捷运算符来使赋值更简洁，例如 `a += 5;`，它等同于 `a = a + 5;`。

- `Assert`（断言）——这通常用于检查你想要执行的语句。
- `Pass`（通过）——这将允许你创建一个空代码块。

关于这些字符，你需要记住的一点是，当它们作为字符使用时，不能转换为变量。它们是 Java 中的保留命令，告诉你的文本编辑器你希望在代码执行期间发生什么。

在 Java 中编写注释是一个简单的过程。你只需要在注释前添加一个井号，写下你想要的语句，然后跳到下一行继续编写代码。编译器会识别井号并直接跳过这部分代码，因此它永远不会显示在屏幕上。你可以在代码中使用尽可能多的此类注释，但要保持在最小范围内，以避免你的 Java 代码可读性出现问题。

## 循环语句

循环语句通过告诉计算机继续循环直到语句返回假，可以节省大量的时间和精力。

### `while` 循环

普通循环语句将帮助在读取语句并确定答案为真为假后运行程序。

### `do...while` 循环

`do while` 循环语句与普通循环语句略有不同，不同在于 `do while` 会在检查条件是否满足之前先运行。如果你想确保循环至少运行一次，这个很好用。

**对比示例：**

```java
int x = 0;
```

```java
do {
    System.out.println(x);
    x--;
} while(x > 0);
```

对于这个示例，输出将与 `while` 循环不同。如果你将其写成普通的 `while` 循环，代码将永远不会运行，因为它在第一轮就会变为假。但使用 `do` 循环，循环会运行一次，发现语句为假，然后停止。因此，如果你想确保循环至少运行一次，你需要使用 `do` 循环的语法。

### `for` 循环

for 循环适用于在循环内部处理增量和范围操作。

**语法：**

```java
for(initialization; termination; increment) {
    // statement
}
```

在这段代码中：
- **初始化**：将初始化你想要使用的计数变量（只会在你调用 `for` 循环时发生一次）。
- **终止**：将指定系统应该评估的表达式，以判断其为真还是假。
- **增量**：将是计数变量中初始化的增量。

**执行流程：**
初始化之后，它将至少运行一次。一旦一个循环完成，它将调用下一个增量值，然后检查程序是否应该终止。如果没有终止，则会再次调用增量值。这将一直持续，直到系统确定语句为假并且是停止的时候。

**示例：**

```java
for(int x = 0; x < 10; x++) {
    System.out.println(x);
}
```

对于这个示例，我们首先引入 `for` 循环。然后我们创建一个名为 "x" 的新 `int`，并将其设置为 0。接下来，我们规定这个 `int` 何时终止，即只要 `x` 小于 10，循环就会继续。然后我们将 `x` 值的增量设为增加 1。循环将重复从 0 到 9 的所有数字，但在达到 10 时终止。

# Java 中的数组

有时你可能想将代码中的几个变量组合在一起。你可以选择在代码中逐行列出它们，这需要大量时间并使代码变得混乱，或者你可以选择使用数组将它们全部整合在一起，而无需这些麻烦。

数组是存储固定数量相同类型变量的数据结构。与其在代码中创建许多不同的整型变量来存储所有的数值，你不如创建一个容纳所有这些数值的整型数组。这使得管理整数变得更容易，并保持代码更易于读。

## 声明数组

声明数组与声明普通变量相似。你创建这些数组时应该使用的语法是：

```java
dataType arrayName[];
```

## 多维数组

我们上面讨论的数组相当简单，只增加了一个维度，但你可以让数组变得更复杂。当你添加更多维度时，你会在你的数组内部添加新数组。

**示例：二维数组声明**

```java
int[][] intArray = new int[5][5];
```

这个数组内部有两个维度。第一个五个表示你正在声明一个拥有五个索引值的数组。第二个数组意味着，对于上面的五个索引值中的每一个，你都可以访问其内部附加的索引值。

**访问多维数组元素：**

```java
int[][] intArray = new int[5][];

intArray[0][0] = 1;
intArray[0][1] = 1;
intArray[0][2] = 1;
intArray[0][3] = 1;
intArray[0][4] = 1;
// 依此类推，直到获取所有它们。
```

如果你想访问第二层的信息，必须首先列出它所包含的层级，然后是第二部分信息所在的名称。

## 数组与循环结合使用

循环允许你快速地分配和检索非常大范围的值，而数组也让创建大范围的数字变得更容易。将它们结合将是多么高效和美好？

### 示例 1：`while` 循环遍历数组

```java
int[] intArray = new int[100];
int x = 0;

while (x < 100) {
    intArray[x] = x;
    System.out.println(intArray[x]);
    x++;
}
```

在这个示例中，我们声明了数组并赋予了它一百个索引值。完成后，我们声明了想要递增的整数变量。我们告诉 `while` 循环，只要 `x` 的值小于 `intArray` 的长度，它就继续循环，而长度就是 `intArray` 拥有的索引数量。然后，我们在每次迭代中让 `x` 递增 1。这段代码允许你快速编辑一百个值，然后将它们打印到控制台上。

### 示例 2：`do...while` 循环遍历数组

```java
int intArray[] = new int[100];
int x = 0;

do {
    intArray[x] = x;
    System.out.println(intArray[x]);
    x++;
} while(x < 100);
```

对于这个示例，我们将得到与第一个示例相似的结果，只是我们设计了 `do-while` 循环而不是使用 `while` 循环。输出将相同，但你将确保循环至少执行一次。

### 示例 3：`for` 循环遍历数组

```java
int intArray[] = new int[100];
for (int x = 0; x < 100; x++) {
    intArray[x] = x;
    System.out.println(x);
}
```

对于这个示例，我们正在执行与其它选项相似的操作，但计数器变量将构建在你的循环中。这意味着你不需要去遍历并声明另一个变量，也不需要告诉系统手动为你递增。这是一种处理数组和循环更高效的方法，不需要编写那么多的代码。

### 示例 4：嵌套 `for` 循环遍历多维数组

```java
int[][] intArray = new int[100][100];
for(int x = 0; x < 100; x++) {
    for(int y = 0; y < 100; y++) {
        intArray[x][y] = y;
        System.out.println(intArray[x][y]);
    }
}
```

这个示例是展示如何遍历多维数组循环的最佳方法之一。你将有两个嵌套的循环，每个循环都负责数组中的一个特定维度。对于这一个，第一次进入循环时，它将处理 `x = 0` 部分，然后它将遍历所有以零开头的数组索引。一旦所有这些索引都被调用，它将把 `x` 递增 1。它会完成这个过程，直到所有索引都被调用。

## 总结

处理数组和循环可以帮助简化你想要编写的一些复杂代码。例如，与其编写一百条语句，你可以设置一个从 1 直到 100 递增 1 的循环。数组可以帮助将某些变量存储在一起，而不是让它们分开列出导致代码变得复杂。你甚至可以将数组和循环结合起来，创建一个可以在程序内部运行你所需的各种组合的复杂代码。

- 数组可以只有一个层级，你也可以添加多个层级来将内容组织在一起。我们只看了两个维度，但你可以根据需要添加任意数量的维度。
- 数组本身在代码中是强大的，你还可以将它们与循环结合，让程序按照你的意愿重复。

# Java 中的函数与方法

当你想要在 Java 中创建一个新程序时，函数和方法是非常重要的。方法是你与代码中的对象通信的方式。当你调用一个方法时，我们是在请求对象执行这项任务。我们基本上可以说，方法实现了你对象的行为。

你的每一个方法都需要给出一个名称，并且你需要定义输入参数以及返回类型以便其正常工作。设置方法的可见性（包括 `public`、`protected` 或 `private`）也是一个好主意。当需要调用方法时，所有这些部分都会发挥作用。

## 定义函数的规则

使用 Java 定义你自己的函数是可能的。在使用这种编程语言时，你会发现你所做的每件事都定义在一个类中，并且所有的类都有方法。所以，如果你想定义一个执行你自己的计算的单元，你需要定义一个类以及该类内部的方法。

**核心规则：**
1. 你在 Java 中创建的代码都将是类的单元。
2. 每个文件都可以定义你需要的任意数量的类。许多初学者假设文件只能定义一个，从而承担了比他们需要的更多的工作。但是，**文件名必须与文件中的某个类名相同**；不关是哪一个，但它需要与之关联。
3. 你文件中的主类必须有一个名为 `"main"` 的方法。这将是程序中开始执行代码的位置。
4. 你文件中的其他类需要起辅助作用。这就是为什么它们通常被称为子程序或函数。

## 代码示例

请记住，你应该在文本编辑器将其保存为 `F1.java`。

**辅助类 `F2`：**

```java
class F2 {
    public int addon(int n) {
        return n + 1;
    }
}
```

**主类 `F1`：**

```java
public class F1 {
    public static void main(String[] arg) {
        F2 x1 = new F2();
        int m = x1.addon(4);
        System.out.println(m); // prints 5
    }
}
```

**代码解析：**
通过上面的代码，我们创建了一个名为 `F1` 的主类，然后在 `F2` 内部定义了 `addon` 方法。我们将通过创建它的实例（即 `x1`）来调用这个方法。一旦这个实例被创建，我们就可以调用 `x1` 方法来为你执行代码的计算。

这是你在 Java 中想要创建许多程序时都会用到的大纲。Java 中的这些函数将帮助你调出语言内部所需的某些代码，并确保你在最需要它们时能够获取正确的方法。每个函数的工作方式略有不同，内部包含不同的信息，但它们将遵循与上述列出相同的大纲。

# 类与对象

类和对象是任何编程语言工作中的一个重要部分。它们被用于整理代码内部的一些信息，这不仅让编写代码更容易，也让其他程序员阅读代码以及你的程序执行代码变得更容易。

## 面向对象编程 (OOP)

首先，让我们看看 Java 这种面向对象的编程语言。一些旧版本的编程语言不是基于 OOP（面向对象）公式的。这些语言通常让非程序员对入门感到畏惧，因为它们很难使用。

对于像 Java 这样的 OOP 语言，事情变得更有意义了。对象将世界中的物理对象联系起来，并在你完成工作后它们将保持在那里。

## 对象

对象是代码中可以与世界中的物理事物联系的部分。它们将拥有属性，就像世界中的真实对象一样。

**示例：`ball` 对象**
- 你需要一些让其他阅读代码的人能够理解的属性。
- 例如，你可以给对象 `ball`（球）`round`（圆形的）属性，因为这符合逻辑。
- 但如果你给它 `triangle`（三角形）属性，这是不被允许的。属性应该是与对象相符的、有意义的，否则它不能被视为你对象的属性之一。

在处理对象时，会产生很多想法，虽然其中一些可能是具体的（例如上面使用的球），但另一些可能更抽象一些。将对象与我们世界的真实物品联系起来是设计代码更好的方法，这种方法可以确保代码保持整体并让初学者更容易学习，这也是使用这种语言的好处之一。

## 类

类将与对象一起工作。它们负责持有各种对象以帮助代码的组织有序。但是，你的类不仅仅是存放一些随机的对象；相反，它们负责将相互相关的对象聚集在一起。



# 类与对象

类中的对象并不非要完全相同。你可以创建一个包含圆球以及它所有允许内容的类，但为运动设备创建一个类同样可行。后者不仅包括圆球，还包括冰球棒、冰球、头盔、制服、跨栏、足球等其他物品。

类中的项目需要属于同一个类别，它们不需要像上面描述的那样完全一样。如果在一个类中将对象放在一起是有意义的，请确保将它们放在同一个类中。这可以帮助你在程序需要时调出正确的内容，并让代码更有组织性。

## 类框架的基本组成

在你的类框架中，你应该包含一些内容。这些内容将帮助程序正常运行，并确保你能够在需要它工作时随时调用该类。你应该在框架内部包含的内容包括：

- **程序类型**：你需要使用 `UNICODE` 声明来描述程序类型。
- **程序信息**：将在文中提供。你应该使用 `<HEAD>` 和 `</HEAD>` 符号来包围这些程序信息。
- **Java 程序部分**：将以类似的描述，但符号是 `<Java>` 和 `</Java>`。
- **标题**：应该在开头，位于文本 `<TITLE>` 和 `</TITLE>` 之中。
- **标题内容**：你在 `<<h1>>` 和 `</<h1>>` 之间看到的文本将是标题。如果你想显示多个标题，只需要更改标题编号，例如使用 `H2`、`H3`、`H4` 等。
- **程序主体**：程序的内容，或者你在屏幕上看到的信息将位于符号 `<BODY>` 和 `</BODY>` 之间。
- **段落**：如果你想创建一个段落，请在 `<p>` 和 `</p>` 之间编写文本。
