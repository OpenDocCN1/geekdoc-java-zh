# 第 1 章

## JAVA 简介

`JAVA` 是一种专门设计用于互联网的编程语言。与它的对标 `C++` 语言相比，它更容易使用，同时利用了面向对象的编程模型。`JAVA` 可用于创建整个应用程序，这些程序可以在网络中的客户端和服务器之间分发，也可以运行在单台计算机上。`JAVA` 还可以用于构建小型应用程序（applet）或小型应用程序模块，作为 Web 页面的一部分。Applets 允许 Web 用户与特定的 Web 页面进行交互。`JAVA` 程序可以在移动设备、桌面电脑、蓝光光、服务器和智能卡中找到。

`JAVA` 最初创建时被称为 `Oak`。`Oak` 由 James Gosling 在 1991 年创建。当时 James Gosling 就职于一家名为太阳微系统公司（Sun Microsystems）的时期，Gosling 编程语言的最初目的是用于电视机、烤面包机、录像机等小型电子设备。`JAVA` 从诞生之初的目标就是快速、高效、小巧且易于移植的。太阳微系统公司重新命名了这种编程语言并在 1995 年引入了 `JAVA`。引入之后，万维网的交互能力呈指数级增长。所有主要的 Web 浏览器都包含 `JAVA` 虚拟机。同样，几乎每个主要的操作系统开发者都将 `JAVA` 编译器作为其产品的一部分提供，主要的操作系统开发者包括微软（Microsoft）和 IBM 这样的公司。`JAVA` 现在由一家名为 Oracle（甲骨文）的公司所有并维护。

那么，`JAVA` 这个名字是怎么来的呢？当 James Gosling 和他的团队成员开发 `JAVA` 语言时，他们恰好在大量大量的高咖啡因咖啡。`JAVA` 团队觉得，由于他们恰好在喝的咖啡量大且质量高，他们能够更好地开发出更高质量的编程语言。James Gosling 和他的团队所喝的咖啡在 `JAVA` 编程语言的发展中有着非常特殊的角色，而且这些咖啡恰好从一个被称为“爪哇岛（Java Island）”的地方分发到全球。基本上，Gosling 和他的尖端团队受到启发，用他们咖啡因灵药源地的名称来为这种全新的编程语言命名。因此，`JAVA` 编程语言的符号就是那个显而易见的咖啡杯和托盘。

### 在开始阅读本书时，你需要了解关于 Java 的 10 个事实

1. `Java` 一词通常泛指以下三者的结合：

- 被称为 `JAVA` 的编程语言

- `JVM`，或 `JAVA Virtual Machine`（Java 虚拟机），它是 `JAVA` 平台。`JVM` 运行编译后的 `Java` 字节码，通常调用一组特定于 `JAVA` 的标准库。这些库包括企业版（称为 `EE`）提供的库，以及标准版（Java Standard Edition，简称 `SE`）。虽然 `JAVA` 平台和 `JVM` 设计为为协同工作，但语言本身并不一定意味着使用了 `Virtual Machine`，反之亦然。

- `Java Virtual Machine (JVM)` 指一种以高性能运行的虚拟机，在特定的平台上执行字节码。`JAVA Virtual Machine` 简称为 `JVM`。

2. 广泛使用的安卓操作系统 `OS` 的大部分层次都是使用 `JAVA` 构建的，因此如果你的目标是为安卓操作系统开发应用程序，学习 `JAVA` 是至重要的。通过 `JAVA` 编程，你能够构建游戏、嵌入式系统、网站和桌面应用程序，这些程序在移动设备和其他设备上也有类似版本。

3. 有 4 种不同的 `JAVA` 平台可用：

- `JAVA Micro Edition`（微型）。`JAVA Micro Edition` 包含了在较小设备（如平板电脑和智能手机）上运行应用程序所需的库和框架。

- `JAVA Enterprise Edition`（企业版）。`JAVA Enterprise Edition` 包含了主要用于企业构建应用程序的库和框架。

- `JAVA FX Edition`。`JAVA FX Edition` 包含了能够在各种平台上运行并构建强大的客户端程序的图形库。

- `JAVA Standard Edition`（标准版）。`JAVA Standard Edition` 包含了核心 `JAVA` 功能和核心 `JAVA` 库。这是你通过本书学习 `JAVA` 编程时使用的版本，在你继续追求编程教育时也将使用它。

4. `JAVA` 编程语言是一种面向对象的编程语言，程序员简称为 `OOP`，并在高层运行。

5. `JAVA` 程序运行在一种名为 `JAVA Virtual Machine`（Java 虚拟机）的特殊专用软件上，在编程领域简称为 `JVM`。

6. `JAVA` 虚拟机或 `JVM` 由许多操作系统支持。

7. 你需要下载并安装 JAVA 运行环境，也称为 `JRE`，以便安装 JAVA 虚拟机并运行 `JAVA` 程序。请注意，`JRE` 不能用于开发 `JAVA` 程序。`JRE` 只能用于运行 `JAVA` 程序。

8. 然而，为了访问开发 `JAVA` 应用所需的工具，你首先需要下载并安装 JAVA 开发包。`JAVA` 开发包也被程序员称为 `JDK`。目前可用的 `JDK` 最新版本是第 8 版本。不过，如果你下载了 `JDK 8 版本`，你就不需要下载 `JRE` 了，因为根据 `JRE` 的许可条款，你可以在你的应用程序中自由分发该版本的 `JRE`。

9. 缩写 `IDE` 指的是被称为集成开发环境的软件套件，它为编写计算机程序的人提供了必要的全面工具，以便软件的编写、测试和整体开发成为可能。通常情况下，一个现代 `IDE` 将由调试器、源代码编辑器和解释器或编译器组成。软件开发者利用单一的图形用户界面（被开发者简称为 `GUI`）来访问这三个工具。有两个非常流行且完全免费的 `JAVA IDE` —— 一个被称为 `Netbeans` 的 `IDE` 和另一个被称为 `Eclipse` 的 `IDE`。在本书中，你将学习如何利用 `Eclipse IDE` 进行编程。

## JAVA 特性

`JAVA` 的主要特性包括：

- `JAVA` 的代码是健壮的。这意味着 `JAVA` 对象可能包含对其他已知对象的引用，或者包含自身外部的数据。相比之下，用 `C++` 等语言编写的程序并不具备这种能力。这一过程确保了指令不包含操作系统本身中存储数据的地址，或其他应用程序的地址。其中任何一种情况都会有效导致操作系统或程序崩溃或终止。为了确保完整性，JAVA 虚拟机（或 `JVM`）设有许多检查机制。

- `JAVA applets` 具有其他特性，使其能够高效地运行，而且它们不是在服务器执行，而是在客户端执行。

- `JAVA` 比 `C++` 容易得多，尽管这种语言确实不是一夜之间就能学会的。

- 用 `JAVA` 创建的程序在网络中是移植的。这意味着这些程序可以在创建它的其他操作系统中运行，而无需进行复杂的、耗时的重大重构。源程序被编译成 `JAVA` 所指的 `字节码`。这种 `字节码` 可以在任何带有 `JVM` 的客户端或服务器网络上运行。该 `JVM` 然后将 `字节码` 翻译成代码，该代码就有在实际计算机硬件上运行的能力，这意味着平台之间的明显差异（例如指令的长度）能够在程序执行时立即被识别并在本地处理。基本上，`JAVA` 确保了不再需要为你的软件程序产生特定平台版本。

- `JAVA 编程` 是所谓的面向对象。这意味着单个对象可以作为对象组的一部分，并继承该类的公共代码，以及其他许多特性。与传统的过程化“动词”不同，对象是用“名词”来指代的，人们更容易与之建立联系。方法可以被看作对象的行为或能力之一。

## 更多关于面向对象编程 (OOP)

面向对象编程被程序员称为 `OOP`，是一种围绕数据而非逻辑、围绕对象而非动作的语言模型。在处理输入数据后，它会输出数据。`OOP` 关注的是感兴趣的处理对象，而不是为了使其运行而所需的逻辑。例如，这些对象可以从计算机组件到建筑及其楼层，再到人类等。

在 `OOP` 中，第一步是定位程序员想要操纵的所有对象，然后识别这些特定对象如何相互关联。这一过程通常被称为数据建模。一旦程序员选择了一个要进行标识的对象，程序员就会对其进行泛化处理。例如，这本特定的书将代表所有的书。这种泛化定义了对象持有的信息类型，以及可以与之协作的逻辑序列。每个独立的序列被称为 `method`（方法）。`OOP` 中的对象通过消息进行通信，消息是定义清晰的接口。`OOP` 中使用的规则、参数和概念提供了所有程序员都需要意识到并掌握的这些处：

- `data class`（数据类）概念允许定义对象子类，这些子类具有所有或至少部分关键组特征。`OOP` 的这种特定特性被称为 `inheritance`（继承），它缩短了开发时间，继承确保了更准确的编码，而且继承还需要更彻底的数据分析。

- `class`（类）只定义特定的数据。当该对象或组运行时，代码不会错误地访问程序中非预留的数据。这种被称为 `data hiding`（数据隐藏）的特定概念特性避免了无意的数据损坏，并提供了更高的系统安全性。

- 由于某个 `class` 的定义不仅可以被其专门为构建的程序复用，还可以被其他面向对象的程序复用，因此在网络中使用时分发效率更高。（参考“编写一次，随处运行”概念）

- `data class` 概念允许程序员构建语言本身尚未定义的任何新数据。

## 了解 applets 的使用

`JAVA` 产生被称为 `applets` 的浏览器运行程序。尽管 `applets` 随着时间的推移变得越来越过时，但它们被用于促进 Web 用户与图形用户界面 `GUI` 之间的交互。在 `JAVA applets` 出现之前，网页和网站通常不是交互性的，而是静态的。竞争产品（如 `Microsoft Silverlight` 和 `Adobe Flash`）使得 `JAVA` 变得不再流行，尽管它曾主导市场。`JAVA` 使用 `JVM` 在浏览器上运行其 `applets`。`JVM` 然后将特定代码翻译成所谓的原生处理器指令，也称为原生代码。

## JAVA 与 JavaScript 的区别

虽然 `JAVA` 和 `JavaScript` 都是用于 Web 页面功能或应用程序的编程语言，但 `JAVA` 不与 `JavaScript` 混淆是非常重要的。`JavaScript` 起于 Netscape，并且比 `JAVA` 稍微容易学习一些。`JavaScript` 的解释层次比 `JAVA` 高，这意味着 `JavaScript` 使用的是一种具有强抽象能力的编程语言，或者说是一种脱离计算机细节来管理计算机系统复杂性的技术。然而，`JavaScript` 缺乏 `JAVA` 字节码的运行以及某些可移植性。这意味着 `JavaScript` 的运行速度明显比 `JAVA` 慢得多。`JAVA` Applets 可以在几乎任何操作系统上运行，而不需要重新编译，并且没有特定于某个操作系统的变体或扩展。这使得 `JAVA` 通常被认为是开发 Web 应用程序最具战略性的语言。然而，`JavaScript` 在运行在 Web 服务器或 Web 客户端的极小应用程序中可能是很有用的。

到目前为止，`JAVA` 和 `JavaScript` 之间最显著的区别在于它们被用于创建的应用类型。`JAVA` 程序用于通过 Web 页面启动或从计算机桌面运行的应用程序。这些程序是独立的程序，通常会打开一个完全独立的程序窗口。此外，在没有安装 `JAVA` 的情况下，计算机绝对无法运行 `JAVA` 应用。然而，`JavaScript` 始终包含在所有最新的浏览器中，只要 `JavaScript` 已启用，它会在 Web 页面加载时启动页面上的 `JavaScript`。

当程序员使用 `JavaScript` 代码时，`JavaScript` 的“思考”和计算始终在客户端侧执行。客户端指的是最初访问 Web 页面的台计算机。另一方面，`JAVA` 程序通常在特定的 `JAVA` applet 内或在服务器端执行所有主要的“思考”过程和计算过程，而该 applet 必须先被下载。由于 `JavaScript` 运行在客户端，它的运行速度通常比 `JAVA` 快，而且取决于连接速度，有时甚至是瞬时完成的。由于 `JAVA` 程序运行在客户端，处理需要稍微多一点时间，但通常只需要几秒钟或更多。

`JavaScript` 使用的内存比 `JAVA` 少得多，事实上在某些情况下，为了进行处理并确保正确运行，它仅需要非常、非常少的内存。由于其内存需求较低并且能够提供许多多样的 Web 页面功能，`JavaScript` 是目前 Web 上许多不同页面中非常常用的编程语言。然而，`JAVA` 程序有时可能需要大量的计算机内存才能正常运行。这种要求绝对会导致另一个程序的运行速度变慢得多，甚至导致计算机完全变慢。因此，尽管 `JAVA` 程序具有开发各种通常是强大的功能的固有能力，但因为它利用了更高的内存，它在某些方面也可能成为速度上的劣势。

# 第 2 章：JAVA 现在是如何被使用的

截至 2016 年，`JAVA` 目前已被全球超过 900 万名软件开发人员使用，也是可用最常用的编程语言之一，特别是对于客户端/服务器应用程序。无论计算机架构如何，`JAVA` 应用都可以被编译成在所有 `JVMs` 上运行的代码。`JAVA` 曾主要被等同于性能缓慢（需要等待 Sun 微型系统公司发布升级）、字节码解释以及对 Applets 的使用。然而，今天 `JAVA` 更多地与可靠的高性能、热点代码的动态编译、日益独立的开源社区，以及面向服务的体系架构（或 `SOAs`）、Web 服务以及 Web 应用程序联系在在一起。本章将深入探讨 `JVM`、`JAVA` 编程语言以及 `JAVA` 平台的使用。

## 使用 JAVA 编程语言

`JAVA` 编程语言在高层次运行，其灵感源于 `Smalltalk` 以及 `C` 和 `C++` 编程。`JAVA` 编程语言还借鉴了其他语言的一些思想。`JAVA` 编程语言的语法设计是为了让那些熟悉“大括号”类 C 系源语言的人感到熟悉，但比 `C++` 使用的原则具有更强（有时可以认为）面向对象原则。此外，垃圾回收是相当自动的，这消除了开发者需要释放过时且不再使用的对象所占内存的需求。

`JAVA` 在哲学上被称为一种“早期失败”语言。由于它有语法限制，大多数编程错误在 `Java` 中实际上根本是不可能的。由于 `JAVA` 不能直接访问指针，其特定的算术错误根本不存在。将某个对象用作其原始命名类型以外的类型需要直接的强制类型转换，这允许代码编译器有明显的机会拒绝可能不符合逻辑且无法使用的编程。

各种 Java 企业级框架使得必须使用部署描述符或配置文件（通常用 `XML` 编写）来识别功能。这可能包括在规则引擎内执行所需的步骤顺序，或者哪个类可能处理 `HTTP` 中的特定请求。换句话说，它们必须超越语言本身才能正确实现其功能。`JAVA 5.0` 为这种语言添加了脚注，这允许对类、字段和方法标记值，然后这些值可以在运行时进行开发和检查，通常通过 `reflection` 实现。许多软件程序员更喜欢这些脚注（通常称为注解 `annotations`），因为它们可以简化可能通过某些描述符或其他方式提出的内容。然而，它们也可能使解释 Java 代码变得困难。是否存在脚注或注释实际上可能会影响代码的执行，并可能以脚注或注释本身不完全明显的方式影响代码。

除了这一单一批评外，`JAVA` 目前主要被认为是世界上最受欢迎的通用计算机语言。`JAVA` 编程语言的优点是巨大的。主要优点包括但不限于：

*   拥有巨大知识库的优势。
*   拥有海量随时可用软件开发人员的优势。
*   在 `Windows`、`Solaris`、`Linux` 和 `Mac` 等多个平台上广泛提供的免费工具的优势。所有这些平台都能执行和编译所有 Java 应用。

`JAVA` 编程语言本身在代码性能与软件开发者效率的权衡中触及了一个独特且价值点。尽管 `CPU`（中央处理器）周期循环的成本因素一直在稳定下降，但软件开发者的成本通常并没有持续降低。事实上，由于许多原因，软件开发者的成本仍在增加，其中包括通货膨胀的上升和技术教育成本的增加。由于这一事实，可能不可避免地导致在执行的 `CPU` 指令码和软件开发者之间引入额外的抽象层——只要这种抽象能让软件开发者能够以更高效的速率创建更高质量的软件。

# JAVA 平台的用法说明

`JAVA` 通常被分为三个不同的平台。这三个平台在本书前面的部分已简要介绍过。请注意，这里不包含 `JAVA FX` 版本。

1. 企业版（Enterprise Edition），也称为 `JAVA EE`
2. 标准版（Standard Edition），也称为 `JAVA SE`
3. 微型版（Micro Edition），也称为 `JAVA ME`

这些不同的平台都利用了特定库组、虚拟机和执行其代码的语言版本的组合。`EE` 版本包含了 `SE` 版本的所有内容以及更多，这意味着任何 `EE` 应用都可以访问并利用整个 `SE` 库。此外，`EE` 对编程语言的使用也与 `SE` 完全相同。这意味着 `SE` 版本是 `EE` 版本的子集。

`JAVA 微型版`（或 `ME`）与其对应版本有显著不同，这是因为小型设备（如智能手机）在空间和能力上的限制要多得多。`微型版`不能被视为`标准版`的子集（因此不能被视为 `EE` 的子集），因为它的许多库只存在于`微型版`中。此外，由于运行平台的计算限制，`微型版`版本完全消除了某些编程语言特性。此类被消除特性的示例包括 `Float` 类和 `float` 原始类型。这意味着`微型版`需要的工具与`企业版`和`标准版`略有不同。由于设备之间存在如此深层的差异，使得代码在微空间内的完全可移植性变得不现实。事实上，许多 Java 开发者将 `ME` 视为完全不同的物种，甚至几乎是一个独立的实体。



# 使用 Java 虚拟机 (JVM) 时的预期

`JAVA` 源代码在过程中的某个时刻必须翻译成可执行的平台原生代码。通常，这需要通过两步过程：

1. 软件开发者需要将源代码编译为 `JAVA` 代码。
2. 然后 `JVM` 必须根据使用的平台将这些信息翻译成该平台的原生代码。

第二步最初是通过解释执行完成的，或者通过获取每一条 `JAVA 虚拟机` (`JVM`) 指令并将其瞬间转换为平台的一个或多个原生指令。完成之后，被软件开发者称为 `JIT` 编译器的即时编译器（just in time compilers）会在程序运行时，将程序从 `JVM` 上的字节码转换为该特定平台的原生代码。目前有几种方法可以实现这种转换。Sun Microsystems 的 `HotSpot` 编译器通过翻译代码并在运行时对其进行剖析来初始化这一过程，优化并编译特定的区域。

存在许多多样的 `JAVA` 相关方面，完全不受 JCP（Java 委员会）的标准认可。许多独立项目在规模上已经增长到在 JCP 消费者的认知水平上，实际上可以与真正的 JCP 基准相竞争。但从整体而言，这些独立项目也能够快速适应修改，而完全不需要使用 `JAVA`，同时还能利用这些修改中的最佳特性，例如 `AJAX` 特性，这是一种简化代码的功能。这是一个直接 Web 远程项目，或者说是 `DWR` 项目，或者是受 Rails 启发的 `Trails` 项目。

## 变量

变量实际上是你将遇到的任何所有 `JAVA` 程序的基石，因此它们也是 `JAVA` 编程语言本身的基石。根据定义，计算机编程中的变量仅仅是存储位置以及相关的名称，该名称象征着未知或已知的信息或数量可能是什么。换句话说，即一个特定的值。简单来说，变量是一种存储某些信息以备以后使用的方法，并且可以通过引用描述该信息的名称或单词来检索。

例如，假设你选择导航到某个网站，而该网站执行的第一件事就是问你名字叫什么名字。这通常是为了建立某种形式的人类熟悉感——当你下次访问时，该网站将通过你的名字称呼你。构建网站的人会在屏幕上创建一个小文本框来询问你的名字，那个小文本框就代表一个变量。构建页面的人可能决定将那个小文本框命名为 `Visitor Name` 之类的名称，这就是该小文本框变量的符号词或名称。

那么，当你在小文本框中输入名字后，你的名字就会作为信息存储在一个名为 `Visitor Name` 的变量中。该信息将供构建页面的人（或程序员）轻松获取。然后，这个人就有能力再次访问页面并询问“变量 `Visitor Name` 包含什么值？”，程序将根据你第一次访问页面时在那个小文本框中输入的任何值来回答程序员。

这个概念在 `JAVA` 编程中不断反复使用，它在编程中也超级强大。这一特定概念是 Twitter 和 Facebook 运行的基础；它让你能够使用在线银行或银行 App 账单，它还让在 eBay 等网站上进行竞价成为可能。变量让编程世界（可以说）继续旋转运转。

好了，现在是时候更具体一点了。在用 `JAVA` 编程语言进行编程时，有不同类型的变量。如果程序员选择将你的名字存储在变量中，你的名字将被存储为一种名为 `String` 的变量类型。或者，程序员可能还想存储你的年龄——那将被存储为一种被称为 `Integer` 的变量类型。最后，也许程序员想存储你的年收入——你的收入将储存储为一种被称为 `Double` 的变量类型。简单回顾一下，这里涵盖了三种不同的变量：

* `String`
* `Integer`
* `Double`

那么，究竟是什么构成了 `String` 变量、`Integer` 变量和 `Double` 变量呢？在使用 `JAVA` 时，编程语言需要知道你将在特定变量中存储什么类型的信息。编程语言需要这一点，是因为 `JAVA` 是所谓的强类型语言。基本上，如果一种语言是弱类型的，意味着所有变量的类型在编译时是推断的或已知的。然而，强类型语言不允许将一种类型用作另一种类型，这意味着它利用了不同类型的变量。这就是字符串、整数和双精度变量用武之地。

## 字符串变量

`JAVA` 编程中的类型输入让编程语言确切知道存储变量中的信息将是具体定义的。当在 `JAVA` 中引用字符串（string）时，我们把数据看作仅仅是一个由英语单词组成的句子。`String` 特别表示按特定顺序排列的字母。与英语中一样，字符串变量构成一系列按特定顺序排列的字母，这赋予了字母序列非常特定的意义。

在字符串变量通过与日常语言比较而变得更易理解的情况下，将两个字符串相加的工作也非常相似。如果你有两个字符串变量并且存储了（例如）数据 `Visitor` 和 `Name`，如果将它们相加，你将得到字符串 `String`：`VisitorName`。

## 整数变量

在 `JAVA` 中，整数变量意味着你有一个不包含小数部分的数字。这意味着一个整数，如 `23` 或 `-784`。在 `Java` 中，当指定变量为整数时，不允许存储整数以外的任何内容。

例如，如果你想两个数字相加，数字 `35` 和数字 `5`。`Java` 的行为实际上非常不同，取决于用于存储这些数据的精确变量类型。然后将 `35` 和 `5` 相加将得到整数 `40`。而不是像字符串那样合并（当 `35` 和 `5` 在字符串中相加，你会得到 `355`），整数是进行数学相加。

## 双精度变量

`JAVA` 中的 double 变量将使用非常大的数字或非常小的数字。最小值和最大值分别是 `17` 和 `307` 个零。

double 变量还可以被用于包含被称为浮点（floating）的值。浮点值基本上是任何带有小数点的数值。

底线是，拥有类型将帮助你开始理解变量中所包含的信息可以做哪些。变量类型非常强大，并解释了特定组内什么是允许的，什么是不允许的。

## 数据结构在 JAVA 编程语言中的应用

计算机科学中的数据结构是在计算机中组织和存储信息的特定方法，以便能够以最高效的方式使用。为了更好地解释数据结构，让我们使用联系人列表的概念。通常，联系人列表包含许多联系人，可以随任何时间缩小或扩大。对于这个例子，假设我们需要按顺序保留五个联系人。如果你尝试在程序用变量表示这些联系人，你需要数据结构。

在这种情况下，你有一个联系人列表。在使用 `JAVA` 编程时，有一种名为列表（list）的数据结构。代码如下：


先不要担心这些符号，它们将在本书的第 5 章中介绍。你现在只需要知道，有一种方法可以将一个列表存储到数据结构中。在 `List` 数据结构中，你可以轻松地向列表中添加项也可以从列表中删除项。

## 控制结构在 JAVA 编程语言中的如何用法

控制结构是一段编程代码，它分析变量并根据给定的参数选择流。它是计算中做出决策的基本过程。流程控制调节了计算机在给定特定条件和特定参数时如何响应。这意味着当一个特定程序运行时，计算机会逐行读取代码。这个过程被称为“代码流”。当代码从上到下被读取时，可能会到达一个需要进行某种程度决策过程的点。这个决策可能导致代码跳转到特定程序的另一个部分，并可能需要重新运行某些代码，也可能只是作为响应跳过很多代码。这个过程可以等同于一本“选择自己的冒险”的小书。你读到书的第 12 页，你在选项 A 和选项 B 之间进行选择。计算机程序的工作方式非常相似，但程序有一组由程序员给出的严格规则需要遵守。程序做出的决策会影响代码流，这被称为控制结构。

## 语法在 JAVA 编程语言中的如何用法

JAVA 编程语言的语法其实就是一组规则，这些规则定义了符号的组合，这些组合在语言中被认为是结构精确的程序。语法基本上是符号的特定布局。在 JAVA 中，这的一个例子是花括号 `{ }` 或圆括号 `( )`。例如，当你看一个电子邮件地址时，你能够根据语法识别出它是电子邮件地址。你也可以将其识别为它的结构或仅仅通过“它的样子”。你能够识别电子邮件地址并与网站地址区分开来，是因为其中包含不同的语法。JAVA 编程语言中的语法也是类似的。那里有既定的规则，当遵循这些规则时，这些规则允许编程语言理解运行软件的功能，并允许你创建运行的软件。如果你不遵守编程语言特定语法的规则，将会收到错误。

在使用 JAVA 时，创建变量的语法有四个特定的步骤。如下：

1. 创建变量语法的第一部分是使用 `String` 单词，它是变量的类型。在特定情况下，`String` 允许存储普通字母以及存储特殊字符。
2. 创建变量语法的第二部分是使用变量名。变量名可以由数字和字母组成，但允许的唯一特殊字符是下划线。变量名的第一个字母通常是小写，这并不是必须的，但由于是 JAVA 编程世界中的一种经验法则。
3. 创建变量语法的第三部分是实现特定变量所持的值。在 JAVA 字符串中，通过在普通数字、字母和特殊字符周围加上引号来明确定义。
4. 创建变量语法的第四也是最后部分是实现完成标记。在 JAVA 中，使用分号。虽然有少数例外，但几乎所有的 JAVA 代码行都会以分号结尾；就像句子末的句号一样。

## 5. 使用 Java 获取用户输入意味着什么

## 6. 了解 Java 中的数学和算术运算符

- 为了执行减法，你只需要将代码第四行（或答案行）中的加号符号替换为减号符号：`answer = x - y;`
- 执行乘法时，`x` 不能用作乘法符号，因为 `x` 通常是一个变量；相反使用的是星号 `*`

- 除法稍微复杂一点——如果你用较小的数除以一个较大的数并且将变量声明为整数，答案将始终为零，因为整数不能是小数
- 同样，当你的变量声明为整数且你在不使用小数的情况下除以不能被较小数整除的较大数时，你也不会获得精确的数学答案——如果你尝试用 70 除以 30，你的答案将是 2，因为在答案为整数的情况下 30 可以进入 70 两次
- 为了在除法中获得准确的答案，你必须将变量声明为 `double`
- 使用除法时用正斜杠符号 `/` 替换其他符号

```java
int x = 10;
```

这个语句基本上是在说，如果 x 等于 10，那么我想运行这段代码。在这里，程序回答说是的，x 确实等于 10，这是真的。

- 这意味着语句被后续执行，条件也将执行执行
- 现在尝试通过仅在 if 行中放置数字 20 来查看 x 是否等于 20

### 如何在 Java 中利用逻辑运算符

- 如果你想使用简单的 `if` 语句或 `if else` 语句评估多个条件，你将需要使用逻辑运算符。
- 逻辑运算符有两种基本类型——`and`（与）运算符，其符号为双安培符 `&&`；第二种类型被称为 `or`（或）运算符，其符号为双竖线符号 `||`。
- `and` 运算符和 `or` 运算符都可以用于在 `if` 和 `if else` 语句中同时定义两个条件。
- `and` 运算符检查所有条件是否同时为真，而 `or` 运算符检查是否有一个或或多个条件为真。
- 放置在主体之间的符号告诉我们你正在使用哪一个，如下所示两个代码的第四行：

```java
int subject1 = 40;
int subject2 = 60;
// && -> AND || -> OR
if ((subject1 >= 35) && (subject2 >= 35)) {
    System.out.println("the condition is true");
}
```

这个条件为真，因为 40 和 60 都大于 35。

- 现在尝试将 `else` 语句与 `if` 语句结合，但首先将 `subject1` 的值改为 20：

```java
int subject1 = 20;
int subject2 = 60;
// && -> AND || -> OR
if ((subject1 >= 35) && (subject2 >= 35)) {
    System.out.println("the condition is true");
} else {
    System.out.println("the condition is false");
}
```

这个条件为假。

- 现在尝试运行相同的程序，但将 `and` 运算符替换为 `or` 运算符：

```java
int subject1 = 40;
int subject2 = 60;
// && -> AND || -> OR
if ((subject1 >= 35) || (subject2 >= 35)) {
    System.out.println("the condition is true");
} else {
    System.out.println("the condition is false");
}
```

这个条件为真。

## 在 Java 中使用 switch 语句

- 每当你需要在 `Java` 中检查多个条件时，你都会想要利用 `switch` 语句。
- 你也可以用 `switch` 语句代替 `if else` 语句。
- `switch` 语句中的 `break` 作用是中断你在运行程序时将收到的响应。
- `switch` 语句的一部分包括 `default` 的使用，它的作用类似于 `if else` 语句中的 `else`。



```java
int score = 90;
// byte, int, short, or char.
switch (score) {
    case 90 :
        System.out.println("Very good");
        break;
    case 60 :
        System.out.println("Good");
        break;
    case 30 :
        System.out.println("OK");
        break;
    default :
        System.out.println("Grades are not defined");
        break;
}
```

当整数值识别为 90 时，`case 90` 语句为真。

* 当 `case` 语句之间没有 `break` 时，在使用此类代码时，程序将默认顺序执行下一个。

## 在 JAVA 中使用 while 语句

* `while` 循环是 `JAVA` 中基础循环。
* 循环是一段代码或语句，它会反复执行某些代码块，直到满足某些条件。
* 如果你想反复执行某些代码而不必反复重写它们，这就是循环的用途：

```java
int a = 0;
while (a <= 10) {
    System.out.println(a);
    a++;
}
```

## 在 JAVA 中继续 do while 语句

* `while` 循环与 `do while` 循环的基本区别在于，尽管 `while` 循环首先评估条件然后执行代码，但 `do while` 循环先执行代码然后评估条件。
