## 多返回值

Go 允许函数返回多个值。此特性通常用于返回结果的同时返回一个错误值，以指示操作的成功或失败。

```go
package main

import "fmt"

func divide(a, b float64) (float64, error) {
	if b == 0 {
		return 0, fmt.Errorf("cannot divide by zero")
	}
	return a / b, nil
}

func main() {
	result, err := divide(10, 2)
	if err != nil {
		fmt.Println("Error:", err)
	} else {
		fmt.Println("Result:", result)
	}
}
```

变长函数允许你传递任意数量的参数。这在你预不知道会有多少个参数时非常有用。

```go
package main

	total := 0.0
	for _, num := range numbers {
		total += num
	}
	return total
}

func main() {
	avg := average(10.5, 20.0, 30.5)
	fmt.Println("Average:", avg)
}
```

### Go 中的方法

方法是与特定类型关联的函数。为了定义方法，你在函数名之前指定接收者。

```go
package main

import "fmt"

type Rectangle struct {
	Width  float64
	Height float64
}

func (r Rectangle) Area() float64 {
	return r.Width * r.Height
}

func main() {
	rect := Rectangle{Width: 10, Height: 5}
	fmt.Println("Rectangle Area:", rect.Area())
}
```

#### 指针接收者

除了值接收者，你还可以使用指针接收者来修改类型的值。当你需要在方法内部更新值时非常有用。

```go
package main

import "fmt"

type Counter struct {
	Value int
}

func (c *Counter) Increment() {
	c.Value++
}

func main() {
	counter := Counter{Value: 10}
	fmt.Println("Initial Value:", counter.Value)
	counter.Increment()
	fmt.Println("Updated Value:", counter.Value)
}
```

### 匿名函数和闭包

匿名函数（称为 Lambda 函数）是没有名称的函数。它们通常在内联定义函数时使用。

```go
package main

import "fmt"

func main() {
	add := func(a, b int) int {
		return a + b
	}
	result := add(3, 5)
	fmt.Println("Result:", result)
}
```

闭包是一个与匿名函数相关的强大概念。闭包“捕获”了它周围的作用域，即使在外部函数完成后仍然访问这些变量。

```go
package main

import "fmt"

func makeCounter() func() int {
	count := 0
	return func() int {
		count++
		return count
	}
}

func main() {
	counter := makeCounter()
	fmt.Println("Count:", counter())
	fmt.Println("Count:", counter())
	fmt.Println("Count:", counter())
}
```

### Defer, Panic 和 Recover

Go 提供了三个关键字来处理异常情况：`defer`、`panic` 和 `recover`。

- `defer` 语句用于调度在环境函数返回后执行的调用。
- `panic` 函数用于引起运行时错误并终止程序。
- `recover` 函数用于处理 panic 并恢复正常执行。

```go
package main

import "fmt"

func main() {
	defer func() {
		if r := recover(); r != nil {
			fmt.Println("Recovered from panic:", r)
		}
	}()

	defer fmt.Println("This will be executed last.")
	fmt.Println("Starting main function...")
	panic("Something went wrong!")
	fmt.Println("This will not be printed.")
}
```

### Go 中的指针

指针是存储另一个变量地址的变量。它们允许间接访问。

#### 声明和初始化指针

在 Go 中声明指针，使用 `*` 符号后跟变量类型。

```go
package main

import "fmt"

func main() {
	var num int = 42
	var ptr *int
	ptr = &num
	fmt.Println("Value:", num)
}
```

#### 解引用指针

解引用意味着访问它指向的值。你使用 `*` 符号解引用指针。

```go
package main

import "fmt"

func main() {
	var num int = 42
	var ptr *int
	ptr = &num
	fmt.Println("Value:", num)
	fmt.Println("Pointer:", ptr)
	fmt.Println("Dereenced Value:", *ptr)
}
```

### 向函数传递指针

向函数传递指针允许你在函数作用域外修改值。

```go
package main

import "fmt"

func modify(valPtr *int) {
	*valPtr = 100
}

func main() {
	var num int = 42
	fmt.Println("Before:", num)
	modify(&num)
	fmt.Println("After:", num)
}
```

### 内存泄漏与最佳实践

虽然 Go 的垃圾回收器有助于防止内存泄漏，但遵循最佳实践以确保高效使用内存仍然重要。

#### 切片重切（Slice Reslicing）

在调整切片大小时，原始数组仍被引用，导致内存无法被垃圾回收。

```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2, 3, 4, 5}
	slice := numbers[1:4]
	fmt.Println("Slice:", slice)
}
```

#### 使用 `copy`

要创建一个新的独立切片，请使用 `copy` 函数。

```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2, 3, 4, 5}
	slice := make([]int, 3)
	copy(slice, numbers[1:4])
	fmt.Println("Slice:", slice)
}
```
