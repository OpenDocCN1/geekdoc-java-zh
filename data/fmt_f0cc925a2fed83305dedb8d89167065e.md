## String 方法 `startsWith` 和 `endsWith`

接下来的示例（图 14.4）演示了 String 方法 `startsWith` 和 `endsWith`。`main` 方法创建一个包含 "started"、"starting"、"ended" 和 "ending" 的字符串数组。`main` 方法的其余部分由三个语句组成，用于测试数组中的元素，以确定它们是否以特定的字符集开头或结尾。

```java
// Fig. 14.4: StringStartEnd.java
// String methods startsWith and endsWith
public class StringStartEnd {
    public static void main(String[] args) {
        String[] strings = {"started", "starting", "ended", "ending"};

        // test method startsWith
        for (String string : strings) {
            if (string.startsWith("st"))
                System.out.printf("%s starts with \"st\"%n", string);
        }
        System.out.println();

        // test method startsWith starting from position 2 of string
        for (String string : strings) {
            if (string.startsWith("art", 2))
                System.out.printf("%s starts with \"art\" at position 2%n", string);
        }
        System.out.println();

        // test method endsWith
        for (String string : strings) {
            if (string.endsWith("ed"))
                System.out.printf("%s ends with \"ed\"%n", string);
        }
    }
} // end class StringStartEnd
```

```
"started" starts with "st"
"starting" starts with "st"
"started" starts with "art" at position 2
"starting" starts with "art" at position 2
"started" ends with "ed"
"ended" ends with "ed"
```

**图 14.4** String 方法 `startsWith` 和 `endsWith`。

行 11–15 使用了接收 String 参数的 `startsWith` 方法版本。`if` 语句中的条件（第 13 行）决定了数组中的每个字符串是否以字符 "st" 开头。如果是，该方法返回 `true`，应用程序打印该字符串。否则，该方法返回 `false`。

行 18–23 使用了接收 String 和整数参数的 `startsWith` 重载版本。整数指定了字符串中开始比较的索引。`if` 语句中的条件（第 22 行）决定了数组中的每个字符串是否从每个字符串的第三个字符开始包含字符 "art"。如果是，该方法返回 `true`，应用程序打印该字符串。

第三个 `for` 语句（第 30–34 行）使用了接收 String 参数的 `endsWith`。第 32 行的条件决定了数组中的每个字符串是否以字符 "ed" 结尾。如果是，该方法返回 `true`，应用程序打印该字符串。

## 14.3.4 在字符串中定位字符和子字符串

通常搜索一个字符或一组字符是非常有用的。例如，如果你正在创建一个文字处理器，你将希望提供一种搜索文档的能力。图 14.5 演示了 String 方法 `indexOf` 和 `lastIndexOf` 的多个版本用于在字符串中搜索字符或子字符串。

```java
// Fig. 14.5: StringIndexMethods.java
// searching methods indexOf and lastIndexOf
public class StringIndexMethods {
    public static void main(String[] args) {
        String letters = "abcdefghijklabcdefghijkl";

        // test indexOf to locate a character in a string
        System.out.printf("'c' is located at index %d%n", letters.indexOf('c'));
        System.out.printf("'a' is located at index %d%n", letters.indexOf('a'));
        System.out.printf("'$' is located at index %d%n", letters.indexOf('$'));

        // test indexOf to locate a substring in a string
        System.out.printf("'def' is located at index %d%n", letters.indexOf("def"));
        System.out.printf("'def' is located at index %d%n", letters.indexOf("def", 7));
        System.out.printf("'hello' is located at index %d%n", letters.indexOf("hello"));

        // test lastIndexOf to find a character in a string
        System.out.printf("Last 'c' is located at index %d%n", letters.lastIndexOf('c'));
        System.out.printf("Last 'a' is located at index %d%n", letters.lastIndexOf('a'));
        System.out.printf("Last '$' is located at index %d%n", letters.lastIndexOf('$'));

        // test lastIndexOf to locate a substring in a string
        System.out.printf("Last 'def' is located at index %d%n", letters.lastIndexOf("def"));
        System.out.printf("Last 'def' is located at index %d%n", letters.lastIndexOf("def", 7));
        System.out.printf("Last 'hello' is located at index %d%n", letters.lastIndexOf("hello"));
    }
}
```

```
'c' is located at index 2
'a' is located at index 0
'$' is located at index -1
'def' is located at index 3
'def' is located at index 15
'hello' is located at index -1
Last 'c' is located at index 14
Last 'a' is located at index 12
Last '$' is located at index -1
Last 'def' is located at index 15
Last 'def' is located at index 3
Last 'hello' is located at index -1
```

**图 14.5** 搜索方法 `indexOf` 和 `lastIndexOf`。

## 14.3.5 从字符串中提取子字符串

String 类有两个 `substring` 方法，通过复制现有字符串对象创建新的字符串对象。每个方法都返回一个新的字符串对象。两种方法都在图 14.6 中进行了演示。

```java
// Fig. 14.6: SubString.java
// String class substring methods.
public class SubString {
    public static void main(String[] args) {
        String letters = "abcdefghijklabcdefghijklm";

        // test substring methods
        System.out.printf("Substring from index 20 to end is %s%n", letters.substring(20));
        System.out.printf("%s%n", "Substring from index 3 up to, but not including 6 is " + letters.substring(3, 6));
    }
}
```

```
Substring from index 20 to end is hijklm
Substring from index 3 up to, but not including 6 is def
```

**图 14.6** String 类 `substring` 方法。

`substring(int beginIndex)` 方法返回一个从 `beginIndex` 开始到字符串结尾的新字符串。`substring(int beginIndex, int endIndex)` 方法返回一个从 `beginIndex` 开始到 `endIndex - 1` 结束的新字符串（即最后一个要复制的字符位于索引 `endIndex - 1` 处）。返回的子字符串包含原始 String 中指定字符的副本。索引超出字符串范围会导致抛出 `StringIndexOutOfBoundsException`。

## 14.3.6 字符串拼接

String 方法 `concat`（图 14.7）拼接两个 String 对象（类似于使用 `+` 运算符），并返回一个包含两个原始 String 中字符的新 String 对象。第 13 行的表达式 `s1.concat(s2)` 通过将 s2 中的字符追加到 s1 的字符之后形成一个字符串。s1 和 s2 所引用的原始对象不会被修改。

```java
// Fig. 14.7: StringConcatenation.java
// String method concat
public class StringConcatenation {
    public static void main(String[] args) {
        String s1 = "Happy ";
        String s2 = "Birthday";

        System.out.printf("s1 = %s%ns2 = %s%n", s1, s2);
        System.out.printf("Result of s1.concat(s2) = %s%n", s1.concat(s2));
        System.out.printf("s1 after concatenation = %s%n", s1);
    }
} // end class StringConcatenation
```

```
s1 = Happy
s2 = Birthday
Result of s1.concat(s2) = Happy Birthday
s1 after concatenation = Happy
```

**图 14.7** String 方法 `concat`。

## 14.3.7 杂项 String 方法

String 类提供了几个方法，可以返回原始 String 内容的 String 或字符数组副本，这些副本随后可以被修改。图 14.8 展示了这些方法——这些方法在调用时均不会修改原始字符串。

```java
// Fig. 14.8: StringMiscellaneous2.java
// String methods replace, toLowerCase, toUpperCase, trim and toCharArray
public class StringMiscellaneous2 {
    public static void main(String[] args) {
        String s1 = "hello";
        String s2 = "GOODBYE";
        String s3 = "  spaces  ";

        System.out.printf("s1=%s%ns2=%s%ns3=%s%n%n", s1, s2, s3);

        // test replace method
        System.out.printf("Replace 'l' with 'L' in s1: %s%n%n", s1.replace("l", "L"));

        // test toUpperCase/toLowerCase
        System.out.printf("s1.toUpperCase()=%s%n", s1.toUpperCase());
        System.out.printf("s2.toLowerCase()=%s%n%n", s2.toLowerCase());

        // test trim method
        System.out.printf("s3 after trim = %s%n%n", s3.trim());

        // test toCharArray method
        char[] charArray = s1.toCharArray();
        System.out.print("s1 as a character array = ");

        for (char character : charArray) {
            System.out.print(character);
        }
    }
} // end class StringMiscellaneous2
```

**图 14.8** String 方法 `replace`、`toLowerCase`、`toUpperCase`、`trim` 和 `toCharArray`。
