UML 在操作名后的括号内列出参数名，随后是冒号和参数类型。UML 拥有与 Java 类似的数据类型，但为了简单起见，我们将使用 Java 数据类型。`Account` 方法 `setName()`（图 3.1）有一个名为 `name` 的 `String` 参数，因此图 3.3 在方法名后的括号之间列出了 `name : String`。

## 3.2.5 关于 Account 类的额外说明

```java
static Method main
```

在第 2 章中，我们为每个类都声明了一个名为 `main()` 的方法。`main()` 是一个特殊的方法，它总是由你执行的 Java 虚拟机 (JVM) 自动调用。你必须显式调用其他方法来执行它们的任务。

图 3.2 的第 7–27 行声明了方法 `main()`。允许 JVM 定位并调用 `main()` 方法以启动程序的关键是 `static` 关键字（第 7 行），它表示 `main()` 是一个静态方法。静态方法是特殊的，因为你不需要创建类的对象就可以调用它。

### 关于 import 声明的说明

注意图 3.2 中的 import 声明（第 3 行），指示程序使用了 `Scanner`。正如你在第 2 章中学到的，`System` 和 `String` 类位于 `java.lang` 包中，该包被隐含导入到每个 Java 程序中，因此程序可以使用它们而无需显式导入。大多数其他类必须显式导入。如果在文件中通过 `java.util.Scanner` 引用类，则第 3 行的 import 声明是不需要的。例如，图 3.2 的第 10 行可以写为：

```java
java.util.Scanner input = new java.util.Scanner(System.in);
```

> **工程观察 3.1**：如果指定完全限定名，编译器不需要 import 声明。大多数程序员倾向于更简洁的编程风格。

## 3.2.6 私有实例变量和公共 set 及 get 方法的软件工程

正如你将看到的，使用 set 和 get 方法允许通过修改尝试来控制呈现给调用者的数据——这就是 setter 方法的好处。我们将在 3.5 节中详细讨论。

如果实例变量是公有的，类的任何客户端（即任何调用该类方法的类）都可以查看数据并对其进行任何操作，将其设置为无效值。

你可能认为，尽管类的客户端无法直接访问私有实例变量，但类可以通过公共的 set 和 get 方法对变量进行任何操作。你可能认为你可以通过公共 get 方法随时查看数据，并通过公共 set 方法随意修改私有数据。但方法可以被设计为对其参数进行验证，并拒绝任何将数据设置为坏值的尝试，例如负温度、3 月份超出 1 到 31 日范围的日期、不在公司产品目录中的产品代码等。而且，`getGrade()` 方法可以以不同的形式呈现数据。例如，`Grade` 类可能将成绩存储为 0 到 100 之间的 `int`，但 `getGrade()` 方法可以返回一个 `String` 类型的字母成绩等级，例如，对于 90–99 之间的分数返回 "A"，对于 80–89 之间的分数返回 "B" 等。严格控制数据的访问和呈现，私有数据（`private data`）可以极大减少错误，同时提高程序的健壮性和安全性。

使用访问修饰符 `private` 声明实例变量被称为数据隐藏或信息隐藏。当程序创建一个 `Account` 类的对象时，实例变量被封装（隐藏）在对象中，并且只能通过该对象类的方法进行访问。

> **软件工程观察 3.2**
>
> 在实例变量和方法声明之前加一个访问修饰符。通常情况下，实例变量应该声明为 `private`，而方法应该声明为 `public`。在书的后面章节，我们将讨论为什么你可能想要声明私有方法（`private method`）。

## 3.3 基本类型 vs. 引用类型

Java 的类型分为基本类型（`primitive types`）和引用类型（`reference types`）。在第 2 章中，你使用了 `int` 类型的变量——其他基本类型包括 `boolean`、`byte`、`char`、`short`、`long`、`float` 和 `double`，我们在书中会讨论每一种——汇总在附录 D 中。所有非基本类型都是引用类型，因此指定对象类型的类也是引用类型。

基本类型变量一次只能恰好持有其声明类型的一个值。例如，一个 `int` 变量一次可以存储一个整数。当将另一个值赋予该变量时，新值将替换旧值——而旧值将丢失。

记住，局部变量默认是不初始化的。基本类型实例变量默认初始化——`byte`、`char`、`short`、`int`、`long`、`float` 和 `double` 类型的实例变量初始化为 0，`boolean` 类型变量初始化为 `false`。你可以在声明变量时通过赋值来指定基本类型变量的初始值，如下：

```java
private int numberOfStudents = 10;
```

程序使用引用类型的变量（通常称为引用）来存储计算机内存中的对象地址。一个变量被认为引用程序中的对象。被引用的对象可能包含许多实例变量。图 3.2 的第 10 行：

```java
Scanner input = new Scanner(System.in);
```

创建了一个 `Scanner` 类的对象，并将变量 `input` 赋值该 `Scanner` 对象的引用。图 3.2 的第 13 行：

```java
Account myAccount = new Account();
```

创建了一个 `Account` 类的对象，并将变量 `myAccount` 赋值该 `Account` 对象的引用。引用类型的实例变量如果没有显式初始化，则默认初始化为值 `null`——它代表对“无”的“引用”。这就是为什么第 3.2 节第一次调用 `getName()` 返回了 `null`——`name` 的值尚未设置，因此返回了默认值 `null`。

要调用对象的方法，你需要该对象的引用。在图 3.2 中，`main()` 方法中的语句使用变量 `myAccount` 调用方法 `getName()`（第 16 和 26 行）和 `setName()`（第 21 行）来与 `Account` 对象交互。基本类型变量不引用对象，因此变量不能用于调用方法。

## 3.4 Account 类：使用构造函数初始化对象

如 3.2 节所述，当创建 `Account` 类的对象（图 3.1）时，`String` 实例变量 `name` 默认初始化为 `null`。但如果你想在创建 `Account` 对象时提供一个名称：

你声明的每个类都可以可选地提供一个带参数的构造函数，该构造函数可以在对象创建时用于初始化类的对象。Java 要求为每个创建的对象都调用一次构造函数，因此这是初始化对象实例变量的理想点。下一个示例通过构造函数增强了 `Account` 类（图 3.5），该构造函数可以接收一个名称并在对象创建时初始化其实例变量（图 3.6）。

### 3.4.1 为自定义初始化声明 Account 构造函数

当你的类声明它时，你可以提供一个构造函数来为你的类对象指定自定义初始化。例如，你可能在对象创建时为账户对象指定一个名称，如图 3.6 的第 10 行所示：

```java
Account account1 = new Account("Jane Green");
```

在这种情况下，字符串参数 "Jane Green" 被传递给 `Account` 对象的构造函数，并初始化实例变量 `name`。前面的语句要求类提供一个只接受一个 `String` 参数的构造函数。图 3.5 包含带有此类构造函数的修改后的 `Account` 类。

```java
// 图 3.5: Account.java
// 带有初始化 name 构造函数的 Account 类
public class Account {
    private String name; // 实例变量
    // 构造函数通过参数 name 初始化 name
    public Account(String name) { // 构造函数名与类名相同
        this.name = name;
    }
    // 设置 name 方法
    public void setName(String name) {
        this.name = name;
    }
    // 获取 name 方法
    public String getName() {
        return name;
    }
} // 结束类
```

#### 构造函数不能返回值

构造函数与方法的一个重要区别是构造函数不能返回类型（甚至不是 `void`）。通常，构造函数被声明为 `public`——在书后面我们将解释何时使用私有构造函数。

#### 默认构造函数

记得图 3.2 的第 13 行：

```java
Account myAccount = new Account();
```

使用 `new` 创建了一个 `Account` 对象。`new Account` 之后的空括号表示调用该类的默认构造函数——在任何没有显式声明构造函数的类中，编译器都会提供一个默认构造函数（无参数）。当类只有默认构造函数时，类的实例变量将初始化为它们的默认值。在第 8.5 节中，你将了解到类可以有多个构造函数。

#### 在声明了构造函数的类中没有默认构造函数

如果你为一个类声明了构造函数，编译器将不会为该类创建默认构造函数。在这种情况下，你将无法像图 3.2 中那样使用实例创建表达式 `new Account()` 来创建 `Account` 对象——除非你声明的自定义构造函数带有参数。

> **软件工程观察 3.3**
>
> 除非你的类实例变量初始化是可以接受的，否则请提供一个自定义构造函数，以确保在创建类的每个新对象时，实例变量都能用有意义的值正确初始化。

## 3.5 带有余额的 Account 类；浮点数

我们声明了一个 `Account` 类，它除了名称外，还维护银行账户的余额。大多数余额不是整数。因此，`Account` 类将账户余额表示为浮点数——一种带有小数点的数字，例如 43.95、0.0–129.8873。[在第 8 章中，我们将开始使用 `BigDecimal` 来精确地表示货币金额，正如你在编写工业级标准货币应用程序时应该做的那样]。

Java 提供了两种用于在内存中存储浮点数的类型——`float` 和 `double`。`float` 类型的变量表示单精度浮点数，可以存储最多七位有效数字。`double` 类型的变量表示双精度浮点数。它们占用的内存是 `float` 变量的两倍，可以存储多达 15 位有效数字——大约是 `float` 变量精度的两倍。

大多数程序员使用 `double` 类型表示浮点数。在 Java 中，Java 默认将你在源码中输入的所有浮点数（如 7.33 和 0.0975）都视为 `double`。源码中的此类值被称为浮点字面量。请参见附录 D“基本类型”，以获取 `float` 和 `double` 取值的精确范围。

### 3.5.1 带有类型为 double 的余额实例变量的 Account 类

我们的下一个程序包含一个 `Account` 类的版本（图 3.8），它维护了实例变量和银行账户的余额。典型的银行服务许多账户，每个账户都有自己的余额，因此它声明了一个类型为 `double` 的实例变量 `balance`。`Account` 类的每个实例（即对象）都包含 `name` 和 `balance` 的各自副本。

```java
// Fig. 3.8: Account.java
// 带有 double 实例变量 balance 的构造函数
// 以及执行验证的 deposit 方法的 Account 类
public class Account {
    private String name; // 实例变量
    private double balance; // 实例变量

    // 接收 double 参数的 Account 构造函数
    public Account(String name, double balance) {
        this.name = name; // 将 name 赋值给实例变量 name

        // 验证余额大于 0.0；如果不是，
        // 实例变量 balance 保留其默认初始值 0.0
        if (balance > 0.0) // 如果余额有效
            this.balance = balance; // 将其赋值给实例变量 balance
    }

    // deposit 方法仅向余额中存款（加上）有效金额
    public void deposit(double depositAmount) {
        if (depositAmount > 0.0) // 如果金额有效
            balance = balance + depositAmount; // 将其加到余额
    }

    // 返回余额的方法
    public double getBalance() {
        return balance;
    }

    // 设置名称的方法
    public void setName(String name) {
        this.name = name;
    }

    // 返回名称的方法
    public String getName() {
        return name;
    } // 类结束
}
```

#### deposit 方法

`deposit()` 方法仅向余额中存款（加上）有效金额。

#### getBalance 方法

`getBalance()` 方法返回余额。

#### setName 方法

`setName()` 方法设置名称。
