public class BasePlusCommissionEmployee {
    private String firstName;
    private String lastName;
    private String socialSecurityNumber;
    private double grossSales;
    private double commissionRate;
    private double baseSalary;

    // 六参数构造函数
    public BasePlusCommissionEmployee(String firstName, String lastName,

        double commissionRate, double baseSalary) {

        // 隐式调用 Object 的默认构造函数
        if (grossSales < 0.0) {
            throw new IllegalArgumentException("Gross sales must be >= 0.0");
        }
        if (commissionRate < 0.0 || commissionRate >= 1.0) {
            throw new IllegalArgumentException("Commission rate must be > 0.0 and < 1.0");
        }
        if (baseSalary < 0.0) {
            throw new IllegalArgumentException("Base salary must be >= 0.0");
        }

        this.firstName = firstName;
        this.lastName = lastName;
        this.socialSecurityNumber = socialSecurityNumber;
        this.grossSales = grossSales;
        this.commissionRate = commissionRate;
        this.baseSalary = baseSalary;
    }

    // 返回名

        return firstName;
    }

    // 返回姓
    public String getLastName() {
        return lastName;
    }

    // 返回社会安全号
    public String getSocialSecurityNumber() {
        return socialSecurityNumber;
    }

    // 设置总销售额
    public void setGrossSales(double grossSales) {
        if (grossSales < 0.0) {
            throw new IllegalArgumentException("Gross sales must be >= 0.0");
        }
        this.grossSales = grossSales;
    }

    // 返回总销售额
    public double getGrossSales() {
        return grossSales;
    }

    // 设置佣金率
    public void setCommissionRate(double commissionRate) {
        if (commissionRate < 0.0 || commissionRate >= 1.0) {
            throw new IllegalArgumentException("Commission rate must be > 0.0 and < 1.0");
        }
        this.commissionRate = commissionRate;
    }

    // 返回佣金率
    public double getCommissionRate() {
        return commissionRate;
    }

    // 设置基本工资
    public void setBaseSalary(double baseSalary) {
        if (baseSalary < 0.0) {
            throw new IllegalArgumentException("Base salary must be >= 0.0");

        this.baseSalary = baseSalary;
    }

    // 返回基本工资
    public double getBaseSalary() {
        return baseSalary;
    }

    public double earnings() {

        return String.format("%s: %s %s%n%s: %s%n%s: %.2f%n%s: %.2f%n%s: %.2f",

## 关于 BasePlusCommissionEmployee 类的说明

`BasePlusCommissionEmployee` 类中的大部分代码与 `CommissionEmployee` 类相似或相同。例如，私有实例变量 `firstName` 以及方法 `setFirstName`、`getFirstName`、`setLastName` 和 `getLastName` 与 `CommissionEmployee` 中的完全相同。这些类还包含实例变量 `socialSecurityNumber`、`grossSales`、`commissionRate` 以及相应的 get 和 set 方法。此外，`BasePlusCommissionEmployee` 的构造函数几乎与 `CommissionEmployee` 的完全相同，区别在于 `BasePlusCommissionEmployee` 的构造函数还设置了 `baseSalary`。`BasePlusCommissionEmployee` 类的其他新增内容是私有实例变量 `baseSalary` 以及方法 `setBaseSalary` 和 `getBaseSalary`。`BasePlusCommissionEmployee` 的 `toString` 方法也与 `CommissionEmployee` 的方法几乎相同，区别在于它输出实例变量 `baseSalary` 时在小数点后保留两位数字。

> 我们直接从 `CommissionEmployee` 复制代码并将其粘贴到 `BasePlusCommissionEmployee` 类中，然后修改 `BasePlusCommissionEmployee` 类以包含基本工资以及处理基本工资的方法。这种“复制-粘贴”的方法往往容易出错且耗费精力。更糟糕的是，它在整个系统中散布了相同的代码，导致了维护问题——这些代码需要在多个类中存在。是否有一种方法可以“获取”一个类的实例变量和方法，并使其成为其他类的一部分，而无需重复代码？接下来我们将使用更优雅的类构建方法来回答这个问题，这种方法强调了继承的好处。

## 软件工程观察 9.3

通过继承，层次结构中所有类共有的实例变量和方法被声明在超类中。对超类中这些功能所做的更改将由子类继承。如果没有继承，则需要对包含相关代码副本的所有源文件进行修改。

## 9.4.3 创建 CommissionEmployee 到 BasePlusCommissionEmployee 的继承层次结构

现在我们声明 `BasePlusCommissionEmployee`（图 9.8）继承类 `CommissionEmployee`。一个 `BasePlusCommissionEmployee` 对象是一个 `CommissionEmployee`，因为继承传递了 `CommissionEmployee` 类的能力。`BasePlusCommissionEmployee` 类还拥有实例变量 `baseSalary`（图 9.8，第 6 行）。`extends` 关键字（第 4 行）表示继承。`BasePlusCommissionEmployee` 继承了 `CommissionEmployee` 的实例变量和方法。

## 软件工程观察 9.4

在面向对象系统的设计阶段，你经常会发现某些类之间关系紧密。你应该“提取”公共实例变量并将它们放在超类中。然后使用继承来开发子类，通过继承自超类的能力使其特异化。

## 软件工程观察 9.5

声明子类不会影响其超类的源代码。继承保持了超类的完整性。

只有 `CommissionEmployee` 的公共和受保护成员在子类中可以直接访问。`CommissionEmployee` 的构造函数不被继承。因此，公有的 `BasePlusCommissionEmployee` 服务包含了构造函数（第 9–23 行）、从 `CommissionEmployee` 继承的公共方法，以及方法 `setBaseSalary`（第 26–33 行）、`earnings`（第 42–47 行）和 `toString`（第 50–60 行）。`earnings` 和 `toString` 方法重写了 `CommissionEmployee` 类中的方法，因为它们的子类版本分别无法正确地计算 `BasePlusCommissionEmployee` 的收入，或无法返回合适的 `String` 字符串表示。

```java
// Fig 9.8: BasePlusCommissionEmployee.java
// 子类无法访问超类的私有成员。

public class BasePlusCommissionEmployee extends CommissionEmployee {
    private double baseSalary; // base salary per week

    // 六参数构造函数
    public BasePlusCommissionEmployee(String firstName, String lastName,
        String socialSecurityNumber, double grossSales,
        double commissionRate, double baseSalary) {

        // 显式调用超类 CommissionEmployee 构造函数
        super(firstName, lastName, socialSecurityNumber,
            grossSales, commissionRate);

        // 如果 baseSalary 无效则抛出异常
        if (baseSalary < 0.0) {
            throw new IllegalArgumentException("Base salary must be >= 0.0");
        }
        this.baseSalary = baseSalary;
    }

    // set baseSalary
    public void setBaseSalary(double baseSalary) {
        if (baseSalary < 0.0) {
            throw new IllegalArgumentException("Base salary must be >= 0.0");
        }
        this.baseSalary = baseSalary;
    }

    // return baseSalary
    public double getBaseSalary() {
        return baseSalary;
    }

    // calculate earnings
    @Override
    public double earnings() {
        return getBaseSalary() + (getCommissionRate() * getGrossSales());
    }

    // return String representation
    @Override
    public String toString() {
        return String.format("%s %s, %s: %s%n%s: %.2f%n%s: %.2f%n%s: %.2f",
            "base-salaried employee", getFirstName(), getLastName(),
            "social security number", getSocialSecurityNumber(),
            "gross sales", getGrossSales(),
            "commission rate", getCommissionRate(),
            "base salary", getBaseSalary());
    }
}
```
