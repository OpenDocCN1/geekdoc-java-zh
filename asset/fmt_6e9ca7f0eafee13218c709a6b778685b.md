public class DesktopFrame extends JFrame {

    private final JDesktopPane theDesktop;
    public DesktopFrame() {
        super("Using a JDesktopPane");
        JMenuBar menuBar = new JMenuBar();
        JMenu addMenu = new JMenu("Add");
        JMenuItem newFrame = new JMenuItem("Internal Frame");
        addMenu.add(newFrame); // 向菜单添加新项
        menuBar.add(addMenu); // 将菜单加入菜单栏

            @Override

                JInternalFrame frame = new JInternalFrame("New Frame", true, true, true);
                frame.setSize(new Dimension(200, 200));
                theDesktop.add(frame);
                frame.setVisible(true);
            }
        });

        setDefaultCloseOperation(EXIT_ON_CLOSE);
        setSize(400, 220);
        setVisible(true);
    }

        new DesktopFrame();

## 22.8 JTabbedPane

`JTabbedPane` 将 GUI 组件排列成层，一次只显示一个层。用户通过标签（tab）访问每个层——类似于文件柜中的文件夹。当用户点击标签时，相应的层会被显示。标签默认情况下位于顶部，也可以位于左侧、右侧或底部。任何组件都可以放在标签上。`JTabbedPane` 是 `JComponent` 的子类。应用程序在图 22.13–24 中创建一个带有三个标签的标签面板，`panel1` 或 `panel2`。
