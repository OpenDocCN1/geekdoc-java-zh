## 指定布局

在构建 GUI 时，你必须将每个 GUI 组件附加到容器上，例如使用 `JFrame` 创建的窗口。此外，你还必须决定每个组件的位置——即指定布局。Java 提供了几种布局管理器，它们可以帮助你定位组件，你将在本章的后半部分以及第 22 章中学习到这些内容。

许多 IDE 提供了 GUI 设计工具，你可以在可视化管理器中使用鼠标指定组件精确的大小和位置；然后 IDE 将为你生成 GUI 代码。这些 IDE 可以极大地简化 GUI 开发。

为了确保我们的 GUI 可以在任何 IDE 中运行，我们没有使用 IDE 来创建 GUI 代码。我们使用了 Java 的 `FlowLayout` 管理器，组件按照创建的顺序从左到右放置在容器中。当当前行无法再容纳更多组件时，它们将继续在下一行从左到右显示。如果调整了容器的大小，它有一个默认布局，我们将 `LabelFrame` 的布局更改为 `FlowLayout`（第 20 行）。`setLayout` 方法直接从 `Container` 类继承自 `Frame` 类。该方法的参数必须是实现 `LayoutManager` 接口的类对象（例如 `FlowLayout`）。第 20 行创建了一个新的 `FlowLayout` 对象并将其引用作为参数传递给 `setLayout`。

## Icon 接口和 ImageIcon 类

图标是调用应用程序外观的一种流行方式，也常用于指示功能。例如，同一个图标被用于 DVD 播放器和 MP3 播放器等设备播放当今大多数媒体。Swing 组件可以显示图像。图标通常通过向构造函数或 `setIcon` 方法传递 `Icon`（包 `javax.swing`）参数来指定。`ImageIcon` 类支持多种图像格式，包括图形交换格式（GIF）、便携网络图形（PNG）和联合图像专家组（JPEG）。

第 28 行声明了一个 `ImageIcon`。文件 `bug1.png` 包含要加载并存储在 `ImageIcon` 对象中的图像。该图像包含在此示例的目录中。`ImageIcon` 对象被赋值给 `Icon` 引用。

## 加载图像资源

第 28 行的 `getClass().getResource("bug1.png")` 调用了 `getClass` 方法（间接继承自 `Object`）以获取代表 `LabelFrame` 类的类对象的引用。该引用被用于调用 `getResource` 方法，该方法将图像的位置作为 URL 返回。`ImageIcon` 的构造函数使用该 URL 加载图像，然后将其加载到内存中。正如我们在第 1 章中讨论过的一样，JVM 使用类加载器将类加载到内存中。类加载器知道每个类在磁盘上的加载位置。`getResource` 使用类的类加载器来确定资源（如图像文件）的位置。在本例中，图像文件存储在与 `LabelFrame.class` 文件相同的位置。这里描述的技巧允许应用程序从相对于类位置的文件加载图像。

# 12.6 文本字段与嵌套类事件处理简介

当用户在 `JTextField` 或 `JPasswordField` 中输入并按下回车键时，就会发生一个事件。我们的下一个示例将演示程序如何响应该事件执行任务。这里展示的技术适用于所有产生事件的 GUI 组件。

图 12.9–10 应用使用了 `JTextField` 和 `JPasswordField` 类来创建和操作文本字段。当用户在其中一个文本字段中输入内容时，应用程序创建一个包含用户输入内容的消息对话框。你只能在文本字段“获得焦点”时进行输入。当你点击它时，它就会接收焦点。这是因为获得焦点的文本字段是会在你按下回车键时产生事件的那个。在这个示例中，当你在 `JPasswordField` 中按下回车键时，密码将会显示。我们首先讨论 GUI 的设置，然后是事件处理程序代码。

```java
// 图 12.9: JTextFieldFrame.java
// JTextField 和 JPasswordField

import java.awt.FlowLayout;
import java.awt.event.ActionListener;
import java.awt.event.ActionEvent;
import javax.swing.JFrame;
import javax.swing.JTextField;
import javax.swing.JPasswordField;
import javax.swing.JOptionPane;

public class JTextFieldFrame extends JFrame {

    private JTextField textField1; // 设置了大小的文本字段
    private JTextField textField2; // 有文本的文本字段
    private JTextField textField3; // 有文本和大小的文本字段
    private JPasswordField passwordField; // 密码字段

    public JTextFieldFrame() {
        super("JTextField and JPasswordField");
        setLayout(new FlowLayout());

        // 10列的文本字段
        textField1 = new JTextField(10);
        add(textField1); // 将 textField1 添加到 JFrame

        // 有默认文本的文本字段
        textField2 = new JTextField("Enter text here");
        add(textField2); // 将 textField2 添加到 JFrame

        // 有默认文本和 21 列的文本字段
        textField3 = new JTextField("Editable text field", 21);
        textField3.setEditable(false); // 禁止编辑
        add(textField3); // 将 textField3 添加到 JFrame

        // 构建带有默认文本的密码字段
        passwordField = new JPasswordField("Hidden text");
        add(passwordField); // 将 passwordField 添加到 JFrame

        // 注册事件处理器
        JTextFieldHandler handler = new JTextFieldHandler();
        textField1.addActionListener(handler);
        textField2.addActionListener(handler);
        textField3.addActionListener(handler);
        passwordField.addActionListener(handler);
    }

    // 用于事件处理的私有内部类
    private class JTextFieldHandler implements ActionListener {
        // 处理字段事件
        @Override
        public void actionPerformed(ActionEvent event) {
            String string = "";

            // 用户在 JTextField textField1 中按了回车
            if (event.getSource() == textField1) {
                string = String.format("textField1: %s", event.getActionCommand());
            }
            // 用户在 JTextField textField2 中按了回车
            else if (event.getSource() == textField2) {
                string = String.format("textField2: %s", event.getActionCommand());
            }
            // 用户在 JTextField textField3 中按了回车
            else if (event.getSource() == textField3) {
                string = String.format("textField3: %s", event.getActionCommand());
            }
            // 用户在 JPasswordField passwordField 中按了回车
            else if (event.getSource() == passwordField) {
                string = String.format("passwordField: %s", event.getActionCommand());
            }

            // 显示 JTextField 内容
            JOptionPane.showMessageDialog(null, string);
        }
    } // 结束私有内部类 JTextFieldHandler
} // 结束类 JTextFieldFrame
```
