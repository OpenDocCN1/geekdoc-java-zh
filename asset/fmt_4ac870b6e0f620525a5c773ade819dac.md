
## 20.8 接受类型参数的方法中的通配符

在本节中，我们引入了关于通配符的泛型概念。让我们来看一个激发通配符的示例。假设你想实现一个泛型方法来计算 `ArrayList` 中数字的总和。你首先会将数字插入集合中。由于泛型类只能与接口类型一起使用，数字将被自动装箱为类型包装类的对象。例如，任何 `int` 值都会被自动装箱为 `Integer` 对象，任何 `double` 值都会被自动装箱为 `Double` 对象。无论类型如何，我们都能计算 `ArrayList` 中所有数字的总和。出于此原因，我们使用类型参数 `Number` 来声明 `ArrayList`，它是 `Integer` 和 `Double` 的父类。此外，图 20.13 展示了对 `Number` 类型 `ArrayList` 元素的求和。

```java
// Fig. 20.13: TotalNumbers.java
// 计算 ArrayList<Number> 中数字的总和
import java.util.ArrayList;

public class TotalNumbers {
    public static void main(String[] args) {
        // 创建、初始化并输出包含
        // Integer 和 Double 的 Numbers 数组，然后显示元素总和
        Number[] numbers = {1, 2.4, 3, 4.1}; // Integers and Doubles
        ArrayList<Number> numberList = new ArrayList<>();

        for (Number number : numbers)
            numberList.add(number); // 将每个数字放入 numberList

        System.out.printf("numberList contains: %s%n", numberList);
        System.out.printf("Total of the elements in numberList: %.1f%n", sum(numberList));
    }

    // 计算 ArrayList 元素的总和
    public static double sum(ArrayList<Number> list) {
        double total = 0;
        for (Number element : list)
            total += element.doubleValue();
        return total;
    }
}
```

Total of the elements in numberList: 10.5

第 11 行声明并初始化了一个 `Number` 数组。由于初始化器是原始值，Java 将每个原始值自动装箱为相应的包装类型对象。`int` 值 1 和 3 被自动装箱为 `Integer` 对象，而 `double` 值 2.4 和 4.1 被自动装箱为 `Double` 对象。第 12 行声明并创建了一个存储 `Number` 的 `ArrayList` 对象并将其赋值给变量 `numberList`。第 14–15 行将每个数字放入 `numberList`。第 17 行输出 `ArrayList` 的内容。该语句隐式调用了 `toString()` 方法，该方法返回一个逗号分隔的字符串。第 18–19 行显示元素总和。第 23–32 行计算元素总和。`for` 循环使用 `doubleValue()` 获取总和。循环结束，方法返回总和。

### 在参数中使用通配符参数实现 sum

回想图 20.13 中 `sum` 方法的目的是计算 `Number` `ArrayList` 的总和。然而，如果我们想让 `sum` 方法更具通用性，使其能够接受 `Number` 的任何子类的 `ArrayList`（例如 `ArrayList<Integer>` 或 `ArrayList<Double>`），我们将使用通配符。通配符用问号 (`?`) 表示。使用 `extends` 关键字表示通配符有一个 `Number` 的上界。例如，`ArrayList<? extends Number>` 意味着 `ArrayList` 可以包含 `Number` 或 `Number` 的任何子类。这使得 `sum` 方法更加灵活，并处理不同类型的 `ArrayList`。

```java
// Fig. 20.14: WildcardTest.java
// 使用通配符计算 ArrayList 元素的总和
import java.util.ArrayList;

public class WildcardTest {
    public static void main(String[] args) {
        // 创建、初始化并输出 ArrayList<Integer>
        ArrayList<Integer> integerList = new ArrayList<>();
        integerList.add(1);
        integerList.add(2);
        integerList.add(3);
        integerList.add(4);
        integerList.add(5);
        System.out.printf("integerList contains: %s%n", integerList);
        System.out.printf("Total of the elements in integerList: %.1f%n%n", sum(integerList));

        // 创建、初始化并输出 ArrayList<Double>
        ArrayList<Double> doubleList = new ArrayList<>();
        doubleList.add(1.1);
        doubleList.add(3.3);
        doubleList.add(5.5);
        System.out.printf("doubleList contains: %s%n", doubleList);
        System.out.printf("Total of the elements in doubleList: %.1f%n%n", sum(doubleList));

        // 创建、初始化并输出 ArrayList<Number>，包含 Integer 和 Double
        ArrayList<Number> numberList = new ArrayList<>();
        numberList.add(1);
        numberList.add(2.4);
        numberList.add(3);
        numberList.add(4.1);
        System.out.printf("numberList contains: %s%n", numberList);
        System.out.printf("Total of the elements in numberList: %.1f%n", sum(numberList));
    }

    // 使用通配符计算 ArrayList 元素的总和
    public static double sum(ArrayList<? extends Number> list) {
        double total = 0;
        for (Number element : list)
            total += element.doubleValue();
        return total;
    }
}
```

integerList 包含: [1, 2, 3, 4, 5]

integerList 中元素的总和: 15.0

doubleList 包含: [1.1, 3.3, 5.5]

doubleList 中元素的总和: 9.9

numberList 包含: [1, 2.4, 3, 4.1]

numberList 中元素的总和: 10.5

**图 20.14** 通配符测试程序。

第 11–20 行创建并初始化了一个 `ArrayList<Integer>`，输出其元素并通过调用 `sum`（第 20 行）来收集它们。第 24–33 行对 `ArrayList<Double>` 执行相同的操作。第 37–44 行对包含 `Integer` 和 `Double` 的 `ArrayList<Number>` 执行相同的操作。

在 `sum` 方法（第 50–59 行）中，`ArrayList` 参数的元素类型已知至少是 `Number`，因为指定通配符时指定了上界 `Number`。因此，第 56 行是允许的，因为所有 `Number` 对象都拥有 `doubleValue()` 方法。

尽管通配符在向方法传递参数化类型时提供了灵活性，但它们也有一些缺点。方法头（第 50 行）中的通配符 (`?`) 并没有指定类型参数名称，你不能在整个方法体中使用它作为名称（即你不能在第 55 行中将 `Number` 替换为 `T`）。然而，你可以将 `sum` 声明为：

```java
public static <T extends Number> double sum(ArrayList<T> list)
```

这允许方法接收一个包含任何 `Number` 子类元素的 `ArrayList`。然后你可以在整个方法体中使用类型 `T`。

如果在指定通配符时没有指定上界，则只能在通配符类型的值上调用 `Object` 类型的方法。此外，在参数类型参数中使用通配符的方法不能用于向参数所引用的集合添加元素。

> **常见编程错误 20.3**
> 在方法的类型参数部分中使用通配符，或在方法体中使用通配符作为变量的显式类型是语法错误。

## 总结

### 第 20.1 节 引言

- 泛型方法允许你通过一个方法声明指定一组相关的方法。
- 泛型类和接口允许你指定一组相关类型。

### 第 20.2 节 泛型方法的动机

- 重载方法通常用于对不同类型的数据执行操作。
- 当编译器遇到方法调用时，它会尝试找到一个名称和参数与方法调用中的参数类型相匹配的方法声明。

### 第 20.3 节 泛型方法：实现与编译时翻译

- 如果多个重载方法执行的操作对于每个参数类型都是相同的，则可以使用泛型方法对其进行更紧凑、更方便的编码。一个泛型方法声明可以使用不同类型的数据调用。根据传递给泛型方法的参数，编译器会妥善地处理每个方法。
- 所有的泛型声明都有一个类型参数部分，用尖括号 (`<` 和 `>`) 隔开，用于指定方法的返回类型。
- 类型参数部分包含一个或多个由逗号分隔的参数。
- 类型参数是指定泛型类型的标识符。类型参数可以作为泛型方法声明中的返回类型、参数类型和局部变量，并作为传递给泛型方法的类型的占位符，这些类型被称为实际类型。类型参数仅表示引用类型。
- 在整个泛型声明中使用的类型参数名称必须与类型参数部分声明的匹配。类型参数名称只能在类型参数部分声明一次，但可以在方法的参数列表中出现多次。
- 当编译器遇到方法调用时，它确定参数类型并尝试找到具有相同名称和参数且匹配参数类型的方法。如果没有这样的方法，编译器将搜索具有相同名称、兼容参数并匹配的泛型方法。
- 实现泛型接口 `Comparable` 的类对象可以通过 `compareTo` 方法进行比较，如果对象相等，则返回 0；如果第一个对象小于第二个对象，则返回负整数；如果第一个对象大于第二个对象，则返回正整数。
- 所有的包装类都实现了 `Comparable`。

### 第 20.4 节 额外的编译翻译：使用参数作为返回类型的方法

- 当泛型方法编译时，编译器执行擦除，将类型参数替换为上界，除非另有指定。
- 当对返回类型的方法执行擦除时，会在方法调用前插入强制转换，以确保返回值具有预期的类型。

### 第 20.5 节 泛型方法的重载

- 泛型方法可以与泛型方法或非泛型方法重载。

### 第 20.6 节 泛型类

- 泛型类提供了一种以类型无关的方式描述类的方法。我们可以实例化特定的类型。
- 泛型类的声明看起来像类声明，只是类名后面跟着类型参数。泛型类的类型参数部分可以有一个或多个由逗号分隔的参数。
- 当泛型类编译时，编译器对类型参数执行擦除。
- 类型参数不能用于类的静态声明。
- 在实例化泛型类对象时，类名尖括号中指定的类型被称为类型实参。编译器使用这些来替换类型参数，以便执行类型检查并插入转换操作。

### 第 20.7 节 原始类型

- 可以在不指定类型参数的情况下实例化泛型类。在这种情况下，类对象被称为具有原始类型——编译器在泛型类的范围内隐式地使用 `Object`（或类型参数的上界）。

### 第 20.8 节 接受类型参数的方法中的通配符

- `Number` 类是 `Integer` 和 `Double` 的父类。
- `doubleValue` 方法使用原始双精度值获取 `Number` 的值。
- 通配符参数允许你指定方法参数、返回值、变量，因此它们作为参数化类型的类型。通配符参数用 `?` 表示，表示一个“未知类型”。通配符也可以有一个上界。
- 由于通配符不是类型参数名称，你不能在整个方法体中使用它作为类型名称。

### 21.2 自引用类

自引用类包含一个指向相同类类型的另一个对象的实例变量。例如，泛型 `Node<T>` 类声明：

```java
class Node<T> {
    private T data;
    private Node<T> nextNode; // 指向下一个链节点的引用

    public Node(T data) { /* 构造函数体 */ }
    public void setData(T data) { /* 方法体 */ }
    public T getData() { /* 方法体 */ }
    public void setNext(Node<T> next) { /* 方法体 */ }
    public Node<T> getNext() { /* 方法体 */ }
}
```

该类有两个实例变量——`data`（泛型类型 `T`）和 `Node<T>` 变量 `nextNode`。变量 `nextNode` 引用一个 `Node<T>` 对象，即声明的同类对象——这里被称为“自引用类”。字段 `nextNode` 是一个链接——它“链接”一个类型为 `Node<T>` 的对象到另一个相同类型的对象。类 `Node<T>` 还有五个方法：一个接收值以初始化 `data` 的构造函数，一个设置 `data` 值的 `setData` 方法，一个返回 `data` 值的 `getData` 方法，一个设置下一个引用的 `setNext` 方法，以及一个返回下一个引用的 `getNext` 方法。
