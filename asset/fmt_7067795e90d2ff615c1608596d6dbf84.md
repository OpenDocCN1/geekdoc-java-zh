## 21.6 队列

另一种常用的数据结构是队列。队列类似于超市的结银台——收银员首先服务队头的人。其他客户从队尾进入队列并等待服务。队列节点仅从队列的头部（前端）移除，并仅从尾部（末端）插入。因此，队列是一种先进先出（FIFO）的数据结构。插入和删除操作分别称为入队（enqueue）和出队（dequeue）。

队列在计算机系统中有许多用途。计算机中的每个 CPU 每次只能服务于一个应用程序。每个需要处理时间的应用程序都被放置在队列中。队列队头的应用程序是下一个接收服务的程序。随着前面的应用程序接收到服务，每个应用程序逐渐移动到队首。

队列还用于支持打印池化（print spooling），单台打印机可能由网络的所有用户共享。许多用户可以向打印机发送任务，即使打印机已经处于忙状态。这些打印任务会被放置在队列中，直到打印机可用。一个称为打印器（spooler）的程序管理队列，以确保每个打印任务完成后，下一个任务会被发送到打印机。

计算机网络中的数据包在队列中等待。每当数据包到达节点时，它必须沿着通往最终目的路径路由到下一个节点。路由过程一次处理一个数据包，因此额外的数据包会被入队，直到路由器可以对它们进行路由。

计算机网络中的文件服务器处理来自网络许多客户端的文件访问请求。服务器处理客户端请求的能力是有限的。当超过容量时，客户端在队列中等待。

图 21.13 创建了一个包含 `List<T>`（图 21.3）对象的 `Queue<T>`，并提供了 `enqueue`、`dequeue`、`isEmpty` 方法，而该 `List<T>` 包含了一些方法（例如 `insertAtFront` 和 `removeBack`），我们更希望通过 `Queue<T>` 的公共接口访问这些方法。使用组合使我们能够从类 `Queue<T>` 中隐藏 `List<T>` 的其他公共方法。每个 `Queue<T>` 可以调用合适的 `List<T>` 方法——`enqueue` 调用 `List<T>` 的 `insertAtBack` 方法，`dequeue` 调用 `List<T>` 的 `removeFront` 方法，`isEmpty` 和 `front` 方法调用 `List<T>` 的 `print` 方法。为了复用，`Queue<T>` 声明在包 `com.deitel.datastructures` 中。

## 21.7 树

```java
// TreeNode 类定义
class TreeNode<T extends Comparable<T>> {
    // 包访问成员
    TreeNode<T> leftNode;
    T data; // 节点值
    TreeNode<T> rightNode;

    // 构造函数初始化数据并使其叶子节点
    public TreeNode(T nodeData) {
        data = nodeData;
        leftNode = rightNode = null; // 节点没有孩子
    }

    // 定位插入点并插入新节点；忽略重复值
    public void insert(T insertValue) {
        // 插入左子树
        if (insertValue.compareTo(data) < 0) {
            // 插入 TreeNode
            if (leftNode == null)
                leftNode = new TreeNode<T>(insertValue);
            else // 继续递归遍历左子树
                leftNode.insert(insertValue);
        }
        // 插入右子树
        else if (insertValue.compareTo(data) > 0) {
            // 插入 TreeNode
            if (rightNode == null)
                rightNode = new TreeNode<T>(insertValue);
            else // 继续递归遍历右子树
                rightNode.insert(insertValue);
        }
    }
} // TreeNode 类结束

// Tree 类定义
public class Tree<T extends Comparable<T>> {
    private TreeNode<T> root;

    // 构造函数初始化一个空的整数树
    public Tree() {
        root = null;
    }

    // 在二叉搜索树中插入新节点
    public void insertNode(T insertValue) {
        if (root == null)
            root = new TreeNode<T>(insertValue); // 创建根节点
        else
            root.insert(insertValue); // 调用 insert 方法
    }

    // 开始前序遍历
    public void preorderTraversal() {
        preorderHelper(root);
    }

    // 执行前序遍历的递归方法
    private void preorderHelper(TreeNode<T> node) {
        if (node == null) return;
        System.out.printf("%s ", node.data); // 输出节点数据
        preorderHelper(node.leftNode); // 遍历左子树
        preorderHelper(node.rightNode); // 遍历右子树
    }

    // 开始中序遍历
    public void inorderTraversal() {
        inorderHelper(root);
    }

    // 执行中序遍历的递归方法
    private void inorderHelper(TreeNode<T> node) {
        if (node == null) return;
        inorderHelper(node.leftNode);
        System.out.printf("%s ", node.data); // 输出节点数据
        inorderHelper(node.rightNode); // 遍历右子树
    }

    // 开始后序遍历
    public void postorderTraversal() {
        postorderHelper(root);
    }

    // 执行后序遍历的递归方法
    private void postorderHelper(TreeNode<T> node) {
        if (node == null) return;
        postorderHelper(node.leftNode);
        postorderHelper(node.rightNode);
        System.out.printf("%s ", node.data); // 输出节点数据
    }
} // Tree 类结束
```

### Tree 类概览

`Tree` 类（图 21.17）要求其类型参数实现 `Comparable` 接口，因此插入到树中的每个值都会与现有值进行比较，以找到插入点。该类有一个私有字段 `root`（第 47 行）——一个指向树根的 `TreeNode<T>` 引用。`Tree` 的构造函数（第 50–53 行）将 `root` 初始化为 `null`，表示该树为空。该类包含 `insertNode` 方法（第 56–62 行）用于在树中插入新节点，以及 `preorderTraversal`（第 65–68 行）、`inorderTraversal`（第 82–85 行）和 `postorderTraversal`（第 99–102 行）用于开始树的遍历。这些方法每个都调用一个递归辅助方法，在树的内部表示上执行遍历操作。

### Tree 方法 insertNode

`Tree` 类的 `insertNode` 方法（第 56–62 行）首先确定树是否为空。如果是，第 59 行初始化一个新的 `TreeNode`，其值为要插入树的值，并将新引用赋值给 `root`。如果树不为空，则第 61 行调用 `TreeNode` 的 `insert` 方法（第 21–41 行）。该方法使用递归来确定新节点在树中的位置并将其插入该位置。在二叉搜索树中，节点只能作为叶子节点插入。

### TreeNode 方法 insert

`TreeNode` 的 `insert` 方法将值与根节点进行比较。如果值小于根节点（第 24 行），则递归处理左子树（第 27 行）。如果值大于根节点（第 33 行），则递归处理右子树（第 36 行）。如果右子树为空，则第 37 行初始化一个新的 `TreeNode`，并将新引用赋值给右侧（第 38 行）。如果右子树不为空，则第 39 行递归处理右子树。
