## 8.2 Time 类案例研究

我们的第一个示例是两个类——`Time1`（图 8.1）和 `Time1Test`（图 8.2）。`Time1` 类代表一天中的时间。`Time1Test` 类的 `main` 方法创建一个 `Time1` 类对象并调用它的方法。该程序的输出如图 8.2 所示。

### Time1 类声明

`Time1` 的私有 `int` 实例变量 `hour`、`minute` 和 `second`（第 6–8 行）代表通用格式的时间（24小时制，小时范围为 0–23，分和秒的范围各为 0–59）。`Time1` 包含公共方法 `setTime` 以及该类向客户端提供的公共接口。

```java
// 图 8.1: Time1.java
// Time 类以 24 小时格式维护时间。
public class Time1 {
    private int hour; // 0-23
    private int minute; // 0-59
    private int second; // 0-59

    // 使用通用时间设置新值；如果小时、分或秒无效则抛出异常
    public void setTime(int hour, int minute, int second) {
        if (hour < 0 || hour >= 24 || minute < 0 || minute >= 60 || second < 0 || second >= 60) {
            throw new IllegalArgumentException("小时、分或秒超出范围");
        }
        this.hour = hour;
        this.minute = minute;
        this.second = second;
    }

    // 转换为通用时间格式 (HH:MM:SS)
    public String toUniversalString() {
        return String.format("%02d:%02d:%02d", hour, minute, second);
    }

    // 转换为标准时间格式 (H:MM:SS AM or PM)
    public String toString() {
        return String.format("%d:%02d:%02d %s",
            (hour == 0 || hour == 12) ? 12 : hour,
            minute, second, hour < 12 ? "AM" : "PM");
    }
}
```

#### 默认构造函数

在此示例中，`Time1` 没有声明构造函数，因此编译器提供了默认构造函数。实例变量接收默认值。当在类主体中声明变量时，可以使用与局部变量相同的语法。

#### setTime 方法与抛异常

`setTime` 方法（第 12–25 行）是一个公共方法，声明三个 `int` 参数并使用它们设置时间。第 15–16 行测试每个参数的值是否超出范围。小时值必须大于等于 0 且小于 24，因为通用时间格式表示 0 到 23 时（例如，下午 1 点是 13，晚上 11 点是 23；午夜是 0，中午是 12）。同样，分和秒的值必须大于等于 0 且小于 60。对于超出这些范围的值，`setTime` 抛出一个 `IllegalArgumentException` 异常（第 18–19 行），告知客户端传递了无效参数。在第 7.5 节中，可以使用 `try...catch` 来捕获异常并尝试恢复，我们将在图 8.2 中这样做。`throw` 语句中的实例创建（图 8.1）创建一个 `IllegalArgumentException` 类型的对象。类名后的括号表示调用 `IllegalArgumentException` 构造函数。在这种情况下，构造函数允许我们指定错误消息。异常创建后，`throw` 语句立即终止 `setTime` 方法。如果参数值有效，将它们赋值给 `hour`、`minute`、`second` 实例变量。

> **软件工程观察 8.1**
> 对于图 8.1 中的 `setTime` 方法，在使用参数设置实例变量之前，确保只有在所有参数有效时才修改对象数据。

#### toUniversalString 方法

`toUniversalString` 方法（第 28–31 行）不接受参数，返回一个通用时间格式的字符串，每个小时、分、秒均为两位——您可以使用格式规范中的零标志（例如 `%02d`）为未达到指定字段宽的值显示导零。例如，如果时间是下午 1:30:07，该方法将返回 `13:30:07`。使用 `String` 的静态方法 `format` 返回一个包含小时、分、秒值的字符串，每个值均为两位并可能带有导零（通过标志指定）。`format` 方法与 `System.out.printf` 类似，但 `format` 返回格式化后的字符串，而不是在命令行窗口中显示。`toUniversalString` 方法返回格式化后的字符串。

#### toString 方法

`toString` 方法（第 34–39 行）不接受参数，返回一个标准时间格式的字符串，由冒号分隔小时、分、秒并带有 AM 或 PM（例如 `11:30:17 AM` 或 `12:27:06 PM`）。像 `toUniversalString` 方法一样，`toString` 使用静态 `String.format` 格式化分秒的值，必要时添加导零。第 37 行使用条件运算符 (`?`) 来确定字符串中的值——如果小时是 0 或 12（AM 或 PM），它显示为 12；否则，它显示为 1 到 11 之间的值。第 39 行的条件运算符决定作为字符串的一部分返回 `AM` 还是 `PM`。

记住 Java 中的所有对象都有一个 `toString` 方法，返回对象的字符串表示。我们选择返回一个包含标准时间格式的字符串。每当 `Time1` 对象出现在需要字符串的地方，`toString` 方法就会被隐式调用，例如在 `System.out.printf` 调用中带有 `%s` 格式指定符输出的值。您也可以显式地调用 `toString` 以获取 `Time1` 对象的字符串表示。

### 使用类 Time1

`Time1Test`（图 8.2）使用了类 `Time1`。第 9 行声明并创建了一个 `Time1` 对象 `time`。`new` 运算符隐式地调用了 `Time1` 的默认构造函数，因为 `Time1` 没有声明构造函数。为了确认 `Time1` 对象已正确初始化，第 12 行调用了 `displayTime` 方法（第 35–39 行），该方法反过来调用 `Time1` 对象的 `toUniversalString` 和 `toString` 方法，分别以通用格式和标准格式输出时间。注意，`toString` 可以隐式调用而非显式调用。接下来，第 16 行调用对象的 `setTime` 方法来更改时间。然后第 17 行再次调用 `displayTime` 以各种格式输出时间，以确认其设置正确。

> **软件工程观察 8.2**
> 回想第 3 章，用访问修饰符 `private` 声明的方法只能由声明该私有方法的类的其他方法调用。方法通常被用作工具方法或辅助方法，因为它们通常用于支持类其他方法的操作。

```java
// 图 8.2: Time1Test.java
// 在程序中使用 Time1 对象。
public class Time1Test {
    public static void main(String[] args) {
        // 创建并初始化 Time1 对象
        Time1 time = new Time1(); // 调用 Time1 构造函数
        // 输出时间的字符串表示
        displayTime("After object is created", time);
        System.out.println();
        // 修改时间并输出更新后的
        time.setTime(13, 27, 6);
        displayTime("After calling setTime", time);
        System.out.println();
        // 尝试用无效值设置时间
        try {
            time.setTime(99, 99, 99); // 所有值超出范围
        } catch (IllegalArgumentException e) {
            System.out.printf("Exception: %s%n%n", e.getMessage());
        }
        // 在尝试设置无效值后显示时间
        displayTime("After calling setTime with invalid values", time);
    }

    // 以 24 小时和 12 小时格式显示 Time1 对象
    private static void displayTime(String header, Time1 t) {
        System.out.printf("%s%nUniversal time: %s%nStandard time: %s%n",
            header, t.toUniversalString(), t.toString());
    }
} // Time1Test 类
```

**输出结果：**

```
创建时间对象后
Universal time: 00:00:00
Standard time: 12:00:00 AM

调用 setter 后
Universal time: 13:27:06
Standard time: 1:27:06 PM

Exception: 小时、分或秒超出范围

带有无效值调用 setter
Universal time: 13:27:06
Standard time: 1:27:06 PM
```

#### 使用无效值调用 Time1 的 setter

为了说明方法 `setTime` 会验证其参数，第 23 行调用了 `setTime` 方法，对小时、分、秒传入无效参数 99。该语句放置在 `try` 块（第 21–24 行）中，以防 `setTime` 抛出 `IllegalArgumentException`（如果所有参数都无效，它将抛出异常）。当发生这种情况时，异常在第 25–28 行被捕获，第 27 行通过调用 `getMessage` 方法显示异常的错误信息。第 31 行再次输出时间，以确认提供无效参数时 `setTime` 未更改时间。

#### Time1 类声明分析

考虑 `Time1` 类的若干问题。实例变量 `hour`、`minute` 和 `second` 被声明为 `private`。类内部使用的数据表示对类的客户端并不重要。例如，`Time1` 在内部将时间表示为自午夜以来的秒数或分钟数是完全合理的。客户端可以使用公共方法获得相同的结果，而无需知道类内部将时间表示为自午夜以来的秒数。

> **软件工程观察 8.3**
> 类编程简单，因为客户端只能使用公共方法。此类方法通常是面向客户端而非面向实现的。客户端既不感知类在做什么，也不关心类如何做。

## 8.3 控制访问

> **软件工程观察 8.4**
> 接口的变化频率比实现低。当实现发生变化时，依赖实现的代码必须相应更改。隐藏实现减少了其他部分依赖实现细节的可能性。

### Java SE 8—Date/Time API

本节和本章后面的示例展示了表示时间的概念。在专业开发中，通常不会自己构建时间类，而是使用 Java 提供的类。Java SE 8 引入了新的 Date/Time API——修复了旧类的各种问题，并提供了处理日期、时区和日历更健壮、更易用的功能。我们在第 2 章使用了 Date/Time 特性。您可以在此处了解更多关于 Date/Time API 类的信息：`java.time/package-summary`。

访问修饰符 `public` 和 `private` 控制类的变量和方法。在第 9 章中，我们引入了额外的修饰符 `protected`。公共方法的主要目的是向客户端展示类提供的服务（即类的公共接口）。客户端不需要关心类是如何完成任务的。因此，类的私有变量和私有方法（即其实现细节）对客户端是不可见的。图 8.3 展示了类外无法访问私有成员。第 9–11 行尝试访问 `Time1` 的实例变量 `hour`、`minute` 和 `second`。当编译此程序时，编译器会生成这些私有成员不可访问的错误信息。

```java
// 图 8.3: MemberAccessTest.java
// 类私有成员不可访问。
public class MemberAccessTest {
    public static void main(String[] args) {
        Time1 time = new Time1(); // 创建并初始化 Time1
        time.hour = 7; // 错误：hour 是私有的
        time.minute = 15; // 错误：minute 是私有的
        time.second = 30; // 错误：second 是私有的
    }
} // MemberAccessTest 类
```

**编译错误输出：**

| 文件与行号 | 错误代码行 |
| :--- | :--- |
| MemberAccessTest.java:9: hour 是私有的 | `time.hour = 7; // 错误：hour 是私有的` |
| MemberAccessTest.java:10: minute 是私有的 | `time.minute = 15; // 错误：minute 是私有的` |
| MemberAccessTest.java:11: second 是私有的 | `time.second = 30; // 错误：second 是私有的` |

## 8.4 使用 this 引用引用当前对象的成员

每个对象都可以通过 `this` 关键字（有时称为 `this` 引用）访问自身。当为特定对象调用实例方法时，方法体隐式地使用 `this` 关键字来引用对象的实例变量和其他方法。这使得类代码知道应该操作哪个对象。正如你在图 8.4 中看到的，你也可以在实例方法中显式使用 `this` 关键字。第 8.5 节展示了 `this` 关键字的另一种用法。第 8.11 节解释了为什么不能在静态方法中使用。

我们展示了 `this` 引用的隐式和显式用法（图 8.4）。在一个文件中声明两个类的示例——`SimpleTime` 类声明在第 4-11 行，我们证明了当你编译包含多个类的 `.java` 文件时，编译器为每个编译后的类生成一个具有 `.class` 扩展名的独立类。在这种情况下，产生了两个独立文件——`SimpleTime.class` 和 `ThisTest.class`。当源代码 (`.java`) 文件包含多个类声明时，编译器将这些类的文件放在同一个目录下。同样注意图 8.4，只有 `ThisTest` 被声明为 `public`，否则会发生编译错误。非公共类只能被同一个包中的其他类使用。因此，在这个示例中，`SimpleTime` 只能被 `ThisTest` 类使用。

```java
// 图 8.4: ThisTest.java
// this 被隐式和显式地引用对象的成员。

public class ThisTest {
    public static void main(String[] args) {
        // 此处省略 main 方法体，原文截断
    }
}

// SimpleTime 类声明（原文第 4-11 行，此处为示意补全）
class SimpleTime {
    private int hour;
    private int minute;
    private int second;

    public SimpleTime(int hour, int minute, int second) {
        this.hour = hour;
        this.minute = minute;
        this.second = second;
    }
    // ... 其他方法
}
```
