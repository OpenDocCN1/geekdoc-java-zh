
## 第 8 章 类和对象：深入探究

### 8.5 时间类研究：重载构造函数

如你所知，你可以声明构造函数来指定类的对象应该如何初始化。接下来，我们将演示一个具有多个重载构造函数的类，这些构造函数允许该类的对象以不同的方式初始化。要重载构造函数，只需提供多个具有不同签名的构造函数声明。

**图 8.5** | 带有重载构造函数的 `Time2` 类。（4 部分，共 4 部分）。

```java
// 图 8.5: Time2.java
private int hour; // 0-23
private int minute; // 0-59
private int second; // 0-59

// Time2 无参数构造函数：
// 将每个实例变量初始化为零
public Time2()
{
    this(0, 0, 0); // 调用带有三个参数的构造函数
}

// Time2 构造函数：提供 hour，minute 和 second 默认为 0
public Time2(int hour)
{
    this(hour, 0, 0); // 调用带有三个参数的构造函数
}

// Time2 构造函数：提供 hour 和 minute，second 默认为 0
public Time2(int hour, int minute)
{
    this(hour, minute, 0); // 调用带有三个参数的构造函数
}

// Time2 构造函数：提供 hour、minute 和 second
public Time2(int hour, int minute, int second)
{
    if (hour < 0 || hour >= 24)
        throw new IllegalArgumentException("hour must be 0-23");
    if (minute < 0 || minute >= 60)
        throw new IllegalArgumentException("minute must be 0-59");
    if (second < 0 || second >= 60)
        throw new IllegalArgumentException("second must be 0-59");
    this.hour = hour;
    this.minute = minute;
    this.second = second;
}

// Time2 构造函数：提供另一个 Time2 对象
public Time2(Time2 time)
{
    // 调用带有三个参数的构造函数
    this(time.getHour(), time.getMinute(), time.getSecond());
}

// Set 方法
// 使用通用时间设置新的时间值；验证数据
public void setTime(int hour, int minute, int second)
{
    if (hour < 0 || hour >= 24)
        throw new IllegalArgumentException("hour must be 0-23");
    if (minute < 0 || minute >= 60)
        throw new IllegalArgumentException("minute must be 0-59");
    if (second < 0 || second >= 60)
        throw new IllegalArgumentException("second must be 0-59");
    this.hour = hour;
    this.minute = minute;
    this.second = second;
}

// 验证并设置 hour
public void setHour(int hour)
{
    if (hour < 0 || hour >= 24)
        throw new IllegalArgumentException("hour must be 0-23");
    this.hour = hour;
}

// 验证并设置 minute
public void setMinute(int minute)
{
    if (minute < 0 || minute >= 60)
        throw new IllegalArgumentException("minute must be 0-59");
    this.minute = minute;
}

// 验证并设置 second
public void setSecond(int second)
{
    if (second < 0 || second >= 60)
        throw new IllegalArgumentException("second must be 0-59");
    this.second = second;
}

// Get 方法
public int getHour()
{
    return hour;
}

// 获取 minute 值
public int getMinute()
{
    return minute;
}

// 获取 second 值
public int getSecond()
{
    return second;
}

// 转换为通用时间格式的字符串 (HH:MM:SS)
public String toUniversalString()
{
    return String.format(
        "%02d:%02d:%02d", getHour(), getMinute(), getSecond());
}

// 转换为标准格式时间的的字符串 (H:MM:SS AM 或 PM)
public String toString()
{
    return String.format("%02d:%02d:%02d %s",
        (getHour() == 0 || getHour() == 12) ? 12 : getHour(),
        getMinute(), getSecond(), (getHour() < 12 ? "AM" : "PM"));
}
} // end class Time2
```

**图 8.5** | 带有重载构造函数的 `Time2` 类。（4 部分，共 4 部分）。

#### Time2 的构造函数——通过 this 调用另一个构造函数

第 12-15 行描述了一个无需参数的无参数构造函数。一旦你在类中声明了任何构造函数，编译器就不会提供默认构造函数。这个无参数构造函数确保 `Time2` 的客户端可以创建带有默认值的 `Time2` 对象。此类构造函数按照方法体指定的方式初始化对象。在方法体中，我们使用了允许作为构造函数第一条语句的 `this` 语法来调用带有三个参数的构造函数（第 30–44 行），并将 `hour`、`minute` 和 `second` 的值设置为 0。在这里这样使用 `this` 是重用另一个构造函数提供的初始化代码的完美方法，而不是在无参数构造函数的方法中定义类似的代码。我们在五个 `Time2` 构造函数中的四个使用了这种语法，以便于维护和修改类。我们需要更改 `Time2` 类初始化的方式，只需要修改其他构造函数调用的那个构造函数。

> **常见编程错误 8.2**
> 在构造函数的方法体中使用 `this` 调用类的另一个构造函数时，如果该调用不是构造函数的第一条语句，则会导致编译错误。当方法尝试通过 `this` 直接调用构造函数时，也会导致编译错误。

第 18–21 行声明了一个带有单个 `int` 参数表示 `hour` 的 `Time2` 构造函数，该参数连同两个 0 传递给第 30–44 行的构造函数。第 24–27 行声明了一个接收两个表示 `hour` 和 `minute` 的 `int` 的 `Time2` 构造函数，这两个参数与一个 0 传递给第 30–44 行的构造函数。无参数构造函数，这些构造函数中的每一个都调用构造函数以减少代码重复。第 30–44 行声明了 `Time2` 构造函数接收三个参数，分别代表小时、分和秒。此构造函数会验证并初始化实例变量。

第 47–51 行声明了一个 `Time2` 构造函数，它接收指向另一个 `Time2` 对象的引用。来自 `Time2` 参数的值被传递给第 30–44 行的三参数构造函数，以初始化小时、分和秒。第 50 行可以直接通过 `time.hour`、`time.minute` 和 `time.second` 表达式访问参数的小时、分和秒——尽管 `hour`、`minute` 和 `second` 被声明为 `Time2` 类的私有变量。这是由于同类对象之间存在特殊关系。我们稍后会看到为什么使用 get 方法会更好。

> **软件工程观察 8.5**
> 当一个类的某个对象拥有另一个同类对象的引用时，第一个对象可以访问第二个对象的所有数据和方法（包括私有方法）。

#### 类 Time2: setTime 方法

`setTime`（第 56–70 行）如果任何参数超出范围，则会抛出 `IllegalArgumentException`（第 59、62 和 65 行）。否则，它会将 `Time2` 的实例变量设置为参数的值（第 67–69 行）。

#### 关于 Time2 set 和 get 方法的说明

`Time2` 的方法在整个类中被调用。特别是，`toUniversalString` 和 `toString` 方法调用了 `getHour`、`getMinute` 和 `getSecond`。在每种情况下，这些方法都可以在调用方法的情况下访问类的私有数据。然而，考虑到将从三个整数表示的时间（需要 12 字节内存）转变为代表自午夜以来经过的总秒数的单个值（仅需 4 字节内存）。如果我们做了这样的更改，只有访问私有数据的方法才需要更改——特别是三参数构造函数、`setTime` 方法以及用于小时、分和秒的单独的 set 和 get 方法。不需要修改 `toUniversalString` 或 `toString` 的方法，因为它们没有直接访问数据。以这种方式设计类可以减少更改类实现时出现编程错误的几率。

同样，每个 `Time2` 构造函数都可以包含三参数构造函数中的任何适当语句。这样做可能会稍微高效一些，因为消除了额外的构造函数调用。但是，重复语句使得更改类的内部表示变得更加困难。`Time2` 构造函数调用带三个参数的构造函数要求对三参数构造函数的任何更改只需进行一次。此外，编译器可以通过删除对简单方法的调用并将其替换为声明的代码来优化程序——这种技术被称为代码内联（inlining），它可以提高程序性能。

### 使用类 Time2: 重载构造函数

`Time2Test` 类（图 8.6）调用了重载的 `Time2` 构造函数（第 8–12 行和 24 行）。第 8 行调用 `Time2` 无参数构造函数。第 9–12 行演示了将参数传递给其他 `Time2` 构造函数。第 9 行调用了图 8.5 第 18–21 行接收一个 `int` 的单参数构造函数。第 10 行调用了图 8.5 第 24–27 行的双参数构造函数。第 11 行调用了第 30–44 行的三参数构造函数。第 12 行调用了图 8.5 第 47–51 行接收 `Time2` 的单参数构造函数。接下来，应用程序显示 `Time2` 的字符串表示以确认其已正确初始化（第 15–19 行）。第 24 行尝试通过创建一个新的 `Time2` 对象向构造函数传递无效值来初始化 `t6`。当构造函数尝试使用无效的小时值来初始化对象时，会发生 `IllegalArgumentException`。我们在第 26 行捕获此异常并显示其错误信息，结果产生了输出中的该行。

```java
// Fig. 8.6: TimeTest.java
// 使用重载构造函数来初始化 Time2 对象
public class TimeTest {
    public static void main(String[] args) {
        Time2 t1 = new Time2(); // 00:00:00
        Time2 t2 = new Time2(2); // 02:00:00
        Time2 t3 = new Time2(21, 34); // 21:34:00
        Time2 t4 = new Time2(12, 25, 42); // 12:25:42
        Time2 t5 = new Time2(t4); // 12:25:42
        System.out.println("Constructed with:");
        System.out.println("t1: all default arguments", t1);
    }
}
```
