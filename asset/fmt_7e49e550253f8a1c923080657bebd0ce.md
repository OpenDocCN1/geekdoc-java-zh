### 连接到数据库

我们在示例中使用的 JDBC 接口扩展了 `AutoCloseable` 接口，因此你可以使用 `try-with-resources` 语句（第 11.12 节引入）来使用这些接口的对象。第 19–23 行在 `try` 关键字后的括号中创建了此示例的 `AutoCloseable` 对象——此类对象在 `try` 块结束（第 43 行）或在 `try` 块执行期间发生异常时会自动关闭。关键字后括号中创建的每个对象都必须用分号 (`;`) 与其他部分隔开。

第 20–21 行创建了 `connection` 引用的 `Connection` 对象（包 `java.sql`）。实现 `Connection` 的对象管理 Java 程序与数据库之间的连接。`Connection` 对象允许程序创建管理数据库的 SQL 语句。程序通过 `DriverManager`（包 `java.sql`）的静态方法 `getConnection` 的结果初始化连接，该方法尝试通过 URL 连接到数据库。

`getConnection` 方法接收三个参数：
- 一个指定数据库 URL 的字符串，
- 一个指定用户名的字符串以及
- 一个指定密码的字符串。

下方数据库的用户名和密码在 24.5 节中设置。如果你在该处使用了不同的用户名和密码，则需要替换第 21 行中传递给 `getConnection` 方法的用户名（第二个参数）和密码（第三个参数）。

URL 用于定位数据库（可能在网络上或计算机的本地文件系统中）。URL `jdbc:derby:books` 指定了通信协议（derby）和数据库的位置（books）。子协议 `derby` 表示程序使用 DB/Apache Derby 子协议连接到数据库——回想一下，DB 仅仅是 Oracle 命名的 Apache Derby。如果 `DriverManager` 无法连接到数据库，`getConnection` 方法将抛出 `SQLException`（包 `java.sql`）。图 24.24 列出了常用 RDBMS 的 JDBC 驱动名称和 URL 格式。

## ResultSetTableModel 类

`ResultSetTableModel` 类（图 24.25）继承自 `AbstractTableModel`（位于 `javax.swing.table` 包，实现了 `TableModel` 接口）。`ResultSetTableModel` 重写了 `TableModel` 的方法 `getColumnClass`、`getColumnName`、`getRowCount` 和 `getValueAt`。`TableModel` 方法的默认实现 `getCellIdentifier` 和 `setValue`（由 `AbstractTableModel` 提供）没有被重写，因为本示例不支持 `JTable` 单元格编辑。`TableModel` 方法的默认实现 `addTableListener` 和 `removeTableListener`（由 `AbstractTableModel` 提供）没有被重写，因为 `AbstractTableModel` 中这些方法的实现已经能够正确地添加和移除事件监听器。

```java
// 图 24.25: ResultSetTableModel.java
// 一个为 JTable 提供 ResultSet 数据的 TableModel。

import java.sql.Connection;
import java.sql.Statement;
import java.sql.DriverManager;
import java.sql.ResultSet;
import java.sql.ResultSetMetaData;
import java.sql.SQLException;
import javax.swing.table.AbstractTableModel;

// 行和列是从 1 开始计数的，而 JTable
// 行和列是从 0 开始计数的。在处理 JTable 中的
// 行、列或列时，必须
// 对行号或列号加 1 才能操作
// 相应的列（例如，JTable 第 0 列是
// ResultSet 第 1 列，JTable 第 0 行是 ResultSet 第 1 行）。
public class ResultSetTableModel extends AbstractTableModel {
    private final Connection connection;
    private final Statement statement;
    private ResultSet resultSet;
    private ResultSetMetaData metaData;
    private int numRows;
    // 跟踪数据库连接状态
    private boolean connectedToDatabase = false;
    // 构造函数初始化 ResultSet 并获取其元数据对象；
    public ResultSetTableModel(String url, String username,
        String password, String query) throws SQLException {
        // 连接数据库
        connection = DriverManager.getConnection(url, username, password);
        // 创建语句查询数据库
        statement = connection.createStatement(
            ResultSet.TYPE_SCROLL_INSENSITIVE,
            ResultSet.CONCUR_READ_ONLY);
```

public Class getColumnClass(int column) throws IllegalStateException {
    // 确保数据库连接可用
    if (!connectedToDatabase) {
        throw new IllegalStateException("未连接到数据库");
    }
    // 确定列的 Java 类
    try {
        String className = metaData.getColumnClassName(column + 1);
        // 返回代表 className 的 Class 对象
        return Class.forName(className);
    } catch (Exception exception) {
        exception.printStackTrace();
    }
    return Object.class; // 如果上方发生问题，假设类型为 Object
}

public int getColumnCount() throws IllegalStateException {
    // 确保数据库连接可用
    if (!connectedToDatabase) {
        throw new IllegalStateException("未连接到数据库");
    }
    // 确定列数
    try {
        return metaData.getColumnCount();
    } catch (SQLException sqlException) {
        sqlException.printStackTrace();
    }
    return 0; // 如果上方发生问题，返回列 0
}
