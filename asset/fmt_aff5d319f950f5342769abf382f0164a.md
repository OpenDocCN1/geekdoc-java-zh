## 实现计数控制重复

在图 4.8 中，`classAverage` 的 `main` 方法（第 7–31 行）实现了图 4.7 中伪代码描述的平均分计算算法——允许用户输入 10 个分数，然后计算并显示平均分。

```java
// 图 4.8: ClassAverage.java
// 使用计数控制重复解决班级平均分问题。
import java.util.Scanner; // 程序使用 Scanner 类

public class ClassAverage {
    public static void main(String[] args) {
        // 创建 Scanner 从命令行窗口获取输入
        Scanner input = new Scanner(System.in);

        // 初始化阶段
        int total = 0; // 初始化成绩总和
        int gradeCounter = 1; // 初始化循环计数器

        // 处理阶段
        while (gradeCounter <= 10) { // 循环 10 次
            System.out.print("Enter grade: "); // 提示输入
            int grade = input.nextInt(); // 读取用户输入
            total = total + grade; // 将 grade 加到 total
            gradeCounter = gradeCounter + 1; // 计数器加 1
        } // end while

        // 终止阶段
        int average = total / 10; // 整数除法
        System.out.printf("%nTotal of all 10 grades is %d%n", total);
        System.out.printf("Class average is %d%n", average);
    } // end main
} // end class ClassAverage
```

### 方法 main 中的局部变量

第 10 行声明并初始化了 `Scanner` 变量 `input`，用于读取用户输入的变量。第 13、14、20 和 26 行分别声明了类型为 `int` 的变量 `total`、`gradeCounter`、`grade` 和 `average`。变量 `grade` 存储用户输入。

这些声明出现在方法 `main` 的体中。记住，在方法中声明的变量是局部变量，可以从声明行一直使用到方法声明结束的右大括号处。局部变量的声明必须在在该方法中使用该变量之前。局部变量无法在声明它的方法之外访问。在 `while` 循环体内声明的变量 `grade` 仅在代码块中有效。

### 初始化阶段：初始化 total 和 gradeCounter

赋值语句（第 13–14 行）将 `total` 初始化为 0，将 `gradeCounter` 初始化为 1。这些初始化发生在变量用于计算之前。

### 处理阶段：从用户处读取 10 个分数

第 17 行表示，只要 `gradeCounter` 的值小于或等于 10，`while` 语句就会继续循环（也称为迭代）。只要条件保持真，`while` 语句就会反复执行大括号限定范围内的语句（第 18–23 行）。

第 19 行显示提示符 "Enter grade: "。第 20 行读取用户输入的成绩并赋值给变量 `grade`。第 21 行将用户输入的新分数加到 `total` 中，并将结果赋值给 `total`，替换其原有值。

第 22 行对 `gradeCounter` 加 1，表示程序已处理了一个分数，并准备好从用户处输入下一个分数。增加 `gradeCounter` 最终会导致其超过 10。然后循环终止，因为其条件（第 17 行）变为假。

### 终止阶段：计算并显示班级平均分

循环终止时，第 26 行执行平均计算并将结果赋值给变量 `average`。第 29 行使用 `System.out.printf` 显示文本 "Total of all 10 grades is " ，后跟变量 `total`。第 30 行使用 `printf` 显示文本 "Class average is " ，后跟变量的值。执行到第 31 行，程序终止。

此示例仅包含一个类，由 `main` 执行所有工作。在本例和第 3 章中，你将看到两个类的示例——一个包含变量和使用这些变量的方法，另一个包含 `main`，创建另一个类的对象并调用其方法。有时为了演示一个概念并不创建一个可重用的类，我们将程序的语句完全放在单个类中。

### 关于整数除法截断的说明

### 使用自顶向下逐步细化的方法开发伪代码算法

#### 顶层与第一次细化

使用称为“自顶向下逐步细化”的技术来处理这个班级平均分程序，这对于开发结构良好的程序关键。我们从程序的伪代码表示开始——一个传达程序整体功能的语句：

```
确定测验的班级平均分
```

“顶层”实际上是程序的完整表示。遗憾的是，顶层很少能提供足够编写 Java 程序的细节。我们现在开始细化过程。我们将顶层分为一系列较小的任务，并按照它们执行的顺序列出它们。这些结果得到了下面的第一次细化：

```
初始化变量
输入、求和并统计测验成绩
计算并打印班级平均分
```

这种细化仅使用了顺序结构——列出的步骤应该按顺序一个接一个地执行。

> **软件工程观察 4.3**：每一次细化，以及顶层本身，都是算法的完整规范——仅仅是细节程度不同。

> **软件工程观察 4.4**
>
> 许多程序可以从逻辑上划分为三个阶段：初始化变量的初始化阶段；输入数据值并调整程序变量的处理阶段；以及计算并输出最终结果的终止阶段。

上述的“软件工程观察”就是你在自顶向下过程中进行第一次细化所需要的所有内容。要继续进行下一层级的细化——即第二次细化——我们需要确定具体的变量。在这个示例中，我们需要一个数字的运行总和、一个已处理数字的计数、一个接收用户输入的每个成绩值的变量，以及一个存储计算出的平均值的变量。伪代码语句

### 实现哨兵控制循环

在图 4.10 中，`main`（第 7–46 行）实现了图 4.9 的伪代码算法。虽然每个成绩都是整数，但平均值的计算可能会产生带有小数点的数字——换句话说，实数（浮点）。`int` 类型无法表示这种数字，因此我们使用 `double`。你还会看到控制语句可以堆叠（顺序）。`while` 语句（第 22–30 行）之后是 `if...else` 语句（第 34–45 行）。该程序中的大部分代码与图 4.8 相同，因此我们专注于新概念。

```java
// 图 4.10: ClassAverage.java
// 使用哨兵控制循环解决班级平均分问题。
import java.util.Scanner; // 程序使用 Scanner 类

public class ClassAverage {
    public static void main(String[] args) {
        // 创建 Scanner 从命令行窗口获取输入
        Scanner input = new Scanner(System.in);
        // 初始化阶段
        int total = 0; // 初始化成绩总和
        int gradeCounter = 0; // 初始化目前已输入的成绩数

        // 处理阶段
        // 提示输入并从用户读取成绩
        System.out.printf("输入成绩或 -1 退出: ");
        int grade = input.nextInt();

        // 循环直到输入哨兵值
        while (grade != -1) {
            total = total + grade; // 将 grade 加到 total
            gradeCounter = gradeCounter + 1; // 计数器加 1

            // 提示输入并从用户读取下一个成绩
            System.out.printf("输入成绩或 -1 退出: ");
            grade = input.nextInt();
        } // end while

        // 终止阶段
        if (gradeCounter != 0) {
            double average = (double) total / gradeCounter; // 显式转换
            System.out.printf("%nTotal of the %d grades entered is %d%n", gradeCounter, total);
            System.out.printf("Class average is %.2f%n", average);
        } else {
            System.out.println("No grades were entered");
        }
    } // end main
} // end class ClassAverage
```

### 哨兵值控制循环与计数控制循环的逻辑

第 37 行声明了 `double average`，这允许我们将课程平均分作为浮点数存储。第 14 行将 `gradeCounter` 初始化为 0，因为还没有输入任何成绩。请记住，程序使用哨兵值控制循环来输入成绩。为了准确统计输入成绩的条数，程序仅在用户输入有效值时才增加 `gradeCounter`。

将此应用程序中哨兵值控制循环的程序逻辑与图 4.8 中计数控制循环的逻辑进行比较。在计数控制循环中，`while` 语句的每次迭代（即图 4.8 的第 17–23 行）都会根据指定的次数从用户处读取一个值。在哨兵值控制循环中，程序在进入 `while` 语句之前读取第一个值（图 4.10 的第 18–19 行）。该值决定了程序的控制流是否应该进入 `while` 循环体。如果 `while` 条件为假（没有输入成绩），则用户输入了哨兵值，因此不执行 `while` 循环体（即没有输入成绩）。相反，如果条件为真，则开始执行循环体，将成绩加到总和并增加 `gradeCounter`（第 24–25 行）。然后循环中的第 28–29 行从用户处输入值。接下来，程序到达第 30 行循环体的结束右大括号，因此执行继续进行 `while` 条件测试（第 22 行）。该条件使用用户最近一次输入的成绩来决定循环体是否应再次执行。变量 `grade` 的值总是在程序测试 `while` 条件之前立即从用户处输入的。这使得程序在处理该值（即将其加到总和）之前，就能确定成绩是否为哨兵值。如果输入了哨兵值，循环将终止，程序不会将 -1 加到总和中。

> **良好的编程实践 4.3**
>
> 在哨兵值控制循环中，提示信息应该提醒用户哨兵值。

![](img/6851b408bcf88c7702f7d951642252f8_167_0.png)

循环结束后，执行第 34–45 行的 `if...else` 语句。第 34 行的条件决定是否输入了成绩。如果没有输入，则执行 `if...else` 语句的 `else` 部分（第 44–45 行），显示消息“No grades were entered”并返回到调用方法。

### while 语句中的大括号

注意图 4.10 中的 `while` 块（第 23–30 行）。如果没有大括号，循环体将只有第一条将成绩加到总和的语句。块中的最后三个语句将落在循环体之外，导致计算机错误地将代码解释：

```java
while (grade != -1)
    total = total + grade; // 将成绩加到总和
    gradeCounter = gradeCounter + 1; // 计数

// 提示并从用户处读取下一个成绩
    System.out.print("Enter grade or -1 to quit: ");
    grade = input.nextInt();
```

如果用户在第 19 行（`while` 语句之前）没有输入哨兵值 -1，上述代码将导致程序出现死循环。

> **常见编程错误 4.5**
>
> 遗漏界定块的大括号会导致逻辑错误，例如死循环。为了防止此类问题，一些程序员会将每个控制语句的体都包含在大括号中，即使该体只包含单条语句。

### 基本数据类型之间的显式和隐式转换

如果至少输入了一个成绩，图 4.10 的第 37 行将计算成绩的平均值。回想图 4.8，整数除法产生整数结果。尽管变量被声明为 `double`，如果我们将平均值计算写成：

```java
double average = total / gradeCounter;
```

在将除法结果赋值给 `average` 之前，它将丢失商的小数部分。这是因为 `total` 和 `gradeCounter` 都是整数，而整数除法产生整数结果。

大多数平均值都不是整数（例如 0、~22 和 1024）。出于此原因，我们在示例中以浮点数形式计算平均值。为了对整数值进行浮点计算，我们必须临时将这些值视为浮点数以供计算。Java 提供了一元转换运算符来创建操作数 `total`（位于运算符右侧）的临时浮点数副本。使用图 4.10 的第 37 行，我们使用了 `(double)` 转换运算符——这是一个一元运算符。像这样使用转换运算符被称为显式转换或类型强制转换。`total` 中存储的值仍然是整数。
