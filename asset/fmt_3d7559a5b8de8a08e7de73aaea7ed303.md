
# II.iv.67 (56,6)

[你若冒着灵魂的危险为此这样做，

那么罪恶与慈善便对等了]

其逻辑是这样的：安杰洛问，为了救这个兄弟，是否可能是一种出于慈善的罪恶？伊莎贝拉回答说，如果安杰洛救他，她愿意赌上自己的灵魂来担保那是慈善，而非罪恶。安杰洛回答说，如果伊莎贝拉愿意以自己的灵魂为代价来救他，那确实不是罪恶，但这种行为等同于慈善。

# III.i.5 (62,8)

# III.i.7 (62,9)

[To lose a thing, That none but fools would keep] [W: would wreck] 意思显然是，除了傻子没人想留命；或者，如果允许选择，除了傻子没人会留它。这种感觉无论真假，都是无辜的。

# III.i.14 (63,3)

[For all the accommodations, that thou'rt Nurs'd by baseness] 沃伯斯特显然误解了，他认为自私（`baseness`）是所有人类行为的动机。莎士比亚只是想观察，对生命细微的分析瞬间展现了令人眩目的华丽。无论多么宏大的展示，或享受奢华，都是由卑微（`baseness`）获得的，这些功能让心灵从思考中退缩。桌上的美味可以追溯到屠宰场，建筑的宏伟源于采石场，而所有装饰的华丽都是来自矿井的潮湿与黑暗。

# III.i.16 (64,4)

[the soft and tender fork Of A poor worm] `Worm`指任何爬行物或蛇。莎士比亚错误地根据通俗认为，蛇用舌头伤人，而它的舌头是分叉的。他混淆了现实与虚构，蛇的舌头是软的，既不分叉也没有伤害。如果它能伤害，就不可能是软的。在《仲夏夜梦》中他有同样的观点——比你的舌头更多，蛇，从未毒过。

# III.i.17 (64,5)

[Thy best of rest is sleep,

And thou oft provok'st; yet grosly fear'st

Thy death which is no more] 这里沃伯斯特可能发现了一种值得他指责的情绪。我无法不愤愤地发现莎士比亚说死亡只是睡眠，通过修道士的一句话来延长他的劝诫是不虔的，在理学家看来是愚蠢的，在诗人看来是平庸世俗的。

# III.i.19 (64,6)

[Thou art not yourself,

For exist'st on many thousand grains,

That issue out of dust] 你通过外部帮助不断修复和更新，你依赖于外来物质，没有产生或维持自身存在的能力。

# III.i.24 (64,7)

[strange effects] `effects`对应`affects`；即情感、心境，或身体的各种影响。在《奥赛罗》中，年轻的影响。

# III.i.32 (65,9)

[Thou hast nor youth, nor age;

But, as it were, an after-dinner's sleep,

Dreaming on both] 这想象得极精妙。当我们年轻时，忙于为未来制定计划，错过了眼前的欢愉；当我们老时，用对童年快乐或成就的回忆来消遣老年的倦怠；因此我们的生活，没有一部分被当下的事务占据，它就像饭后的睡眠，对两者都在梦中。

……而其他的页本据此变成了王室的，每一位编辑者都可以尽其所能。

# III.i.113 (71,7)

[如果那是不可饶恕的罪，对于如此睿智的人，

他为何会为了这瞬间的诡计

而甘愿被永恒地揭穿呢]？

莎士比亚通过克劳迪的行为展示了他对人性的洞察。当伊莎贝拉第一次告诉他安杰洛的提议时，他带着诚恳的愤慨，顺应他内心固定的原则回答道：

汝不准这么做。

由于对生命的渴望被允许发挥，这让他提供了精妙的辩护，他认为这对灵魂来说并不危险，因为如此睿智的安杰洛都为此冒了险。

# III.i.121 (71,8)

[delighted spirit] 这种读法或许可以站得住，但已有许多尝试对其进行纠正。最合理的解释是替换：

- — 蒙昧的精神（`the benighted spirit`），

暗指人们认为在未来惩罚之地总是存在的黑暗。

也许我们可以读作：

- — 违规的精神（`the delinquent spirit`），

这个词很容易被糟糕的抄员或不熟练的读者误写为`delighted`（愉悦的）。

`Delinquent`是Thirlby在他的手稿中（1773年）提出的词。

# III.i.127 (72,9)

[lawless and uncertain thoughts] 臆测的思绪被无目的地游荡，在所有痛苦的可能性中徘徊。

# III.i.139 (73,2)

[从自己妹妹的房间里夺走生命，难道不是一种诱惑吗？] 在伊莎贝拉的慷慨陈词中，有些地方显得很刻薄，有些地方生硬且牵强。当我们考虑到她不仅是一个处女，而且是一个修女时，这种愤慨不能被认为是激烈的。

# III.i.149 (74,4)

# III.ii.40 (80,7)

[如果我们都像某些人表现的那样，完全没有瑕点，就像错误没有看起来是自由的一样！]

Sir T. Hammer读作：完全没有瑕点，就像错误没有看起来是自由的一样。

在Warburton博士的解释中，意义是微不足道的，且表达生硬。希望人们免于瑕点，就像错误免于美观[而不是缺乏美观]一样，这是一个非常贫劣的构思。我曾想过应该是：

噢，愿一切都像他们所表现的那样。完全没有瑕点，或没有看起来是自由的。所以在部剧中：

噢地方，噢权力——你如何从愚人手中夺走敬畏，并将更理智的灵魂系在你虚假的表象上。

现在我相信一个较小的改动就能达到效果。完全没有瑕点，或没有看起来是自由的；那样真的很好，或者说如果他们的错误被知道了，人们就免于瑕点，或免于虚伪。所以伊莎贝拉称安杰洛的虚伪为表象、表象。

# III.ii.51 (81,1)

# IV.iv.28 (116,8)

任何特定的丑闻都无法触及我]

`Credent`是"可信的"，强迫信誉的，不可质疑的。老英语作家经常混淆主动态和被动态形容词。所以莎士比亚以及随其后的米尔顿，将`inexpressive`用来表示`inexpressive`。

`Particular`是"私人的"，法语含义。任何来自私人口中的丑闻都无法触及一个拥有权威的人。
