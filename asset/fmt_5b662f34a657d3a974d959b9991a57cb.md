
# 第 17 章 Java SE 8 Lambdas 和 Streams

## 方法引用类型

`String::toUpperCase` 是 `String` 实例方法 `toUpperCase` 的方法引用。下表显示了四种方法引用。

| Lambda | 说明 |
| :--- | :--- |
| `String::toUpperCase` | 类实例方法的方法引用。创建一个单参数的 lambda，该 lambda 在 lambda 的参数上调用该实例方法并返回方法的结果。 |
| `System.out::println` | 应在特定对象上调用的实例方法的方法引用。创建一个单参数的 lambda，该 lambda 在指定的对象上调用该实例方法（将 lambda 的参数传递给实例方法）并返回方法的结果。 |
| `Math::sqrt` | 类静态方法的方法引用。创建一个单参数的 lambda，将 lambda 的参数传递给静态方法，并且 lambda 返回方法的结果。 |
| `TreeMap::new` | 构造函数引用。创建一个 lambda，该 lambda 调用指定类的无参数构造函数以创建并初始化该类的新对象。 |

Stream `map` 接收一个实现 `Function` 函数式接口的对象作为参数——实例方法 `String::toUpperCase` 被视为实现 `Function` 的 lambda。该接口的 `apply` 方法接收一个参数并返回一个结果——在这种情况下，方法应用于一个 `String` 并返回该 `String` 的大写版本。第 21 行将结果收集到一个 `List<String>` 中，我们将其作为 String 输出。

## 17.5.2 过滤字符串并按不区分大小写的升序排序

第 24–28 行对字符串进行了过滤和排序。第 25 行从数组 `strings` 创建一个 `Stream<String>`，第 26 行调用 Stream 方法定位所有大于 "m" 的字符串，在 `Predicate` lambda 中使用不区分大小写的比较。第 27 行对结果进行排序，第 28 行将其收集到一个 `List<String>` 中，我们将其作为 String 输出。在这种情况下，第 27 行调用了接收 `Comparator` 作为参数的 Stream 方法版本。正如你在第 16.7.1 节中学到的，`Comparator` 定义了一个方法：如果第一个值与第二个值比较，则返回负值；如果它们相等则返回 0，如果第一个值大于第二个值则返回正值。默认情况下，方法 `sorted` 使用该类型的自然顺序——`String` 的自然顺序是区分大小写的，这意味着 "Z" 排在 "a" 之前。传递预定义的 `Comparator` `String.CASE_INSENSITIVE_ORDER` 可执行不区分大小写的排序。

## 17.5.3 过滤字符串并按不区分大小写的降序排序

第 31–35 行执行与第 24–28 行相同的任务，但按降序排序字符串。函数式接口 `Comparator` 包含默认方法 `reversed`，它可以反转现有比较器的排序。当应用于 `String` 的 `CASE_INSENSITIVE_ORDER` 时，字符串按降序排序。

## 17.6 Stream<Employee> 的操作

图 17.9–17.16 中的示例演示了使用 `Stream<Employee>` 的各种 lambda 和流能力。`Employee` 类（图 17.9）代表一个具有名、姓、薪水和部门的员工，以及处理这些值的方法。此外，该类提供了 `getName` 方法（第 69–72 行），该方法返回合并后的名和姓作为 `String`，以及一个 `toString` 方法（第 75–80 行），返回包含员工名、姓、薪水和部门的格式化 `String`。

```java
// 图 17.9: Employee.java
// Employee 类。

public class Employee {

    private String firstName;
    private String lastName;
    private double salary;
    private String department;

    // 构造函数
    public Employee(String firstName, String lastName,
        double salary, String department) {
        this.firstName = firstName;
        this.lastName = lastName;
        this.salary = salary;
        this.department = department;
    }

    // set firstName
    public void setFirstName(String firstName) {
        this.firstName = firstName;
    }

    // get firstName
    public String getFirstName() {
        return firstName;
    }

    // set lastName
    public void setLastName(String lastName) {
        this.lastName = lastName;
    }

    // get lastName
    public String getLastName() {
        return lastName;
    }

    // set salary
    public void setSalary(double salary) {
        this.salary = salary;
    }

    // get salary
    public double getSalary() {
        return salary;
    }

    // set department
    public void setDepartment(String department) {
        this.department = department;
    }

    // get department
    public String getDepartment() {
        return department;
    }

    // 返回合并的名和姓作为 String
    public String getName() {
        return firstName + " " + lastName;
    }

    // 返回包含员工名、姓、薪水和部门的格式化 String
    @Override
    public String toString() {
        return String.format("%s %s, %.2f, %s",
            firstName, lastName, salary, department);
    }
}
```

### 过滤薪资在 $4000-$6000 之间的员工

```java
// Predicate<Employee> returns true for salaries in the range $4000-$6000
Predicate<Employee> fourToSixThousand =
    e -> e.getSalary() >= 4000 && e.getSalary() <= 6000;
```

```java
// Display Employees with salaries in the range $4000-$6000
// sorted into ascending order by salary
System.out.printf("%n%s earning $4000-$6000 per month by salary:%n",
    list.stream()
        .filter(fourToSixThousand)
        .sorted(Comparator.comparing(Employee::getSalary))
```

#### 短路流流水线处理

在第 5.9 节中，你学习了使用逻辑与 (`&&`) 和或 (`||`) 操作符的短路求值。惰性求值性能特性之一是能够执行短路求值——即一旦达到所需的结果立即停止流流水线。类似于 `findFirst` 方法——这是一个短路终止操作，它处理流流水线并在一旦从流流水线找到第一个对象时终止。基于原始的 Employees 列表，第 48–51 行的流处理（即过滤薪资在 $4000–6000 之间的员工）执行过程如下：谓词 `fourToSixThousand` 被应用于第一个员工（Jason Red）。他的工资（$5000.00）符合条件，处理立即终止，仅处理了八个对象中的一个。方法 `findFirst` 然后返回一个 `Optional`（在本例中为 `Optional<Employee>`），如果找到了对象则返回它。在本例中，`Optional` 方法 `get`（第 51 行）返回了匹配的 `Employee` 对象。即使流包含数百万个 `Employee` 对象，过滤操作也只会执行到找到匹配项为止。

## 17.6.3 按多个字段对员工排序

下例展示了如何使用流按多个字段对对象排序。在这个示例中，我们先按姓对 `Employees` 进行排序，然后对于姓相同的 `Employees`，我们再按名进行排序。为了实现这一点，我们首先创建两个 `Function`，每个 `Function` 接收一个 `Employee` 并返回一个 `String`：

- `byFirstName`（第 54 行）被分配了 `Employee` 实例方法 `getFirstName` 的方法引用
- `byLastName`（第 55 行）被分配了 `Employee` 实例方法 `getLastName` 的方法引用

接下来，我们使用这些 `Function` 创建一个 `Comparator`（`lastThenFirst`；第 58–60 行），该 `Comparator` 按姓比较两个 `Employees`，然后按名比较。我们使用 `Comparator` 方法 `comparing` 来创建一个 `Comparator`，该比较器在 `Employee` 上调用 `byLastName` 以获取其姓。使用生成的 `Comparator`，我们调用 `Comparator.thenComparing` 来创建一个 `Comparator`，该比较器按姓比较 `Employees`，如果姓相同，则按名比较。第 63–67 行使用这个新的 `lastThenFirst` `Comparator` 对员工进行升序排序，然后我们使用第 70–74 行的 `Comparator`，但调用了 `reversed()` 方法，表示按姓名降序排序员工。

```java
// 从 Employee 获取名和姓 Function
Function<Employee, String> byFirstName = Employee::getFirstName;
Function<Employee, String> byLastName = Employee::getLastName;

// 按姓、名比较 Employees 的 Comparator
Comparator<Employee> lastThenFirst =
    Comparator.comparing(byLastName).thenComparing(byFirstName);

// 按姓、名升序排序员工
System.out.printf(
    "%nEmployees in ascending order by last name first:%n%s%n",
    list.stream()
        .sorted(lastThenFirst)
        .collect(Collectors.toList()));

// 按姓、名降序排序员工
System.out.printf(
    "%nEmployees in descending order by last name first:%n%s%n",
    list.stream()
        .sorted(lastThenFirst.reversed())
        .collect(Collectors.toList()));
```

## 17.6.6 统计每个部门的人数

下例展示了 Stream 方法 `collect` 和静态方法 `Collectors.groupingBy`，在此例中我们统计每个部门的员工人数。第 107–110 行生成了一个 `Map<String, Long>`，其中每个 `String` 键是部门名称，对应的 `Long` 值是该部门的员工人数。在这种情况下，我们使用了 `Collectors.groupingBy` 的一个版本，它接收两个参数——第一个是对流中的对象进行分类的 `Function`，第二个是另一个 `Collector`（称为下游 Collector）。在此例中，我们使用对 `Collectors` 静态方法的调用作为第二个参数。该方法返回一个 `Collector`，它用于计算给定分类中的对象数量，而不是将它们收集到 `List` 中。第 111–113 行输出来自 `Map<String, Long>` 的键值对。

```java
// 统计每个部门的员工人数
System.out.printf("Count of Employees by department:%n%n");
Map<String, Long> employeeCountDepartment =
    list.stream()
        .collect(Collectors.groupingBy(Employee::getDepartment,
            Collectors.counting()));
employeeCountDepartment.forEach(
    (department, count) -> System.out.printf(
        "%s has %d employee(s)%n", department, count));
```
