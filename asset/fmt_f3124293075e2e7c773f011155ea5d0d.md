## Java 简介

想象你正在走在玩具过道，试图为你的生日挑选想要的玩具。有太多选择了！你将如何决定买哪一个呢？在选择要使用的编程语言时，选择几乎和玩具店里的玩具一样多。你可以把 Java 想成一辆玩具汽车。你可以在任何玩具店找到玩具汽车，而 Java 是最常用的编程语言之一。

### 什么是 Java？

Java 是一种面向对象的语言（OOP），这意味着它关注对象。对象类似于现实生活。当你开始一个项目时，要做的第一工作是创建一个类。类描述了对象将如何行为。Java 已经创建了一些类，但你也可以创建自己的类。Java 用于创建互联网上的程序，还用于各种智能手机应用程序。Java 用于创建大多数 Android 应用。你可能会惊讶你每天遇到的多少设备和应用程序是在 Java 的帮助下运行的。

### 学习规则

在开始使用 Java 之前，你需要了解规则。了解这些规则将帮助你创建无错误的程序。

- 规则 1：编码者必须知道他们想做什么。
- 规则 2：编码者必须使用被称为“命令”的特殊单词。
- 规则 3：编码者需要考虑“组”。
- 规则 4：编码者必须使用逻辑，使用 AND、OR、NOT。
- 规则 5：编码者必须探索它是如何工作的。

## 变量与数据类型

**变量**是放置对象或信息的地方。这些信息可以是字母、数字或其他字符。在程序中使用变量时，你必须先给它起一个名字（例如“tax”），然后用数据类型来定义它。

在处理数字时，你会使用 `int`、`long`、`float` 和 `double` 数据类型。`int` 类型是 `integer`（整数）的缩写，用于较小的整数。`long` 类型用于非常大的整数；`float` 用于带有小数点的数字；而 `double` 用于带有小数点的非常大的数字。

如果我们让程序计算包含销售税的物品成本，我们可能会使用一个名为“tax”的变量和数据类型 `float`。

```java
Java 的许多不同变量存储信息。Java 中最基础的变量被称为原始类型（primitives）。这些包括 "byte"、"short"、"int"、"long"、"float"、"double"、"char" 和 "boolean"。
```

## 代码规范

命名变量时，你需要编写不带空格的名字。程序员使用驼峰命名法（CamelCase）或蛇形命名法（snake_case）等命名系统，而不是在变量名的单词之间使用空格。CamelCase 在每个单词的首字母使用大写，就像驼背上的峰一样。Snake_case 使用下划线连接单词。准确记住你是如何命名变量和程序的非常重要，因为如果你输入的字母大小写与你创建它们时使用的不相同，它们将无法运行。

## 你好世界！

Hello World 是一个基础程序，告诉计算机打印或显示文本“Hello world!”要编写此程序，你首先必须在你的 IDE 或文本编辑器中创建一个新项目，并命名为“HelloWorld.java”。

接下来，你将创建一个类来解释程序的目的。然后，编写你的主方法（main method），它是程序运行时执行的第一行代码。Java 中的主方法就像一个待办事项列表：主方法中始终使用以下单词：`public static void main(String [] args){`。程序的最后一行是打印行，它告诉计算机在程序每次运行时都打印一次“Hello world!”。这意味着这些词将在运行程序的屏幕或终端上显示。

```java
public class HelloWorld {

    public static void main(String[] args) {
        System.out.println("Hello world!");
    }
}
```

### 良好的编程

在创建 Java 程序时，确保你添加了注释。注释为程序员提供有关程序的信息，例如创建者的名字或代码的功能。对于任何可能想使用你的程序的人来说，注释将非常有帮助。

## 词汇表

**应用程序 (application)**：运行在计算机、手机、平板电脑或浏览器上的软件程序。

**命令 (command)**：告诉计算机执行某些操作的代码或消息。

**数据类型 (data type)**：存储在变量中的数据类型。

**诊断 (diagnostic)**：用于定位程序中的问题。

**环境 (environment)**：计算机硬件和软件的结合，允许用户执行各种任务。

**文件扩展名 (file extension)**：构成文件名最后部分的字母和数字，例如 `.docx` 或 `.txt`。

**函数 (function)**：执行特定任务程序部分。

**输入 (input)**：输入计算机的信息。

**逻辑 (logic)**：思考或理解某事的正确或合理的方法。

**方法 (method)**：与类相关的过程或任务列表。

**教程 (tutorial)**：提供特定主题信息的书籍或引导程序。

**变量 (variable)**：可以根据条件或传递给程序的其他信息而改变的占位值。
